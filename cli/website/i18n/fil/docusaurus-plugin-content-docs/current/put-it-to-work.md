# Gamitin ito

Ang tagasalin ay para gamitin. Narito ang mga paraan para magamit ang sa inyo, mula sa pinakapayak
hanggang sa pinakamalaki — at ang nag-iisang panuntunang sumasaklaw sa lahat ng ito: **ang mga taong
may hawak ng mga salita ang nagpapasiya kung ano ang lalabas sa inyong computer.**

## Subukan ito sa inyong browser

Ang pinakamabilis na paraan. Sisimulan ng mga kagamitan ang inyong tagasalin sa inyong computer at bibigyan
kayo ng pahinang bubuksan sa inyong web browser. Mag-type ng pangungusap, tingnan ang salin.
Walang anumang lalabas sa inyong computer. Kung ang inyong pangungusap ay may salitang hindi kailanman
nakita ng tagasalin sa mga aralin nito, sasabihin ng pahina kung alin — malamang na mali ang linyang iyon,
gaano man ito kahusay basahin.

Kung natuto ang inyong tagasalin mula sa mga pribadong pangungusap, maaari nitong ulitin ang mga ito — kaya
hindi ipapasa ng try tool ng mga rail ang mga salin nito sa inyong AI assistant (ipapadala kasi
ng mga iyon ang mga ito sa kompanya ng assistant). Sa halip, ibinibigay nito sa inyo ang address ng pahina,
at kayo mismo ang titingin doon. Ang isang assistant na nakakapagpatakbo ng mga command sa
inyong computer ay maaari pa ring magtanong nang direkta sa tagasalin, kaya sabihan itong huwag gawin iyon.

## Magsalin ng mga dokumento

Magbigay sa mga kagamitan ng isang file ng mga pangungusap, at isasalin ng mga ito ang bawat linya sa isang bagong
file, sa inyong computer, gamit ang mga setting kung saan sinubukan ang tagasalin.
Ang bagong file ay sakop ng parehong mga panuntunan gaya ng mga pangungusap kung saan natuto
ang tagasalin.

## Patakbuhin ito bilang isang serbisyo

Maaaring patakbuhin ng mga kagamitan ang inyong tagasalin bilang isang maliit na serbisyo sa inyong computer, upang
makahingi rito ang iba pang mga programa ng mga salin. Bilang default, tanging mga programa lamang sa
parehong computer ang makakaabot dito, at maaari itong humingi ng password.

Ang paggawa nitong maabot mula sa iba pang mga computer ay isang mas malaking hakbang. Para sa isang tagasalin
na natuto mula sa mga pribadong pangungusap, tatanggi ang mga kagamitan hanggang sa pangalanan ninyo kung sino,
mula sa mga taong may hawak ng mga salita, ang sumang-ayon — at nakasulat iyon.

## Ikonekta ito sa isang app

Kung gumagawa kayo ng app, maikokonekta ng mga kagamitan ang inyong tagasalin dito, upang ang
mga salita ng app ay maisalin ng inyong tagasalin. Parehong panuntunan ang umiiral: ang isang
tagasalin na natuto mula sa mga pribadong pangungusap ay kokonekta lamang kapag naipangalanan
na ninyo kung sino ang sumang-ayon.

## Sa iba pang mga computer at telepono

Nasa computer na bumuo rito ang inyong tagasalin. Upang magamit ito ng isang paaralan o opisina
mula sa iba pang mga computer o telepono, kailangang maabot ito mula sa mga iyon —
sa pamamagitan ng pagpapatakbo rito bilang isang serbisyo sa inyong network, o sa loob ng isang app. Parehong mas malalaking
hakbang ang mga ito, at para sa isang tagasalin na natuto mula sa mga pribadong pangungusap, parehong naghihintay ang mga ito
ng pagsang-ayon mula sa mga taong may hawak ng mga salita. Kung kailangan ninyo ng tulong sa bahaging ito,
[mag-usap tayo](/docs/getting-help).

## Isalin ang mga salita ng isang app o website

Para sa pagsasalin ng mga button, menu, at pahina ng isang app o website — at
pagpapanatiling napapanahon sa mga ito habang nagbabago ang orihinal —
nasa [Magsalin ng app o website](/docs/translate-an-app-or-website) ang buong
paliwanag.

## Sa pang-araw-araw na paggamit: tagapagsalita ang may huling salita

Gaano man kaganda ang mga marka, dapat basahin ng isang taong nagsasalita ng wika ang anuman
bago ito ilathala. Ang isang magandang paraan ng paggawa ay mga draft: ang tagasalin ang nagsusulat, ang
tagapagsalita ang nagwawasto. Ang bawat pagwawasto ay isa ring regalo para sa susunod na yugto — ito
mismo ang bahaging nagkamali ang tagasalin.

Kapag may maling nailabas, itama ito nang hayagan at sabihin kung ano ang binago.
Ang mga pagkakamaling napansin at inako ay nagbubuo ng higit na tiwala kaysa sa isang tagasaling nag-aangking
perpekto.
