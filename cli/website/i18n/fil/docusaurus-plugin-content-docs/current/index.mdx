# Pagbuo at pag-deploy ng machine translation nang nasa riles at may mga bantay-proteksyon

**Bumuo ng tagasalin para sa inyong wika mula sa mga pangungusap na mayroon na kayo.**

- **Nasa riles:** bawat hakbang ay nakalatag para sa inyo, nang sunod-sunod.
- **May mga bantay-proteksyon:** mga pagsusuri na pumipigil sa mga karaniwang pagkakamali, at nagpapanatili sa inyong mga salita sa inyong mga kamay.

Binuo nang isinasaalang-alang ang mga komunidad ng low-resource at Katutubong wika.

**Bago po rito?** [Basahin muna ang kuwento](/docs/what-is-champollion) — apat na maikling
pahina, mga dalawampung minuto.
