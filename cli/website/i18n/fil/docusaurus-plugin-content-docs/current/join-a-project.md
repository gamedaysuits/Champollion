# Sumali sa isang proyekto

Ang isang tagasalin para sa isang wikang kakaunti ang nakasulat na mga pangungusap ay nangangailangan ng maraming kamay.
Ang **Sumali sa isang proyekto** ang paraan upang mahanap nila ang isa't isa: inililista ng mga taong bumubuo ng tagasalin ang kanilang proyekto, sinasabi kung ano ang makatutulong, at nag-aalok naman ang iba nito.

## Kung nais ninyong tumulong

Tingnan ang mga proyekto sa pahinang [Sumali sa isang proyekto](/join). Ipinapakita ng bawat isa ang
dalawang wika, kung para saan ang proyekto, at kung ano ang hinihiling ng mga may-hawak nito —
mga pangungusap sa ilang partikular na paksa, talaan ng mga salita, isang pamamaraang susubukan.

Kapag may inialok kayo:

- **Ipinapadala ninyo ito sa proyekto, hindi sa publiko.** Ang inyong file ay ia-upload sa
  imbakan ng proyekto ng Champollion, kung saan kayo lamang, ang mga may-hawak ng proyektong iyon, at
  ang mga taong nagpapatakbo ng imbakan na iyon ang makapagbubukas nito.
- **Hawak ito ninyong dalawa.** Kayo ang nagsumite nito; sila ang magpapasya kung tatanggapin
  ito. Kapag tinanggap nila ito, itatala sa isang tala kung sino ang nag-alok nito, sino ang tumanggap nito,
  at kung ano ang napagkasunduan.
- **Makikita nila kung sino kayo.** Makikita ng mga may-hawak ng proyekto ang pangalan at email na
  ginamit ninyo sa pag-aalok, upang maabot nila kayo. Hindi kailanman nagpapakita ng email ang pampublikong pahina.
- **Maaari silang tumanggi.** Maaaring tanggihan ng isang proyekto ang isang alok.
- **Maaari ninyo itong bawiin** bago nila ito tanggapin. Ang pagbawi (o ang kanilang
  pagtanggi) ay nagbabago sa katayuan ng alok ngunit hindi nagbubura sa file, at maaari pa ring buksan
  ng mga may-hawak ng proyekto ang file — kaya ialok lamang ang handa kayong panatilihin nila.
- **Nauuna ang tala nito.** Hindi mag-aalok ang mga tool ng file na minarkahang pribado, o
  ng file kung saan hindi pa sumasang-ayon ang lahat ng tagapagsalita nito — ang mga may-hawak lamang nito ang makapagbabago niyan.

Ang hindi ninyo makukuha mula sa isang proyekto: ang mga pangungusap nito. Walang anuman mula sa kanila ang ipapadala
sa inyo nang walang pagsang-ayon nila.

## Kung bumubuo kayo ng tagasalin

Maaari ninyong ilista ang inyong proyekto kapag nasimulan na ito sa rails. Sasabihin ninyo:

- ang dalawang wika, at kung para saan ang tagasalin,
- ang pangalang nais ninyong ipakita — hindi kailanman ang inyong email,
- kung ano ang higit na makatutulong.

Bawat listahan ay sumasailalim sa maikling pagsusuri bago ito lumitaw, upang manatiling mapagkakatiwalaan
ang pahina. Kapag may nag-alok ng isang bagay, kayo ang magpapasya: tanggapin ito, at
darating ito sa inbox ng inyong proyekto kalakip ang isang talang nagpapangalan sa inyong dalawa, handang ipasok
tulad ng anumang file — o tanggihan ito.

## Ano ang maaaring ialok ngayon

Mga file: mga pangungusap, talaan ng mga salita, at mga paraan ng pagsasalin na susubukan. Ang pagtulong sa iba pang paraan —
pagsusuri ng mga draft mula sa malayo, o pagpapahiram ng lakas ng kompyuter — ay hindi pa bahagi nito.

Kapag wala pang nakalistang mga proyekto, tapat itong sinasabi ng pahina.
