# Ang inyong mga salita, ang inyong mga panuntunan

Ang wikang ibinahagi nang may pagtitiwala ay napakadalas nang naitala, nakolekta, o ginamit upang
sanayin ang teknolohiya ng iba — at pagkatapos ay hinawakan ng mga taga-labas, habang ang
mga taong nagmamay-ari ng wika ay kinakailangan pang humingi ng pahintulot para sa sarili nilang mga salita. Binuo ang mga rail upang hindi iyon mangyari rito.

Simple lamang ang panuntunan: **ang mga taong may hawak ng mga salita ang nagpapasya kung ano ang mangyayari sa mga ito.** Itinatala ng mga kagamitan ang mga pasyang iyon, at sumusunod sa mga ito.

## Kung saan napupunta ang inyong mga salita

Bilang default, wala itong pinupuntahan. Nananatili ang inyong mga file sa inyong computer. Dinadala ng mga kagamitan ang mga ito kung nasaan ang mga ito, at ipinapakita lamang sa inyong AI assistant ang mga bilang at mga pangalan ng column.

Ipinapakita ng [Kung saan napupunta ang inyong data](/your-data) ang bawat sitwasyon nang magkatabi: ang inyong
mga file, kung ano ang sinasabi sa inyong assistant, ang output ng isang tagasalin, ang isang test set na
pinili ninyong irehistro, at ang ilang mga bagay na talagang lumalabas sa inyong computer — tulad ng
code ng wika, kapag hinahanap ng mga kagamitan ang pampublikong information card nito.

## Ang tala sa tabi ng bawat file

Ang bawat file ay nagkakaroon ng maikling tala, na isinulat ng mga kagamitan mula sa inyong mga sagot:

- kung kanino ito pagmamay-ari, at kung kaninong mga salita ang nasa loob nito;
- kung sumang-ayon ang mga taong iyon — *oo*, *hindi pa*, o *may ilang tumanggi*;
- kung maaaring matuto mula rito ang isang tagasalin;
- kung maaari ba itong lumabas kailanman sa computer na ito.

Binabasa ng bawat kagamitan ang tala at sumusunod dito — kabilang ang pag-alok ng file sa proyekto ng
iba, na tumatanggi sa isang pribadong file, o sa isang file kung saan hindi lahat ng tagapagsalita ay
sumang-ayon. Nagsisimula ang mga file bilang pribado. Pagkatapos ng
unang sagot, maaari lamang gawing mas mahigpit ng mga kagamitan ang mga panuntunan — maliban sa pagtatala ng
*oo* mula sa isang taong hindi pa natatanong noon. Ang pagpapaluwag ng panuntunan ay isang bagay na
mano-manong ginagawa nang sadya ng mga taong may hawak ng mga salita.

## Sa inyo ang anumang binuo mula sa inyong mga salita

Natututo ang isang tagasalin mula sa inyong mga pangungusap, kaya dala nito ang inyong mga panuntunan:

- Ang isang tagasalin na natuto mula sa mga pribadong pangungusap ay itinuturing ding pribado,
  dahil maaari nitong ulitin ang natutuhan nito. Nananatili ang mga salin nito sa inyong
  computer maliban kung sumang-ayon ang mga taong may hawak ng mga salita, at sabihin kung sino ang sumang-ayon.
- Hindi nag-aangkin ang Champollion ng pagmamay-ari sa anumang tagasalin, talaan ng mga salita, o anupamang
  ibang binuo mula sa mga salita ng isang komunidad — at wala itong hangaring magmay-ari. Ang pagsusulat ng mga kagamitan
  ay hindi nagiging dahilan upang maging may-ari kami ng anumang bubuuin ninyo gamit ang mga ito.
- Maaaring ibahagi ang mga marka nang wala ang mga pangungusap. Maaari ninyong ilathala kung gaano kahusay ang
  naging pagganap ng tagasalin, at panatilihing pribado ang bawat pangungusap.

## Mga koleksyon ng ibang tao

Kung gagamit kayo ng mga pangungusap na inilathala ng iba, kasama rin ang kanilang mga panuntunan:

- **Kapag nagpapadala ng mga pangungusap ang mga kagamitan, sinusunod ng mga ito ang lisensya.** Ang isang koleksyon
  na may kakaiba o hindi malinaw na lisensya ay hindi kailanman binibigyang-kahulugan sa ngalan ng mga may-ari nito: hindi ito ipinapadala hangga't hindi sinasabi ng mga may-ari nito kung ano ang pinapayagan. Kung komersyal ba ang inyong sariling
  paggamit ay isang bagay na hindi masusuri ng anumang kagamitan — bahagi ninyo iyon.
- **Ang pagpapadala ng mga pangungusap sa isang panlabas na AI ay isang pasya.** Ang pagsubok sa isang modelo ng AI
  ay nangangahulugan ng pagpapadala ng mga pangungusap dito. Ang mga koleksyong may payak na di-komersyal na lisensya
  ay napupunta lamang sa mga serbisyong nangangakong hindi matututo mula sa ipinadala sa kanila.
  Ang mga koleksyong may hindi malinaw na mga tuntunin ay hindi ipinapadala kailanman hangga't hindi sumasang-ayon ang kanilang mga may-ari.
  Ang mga selyadong set ay hindi kailanman lumalabas sa computer na humahawak sa mga ito.
- **Hindi nagho-host ang Champollion ng mga koleksyon.** Itinuturo ng mga kagamitan kung saan
  nakalathala ang isang koleksyon, at kinukuha ito mula roon. Dalawang eksepsiyon: ang mga file na
  iniaalok ng isang tao sa pamamagitan ng [Sumali sa isang proyekto](/docs/join-a-project) ay nakaimbak sa
  project storage ng Champollion, at ang isang nai-publish na marka para sa isang may bukas na lisensyang
  test set ay maaaring magsama ng mga pangungusap nito.

## Ang hindi mapipigilan ng anumang kagamitan

Maingat ang mga kagamitan, ngunit may ilang bagay na nakasalalay sa mga tao:

- **Maaaring magbukas ng file ang inyong AI assistant kung hihilingin ninyo rito.** Ipinapadala ng karamihan sa mga assistant
  ang nababasa ng mga ito sa kumpanyang nagpapatakbo sa kanila. Para sa mga salitang nais ninyong panatilihing
  pribado, gumamit ng assistant na tumatakbo sa inyong sariling computer, o huwag itong hilingang
  buksan ang mga ito.
- **Kahit sino ay maaaring mag-paste ng mga salita sa isang chat.** Hindi nakikita ng mga kagamitan ang pagyayaring iyon.
- **Hindi matutukoy ng mga kagamitan kung sino ang sumagot.** Kapag nagtanong ang mga rail kung sino ang may hawak ng isang file,
  o kung sumang-ayon ang isang tagapagsalita, dapat ang tamang tao mismo ang sumagot para sa kanyang sarili.

## Ang aming bahagi

Bumubuo kami upang maangkin at makontrol ng mga komunidad ang kanilang data ng wika, at
ang anupamang gawa mula rito. Kung magtatagumpay man kami ay nasa mga komunidad ang paghusga — nagsusumikap
kami patungo rito, at hindi namin ipinagmamalaking narating na namin ito.

Hindi namin kailanman papangalanan ang isang komunidad, bansa, o organisasyon bilang kasosyo, o bilang may hawak
ng susi, nang walang pahintulot nito. Kung makita ninyong pinangalanan dito ang inyong komunidad nang walang
pahintulot na iyon, sabihin sa amin, at tatanggalin namin ito.

## Mga pagtutol at pagpapatanggal

Kung may anumang bagay rito na mali, walang paggalang, o gumagamit sa mga salita o
pangalan ng inyong komunidad sa paraang hindi ninyo sinang-ayunan, nais naming marinig ito — sa sarili ninyong mga salita. Hindi
ninyo kailangan ng account.

- **Sumulat sa** [info@champollion.dev](mailto:info@champollion.dev), o gamitin
  ang form ng mensahe ng gabay sa site (ang chat panel → *Magpadala ng mensahe*). Upang humiling
  na may tanggalin, ilagay ang **Takedown** sa paksa, o piliin ang
  *Takedown* sa form.
- **Ang aming default ay ang kumilos.** Halos wala kaming hino-host na mga pangungusap ng kahit sino, kaya ang karamihan sa
  mga pagpapatanggal ay isang talaan, isang pagsipi, o isang field sa isang pahina — at mabilis naming
  tinatanggal ang mga iyon.
- **Sinasabi namin kung ano ang ginawa namin.** Kung hindi namin magawa ang inyong hinihiling, sinasabi namin kung bakit, at kung sino
  ang nagpapasya.
- **Mga problema sa seguridad:** [security@champollion.dev](mailto:security@champollion.dev).
