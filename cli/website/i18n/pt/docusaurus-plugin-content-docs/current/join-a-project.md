# Participar de um projeto

Um tradutor para uma língua com poucas frases escritas precisa de muitas mãos.
**Participar de um projeto** é como essas mãos se encontram: quem está construindo um tradutor
lista seu projeto, diz o que ajudaria, e outras pessoas oferecem.

## Se você quer ajudar

Navegue pelos projetos na página [Participar de um projeto](/join). Cada um mostra as
duas línguas, para que serve o projeto e o que os responsáveis estão pedindo —
frases sobre determinados assuntos, uma lista de palavras, um método para testar.

Quando você oferece algo:

- **Você envia para o projeto, não para o público.** Seu arquivo é enviado para o
  armazenamento de projetos do Champollion, onde apenas você, os responsáveis por esse projeto e
  as pessoas que administram esse armazenamento podem abri-lo.
- **Ele pertence a ambos.** Você o enviou; eles decidem se vão aceitá-lo.
  Quando aceitam, uma nota registra quem o ofereceu, quem o aceitou
  e o que foi combinado.
- **Eles veem quem você é.** Os responsáveis pelo projeto veem o nome e o e-mail que você
  usou ao oferecer, para que possam entrar em contato. A página pública nunca mostra um e-mail.
- **Eles podem recusar.** Um projeto pode recusar uma oferta.
- **Você pode retirá-la** antes que ela seja aceita. Retirar (ou a recusa por parte deles)
  muda o status da oferta, mas não exclui o arquivo, e os responsáveis pelo projeto
  ainda podem abri-lo — portanto, ofereça apenas aquilo que você não se importa que
  eles guardem.
- **A nota vem primeiro.** As ferramentas não vão oferecer um arquivo marcado como privado, ou
  cujos falantes não tenham todos concordado — apenas os responsáveis podem alterar isso.

O que você não receberá de um projeto: as frases dele. Nada deles é enviado
a você sem o sim deles.

## Se você está construindo um tradutor

Você pode listar seu projeto assim que ele for iniciado nos trilhos. Você vai informar:

- as duas línguas e para que serve o tradutor,
- o nome que você quer que apareça — nunca o seu e-mail,
- o que mais ajudaria.

Cada publicação passa por uma breve revisão antes de aparecer, para que a página continue
confiável. Quando alguém oferece algo, você decide: se aceitar, o item
chega na caixa de entrada do seu projeto com uma nota identificando vocês dois, pronto para ser
importado como qualquer arquivo — ou você pode recusá-lo.

## O que pode ser oferecido hoje

Arquivos: frases, listas de palavras e métodos de tradução para testar. Ajudar de outras formas —
revisando rascunhos à distância ou cedendo poder computacional — ainda não faz parte disso.

Quando ainda não houver nenhum projeto listado, a página diz isso com sinceridade.
