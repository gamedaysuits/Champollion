# แยกประโยคทดสอบของคุณไว้ต่างหาก

ก่อนที่ตัวแปลภาษาใดๆ จะเริ่มเรียนรู้ คุณต้องแยกประโยคไว้จำนวนหนึ่งเพื่อนำมาใช้ทดสอบ นี่คือขั้นตอนที่สำคัญที่สุดบนรางนำทาง ผลลัพธ์ทั้งหมดที่คุณจะได้เห็นจะถูกวัดผลจากประโยคเหล่านี้ ดังนั้นหากประโยคเหล่านี้ผิด ผลลัพธ์ทุกอย่างก็จะผิดไปด้วย

## ทำไมขั้นตอนนี้จึงสำคัญ

ลองจินตนาการถึงการทดสอบนักเรียนด้วยคำถามเดียวกับที่อยู่ในการบ้านของพวกเขา นักเรียนจะดูเก่งกาจมาก แต่คุณจะไม่ได้เรียนรู้อะไรเลยเกี่ยวกับสิ่งที่พวกเขาทำได้จริงๆ ตัวแปลภาษาก็เช่นเดียวกัน หากทดสอบด้วยประโยคที่มันเคยเรียนรู้มา มันก็แค่จำประโยคนั้นได้เท่านั้น

ดังนั้น ประโยคทดสอบจึงต้องถูกแยกเก็บไว้ต่างหาก ตัวแปลภาษาจะไม่เคยได้เรียนรู้จากประโยคเหล่านี้ และประโยคเหล่านี้จะถูกใช้เพื่อการประเมินผลเท่านั้น

## การเลือกประโยคทดสอบที่ดี

- **ผ่านการตรวจสอบโดยผู้พูดที่เชี่ยวชาญ** แต่ละประโยคและคำแปลควรถูกต้องตามวิธีที่ชุมชนของคุณพูดจริง
- **เป็นประโยคจริงที่คุณต้องการให้แปล** สิ่งที่พูดในชีวิตประจำวันเวลาอยู่บ้าน เขียนในบันทึกข้อความ หรือใช้สอนในชั้นเรียน ซึ่งเป็นประเภทประโยคที่ตัวแปลภาษานี้ถูกสร้างขึ้นมาเพื่อใช้งาน
- **มีความหลากหลาย** มีทั้งคำถาม ประโยคบอกเล่า คำขอร้อง ทั้งประโยคสั้นและประโยคยาว
- **ไม่คัดลอกมาจากประโยคที่คุณจะใช้สอน** เขียนขึ้นมาใหม่ หรือนำมาจากแหล่งข้อมูลอื่นแยกต่างหาก
- **สะกดในรูปแบบเดียวกันกับส่วนที่เหลือ** ตกลงร่วมกันเกี่ยวกับวิธีสะกดภาษาให้เป็นแบบเดียวกันก่อนเริ่มต้น
- **มากเท่าที่ผู้พูดของคุณจะตรวจได้** สองสามโหลก็ถือเป็นจุดเริ่มต้นที่ดี แต่หากมีน้อยเกินไป ผลลัพธ์แต่ละครั้งจะไม่ละเอียด และเครื่องมือจะแสดงช่วงผลลัพธ์ที่กว้างแทนที่จะเป็นตัวเลขเดียว หากมีสักสองสามร้อยประโยค คุณจะเห็นความแตกต่างที่ละเอียดยิ่งขึ้น

## ระบบรางปกป้องประโยคเหล่านี้อย่างไร

คุณเก็บประโยคเหล่านี้ไว้ในที่ของมันเอง นั่นคือชั้นวางชุดทดสอบ (test shelf) และเครื่องมือจะทำเครื่องหมายไว้:

- เป็นส่วนตัว: เก็บไว้ในคอมพิวเตอร์เครื่องนี้ เว้นแต่ผู้ที่ถือครองจะตัดสินใจเป็นอย่างอื่น
- ห้ามนำไปใช้สอนหรือเรียนรู้โดยเด็ดขาด
- ไม่แสดงออกมาในสิ่งที่เครื่องมือพิมพ์หรือแสดงผล

จากนั้น ก่อนที่การสอนจะเริ่มขึ้น ทุกประโยคที่ตัวแปลภาษาจะได้เรียนรู้จะถูกตรวจสอบเทียบกับประโยคทดสอบ ประโยคที่ซ้ำและเกือบซ้ำจะถูกแยกออกไป เพื่อไม่ให้ตัวแปลภาษาได้คะแนนจากความจำ

และทุกครั้งที่เครื่องมือฝึกฝนให้คะแนนประโยคทดสอบ ข้อมูลจะถูกบันทึกไว้ ในแต่ละวัน ความก้าวหน้าจะถูกประเมินจากชุด**ประโยคฝึกฝน**ที่แยกต่างหาก เพื่อให้ประโยคทดสอบยังคงใหม่และไม่ถูกแตะต้อง สำหรับช่วงเวลาที่สำคัญจริงๆ

## สิ่งที่คุณจะเห็น

ในการบันทึกการเดินทางตามลำดับขั้นตอน (recorded walk) ซึ่งเป็นการสาธิตด้วยประโยคที่แต่งขึ้น ครอบครัวได้แยกประโยคที่ตรวจสอบแล้วไว้ <WalkFact of="test.pairs" /> ประโยค เมื่อเครื่องมือตรวจสอบประโยคอื่นๆ เทียบกับประโยคเหล่านั้น เครื่องมือพบว่า <WalkFact of="twins.n" /> ประโยค หรือประมาณ <WalkFact of="twins.pct" /> ใน 100 ประโยค มีคู่ที่เกือบซ้ำอยู่ในประโยคที่ครอบครัวตั้งใจจะใช้สอน ประโยคที่เกือบซ้ำเหล่านั้นจึงถูกแยกออกไปก่อนที่การสอนจะเริ่มต้นขึ้น หากไม่มีขั้นตอนนี้ คะแนนแรกที่ได้คงจะดูดีเกินความเป็นจริง

## การแบ่งปันชุดทดสอบในภายหลัง

ประโยคทดสอบของคุณสามารถอยู่บนคอมพิวเตอร์ของคุณตลอดไปได้ ซึ่งนี่คือค่าเริ่มต้น หากในอนาคตคุณต้องการให้ผู้อื่นสามารถวัดผลเทียบกับประโยคเหล่านี้ได้ เครื่องมือก็สามารถลงทะเบียนชุดข้อมูลได้ที่หนึ่งในสี่ระดับ:

- **เก็บไว้ที่นี่** — ไม่เคยลงทะเบียน และไม่มีสิ่งใดออกจากคอมพิวเตอร์เครื่องนี้
- **ระบุไว้แบบส่วนตัว** — มีการแชร์เฉพาะคำอธิบายของชุดข้อมูลเท่านั้น ไม่แชร์ประโยค ผลลัพธ์สามารถเผยแพร่ได้โดยไม่มีใครเห็นข้อมูล
- **ระบุไว้แบบสาธารณะ** — มีคำอธิบาย พร้อมตัวชี้ไปยังตำแหน่งที่มีการเผยแพร่ชุดข้อมูลอยู่แล้ว ใช้ได้เฉพาะกับชุดข้อมูลที่สัญญาอนุญาตยินยอมเท่านั้น Champollion จะไม่โฮสต์ประโยคเหล่านั้นเอง
- **ปิดผนึก** — ล็อกไว้บนคอมพิวเตอร์ของคุณด้วยคีย์ เพื่อให้ผู้อื่นสามารถทดลองใช้ตัวแปลภาษาของตนกับชุดข้อมูลนี้ได้โดยมองไม่เห็นเนื้อหา
