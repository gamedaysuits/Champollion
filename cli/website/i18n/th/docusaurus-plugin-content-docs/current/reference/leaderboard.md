# ลีดเดอร์บอร์ดและการเผยแพร่

[ลีดเดอร์บอร์ด](/leaderboard) คือบันทึกสาธารณะของการรันการแปลที่ได้รับการวัดคะแนนแล้ว
ทุกคนสามารถเพิ่มข้อมูลลงในนี้ได้: คุณรันชุดเครื่องมือประเมินผล (`mt-eval`) บนเครื่องของคุณเอง
กับชุดข้อมูลที่ลงทะเบียนไว้ แล้วเผยแพร่ผลลัพธ์เป็น **การ์ดการรัน (run
card)** บอร์ดจะเก็บการ์ดนี้ไว้ แต่จะไม่รันเมธอดแทนคุณ บอร์ดจะเก็บข้อความระดับประโยคเฉพาะสำหรับชุดข้อมูลที่มีสัญญาอนุญาตแบบเปิดและสามารถเผยแพร่ต่อได้เท่านั้น —
และจะไม่เก็บข้อความดังกล่าวสำหรับชุดข้อมูลที่ไม่ใช่เชิงพาณิชย์ ถูกจำกัด ปิดผนึก ถูกกักกัน หรือใช้เฉพาะในเครื่องอย่างเด็ดขาด
รวมถึงจะไม่เก็บเมื่อคุณเผยแพร่ด้วย `--scores-only` เช่นกัน

นี่คือบัญชีบันทึกการวัดผล ไม่ใช่คำตัดสินสำหรับระบบแปลภาษาใด ๆ อันดับบนบอร์ดบอกเพียงว่าเมธอดหนึ่ง ๆ ได้คะแนนเท่าใดบนชุดข้อมูลชุดหนึ่งภายใต้เมตริกหนึ่งเท่านั้น ไม่ได้บอกว่าการแปลนั้นดีหรือไม่ และไม่ได้อนุญาตให้ใครนำเมธอดดังกล่าวไปใช้กับภาษาของชุมชน

## สามส่วนที่แยกจากกันอย่างชัดเจน

| | คืออะไร | รันที่ไหน |
|---|---|---|
| **ชุดเครื่องมือ (harness)** ([`mt-eval`](/docs/network/specifications/harness)) | ตัวคิดคะแนน เมื่อได้รับเมธอดและชุดทดสอบ จะสร้างคะแนนและการ์ดการรัน | เครื่องของคุณ |
| **ลีดเดอร์บอร์ด** | ช่องทางการส่งข้อมูลและบัญชีบันทึกการ์ดการรัน จัดดัชนีตามชุดข้อมูลและทิศทางคู่ภาษา | champollion.dev |
| **แผนผังเครือข่าย** | ผลรวมของการรันที่เผยแพร่: คู่ภาษาใดได้รับการวัดผลแล้ว และคู่ภาษาใดยังไม่ได้รับการวัดผล | มุมมองของบัญชีบันทึก ไม่ใช่คอมโพเนนต์แยกต่างหาก |

ไม่มีสิ่งใดเข้าสู่แผนผังได้นอกจากผ่านทางบอร์ด และไม่มีสิ่งใดเข้าสู่บอร์ดได้นอกจากจะมาในรูปของการรันที่ผ่านการคิดคะแนนและมีลายนิ้วมือดิจิทัลกำกับแล้ว การวัดผลที่ไม่มีที่มาที่ไปไม่อาจนำมารวมในนี้ได้

## การทดสอบเปรียบเทียบมาตรฐานสองประเภท

**เบนช์มาร์กสาธารณะ** ใช้ชุดข้อมูลเปิด แต่ละชุดข้อมูลจะถูกลงทะเบียนไว้เป็นการ์ดเมทาดาตาพร้อมตัวชี้สำหรับดึงข้อมูลจากต้นทาง: ตัว harness จะดาวน์โหลดชุดข้อความอ้างอิงจากต้นน้ำขณะรัน ตรวจสอบกับค่า SHA-256 ที่ปักหมุดไว้ และคิดคะแนนเทียบกับข้อมูลที่ดึงมา ข้อมูลสาธารณะอาจเคยอยู่ในข้อมูลฝึกฝนของโมเดลแล้ว ชุดข้อมูลจึงมีเกรดการปนเปื้อนกำกับไว้ ชุดข้อมูลที่ได้เกรด `HIGH` หรือ `MEDIUM` (FLORES+ คือ `HIGH`) หรือไม่ได้รับการตัดเกรดเลย จะใช้ได้สำหรับ **การเปรียบเทียบเชิงสัมพัทธ์เท่านั้น**: ใช้เปรียบเทียบระหว่างเมธอดต่าง ๆ ที่รันบนชุดข้อมูลนั้นได้ แต่ห้ามรายงานว่าเป็นคุณภาพสัมบูรณ์ เฉพาะชุดข้อมูลที่ได้เกรด `LOW` เท่านั้นที่จะจัดอันดับตามคุณภาพสัมบูรณ์ได้ ชุดข้อมูลที่ถูกกักกันจะไม่ถูกนำมาจัดอันดับโดยเด็ดขาด: ฐานข้อมูลจะปฏิเสธคะแนนที่ส่งเข้ามาเทียบกับชุดข้อมูลดังกล่าว ชุดข้อมูลที่ลงทะเบียนไว้และช่องทางสัญญาอนุญาตมีระบุไว้ใน [ชุดข้อมูลประเมินผล](/docs/network/leaderboard/datasets)

**เบนช์มาร์กแบบปิดผนึก** คือชุดทดสอบที่แยกเก็บไว้ต่างหากโดยโฮสต์จะเก็บไว้บนเครื่องของตนเอง ผู้ส่งผลงานจะไม่มีวันได้เห็นชุดข้อมูลเหล่านี้ ผลงานที่ส่งเข้ามาคือโมเดลหรือเมธอดที่โหนดคิดคะแนนของโฮสต์เองจะรันเทียบกับชุดข้อมูลที่ปิดผนึก มีเพียงคะแนนเท่านั้นที่จะถูกส่งออกมา และการรันแบบปิดผนึกทุกครั้งต้องได้รับอนุญาตจากโฮสต์ ในปัจจุบันคีย์ของชุดข้อมูลจะถือโดยผู้จัด ผู้ดูแลคีย์ของชุมชน — ยังไม่มีการแต่งตั้ง Champollion ไม่ได้ถือส่วนแบ่งคีย์ใด ๆ รางวัลจะมีอยู่เฉพาะในการแข่งขันแบบปิดผนึกเท่านั้น ภายใต้เงื่อนไขที่โฮสต์ประกาศไว้ก่อนที่จะมีใครเข้าร่วม วิธีการจัดแข่งขัน: [จัดการแข่งขันแบบอธิปไตย](/docs/network/sovereignty/run-a-sovereign-contest)

## ขอบเขต

- **ข้อความเขียน** บอร์ดนี้วัดผลการแปลข้อความเขียน ได้แก่ เอกสาร สื่อการศึกษาและเอกสารทางการ สตริงข้อความของ UI บอร์ดไม่ได้วัดผลเสียงพูด การแปลล่ามแบบเรียลไทม์ หรือการสนทนาปลายเปิด
- **ภาษาที่ใช้ตัวเขียน** การแปลภาษามือด้วยเครื่องเป็นโจทย์คนละประเภทกัน รายการภาษามือในดัชนีจึงระบุว่า "ยังไม่รองรับ" ([สิ่งใดนับเป็นภาษา](/docs/network/context/what-counts-as-a-language))
- **ทีละชุดข้อมูล** คะแนนจะเปรียบเทียบได้กับคะแนนบนชุดข้อมูลเวอร์ชันเดียวกันเท่านั้น อันดับจะไม่มีการเปรียบเทียบข้ามชุดข้อมูลหรือข้ามภาษา
- **วัดระดับเมธอด ไม่ใช่ระดับประโยค** คะแนนใช้อธิบายประสิทธิภาพของเมธอดบนชุดทดสอบมาตรฐาน จะไม่มีการเผยแพร่ความเชื่อมั่นระดับประโยคสำหรับคำแปลใด ๆ ([ข้อจำกัดทางเทคนิค](/docs/network/honest-limitations#system-vs-output))

## ข้อมูลที่แนบมากับการรันที่เผยแพร่

การ์ดใหม่ทุกใบจะได้รับการคิดคะแนนภายใต้ **scoring standard/1**
([ข้อกำหนดเฉพาะการคิดคะแนน](/docs/network/specifications/scoring)):

- **คะแนนหลัก:** chrF++ ระดับคลังข้อมูล (0–100) พร้อมช่วงความเชื่อมั่นแบบบูตสแตรป 95% และลายเซ็น sacreBLEU เพื่อให้ทุกคนสามารถคำนวณซ้ำได้
- **คะแนนประกอบ:** BLEU, spBLEU และ TER รวมถึง COMET เมื่อมีการคำนวณไว้ โดยจะแสดงไว้ข้างกัน และไม่มีการนำไปคำนวณรวมกับคะแนนหลัก
- **ข้อมูลแยกส่วน:** การวินิจฉัย เช่น การยอมรับของ FST และการตรงกันทุกประการ (exact match) ในกรณีที่มีเครื่องมือเหล่านี้อยู่ ซึ่งจะไม่ถูกนำมาคิดในคะแนนหลักหรือใช้จัดอันดับการรัน
- **ฟิลด์ที่ยกเลิกแล้ว:** `composite`, `quality_tier` และ `cost_adjusted` จะมีค่าเป็น `null` ในการ์ดใหม่ทุกใบ การ์ดเก่าจะยังคงเก็บคะแนนรวมเดิมไว้ ซึ่งจะแสดงเป็น "legacy composite (retired)" ทั้งนี้ไม่มีคะแนนอัตโนมัติใดที่ถือเป็นป้ายกำกับคุณภาพ
- **ที่มาที่ไป:** รหัสชุดข้อมูลและค่า SHA-256 สลักโมเดลที่แน่นอน เงื่อนไข สิ่งที่แจ้งกับโมเดล (SHA-256 ของพร้อมต์ และข้อความพร้อมต์เว้นแต่คุณจะปกปิดไว้) ค่าใช้จ่าย เวอร์ชันของ harness และลายนิ้วมือดิจิทัลของการกำหนดค่า การรันที่เหมือนกันทุกประการจะถูกตัดข้อมูลซ้ำซ้อนเมื่อเผยแพร่ และการทำซ้ำที่เป็นอิสระจะนับเป็นหลักฐานยืนยัน
- **ระดับความน่าเชื่อถือ:** ทุกแถวจะเข้ามาในสถานะ *ทดสอบเทียบมาตรฐานด้วยตนเอง (self-benchmarked)*; *รับรองโดย Champollion (Champollion Verified)* หมายถึงคะแนนได้รับการคำนวณซ้ำจากผลลัพธ์ที่คุณส่งเทียบกับข้อความอ้างอิงที่ปักหมุดไว้ ซึ่งคำสั่งคำนวณคะแนนซ้ำนี้เป็นคำสั่งของผู้ดูแลที่ต้องรันด้วยตนเอง ดังนั้นในปัจจุบันจึงไม่มีแถวใดได้รับการเลื่อนขั้นทันทีที่ส่งเข้ามา; *ตรวจสอบความถูกต้องโดยชุมชน (Community Validated)* จะมอบให้ผ่านการตรวจทานของชุมชนเองเท่านั้น ([ระดับการตรวจสอบความถูกต้อง](/docs/network/leaderboard/rules#verification-tiers))

สกีมาฉบับเต็มดูได้ที่ [ข้อกำหนดเฉพาะของการ์ดการรัน](/docs/network/specifications/run-card)

## การเผยแพร่

```bash
# See exactly what would be uploaded (no sign-in, no network)
mt-eval publish eval/logs/harness/<run-id>_report.json --dry-run

# Publish to the live board (a browser sign-in the first time)
mt-eval publish eval/logs/harness/<run-id>_report.json --prod
```

- จำเป็นต้องมี `--prod` (หรือ `MT_EVAL_ALLOW_PROD=1`) สำหรับการเขียนข้อมูลลงในบอร์ดจริง หากไม่มี ตัว harness จะปฏิเสธ
- `--anonymous` เผยแพร่โดยไม่ต้องลงชื่อเข้าใช้ โดยบอร์ดจะแสดงเป็น "anonymous"
- `--scores-only` เผยแพร่เฉพาะคะแนนรวม แฮช และขนาดของชุดข้อมูล โดยจะไม่เผยแพร่ข้อความต้นฉบับหรือข้อความอ้างอิง — สำหรับคลังข้อมูลของคุณเองหรือคลังข้อมูลส่วนตัว
- `--redact-coaching` แทนที่ข้อความพร้อมต์ด้วยเครื่องหมายกำกับและเก็บค่าแฮชไว้ โดยพร้อมต์ที่มีการแนะนำตัวอย่างของคลังข้อมูลที่ใช้เฉพาะในเครื่องจะถูกปกปิดเป็นค่าเริ่มต้น

คู่มือแบบเป็นขั้นตอนดูได้ที่ [ส่งเมธอด](/docs/network/getting-started/submit-a-method)

## กฎที่ใช้บังคับในทุกกรณี

- **ห้ามฝึกฝนด้วยข้อมูลประเมินผลอย่างเด็ดขาด** เมธอดใดก็ตามที่เคยสัมผัสกับชุดเบนช์มาร์ก — ไม่ว่าจะในฐานะข้อมูลฝึกฝน ตัวอย่างแบบ few-shot รายการคำศัพท์ในพจนานุกรม หรือเนื้อหาในพร้อมต์ — จะถูกตัดสิทธิ์ ([กฎการส่งผลงาน](/docs/network/leaderboard/rules))
- **การตัดสินว่าดีกว่าตัดสินด้วยการทดสอบทางสถิติ ไม่ใช่ตัวเลขสองจำนวน** การที่การรันหนึ่งจะชนะอีกการรันหนึ่งได้นั้น ตัดสินโดยการทดสอบนัยสำคัญแบบจับคู่บน chrF++ หากการทดสอบไม่สามารถแยกความแตกต่างระหว่างอันดับใกล้เคียงได้ จะถือว่าครองอันดับร่วมกัน ([นัยสำคัญ](/docs/network/specifications/significance))
- **ไม่มีการโฮสต์คลังข้อมูลไว้ที่นี่** การลงทะเบียนเป็นเพียงเมทาดาตา ส่วนคลังข้อมูลจะถูกดึงมาจากต้นทาง การรันที่เผยแพร่ของชุดข้อมูลที่มีสัญญาอนุญาตแบบเปิดอาจแนบข้อความระดับประโยคมาด้วยได้ (ตามที่ระบุไว้ข้างต้น)
- **ช่องทางสัญญาอนุญาตเป็นข้อกำหนดเชิงโครงสร้าง** คลังข้อมูลที่ไม่ใช่เชิงพาณิชย์จะถูกแยกออกจากเส้นทางของรางวัล, API และเชิงพาณิชย์ทั้งหมด คลังข้อมูลภายใต้สัญญาอนุญาตที่มีการดัดแปลง จัดทำขึ้นเฉพาะ หรือไม่ได้ระบุไว้ (`LicenseRef-*`) จะปฏิเสธการประเมินผลผ่าน API โมเดลทางไกล จนกว่าจะมีการบันทึกความยินยอมของผู้ถือสิทธิ์ไว้บนการ์ด; สัญญาอนุญาตที่ไม่ใช่เชิงพาณิชย์ตามมาตรฐานจะส่งไปยังโมเดลทางไกลผ่านช่องทางที่ไม่นำข้อมูลไปฝึกฝนต่อเท่านั้น; เซกเมนต์ที่ปิดผนึกจะไม่มีวันถูกส่งออกไปยังภายนอก ชุดข้อมูล EdTeKLA Plains Cree ถูกจัดหมวดหมู่เป็นป้ายกำกับที่ถูกกักกัน และฐานข้อมูลจะปฏิเสธคะแนนใด ๆ ก็ตามที่ส่งเข้ามาเทียบกับชุดข้อมูลเหล่านี้

## สิ่งที่เปิดใช้งานอยู่ในปัจจุบัน

- บอร์ดเปิดใช้งานอยู่ เป็นสาธารณะ และเปิดรับผลงาน เนื้อหาในบอร์ดเป็นข้อมูลแบบสด หน้านี้จึงไม่ได้ระบุรายละเอียดเหล่านั้น — [ดูข้อมูลบนบอร์ด](/leaderboard)
- ทุกแถวในปัจจุบันเป็นแบบทดสอบเทียบมาตรฐานด้วยตนเอง (ดูระดับความน่าเชื่อถือข้างต้น)
- ยังไม่มีรางวัลใดที่เปิดอยู่ และยังไม่มีคะแนนใดผ่านเกณฑ์รางวัล ([ข้อกำหนดเฉพาะของรางวัล](/docs/network/specifications/prizes))
- ยังไม่มีการตรวจทานโดยผู้พูดภาษาของชุมชน ([การตรวจสอบความถูกต้องโดยผู้พูดภาษา](/docs/network/specifications/speaker-validation))
- ยังไม่มีเมธอดใดถูกส่งมอบให้แก่ชุมชนภายใต้เงื่อนไขของการแข่งขัน

[ข้อจำกัดทางเทคนิค](/docs/network/honest-limitations) คือรายการทั้งหมดของสิ่งที่เราไม่ได้กล่าวอ้าง หากเนื้อหาในหน้านี้กับหน้านั้นขัดแย้งกัน ให้ยึดตามหน้านั้นเป็นหลัก
