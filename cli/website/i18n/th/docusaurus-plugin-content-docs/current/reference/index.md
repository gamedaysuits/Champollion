# ข้อมูลอ้างอิง

บันทึกทางเทคนิคฉบับสมบูรณ์ สำหรับนักพัฒนา นักวิจัย และเอเจนต์ AI
[หน้าสำหรับบุคคลทั่วไป](/docs/) จะเล่าเรื่องเดียวกันด้วยภาษาที่เข้าใจง่าย และ
[คู่มือสำหรับเอเจนต์](/docs/agents) จะระบุวิธีที่เอเจนต์ควบคุมระบบ ทุกหน้า
ด้านล่างนี้จะระบุรายละเอียดทั้งหมดอย่างแม่นยำ

## คำสั่ง

- [`champollion`](/docs/reference/cli) — ทุกคำสั่งและแฟล็กของเครื่องมือ
  โปรเจกต์และตัวแปลภาษาสำหรับแอปและเว็บไซต์
- [`nmt-forge`](/docs/network/getting-started/forge-command-reference) — ทุก
  คำสั่งของชุดเครื่องมือฝึกโมเดล สร้างขึ้นจากพาร์เซอร์ของเครื่องมือโดยตรง
- [`mt-eval`](/docs/reference/mt-eval) — ทุกคำสั่งของชุดเครื่องมือ
  ประเมินผล สร้างขึ้นจากพาร์เซอร์ของเครื่องมือโดยตรง
- [เซิร์ฟเวอร์ MCP](/docs/network/getting-started/mcp-server) — ทั้งสองโปรไฟล์
  ทุกเครื่องมือ และทุกอาร์กิวเมนต์

## รูปแบบข้อมูล

- [รูปแบบของเฟรมเวิร์ก](/docs/reference/formats) — project/1, set/1, method/1,
  gate-chain/1, deployment/1 และ service-api/1 จากสคีมาของแต่ละรูปแบบ
- [การ์ดการรัน](/docs/network/specifications/run-card) — สิ่งที่การรัน
  ที่ได้รับการให้คะแนนบันทึกและเผยแพร่
- [ข้อมูลโค้ชชิง](/docs/concepts/coaching-data) — บันทึกไวยากรณ์และรายการ
  คำศัพท์ที่ป้อนให้กับวิธีการแบบ LLM
- [ข้อกำหนดของปลั๊กอิน](/docs/reference/plugin-spec) — แมนิเฟสต์ปลั๊กอินของวิธี
  การ (`method.json`) ที่วิธีการแปลภาษาจัดส่งมาพร้อมกัน
- [การ์ดภาษา](/docs/reference/language-card-spec) — สคีมาของการ์ด
  ใน Atlas

## ข้อกำหนดเฉพาะ

- [การให้คะแนน](/docs/network/specifications/scoring) — scoring standard/1: คะแนน
  chrF++ หลักของคลังข้อมูลพร้อมช่วงความเชื่อมั่นแบบบูตสแตรป 95%, เมทริกมาตรฐาน
  ที่แสดงควบคู่กัน และการวินิจฉัยที่แยกไว้ต่างหาก
- [นัยสำคัญ](/docs/network/specifications/significance) — การทดสอบแบบจับคู่
  และเกณฑ์ในการพิจารณาว่าการรันหนึ่งดีกว่าอีกการรันหนึ่งเมื่อใด
- [อินเทอร์เฟซของวิธีการ](/docs/network/specifications/methods) — วิธีการแปลคืออะไร
  คลาส และดีเพนเดนซีของวิธีการนั้น
- [ความน่าเชื่อถือของเมทริก](/docs/network/specifications/metric-reliability) —
  เมทริกใดที่น่าเชื่อถือสำหรับภาษาประเภทใด โดยอิงจากการตัดสินของมนุษย์
- [เบนช์มาร์ก](/docs/network/specifications/benchmark) — โพรโทคอลที่ทุก
  การรันที่ถูกต้องต้องปฏิบัติตาม
- [ชุดเครื่องมือประเมิน](/docs/network/specifications/harness) — วิธีที่ `mt-eval` ทำงาน
  ให้คะแนน และเผยแพร่
- [การตรวจสอบโดยเจ้าของภาษา](/docs/network/specifications/speaker-validation) — การตรวจสอบ
  โดยมนุษย์ที่คะแนนอัตโนมัติถูกนำมาใช้แทนที่

## ขีดจำกัดทางเทคนิค

- [ขีดจำกัดทางเทคนิค](/docs/network/honest-limitations) — สิ่งที่ไม่ได้กล่าวอ้างเกินจริง:
  ระดับความน่าเชื่อถือที่รายงานด้วยตนเอง, การที่ยังไม่มีการตรวจสอบโดยเจ้าของภาษา, การเก็บรักษาชุดทดสอบแบบปิดผนึก และการไม่มีค่าความเชื่อมั่นรายประโยค

## การจัดชุดทดสอบแบบปิดผนึก

- [จัดการแข่งขันแบบอธิปไตย](/docs/network/sovereignty/run-a-sovereign-contest)
  — คู่มือการดำเนินงานตั้งแต่ต้นจนจบสำหรับชุดทดสอบที่ไม่เคยออกจากเครื่องของโฮสต์
- [โหนดประเมินผลแบบอธิปไตย](/docs/network/sovereignty/sovereign-eval-node) — เครื่อง
  ให้คะแนน: ฮาร์ดแวร์, แอร์แก็ป และพิธีการจัดการคีย์
- [การลงทะเบียนคลังข้อมูล](/docs/network/sovereignty/registering-corpora) —
  ระดับการเปิดเผยและช่องทางสัญญาอนุญาตสำหรับคลังข้อมูลที่คุณครอบครอง
- [ความเป็นเจ้าของและข้อกำหนด](/docs/network/sovereignty/ownership-transfer) และ
  [เทมเพลตข้อกำหนด](/docs/network/sovereignty/terms-templates) — สิ่งที่ผลงานที่ส่งเข้าประกวด
  ต้องส่งมอบ ซึ่งประกาศไว้ล่วงหน้าก่อนจะมีผู้เข้าร่วม
- [รางวัล](/docs/network/specifications/prizes) — ข้อกำหนดสำหรับรางวัล หากมี
  ผู้สนับสนุนเปิดให้ชิงรางวัล

## ลีดเดอร์บอร์ดและการเผยแพร่

- [ลีดเดอร์บอร์ดและการเผยแพร่](/docs/reference/leaderboard) — ลีดเดอร์บอร์ด
  คืออะไร, เบนช์มาร์กทั้งสองประเภท และข้อมูลที่ติดมากับการรันที่ได้รับการเผยแพร่
- [กฎการส่งผลงาน](/docs/network/leaderboard/rules) — สิ่งที่ยอมรับ
  สิ่งที่ถูกตัดสิทธิ์ และระดับการยืนยันความถูกต้อง
- [ชุดข้อมูลการประเมินผล](/docs/network/leaderboard/datasets) — ชุดข้อมูล
  ที่ลงทะเบียนและช่องทางสัญญาอนุญาตของชุดข้อมูลเหล่านั้น
- [ส่งวิธีการ](/docs/network/getting-started/submit-a-method) — ใช้งานชุดเครื่องมือ
  ประเมินและเผยแพร่การ์ดการรัน
- [การสนับสนุนพลังการประมวลผล](/docs/network/getting-started/contributing-compute) —
  รันงานจากคิวสาธารณะด้วยคีย์ของคุณเอง
- [คำถามที่พบบ่อย](/docs/network/getting-started/faq) — เมทริก, โมเดล, FST และ
  การตัดสิทธิ์

## การแปลภาษาสำหรับแอปและเว็บไซต์

- [การแปลภาษาสำหรับแอปและเว็บไซต์](/docs/intro) — สิ่งที่ `champollion sync` ทำได้ และ
  คำแนะนำสำหรับทุกหน้าที่เกี่ยวข้อง: การเริ่มต้นฉบับย่อ, การติดตั้ง, การกำหนดค่า,
  เฟรมเวิร์ก, CI/CD, วิธีการแปล, เนื้อหา, หน่วยความจำการแปล, ประตูตรวจสอบคุณภาพ,
  ความปลอดภัย, สคริปต์, นักแปล และการแก้ไขปัญหา

## The Atlas

- [The Atlas](/docs/atlas) — ดัชนีภาษาคืออะไรและข้อเท็จจริงในดัชนีมีที่มา
  จากไหน
- [ข้อกำหนดของการ์ดภาษา](/docs/reference/language-card-spec) และ
  [ขั้นตอนการอ้างอิง](/docs/reference/language-card-citation-procedure) —
  ทุกฟิลด์และวิธีอ้างอิงแต่ละฟิลด์
- [สิ่งใดบ้างที่นับว่าเป็นภาษา](/docs/network/context/what-counts-as-a-language)
  — คำตอบที่ดัชนีระบุไว้และเหตุผล
- [ส่งข้อมูลเข้าสู่ดัชนี](/docs/network/getting-started/submit-to-the-index) และ
  [การรายงานข้อผิดพลาด](/docs/network/perspectives/reporting-errors-and-owning-corrections)
  — การเสนอรายการใหม่หรือการแก้ไข
