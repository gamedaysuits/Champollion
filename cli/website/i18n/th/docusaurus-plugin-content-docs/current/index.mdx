# การพัฒนาและติดตั้งใช้งานระบบแปลภาษาด้วยเครื่องบนรางพร้อมแนวกันตก

**สร้างระบบแปลภาษาสำหรับภาษาของคุณจากประโยคที่คุณมีอยู่แล้ว**

- **บนราง:** วางทุกขั้นตอนไว้ให้คุณอย่างเป็นลำดับ
- **พร้อมแนวกันตก:** การตรวจสอบที่ช่วยหยุดข้อผิดพลาดทั่วไป และรักษาคำของคุณให้อยู่ในมือคุณ

สร้างขึ้นโดยคำนึงถึงชุมชนภาษาที่มีทรัพยากรน้อยและภาษาชนพื้นเมืองเป็นหลัก

**เพิ่งเคยมาที่นี่ใช่ไหม?** [อ่านเรื่องราวก่อนได้ที่นี่](/docs/what-is-champollion) — หน้าสั้นๆ สี่หน้า ใช้เวลาราวยี่สิบนาที

## คุณต้องการทำอะไร?

### สร้างสิ่งใหม่

- [**ทดสอบระบบแปลภาษาอย่างเป็นธรรมด้วยประโยคของเราเอง**<br/>เปิดโอกาสให้ผู้อื่นได้ลองใช้ระบบแปลภาษากับประโยคของคุณ โดยที่พวกเขาจะไม่มีวันได้เห็นประโยคเหล่านั้น](/docs/network/sovereignty/run-a-sovereign-contest)
