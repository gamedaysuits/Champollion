# ก่อนที่คุณจะเริ่มต้น

ส่วนที่สำคัญที่สุดในการสร้างระบบแปลภาษาไม่จำเป็นต้องใช้คอมพิวเตอร์เลย
คุณสามารถทำทุกอย่างได้ตั้งแต่วันนี้ — แม้กระทั่งก่อนที่เครื่องมือจะเปิดให้ใช้งาน

## พูดคุยกับผู้พูดภาษาของคุณ

ระบบแปลภาษาสร้างขึ้นจากถ้อยคำของผู้คน ดังนั้นจงเริ่มต้นที่ผู้คน บอกให้พวกเขา
ทราบว่าคุณต้องการสร้างอะไรและทำไม ใครบ้างที่จะได้เห็นประโยคของพวกเขา และบอกด้วยว่า
พวกเขาสามารถปฏิเสธได้ สอบถามว่าควรขอบคุณใครและขอบคุณอย่างไร อ่านเพิ่มเติมได้ที่ [การทำงานร่วมกับ
ผู้พูดภาษา](/docs/working-with-speakers)

## ตกลงร่วมกันเรื่องวิธีสะกดคำ

หากผู้คนเขียนภาษาของคุณด้วยวิธีที่ต่างกัน ระบบแปลภาษาก็จะเรียนรู้แบบ
สับสนปนเปกันไปหมด เลือกวิธีใดวิธีหนึ่งสำหรับโครงการนี้ — วิธีที่โรงเรียนใช้ หรือตาม
มาตรฐานของชุมชนคุณ — และระบุไว้ด้วยว่าประโยคเหล่านั้นมาจากภาษาถิ่นใด

## ตัดสินใจว่าถ้อยคำของคุณเป็นของใคร

สำหรับชุดประโยคแต่ละชุด โปรดรับทราบว่าใครเป็นผู้ถือครอง และสามารถนำไปใช้เพื่ออะไร
ได้บ้าง: ระบบแปลภาษาเรียนรู้จากประโยคเหล่านี้ได้หรือไม่ และประโยคเหล่านี้จะถูกส่งออกไปนอกคอมพิวเตอร์ของคุณได้หรือไม่?
ระบบ rails จะถามคำถามเหล่านี้กับคุณ อ่านเหตุผลว่าทำไมเรื่องนี้จึงสำคัญได้ที่ [ถ้อยคำของคุณ กฎเกณฑ์
ของคุณ](/docs/your-words-your-rules)

## เริ่มต้นจดบันทึกประโยค

ยังไม่มีอะไรเขียนไว้เลยใช่ไหม? แค่มีผู้พูดภาษาสักคนก็เริ่มได้แล้ว คนหนึ่งพูด
ประโยคออกมาในภาษานั้น อีกคนพิมพ์ลงในสเปรดชีต พร้อมคำแปลภาษาอังกฤษ
อยู่ข้างกัน — สองคอลัมน์ แถวละหนึ่งประโยค

เขียนสิ่งที่ครอบครัวของคุณพูดกันจริงๆ: ที่บ้าน ที่โรงเรียน ที่ร้านค้า
หรือกับเพื่อนฝูง ประโยคสั้นๆ ในชีวิตประจำวัน
เหล่านี้คือสิ่งที่ช่วยสอนระบบได้ดีที่สุด

## แยกบางส่วนไว้สำหรับทดสอบ

ขอให้ผู้พูดภาษาที่เชี่ยวชาญที่สุดของคุณช่วยตรวจทานประโยคเหล่านั้นสักสองสามโหลอย่างรอบคอบ และ
เก็บประโยคเหล่านั้นไว้ในไฟล์แยกต่างหาก นี่คือประโยคทดสอบของคุณ — ซึ่งเป็นประโยคที่ระบบ
แปลภาษาทุกตัวจะถูกนำมาประเมิน และจะไม่มีวันได้เรียนรู้จากประโยคเหล่านี้ อ่านเหตุผลได้ที่ [แยกประโยคทดสอบ
ของคุณไว้](/docs/your-test-sentences)

## สิ่งที่คุณจะต้องใช้ในภายหลัง

- คอมพิวเตอร์ — เครื่องรุ่นใหม่ ๆ ทั่วไปก็เริ่มใช้งานได้ Mac รุ่นใหม่ หรือคอมพิวเตอร์ที่มีการ์ดจอ
  NVIDIA จะสามารถสร้างตัวแปลภาษาที่ทรงพลังกว่าได้
- พื้นที่ว่างในดิสก์ ตัวแปลภาษาที่ทรงพลังกว่าแต่ละตัวที่เครื่องมือเก็บไว้จะใช้พื้นที่มากกว่า
  หนึ่งกิกะไบต์ โดยระบบจะตรวจสอบว่ามีพื้นที่ว่างก่อนเริ่มการสอน และสามารถล้างตัวแปลภาษา
  จากรอบก่อนหน้าที่ไม่ได้ใช้งานแล้วออกไปได้
- ผู้ช่วย AI ที่ทำงานเป็นแอปบนคอมพิวเตอร์เครื่องนั้น หรือใครสักคนที่
  คุ้นเคยกับการพิมพ์คำสั่งไม่กี่คำสั่ง

เมื่อคุณมีประโยคจำนวนหนึ่งและเครื่องมือเปิดให้ใช้งานแล้ว คุณก็พร้อมแล้ว
