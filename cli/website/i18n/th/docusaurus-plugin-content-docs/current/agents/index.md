# สำหรับ AI เอเจนต์

คุณมาอยู่ที่นี่เพราะมีผู้ขอให้คุณช่วยสร้างระบบแปลภาษาด้วยเครื่องสำหรับ
ภาษาของพวกเขาด้วย Champollion ส่วนนี้คือคู่มือสำหรับคุณ ซึ่งระบุข้อมูลอย่างแม่นยำ
ในจุดที่หน้าเอกสารสำหรับบุคคลทั่วไปใช้คำเรียบง่าย: ชื่อฟิลด์, โหมด, การปฏิเสธคำขอ และคำสั่งต่าง ๆ
ล้วนยกมาจากโค้ดโดยตรง

**อ่าน[สัญญาการปฏิบัติงาน](/docs/agents/contract)ก่อนเป็นอันดับแรก** เนื้อหาส่วนนี้สั้น
และเป็นส่วนที่คุณต้องไม่ทำผิดพลาดเด็ดขาด: สิ่งที่คุณอ่านได้, สิ่งที่คุณต้อง
ถาม, สิ่งที่คุณต้องไม่ตัดสินใจแทนผู้คนโดยเด็ดขาด และกฎข้อใดที่เครื่องมือ
บังคับใช้เทียบกับกฎข้อใดที่มีเพียงคุณเท่านั้นที่ดูแลให้เป็นไปตามนั้นได้

## การเชื่อมต่อ

ระบบ rails คือเซิร์ฟเวอร์ MCP เพิ่มเซิร์ฟเวอร์นี้ลงในการกำหนดค่าของไคลเอนต์ MCP ของคุณ:

```json
{
  "mcpServers": {
    "champollion": { "command": "npx", "args": ["-y", "champollion-mcp-server"] }
  }
}
```

โปรไฟล์เริ่มต้นคือ rails: เครื่องมือหกรายการ — `start_project`,
`project_status`, `run_next_step`, `add_data`, `try_translation` และ
`explain` ทุกขั้นตอนของ rails ยังเป็นคำสั่งเชลล์ทั่วไป
(`champollion`, `nmt-forge`, `mt-eval`) ดังนั้นเอเจนต์ที่ไม่มี MCP จึงสามารถดำเนินการตาม
rails เดียวกันนี้ผ่านเทอร์มินัลได้
