# ทำให้ดีขึ้น ทีละรอบ

ตัวแปลภาษาตัวแรกของคุณเป็นเพียงจุดเริ่มต้น ไม่ใช่จุดสิ้นสุด จากตรงนี้ ระบบจะพัฒนาขึ้นเป็น**รอบ ๆ** ในแต่ละรอบ ผู้พูดภาษาจะตรวจสอบสิ่งที่ตัวแปลเขียน คุณเพิ่มประโยคที่จะช่วยได้มากที่สุด และระบบจะเรียนรู้อีกครั้ง เมื่อสิ้นสุดแต่ละรอบ คุณจะได้รับรายงานสั้น ๆ: มีอะไรเปลี่ยนแปลงบ้าง เครื่องมือมั่นใจแค่ไหน และควรทำอะไรต่อไป

นี่คือหัวใจสำคัญของ rails และเป็นจุดที่เวลาของผู้พูดภาษาจะเกิดประโยชน์สูงสุดเช่นกัน

## ก่อนเริ่มรอบแรก: ใช้เวลาเท่าไร?

rails จะเริ่มต้นด้วยการถามว่าผู้พูดภาษาสามารถสละเวลาให้ได้เท่าไร — ต่อสัปดาห์ และทั้งหมด แต่ละรอบจะปรับขนาดตามเวลานั้น เมื่อผ่านไปสองสามรอบจนเห็นแนวโน้มแล้ว rails จะบอกคุณอย่างตรงไปตรงมาว่าเวลานั้นน่าจะให้ผลลัพธ์ได้แค่ไหน รวมถึงกรณีที่ดูเหมือนว่าจะน้อยเกินไป rails จะไม่เร่งเร้าขอเวลาเพิ่ม เวลาของผู้พูดภาษาย่อมเป็นของพวกเขาเอง

## ในหนึ่งรอบ

1. **รายการสิ่งที่ต้องการ** เครื่องมือจะดูว่าตัวแปลภาษาแปลสิ่งใดผิด แล้วจัดทำเอกสารแบบพิมพ์ได้ซึ่งระบุสิ่งที่จะช่วยได้มากที่สุด: คำที่ไม่เคยพบมาก่อน — โดยขอให้มีสองหรือสามประโยคสำหรับแต่ละคำ เนื่องจากคำที่พบเพียงครั้งเดียวมักจะเรียนรู้ได้ยาก — และประเภทของประโยคที่ระบบมักแปลสะดุด โดยจะเว้นว่างพื้นที่ไว้หนึ่งในสี่ของเอกสาร เพื่อให้คุณยังคงเขียนสิ่งที่คุณต้องการได้ ใช้มากหรือน้อยตามที่คุณต้องการ
2. **ประโยคของคุณ** เขียนประโยค 20 ประโยคขึ้นไปที่คุณต้องการให้แปลจริง ๆ — สิ่งที่คุณจะพูดที่บ้าน เขียนในบันทึกข้อความ หรือสอนในชั้นเรียน มากเท่าที่ผู้พูดภาษาจะสามารถตรวจสอบได้ในสัปดาห์นี้
3. **ตัวแปลภาษาร่างคำแปล** ระบบจะเขียนคำแปลของแต่ละประโยกลงในเอกสารเพื่อให้ผู้พูดภาษาตรวจ ในขณะที่ยังมีประโยคฝึกหัดน้อย บางแถวจะไม่มีคำแปลร่างไว้ — หนึ่งในสองแถวจนกว่าจะมีประโยคฝึกหัดครบ 50 ประโยค จากนั้นจะเป็นหนึ่งในสี่แถวจนกว่าจะครบ 200 ประโยค ผู้พูดภาษาจะเป็นผู้เขียนคำแปลเหล่านั้น และประโยคเหล่านี้จะกลายเป็นประโยคฝึกหัดใหม่ (ซึ่งระบบจะไม่ใช้เรียนรู้)
4. **ผู้พูดภาษาตรวจสอบ** สำหรับคำแปลร่างแต่ละประโยค: ทำเครื่องหมาย **Y** หากถูกต้อง; **N** หากผิด พร้อมระบุว่าควรพูดอย่างไร; **?** หากไม่แน่ใจ เปิดดูในสเปรดชีต หรือพิมพ์ออกมาแล้วพิมพ์เครื่องหมายที่ทำไว้ลงในระบบภายหลัง

   ตั้งแต่รอบที่สองเป็นต้นไป จะมีประมาณหนึ่งในสิบแถวที่นำกลับมาจากเอกสารชุดก่อนหน้าโดยเจตนา — เอกสารจะระบุไว้ที่ด้านบน แต่ไม่ได้บอกว่าเป็นแถวใด ให้ตรวจใหม่เหมือนเป็นประโยคใหม่ ความสม่ำเสมอของผลการตรวจจะบอกให้ทุกคนรู้ว่าสามารถเชื่อถือได้มากน้อยเพียงใด แถวเหล่านี้ใช้เวลาตรวจเพียงไม่กี่วินาทีต่อแถว และจะไม่ถูกนับรวมในผลลัพธ์ของรอบนั้น
5. **เครื่องมืออ่านผลการตรวจ** เครื่องมือจะนับจำนวนคำแปลร่างที่ถูกต้อง ประโยคที่แก้ไขและคำแปลร่างที่ทำเครื่องหมายว่าถูกต้องจะกลายเป็นประโยคใหม่ให้ระบบได้เรียนรู้ — หลังจากที่คุณระบุแล้วว่าเป็นของใคร เช่นเดียวกับไฟล์ทั่วไป
6. **รายงาน** ดูด้านล่าง
7. **เรียนรู้อีกครั้ง** เมื่อคุณตอบตกลง ตัวแปลภาษาจะเรียนรู้จากทุกสิ่งที่มีจนถึงตอนนี้ — โดยทั่วไปจะเป็นการต่อยอดจากตัวที่คุณกำลังใช้อยู่ ทำให้แต่ละรอบใช้เวลาน้อยกว่าการสอนครั้งแรก ตัวใหม่จะถูกนำมาเปรียบเทียบกับตัวที่คุณกำลังใช้อยู่ แบบประโยคต่อประโยค โดยใช้ประโยคฝึกหัดชุดเดียวกัน rails จึงจะเสนอตัวใหม่ให้คุณก็ต่อเมื่อมันดีขึ้นจริงจนไม่ใช่เพราะความบังเอิญ — และจะมีผลใช้งานแทนที่ก็ต่อเมื่อคุณตอบตกลงเท่านั้น มิฉะนั้นตัวที่คุณกำลังใช้อยู่จะยังคงเดิม และเริ่มรอบถัดไป หากมีประโยคฝึกหัดน้อยกว่า 50 ประโยค จะไม่มีคะแนนใดบอกได้ว่าตัวไหนดีกว่ากัน — เครื่องมือจึงไม่คาดเดา ตัวที่คุณกำลังใช้อยู่จะคงเดิม และให้ผู้พูดภาษาเป็นผู้ตัดสินใจแทน (ดูด้านล่าง)

## รายงานประจำรอบ

แต่ละรายงานจะเริ่มต้นด้วยความคืบหน้า ตามด้วยผลการตรวจสอบ และสิ่งที่ควรทำต่อไป:

- **สัดส่วนคำแปลร่างที่ผู้พูดภาษาตรวจว่าถูกต้อง** — ตัวเลขที่สำคัญที่สุด — พร้อมช่วงค่าที่แสดงความมั่นใจของเครื่องมือ
- **คะแนนการฝึกหัด** — ตัวเลขเต็ม 100 สำหรับความใกล้เคียงของตัวแปลภาษา ในประโยคฝึกหัดที่ระบบไม่เคยใช้เรียนรู้ — และตัวแปลภาษาตัวใหม่ทำได้ดีกว่าตัวเดิมจริงหรือไม่
- **การตรวจสอบว่าไม่ได้เพียงแค่ท่องจำ** — ดูว่าการพัฒนาที่ดีขึ้นในประโยคฝึกหัด ปรากฏในประโยคใหม่ด้วยหรือไม่
- **ความน่าเชื่อถือของผลการตรวจ** — เมื่อตรวจแถวที่นำกลับมาแสดงซ้ำครบสิบแถว: ผู้พูดภาษาตรวจแถวเหล่านั้นได้ผลตรงกันบ่อยแค่ไหน และคำแปลร่างที่เคยตรวจว่าผิด ตอนนี้ได้รับการตรวจว่าถูกบ่อยขึ้นหรือไม่ ซึ่งเกิดขึ้นได้เมื่อใครก็ตามเริ่มคุ้นเคยกับตัวแปลภาษา นั่นไม่ใช่ความผิดของใคร และเป็นเรื่องที่ควรทราบ
- **อีกไกลแค่ไหนกว่าจะ "ใช้งานได้จริง"** — เมื่อเห็นการพัฒนาที่ชัดเจนแล้ว จะมีช่วงค่าที่ประเมินว่าต้องใช้ประโยคและเวลาเพิ่มอีกประมาณเท่าใด ทุกครั้งที่ประโยคของคุณเพิ่มขึ้นเป็นสองเท่า โดยช่วงค่านี้จะคำนึงถึงความน่าเชื่อถือของผลการตรวจจากผู้พูดภาษาด้วย
- **สิ่งควรทำต่อไปสองถึงสี่ข้อ** — เช่น *เขียนประโยคด้วยคำเหล่านี้*, *ตรวจเอกสารชุดนี้*, *ลองใช้ตัวแปลภาษาที่ทรงพลังกว่า* หรือ *ขอความช่วยเหลือผ่าน เข้าร่วมโครงการ*

ผู้ช่วยของคุณได้รับคำแนะนำให้ถ่ายทอดข้อมูลทั้งหมดพร้อมความหมายของตัวเลขแต่ละตัว ให้แสดงความยินดีเฉพาะความก้าวหน้าที่เครื่องมือวัดค่าได้จริงเท่านั้น และให้แจ้งว่า *"ไม่มีการเปลี่ยนแปลงที่วัดผลได้"* อย่างตรงไปตรงมาเมื่อผลออกมาเป็นเช่นนั้น รอบที่ไม่มีการเปลี่ยนแปลงที่วัดผลได้ก็ยังถือว่ามีความหมาย: คุณยังคงใช้ตัวแปลเดิมต่อไป และรู้ว่าสถานะปัจจุบันอยู่ตรงไหน

## ผู้พูดภาษาตรวจสอบโดยไม่รู้ว่าเป็นคำแปลจากตัวใด

มีสองสถานการณ์ที่จะใช้การตรวจสอบแบบไม่เปิดเผยที่มากับประโยคของคุณ:

- **หลังจากที่คุณเริ่มใช้ตัวแปลภาษาตัวใหม่** แผ่นงานถัดไปจะนำคำแปลร่างของตัวใหม่มาผสมกับคำแปลร่างของตัวเดิมที่ถูกแทนที่ — โดยสุ่มเลือกและไม่มีป้ายกำกับ การที่คะแนนเพิ่มขึ้นจะถือเป็นความก้าวหน้าที่แท้จริงก็ต่อเมื่อผลการตรวจของผู้พูดภาษาเห็นพ้องด้วยเท่านั้น
- **เมื่อประโยคฝึกหัดไม่สามารถตัดสินได้** — เช่น มีน้อยกว่า 50 ประโยค หรือในรอบนั้นไม่พบการเปลี่ยนแปลงที่วัดผลได้ — ครึ่งหนึ่งของคำแปลร่างในแผ่นงานถัดไปจะมาจากตัวแปลภาษาตัวใหม่ หากผู้พูดภาษาเห็นว่าตัวใหม่ดีกว่าอย่างชัดเจน ระบบรางจะเสนอให้นำมาใช้งาน (คุณยังต้องเป็นผู้ตอบตกลง) และรายงานจะระบุว่าได้รับการเลือกจากผลการตรวจของผู้พูดภาษา

ไม่ว่าจะในกรณีใด ผู้พูดภาษาจะตรวจคำแปลร่างทุกประโยคด้วยวิธีเดียวกัน โดยไม่รู้ว่าตัวแปลใดเป็นผู้เขียน

## เมื่อผลการพัฒนาในแต่ละรอบเริ่มนิ่ง

หากผ่านไปสองรอบติดต่อกันแล้วไม่เห็นการพัฒนาที่ชัดเจน ไม่ได้หมายความว่ารอบการทำงานเหล่านั้นหยุดช่วยพัฒนา เมื่อตัวแปลทำงานได้ค่อนข้างดีแล้ว แต่ละรอบอาจพัฒนาเพิ่มขึ้นน้อยกว่าที่ประโยคฝึกฝนของคุณจะตรวจจับได้ รายงานจะบอกเรื่องนี้อย่างตรงไปตรงมา — คือไม่สามารถแยกความแตกต่างระหว่างการพัฒนาเพียงเล็กน้อยกับการไม่พัฒนาเลยได้ — พร้อมทั้งชี้แนะแนวทางที่เร็วกว่าในการเดินหน้าต่อ: เช่น ใช้ตัวแปลรุ่นที่เก่งขึ้น หรือเพิ่มประโยคในรูปแบบที่ตัวแปลมักทำผิด

หากคุณเริ่มต้นด้วยตัวแปลภาษาขนาดเล็ก คอมพิวเตอร์ของคุณสามารถสอนตัวที่มีประสิทธิภาพสูงกว่าได้ และหากสองรอบติดต่อกันนับตั้งแต่คุณเปลี่ยนตัวแปลภาษาครั้งล่าสุดไม่พบการพัฒนาที่วัดผลได้ ระบบรางจะเสนอให้เปลี่ยนรุ่น (รอบที่มีประโยคฝึกหัดน้อยเกินกว่าจะบอกได้จะไม่ถูกนับ) การดาวน์โหลดนี้มีขนาดใหญ่กว่าและใช้เวลาสอนนานกว่า ระบบรางจึงถามว่า: *ตกลง* หรือ *ยังไม่ใช่ตอนนี้* หากคุณตอบตกลง ระบบจะเรียนรู้จากทุกสิ่งที่คุณมี และจะเสนอให้คุณใช้ก็ต่อเมื่อมันดีขึ้นอย่างวัดผลได้ — คุณยังต้องตอบตกลงก่อนที่มันจะเข้ามาแทนที่

## ผู้ที่ยังไม่ได้ให้ความยินยอม

หากมีบางประโยคมาจากผู้ที่ยังไม่ได้ให้ความยินยอม rails จะแยกประโยคเหล่านั้นไว้และดำเนินการต่อไป ในแต่ละเซสชัน rails จะถามอย่างสุภาพหนึ่งครั้งว่าทุกคนให้ความยินยอมแล้วหรือยัง เมื่อได้รับคำตอบว่าใช่ ประโยคเหล่านั้นจะถูกนำมารวมในรอบถัดไป
