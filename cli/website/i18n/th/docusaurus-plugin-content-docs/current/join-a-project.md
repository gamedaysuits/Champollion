# เข้าร่วมโครงการ

ระบบแปลภาษาสำหรับภาษาที่มีประโยคเขียนอยู่น้อยต้องการความร่วมมือจากหลายฝ่าย
**เข้าร่วมโครงการ** เป็นพื้นที่ให้แต่ละฝ่ายมาพบกัน ผู้ที่กำลังสร้างระบบแปลภาษาจะลงรายการโครงการของตน ระบุสิ่งที่ต้องการความช่วยเหลือ และคนอื่นๆ ก็สามารถยื่นข้อเสนอช่วยเหลือได้

## หากคุณต้องการช่วยเหลือ

ดูโครงการต่างๆ ในหน้า [เข้าร่วมโครงการ](/join) แต่ละโครงการจะแสดงภาษาทั้งสองภาษา จุดประสงค์ของโครงการ และสิ่งที่ผู้ดูแลโครงการกำลังมองหา ไม่ว่าจะเป็นประโยคในหัวข้อใดหัวข้อหนึ่ง รายการคำศัพท์ หรือวิธีการแปลใหม่ๆ ที่อยากทดลอง

เมื่อคุณยื่นข้อเสนอช่วยเหลือ:

- **คุณส่งมอบให้กับโครงการ ไม่ใช่เพื่อสาธารณะ** ไฟล์ของคุณจะถูกอัปโหลดไปยังพื้นที่จัดเก็บโครงการของ Champollion ซึ่งมีเพียงคุณ ผู้ดูแลโครงการนั้น และผู้ดูแลระบบจัดเก็บข้อมูลเท่านั้นที่สามารถเปิดดูได้
- **ทั้งสองฝ่ายถือครองร่วมกัน** คุณเป็นผู้ส่งมอบ ส่วนผู้ดูแลเป็นผู้ตัดสินใจว่าจะรับไว้หรือไม่ เมื่อพวกเขายอมรับ จะมีบันทึกระบุว่าใครเป็นผู้เสนอ ใครเป็นผู้ยอมรับ และมีข้อตกลงอะไรบ้าง
- **พวกเขารู้ว่าคุณเป็นใคร** ผู้ดูแลโครงการจะเห็นชื่อและอีเมลที่คุณใช้ยื่นข้อเสนอ เพื่อให้สามารถติดต่อคุณได้ โดยหน้าสาธารณะจะไม่แสดงอีเมลของคุณเด็ดขาด
- **พวกเขาสามารถปฏิเสธได้** ทางโครงการอาจปฏิเสธข้อเสนอได้
- **คุณสามารถถอนข้อเสนอได้** ก่อนที่พวกเขาจะยอมรับ การถอนข้อเสนอ (หรือการปฏิเสธของพวกเขา) จะเปลี่ยนสถานะของข้อเสนอ แต่ไม่ได้ลบไฟล์ออก และผู้ดูแลโครงการยังคงสามารถเปิดดูได้ ดังนั้นโปรดยื่นข้อเสนอเฉพาะสิ่งที่คุณยินดีให้พวกเขาเก็บรักษาไว้เท่านั้น
- **บันทึกกำกับต้องมาก่อนเสมอ** เครื่องมือจะไม่ยื่นข้อเสนอไฟล์ที่ระบุว่าเป็นส่วนตัว หรือไฟล์ที่เจ้าของภาษายังไม่ได้เห็นพ้องต้องกันทั้งหมด มีเพียงผู้ดูแลไฟล์เท่านั้นที่สามารถเปลี่ยนสถานะนี้ได้

สิ่งที่คุณจะไม่ได้รับจากโครงการคือ ประโยคต่างๆ ในโครงการนั้น จะไม่มีสิ่งใดของพวกเขาส่งถึงคุณโดยปราศจากการยินยอมจากพวกเขา

## หากคุณกำลังสร้างระบบแปลภาษา

คุณสามารถลงรายการโครงการของคุณได้ทันทีเมื่อเริ่มต้นบน rails แล้ว โดยคุณจะต้องระบุ:

- ภาษาทั้งสองภาษา และจุดประสงค์ของระบบแปลภาษานี้
- ชื่อที่คุณต้องการให้แสดง ซึ่งจะไม่ใช่อีเมลของคุณเด็ดขาด
- สิ่งที่จะช่วยโครงการได้มากที่สุด

ทุกรายการที่ลงไว้จะได้รับการตรวจสอบสั้นๆ ก่อนเผยแพร่ เพื่อรักษาความน่าเชื่อถือของหน้าโครงการ เมื่อมีใครยื่นข้อเสนอช่วยเหลือ คุณจะเป็นผู้ตัดสินใจ หากยอมรับ ไฟล์จะเข้ามายังกล่องข้อความของโครงการพร้อมบันทึกที่ระบุชื่อของทั้งสองฝ่าย พร้อมให้นำเข้าใช้งานได้เหมือนไฟล์ทั่วไป หรือคุณสามารถเลือกปฏิเสธก็ได้

## สิ่งที่สามารถยื่นข้อเสนอได้ในปัจจุบัน

ไฟล์ต่างๆ ได้แก่ ประโยค รายการคำศัพท์ และแนวทางการแปลที่อยากให้ทดลอง ส่วนการช่วยเหลือในรูปแบบอื่น เช่น การช่วยตรวจทานงานแปลจากระยะไกล หรือการสนับสนุนกำลังประมวลผลของคอมพิวเตอร์ ยังไม่รวมอยู่ในระบบขณะนี้

หากยังไม่มีโครงการใดลงรายการไว้ หน้านี้จะแจ้งให้ทราบตามตรง
