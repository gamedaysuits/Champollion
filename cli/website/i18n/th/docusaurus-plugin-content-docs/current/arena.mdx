# The Arena

**The Arena คือสถานที่ที่เกิดการวัดผล** มันคือประตูที่คุณใช้ส่งผลลัพธ์ เป็นบัญชีแยกประเภท (ledger) ที่เก็บผลลัพธ์นั้น และเป็นกลไกการแข่งขันที่สร้างขึ้นบนทั้งสองสิ่งนี้

มันคือโครงสร้างพื้นฐาน ไม่ใช่กระดานคะแนนและไม่ใช่แผนที่ มีสามสิ่งที่มักทำให้สับสนได้ง่าย ดังนั้นจึงควรแยกแยะให้ชัดเจนดังนี้:

| | สิ่งที่มันเป็น | สถานที่รัน |
|---|---|---|
| **[MT-Eval Harness](/docs/network/specifications/harness)** | ตัวให้คะแนน เมื่อกำหนดวิธีการและชุดทดสอบให้ มันจะสร้างตัวเลขและ run card ออกมา | **เครื่องของคุณ** เราไม่ได้รันวิธีการของคุณให้คุณ และเราก็ไม่จำเป็นต้องทำเช่นนั้น |
| **The Arena** | ประตูสำหรับส่งข้อมูล บัญชีแยกประเภทของ run card และกลไกการแข่งขันและรางวัล | ที่นี่ |
| **[Network](/docs/network/)** | แผนที่ที่เกิดขึ้นเมื่อมี run card มากพอ — ใครสามารถแปลอะไรได้ แปลได้ดีแค่ไหน และมีพื้นที่ว่างอยู่ที่ไหน การกำหนดเส้นทาง (Routing) จะวิ่งผ่านสิ่งนี้ | เป็นผลลัพธ์ที่ตามมา ไม่ใช่ส่วนประกอบ |

ไม่มีสิ่งใดเข้าสู่ Network ได้นอกจากจะผ่าน The Arena และไม่มีสิ่งใดเข้าสู่ The Arena ได้นอกจากจะเป็นการรันที่ได้รับการให้คะแนนและมีลายนิ้วมือ (fingerprint) กำกับ นี่คือการออกแบบทั้งหมด: การวัดผลที่ไม่มีแหล่งที่มาจะไม่สามารถกลายเป็นส่วนหนึ่งของแผนที่ได้

## The Arena ประกอบด้วยอะไรบ้าง

**ประตู** ใครก็สามารถส่งข้อมูลได้ — ไม่ว่าจะเป็นโมเดลที่ผ่านการ fine-tune, frontier model ที่ใช้ prompt, ไปป์ไลน์ที่มี FST ควบคุม, ระบบ rule-based, หรือนักแปลมืออาชีพที่เป็นมนุษย์ วิธีการนั้นไม่เกี่ยวข้องกับกระบวนการ มีเพียงขั้นตอนเท่านั้นที่ตายตัว มีประตูสองบานที่แตกต่างกัน ขึ้นอยู่กับสิ่งที่คุณมี: [เผยแพร่ run card](/docs/network/getting-started/submit-a-method) หากคุณได้ให้คะแนนบางอย่างไปแล้ว หรือ [เสนอรายการ](/docs/network/getting-started/submit-to-the-index) หากคุณมีชุดข้อมูล พจนานุกรม เอนจิน บริการแปลภาษา ผลลัพธ์ที่เผยแพร่ภายนอก หรือการแก้ไข language card ข้อเสนอต่างๆ จะถูกอ่านโดยมนุษย์ ไม่ใช่หุ่นยนต์ และไม่มีการอนุมัติอัตโนมัติใดๆ ทั้งสิ้น

**บัญชีแยกประเภท** ทุกการรันที่เผยแพร่คือ run card: ซึ่งประกอบด้วยคะแนน แฮชของชุดข้อมูล slug ของโมเดล เงื่อนไข และลายนิ้วมือที่ครอบคลุมข้อมูลทั้งหมดนี้ การที่คนสองคนรันการกำหนดค่าเดียวกันนั้นไม่เป็นอันตรายตามการออกแบบ — การรันที่เหมือนกันจะถูกลบข้อมูลที่ซ้ำซ้อน (deduplicate) เมื่อเผยแพร่ และการทำซ้ำอย่างอิสระถือเป็นหลักฐานมากกว่าความสูญเปล่า [Run Card Specification](/docs/network/specifications/run-card) กำหนดสิ่งที่การ์ดต้องเปิดเผย; [Benchmark Specification](/docs/network/specifications/benchmark) กำหนดโปรโตคอลที่ใช้สร้างการ์ดนั้นขึ้นมา

**ชุดของเป้าหมาย** ชุดข้อมูลการประเมิน <SSOTCount field="registryDatasetCount" /> รายการได้รับการลงทะเบียนแล้ว แต่ละรายการคือการ์ดข้อมูลเมตา (metadata) พร้อมกับตัวชี้สำหรับดึงข้อมูลจากแหล่งที่มา — **เนื้อหาของคลังข้อมูล (corpus) จะไม่ถูกโฮสต์ไว้ที่นี่เด็ดขาด** harness จะดึงข้อมูลอ้างอิงจากต้นทางในขณะรันไทม์ และให้คะแนนเทียบกับสิ่งที่เพิ่งดึงมา

การลงทะเบียนไม่ได้หมายความว่าจะสามารถรันได้ทุกที่ และความแตกต่างนี้เป็นความตั้งใจ รายการเหล่านั้นสองสามร้อยรายการมีใบอนุญาตที่ถูกดัดแปลง สั่งทำพิเศษ หรือไม่ได้ระบุไว้ ซึ่งรายการเหล่านี้จะ **ปฏิเสธการประเมินระยะไกล** จนกว่าผู้ถือสิทธิ์จะบันทึกความยินยอมในการส่งข้อมูลอย่างชัดเจน — ไม่มีตัวแทนใดสามารถเพิ่มความยินยอมแทนพวกเขาได้ ข้อมูลเหล่านี้ยังคงสามารถรันแบบโลคัลได้ และรันผ่านช่องทาง no-train ได้หากใบอนุญาตอนุญาต ดู [Evaluation Datasets](/docs/network/leaderboard/datasets) และ [Data Stewardship](/docs/network/sovereignty/data-sovereignty)

**กลไกการแข่งขัน** เหนือการรันเดี่ยวๆ คือส่วนที่เหลือ: [งานที่ใช้ร่วมกันและการแข่งขัน](/shared-tasks), [คิวสาธารณะ](/docs/network/getting-started/contributing-compute) ของการวัดผลที่จะช่วยปรับปรุงแผนที่ได้มากที่สุด และข้อกำหนดสำหรับ [สิ่งที่รางวัลต้องการ](/docs/network/specifications/prizes) หากมีการเปิดให้ชิงรางวัล ชุมชนสามารถจัดการแข่งขันของตนเองบนคลังข้อมูลของตนเองด้วยเงินของตนเองได้ — [Champollion ไม่ได้ถือครองทั้งสองอย่าง](/docs/network/sovereignty/run-a-sovereign-contest)

## กฎที่บังคับใช้ทุกที่ในที่นี้

สิ่งเหล่านี้คือสิ่งที่ไม่สามารถเปลี่ยนแปลงได้ (invariants) แต่ละข้อจะมีหน้าเพจที่ระบุรายละเอียดเฉพาะ

**ห้ามฝึกสอนบนข้อมูลการประเมิน** วิธีการใดๆ ที่สัมผัสกับชุดข้อมูลเกณฑ์มาตรฐาน (benchmark) — ไม่ว่าจะเป็นข้อมูลการฝึกสอน ตัวอย่างแบบ few-shot รายการพจนานุกรม หรือเนื้อหาใน prompt — จะถูกตัดสิทธิ์ คุณสามารถ fine-tune บนอะไรก็ได้ที่คุณต้องการ เพียงแต่ต้องไม่ใช่บนชุดทดสอบ นี่เป็นกฎเพียงข้อเดียวที่ระบบทั้งหมดจะไม่สามารถอยู่รอดได้หากถูกละเมิด เพราะคะแนนที่ปนเปื้อนจะทำลายทุกการเปรียบเทียบที่อยู่ปลายทาง ([Leaderboard rules](/docs/network/leaderboard/rules))

**ตัวเลขทุกตัวต้องมีแหล่งที่มา มิฉะนั้นจะไม่ถูกนับ** run card จะระบุเวอร์ชันของชุดข้อมูล โมเดล เงื่อนไข system prompt และต้นทุน คะแนนจะสามารถเปรียบเทียบได้เฉพาะภายในชุดข้อมูลเวอร์ชันเดียวกันเท่านั้น และลายนิ้วมือคือสิ่งที่ทำให้สามารถตรวจสอบได้แทนที่จะเป็นเพียงการกล่าวอ้าง ([Benchmark Spec](/docs/network/specifications/benchmark))

**เราไม่เคยถือครองคลังข้อมูลของคุณ** การลงทะเบียนเป็นเพียงข้อมูลเมตา ชุดทดสอบจะถูกให้คะแนนโดยไม่ต้องส่งมอบข้อมูลมาให้ และในเส้นทางอธิปไตย (sovereign lane) ข้อมูลจะไม่เคยออกจากโครงสร้างพื้นฐานของชุมชนเลย — มีเพียงคะแนนเท่านั้นที่ถูกส่งออกมา ([Registering Corpora](/docs/network/sovereignty/registering-corpora))

**เส้นทางใบอนุญาตเป็นเรื่องของโครงสร้าง ไม่ใช่การแก้ไข** คลังข้อมูลที่ไม่ใช่เชิงพาณิชย์และสำหรับการวิจัยเท่านั้น จะถูกแยกออกจากทุกรางวัล API และเส้นทางเชิงพาณิชย์โดยโครงสร้าง คลังข้อมูลภายใต้ใบอนุญาตที่ถูกดัดแปลง สั่งทำพิเศษ หรือไม่ได้ระบุไว้ จะถูกควบคุมด้วยความยินยอมเพิ่มเติม: harness จะปฏิเสธการส่งข้อความไปยัง API ของโมเดลบุคคลที่สาม จนกว่าจะมีการบันทึกการอนุญาตจากผู้ถือสิทธิ์ ([Data Stewardship](/docs/network/sovereignty/data-sovereignty))

**คะแนนคือสัญญาณจากเครื่องจักร ไม่ใช่คำตัดสิน** เมตริกอัตโนมัติเป็นเพียงตัวแทนของการตัดสินโดยมนุษย์ และ [Speaker Validation Protocol](/docs/network/specifications/speaker-validation) ได้กำหนดด่านของมนุษย์ที่เมตริกเหล่านี้เป็นตัวแทน*ให้* ตำแหน่งบนกระดานผู้นำพิสูจน์ว่าวิธีการนั้นวัดผลได้ดี แต่มันไม่ได้พิสูจน์ว่าการแปลนั้นดี และไม่ได้ให้สิทธิ์ใครในการนำไปใช้งานกับภาษาของชุมชน

**การชนะไม่ใช่จุดสิ้นสุด** สำหรับภาษาพื้นเมือง การออกแบบคือวิธีการที่ใช้งานได้จะถูกถ่ายโอนไปยังองค์กรปกครองของชุมชน และนำไปใช้งานบนโครงสร้างพื้นฐานที่ชุมชนควบคุม โดย Champollion จะไม่มีส่วนแบ่งในรายได้ที่เกิดขึ้นที่นั่น ([The derived-artifacts commitment](/docs/network/sovereignty/derived-artifacts))

## ส่วนที่คุณเข้ามามีบทบาท

เลือกแถวที่ตรงกับสิ่งที่คุณมีอยู่แล้ว

| คุณมี… | ให้ทำสิ่งนี้ | เริ่มต้นที่ |
|---|---|---|
| วิธีการและ API key | รัน harness กับคลังข้อมูลที่ลงทะเบียนไว้และเผยแพร่ run card | [Submit a Method](/docs/network/getting-started/submit-a-method) |
| สิ่งที่ดัชนีขาดหายไป — ชุดข้อมูล พจนานุกรม FST เอนจิน บริการแปลโดยมนุษย์ ผลลัพธ์ที่เผยแพร่ หรือการแก้ไขการ์ด | ยื่นข้อเสนอที่มีโครงสร้าง; ผู้ดูแลจะตรวจสอบด้วยตนเอง | [Submit to the Index](/docs/network/getting-started/submit-to-the-index) |
| เครดิต API ที่เหลือและไม่มีวิธีการของตัวเอง | รันรายการที่เปิดอยู่จากคิวสาธารณะด้วยคีย์ของคุณเองและเผยแพร่ผลลัพธ์ที่ได้กลับมา | [Contributing Compute](/docs/network/getting-started/contributing-compute) |
| คลังข้อมูลที่ชุมชนของคุณเป็นเจ้าของ | ลงทะเบียนเป็นข้อมูลเมตาและเลือกเส้นทางการเปิดเผย — เปิดกว้าง (open), มีการควบคุม (gated), หรือมีอธิปไตยเต็มรูปแบบ (fully sovereign) | [Registering Corpora](/docs/network/sovereignty/registering-corpora) |
| คลังข้อมูลและเหตุผลในการจัดการแข่งขันบนข้อมูลนั้น | รันด้วยตัวคุณเอง ตามเงื่อนไขของคุณ; เราไม่ได้ถือครองทั้งข้อมูลและเงิน | [Run a Sovereign Contest](/docs/network/sovereignty/run-a-sovereign-contest) |
| วิธีการที่ทำคะแนนได้ดีอยู่แล้ว | ส่งออกเป็นปลั๊กอินและนำเข้าสู่ระบบโปรดักชัน | [Deploy to Production](/docs/network/getting-started/deploy-to-production) |
| คำถามก่อนเริ่มต้น | การให้คะแนน การตัดสิทธิ์ โมเดล FST อธิปไตย | [FAQ](/docs/network/getting-started/faq) |

หากคุณเป็น AI agent คิว ผลลัพธ์ และ run card ทั้งหมดมีให้ใช้งานในรูปแบบเครื่องมือ — ดูที่ [MCP Server](/docs/network/getting-started/mcp-server)

## สิ่งที่กำลังรันอยู่จริงในวันนี้

The Arena อยู่ในขั้นตอนการเปิดตัว และคำอธิบายอย่างตรงไปตรงมาของมันนั้นสั้นมาก

- **บอร์ดเปิดใช้งานจริง เป็นสาธารณะ และเปิดรับการส่งข้อมูล** เนื้อหาปัจจุบันเป็นข้อมูลแบบเรียลไทม์ ดังนั้นหน้านี้จะไม่บอกคุณว่ามีอะไรอยู่บนนั้นบ้าง — [อ่านกระดานผู้นำ](/leaderboard)
- **"รายงานด้วยตนเอง" (Self-reported) คือระดับความน่าเชื่อถือเริ่มต้น** การตรวจสอบฝั่งเซิร์ฟเวอร์ — การให้คะแนนการส่งข้อมูลใหม่เทียบกับคลังข้อมูลหลักที่ปักหมุดด้วย SHA — มีอยู่และกำลังขยายตัว แต่ยังไม่ครอบคลุมทั้งหมด ให้อ่านป้ายกำกับ (badge) ในแต่ละแถว
- **ไม่มีรางวัลใดเปิดอยู่ และไม่มีคะแนนใดบนเว็บไซต์นี้ที่ผ่านเกณฑ์รางวัล** [Prize Specification](/docs/network/specifications/prizes) ถูกเขียนขึ้นเพื่อให้เกณฑ์มีความชัดเจน *หากและเมื่อ* มีการเปิดให้ชิงรางวัล รางวัลจะได้รับทุนและถือครองโดยผู้สนับสนุน; Champollion ไม่เคยถือครอง เป็นคนกลาง (escrow) หรือกำหนดเส้นทางเงินรางวัล
- **ยังไม่มีการตรวจสอบโดยผู้พูดในชุมชน** ด่านนี้ได้รับการระบุไว้แล้วและเครื่องมือกำลังอยู่ระหว่างการสร้าง ตัวเลข Composite และ chrF++ เป็นสัญญาณจากเครื่องจักร ไม่ใช่คำตัดสินของชุมชน
- **ยังไม่มีวิธีการใดถูกถ่ายโอนไปยังชุมชน** โมเดลการถ่ายโอนความเป็นเจ้าของเป็นการออกแบบที่ให้คำมั่นไว้ ไม่ใช่โปรแกรมที่กำลังทำงานอยู่ มันถูกอธิบายไว้เพื่อให้คุณสามารถตรวจสอบเราได้ ไม่ใช่เพื่อบอกเป็นนัยว่ามันกำลังดำเนินการอยู่
- **การดูแลคีย์ได้รับการตัดสินใจแล้ว; แต่ยังไม่ได้กำหนดผู้ดูแล** กลไกนี้เป็นรูปแบบ threshold scheme ซึ่ง Champollion จะไม่ถือครองส่วนแบ่งคีย์ใดๆ เลย ผู้ดูแลจะถูกเลือกโดยชุมชน และการสนทนาเหล่านั้นกำลังดำเนินอยู่ — ดังนั้นเราจึงระบุว่า **ผู้ดูแลคีย์ของชุมชน (อยู่ระหว่างการยืนยัน)**

บัญชีแยกประเภทฉบับเต็มของสิ่งที่โปรเจกต์นี้ *ไม่* กล่าวอ้างคือ [Honest Limitations](/docs/network/honest-limitations) หากมีสิ่งใดในหน้านี้ที่สื่อความหมายเกินกว่าที่หน้านั้นอนุญาต ให้ยึดหน้านั้นเป็นหลักและถือว่าหน้านี้มีข้อผิดพลาด (bug)
