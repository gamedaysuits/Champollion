**Champollion** ได้รับการตั้งชื่อตาม Jean-François Champollion ผู้ซึ่งในปี ค.ศ. 1822 ได้ถอดรหัสอักษรเฮียโรกลิฟของอียิปต์ และทำให้ระบบการเขียนนั้นกลับมาอ่านได้อีกครั้งสำหรับโลก นั่นคืออุปมาที่เราใช้: การคืนการเข้าถึงความหมาย และการอ่านภาษาหนึ่งในแบบของมันเอง

เราไม่อาจใช้ชื่อนี้โดยไม่แบกรับประวัติศาสตร์ที่มาพร้อมกับมัน

Champollion ทำงานอยู่ภายในกิจการอาณานิคม ศิลาโรเซตตาที่ทำให้การค้นพบของเขาเป็นไปได้นั้นเดินทางมาถึงยุโรปในฐานะของที่ริบมาจากสงคราม และยังคงเป็นทรัพย์สินที่มีข้อพิพาทจนถึงทุกวันนี้ ในการเดินทางสำรวจอียิปต์ของเขาเองในปี ค.ศ. 1828–29 เขาได้สั่งให้ตัดแผ่นผนังออกจากสุสานของ Seti I และส่งไปยังฝรั่งเศส ซึ่งยังคงอยู่ที่นั่นจนถึงปัจจุบัน และ "การถอดรหัส" นั้นเองก็อาจเป็นการกระทำที่เป็นการยึดครอง — คนนอกที่อ้างสิทธิ์อำนาจเหนือถ้อยคำของผู้คน เราระบุสิ่งนี้อย่างตรงไปตรงมา เราไม่สนใจที่จะฟอกขาวมัน

สิ่งที่เราคงไว้จาก Champollion คือวิธีการ ไม่ใช่ตัวบุคคล: ความเชื่อมั่นว่าภาษาหนึ่งและการเขียนของมันสมควรได้รับการทำความเข้าใจในแบบของมันเอง และงานด้านการเข้าถึงนั้นคุ้มค่าที่จะทำให้ดี การสกัดเอาไปนั้นเราปฏิเสธ — และเราสร้างเครื่องมือนี้ขึ้นมาเพื่อเป็นสิ่งตรงข้ามกับมัน

## วิธีที่เครื่องมือนี้พลิกกลับการสกัดเอาไป

- **เราไม่ยึดถือและเก็บไว้เอง** คลังข้อมูลจะถูกดึงมาจากแหล่งต้นทางและเราไม่เคยโฮสต์ไว้เอง เราถือครองเพียงข้อมูลเมทาดาตา ไม่ใช่ภาษาของผู้อื่น
- **ความเป็นเจ้าของยังคงอยู่กับชุมชน** เราพัฒนางานโดยมุ่งสู่หลักการอธิปไตยเหนือข้อมูลของชนพื้นเมือง — ชุมชนเป็นเจ้าของและควบคุมข้อมูลภาษา — และการที่เราบรรลุเกณฑ์ดังกล่าวหรือไม่นั้นขึ้นอยู่กับชุมชนเป็นผู้ตัดสิน ไม่ใช่เรา สำหรับข้อมูลการประเมินที่ปิดผนึก การออกแบบได้มอบกุญแจไว้กับผู้ดูแลของชุมชนภายใต้ข้อตกลงแบบกำหนดสัดส่วนขั้นต่ำ (threshold arrangement) โดยที่เราไม่ได้ถือส่วนแบ่งใด ๆ เลย และยังไม่มีการแต่งตั้งผู้ดูแลในขณะนี้ หากเรายุติบทบาทลง อำนาจในการควบคุมจะยังคงอยู่กับชุมชน
- **เราวัดว่าการแปลทำงานได้ดีเพียงใด เราไม่ได้สะสมภาษา** Network รายงานว่าการแปลทำงานได้ดีเพียงใดสำหรับคู่ภาษาที่กำหนด นี่ไม่ใช่ตู้โชว์รางวัล และข้อมูลที่ง่ายเกินไปหรือกำหนดขอบเขตไม่เหมาะสมจะถูกตัดสิทธิ์จากการจัดอันดับ
- **เราให้เครดิตแก่บุคคลที่อยู่เบื้องหลังสิ่งนี้** — นักภาษาศาสตร์ ผู้พูดภาษา และผู้สร้างคลังข้อมูล — โดยระบุชื่อเมื่อได้รับความยินยอมให้ระบุชื่อแล้วเท่านั้น และจะไม่ระบุชื่อผู้ที่ไม่ได้ยินยอมอย่างเด็ดขาด
- **ความยินยอมสามารถเพิกถอนได้** ผู้พูดภาษาเป็นเจ้าของผลการประเมินของตนเองและสามารถเพิกถอนได้ตลอดเวลา
