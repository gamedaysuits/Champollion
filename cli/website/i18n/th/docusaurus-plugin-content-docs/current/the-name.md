**Champollion** ได้รับการตั้งชื่อตาม Jean-François Champollion ผู้ซึ่งในปี ค.ศ. 1822 ได้ถอดรหัสอักษรเฮียโรกลิฟของอียิปต์ และทำให้ระบบการเขียนนั้นกลับมาอ่านได้อีกครั้งสำหรับโลก นั่นคืออุปมาที่เราใช้: การคืนการเข้าถึงความหมาย และการอ่านภาษาหนึ่งในแบบของมันเอง

เราไม่อาจใช้ชื่อนี้โดยไม่แบกรับประวัติศาสตร์ที่มาพร้อมกับมัน

Champollion ทำงานอยู่ภายในกิจการอาณานิคม ศิลาโรเซตตาที่ทำให้การค้นพบของเขาเป็นไปได้นั้นเดินทางมาถึงยุโรปในฐานะของที่ริบมาจากสงคราม และยังคงเป็นทรัพย์สินที่มีข้อพิพาทจนถึงทุกวันนี้ ในการเดินทางสำรวจอียิปต์ของเขาเองในปี ค.ศ. 1828–29 เขาได้สั่งให้ตัดแผ่นผนังออกจากสุสานของ Seti I และส่งไปยังฝรั่งเศส ซึ่งยังคงอยู่ที่นั่นจนถึงปัจจุบัน และ "การถอดรหัส" นั้นเองก็อาจเป็นการกระทำที่เป็นการยึดครอง — คนนอกที่อ้างสิทธิ์อำนาจเหนือถ้อยคำของผู้คน เราระบุสิ่งนี้อย่างตรงไปตรงมา เราไม่สนใจที่จะฟอกขาวมัน

สิ่งที่เราคงไว้จาก Champollion คือวิธีการ ไม่ใช่ตัวบุคคล: ความเชื่อมั่นว่าภาษาหนึ่งและการเขียนของมันสมควรได้รับการทำความเข้าใจในแบบของมันเอง และงานด้านการเข้าถึงนั้นคุ้มค่าที่จะทำให้ดี การสกัดเอาไปนั้นเราปฏิเสธ — และเราสร้างเครื่องมือนี้ขึ้นมาเพื่อเป็นสิ่งตรงข้ามกับมัน

## วิธีที่เครื่องมือนี้พลิกกลับการสกัดเอาไป

- **เราไม่นำมาและเก็บไว้เอง** คลังข้อมูลจะถูกดึงมาจากแหล่งที่มาและเราจะไม่เป็นผู้โฮสต์
  ข้อมูลเหล่านั้นโดยเด็ดขาด เราเก็บรักษาเพียง metadata ไม่ใช่ภาษาของผู้อื่น
- **กรรมสิทธิ์ยังคงเป็นของชุมชน** เราพัฒนาโดยมุ่งสู่หลักการอธิปไตยทางข้อมูลของชนพื้นเมืองและหลักการ CARE
  — ส่วนเราจะบรรลุหลักการเหล่านั้นหรือไม่ ชุมชนจะเป็นผู้ตัดสิน ไม่ใช่เรา
  สำหรับข้อมูลการประเมินที่ถูกปิดผนึกไว้ กุญแจจะถูกเก็บรักษาโดยผู้ดูแลจากชุมชนภายใต้
  ข้อตกลงแบบหลายลายเซ็น (multi-signature) — โดยเราไม่ได้ถือครองส่วนแบ่งใดๆ เลย หากเราหายไป อำนาจการควบคุม
  จะยังคงอยู่กับชุมชน
- **เราวัดระดับความมั่นใจ เราไม่ได้รวบรวมภาษา** เครือข่ายจะรายงานว่า
  การแปลทำงานได้ดีเพียงใดสำหรับคู่ภาษาที่กำหนด นี่ไม่ใช่ตู้โชว์ถ้วยรางวัล และ
  ข้อมูลที่ง่ายหรือมีขอบเขตไม่เหมาะสมจะถูกตัดออกจากการจัดอันดับ
- **เราให้เครดิตแก่ผู้ที่อยู่เบื้องหลังสิ่งนี้** — ทั้งนักภาษาศาสตร์ ผู้พูด และผู้สร้าง
  คลังข้อมูล — ด้วยการระบุชื่อในทุกๆ ที่
- **ความยินยอมสามารถเพิกถอนได้** ผู้พูดเป็นเจ้าของการตัดสินของตนเอง และสามารถถอนความยินยอมได้
  ตลอดเวลา

โครงการที่ไม่ใช่ของชนพื้นเมืองและไม่ใช่เชิงพาณิชย์ที่ใช้ชื่อนี้ จะต้องสร้างความไว้วางใจ
มากกว่าที่จะเรียกร้องเอาเอง เราคาดหวังว่าจะได้รับการตรวจสอบ เรายินดีรับคำวิจารณ์ และเราจะนำ
ชื่อนี้ — รวมถึงผลงาน — เข้าสู่การทบทวนอย่างต่อเนื่องร่วมกับชุมชนที่เรารับใช้
