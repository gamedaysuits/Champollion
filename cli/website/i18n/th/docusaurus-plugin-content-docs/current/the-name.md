**Champollion** ได้รับการตั้งชื่อตาม Jean-François Champollion ผู้ซึ่งในปี ค.ศ. 1822 ได้ถอดรหัสอักษรเฮียโรกลิฟของอียิปต์ และทำให้ระบบการเขียนนั้นกลับมาอ่านได้อีกครั้งสำหรับโลก นั่นคืออุปมาที่เราใช้: การคืนการเข้าถึงความหมาย และการอ่านภาษาหนึ่งในแบบของมันเอง

เราไม่อาจใช้ชื่อนี้โดยไม่แบกรับประวัติศาสตร์ที่มาพร้อมกับมัน

Champollion ทำงานอยู่ภายในกิจการอาณานิคม ศิลาโรเซตตาที่ทำให้การค้นพบของเขาเป็นไปได้นั้นเดินทางมาถึงยุโรปในฐานะของที่ริบมาจากสงคราม และยังคงเป็นทรัพย์สินที่มีข้อพิพาทจนถึงทุกวันนี้ ในการเดินทางสำรวจอียิปต์ของเขาเองในปี ค.ศ. 1828–29 เขาได้สั่งให้ตัดแผ่นผนังออกจากสุสานของ Seti I และส่งไปยังฝรั่งเศส ซึ่งยังคงอยู่ที่นั่นจนถึงปัจจุบัน และ "การถอดรหัส" นั้นเองก็อาจเป็นการกระทำที่เป็นการยึดครอง — คนนอกที่อ้างสิทธิ์อำนาจเหนือถ้อยคำของผู้คน เราระบุสิ่งนี้อย่างตรงไปตรงมา เราไม่สนใจที่จะฟอกขาวมัน

สิ่งที่เราคงไว้จาก Champollion คือวิธีการ ไม่ใช่ตัวบุคคล: ความเชื่อมั่นว่าภาษาหนึ่งและการเขียนของมันสมควรได้รับการทำความเข้าใจในแบบของมันเอง และงานด้านการเข้าถึงนั้นคุ้มค่าที่จะทำให้ดี การสกัดเอาไปนั้นเราปฏิเสธ — และเราสร้างเครื่องมือนี้ขึ้นมาเพื่อเป็นสิ่งตรงข้ามกับมัน

## วิธีที่เครื่องมือนี้พลิกกลับการสกัดเอาไป

- **เราไม่เก็บรวบรวมมาเป็นของตนเอง** คลังข้อมูลภาษา (Corpora) จะถูกดึงมาจากแหล่งต้นทางและเราจะไม่โฮสต์ไว้ เราถือครองเพียงข้อมูลเมทาดาตา ไม่ใช่ภาษาของผู้อื่น
- **สิทธิความเป็นเจ้าของยังคงอยู่กับชุมชน** เราพัฒนาระบบตามหลักการอธิปไตยเหนือข้อมูลของชนพื้นเมือง (Indigenous data sovereignty) — นั่นคือการที่ชุมชนเป็นเจ้าของและมีอำนาจควบคุมข้อมูลภาษาของตน — และชุมชนเป็นผู้ตัดสินว่าเราบรรลุหลักการดังกล่าวหรือไม่ ไม่ใช่เราเป็นผู้กำหนด สำหรับข้อมูลการประเมินที่ปิดผนึก (sealed evaluation data) การออกแบบจะมอบกุญแจไว้กับผู้ดูแลของชุมชนภายใต้ข้อตกลงการแบ่งปันความลับตามเกณฑ์ที่กำหนด (threshold arrangement) ซึ่งเราไม่ได้ถือครองส่วนแบ่งกุญแจใด ๆ เลย ทั้งนี้ ยังไม่มีการแต่งตั้งผู้ดูแลในขณะนี้ หากเรายุติการดำเนินงาน อำนาจการควบคุมก็จะยังคงอยู่กับชุมชนต่อไป
- **เราวัดผลว่าการแปลทำงานได้ดีเพียงใด เราไม่ได้สะสมภาษา** Network จะรายงานว่าการแปลทำงานได้ดีเพียงใดสำหรับคู่ภาษาที่กำหนด ระบบนี้ไม่ใช่ตู้โชว์สะสมผลงาน และข้อมูลที่ง่ายเกินไปหรือกำหนดขอบเขตอย่างไม่เหมาะสมจะถูกระงับสิทธิ์จากการจัดอันดับ
- **เราให้เครดิตแก่บุคคลที่เป็นรากฐานของสิ่งนี้** — นักภาษาศาสตร์ ผู้พูดภาษา และผู้สร้างคลังข้อมูล — โดยระบุชื่ออย่างชัดเจนในทุกแห่ง
- **ความยินยอมสามารถเพิกถอนได้** ผู้พูดภาษาเป็นเจ้าของการประเมินของตนเอง และสามารถเพิกถอนความยินยอมได้ตลอดเวลา

โครงการที่ไม่ใช่ของชนพื้นเมืองและไม่แสวงหากำไรที่ใช้ชื่อนี้ จำเป็นต้องสร้างความไว้วางใจให้เกิดขึ้นจริง ไม่ใช่เพียงแค่เรียกร้องเอา เราคาดหวังให้มีการตรวจสอบ เรายินดีรับฟังคำวิจารณ์ และเราจะทบทวนการใช้ชื่อนี้ — รวมถึงผลงานที่ทำ — ร่วมกับชุมชนที่เราให้บริการอย่างต่อเนื่อง
