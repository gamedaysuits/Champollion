# นำสิ่งที่คุณมีมาใช้

ระบบแปลภาษาเรียนรู้จาก **คู่ประโยค**: ประโยคหนึ่งในภาษาหนึ่ง และประโยคเดียวกันนั้นในอีกภาษาหนึ่ง หน้านี้เกี่ยวกับการนำข้อมูลของคุณเข้ามา — และเกี่ยวกับคำถามที่คุณจะได้รับสำหรับแต่ละไฟล์ ซึ่งสำคัญกว่าสิ่งอื่นใดบน rails

## ข้อมูลที่เครื่องมือสามารถอ่านได้

นำไฟล์ของคุณมาในแบบที่คุณเก็บไว้ได้เลย คุณไม่จำเป็นต้องแปลงไฟล์ใดๆ

| สิ่งที่คุณมี | สิ่งที่เครื่องมืออ่าน |
|---|---|
| สเปรดชีตของประโยคและคำแปล | Excel (`.xlsx`), LibreOffice (`.ods`), `.csv`, `.tsv` หรือข้อความธรรมดา |
| ตารางในเอกสาร Word | แถวต่างๆ ในตาราง |
| พจนานุกรมที่สร้างใน Toolbox หรือ FieldWorks (โปรแกรมที่นักภาษาศาสตร์หลายคนใช้) | คำศัพท์ — และประโยคตัวอย่าง ในรูปแบบคู่ประโยค |
| บันทึกเสียงที่ถอดความไว้ใน ELAN (โปรแกรมสำหรับถอดความเสียงบันทึก) | บรรทัดที่ถอดความไว้และคำแปล ในรูปแบบคู่ประโยค |
| รายการคำศัพท์ | แต่ละคำพร้อมคำแปล |
| บันทึกเกี่ยวกับไวยากรณ์ | จัดเก็บไว้ในที่ของตน เพื่อให้ผู้คนและเครื่องมือใช้อ้างอิง |
| คัมภีร์หรือข้อความศักดิ์สิทธิ์ | เฉพาะในกรณีที่คุณร้องขอ และไม่มีระบบแปลภาษาใดเรียนรู้จากข้อมูลนี้ จนกว่าผู้ดูแลจะอนุญาต |

ไฟล์ของคุณจะถูกอ่าน ณ จุดที่ไฟล์เหล่านั้นอยู่ หากคอลัมน์ในสเปรดชีตไม่ได้ระบุว่าภาษาใดเป็นภาษาใด เครื่องมือจะถามคุณ — โดยจะไม่คาดเดาเอาเองจากเนื้อหาเด็ดขาด

เครื่องมือยังช่วยตรวจหาแถวที่ดูผิดปกติด้วย — เช่น คำแปลที่เลื่อนบรรทัดลงไป คอลัมน์สองคอลัมน์สลับที่กัน คำแปลที่คัดลอกมาจากอีกฝั่ง คู่ประโยคเดิมซ้ำสองครั้ง คำแปลที่ยาวหรือสั้นกว่าปกติมาก — และแจ้งให้คุณทราบว่าเป็นแถวใดตามหมายเลขแถว เครื่องมือจะไม่เปลี่ยนแปลงหรือลบสิ่งใดทั้งสิ้น ผู้ที่เข้าใจข้อมูลจะเป็นผู้ตัดสินใจ

## เครื่องมือนับจำนวนเท่านั้น และไม่อ่านข้อความของคุณให้ใครฟัง

เมื่อนำไฟล์เข้ามา เครื่องมือจะบอกคุณว่าพบคู่ประโยคกี่คู่และใช้คอลัมน์ใดบ้าง นั่นคือทั้งหมดที่ผู้ช่วย AI ของคุณจะเห็น: จำนวนนับและชื่อคอลัมน์เท่านั้น ไม่ใช่ตัวประโยคอย่างแน่นอน

## คำถามสำหรับแต่ละไฟล์

ก่อนที่สิ่งใดจะเรียนรู้จากไฟล์ ระบบ rails จะถามผู้ที่ถือครองไฟล์นั้น:

- **ไฟล์นี้เป็นของใคร?** ตอบด้วยคำพูดของคุณเอง — ครอบครัว คุณครู หรือที่ทำการชุมชน
- **คำพูดในไฟล์เป็นของใคร?** ผู้ที่พูดหรือเขียนประโยคเหล่านั้น สมุดบันทึกของคุณยายเก็บรักษาคำพูดของท่าน แม้ว่าหลานชายจะเป็นคนพิมพ์ก็ตาม
- **พวกเขาตกลงยินยอมให้ใช้งานหรือไม่?** *ยินยอม*, *ยังก่อน*, หรือ *บางคนไม่ยินยอม* ระบบ rails จะคอยถามต่อไปจนกว่าจะได้รับคำตอบ คำพูดจากผู้ที่ยังไม่ยินยอม หรือผู้ที่ปฏิเสธ จะไม่มีวันถูกนำไปสอนระบบแปลภาษา
- **อนุญาตให้ระบบแปลภาษาเรียนรู้จากไฟล์นี้ได้หรือไม่?**
- **อนุญาตให้นำไฟล์นี้ออกจากคอมพิวเตอร์เครื่องนี้ได้หรือไม่?** ไฟล์จะเริ่มต้นด้วยสถานะส่วนตัว — เก็บไว้ในคอมพิวเตอร์เครื่องนี้ — จนกว่าคุณจะตอบ

คำตอบจะถูกบันทึกไว้ในบันทึกข้อความเล็กๆ ข้างไฟล์ และทุกเครื่องมือจะปฏิบัติตามนั้น หลังจากการตอบครั้งแรกของคุณ เครื่องมือจะทำได้เพียงปรับกฎให้เข้มงวดยิ่งขึ้นเท่านั้น จะไม่ผ่อนปรนลงโดยเด็ดขาด ข้อยกเว้นเพียงอย่างเดียวคือ: ผู้พูดที่ยังไม่ได้ถูกสอบถามมาก่อนยังคงสามารถตอบตกลงในภายหลังได้

ผู้ช่วยของคุณจะถามคำถามเหล่านี้ แต่จะต้องไม่ตอบคำถามแทนคุณเด็ดขาด หากคุณยังไม่ทราบ — เช่น คุณยังต้องถามคุณป้าก่อน — ให้ตอบว่า *ยังก่อน* ระบบ rails จะแยกไฟล์นั้นพักไว้และทำงานต่อไป แล้วจะกลับมาถามใหม่อีกครั้งอย่างสุภาพ

## สิ่งที่คุณจะเห็น

ในการทดลองใช้งานเครื่องมือของเรา — ซึ่งเป็นการสาธิตด้วยประโยคที่สมมติขึ้น — ครอบครัวหนึ่งนำไฟล์เข้ามาสี่ไฟล์: คู่ประโยคจำนวน <WalkFact of="trainingFiles.0.pairs" /> คู่จากสเปรดชีตของคุณตา, <WalkFact of="trainingFiles.1.pairs" /> คู่จากของคุณป้า, รายการคำศัพท์จำนวน <WalkFact of="lexicon.pairs" /> คำ และประโยคจำนวน <WalkFact of="test.pairs" /> ประโยคที่ผู้พูดภาษานั้นได้ตรวจสอบแล้วสำหรับการทดสอบ ในแต่ละครั้ง ผู้ช่วยจะรายงานจำนวนนับ จากนั้นจะถามว่าไฟล์นั้นเป็นของใคร และระบบแปลภาษาจะสามารถเรียนรู้จากไฟล์ดังกล่าวได้หรือไม่

## ประโยคจากแหล่งอื่น

หากคุณใช้ประโยคที่คุณไม่ได้เขียนเอง — จากหนังสือ เว็บไซต์ หรือชุดรวมผลงานที่ตีพิมพ์ — ประโยคเหล่านั้นย่อมมีกฎเกณฑ์เฉพาะของตัวเอง บางส่วนอาจให้อ่านได้แต่ห้ามเผยแพร่ บางส่วนอาจห้ามนำไปใช้สอนระบบใดๆ ให้นำเข้ามาในลักษณะเดียวกัน และตอบคำถามตามความเป็นจริงสำหรับข้อมูลเหล่านั้นเช่นกัน: เครื่องมือจะปฏิบัติตามคำตอบของคุณ เมื่อสัญญาอนุญาตของชุดข้อมูลมีความไม่ปกติหรือไม่ชัดเจน เครื่องมือจะไม่ส่งข้อมูลนั้นไปยังบริการ AI ภายนอก จนกว่าเจ้าของข้อมูลจะยินยอม
