# ใครสามารถใช้งานได้บ้าง และมีค่าใช้จ่ายเท่าใด

**โดยสรุป:**

- **ใช้งานฟรี** สำหรับครอบครัว โรงเรียน องค์กรการกุศล บริการสาธารณะ เช่น โรงพยาบาล
  สำนักงานของหน่วยงานรัฐ และโครงการส่วนบุคคลหรืองานวิจัย
- **การใช้งานเชิงพาณิชย์** — แอปภาษา หรือบริการแบบคิดค่าบริการ — ไม่ครอบคลุมอยู่ในสัญญาอนุญาตฟรีนี้
  **หากชุมชนผู้ใช้ภาษาของคุณต้องการใช้เครื่องมือเหล่านี้ในเชิงพาณิชย์ เพียงแจ้งให้เราทราบ และจะได้รับสัญญาอนุญาตฟรี**
  [ขอรับสัญญาอนุญาต](mailto:info@champollion.dev?subject=Commercial%20licence%20request)
- **ไม่มีการหักส่วนแบ่ง** Champollion ไม่หักส่วนแบ่งใด ๆ จากสิ่งที่ชุมชนสร้างรายได้จากภาษาของตนเอง
  หากมีผู้สนับสนุนจัดหาทุนสำหรับการทำงาน เงินทั้งหมดจะส่งตรงไปถึงชุมชน
- **ความช่วยเหลือเป็นทางเลือก** หากคุณต้องการให้มีคนช่วยในโครงการของคุณ [มาพูดคุยกับเราได้](/docs/getting-help) — เงื่อนไขต่าง ๆ จะพูดคุยร่วมกับแต่ละชุมชน
  และไม่มีรายการราคา คุณไม่จำเป็นต้องมีเราก็สามารถทำจนเสร็จสิ้นได้

นี่คือข้อมูลทั้งหมดที่คนส่วนใหญ่จำเป็นต้องทราบ ส่วนที่เหลือของหน้านี้เป็นรายละเอียดสำหรับนักกฎหมายและนักพัฒนา: แพ็กเกจต่าง ๆ ของ Champollion ไม่ได้ใช้สัญญาอนุญาตเดียวกันทั้งหมด และหน้านี้จะอธิบายด้วยภาษาที่เข้าใจง่ายว่าแต่ละแพ็กเกจครอบคลุมใครบ้าง

**นี่คือบทสรุป ไม่ใช่คำแนะนำทางกฎหมาย ข้อความในสัญญาอนุญาตมีผลบังคับใช้ตามกฎหมาย** สัญญาอนุญาตแต่ละฉบับมีลิงก์อยู่ในตารางด้านล่างและแนบมาพร้อมกับแต่ละแพ็กเกจ

## CLI, เซิร์ฟเวอร์ MCP และ nmt-forge

ทั้งสามรายการนี้อยู่ภายใต้สัญญาอนุญาต PolyForm Noncommercial License 1.0.0 คุณสามารถใช้งาน ดัดแปลง และแชร์สิ่งเหล่านี้ได้สำหรับ**วัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์** โดยสัญญาอนุญาตได้ระบุวัตถุประสงค์เหล่านั้นไว้ ซึ่งข้อกำหนดสองข้อต่อไปนี้ครอบคลุมกรณีส่วนใหญ่:

> **การใช้งานส่วนบุคคล (Personal Uses)** การใช้งานส่วนบุคคลเพื่อการวิจัย การทดลอง และการทดสอบเพื่อประโยชน์ต่อองค์ความรู้สาธารณะ การศึกษาส่วนตัว ความบันเทิงส่วนตัว โครงการงานอดิเรก กิจกรรมยามว่าง หรือการประกอบพิธีกรรมทางศาสนา โดยไม่ได้คาดหวังการประยุกต์ใช้ในเชิงพาณิชย์ ถือเป็นการใช้งานตามวัตถุประสงค์ที่ได้รับอนุญาต

> **องค์กรที่ไม่แสวงหาผลกำไร (Noncommercial Organizations)** การใช้งานโดยองค์กรการกุศล สถาบันการศึกษา องค์กรวิจัยสาธารณะ องค์กรด้านความปลอดภัยสาธารณะหรือสาธารณสุข องค์กรคุ้มครองสิ่งแวดล้อม หรือหน่วยงานภาครัฐ ถือเป็นการใช้งานตามวัตถุประสงค์ที่ได้รับอนุญาต โดยไม่คำนึงถึงแหล่งที่มาของเงินทุนหรือข้อผูกพันที่เกิดขึ้นจากเงินทุนนั้น

สำหรับองค์กรประเภทใดประเภทหนึ่งข้างต้น วิธีการระดมทุนจะไม่ส่งผลต่อเงื่อนไขนี้ เนื่องจากข้อกำหนดระบุไว้อย่างชัดเจนว่า "โดยไม่คำนึงถึงแหล่งที่มาของเงินทุน"

| ผู้ใช้งาน | ครอบคลุมหรือไม่ | เหตุผล |
|---|---|---|
| โรงเรียนที่แปลแอปพลิเคชันหรือจดหมายข่าวของตนเอง | ✓ ครอบคลุม | เป็นสถาบันการศึกษา |
| โรงพยาบาลรัฐหรือคลินิกสาธารณสุขที่แปลคำแนะนำสำหรับผู้ป่วย | ✓ ครอบคลุม | เป็นองค์กรด้านความปลอดภัยสาธารณะหรือสาธารณสุข |
| องค์กรการกุศลที่แปลเว็บไซต์ของตนเอง | ✓ ครอบคลุม | เป็นองค์กรการกุศล |
| หน่วยงานภาครัฐ หรือสถาบันวิจัยสาธารณะ | ✓ ครอบคลุม | เป็นหน่วยงานภาครัฐ หรือองค์กรวิจัยสาธารณะ |
| ตัวคุณ ในโครงการส่วนบุคคลหรือโครงการวิจัยที่ไม่มีเป้าหมายเชิงพาณิชย์ | ✓ ครอบคลุม | การใช้งานส่วนบุคคลเพื่อการวิจัย การทดลอง การทดสอบ การศึกษาส่วนตัว หรืองานอดิเรก |
| ร้านค้าที่แปลหน้าร้านของตนเอง | ✗ ไม่ครอบคลุม | ผลิตภัณฑ์ของธุรกิจที่แสวงหาผลกำไรถือเป็นการใช้งานเชิงพาณิชย์ |
| คลินิกเอกชนที่แสวงหาผลกำไรที่แปลพอร์ทัลผู้ป่วยของตนเอง | ✗ ไม่ครอบคลุม | ผลิตภัณฑ์ของธุรกิจที่แสวงหาผลกำไรถือเป็นการใช้งานเชิงพาณิชย์ และไม่ใช่หน่วยงานสาธารณสุข |

การนำไปใช้เพื่อวัตถุประสงค์เชิงพาณิชย์ไม่ได้รับความคุ้มครอง: สัญญาอนุญาตนี้ไม่ได้อนุญาตสำหรับการใช้งานดังกล่าว
หากชุมชนผู้ใช้ภาษาต้องการใช้เครื่องมือเหล่านี้ในเชิงพาณิชย์ สามารถขอสัญญาอนุญาตเชิงพาณิชย์ได้ และสำหรับชุมชนผู้ใช้ภาษา สัญญาอนุญาตนั้นจะไม่มีค่าใช้จ่าย:
[ขอรับสัญญาอนุญาต](mailto:info@champollion.dev?subject=Commercial%20licence%20request)

## เครื่องมือประเมินผล (`mt-eval-harness`)

ตัว harness เป็นโอเพนซอร์สภายใต้สัญญาอนุญาต GNU Affero General Public License เวอร์ชัน 3 ขึ้นไป (AGPL-3.0-or-later) โดย AGPL อนุญาตให้ใช้งานเชิงพาณิชย์ได้ภายใต้เงื่อนไขที่กำหนด ซึ่งเงื่อนไขหลักมีดังนี้:

- หากคุณเผยแพร่ตัว harness ไม่ว่าจะมีการดัดแปลงหรือไม่ คุณต้องเผยแพร่ภายใต้สัญญาอนุญาตเดียวกัน พร้อมทั้งเปิดเผยซอร์สโค้ด
- หากคุณดัดแปลง harness และเปิดให้ผู้อื่นใช้งานผ่านเครือข่าย คุณต้องเปิดเผยซอร์สโค้ดของเวอร์ชันที่คุณดัดแปลงแก่บุคคลเหล่านั้นด้วย (ข้อ 13, "การโต้ตอบผ่านเครือข่ายระยะไกล" หรือ "Remote Network Interaction")

การอนุญาตแยกต่างหาก ([LICENSE-EXCEPTION.md](https://github.com/gamedaysuits/Champollion/blob/main/arena/LICENSE-EXCEPTION.md) ภายใต้ AGPL ข้อ 7) อนุญาตให้ปลั๊กอินมาตรฐานการประเมินผลที่อยู่ภายใต้สัญญาอนุญาตอื่นสามารถทำงานร่วมกับ harness ผ่าน public plugin interface ได้ โดยสิ่งนี้ไม่ได้เปลี่ยนแปลงสัญญาอนุญาตของตัว harness เอง

## ปลั๊กอิน Plains Cree (`champollion-lyss`)

`champollion-lyss` มีสัญญาอนุญาตชั่วคราวของตนเอง: สามารถใช้งานได้เฉพาะเมื่อได้รับอนุญาตเป็นลายลักษณ์อักษรเท่านั้น โดยปกติแล้วจะได้รับอนุญาตโดยไม่มีค่าใช้จ่ายสำหรับการวิจัยที่ไม่ใช่เชิงพาณิชย์ การศึกษา และการใช้งานเพื่อประโยชน์ของชุมชน ไม่อนุญาตให้ใช้งานเชิงพาณิชย์แต่อย่างใด สัญญาอนุญาตนี้เป็นสัญญาอนุญาตชั่วคราว ซึ่งมีไว้เพื่อรอการแทนที่ด้วยข้อกำหนดที่กำหนดขึ้นผ่านการกำกับดูแลของชุมชน ทั้งนี้ ข้อความสัญญาอนุญาตและไฟล์ NOTICE จะแนบมาพร้อมกับตัวแพ็กเกจ

## สิ่งที่สัญญาอนุญาตเหล่านี้ไม่ครอบคลุม

บริการแปลภาษา โมเดล และคลังข้อมูลภาษา (corpora) ที่คุณใช้งานผ่านเครื่องมือเหล่านี้ยังคงอยู่ภายใต้ข้อกำหนดของตนเอง เช่น ข้อกำหนดการใช้งาน API ของผู้ให้บริการ สัญญาอนุญาตของโมเดล สัญญาอนุญาตของคลังข้อมูล ตัว harness จะบันทึกสัญญาอนุญาตของแต่ละคลังข้อมูลและบังคับใช้กฎว่าบริการโมเดลใดสามารถเข้าถึงข้อมูลนั้นได้ แต่ข้อกำหนดเหล่านั้นถูกกำหนดโดยเจ้าของข้อมูล ไม่ใช่สัญญาอนุญาตในหน้านี้
