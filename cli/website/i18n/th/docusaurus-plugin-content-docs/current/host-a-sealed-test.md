# จัดการทดสอบแบบปิดผนึก

บางครั้ง ระบบแปลภาษาที่ดีที่สุดสำหรับภาษาของคุณอาจมาจากผู้อื่น —
ไม่ว่าจะเป็นนักวิจัย นักศึกษา หรือบริษัท **การทดสอบแบบปิดผนึก**ช่วยให้พวกเขาพิสูจน์สิ่งนั้นได้ด้วยประโยคของ*คุณ*
โดยที่พวกเขาไม่มีวันได้เห็นประโยคเหล่านั้นเลย

## วิธีการทำงาน

ประโยคทดสอบของคุณจะถูกล็อกไว้ด้วยกุญแจบนคอมพิวเตอร์ของคุณ ผู้ที่ต้องการ
เข้าแข่งขันจะส่งระบบแปลภาษาของตนเข้ามา คอมพิวเตอร์ของคุณจะรันแต่ละระบบกับ
ประโยคที่ถูกล็อกไว้ และส่งออกมาเพียงแค่คะแนนเท่านั้น — จะไม่มีประโยค
และไม่มีผลการแปลหลุดออกไปอย่างแน่นอน

การทดสอบจึงยังคงเป็นการทดสอบจริง: ไม่มีใครสามารถศึกษาล่วงหน้าหรือปรับแต่งให้ตรงกับข้อสอบได้
เพราะไม่มีใครสามารถอ่านมันได้

## สิ่งที่คุณเป็นผู้ตัดสินใจ

คุณเป็นผู้กำหนดเงื่อนไข ก่อนที่จะมีใครเข้าแข่งขัน:

- **เกณฑ์ที่ถือว่าดีพอ**สำหรับการชนะ
- **สิ่งที่จะเกิดขึ้นกับวิธีที่ชนะ:**
  - **ตกเป็นของคุณ** — สิทธิ์จะส่งมอบให้กับคุณ ซึ่งเป็นผู้จัดการทดสอบ
  - **ผู้สร้างยังคงเก็บไว้** — คุณให้คะแนน และเก็บสำเนาที่ถูกล็อกไว้อย่างมากที่สุดเพื่อการตรวจสอบเท่านั้น
  - **ผู้สร้างยังคงเก็บไว้ แต่แบ่งปันให้ทุกคน** — พวกเขาต้องเผยแพร่อย่างเปิดเผย
- **จะมีรางวัลหรือไม่** และใครเป็นผู้ออกทุนรางวัลนั้น Champollion จะไม่หักส่วนแบ่งใดๆ จากรางวัลเลย

## สิ่งที่มีอยู่ในปัจจุบัน

เครื่องมือสำหรับการทดสอบแบบปิดผนึกสามารถทำงานได้แล้ว: ทั้งการล็อกชุดข้อมูล การรันระบบแปลภาษาที่ส่งเข้ามาบนคอมพิวเตอร์ที่ตัดการเชื่อมต่อจากอินเทอร์เน็ต และการเผยแพร่เฉพาะคะแนนเท่านั้น แต่นี่**ยังไม่ได้อยู่บนราง** — ในปัจจุบันยังหมายถึงการปฏิบัติตามคู่มือที่มีขนาดยาว ไม่ใช่การตอบคำถามของผู้ช่วยไปทีละขั้นตอน

ใครเป็นผู้ถือกุญแจในปัจจุบัน: ใครก็ตามที่ล็อกชุดข้อมูล ยังไม่มีชุมชนใดกำหนดตัวแทนมาร่วมกันถือกุญแจ และ Champollion ไม่ได้ถือส่วนใดส่วนหนึ่งของกุญแจเลย
