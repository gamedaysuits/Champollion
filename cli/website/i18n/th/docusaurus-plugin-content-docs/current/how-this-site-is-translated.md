# How this site is translated

เว็บไซต์นี้มีให้บริการใน 13 ภาษา ทุกภาษา (ยกเว้นภาษาอังกฤษ) ได้รับการ
**แปลด้วยเครื่องโดย Champollion เอง** — ซึ่งเป็น CLI เดียวกับที่เอกสารนี้
อธิบายไว้ (`npx champollion sync`) เราใช้งานเครื่องมือของเราเอง (dogfood)

ในขณะนี้ ทุกคู่ภาษาใช้โมเดลเดียว:
**`google/gemini-3.1-pro-preview`** โดยแปลตามระดับภาษา
และคำแนะนำด้านคำศัพท์เฉพาะของแต่ละภาษาตามที่อธิบายไว้ด้านล่าง เราจงใจเลือกโมเดลเดียว
เป็นค่าเริ่มต้นที่ตรงไปตรงมาในระหว่างที่เราสร้างระบบการเลือกโมเดลตามเกณฑ์มาตรฐาน (benchmark) ของเราใหม่ (ดูด้านล่าง) — ดังนั้นนี่จึงเป็นตัวเลือกที่เรียบง่ายและมีการบันทึกไว้ ไม่ใช่
ผลลัพธ์ที่เราพยายามตกแต่งให้เป็นสิ่งที่ไม่ใช่ความจริง

สองสิ่งที่คุณควรรู้ในฐานะผู้อ่าน:

1. **หน้าเหล่านี้เป็นการแปลด้วยเครื่อง** หน้าเหล่านี้ถูกสร้างขึ้นด้วย
   ระดับภาษาและคำแนะนำด้านคำศัพท์ตามที่อธิบายไว้ด้านล่าง แต่ไม่มีมนุษย์ตรวจสอบ
   ทุกประโยค หากมีข้อความใดที่อ่านแล้วไม่ถูกต้อง ให้ถือว่าเวอร์ชันภาษาอังกฤษเป็น
   ฉบับอ้างอิงหลัก — และเรายินดีรับการแก้ไข
2. **โมเดลที่ใช้ในวันนี้เป็นค่าเริ่มต้นเดียว แต่ในอนาคตจะถูกเลือกตามเกณฑ์มาตรฐาน**
   การออกแบบของ Champollion คือการเลือกโมเดลการแปล *สำหรับแต่ละคู่ภาษา*
   ตามเกณฑ์มาตรฐาน — โดยให้คะแนนผู้ท้าชิงทุกรายบนคลังข้อมูลการพัฒนา (development corpus) และ
   แปลภาษานั้นด้วยวิธีที่ได้คะแนนสูงสุด (หากคะแนนทางสถิติเท่ากัน
   จะตัดสินด้วยต้นทุน) เรากำลังรันการคัดเลือกนั้นใหม่ผ่าน
   ด่านตรวจสอบความสมบูรณ์ของเราเองก่อนที่เราจะปักหมุดผู้ชนะของแต่ละคู่ภาษาที่นี่ **จนกว่าการรันเหล่านั้น
   จะถูกเผยแพร่บน [Network leaderboard](/leaderboard) หน้านี้จะ
   ไม่อ้างอิงแหล่งที่มาของเกณฑ์มาตรฐานที่ยังไม่สามารถแสดงให้คุณเห็นได้**

## The benchmark selection we're rebuilding

วิธีการที่ตั้งใจไว้ — และวิธีการที่โครงสร้างการกำหนดค่าถูกออกแบบมาให้ทำงาน — คือ
การเลือกโมเดลสำหรับแต่ละคู่ภาษาที่ขับเคลื่อนโดยการประเมินของเราเอง: ให้คะแนนทุก
โมเดลผู้ท้าชิงบนคลังข้อมูลการพัฒนาของคู่นั้น นำคะแนนรวม (composite score)
ที่สูงที่สุดมาใช้ และตัดสินคะแนนทางสถิติที่เท่ากันด้วยต้นทุน กระบวนการทั้งหมดนี้
ได้รับการบันทึกไว้สำหรับทุกคนที่ต้องการทำซ้ำ

เรา **ไม่ได้** เผยแพร่คะแนนรวมหรือ "ผู้ชนะตามเกณฑ์มาตรฐาน" ของแต่ละ
ภาษาในหน้านี้ในวันนี้ เนื่องจากการคัดเลือกที่จะสนับสนุน
ตัวเลขเหล่านั้นกำลังถูกรันใหม่ผ่านด่านตรวจสอบความสมบูรณ์ของระบบทดสอบ (harness integrity gate) ก่อน
เมื่อเสร็จสิ้น การรันเหล่านั้นจะอยู่บนกระดานผู้นำสาธารณะ ตารางนี้จะ
แสดงโมเดลที่ชนะของแต่ละคู่ภาษาพร้อมกับการรันที่อ้างอิง และการกำหนดค่าของเว็บไซต์
จะปักหมุดผู้ชนะของแต่ละคู่ภาษาใหม่อีกครั้ง จนกว่าจะถึงตอนนั้น: เราใช้ค่าเริ่มต้นเดียวที่ตรงไปตรงมา

*คะแนนรวม (Composite score)* คือตัวชี้วัดคุณภาพแบบผสมผสานของ Network (chrF++, exact
match และปลั๊กอินตัวชี้วัดที่โหลดไว้ ซึ่งผ่านการตรวจสอบด้วย bootstrap-CI) คะแนนจะสามารถ
เปรียบเทียบได้ **ภายในคู่ภาษาเดียวกันเท่านั้น** ไม่สามารถเปรียบเทียบข้ามคู่ภาษาได้ — ความแตกต่างของตัวอักษรและ
คลังข้อมูลทำให้การเปรียบเทียบข้ามคู่ภาษาไม่มีความหมาย

## Register and tone

แต่ละภาษาได้รับการแปลด้วยระดับภาษาที่ชัดเจนซึ่งเลือกจาก
การ์ดภาษาของ Champollion เพื่อให้ความเป็นทางการมีความสอดคล้องกันทั่วทั้งเว็บไซต์:

- **Français** — vouvoiement (formal *vous*)
- **Deutsch** — Sie-Form
- **Nederlands** — u-vorm
- **Filipino** — formal, with standard technical terms
- **Español** — neutral Latin American Spanish
- **简体中文** — professional technical register
- **日本語** — です/ます (polite form)
- **한국어** — 해요체 (polite)
- **Português** — professional register
- **ไทย** — neutral professional
- **Tiếng Việt** — neutral *bạn*-form
- **العربية** — Modern Standard Arabic, professional register

## What is not machine-translated

บล็อกโค้ด, คำสั่ง CLI, คีย์การกำหนดค่า, ชื่อแพ็กเกจ, URL และ
คำนามเฉพาะจะได้รับการปกป้องในระหว่างการแปลและยังคงเป็นภาษาอังกฤษตาม
การออกแบบ

## Found a mistranslation?

เปิด Issue หรือ PR — ต้นฉบับของทุกหน้าที่ได้รับการแปลคือภาษาอังกฤษ
ต้นฉบับ การแก้ไขในหน้าที่ได้รับการแปลจะถูกเก็บรักษาไว้ในการซิงค์ครั้งต่อไปตราบ
เท่าที่ต้นฉบับภาษาอังกฤษของหน้านั้นไม่มีการเปลี่ยนแปลง (การซิงค์จะแปล
หน้าใหม่ก็ต่อเมื่อต้นฉบับภาษาอังกฤษมีการเปลี่ยนแปลงเท่านั้น)

*หน้านี้ได้รับการแปลด้วยเครื่องตามวิธีการที่อธิบายไว้ข้างต้น — ซึ่ง
อธิบายถึงการแปลของตัวมันเอง*
