# Champollion คืออะไร

**Champollion วัดผลการแปลด้วยเครื่องสำหรับภาษาที่ไม่มีใครวัดผล และเผยแพร่สิ่งที่ค้นพบ**

นั่นคือแนวคิดทั้งหมด ทุกสิ่งบนเว็บไซต์นี้เป็นเครื่องมือที่ใช้ในการวัดผล แผนที่ที่สร้างขึ้นจากการวัดผลเหล่านั้น หรือกฎเกณฑ์ที่เราใช้ในการดำเนินการ

---

## ปัญหา

มีภาษาที่ยังมีผู้ใช้งานอยู่ประมาณ 7,000 ภาษา สำหรับภาษาส่วนใหญ่ คุณไม่สามารถตอบคำถามพื้นฐานได้ว่า: *ถ้าเราต้องการแปลสิ่งนี้ วิธีที่ดีที่สุดที่มีอยู่คืออะไร และมันดีพอที่จะใช้งานหรือไม่?*

ไม่ใช่ "บริษัทไหนมีเดโม" แต่วิธีการใด — นักแปลที่เป็นมนุษย์, ระบบที่อิงตามกฎ (rule-based system), โมเดลภาษาที่ใช้พรอมต์ (prompted language model), โมเดลที่ผ่านการฝึกสอน (trained model) — ที่ใช้งานได้จริงสำหรับ **คู่ภาษานี้ บนข้อความประเภทนี้** และคุณจะรู้ได้อย่างไร

สำหรับคู่ภาษา English↔French คำถามนั้นได้รับการตอบมาแล้วเป็นพันครั้ง สำหรับคู่ภาษา English↔Plains Cree หรือ Ayta Abellen หรือภาษาอื่นๆ อีกหลายพันภาษา คำถามนี้มักไม่เคยถูกถามเลยด้วยซ้ำ มีการประกาศถึงความครอบคลุมของภาษา แต่แทบไม่มีการแสดงให้เห็นถึงคุณภาพ

ไม่มีใครทำการวัดผล ดังนั้นจึงไม่มีใครสามารถแยกแยะการพัฒนาที่แท้จริงออกจากข่าวประชาสัมพันธ์ได้ — และชุมชนที่ต้องการใช้เทคโนโลยีนี้ก็ไม่มีวิธีตรวจสอบว่ามันปลอดภัยพอที่จะเชื่อถือให้ใช้งานกับภาษาของพวกเขาหรือไม่

## สิ่งที่เราทำเพื่อแก้ไขปัญหานี้

เราไม่ได้กำลังสร้างเอนจินการแปล บริษัทเทคโนโลยีขนาดใหญ่เป็นผู้สร้างเอนจิน เราสร้างสิ่งที่บอกคุณว่าเอนจินนั้นใช้งานได้หรือไม่:

1. **รันวิธีการกับชุดทดสอบ** และให้คะแนน โดยใช้ขั้นตอนเดียวกันสำหรับทุกวิธีการและทุกภาษา
2. **เผยแพร่ผลลัพธ์** พร้อมแหล่งที่มา — ใช้ข้อมูลอะไร, วิธีการเวอร์ชันไหน, ตัวชี้วัดใด, และมีค่าใช้จ่ายเท่าไร
3. **ทำซ้ำจนกว่าแผนที่จะเป็นรูปเป็นร่าง**: ภาษาใดเชื่อมต่อกับภาษาใด, เชื่อมต่อกันได้ดีแค่ไหน, และมีช่องว่างอยู่ที่ใดบ้าง

คำตอบอย่างตรงไปตรงมาว่า "ยังไม่มีวิธีการใดที่ใช้งานได้สำหรับคู่ภาษานี้" คือผลลัพธ์ที่เราเผยแพร่ พื้นที่ส่วนใหญ่ของแผนที่ในตอนนี้คือคำตอบนั้น และการบอกเช่นนั้นคือประเด็นสำคัญ — ช่องว่างที่คุณมองเห็นคือช่องว่างที่ใครบางคนสามารถให้ทุนสนับสนุนหรือเข้ามาเติมเต็มได้

## กฎเกณฑ์ที่เราใช้ในการทำงาน

สิ่งเหล่านี้คือข้อจำกัด ไม่ใช่การตลาด ซึ่งเป็นตัวกำหนดว่าซอฟต์แวร์สามารถทำอะไรได้บ้าง

**เราไม่เคยเก็บคลังข้อมูล (corpus) ของคุณ** ชุดทดสอบจะถูกลงทะเบียนโดยการชี้ไปยังตำแหน่งที่ข้อมูลนั้นอยู่แล้ว ไม่ใช่การอัปโหลดมาให้เรา วิธีการต่างๆ จะถูกให้คะแนนโดยอิงจากคลังข้อมูลที่เราไม่เคยครอบครอง สำหรับชุดข้อมูลที่ถูกปิดผนึก (sealed sets) ข้อมูลจะถูกเข้ารหัสบนเครื่องของคุณก่อนที่จะถูกส่งออกไป และต้องอาศัยผู้ดูแลคีย์ของชุมชนตามจำนวนที่กำหนดร่วมกันเท่านั้นจึงจะสามารถอนุญาตให้รันการทดสอบได้

**ข้อมูลภาษาได้รับการปฏิบัติเสมือนข้อมูลทางชีวภาพ (biodata)** ผู้ที่ให้คลังข้อมูลจะเป็นผู้ถือคีย์สำหรับข้อมูลนั้น และสำหรับสิ่งใดก็ตามที่ถูกวัดผลโดยอิงจากข้อมูลนั้น เราจะขอความยินยอมเสมอ ไม่มีการทึกทักเอาเอง — และสามารถถอนความยินยอมได้

**เรามุ่งสู่อธิปไตยทางข้อมูล (sovereignty-aspirant) แต่ไม่ได้อ้างว่าได้รับการรับรอง (sovereignty-certified)** ความเป็นเจ้าของ การควบคุม การเข้าถึง และการครอบครองข้อมูลภาษาโดยชุมชน เป็นหลักการที่ชุมชนเป็นผู้กำหนดขึ้นเอง และการที่โปรเจกต์ใดจะตรงตามเกณฑ์นี้หรือไม่นั้น ไม่ใช่สิ่งที่โปรเจกต์จะสามารถกล่าวอ้างได้เอง เราลงมือทำงานและอธิบายกลไกต่างๆ อย่างตรงไปตรงมา ส่วนการตัดสินใจนั้นเป็นของชุมชนที่เกี่ยวข้อง

**ยินดีต้อนรับทุกวิธีการ ทั้งมนุษย์และเครื่องจักร** นักแปลมืออาชีพ, ระบบกฎที่อิงตาม FST, โมเดลระดับแนวหน้าที่ใช้พรอมต์ (prompted frontier model) และโมเดล NMT ที่ผ่านการปรับแต่ง (fine-tuned NMT model) จะถูกเปรียบเทียบด้วยวิธีเดียวกัน บนชุดทดสอบเดียวกัน เราใส่ใจเรื่องการทำให้ภาษาได้รับการแปล ไม่ใช่เรื่องที่ว่าเครื่องมือใดจะเป็นผู้ชนะ

**เราเผยแพร่สิ่งที่เราไม่สามารถทำได้** ดู [ข้อจำกัดตามความเป็นจริง](/docs/network/honest-limitations) — รายการสิ่งที่โปรเจกต์นี้ *ยังไม่* กล่าวอ้าง โปรดอ่านก่อนที่คุณจะเชื่อถือสิ่งอื่นใดในที่นี้

## องค์ประกอบต่างๆ และหน้าที่ของแต่ละส่วน

| หากคุณต้องการ… | ใช้ | สิ่งนี้คืออะไร |
|---|---|---|
| แปลแอปหรือเว็บไซต์ | **[Champollion CLI](/docs/intro)** | คำสั่งเดียวในการแปลไฟล์ locale ของคุณ; คุณสามารถเลือกวิธีการสำหรับแต่ละคู่ภาษาได้ |
| ให้คะแนนวิธีการ หรือทำซ้ำผลคะแนน | **[MT-Eval Harness](/docs/network/specifications/harness)** | เอนจินการประเมินผลด้วย Python ตัวเลขทุกตัวบนเว็บไซต์นี้มาจากเอนจินนี้ |
| ส่งผลลัพธ์ หรือจัดการแข่งขัน | **[The Arena](/docs/network/getting-started/submit-a-method)** | ช่องทางการส่งผลลัพธ์ ฐานข้อมูล และกลไกการแข่งขัน — สถานที่ที่เกิดการวัดผล |
| ดูข้อมูลที่เป็นที่ทราบเกี่ยวกับคู่ภาษา | **[The Network](/docs/network/)** | แผนที่ที่สร้างขึ้นจากการวัดผล: ความครอบคลุม, ความแข็งแกร่งของการเชื่อมต่อ, การกำหนดเส้นทาง (routing), และคิวของสิ่งที่จะวัดผลต่อไป |
| ค้นหาข้อมูลภาษา | **[The Atlas](/languages)** | การ์ดภาษา <SSOTCount field="catalogLanguageCount" /> — การจัดหมวดหมู่, สัทวิทยา, ความมีชีวิตชีวาของภาษา, และทรัพยากรที่มีอยู่ ทุกค่ามีการอ้างอิงแหล่งที่มา |
| ฝึกสอนโมเดลโดยไม่หลอกตัวเอง | **[NMT Forge](/docs/network/getting-started/training-honestly)** | ชุดเครื่องมือการฝึกสอนที่มีระบบป้องกัน (guardrails) ซึ่งทำให้การหลอกตัวเองแบบมาตรฐาน (ข้อมูลทดสอบรั่วไหล, การแบ่งข้อมูลที่ไม่เป็นตัวแทนที่ดี) เกิดขึ้นได้ยากในเชิงโครงสร้าง |
| ทำงานกับสิ่งนี้ในฐานะ AI agent | **[Agent Guide](/docs/network/getting-started/agent-guide)** | เครื่องมือ, เซิร์ฟเวอร์ MCP, และสิ่งที่อยู่ในปลายทาง (endpoints) ที่เครื่องสามารถอ่านได้ |

**Champollion เป็นดัชนี ไม่ใช่ผู้ตัดสิน** ทุกค่ามีการอ้างอิงแหล่งที่มาและรายงานสิ่งที่แหล่งที่มานั้นระบุไว้จริง ในกรณีที่แหล่งที่มาขัดแย้งกัน — ซึ่งมักเกิดขึ้นบ่อยครั้งในเรื่องจำนวนผู้พูด — การ์ดจะแสดงข้อมูลทั้งหมดพร้อมระบุที่มา เราไม่เลือกผู้ชนะหรือสร้างฉันทามติขึ้นมาเอง

## ที่มาของชื่อ

Jean-François Champollion ถอดรหัสอักษรเฮียโรกลิฟิกของอียิปต์โดยใช้ Rosetta Stone — ซึ่งเป็นข้อความเดียวกันในสามรูปแบบอักษร ข้อความคู่ขนาน (parallel text) ยังคงเป็นวิธีที่ใช้ในการเรียนรู้การแปล ชื่อนี้ยังแฝงความตึงเครียดที่ควรค่าแก่การกล่าวถึงอย่างชัดเจน: นักวิชาการชาวยุโรปที่อ่านงานเขียนของผู้อื่น ในยุคแห่งการตักตวงผลประโยชน์ เราตระหนักถึงเรื่องนั้น นั่นคือเหตุผลที่กฎเกณฑ์ด้านอธิปไตยข้างต้นเป็นข้อจำกัดในซอฟต์แวร์ ไม่ใช่แค่หน้ากระดาษในโบรชัวร์

## ไปที่ไหนต่อ

- **คุณต้องการแปลบางสิ่ง** → [เริ่มต้นใช้งานด่วน](/docs/getting-started/quick-start)
- **คุณเป็นผู้พูด ผู้สอน หรือผู้ดูแลภาษา** → [สำหรับชุมชนภาษา](/docs/network/community/for-language-communities) จากนั้นดู [การลงทะเบียนคลังข้อมูล](/docs/network/sovereignty/registering-corpora) เพื่อดูว่าชุดทดสอบถูกนำมาใช้อย่างไรโดยไม่ต้องส่งมอบข้อมูล
- **คุณเป็นนักวิจัยหรือผู้สร้างวิธีการ** → ข้อโต้แย้งที่ให้ความสำคัญกับการประเมินผลเป็นอันดับแรกใน [ใครได้รับประโยชน์](/docs/network/who-benefits#researchers) — ทำไมคู่ภาษาที่ผ่านการคัดสรรหนึ่งพันคู่จึงดีกว่าคู่ภาษาที่ไม่ผ่านการคัดสรรเจ็ดแสนคู่ — จากนั้นดู [ความร่วมมือด้านคลังข้อมูล](/docs/network/specifications/corpus-partnership) เพื่อนำภาษาเข้ามา หรือ [ส่งวิธีการ](/docs/network/getting-started/submit-a-method) และ [ข้อกำหนดการให้คะแนน](/docs/network/specifications/scoring) เพื่อแข่งขันในภาษาที่มีอยู่แล้ว
- **คุณเป็น AI agent** → [คู่มือสำหรับ Agent](/docs/network/getting-started/agent-guide); จุดเข้าถึงที่เครื่องสามารถอ่านได้คือ `/llms.txt` และ `/llms-full.txt`
- **คุณเป็นผู้ให้ทุนสนับสนุนงานประเภทนี้** → [ใครได้รับประโยชน์](/docs/network/who-benefits#funders) และ [ข้อจำกัดตามความเป็นจริง](/docs/network/honest-limitations)
- **คุณต้องการทราบภูมิหลัง** → [วงการนี้มาถึงจุดนี้ได้อย่างไร](/docs/network/context/mt-field-briefing), [อะไรที่นับว่าเป็นภาษา](/docs/network/context/what-counts-as-a-language), และ [การนับความครอบคลุมทำอย่างไร](/docs/network/context/coverage-counting)
