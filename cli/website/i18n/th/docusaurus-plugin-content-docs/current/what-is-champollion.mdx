# Champollion คืออะไร

**Champollion คือชุดเครื่องมือโอเพนซอร์สสำหรับการสร้างระบบแปลภาษาด้วยเครื่อง (machine translation) สำหรับภาษาของคุณ — พร้อมทั้งพิสูจน์ว่าใช้งานได้จริงก่อนที่ใครจะนำไปพึ่งพา**

เครื่องมือนี้สร้างขึ้นเพื่อภาษาที่บริษัทยักษ์ใหญ่ด้านเทคโนโลยีมองข้าม: โรงเรียนที่ต้องการจดหมายข่าวเป็นภาษาครี (Cree), โรงพยาบาลที่ต้องการคู่มือรวมวลีข้างเตียงสำหรับครอบครัวที่ตนดูแล, ชุมชนที่ต้องการรู้ว่ามีเครื่องมือใดที่ดีพอที่จะไว้วางใจให้ดูแลภาษาของตนหรือไม่ คุณ — หรือ AI agent ที่คุณสั่งการให้ใช้เครื่องมือเหล่านี้ — สามารถเริ่มต้นจาก *"เราจะเริ่มอย่างไรดี?"* ไปสู่เวิร์กโฟลว์การแปลที่ผ่านการทดสอบและนำไปใช้งานได้จริง

---

## เส้นทางการทำงาน และเครื่องมือสำหรับแต่ละขั้นตอน

| ขั้นตอน | คำถาม | เครื่องมือ |
|---|---|---|
| **1. สำรวจสิ่งที่มีอยู่** | มีข้อมูลอะไรบ้างเกี่ยวกับภาษานี้ — พจนานุกรม, ไวยากรณ์, คลังข้อมูลภาษา (corpora), โมเดล, ผลงานที่เผยแพร่, บริการต่างๆ? | **[The Atlas](/languages)** — บัตรข้อมูลภาษา <SSOTCount field="catalogLanguageCount" /> ภาษา; ทุกค่ามีการอ้างอิงแหล่งที่มา |
| **2. ปกป้องข้อมูลของคุณเอง** | เราจะทดสอบด้วยประโยคของเราเองโดยไม่ต้องส่งมอบข้อมูลให้ผู้อื่นได้อย่างไร? | **[การลงทะเบียนคลังข้อมูลภาษา (Registering corpora)](/docs/network/sovereignty/registering-corpora)** และ **[โหนดอธิปไตย (sovereign node)](/docs/network/sovereignty/sovereign-eval-node)** — เก็บชุดทดสอบไว้ในเครื่องของคุณ หรือตัดการเชื่อมต่อจากเครือข่าย (air-gapped) |
| **3. วัดผลตัวเลือกต่างๆ** | วิธีการใดดีที่สุดสำหรับข้อความของ*เรา* และดีกว่ามากน้อยเพียงใด? | **[The harness](/docs/network/specifications/harness)** (`mt-eval`) — ให้คะแนนวิธีการใดๆ เทียบกับคลังข้อมูลภาษาใดๆ ด้วยขั้นตอนเดียวกันในทุกครั้ง |
| **4. สร้างสิ่งที่ดีกว่า** | เราสามารถฝึกฝน (train) หรือปรับแต่งโมเดลด้วยตัวเองโดยไม่หลอกตัวเองได้หรือไม่? | **[NMT Forge](/docs/network/getting-started/training-honestly)** (`nmt-forge`) — การเทรนที่มีเกราะป้องกันชุดทดสอบรั่วไหล, การแบ่งข้อมูลที่ไม่ถูกต้อง และการมองสัญญาณรบกวนเข้าข้างตัวเอง |
| **5. พิสูจน์ผล เปิดเผยอย่างโปร่งใสหากคุณเลือก** | ดีขึ้นจริงหรือไม่? ผู้อื่นสามารถตรวจสอบได้ไหม? | **[ตารางคะแนนและการแข่งขัน](/docs/network/getting-started/submit-a-method)** — เผยแพร่ผลลัพธ์ หรือจัดการแข่งขันบนชุดทดสอบแบบปิดผนึก (sealed test set) ที่ไม่มีวันหลุดออกจากโหนดของคุณ |
| **6. รวมสิ่งที่ดีที่สุดเข้าด้วยกัน** | ใครให้บริการอะไรสำหรับคู่ภาษานี้บ้าง และสิ่งใดที่ทำงานร่วมกันได้? | **[เครือข่าย (The Network)](/docs/network/)** — วิธีการและบริการที่มีอยู่ พร้อมหลักฐานยืนยันของแต่ละรายการ |
| **7. นำไปใช้งาน** | แปลแอปพลิเคชัน, เว็บไซต์, หรือเอกสาร | **[Champollion CLI](/docs/intro)** — นำผลลัพธ์ที่ได้รับการพิสูจน์แล้วไปใช้งานจริงในแต่ละคู่ภาษา พร้อมระบบหน่วยความจำการแปล (translation memory) เพื่อให้คุณไม่ต้องจ่ายซ้ำสองสำหรับประโยคเดิม |

**[เซิร์ฟเวอร์ MCP](/docs/network/getting-started/mcp-server)** ช่วยให้ AI agent มีเครื่องมือสำหรับดำเนินการทุกขั้นตอนข้างต้น และเอกสารเหล่านี้เขียนขึ้นเพื่อให้ทั้งมนุษย์และ agent ใช้งานได้เหมือนกัน (รูปแบบที่เครื่องอ่านได้: `/llms.txt`, `/llms-full.txt`)

**การวัดผลคือหัวใจหลัก** การครอบคลุมมักถูกป่าวประกาศ แต่คุณภาพกลับแทบไม่เคยถูกนำมาแสดง ทุกขั้นตอนข้างต้นจบลงด้วยตัวเลขที่คุณสามารถตรวจสอบได้ พร้อมที่มาที่ไป — ข้อมูลใด, วิธีการเวอร์ชันใด, ตัววัดใด, และใช้ต้นทุนเท่าใด การบอกความจริงว่า "ยังไม่มีอะไรใช้งานได้สำหรับคู่นี้" คือผลลัพธ์ที่เราเผยแพร่ เพราะช่องว่างที่คุณมองเห็นคือช่องว่างที่ใครสักคนสามารถเข้ามาเติมเต็มได้

## กฎเกณฑ์ที่เราใช้ในการทำงาน

สิ่งเหล่านี้คือข้อจำกัด ไม่ใช่การตลาด ซึ่งเป็นตัวกำหนดว่าซอฟต์แวร์สามารถทำอะไรได้บ้าง

**เราไม่เคยถือครองคลังข้อมูลภาษาของคุณ** การลงทะเบียนชุดทดสอบทำได้โดยการชี้ไปยังตำแหน่งที่ข้อมูลนั้นจัดเก็บอยู่เดิม ไม่ใช่การอัปโหลดมาให้เรา วิธีการต่างๆ จะได้รับการให้คะแนนเทียบกับคลังข้อมูลที่เราไม่เคยครอบครอง สำหรับชุดข้อมูลแบบปิดผนึก ข้อมูลจะถูกเข้ารหัสไว้ในเครื่องของคุณและคงอยู่ที่นั่น โดยการออกแบบระบบจำเป็นต้องอาศัยเกณฑ์ขั้นต่ำของผู้ดูแลกุญแจชุมชนในการร่วมกันอนุมัติการรัน (ขณะนี้ยังไม่มีการแต่งตั้งผู้ใด)

**ข้อมูลภาษาได้รับการปฏิบัติเสมือนข้อมูลทางชีวภาพ (biodata)** ผู้ที่ให้คลังข้อมูลจะเป็นผู้ถือคีย์สำหรับข้อมูลนั้น และสำหรับสิ่งใดก็ตามที่ถูกวัดผลโดยอิงจากข้อมูลนั้น เราจะขอความยินยอมเสมอ ไม่มีการทึกทักเอาเอง — และสามารถถอนความยินยอมได้

**เรามุ่งหวังอธิปไตยทางข้อมูล แต่ไม่ได้ผ่านการรับรองอธิปไตยทางข้อมูล** การที่โครงการใดจะเคารพความเป็นเจ้าของและการควบคุมข้อมูลภาษาของชุมชนหรือไม่นั้น ไม่ใช่ข้ออ้างที่โครงการนั้นจะประกาศขึ้นมาเองได้ เราลงมือทำงานและอธิบายกลไกต่างๆ อย่างตรงไปตรงมา การตัดสินชี้ขาดขึ้นอยู่กับชุมชนที่เกี่ยวข้อง

**ยินดีต้อนรับทุกวิธีการ ทั้งมนุษย์และเครื่องจักร** นักแปลมืออาชีพ, ระบบกฎที่อิงตาม FST, โมเดลระดับแนวหน้าที่ใช้พรอมต์ (prompted frontier model) และโมเดล NMT ที่ผ่านการปรับแต่ง (fine-tuned NMT model) จะถูกเปรียบเทียบด้วยวิธีเดียวกัน บนชุดทดสอบเดียวกัน เราใส่ใจเรื่องการทำให้ภาษาได้รับการแปล ไม่ใช่เรื่องที่ว่าเครื่องมือใดจะเป็นผู้ชนะ

**เราเผยแพร่สิ่งที่เราไม่สามารถทำได้** ดู [ข้อจำกัดตามความเป็นจริง](/docs/network/honest-limitations) — รายการสิ่งที่โปรเจกต์นี้ *ยังไม่* กล่าวอ้าง โปรดอ่านก่อนที่คุณจะเชื่อถือสิ่งอื่นใดในที่นี้

---

**Champollion เป็นดัชนี ไม่ใช่ผู้ตัดสิน** ทุกค่ามีการอ้างอิงแหล่งที่มาและรายงานสิ่งที่แหล่งที่มานั้นระบุไว้จริง ในกรณีที่แหล่งที่มาขัดแย้งกัน — ซึ่งมักเกิดขึ้นบ่อยครั้งในเรื่องจำนวนผู้พูด — การ์ดจะแสดงข้อมูลทั้งหมดพร้อมระบุที่มา เราไม่เลือกผู้ชนะหรือสร้างฉันทามติขึ้นมาเอง

---

## ที่มาของชื่อ

Jean-François Champollion ถอดรหัสอักษรเฮียโรกลิฟิกของอียิปต์โดยใช้ Rosetta Stone — ซึ่งเป็นข้อความเดียวกันในสามรูปแบบอักษร ข้อความคู่ขนาน (parallel text) ยังคงเป็นวิธีที่ใช้ในการเรียนรู้การแปล ชื่อนี้ยังแฝงความตึงเครียดที่ควรค่าแก่การกล่าวถึงอย่างชัดเจน: นักวิชาการชาวยุโรปที่อ่านงานเขียนของผู้อื่น ในยุคแห่งการตักตวงผลประโยชน์ เราตระหนักถึงเรื่องนั้น นั่นคือเหตุผลที่กฎเกณฑ์ด้านอธิปไตยข้างต้นเป็นข้อจำกัดในซอฟต์แวร์ ไม่ใช่แค่หน้ากระดาษในโบรชัวร์

## ไปที่ไหนต่อ

- **คุณต้องการสร้าง MT สำหรับภาษาหนึ่งๆ ตั้งแต่ต้นจนจบ** → [สร้าง MT สำหรับภาษาของคุณ](/docs/build-mt-for-your-language): อธิบายทุกขั้นตอนข้างต้นพร้อมคำสั่งที่แน่นอน และเครื่องมือ MCP ที่ agent จะเรียกใช้สำหรับแต่ละขั้นตอน
- **คุณต้องการแปลแอปหรือเว็บไซต์** → [เริ่มต้นอย่างรวดเร็ว](/docs/getting-started/quick-start)
- **คุณพูด สอน หรือดูแลภาษา** → [สำหรับชุมชนภาษา](/docs/network/community/for-language-communities) จากนั้นดูที่ [การลงทะเบียนคลังข้อมูลภาษา](/docs/network/sovereignty/registering-corpora) เพื่อดูวิธีนำชุดทดสอบไปใช้งานโดยไม่ต้องส่งมอบข้อมูล
- **คุณเป็นนักวิจัยหรือผู้พัฒนาวิธีการ** → ข้อสนับสนุนแนวทาง eval-first ใน [ใครได้รับประโยชน์](/docs/network/who-benefits#researchers) — เหตุใดคู่ภาษาที่ผ่านการคัดสรรหนึ่งพันคู่จึงดีกว่าเจ็ดแสนคู่ที่ไม่ได้คัดสรร — จากนั้นดูที่ [ความร่วมมือด้านคลังข้อมูลภาษา](/docs/network/specifications/corpus-partnership) เพื่อนำภาษาใหม่เข้ามา หรือ [ส่งวิธีการของคุณ](/docs/network/getting-started/submit-a-method) และ [ข้อกำหนดการให้คะแนน](/docs/network/specifications/scoring) เพื่อร่วมแข่งขันในภาษาที่มีอยู่แล้ว
- **คุณเป็น AI agent** → [คู่มือสำหรับ Agent](/docs/network/getting-started/agent-guide); จุดเริ่มต้นที่เครื่องอ่านได้คือ `/llms.txt` และ `/llms-full.txt`
- **คุณเป็นผู้สนับสนุนทุนให้งานลักษณะนี้** → [ใครได้รับประโยชน์](/docs/network/who-benefits#funders) และ [ข้อจำกัดอย่างตรงไปตรงมา](/docs/network/honest-limitations)
- **คุณต้องการทราบความเป็นมา** → [วงการ MT มาถึงจุดนี้ได้อย่างไร](/docs/network/context/mt-field-briefing), [สิ่งใดนับเป็นภาษา](/docs/network/context/what-counts-as-a-language) และ [การนับความครอบคลุมทำอย่างไร](/docs/network/context/coverage-counting)
