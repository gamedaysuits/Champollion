# เริ่มต้นโปรเจกต์

มีสองวิธีในการเริ่มต้น ไม่ว่าจะเลือกวิธีไหน เครื่องมือจะทำงานบนคอมพิวเตอร์ของคุณเอง
และจะพาคุณทำไปทีละขั้นตอน

## ใช้ผู้ช่วย AI

นี่คือวิธีที่ง่ายที่สุด ผู้ช่วยของคุณจะเป็นคนพิมพ์ ส่วนคุณเพียงแค่ตอบคำถามที่เป็นการตัดสินใจของคุณ

**สิ่งที่คุณต้องมี:** ผู้ช่วย AI ที่ทำงานเป็นแอปบนคอมพิวเตอร์ของคุณ — ไม่ใช่แค่แอปบนโทรศัพท์ — และสามารถใช้งานเครื่องมือในเครื่องได้

### 1. เพิ่ม rails ให้กับผู้ช่วยของคุณ

คัดลอกการตั้งค่าสั้น ๆ ด้านล่างนี้ วางลงในผู้ช่วยของคุณ แล้วบอกว่า:
*"ช่วยตั้งค่านี้ให้หน่อย"* ผู้ช่วยหลายตัวสามารถทำได้ หากผู้ช่วยของคุณทำไม่ได้ ให้ขอให้คนที่เชี่ยวชาญคอมพิวเตอร์ช่วยทำให้สักครั้ง — ขั้นตอนอยู่ด้านล่างนี้แล้ว

```json
{
  "mcpServers": {
    "champollion": { "command": "npx", "args": ["-y", "champollion-mcp-server"] }
  }
}
```

<details>
<summary>การตั้งค่าด้วยตนเอง</summary>

ผู้ช่วยเชื่อมต่อกับเครื่องมือต่าง ๆ ผ่านมาตรฐานทั่วไปที่เรียกว่า MCP การตั้งค่าด้านบนจะบอกให้ผู้ช่วยของคุณทราบวิธีเริ่มการทำงานของ rails นอกจากนี้ คอมพิวเตอร์ของคุณต้องมี Node.js 20.11 หรือใหม่กว่า ซึ่งเป็นโปรแกรมฟรี

- **แอปเดสก์ท็อปของ Claude:** Settings → Developer → Edit Config แล้วเพิ่มการตั้งค่าลงในไฟล์นั้น บันทึกไฟล์ และรีสตาร์ตแอป
- **Claude Code:** รันคำสั่งนี้หนึ่งครั้งในเทอร์มินัล:
  `claude mcp add champollion -- npx -y champollion-mcp-server`
- **Cursor:** เพิ่มการตั้งค่าลงในไฟล์ `mcp.json` ในโฟลเดอร์ `.cursor` ของโปรเจกต์คุณ หรือในโฟลเดอร์ `.cursor` ในโฟลเดอร์โฮมของคุณ

</details>

### 2. บอกสิ่งที่คุณต้องการด้วยคำพูดของคุณเอง

ประมาณว่า:

> *เราต้องการสร้างระบบแปลภาษาจากภาษาอังกฤษเป็นภาษาของเรา — ใช้
> champollion*

### 3. ตอบคำถามที่ผู้ช่วยถาม

ขั้นแรก ผู้ช่วยจะทวนทิศทางการแปลให้คุณฟัง — *"คุณป้อนภาษาอังกฤษ แล้วผลลัพธ์เป็นภาษาของคุณ คุณต้องการแบบนี้ใช่ไหม?"* — เพราะการสลับทิศทางเป็นข้อผิดพลาดที่เกิดขึ้นได้ง่าย จากนั้น ผู้ช่วยจะสร้างโฟลเดอร์โปรเจกต์และขอไฟล์ของคุณ

จากนั้นเป็นต้นไป ผู้ช่วยจะถามทุกครั้งที่ต้องมีการตัดสินใจจากคุณ: ถ้อยคำของคุณเป็นของใคร ระบบแปลภาษาสามารถเรียนรู้จากคำเหล่านี้ได้หรือไม่ หรือควรติดตั้งบางอย่างหรือไม่ ตอบตามความต้องการของคุณได้เลย หากคุณยังไม่ทราบ ก็บอกไปตามตรง — rails รอได้เสมอ และคำตอบว่า *ยังไม่ใช่ตอนนี้* ก็ใช้ได้ตลอด: rails จะไม่ถามซ้ำอีกในเซสชันนั้น

**สิ่งหนึ่งที่ควรทราบก่อน** ผู้ช่วยส่วนใหญ่จะส่งสิ่งที่อ่านกลับไปยังบริษัทที่ดูแลระบบ สำหรับไฟล์ที่เก็บไว้ในคอมพิวเตอร์เครื่องนี้ เครื่องมือจะบอกผู้ช่วยของคุณเพียงแค่ว่าคุณมีประโยคอยู่*จำนวนเท่าใด*เท่านั้น โดยไม่ส่งเนื้อหาประโยคไป — แต่ผู้ช่วยที่สามารถใช้งานคอมพิวเตอร์ของคุณได้ ก็สามารถเปิดไฟล์ใดก็ได้ที่คุณเปิดได้เช่นกัน สำหรับถ้อยคำที่คุณต้องการเก็บไว้เป็นส่วนตัว ให้บอกผู้ช่วยว่าห้ามเข้าถึง หรือใช้ผู้ช่วยที่ทำงานบนคอมพิวเตอร์ของคุณเอง หน้า [ถ้อยคำของคุณ กฎเกณฑ์ของคุณ](/docs/your-words-your-rules) มีคำอธิบายเพิ่มเติม

## ดำเนินการด้วยตนเอง

หากคุณสะดวกพิมพ์คำสั่งเอง ก็มีเพียงสี่บรรทัด ติดตั้งเครื่องมือของโปรเจกต์ (ต้องใช้ Node.js 20.11 หรือใหม่กว่า) เริ่มต้นโปรเจกต์ และถามว่าต้องทำอะไรต่อ:

```bash
npm install -g champollion
champollion new family --from English --to qaa --target-name "Our language"
cd family
champollion next
```

`qaa` หมายถึง "ภาษาที่ยังไม่มีรหัสภาษา" — ซึ่งสามารถใช้งานได้ตามปกติ เพียงแต่เครื่องมือจะไม่สามารถกรอกข้อมูลพื้นฐานอย่างเช่นชุดตัวอักษรให้คุณได้ ชื่อในเครื่องหมายคำพูดคือชื่อที่คุณจะใช้เรียกภาษานั้น หากภาษาของคุณมีรหัสภาษา หรือมีชื่อที่เครื่องมือรู้จัก ให้ใช้รหัสนั้นแทน หากชื่อหนึ่งอาจหมายถึงได้หลายภาษา ให้สอบถามผู้พูดภาษาของคุณก่อนว่าพวกเขาพูดภาษาใดก่อนจะเลือกรหัส ระหว่างที่ยังไม่แน่ใจ การใช้ `qaa` สามารถทำงานได้ แต่จะไม่มีการ์ดข้อมูลภาษา ดังนั้นจึงไม่มีกฎพหูพจน์หรือชุดอักษรติดมาด้วย

จากนั้นเป็นต้นไป `champollion next` จะบอกขั้นตอนถัดไปและคำสั่งที่ต้องใช้อย่างแม่นยำเสมอ เมื่อถึงเวลาสอนระบบแปลภาษา rails จะถามก่อนที่จะติดตั้งเครื่องมือฝึกฝน

## การทำงานโดยไม่ใช้อินเทอร์เน็ต

โปรดเชื่อมต่ออินเทอร์เน็ตไว้ตลอดการติดตั้งและการฝึกฝนครั้งแรก: เครื่องมือฝึกฝนและระบบแปลภาษาที่มีประสิทธิภาพสูงกว่า (ขนาดประมาณ 1.2 GB) จะถูกดาวน์โหลดในช่วงนี้ หลังจากนั้น การทำงานทั้งหมดจะเกิดขึ้นบนคอมพิวเตอร์ของคุณ เพื่อระงับการค้นหาข้อมูลของตัวเครื่องมือเอง — ซึ่งอาจดึงการ์ดข้อมูลสาธารณะของภาษา โดยส่งไปเพียงรหัสภาษาเท่านั้น — ให้ตั้งค่าสิ่งนี้ในเทอร์มินัลของคุณและในการตั้งค่าของผู้ช่วย:

```bash
export CHAMPOLLION_OFFLINE=1
```

ผู้ช่วย AI ที่ทำงานบนคอมพิวเตอร์ของบริษัทผู้ให้บริการยังคงต้องใช้อินเทอร์เน็ต หากต้องการทำงานแบบออฟไลน์โดยสมบูรณ์ ให้ใช้ผู้ช่วยที่ทำงานบนคอมพิวเตอร์ของคุณเอง

## สิ่งที่คาดหวังได้

ระบบแปลภาษาชุดแรกของคุณอาจทำหน้าที่เหมือนคู่มือวลีสนทนา: แปลประโยคที่คล้ายกับสิ่งที่เคยเรียนรู้มาได้ดี แต่ยังทำสิ่งอื่นไม่ได้มากนัก ทุกโปรเจกต์ต่างก็เริ่มต้นจากจุดนี้ หน้า [สิ่งที่ระบบยังทำไม่ได้ในตอนนี้](/docs/what-it-cant-do-yet) จะอธิบายสิ่งที่คาดหวังได้อย่างตรงไปตรงมา และหน้า [พัฒนาให้ดียิ่งขึ้น](/docs/make-it-better) จะแสดงให้เห็นว่าระบบพัฒนาต่อไปได้อย่างไร
