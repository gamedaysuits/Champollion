# การทำงาน: บนรางพร้อมราวกั้น

ลองนึกภาพสองบรรทัดที่วางคู่ขนานกัน: ประโยคหนึ่งในภาษาหนึ่ง และประโยคเดียวกันในอีกภาษาหนึ่ง นั่นคือสิ่งที่ระบบแปลภาษาใช้เรียนรู้ และเป็นสิ่งที่ระบบสร้างขึ้นมา

แต่ก่อน การสร้างระบบแปลภาษาจำเป็นต้องพึ่งพาผู้เชี่ยวชาญ คุณต้องรู้วิธีเตรียมประโยค วิธีฝึกสอนระบบแปลภาษา และที่ยากที่สุดคือวิธีทดสอบโดยไม่หลอกตัวเอง บทเรียนส่วนใหญ่เหล่านั้นล้วนได้มาจากการลองผิดลองถูกอย่างยากลำบาก

Champollion วางขั้นตอนทั้งหมดไว้เป็นเหมือน **ราง** ที่จัดลำดับทุกก้าวอย่างเป็นระเบียบ และมีที่ทางสำหรับทุกสิ่ง ขนานไปตามรางคือ **ราวกั้น** ที่คอยตรวจสอบเพื่อป้องกันข้อผิดพลาดทั่วไป และช่วยให้คำของคุณอยู่ภายใต้การควบคุมของคุณเสมอ คุณ หรือผู้ช่วย AI ที่คุณไว้วางใจ จะเดินไปตามรางนี้ โดยที่คุณเป็นผู้ตัดสินใจ

## ใครเป็นผู้ตัดสินใจเรื่องใด

รางทำหน้าที่ดำเนินขั้นตอนต่างๆ แต่คนเป็นผู้ตัดสินใจ ทุกขั้นตอนจัดอยู่ใน 4 ประเภทนี้:

- **มีเพียงคนเท่านั้นที่ทำได้** — การเขียนประโยค และการตรวจทานคำแปล ไม่มีเครื่องมือใดแอบอ้างว่าเป็นผู้ใช้ภาษานั้น
- **มีเพียงคุณเท่านั้นที่ตอบได้** — คำของคุณเป็นของใคร ระบบแปลภาษาจะใช้เรียนรู้ได้หรือไม่ และคุณคาดหวังอะไรก่อนที่จะเห็นผลลัพธ์ ผู้ช่วยจะถามคุณเสมอ และไม่ตอบแทนคุณโดยพลการ
- **ผู้ช่วยของคุณต้องถามก่อน** — สิ่งใดก็ตามที่ต้องติดตั้งสิ่งใหม่ ฝึกสอนระบบแปลภาษา มีค่าใช้จ่าย หรือนำข้อมูลขึ้นออนไลน์ จะต้องรอให้คุณตอบตกลงก่อนเสมอ การตอบว่า *ยังไม่ใช่ตอนนี้* ก็เป็นคำตอบเช่นกัน รางจะไม่ถามซ้ำอีกในเซสชันนั้น
- **ผู้ช่วยของคุณลงมือทำได้เลย** — เช่น การตรวจหาปัญหาในประโยค หรือการแยกประโยคบางส่วนเก็บไว้

## ราง: ที่ทางสำหรับทุกสิ่ง

โปรเจกต์คือโฟลเดอร์หนึ่งบนคอมพิวเตอร์ของคุณ โดยมีชั้นวางสำหรับข้อมูลแต่ละประเภท:

| ชั้นวาง | สิ่งที่วางบนชั้นนี้ |
|---|---|
| ประโยคสำหรับเรียนรู้ | คู่ประโยค ภาษาละหนึ่งประโยค |
| ประโยคสำหรับทดสอบ | ประโยคที่ผู้ใช้ภาษาอย่างคล่องแคล่วได้ตรวจทานแล้ว ใช้เพื่อประเมินผลเท่านั้น ไม่ใช้ในการเรียนรู้เด็ดขาด |
| รายการคำศัพท์ | พจนานุกรมและรายการคำ |
| บันทึกไวยากรณ์ | สิ่งใดก็ตามที่บันทึกไว้เกี่ยวกับหลักการทำงานของภาษา |
| ข้อตกลง | บันทึกว่าใครตกลงเรื่องใด และเมื่อใด |
| กล่องขาเข้า | ไฟล์ต่างๆ ของคุณตามสภาพเดิม ที่รอการนำเข้า |

ระบบแปลภาษาที่คุณสร้าง ผลลัพธ์ของระบบเหล่านั้น และบันทึกของแต่ละขั้นตอน ล้วนมีชั้นวางเฉพาะของตัวเอง

ประโยคของคุณจะถูกแบ่งออกเป็นสามกอง ส่วนใหญ่มีไว้สำหรับ**การเรียนรู้** บางส่วน — ในตอนแรก
คือหนึ่งในสี่ และเป็นหนึ่งในสิบเมื่อคุณมีประโยคมากขึ้น — จะกลายเป็น**ประโยค
ฝึกฝน** — เหมือนโจทย์แบบฝึกหัดที่นำมาใช้ในทุกรอบ
เพื่อดูว่าระบบทำได้ดีแค่ไหน และอีกไม่กี่ประโยคที่ผ่านการตรวจสอบโดยผู้พูดภาษานั้น จะเป็น**ประโยค
ทดสอบ** ซึ่งนำมาใช้เพียงนาน ๆ ครั้งเท่านั้น ตัวแปลภาษาจะไม่เรียนรู้จาก
สองส่วนหลังนี้เลย

เพราะทุกสิ่งมีที่ทางของมัน เครื่องมือจึงรู้ได้เสมอว่ามีสิ่งใดทำเสร็จไปแล้วและสิ่งใดที่ต้องทำต่อไป คุณสามารถถามได้ทุกเมื่อ แล้วเครื่องมือจะบอก **ขั้นตอนถัดไป** โดยอ่านจากโฟลเดอร์โดยตรง ผู้ช่วยของคุณจึงไม่จำเป็นต้องเป็นผู้เชี่ยวชาญ หรือต้องคอยจำว่าคุณทำค้างไว้ตรงไหน แค่ทำตามรางไปเรื่อยๆ

ขั้นตอนจะเรียงตามลำดับดังนี้:

1. **เริ่มต้นโปรเจกต์** — ระบุชื่อทั้งสองภาษา และทิศทางที่คุณต้องการแปล
2. **รวบรวมข้อมูลของคุณ** — นำสิ่งที่คุณมีเข้ามา พร้อมบันทึกว่าข้อมูลเป็นของใครและอนุญาตให้ใช้งานอย่างไรได้บ้าง
3. **ปกป้องชุดทดสอบของคุณ** — แยกประโยคที่คุณจะใช้ประเมินระบบแปลภาษาทุกตัวเก็บไว้
4. **ติดตั้งเครื่องมือฝึกสอน** — ทำเพียงครั้งเดียว เมื่อคุณตอบตกลง
5. **สร้างและทดสอบระบบแปลภาษา** — ฝึกสอนระบบ แล้วดูผลการทำงานกับประโยคสำหรับทดสอบ
6. **ปรับปรุงให้ดีขึ้นทีละรอบ** — ให้ผู้ใช้ภาษาตรวจทานฉบับร่าง และในแต่ละรอบให้มุ่งเน้นไปที่จุดที่ยังแปลผิด

คุณสามารถทำขั้นตอนใดๆ ด้วยวิธีของคุณเองได้เสมอ — ไม่ว่าจะทำด้วยมือ หรือใช้เครื่องมืออื่น — แล้วรางจะสานต่อจากสถานะปัจจุบันที่ระบุไว้ในโฟลเดอร์

## ราวกั้น

ราวกั้นแบ่งออกเป็นสองประเภท

**บางข้อช่วยป้องกันไม่ให้คุณหลอกตัวเอง** ระบบแปลภาษาที่ทดสอบด้วยประโยคที่เคยเรียนรู้มาแล้วอาจดูเก่งกาจ ทั้งที่จริงไม่ได้เป็นเช่นนั้น หรือรอบที่โชคดีอาจดูเหมือนมีความก้าวหน้า ดังนั้น รางจึง:

- แยกประโยคสำหรับทดสอบไว้ก่อนที่การฝึกสอนจะเริ่มต้นขึ้น
- นำประโยคที่แทบจะคัดลอกมาจากประโยคทดสอบออกไป
- ขอให้คุณระบุสิ่งที่คาดหวังไว้เป็นลายลักษณ์อักษรก่อนที่จะเห็นผลลัพธ์
- และจะตัดสินว่าระบบแปลภาษาตัวใหม่ดีกว่า ก็ต่อเมื่อมันทำผลงานได้ดีกว่าตัวเดิมเกินกว่าที่จะเป็นเพียงเรื่องของโชค

**บางข้อช่วยให้คำของคุณอยู่ภายใต้การควบคุมของคุณเสมอ** ทุกไฟล์จะมีบันทึกระบุว่าเจ้าของข้อมูลได้ตัดสินใจไว้อย่างไร — ไฟล์นี้จะส่งออกจากคอมพิวเตอร์เครื่องนี้ได้หรือไม่ ระบบแปลภาษาจะนำไปใช้เรียนรู้ได้หรือไม่ — และทุกเครื่องมือจะปฏิบัติตามบันทึกนั้นอย่างเคร่งครัด

เครื่องมือจะไม่อนุญาตให้ข้ามการตรวจสอบส่วนใหญ่เหล่านี้ มีเพียงไม่กี่ข้อที่ขึ้นอยู่กับคุณและผู้ช่วยของคุณ ซึ่ง[หน้าราวกั้น](/docs/guardrails)จะมีรายละเอียดระบุไว้
