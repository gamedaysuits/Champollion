# แปลแอปหรือเว็บไซต์

แอปและเว็บไซต์จะเก็บข้อความต่าง ๆ — ไม่ว่าจะเป็นปุ่ม เมนู ข้อความ หรือหน้าเว็บ — ไว้ในไฟล์ แยกภาษาละไฟล์ Champollion สามารถเติมคำแปลลงในไฟล์ภาษาของคุณ และคอยอัปเดตให้เป็นปัจจุบันอยู่เสมอเมื่อต้นฉบับเปลี่ยนแปลง เพียงคำสั่งเดียวก็จัดการได้ทั้งหมด:

```bash
npx champollion sync
```

ระบบจะค้นหาไฟล์ภาษาของแอป แปลเฉพาะส่วนที่ขาดหายไปหรือมีการเปลี่ยนแปลง ตรวจสอบคำแปลทุกรายการก่อนเขียนลงไฟล์ และปล่อยส่วนที่เหลือไว้ตามเดิม

## ตัวแปลภาษาใดเป็นผู้ทำงานนี้

คุณสามารถเลือกได้สำหรับแต่ละภาษา:

- **ตัวแปลภาษาของคุณเอง** ที่สร้างขึ้นบน rails — เครื่องมือต่าง ๆ จะเชื่อมต่อตัวแปลนี้เข้ากับแอปของคุณ หากตัวแปลภาษาเรียนรู้จากประโยคที่เป็นความลับส่วนบุคคล ระบบจะเชื่อมต่อก็ต่อเมื่อคุณระบุว่าใครในกลุ่มผู้ดูแลถ้อยคำที่ให้ความยินยอม
- **โมเดล AI หรือบริการแปลภาษา** — สำหรับภาษาที่ระบบเหล่านั้นรองรับได้ดีอยู่แล้ว บริการเหล่านี้จะส่งข้อความในแอปของคุณไปยังบริษัทผู้ให้บริการ จึงควรใช้กับข้อความที่เปิดเผยและแชร์ได้
- **บริการของคุณเอง** ตามที่อยู่ที่คุณระบุไว้

## สิ่งที่ระบบช่วยดูแล

- **แปลเฉพาะส่วนที่เปลี่ยน** ระบบจะจำสิ่งที่เคยแปลไว้ก่อนหน้า คุณจึงไม่ต้องจ่ายซ้ำสองรอบสำหรับประโยคเดิม
- **ตรวจสอบก่อนเขียนลงไฟล์** คำตอบที่ว่างเปล่า การคัดลอกต้นฉบับกลับมา คำที่วนซ้ำไปมา ข้อความที่ยาวเกินควร ชิ้นส่วนที่ขาดหาย หรือการใช้อักษรผิด จะถูกตรวจพบและปฏิเสธ การตรวจสอบเหล่านี้จะตรวจจับผลลัพธ์ที่เสียหาย ไม่ใช่การแปลผิดความหมาย — ผู้พูดภาษานั้นยังคงเป็นผู้ตัดสินใจขั้นสุดท้าย
- **ไฟล์ของคุณ ในรูปแบบของคุณ** ทั้ง JSON, YAML, TOML และหน้า Markdown รวมถึงเฟรมเวิร์กของแอปและเว็บไซต์ทั่วไป

## ใครบ้างที่สามารถใช้งานได้

ใช้งานได้ฟรีสำหรับการใช้งานที่ไม่ใช่เชิงพาณิชย์ — แอปของโรงเรียน เว็บไซต์ชุมชน บริการสาธารณะ ผลิตภัณฑ์ของธุรกิจจะไม่อยู่ภายใต้ใบอนุญาตฟรีนี้ แต่หากชุมชนเจ้าของภาษาต้องการนำไปใช้ในเชิงพาณิชย์ เพียงแจ้งขอมา เราก็อนุญาตให้ใช้ได้ฟรี อ่านรายละเอียดได้ที่ [ใครบ้างที่สามารถใช้งานสิ่งนี้ได้](/docs/getting-started/who-may-use-this)
