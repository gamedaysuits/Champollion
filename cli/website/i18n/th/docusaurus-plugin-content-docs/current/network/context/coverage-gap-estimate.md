# ช่องว่างความครอบคลุม: วิธีที่เราใช้ประเมิน

> **บทสรุปผู้บริหาร** หน้าแรกของ Champollion ระบุว่าผู้คน *มากกว่าหนึ่งพันล้านคน* ที่ยังมีชีวิตอยู่ในปัจจุบันไม่สามารถเข้าถึงการแปลด้วยเครื่อง (machine translation) เป็นภาษาแม่ของตนได้ หน้านี้จะแสดงวิธีการคำนวณที่อยู่เบื้องหลังวลีดังกล่าว ระบุการตัดสินใจสองประการที่ส่งผลต่อตัวเลขนี้ และอธิบายเหตุผลที่เราเผยแพร่ตัวเลขขั้นต่ำแบบอนุรักษ์นิยมแทนที่จะเป็นผลรวมดิบที่มีจำนวนมากกว่า Champollion เป็นเพียงดัชนี ไม่ใช่ผู้มีอำนาจตัดสิน — ทุกตัวเลขในที่นี้สามารถหาได้จากบิลด์สาธารณะ และเรายินดีรับการแก้ไขเสมอ

## คำถามที่เรากำลังถามจริงๆ

ไม่ใช่ "มีกี่ภาษาที่ขาดแคลน MT" แต่เป็น **มีกี่คนที่ไม่สามารถเข้าถึงการแปลด้วยเครื่องเป็นภาษาแม่ของตนได้** ภาษาแม่ (L1) ของบุคคลคือภาษาที่พวกเขาใช้คิดและต้องการใช้อ่านข่าวมากที่สุด การพูดได้สองภาษาไม่ได้ทำให้ใครถูกตัดออกจากการนับนี้: ผู้ที่พูดได้ทั้งภาษา Quechua และภาษาสเปนซึ่งมีภาษาแม่เป็นภาษา Quechua ก็ยังคงไม่สามารถอ่านหน้าเว็บ *ในภาษา Quechua* ได้ ดังนั้นประชากรเป้าหมายคือ: ทุกคนที่มี L1 เป็นหนึ่งในภาษาที่ยังมีผู้ใช้งานอยู่ (living languages) ซึ่งไม่มีเอนจิน MT เฉพาะทางใดรองรับ

## ตัวเลขนี้คำนวณอย่างไร

มีองค์ประกอบสองส่วน ซึ่งทั้งคู่อยู่ในรีโพสิทอรี:

1. **ภาษาที่ยังมีผู้ใช้งานอยู่ภาษาใดบ้างที่มี MT** บิลด์จะทำการอินเตอร์เซกชัน (intersect) ระหว่างยูเนียนของรายการภาษาจากเอนจินที่ติดตามเก้าตัว (Google, Microsoft, DeepL, LibreTranslate, NLLB-200, OPUS-MT, M2M-100, MADLAD-400, Tilde — `shared/catalogue/method-coverage.json` โดยแต่ละรายการมีการอ้างอิงและลงวันที่) กับภาษา *individual living* ตามมาตรฐาน ISO 639-3 (`isoType: 'L'`) ใน `data/tc-index.json` ผลลัพธ์: **ครอบคลุม 552 ภาษาที่ยังมีผู้ใช้งานอยู่, ไม่ครอบคลุม 6,525 ภาษา** จากภาษาที่ยังมีผู้ใช้งานอยู่ทั้งหมด **7,077** ภาษา (`stats.coverage.dedicatedLiving` / `uncoveredLiving`)
2. **มีผู้พูดภาษาที่ไม่ครอบคลุมจำนวนเท่าใด** สำหรับแต่ละภาษาที่ยังมีผู้ใช้งานอยู่แต่ไม่ครอบคลุม เราจะนำ `speakerCount` ของภาษานั้น (ดึงมาจากการประมาณการที่อ้างอิงในการ์ดภาษา) มาหาผลรวม บิลด์จะส่งออกค่านี้เป็น `stats.coverageGap` ผลรวมดิบของทั้ง 6,525 ภาษาที่ไม่ครอบคลุมคือประมาณ **2.9 พันล้านคน** (`uncoveredSpeakerSumRaw` ≈ 2,974,871,273)

ตัวเลข 2.9 พันล้านคนนั้นเป็นตัวเลข **ค่อนไปทางขอบเขตบน (upper-ish)** และเราก็ระบุไว้อย่างชัดเจน

### ทำไมผลรวมดิบจึงไม่สมบูรณ์

`speakerCount` เป็นการผสมผสานระหว่างผู้พูดภาษาแม่ (L1) และผู้พูดทั้งหมด (L1+L2) ขึ้นอยู่กับสิ่งที่แต่ละแหล่งข้อมูลรายงาน และบุคคลที่พูดได้หลายภาษาสามารถถูกนับรวมในมากกว่าหนึ่งภาษาได้ ข้อสังเกตคือ: การรวม `speakerCount` จาก *ทั้งหมด* 7,082 ภาษาที่ยังมีผู้ใช้งานอยู่ จะได้ตัวเลขประมาณ **10.8 พันล้านคน** — ซึ่งมากกว่าประชากรโลกที่มีชีวิตอยู่ประมาณ 8.1 พันล้านคน (UN World Population Prospects) การสำรวจสำมะโนประชากร L1 ที่สมบูรณ์จะไม่สามารถเกินจำนวนประชากรโลกได้ แต่ตัวเลขนี้เกิน ซึ่งพิสูจน์ให้เห็นว่าฟิลด์นี้ไม่ใช่ L1 ล้วนๆ

## การตัดสินใจสองประการ (แต่ละประการส่งผลต่อตัวเลข)

**(a) การนับเฉพาะ L1 เทียบกับการนับรวมทั้งหมด** การจำกัดเฉพาะผู้พูดภาษาแม่จะทำให้ค่าประมาณลดลง — โดยพื้นฐานแล้ว ผู้พูด L2 คือผู้ที่ *มี* ภาษาอื่นอยู่แล้ว แต่ตัวเลข L1 ของแต่ละภาษานั้นไม่ได้มีให้ใช้อย่างสม่ำเสมอในแหล่งข้อมูลที่เราอ้างอิง ดังนั้นเราจึงไม่สามารถใช้กฎเฉพาะ L1 ได้ทุกที่โดยไม่สร้างตัวเลขขึ้นมาเอง การใช้การนับแบบผสมจึงดันค่าประมาณให้ *สูงขึ้น*

**(b) 777 ภาษาที่ไม่ครอบคลุมและไม่มีการรายงานจำนวนผู้พูด** จาก 6,525 ภาษาที่ยังมีผู้ใช้งานอยู่แต่ไม่ครอบคลุม **5,748 ภาษามีตัวเลขผู้พูด และ 777 ภาษาไม่มี** (`uncoveredWithCount` / `uncoveredNoCount`) การละเว้น 777 ภาษาดังกล่าว — ซึ่งเป็นสิ่งที่ผลรวมดิบทำ — ทำให้ *นับได้น้อยกว่าความเป็นจริง* เนื่องจากภาษาเหล่านี้เป็นภาษาที่มีอยู่จริงและมีผู้พูดจริง (ที่ไม่ได้วัดจำนวน) ซึ่งส่วนใหญ่เป็นภาษาชนกลุ่มน้อยและใกล้สูญพันธุ์

ดังนั้นข้อผิดพลาดทั้งสองจึงชี้ไปในทิศทางตรงกันข้าม: การผสม L1/L2 ทำให้ตัวเลขสูงเกินจริง และส่วนหางของ 777 ภาษาทำให้ตัวเลขต่ำกว่าความเป็นจริง

## เหตุใดเราจึงรายงานตัวเลขขั้นต่ำที่ "มากกว่าหนึ่งพันล้านคน"

ช่วงที่เป็นไปได้เริ่มตั้งแต่ขั้นต่ำใกล้เคียง **1 พันล้านคน** ไปจนถึงตัวเลขดิบที่ **~2.9 พันล้านคน** แม้จะหักลบอย่างหนักสำหรับการนับซ้ำของ L2 *และ* ละเว้นส่วนหางของ 777 ภาษาที่ไม่ได้วัดจำนวนทั้งหมด ประชากรที่ใช้ภาษาแม่ในกลุ่มภาษาที่ไม่ครอบคลุมก็ยังคงมีมากกว่าหนึ่งพันล้านคนอย่างแน่นอน แทนที่จะพาดหัวด้วยตัวเลขที่ใหญ่กว่าและซับซ้อนกว่า เว็บไซต์จึงรายงานตัวเลขในฝั่งอนุรักษ์นิยม "มากกว่าหนึ่งพันล้านคน" คือคำกล่าวอ้างที่เรามั่นใจที่สุดว่าจะผ่านการตรวจสอบความถูกต้องได้

## สิ่งใดที่สามารถเปลี่ยนแปลงตัวเลขนี้ได้

การประมาณการที่แม่นยำยิ่งขึ้นจำเป็นต้องมี **ตัวเลขผู้พูด L1 ของแต่ละภาษา โดยแต่ละตัวเลขต้องมีการอ้างอิง** เพื่อให้เราสามารถรวม L1 ได้โดยตรงแทนการผสม L1/L2 และสามารถใส่ค่าประมาณที่สมเหตุสมผลให้กับ 777 ภาษาที่ยังไม่ได้นับในปัจจุบัน เมื่อเอนจินเพิ่มภาษา ตัวเลข 552 จะเพิ่มขึ้นและช่องว่างจะแคบลง; เมื่อการ์ดภาษาได้รับจำนวนนับจากแหล่งข้อมูลที่ดีขึ้น ผลรวมก็จะแม่นยำขึ้น นี่คือ **การประมาณการที่ดำเนินการอย่างต่อเนื่อง** ซึ่งจะถูกคำนวณใหม่ในทุกๆ บิลด์ — ไม่ใช่ข้อเท็จจริงที่ตายตัว

## ยินดีรับการแก้ไขและการถกเถียง

หากคุณมีข้อมูลที่ดีกว่า คิดว่าการตัดสินใจในที่นี้ผิดพลาด หรือสามารถหาแหล่งข้อมูลสำหรับ 777 ภาษาที่หายไปได้ โปรดบอกเรา นั่นคือจุดประสงค์หลัก เปิด Issue ได้ที่ [github.com/gamedaysuits/Champollion/issues](https://github.com/gamedaysuits/Champollion/issues) หรือส่งอีเมลมาที่ [info@champollion.dev](mailto:info@champollion.dev)

## แหล่งข้อมูล

- **ความครอบคลุม (Coverage)** — `cli/shared/catalogue/method-coverage.json` (เก้าเอนจิน แต่ละรายการมีการอ้างอิงและลงวันที่) ∩ ภาษา individual living ตามมาตรฐาน ISO 639-3 ใน `cli/website/data/tc-index.json`; แสดงผลเป็น `stats.coverage.dedicatedLiving` / `uncoveredLiving` ได้มาจาก Champollion
- **ผลรวมผู้พูด (Speaker sums)** — `speakerCount` บนแถว `tc-index.json` (จาก `speakerEstimates` ที่อ้างอิงในการ์ดภาษาแต่ละใบ) ซึ่งบิลด์นำมารวมกันเป็น `stats.coverageGap` (`uncoveredSpeakerSumRaw`, `uncoveredWithCount`, `uncoveredNoCount`) ได้มาจาก Champollion; ผสม L1/L2 ตามแหล่งข้อมูล
- **ประชากรโลก (World population)** — ประมาณ 8.1 พันล้านคน (สหประชาชาติ, *World Population Prospects*) ใช้เป็นเพียงขอบเขตตรวจสอบความสมเหตุสมผล (sanity bound) สำหรับผลรวมผู้พูดเท่านั้น
