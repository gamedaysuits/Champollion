# แหล่งที่มาของการสนับสนุนทางการเงิน

> **บทสรุปผู้บริหาร** Champollion เป็นโครงการวิจัยที่ไม่แสวงหาผลกำไร —
> เปิดเผยซอร์สโค้ด (source-available) และใช้งานได้ฟรีสำหรับวัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์ evaluation harness และ
> registries เป็นโอเพนซอร์ส — และในปัจจุบัน **ได้รับทุนสนับสนุนทั้งหมดจาก
> ผู้ก่อตั้งเอง** ไม่มีเงินทุนสนับสนุน
> ไม่มีผู้สนับสนุน ไม่มีสถาบันใดอยู่เบื้องหลัง — ในตอนนี้: เรากำลัง[เปิดรับ
> ผู้สนับสนุนอย่างเป็นทางการ](/get-involved#sponsors) เงินสนับสนุนทุกดอลลาร์จะถูก
> **ส่งต่อ 100%**: เพื่อใช้เป็นทุนในการสร้างคลังข้อมูล (corpus) เครื่องมือ และงานชุมชน
> ตามอัตราที่ประกาศไว้ โดยมีการทำบัญชีอย่างเปิดเผย — จะไม่มีส่วนใดตกเป็นของ Champollion
> ไม่มีสิ่งใดในที่นี้ที่ถูกนำไปสร้างรายได้: ไม่มี API แบบชำระเงิน ไม่มีการคิดค่าบริการตามการใช้งาน (metering) ไม่มีการแบ่งปันรายได้
> และไม่มีการอ้างสิทธิ์ของแพลตฟอร์มเหนือสิ่งใดก็ตามที่ชุมชนเป็นเจ้าของ หน้านี้จะอธิบาย
> อย่างชัดเจนว่าปัจจุบันเงินทุนมาจากไหน เงินทุนจะถูกนำไปใช้อะไรบ้าง และวิธี
> ติดต่อเราหากคุณต้องการเปลี่ยนแปลงส่วนแรก

Champollion เป็นเครื่องมือสำหรับการวิจัยและพัฒนาการแปลด้วยเครื่อง (machine-translation) —
เปิดเผยซอร์สโค้ด (source-available) และใช้งานได้ฟรีสำหรับวัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์ CLI ใช้สัญญาอนุญาต PolyForm
Noncommercial 1.0.0 (การใช้งานเชิงพาณิชย์ต้องได้รับอนุญาต) evaluation
harness เป็นโอเพนซอร์สภายใต้ AGPL-3.0 และ data registries เป็นโอเพนซอร์สภายใต้
Apache-2.0 ไม่มีผลิตภัณฑ์เชิงพาณิชย์ใดอยู่เบื้องหลัง — และยังไม่มีเงินทุน
สนับสนุนอยู่เบื้องหลังเช่นกัน

## แหล่งที่มาของเงินในปัจจุบัน

**บุคคลเดียว** ทุกสิ่งที่สร้างขึ้นจนถึงตอนนี้ — ชุดประเมินผล, CLI, ดัชนีภาษา, ข้อกำหนดเกณฑ์มาตรฐาน, และเว็บไซต์ — ล้วนได้รับการสนับสนุนทางการเงินด้วยตนเองโดยผู้ก่อตั้งโครงการ เราระบุสิ่งนี้อย่างตรงไปตรงมาด้วยเหตุผลสองประการ:

1. **ความซื่อสัตย์เกี่ยวกับขนาด** โครงการที่สนับสนุนตนเองยังไม่สามารถจ่ายค่าใช้จ่ายสำหรับการสร้างคลังข้อมูลและการตรวจสอบโดยผู้พูดภาษาตามที่ข้อกำหนดระบุไว้ได้ อัตราที่เผยแพร่ไว้เป็นข้อผูกพันเกี่ยวกับ *วิธีการ* เคลื่อนย้ายเงินเมื่อมีอยู่ ไม่ใช่หลักฐานว่ากำลังเคลื่อนย้ายอยู่แล้ว
2. **เป็นคำเชิญชวนที่เปิดกว้าง** โครงสร้างพื้นฐานถูกสร้างขึ้นแล้วและต้นทุนต่อหน่วยได้รับการเผยแพร่แล้ว สิ่งที่ขาดอยู่คือเงินทุนสำหรับดำเนินการ หากคุณให้ทุนสนับสนุนเทคโนโลยีภาษา — ในฐานะหน่วยงานให้ทุน มูลนิธิ ภาควิชา หรือบุคคล — **เราอยากได้ยินจากคุณ**: เปิด issue บน [GitHub](https://github.com/gamedaysuits/Champollion) หรือติดต่อผ่าน [champollion.dev](https://champollion.dev)

## สิ่งที่เงินทุนสามารถซื้อได้

ต้นทุนได้รับการระบุไว้แล้ว ดังนั้นผู้ให้ทุนจึงสามารถสนับสนุนสิ่งที่เป็นรูปธรรมและมีขอบเขตชัดเจนได้:

- **การสร้างคลังข้อมูลสำหรับภาษาหนึ่ง** — ค่าตอบแทนผู้พูดภาษา $2,500–6,000 (อัตรา $50–65 CAD/ชั่วโมง ตามอัตราที่เผยแพร่) สร้างคลังข้อมูลเกณฑ์มาตรฐานที่ยังคงเป็นทรัพย์สินของผู้สร้าง ดูที่ [วิธีที่ผู้พูดภาษาได้รับค่าตอบแทน](/docs/network/perspectives/how-speakers-get-paid)
- **รอบการตรวจสอบเมตริก** — $1,475–1,920 จ่ายให้ผู้พูดสองภาษาสามคนเพื่อตรวจสอบเมตริกอัตโนมัติเทียบกับการตัดสินของมนุษย์
- **รางวัลที่ได้รับการสนับสนุน** — สนับสนุนเป้าหมายที่กำหนด (เช่น การแปลภาษาอังกฤษ → Plains Cree ที่เชื่อถือได้) เงินรางวัลถูกดูแลและมอบโดยทรัสต์ที่ชุมชนกำกับดูแล ตามเงื่อนไขของชุมชน — ไม่ใช่โดย Champollion ดูที่ [ข้อกำหนดรางวัล](/docs/network/specifications/prizes)
- **เครดิตการประมวลผลและ API** — รวมกันเพื่อรันคิวเกณฑ์มาตรฐานสาธารณะ

ในทางปฏิบัติ สิ่งนี้ทำให้ Network เป็นกลไกการกระจายเงินทุนสำหรับงานข้อมูลภาษา: เงินเข้า งานที่ได้รับค่าตอบแทนสำหรับผู้สร้างคลังข้อมูลออก — และพวกเขาเก็บสิ่งที่สร้างไว้เป็นของตนเอง

## เงินไปที่ไหน

- **ไปยังผู้สร้างคลังข้อมูลและผู้ตรวจสอบ ตามอัตราที่เผยแพร่** การชำระเงินไม่ได้โอนความเป็นเจ้าของ: ผู้สร้างได้รับค่าตอบแทนสำหรับงาน *และ* ยังคงเป็นผู้ดูแลคลังข้อมูล
- **ไปยังผู้ชนะรางวัล ผ่านทรัสต์ของชุมชน** เมื่อมีการเรียกรับรางวัลที่ได้รับการสนับสนุน ทรัสต์จะจ่ายให้นักพัฒนา และวิธีการดังกล่าวจะถ่ายโอนไปยังชุมชนตามเงื่อนไขของรางวัลนั้น (ดู [ความเป็นเจ้าของและเงื่อนไข](/docs/network/sovereignty/ownership-transfer))
- **ไปยังโครงสร้างพื้นฐาน** — การโฮสต์ การรันการประเมินผล และการบำรุงรักษา
- **บัญชีสาธารณะ** การสนับสนุนที่ได้รับทุนจะถูกบันทึกอย่างเปิดเผย — สิ่งที่ได้รับทุน ในอัตราที่เผยแพร่ใด และสิ่งที่ส่งมอบ — เพื่อให้ผู้สนับสนุน (และทุกคน) สามารถตรวจสอบได้ว่าคำมั่นสัญญาการส่งต่อ 100% ยังคงอยู่

## สิ่งที่ Champollion รับ

**ไม่มีอะไร** ไม่มีการแบ่งรายได้ ไม่มีเปอร์เซ็นต์โครงสร้างพื้นฐาน และไม่มีการอ้างสิทธิ์ในทรัพย์สินของชุมชน หากชุมชนนำวิธีการที่ตนเป็นเจ้าของไปใช้งาน — บนเซิร์ฟเวอร์ของตนเอง ผ่านช่องทางของตนเอง ไม่ว่าจะเชิงพาณิชย์หรือไม่ก็ตาม — ทุกสิ่งที่ได้รับเป็นของตนเองทั้งหมด คลังข้อมูลที่ลงทะเบียนกับ Network ยังคงเป็นทรัพย์สินของผู้ดูแลอย่างสมบูรณ์ ก่อน ระหว่าง และหลังการประเมินใดๆ

หากโอกาสเชิงพาณิชย์เกิดขึ้นรอบๆ งานนี้ในอนาคต เราเปิดรับการสนทนานั้น — แต่ข้อตกลงใดๆ ดังกล่าวจะถูกเจรจาในเวลานั้น ร่วมกับผู้ดูแลที่มีข้อมูลหรือวิธีการที่เกี่ยวข้อง ตามเงื่อนไขของพวกเขา ไม่มีสิ่งใดถูกผูกมัดล่วงหน้าในเอกสารเหล่านี้ และไม่มีเอกสารใดในที่นี้ที่ควรถูกตีความว่าสงวนส่วนแบ่งของสิ่งใดไว้สำหรับแพลตฟอร์ม

## สำหรับผู้ให้ทุน

คำถามเรื่องความยั่งยืนสำหรับเทคโนโลยีภาษามักจะเป็น "จะเกิดอะไรขึ้นหลังจากทุนหมด?" สำหรับโครงการที่ไม่มุ่งหวังผลกำไร คำตอบที่ซื่อสัตย์คือ: *ทรัพย์สิน* มีอายุยืนกว่าเงินทุน เพราะเป็นของผู้ที่สามารถดูแลรักษาได้

| รูปแบบดั้งเดิม | รูปแบบการดูแลรักษา |
|---|---|
| ทุนสนับสนุนการวิจัย | ทุนสนับสนุนการวิจัย |
| เผยแพร่บทความ | สร้างคลังข้อมูล วัดผลวิธีการ |
| ทุนหมด เครื่องมือถูกทิ้งร้าง | ชุมชนเป็นเจ้าของคลังข้อมูลและวิธีการที่ถ่ายโอนอย่างสมบูรณ์ |
| ชุมชนไม่ได้รับอะไร | ผู้พูดภาษาได้รับค่าตอบแทนทุกชั่วโมง ทรัพย์สินอยู่กับชุมชน |

ผลลัพธ์ที่วัดได้สำหรับผู้ให้ทุน:

- คลังข้อมูลที่สร้างและลงทะเบียนแล้ว ภายใต้การควบคุมของผู้ดูแล
- ชั่วโมงการทำงานของผู้พูดภาษาที่ได้รับค่าตอบแทน ส่งมอบให้ชุมชนภาษา
- วิธีการที่ได้รับการวัดผล และ (ในกรณีที่เงื่อนไขของรางวัลระบุไว้) ถ่ายโอนไปยังความเป็นเจ้าของของชุมชน
- คู่ภาษาที่ครอบคลุมโดยเกณฑ์มาตรฐานสาธารณะที่เชื่อถือได้

ดู [ข้อกำหนดเกณฑ์มาตรฐาน](/docs/network/specifications/benchmark) §10 สำหรับรูปแบบต้นทุนโดยละเอียด
