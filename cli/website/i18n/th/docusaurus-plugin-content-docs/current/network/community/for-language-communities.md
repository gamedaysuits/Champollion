# สำหรับชุมชนภาษา

> **สรุปสำหรับผู้บริหาร** ชุมชนของคุณสามารถเป็นเจ้าของชุดทดสอบของตนเอง — "เฉลยคำตอบ" ที่ใช้วัดผลวิธีการแปลทุกรูปแบบ — และจัดการแข่งขันของตนเองตามเงื่อนไขของตนเอง โดยไม่ต้องส่งมอบข้อมูลให้ใครเลย หน้านี้อธิบายสิ่งที่ Network ต้องการจากชุมชนภาษา (การแปลอ้างอิง การตรวจสอบการแปล ข้อมูลสำหรับการฝึกสอน) สิ่งที่คุณได้รับกลับ (งานที่ได้รับค่าตอบแทนตามอัตราที่เผยแพร่ไว้ ความเป็นเจ้าของโค้ด การควบคุมการใช้งานอย่างเต็มรูปแบบ) และการรับประกันด้านอธิปไตยที่มาเป็นอันดับแรก ไม่จำเป็นต้องมีความรู้ด้านการเขียนโปรแกรม และไม่มีสิ่งใดในที่นี้ที่ต้องอาศัยความไว้วางใจต่อเรา เพราะการรับประกันเหล่านี้เป็นโครงสร้าง ไม่ใช่คำสัญญา

คุณไม่จำเป็นต้องเป็นโปรแกรมเมอร์เพื่อมีส่วนร่วมกับ Network หากคุณพูดภาษาพื้นเมืองหรือภาษาที่มีทรัพยากรน้อย คุณคือบุคคลที่สำคัญที่สุดในระบบนิเวศนี้

---

## อธิปไตยมาเป็นอันดับแรก

ก่อนที่เราจะขอสิ่งใดจากคุณ ขอกำหนดกฎพื้นฐานไว้ก่อน: **ข้อมูลภาษาของคุณเป็นของคุณ** ข้อมูลภาษาคือ *ข้อมูลชีวภาพ* — มันบรรจุอัตลักษณ์และความสัมพันธ์ของชุมชนคุณ และไม่สามารถทำให้ไม่ระบุตัวตนได้อย่างมีความหมาย — ดังนั้นผู้ที่ให้ข้อมูลนี้จึงถือกุญแจสำคัญของมัน และของทุกสิ่งที่วัดผลเทียบกับมัน Network สร้างขึ้นบน[หลักการอธิปไตยทางข้อมูล](/docs/network/sovereignty/data-sovereignty):

- เราไม่เก็บรวบรวมหรือจัดเก็บข้อมูลภาษาของคุณบนเซิร์ฟเวอร์ของเรา
- วิธีการแปลใช้สถาปัตยกรรม `api` — ข้อมูลสำหรับการฝึกสอน พจนานุกรม และกฎไวยากรณ์ทั้งหมดอยู่บนโครงสร้างพื้นฐานที่คุณควบคุม
- คุณเป็นผู้ตัดสินใจว่าใครสามารถพัฒนาวิธีการสำหรับภาษาของคุณได้
- คะแนนบน Leaderboard พิสูจน์ว่าวิธีการนั้นใช้งานได้ แต่ไม่ได้ให้สิทธิ์ในการนำไปใช้งาน

:::note[สถานะในปัจจุบัน]
โมเดลการโอนความเป็นเจ้าของที่อธิบายไว้ด้านล่างนี้เป็น **การออกแบบที่มุ่งมั่นจะดำเนินการ ไม่ใช่โปรแกรมที่กำลังทำงานอยู่** ลีดเดอร์บอร์ดเปิดรับการส่งผลงานและยังไม่มีการรันที่เผยแพร่ในขณะนี้ และยังไม่มีวิธีการใดที่ถ่ายโอนไปยังชุมชนแล้ว เราอธิบายวิธีการที่สร้างขึ้นเพื่อให้ทำงานได้ เพื่อให้คุณสามารถตรวจสอบเราได้ — ไม่ใช่เพื่อบอกว่ามันกำลังดำเนินอยู่แล้ว ความสัมพันธ์และอำนาจของคุณเหนือข้อมูลของคุณมาก่อนเสมอ สิ่งอื่น ๆ ทั้งหมดตามมาจากนั้น
:::

## เป็นเจ้าของชุดทดสอบของคุณ

ตำแหน่งที่แข็งแกร่งที่สุดที่ชุมชนสามารถถือครองในระบบนี้คือ **การเป็นเจ้าของ benchmark นั้นเอง** ชุดทดสอบคือเฉลยคำตอบ: ผู้ที่ถือครองมันเป็นผู้ตัดสินว่า "การแปลที่ดี" หมายความว่าอะไรสำหรับภาษานั้น และทุกวิธีการ — ของเรา ของบริษัท ของใครก็ตาม — ถูกวัดผลเทียบกับ *มาตรฐานของคุณ*

- **การลงทะเบียนคือข้อมูลเมตา ไม่ใช่เนื้อหา** การลงทะเบียน corpus กับ Network หมายถึงการเผยแพร่การ์ดคำอธิบาย — ไม่ใช่การอัปโหลด corpus คุณเลือก[เลนการเปิดเผย](/docs/network/sovereignty/registering-corpora)ของมัน: เปิด, มีการควบคุม, หรืออธิปไตยเต็มรูปแบบ
- **Benchmark แบบอธิปไตยยังคงเป็นความลับ** ในเลนอธิปไตย ชุดทดสอบจะไม่ออกจากโครงสร้างพื้นฐานของชุมชน และเราจะไม่มีวันเห็นมัน วิธีการถูกให้คะแนนเทียบกับมันในฝั่งของคุณ มีเพียงคะแนนเท่านั้นที่ส่งผ่านมา
- **คุณสามารถจัดการแข่งขันของคุณเองได้** คู่มือทีละขั้นตอน — [Run a Sovereign Contest](/docs/network/sovereignty/run-a-sovereign-contest) — อธิบายการจัดการประเมินผลที่ควบคุมโดยชุมชนตามเงื่อนไขของคุณเอง: ชุดทดสอบของคุณ กฎของคุณ การตัดสินใจของคุณว่าจะเผยแพร่อะไร (ถ้ามี)

การรับประกันที่อยู่เบื้องหลังทั้งหมดนี้ถูกเขียนไว้อย่างชัดเจน ไม่ใช่แค่นัยยะ: [Data Stewardship](/docs/network/sovereignty/data-sovereignty) (จุดยืนด้านอธิปไตยทางข้อมูล/CARE และสิ่งที่ห้ามเราทำ) และ [Ownership & Terms](/docs/network/sovereignty/ownership-transfer) (สิ่งที่เกิดขึ้นตามสัญญาเมื่อวิธีการชนะ)

## สิ่งที่เราต้องการจากคุณ

### การแปลอ้างอิง

เราต้องการคู่การแปลที่ผ่านการคัดสรรสำหรับการประเมินผล — ภาษาอังกฤษด้านหนึ่ง ภาษาของคุณอีกด้านหนึ่ง สิ่งเหล่านี้จะกลายเป็น "เฉลยคำตอบ" ที่ใช้ให้คะแนนวิธีการแปลทั้งหมด

คุณอาจสร้างสิ่งเหล่านี้จาก:
- **สื่อการศึกษา** — แบบฝึกหัดในตำรา แผนการสอน ใบงาน
- **เอกสารชุมชน** — รายงานการประชุม จดหมายข่าว ประกาศ
- **วลีในชีวิตประจำวัน** — สตริง UI ป้ายกำกับแอป สำนวนทั่วไป
- **เนื้อหาทางวัฒนธรรม** — เรื่องราว เพลง หรือคำอธิบาย (พร้อมการอนุญาตที่เหมาะสม)

รูปแบบเป็น JSON ที่เรียบง่าย:
```json
{
  "entries": [
    { "id": 1, "source": "Hello", "reference": "tânisi" },
    { "id": 2, "source": "Thank you", "reference": "kinanâskomitin" }
  ]
}
```

### การตรวจสอบการแปล

ทุกวิธีการที่อ้างว่าสามารถสร้างการแปลที่ใช้งานได้ต้องผ่านการตรวจสอบโดยมนุษย์ ผู้พูดสองภาษาตรวจสอบผลลัพธ์และบอกเราว่าคอมพิวเตอร์แปลถูกต้องหรือไม่ — และที่สำคัญกว่านั้น *ทำไม* มันถึงแปลผิด

### ข้อมูลสำหรับการฝึกสอน

กฎไวยากรณ์ รายการพจนานุกรม รูปแบบทางสัณฐานวิทยา — สิ่งเหล่านี้คือทรัพยากรทางภาษาที่ทำให้วิธีการแปลทำงานได้ ความรู้ของคุณเกี่ยวกับวิธีที่ภาษาของคุณทำงานนั้นไม่มีโมเดล AI ใดสามารถทดแทนได้

## สิ่งที่คุณได้รับกลับ

### ความเป็นเจ้าของ

เมื่อวิธีการแปลถูกสร้างขึ้นสำหรับภาษาของคุณและได้รับการตรวจสอบบน Network แล้ว [ความเป็นเจ้าของจะโอน](/docs/network/sovereignty/ownership-transfer)ไปยังองค์กรกำกับดูแลของชุมชนคุณ คุณเป็นเจ้าของโค้ด น้ำหนักโมเดล และการใช้งาน

### งานที่ได้รับค่าตอบแทน ไม่ใช่การดึงเอาทรัพยากรไป

การสร้าง corpus และการตรวจสอบการแปลเป็นงานวิชาชีพ ได้รับค่าตอบแทนตาม[อัตราที่เผยแพร่ไว้](/docs/network/perspectives/how-speakers-get-paid) — และการจ่ายเงินไม่ได้ซื้อข้อมูลของคุณ คุณได้รับค่าตอบแทนสำหรับงาน *และ* ยังคงเป็นเจ้าของสิ่งที่คุณสร้าง Champollion เป็นโครงการวิจัยที่ไม่แสวงหากำไร: ไม่ขายอะไร ไม่คิดค่าใช้งาน และ[ไม่รับส่วนแบ่ง](/docs/network/sovereignty/economic-model)จากสิ่งที่ชุมชนของคุณได้รับจากวิธีการที่ตนเองเป็นเจ้าของ

### การควบคุม

องค์กรกำกับดูแลของคุณควบคุม:
- ใครสามารถเข้าถึงวิธีการได้
- ว่าจะสามารถนำไปใช้เชิงพาณิชย์ได้หรือไม่ — และถ้าใช่ ตามเงื่อนไขของคุณ โดยเก็บรายได้ทั้งหมดไว้
- เมื่อใดและอย่างไรที่จะอัปเดต
- ข้อมูลใดที่ใช้สำหรับการพัฒนาต่อไป

## วิธีการมีส่วนร่วม

:::tip[สิ่งที่ผู้พูดภาษาสามารถทำได้ในวันนี้]
Champollion ไม่ได้สร้างหรือโฮสต์คลังข้อมูล — ข้อมูลทดสอบจะถูกดึงมาจากแหล่งที่มาเสมอ หากผู้พูดภาษาในชุมชนของคุณต้องการมีส่วนร่วมในการเพิ่มประโยค*ตอนนี้เลย* [Tatoeba](https://tatoeba.org) รับการมีส่วนร่วมทีละประโยคในทุกภาษา และคอลเลกชันแบบเปิดอย่าง [OPUS](https://opus.nlpl.eu/) รวบรวมข้อความคู่ขนานที่ Network ใช้สร้างเกณฑ์มาตรฐาน ประโยคที่เพิ่มไว้ที่นั่นสามารถกลายเป็นข้อมูลการประเมินที่นี่ได้ในการสร้างคลังข้อมูลครั้งถัดไป แอปสำหรับผู้พูดภาษาในการมีส่วนร่วมโดยตรงและเครื่องมือสร้างคลังข้อมูลเป็นขั้นตอนถัดไปที่วางแผนไว้ใน roadmap ของเรา
:::

1. **ติดต่อเรา** — เปิด issue บน [Network repository](https://github.com/gamedaysuits/Champollion) หรืออีเมล [info@champollion.dev](mailto:info@champollion.dev)
2. **อธิบายภาษาของคุณ** — อยู่ในตระกูลภาษาใด? มีผู้พูดกี่คน? ใช้ระบบการเขียนใด? มีทรัพยากรการประมวลผลอะไรบ้าง (FST พจนานุกรม corpus)?
3. **เริ่มจากสิ่งเล็กน้อย** — แม้แต่คู่การแปลที่ผ่านการคัดสรร 50 คู่ก็เพียงพอที่จะสร้างชุดข้อมูลการประเมินและเปิด leaderboard track ใหม่ งาน corpus ได้[รับค่าตอบแทนตามอัตราที่เผยแพร่ไว้](/docs/network/perspectives/how-speakers-get-paid)
4. **รักษาไว้เป็นของคุณ** — ลงทะเบียน corpus เป็นข้อมูลเมตาในเลนที่คุณเลือก ([Registering Corpora](/docs/network/sovereignty/registering-corpora)); หากคุณต้องการให้ชุดทดสอบเป็นความลับอย่างสมบูรณ์ [คู่มือการแข่งขันแบบอธิปไตย](/docs/network/sovereignty/run-a-sovereign-contest)คือเส้นทางนั้น
5. **เชื่อมต่อเรากับการกำกับดูแล** — ใครในชุมชนของคุณมีอำนาจเหนือข้อมูลภาษาและเทคโนโลยี? โมเดลอธิปไตยของ Network ต้องการพันธมิตรด้านการกำกับดูแล

## ดูเพิ่มเติม

- [Run a Sovereign Contest](/docs/network/sovereignty/run-a-sovereign-contest) — คู่มือสำหรับการประเมินผลที่ควบคุมโดยชุมชน
- [Terms Templates](/docs/network/sovereignty/terms-templates) — เงื่อนไขที่เรียบง่ายทางกฎหมายและมุ่งสู่ความไม่ต้องไว้วางใจที่ชุมชนของคุณสามารถปรับใช้ได้ พร้อมระบุความเสี่ยงแบบ trojan-horse ไว้อย่างชัดเจน
- [Data Stewardship](/docs/network/sovereignty/data-sovereignty) — จุดยืน และกรอบการทำงาน (หลักการอธิปไตยทางข้อมูลของ First Nations, CARE, Te Mana Raraunga) ที่เป็นแรงบันดาลใจ
- [Ownership & Terms](/docs/network/sovereignty/ownership-transfer) — เงื่อนไขรายภาษาและสิ่งที่เกิดขึ้นเมื่อวิธีการชนะ
- [How the Work Is Funded](/docs/network/sovereignty/economic-model) — การเคลื่อนไหวของเงินในโครงการที่ไม่แสวงหากำไร
- [Support a Low-Resource Language](/docs/network/community/low-resource-languages) — บริบททางเทคนิคสำหรับนักวิจัยที่ทำงานร่วมกับชุมชน
