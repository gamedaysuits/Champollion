# สำหรับชุมชนภาษา

> **บทสรุปสำหรับผู้บริหาร** ชุมชนของคุณสามารถเป็นเจ้าของชุดข้อมูลทดสอบ (test set) ของตนเองได้ ซึ่งก็คือ "เฉลยคำตอบ" ที่ทุกวิธีการแปลจะถูกนำมาวัดผลเทียบเคียง และสามารถจัดการแข่งขันของตนเองตามเงื่อนไขที่กำหนดได้ โดยไม่จำเป็นต้องส่งมอบข้อมูลให้ใครเลย หน้านี้จะอธิบายถึงสิ่งที่ Network ร้องขอจากชุมชนภาษา (คำแปลอ้างอิง, การตรวจสอบการแปล, ข้อมูลสำหรับการฝึกสอน), สิ่งที่คุณจะได้รับกลับคืนมา (ค่าตอบแทนการทำงานตามอัตราที่ประกาศไว้เมื่อได้รับเงินทุนสนับสนุน — ปัจจุบันยังไม่มีเงินทุนสำรองไว้ — รวมถึงความเป็นเจ้าของโค้ดและการควบคุมการนำไปใช้งานได้อย่างสมบูรณ์) ตลอดจนการคุ้มครองอธิปไตยเหนือข้อมูลซึ่งมีความสำคัญสูงสุด ไม่จำเป็นต้องมีทักษะการเขียนโปรแกรม การคุ้มครองบางส่วนถูกสร้างขึ้นไว้ในตัวซอฟต์แวร์และฐานข้อมูลแล้ว ส่วนการคุ้มครองอื่นๆ ยังคงอยู่ในรูปแบบข้อผูกพัน ซึ่งคุณสามารถอ่านรายละเอียดได้ใน [ข้อจำกัดตามความเป็นจริง](/docs/network/honest-limitations)

คุณไม่จำเป็นต้องเป็นโปรแกรมเมอร์เพื่อมีส่วนร่วมกับ Network หากคุณพูดภาษาพื้นเมืองหรือภาษาที่มีทรัพยากรน้อย คุณคือบุคคลที่สำคัญที่สุดในระบบนิเวศนี้

## อธิปไตยมาเป็นอันดับแรก

ก่อนที่เราจะร้องขอสิ่งใดจากคุณ นี่คือกฎพื้นฐาน: **ข้อมูลภาษาของคุณเป็นของคุณ** ข้อมูลภาษานั้นถือเป็น *ข้อมูลชีวภาพ (biodata)* ซึ่งสื่อถึงอัตลักษณ์และความสัมพันธ์ของชุมชนของคุณ และไม่สามารถทำให้เป็นนิรนามได้อย่างแท้จริง ดังนั้น บุคคลที่เป็นผู้ให้ข้อมูลจึงเป็นผู้ถือสิทธิ์เด็ดขาดในข้อมูลนั้น รวมถึงสิ่งใดก็ตามที่นำมาวัดผลเทียบกับข้อมูลดังกล่าว Network สร้างขึ้นบน [หลักการอธิปไตยเหนือข้อมูลของชนพื้นเมือง (Indigenous data-sovereignty principles)](/docs/network/sovereignty/data-sovereignty):

- เราไม่เก็บรวบรวมหรือจัดเก็บข้อมูลภาษาของคุณบนเซิร์ฟเวอร์ของเรา
- วิธีการแปลใช้สถาปัตยกรรม `api` — ข้อมูลสำหรับการฝึกสอน พจนานุกรม และกฎไวยากรณ์ทั้งหมดอยู่บนโครงสร้างพื้นฐานที่คุณควบคุม
- คุณเป็นผู้ตัดสินใจว่าใครสามารถพัฒนาวิธีการสำหรับภาษาของคุณได้
- คะแนนบน Leaderboard พิสูจน์ว่าวิธีการนั้นใช้งานได้ แต่ไม่ได้ให้สิทธิ์ในการนำไปใช้งาน

:::note[สถานะในปัจจุบัน]
โมเดลการโอนความเป็นเจ้าของที่อธิบายไว้ด้านล่างนี้เป็น **การออกแบบที่มุ่งมั่นจะดำเนินการ ไม่ใช่โปรแกรมที่กำลังทำงานอยู่** ลีดเดอร์บอร์ดเปิดรับการส่งผลงานและยังไม่มีการรันที่เผยแพร่ในขณะนี้ และยังไม่มีวิธีการใดที่ถ่ายโอนไปยังชุมชนแล้ว เราอธิบายวิธีการที่สร้างขึ้นเพื่อให้ทำงานได้ เพื่อให้คุณสามารถตรวจสอบเราได้ — ไม่ใช่เพื่อบอกว่ามันกำลังดำเนินอยู่แล้ว ความสัมพันธ์และอำนาจของคุณเหนือข้อมูลของคุณมาก่อนเสมอ สิ่งอื่น ๆ ทั้งหมดตามมาจากนั้น
:::

## เป็นเจ้าของชุดทดสอบของคุณ

ตำแหน่งที่แข็งแกร่งที่สุดที่ชุมชนสามารถถือครองในระบบนี้คือ **การเป็นเจ้าของ benchmark นั้นเอง** ชุดทดสอบคือเฉลยคำตอบ: ผู้ที่ถือครองมันเป็นผู้ตัดสินว่า "การแปลที่ดี" หมายความว่าอะไรสำหรับภาษานั้น และทุกวิธีการ — ของเรา ของบริษัท ของใครก็ตาม — ถูกวัดผลเทียบกับ *มาตรฐานของคุณ*

- **การลงทะเบียนคือข้อมูลเมตา ไม่ใช่เนื้อหา** การลงทะเบียน corpus กับ Network หมายถึงการเผยแพร่การ์ดคำอธิบาย — ไม่ใช่การอัปโหลด corpus คุณเลือก[เลนการเปิดเผย](/docs/network/sovereignty/registering-corpora)ของมัน: เปิด, มีการควบคุม, หรืออธิปไตยเต็มรูปแบบ
- **Benchmark แบบอธิปไตยยังคงเป็นความลับ** ในเลนอธิปไตย ชุดทดสอบจะไม่ออกจากโครงสร้างพื้นฐานของชุมชน และเราจะไม่มีวันเห็นมัน วิธีการถูกให้คะแนนเทียบกับมันในฝั่งของคุณ มีเพียงคะแนนเท่านั้นที่ส่งผ่านมา
- **คุณสามารถจัดการแข่งขันของคุณเองได้** คู่มือทีละขั้นตอน — [Run a Sovereign Contest](/docs/network/sovereignty/run-a-sovereign-contest) — อธิบายการจัดการประเมินผลที่ควบคุมโดยชุมชนตามเงื่อนไขของคุณเอง: ชุดทดสอบของคุณ กฎของคุณ การตัดสินใจของคุณว่าจะเผยแพร่อะไร (ถ้ามี)

การรับประกันเบื้องหลังทั้งหมดนี้มีระบุไว้เป็นลายลักษณ์อักษร ไม่ได้เกิดขึ้นโดยนัย:
[การดูแลข้อมูล (Data Stewardship)](/docs/network/sovereignty/data-sovereignty) (จุดยืนด้านอธิปไตยเหนือข้อมูล/หลักการ CARE และสิ่งที่เราถูกห้ามไม่ให้ทำ) และ
[ความเป็นเจ้าของและข้อกำหนด (Ownership & Terms)](/docs/network/sovereignty/ownership-transfer) (สิ่งที่จะเกิดขึ้นในทางสัญญาเมื่อวิธีการใดวิธีการหนึ่งชนะการประเมิน)

## สิ่งที่เราต้องการจากคุณ

### การแปลอ้างอิง

เราต้องการคู่การแปลที่ผ่านการคัดสรรสำหรับการประเมินผล — ภาษาอังกฤษด้านหนึ่ง ภาษาของคุณอีกด้านหนึ่ง สิ่งเหล่านี้จะกลายเป็น "เฉลยคำตอบ" ที่ใช้ให้คะแนนวิธีการแปลทั้งหมด

คุณอาจสร้างสิ่งเหล่านี้จาก:
- **สื่อการศึกษา** — แบบฝึกหัดในตำรา แผนการสอน ใบงาน
- **เอกสารชุมชน** — รายงานการประชุม จดหมายข่าว ประกาศ
- **วลีในชีวิตประจำวัน** — สตริง UI ป้ายกำกับแอป สำนวนทั่วไป
- **เนื้อหาทางวัฒนธรรม** — เรื่องราว เพลง หรือคำอธิบาย (พร้อมการอนุญาตที่เหมาะสม)

รูปแบบเป็น JSON ที่เรียบง่าย:
```json
{
  "entries": [
    { "id": 1, "source": "Hello", "reference": "tânisi" },
    { "id": 2, "source": "Thank you", "reference": "kinanâskomitin" }
  ]
}
```

### การตรวจสอบการแปล

ทุกวิธีการที่อ้างว่าสามารถสร้างการแปลที่ใช้งานได้ต้องผ่านการตรวจสอบโดยมนุษย์ ผู้พูดสองภาษาตรวจสอบผลลัพธ์และบอกเราว่าคอมพิวเตอร์แปลถูกต้องหรือไม่ — และที่สำคัญกว่านั้น *ทำไม* มันถึงแปลผิด

### ข้อมูลสำหรับการฝึกสอน

กฎไวยากรณ์ รายการพจนานุกรม รูปแบบทางสัณฐานวิทยา — สิ่งเหล่านี้คือทรัพยากรทางภาษาที่ทำให้วิธีการแปลทำงานได้ ความรู้ของคุณเกี่ยวกับวิธีที่ภาษาของคุณทำงานนั้นไม่มีโมเดล AI ใดสามารถทดแทนได้

## สิ่งที่คุณได้รับกลับ

### ความเป็นเจ้าของ

เมื่อวิธีการแปลถูกสร้างขึ้นสำหรับภาษาของคุณและได้รับการตรวจสอบบน Network แล้ว [ความเป็นเจ้าของจะโอน](/docs/network/sovereignty/ownership-transfer)ไปยังองค์กรกำกับดูแลของชุมชนคุณ คุณเป็นเจ้าของโค้ด น้ำหนักโมเดล และการใช้งาน

### งานที่ได้รับค่าตอบแทน ไม่ใช่การดึงเอาทรัพยากรไป

การสร้างคลังข้อมูลภาษา (corpus) และการตรวจสอบการแปลถือเป็นการทำงานระดับมืออาชีพ ซึ่งจะได้รับค่าตอบแทนตาม
[อัตราที่ประกาศไว้](/docs/network/perspectives/how-speakers-get-paid) เมื่อมีเงินทุนสนับสนุน
(ปัจจุบันยังไม่มีเงินทุนสำรองไว้) — และการจ่ายค่าตอบแทนไม่ได้หมายถึงการซื้อข้อมูลของคุณ คุณได้รับค่าจ้างสำหรับการทำงาน *และ* ยังคงเป็นเจ้าของสิ่งที่คุณสร้างขึ้น Champollion เป็นโครงการวิจัยที่ไม่แสวงหาผลกำไร: เราไม่ขายสิ่งใด ไม่คิดค่าบริการตามปริมาณการใช้งาน และ [ไม่หักส่วนแบ่งใดๆ](/docs/network/sovereignty/economic-model) จากสิ่งที่ชุมชนของคุณจะได้รับจากวิธีการแปลที่ชุมชนเป็นเจ้าของ

### การควบคุม

องค์กรกำกับดูแลของคุณควบคุม:
- ใครสามารถเข้าถึงวิธีการได้
- ว่าจะสามารถนำไปใช้เชิงพาณิชย์ได้หรือไม่ — และถ้าใช่ ตามเงื่อนไขของคุณ โดยเก็บรายได้ทั้งหมดไว้
- เมื่อใดและอย่างไรที่จะอัปเดต
- ข้อมูลใดที่ใช้สำหรับการพัฒนาต่อไป

## วิธีการมีส่วนร่วม

:::tip[สิ่งที่ผู้พูดภาษาสามารถทำได้ในวันนี้ — หากชุมชนเห็นพ้องต้องกัน]
Champollion ไม่ได้สร้างหรือจัดเก็บคลังข้อมูลภาษาด้วยตนเอง — ข้อมูลทดสอบจะถูกดึงมาจากแหล่งต้นทางเสมอ หากผู้พูดภาษาในชุมชนของคุณต้องการมีส่วนร่วมในการส่งประโยค *ในตอนนี้* [Tatoeba](https://tatoeba.org) เปิดรับการส่งประโยคทีละประโยคในทุกภาษา และแหล่งรวมข้อมูลแบบเปิดอย่าง [OPUS](https://opus.nlpl.eu/) ก็รวบรวมข้อความคู่ขนาน (parallel text) ที่ Network นำมาใช้สร้างชุดข้อมูลมาตรฐานเปรียบเทียบ (benchmark) ประโยคที่เพิ่มเข้าไปที่นั่นสามารถนำมาใช้เป็นข้อมูลการประเมินผลที่นี่ได้

ควรทำความเข้าใจข้อตกลงล่วงหน้า: Tatoeba เผยแพร่ประโยคภายใต้สัญญาอนุญาตแบบเปิด (ค่าเริ่มต้นคือ CC BY 2.0 FR) ดังนั้นทุกคนจึงสามารถคัดลอกได้ — รวมถึงนำไปใช้ฝึกฝนโมเดล AI — และประโยคที่ถูกคัดลอกไปแล้วจะไม่สามารถเรียกคืนได้ นี่อาจเป็นตัวเลือกที่เหมาะสมสำหรับประโยคที่ใช้ในชีวิตประจำวัน แต่สำหรับสิ่งใดก็ตามที่ชุมชนของคุณต้องการเก็บไว้ภายใต้การควบคุมของตนเอง ขอแนะนำให้เก็บข้อมูลไว้กับตัวคุณเองและใช้ [ชุดข้อมูลทดสอบแบบปิดผนึก (sealed test set)](/docs/network/sovereignty/run-a-sovereign-contest) แทน ทั้งนี้ แอปพลิเคชันสำหรับการร่วมส่งข้อมูลจากผู้พูดภาษาโดยตรงและเครื่องมือสร้างคลังข้อมูลภาษากำลังอยู่ในแผนงาน แต่ยังไม่ได้พัฒนาขึ้นในขณะนี้
:::

1. **ติดต่อเรา** — เปิดประเด็น (issue) บน [คลังเก็บโค้ดของ Network](https://github.com/gamedaysuits/Champollion) หรือส่งอีเมลมาที่ [info@champollion.dev](mailto:info@champollion.dev)
2. **อธิบายเกี่ยวกับภาษาของคุณ** — จัดอยู่ในตระกูลภาษาใด? มีผู้พูดภาษานี้จำนวนเท่าใด? ใช้ระบบการเขียนแบบใด? มีทรัพยากรด้านการประมวลผลทางคอมพิวเตอร์อะไรอยู่แล้วบ้าง (เช่น FST, พจนานุกรม, คลังข้อมูลภาษา)?
3. **เริ่มต้นจากจุดเล็กๆ** — แม้เพียงคู่ประโยคแปลที่ผ่านการคัดสรร 50 คู่ ก็เพียงพอที่จะสร้างชุดข้อมูลการประเมินผลและเปิดหมวดหมู่ใหม่บนกระดานผู้นำ (leaderboard) ได้ งานสร้างคลังข้อมูลภาษาจะได้รับ [ค่าตอบแทนตามอัตราที่ประกาศไว้](/docs/network/perspectives/how-speakers-get-paid) เมื่อมีเงินทุนสนับสนุน ปัจจุบันยังไม่มีเงินทุนสำรองไว้
4. **รักษาความเป็นเจ้าของไว้** — ลงทะเบียนคลังข้อมูลภาษาเป็นข้อมูลอภิพันธุ์ (metadata) ในช่องทางที่คุณเลือก ([การลงทะเบียนคลังข้อมูลภาษา](/docs/network/sovereignty/registering-corpora)) หากคุณต้องการให้ชุดข้อมูลทดสอบเป็นความลับอย่างสมบูรณ์ แนวทางที่เหมาะสมคือ [คู่มือขั้นตอนการแข่งขันแบบมีอธิปไตย (sovereign contest runbook)](/docs/network/sovereignty/run-a-sovereign-contest)
5. **เชื่อมโยงเรากับฝ่ายกำกับดูแล** — ใครในชุมชนของคุณที่มีอำนาจตัดสินใจเกี่ยวกับข้อมูลและเทคโนโลยีทางภาษา? รูปแบบการคุ้มครองอธิปไตยของ Network จำเป็นต้องมีพันธมิตรด้านการกำกับดูแล

## ดูเพิ่มเติม

- [จัดการแข่งขันแบบมีอธิปไตย](/docs/network/sovereignty/run-a-sovereign-contest) — คู่มือขั้นตอนสำหรับการประเมินผลภายใต้การควบคุมของชุมชน
- [เทมเพลตข้อกำหนด](/docs/network/sovereignty/terms-templates) — ข้อกำหนดที่ไม่ซับซ้อนในทางกฎหมายและมุ่งเน้นการลดการพึ่งพาความไว้วางใจ (trustless) ซึ่งชุมชนของคุณสามารถนำไปปรับใช้ได้ โดยมีการระบุความเสี่ยงประเภทม้าโทรจันไว้อย่างชัดเจน
- [การดูแลข้อมูล](/docs/network/sovereignty/data-sovereignty) — จุดยืนและกรอบการทำงาน (CARE, Te Mana Raraunga และตราสารด้านอธิปไตยเหนือข้อมูลของชนพื้นเมืองอื่นๆ) ที่ร่วมกำหนดแนวทางนี้
- [ความเป็นเจ้าของและข้อกำหนด](/docs/network/sovereignty/ownership-transfer) — ข้อกำหนดเฉพาะสำหรับแต่ละภาษา และสิ่งที่จะเกิดขึ้นเมื่อวิธีการใดวิธีการหนึ่งชนะการประเมิน
- [การจัดหาเงินทุนสำหรับการทำงาน](/docs/network/sovereignty/economic-model) — เส้นทางการไหลเวียนของเงินในโครงการที่ไม่แสวงหาผลกำไร
- [สนับสนุนภาษาที่มีทรัพยากรน้อย](/docs/network/community/low-resource-languages) — บริบททางเทคนิคสำหรับนักวิจัยที่ทำงานร่วมกับชุมชน
