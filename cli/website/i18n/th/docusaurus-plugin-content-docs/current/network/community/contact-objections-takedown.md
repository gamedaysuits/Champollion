# การติดต่อ ข้อโต้แย้ง และการขอลบเนื้อหา

> **บทสรุปผู้บริหาร** โปรเจกต์นี้ยังไม่เสร็จสมบูรณ์โดยความตั้งใจ และจะเป็นผลงานที่อยู่ระหว่างการพัฒนาตลอดไป หากมีสิ่งใดในที่นี้ไม่ถูกต้อง เป็นการตักตวงผลประโยชน์ ไม่เคารพสิทธิของชุมชน หรือเพียงแค่อธิบายได้ไม่ดีพอ — เราต้องการรับฟัง และเราจะดำเนินการแก้ไข หน้านี้คือช่องทางในการติดต่อเรา สิ่งที่เราให้คำมั่นสัญญา และวิธีการขอให้แก้ไขหรือลบเนื้อหา ข้อโต้แย้งที่ดีจะช่วยให้โปรเจกต์นี้ดีขึ้น เรายินดีต้อนรับข้อโต้แย้งเหล่านั้น ไม่ใช่แค่ยอมทนรับฟัง

## สำหรับใคร

- **ชุมชนเจ้าของภาษาและตัวแทน** ที่เห็นภาษา ข้อมูล หรือการกำกับดูแลของตนถูกอธิบายไว้ในที่นี้ และต้องการให้มีการแก้ไข ลบออก หรือพูดคุยหารือ
- **นักวิจัย นักแปล และผู้ดูแลชุดข้อมูล** ที่ผลงานถูกอ้างอิง และต้องการให้แก้ไขการให้เครดิตหรือเปลี่ยนแปลงรายการ
- **ทุกคน** ที่พบข้อผิดพลาด การกล่าวอ้างเกินจริง หรือข้อความที่อ่านแล้วรู้สึกถึงความไม่เคารพ

คุณไม่จำเป็นต้องมีบัญชีผู้ใช้ และไม่จำเป็นต้องมีความรู้ทางเทคนิค การใช้ภาษาธรรมดาในแบบของคุณเองนั้นเหมาะสมที่สุดแล้ว

## สิ่งที่เราเป็น (และผลที่มีต่อการแก้ไข)

Champollion เป็น **ดัชนี ไม่ใช่ผู้มีอำนาจตัดสิน** ข้อเท็จจริงทุกประการบนการ์ดภาษาหรือใน Network จะอ้างอิงแหล่งที่มาและรายงานสิ่งที่แหล่งที่มานั้นกล่าวไว้จริงๆ ในกรณีที่แหล่งที่มามีข้อมูลขัดแย้งกัน เราจะแสดงข้อมูลทั้งหมดแทนที่จะเลือกข้อมูลใดข้อมูลหนึ่ง การออกแบบดังกล่าวส่งผลโดยตรงต่อคุณ: **หากแหล่งที่มาที่อ้างอิงไม่ถูกต้อง หรือเรานำเสนอได้ไม่ดี นั่นคือข้อบกพร่องที่แก้ไขได้และเราจะจัดการแก้ไขมัน** เราไม่ได้กำลังปกป้องข้อกล่าวอ้างของเราเอง — เราพยายามชี้ให้เห็นถึงผลงานของผู้อื่นและตัวภาษาเองอย่างถูกต้องแม่นยำ

จุดยืนด้านอธิปไตยของเราคือการ**มุ่งสู่อธิปไตย**: โครงสร้างได้รับการออกแบบเพื่อให้
ชุมชน*สามารถ*ใช้สิทธิ์ในการเป็นเจ้าของ การควบคุม การเข้าถึง และการครอบครองข้อมูลของตน
รวมถึงสิ่งใดก็ตามที่ต่อยอดมาจากข้อมูลนั้น การที่จะ*บรรลุเป้าหมายดังกล่าวได้หรือไม่*นั้นขึ้นอยู่กับชุมชน
จะเป็นผู้ตัดสิน — ซึ่งนี่คือเหตุผลอย่างแท้จริงว่าทำไมช่องทางนี้จึงมีอยู่

## วิธีติดต่อเรา

| คุณต้องการ… | ใช้ | ส่งไปที่ |
|---|---|---|
| ถามคำถาม เสนอข้อโต้แย้ง หรือขอให้แก้ไข | **แบบฟอร์มทิกเก็ตของคู่มือเว็บไซต์** (แผงแชท → "Send a message") หรืออีเมล | `info@champollion.dev` |
| ขอให้ **ลบ** ข้อมูล การอ้างอิง หรือรายการ | แบบฟอร์มทิกเก็ต (เลือก **Takedown**) หรืออีเมลโดยระบุ "Takedown" ในหัวข้อ | `info@champollion.dev` |
| รายงาน **ช่องโหว่ด้านความปลอดภัย** | อีเมล | `security@champollion.dev` |

แบบฟอร์มทิกเก็ตและที่อยู่อีเมลจะส่งไปยังที่เดียวกัน แบบฟอร์มเพียงแค่บันทึกข้อความของคุณไว้อย่างถาวรเพื่อไม่ให้มีสิ่งใดสูญหายระหว่างทาง คุณสามารถทิ้งที่อยู่อีเมลสำหรับตอบกลับไว้ได้หากต้องการคำตอบ หรือจะปกปิดตัวตนก็ได้หากคุณไม่ต้องการเปิดเผย

## สิ่งที่เราให้คำมั่นสัญญา

1. **เราตอบรับ** หากคุณระบุช่องทางติดต่อกลับ เรามุ่งมั่นที่จะยืนยันว่าเราได้รับ
   ข้อความของคุณอย่างรวดเร็ว ด้วยภาษาที่เข้าใจง่าย และปราศจากการบ่ายเบี่ยงทางกฎหมาย
2. **คำขอให้ลบเนื้อหาจะได้รับความสำคัญเป็นอันดับแรก และแนวทางตั้งต้นคือการดำเนินการ** สำหรับสิ่งใดก็ตาม
   ที่เราโฮสต์หรือจัดทำดัชนีไว้ ซึ่งผู้ถือสิทธิ์หรือชุมชนร้องขอให้เราลบ ท่าที
   เริ่มต้นของเราคือการลบออก ไม่ใช่การโต้แย้ง ตั้งแต่แรกเริ่ม เรา**ไม่ได้โฮสต์เนื้อหาคลังข้อมูล**
   แต่อย่างใด — คลังข้อมูลจะถูกดึงมาจากต้นทางพร้อมการ์ดข้อมูลเมทาดาทาเท่านั้น
   — ดังนั้น "การขอลบเนื้อหา" ส่วนใหญ่จึงเป็นเพียงการอ้างอิง รายการ หรือฟิลด์ในการ์ด และสิ่งเหล่านี้
   เราสามารถแก้ไขหรือนำออกได้อย่างรวดเร็ว
3. **Champollion ไม่มีพันธมิตร และเราจะไม่ระบุชื่อชุมชน ชนชาติ หรือ
   องค์กรใด ๆ ในฐานะพันธมิตรหรือผู้ดูแลโดยไม่ได้รับความยินยอมเป็นอันขาด** หากคุณพบว่ามีการระบุชื่อดังกล่าวเชื่อมโยงกับ
   ชุมชนของคุณโดยไม่ได้รับความยินยอม โปรดแจ้งให้เราทราบแล้วเราจะนำออกให้
4. **เราบันทึกข้อคัดค้านอย่างตรงไปตรงมา** คำวิจารณ์สามารถเผยแพร่ได้เช่นเดียวกับคำชมเชย หน้า
   ข้อจำกัดอย่างตรงไปตรงมาของเรามีขึ้นเพื่อให้มองเห็นปัญหาที่ยังค้างคาอยู่ได้อย่างชัดเจน
   ไม่ใช่การฝังกลบไว้
5. **เราจะไม่แสร้งทำเป็นว่าข้อขัดแย้งได้รับการคลี่คลายแล้ว** หากเราไม่สามารถทำตามสิ่งที่คุณร้องขอได้
   เราจะแจ้งให้ทราบ ชี้แจงเหตุผล และบอกว่าใครเป็นผู้ตัดสินใจ — แทนที่จะเพิกเฉยไปเงียบ ๆ

## สิ่งที่ช่วยให้เราดำเนินการได้เร็วขึ้น

คุณไม่จำเป็นต้องมีสิ่งเหล่านี้ แต่จะช่วยให้ดำเนินการได้เร็วขึ้น:

- ลิงก์ไปยังหน้า การ์ด หรือค่าที่เฉพาะเจาะจง
- สิ่งที่ผิดพลาดในคำพูดของคุณ และสิ่งที่ถูกต้องควรเป็นอย่างไร
- คุณกำลังพูดในนามของตนเองหรือในนามของชุมชนหรือองค์กร (และสำหรับการขอลบเนื้อหา ความสัมพันธ์ใดๆ กับผู้ถือสิทธิ์ — เราไม่ต้องการหลักฐาน แต่จะช่วยให้เราจัดลำดับความสำคัญได้)

## สิ่งที่ช่องทางนี้ *ไม่ใช่*

- **ไม่ใช่** พื้นที่สำหรับขอความช่วยเหลือด้านการพัฒนา สคริปต์แบบกำหนดเอง หรือการแปลตามความต้องการ — โปรเจกต์สามารถแนะนำเครื่องมือให้คุณได้ แต่จะไม่ทำงานด้านวิศวกรรมให้กับผู้เยี่ยมชมที่นี่
- **ไม่ใช่** วิธีการทำให้ภาษาได้รับการจัดอันดับ โปรโมต หรือนำเสนอ — การจัดอันดับของ Network มาจากการรันการประเมินผลเท่านั้น ไม่เคยมาจากการร้องขอ

เราอยากรับฟังข้อโต้แย้งตั้งแต่เนิ่นๆ มากกว่าที่จะปล่อยให้มันเป็นเรื่องจริงแต่ไม่มีใครพูดถึง ขอบคุณที่ช่วยให้โปรเจกต์นี้มีความซื่อตรง
