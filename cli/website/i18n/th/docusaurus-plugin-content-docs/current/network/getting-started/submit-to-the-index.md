# ส่งข้อมูลเข้าสู่ดัชนี

> **สรุปสำหรับผู้บริหาร** เสนอสิ่งที่ต้องการเพิ่มในดัชนี Champollion ไม่ว่าจะเป็น benchmark ทรัพยากร วิธีการแปล บริการแปลโดยมนุษย์ หรือผลลัพธ์ที่เผยแพร่จากภายนอก คุณกรอกแบบฟอร์มโครงสร้างสั้น ๆ (ผ่านเบราว์เซอร์หรือ CLI) จากนั้น **ผู้ดูแลระบบจะตรวจสอบทุกการส่งด้วยตนเอง** เพื่อตรวจสอบด้านทรัพย์สินทางปัญญา ใบอนุญาต และการปฏิบัติตามข้อกำหนดของชุมชน/อธิปไตยทางภาษา ก่อนที่จะเพิ่มข้อมูลใด ๆ **ไม่มีการอนุมัติอัตโนมัติ**

ดัชนีคือแผนที่ร่วมกัน ประกอบด้วย: ชุดข้อมูลที่ใช้ benchmark วิธีการต่าง ๆ พจนานุกรมและเครื่องมือที่ช่วยสนับสนุน วิธีการแปลเอง ผู้แปลที่ทำงานด้วยมือ และผลลัพธ์ที่ผู้อื่นเผยแพร่ไว้ ทุกคนสามารถเสนอการเพิ่มข้อมูลได้ เนื่องจากนี่คือโครงสร้างพื้นฐานสำหรับชุมชนภาษา ทุกข้อเสนอจึงต้องผ่านการตรวจสอบโดยมนุษย์ก่อนเสมอ

---

## สิ่งที่คุณสามารถส่งได้

| ประเภท | คำอธิบาย | สิ่งที่เราเพิ่ม |
|---|---|---|
| **เบนช์มาร์ก / ชุดข้อมูล** | คลังข้อมูลสำหรับการประเมินผลหรือเกณฑ์มาตรฐาน (เบนช์มาร์ก) | การ์ดข้อมูลกำกับ (metadata card) + พอยน์เตอร์ระบุแหล่งดึงข้อมูล (*fetch-from-source*) — ไม่เก็บเนื้อหาของคลังข้อมูลโดยเด็ดขาด |
| **ทรัพยากร** | พจนานุกรม แหล่งจัดเก็บเอกสาร แอป FST (เครื่องมือวิเคราะห์ทางสัณฐานวิทยา) หรือเครื่องมืออื่นๆ | รายการข้อมูลพร้อมพอยน์เตอร์ + ระดับการเข้าถึง (เปิดเผย / จำกัดสิทธิ์ / ต้องได้รับความยินยอม) |
| **วิธีการแปล** | เอนจิน MT, ผู้ให้บริการ LLM หรือไปป์ไลน์ | รายการในรีจิสทรีระเบียบวิธี (method-registry) เพื่อให้สามารถรันและวัดเกณฑ์มาตรฐานได้ |
| **บริการแปลโดยมนุษย์** | สำนักงานชุมชน เอเจนซี หรือนักแปลรายบุคคลที่เข้าร่วมด้วยความสมัครใจ | รายการแยกตามคู่ภาษา (ข้อมูลติดต่อจะเก็บไว้ภายนอกช่องทางสาธารณะ — ไม่ปรากฏใน issue สาธารณะโดยเด็ดขาด) |
| **ผลลัพธ์ที่เผยแพร่ภายนอก** | คะแนนที่รายงานโดยระบบอื่นหรือรายงานทางวิชาการ | **การอ้างอิง** — ผลลัพธ์ภายนอกจะใช้วิธีอ้างอิงเท่านั้น โดยจะไม่นำมาโฮสต์ซ้ำหรือจัดอันดับใหม่เสมือนเป็นการวัดผลของเราเอง |
| **การแก้ไขข้อมูลการ์ดภาษา** | ข้อมูลบางอย่างใน[การ์ดภาษา](/catalogue) ไม่ถูกต้อง ล้าสมัย หรือขาดหายไป — เช่น จำนวนผู้พูดโดยประมาณ สถานะ ตัวเขียน หรือทรัพยากรที่เรายังไม่ได้ระบุ | **การแก้ไขพร้อมระบุแหล่งอ้างอิงที่ต้นทางข้อมูล** (เนื่องจากการ์ดถูกสร้างขึ้นโดยอัตโนมัติ การแก้ไขนี้จึงมีผลถาวร) ในกรณีที่แหล่งข้อมูลไม่ตรงกัน การ์ดจะแสดงข้อมูลจากทุกแหล่งพร้อมระบุที่มา |

การ์ดภาษาทุกใบจะมีลิงก์ **"Suggest a correction or addition"**
ซึ่งจะเปิดแบบฟอร์มการแก้ไขโดยกรอกข้อมูลภาษาไว้ล่วงหน้าให้เรียบร้อย

**คำขอจำกัดสิทธิ์หรือลบข้อมูลจากชุมชน** หากคุณเป็นสมาชิกชุมชน
หรือผู้มีอำนาจหน้าที่ในชุมชน และต้องการให้จำกัดการเข้าถึงหรือลบข้อมูลเกี่ยวกับภาษาของคุณ
โปรดใช้แบบฟอร์มการแก้ไข (หรือติดต่อผู้ดูแลระบบนอกช่องทางสาธารณะ หากไม่ต้องการให้เป็นข้อมูลสาธารณะ)
คำขอเหล่านี้จะได้รับการดำเนินการผ่าน[การตรวจสอบอธิปไตยเหนือข้อมูล](/docs/network/sovereignty/data-sovereignty)
เป็นลำดับความสำคัญสูงสุด — โดยไม่ต้องใช้การอ้างอิงใดๆ

## กระบวนการตรวจสอบ

นี่คือส่วนสำคัญ: **การส่งข้อมูลจะถูกตรวจสอบโดยมนุษย์ ไม่ใช่ระบบอัตโนมัติ** เมื่อคุณส่งข้อมูล คุณจะเปิด GitHub issue ซึ่ง issue นั้นคือคิวการตรวจสอบ ผู้ดูแลระบบจะอ่านและตรวจสอบตามกฎของโครงการก่อนที่จะเพิ่มข้อมูลใด ๆ:

- **ทรัพย์สินทางปัญญาและสัญญาอนุญาต** เราต้องได้รับอนุญาตให้ระบุข้อมูลดังกล่าวได้ ข้อมูลที่ไม่อนุญาตให้ใช้ในเชิงพาณิชย์ ห้ามแจกจ่ายต่อ หรือมีสัญญาอนุญาตที่ไม่ชัดเจน ยังคงสามารถนำมา*จัดทำแค็ตตาล็อก*ได้ แต่จะถูกแยกออกไม่ให้เข้าถึงผ่านช่องทางเชิงพาณิชย์ / การแข่งขัน / การดึงข้อมูลสาธารณะ
- **ชุมชนและอธิปไตยเหนือข้อมูล** ข้อมูลภาษาของชนพื้นเมืองและภาษาชุมชนจะถูกระบุไว้ก็ต่อเมื่อได้รับความยินยอมจากชุมชนเท่านั้น เราจะไม่ระบุชื่อผู้ให้บริการหรือผู้ดูแลสู่สาธารณะก่อนที่ได้รับการยืนยันจากพวกเขา
- **เราไม่โฮสต์เนื้อหาของคลังข้อมูลโดยเด็ดขาด** ชุดข้อมูลจะแสดงในรูปแบบข้อมูลกำกับ (metadata) พร้อมพอยน์เตอร์ไปยังแหล่งดึงข้อมูล **ห้ามวางประโยคต้นฉบับหรือประโยคอ้างอิงลงในการส่งข้อมูล**
- **ห้ามใส่ข้อมูลส่วนบุคคล** ห้ามระบุอีเมล หมายเลขโทรศัพท์ หรือข้อมูลระบุตัวตน (PII) อื่นๆ ใน issue สาธารณะ สำหรับบริการแปลโดยมนุษย์ ให้ส่งข้อมูลติดต่อแก่ผู้ดูแลระบบนอกช่องทางสาธารณะ (out-of-band)
- **ขอบเขต** คลังข้อมูลคัมภีร์ไบเบิล / พิธีกรรมทางศาสนา และคลังข้อมูลอื่นๆ ที่เกิดจากการครอบงำในยุคล่าอาณานิคมถือว่าอยู่นอกขอบเขตและจะไม่ได้รับการพิจารณา

ทุกแบบฟอร์มจะสิ้นสุดด้วยการรับรองที่บังคับ:

> *"ข้าพเจ้าขอยืนยันว่าข้อมูลนี้สามารถแสดงรายการสาธารณะได้ ไม่มีเนื้อหาของคลังข้อมูลหรือข้อมูลส่วนบุคคล และเคารพใบอนุญาตของแหล่งที่มาและข้อจำกัดด้านชุมชน/อธิปไตยทางภาษา"*

## สองวิธีในการส่งข้อมูล

### ผ่านเบราว์เซอร์

เปิดตัวเลือก issue และเลือกแบบฟอร์มที่ตรงกับสิ่งที่คุณต้องการส่ง:

➡️ **[เปิดแบบฟอร์มการส่งข้อมูลบน GitHub](https://github.com/gamedaysuits/Champollion/issues/new/choose)**

แต่ละแบบฟอร์มจะถามเฉพาะข้อมูลที่ดัชนีนั้น ๆ ต้องการ (ชื่อ ภาษา/คู่ภาษา ใบอนุญาต URL ต้นทาง และอื่น ๆ) พร้อมช่องทำเครื่องหมายการรับรอง

### ผ่าน CLI

หากคุณมี [champollion CLI](/docs/network/getting-started/submit-a-method) `champollion submit` จะรวบรวมข้อมูลและสร้าง URL ของแบบฟอร์ม GitHub เดียวกันแบบ **กรอกข้อมูลล่วงหน้า** ให้คุณ:

```bash
# Interactive — pick a type and answer the prompts
champollion submit

# See the submission types
champollion submit --list

# Fully scripted (prints a pre-filled GitHub issue URL)
champollion submit --yes --type dataset --attest \
  --field dataset-name="GlobalVoices eng-amh" \
  --field pairs=eng-amh \
  --field license=CC-BY-4.0 \
  --field source-url=https://globalvoices.org
```

CLI จะแสดง URL — เปิดลิงก์นั้น ตรวจสอบการรับรองในเบราว์เซอร์ และส่งข้อมูล เพิ่ม `--out submission.json` เพื่อบันทึกสำเนาในเครื่องที่ไม่มีเนื้อหาของสิ่งที่คุณกำลังเสนอด้วย CLI ไม่อัปโหลดข้อมูลใด ๆ เองและไม่เขียนลงในดัชนี

## สิ่งที่เกิดขึ้นหลังจากคุณส่งข้อมูล

1. การส่งข้อมูลของคุณจะปรากฏเป็น GitHub issue — คิวการตรวจสอบ
2. ผู้ดูแลระบบจะตรวจสอบตามกฎด้านทรัพย์สินทางปัญญา / ใบอนุญาต / อธิปไตยทางภาษาข้างต้น
3. **หากได้รับการยอมรับ:** ผู้ดูแลระบบจะเพิ่มรายการลงในแหล่งข้อมูลที่เกี่ยวข้อง (ทะเบียนชุดข้อมูล การ์ดข้อมูล ทะเบียนวิธีการหรือบริการแปลโดยมนุษย์ หรือรายการผลลัพธ์ภายนอก) ผ่านกระบวนการปกติ และติดป้ายกำกับ issue ว่า **accepted**
4. **หากไม่สามารถแสดงรายการได้ตามที่ส่งมา:** ผู้ดูแลระบบจะติดป้ายกำกับว่า **declined** (หรือขอข้อมูลเพิ่มเติม) พร้อมระบุเหตุผล

ไม่มีการ merge อัตโนมัติและไม่มีการเผยแพร่อัตโนมัติ มนุษย์เป็นผู้ตัดสินใจทุกครั้ง
