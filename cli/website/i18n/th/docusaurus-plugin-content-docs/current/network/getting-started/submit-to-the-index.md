# ส่งข้อมูลเข้าสู่ดัชนี

> **สรุปสำหรับผู้บริหาร** เสนอสิ่งที่ต้องการเพิ่มในดัชนี Champollion ไม่ว่าจะเป็น benchmark ทรัพยากร วิธีการแปล บริการแปลโดยมนุษย์ หรือผลลัพธ์ที่เผยแพร่จากภายนอก คุณกรอกแบบฟอร์มโครงสร้างสั้น ๆ (ผ่านเบราว์เซอร์หรือ CLI) จากนั้น **ผู้ดูแลระบบจะตรวจสอบทุกการส่งด้วยตนเอง** เพื่อตรวจสอบด้านทรัพย์สินทางปัญญา ใบอนุญาต และการปฏิบัติตามข้อกำหนดของชุมชน/อธิปไตยทางภาษา ก่อนที่จะเพิ่มข้อมูลใด ๆ **ไม่มีการอนุมัติอัตโนมัติ**

ดัชนีคือแผนที่ร่วมกัน ประกอบด้วย: ชุดข้อมูลที่ใช้ benchmark วิธีการต่าง ๆ พจนานุกรมและเครื่องมือที่ช่วยสนับสนุน วิธีการแปลเอง ผู้แปลที่ทำงานด้วยมือ และผลลัพธ์ที่ผู้อื่นเผยแพร่ไว้ ทุกคนสามารถเสนอการเพิ่มข้อมูลได้ เนื่องจากนี่คือโครงสร้างพื้นฐานสำหรับชุมชนภาษา ทุกข้อเสนอจึงต้องผ่านการตรวจสอบโดยมนุษย์ก่อนเสมอ

## สิ่งที่คุณสามารถส่งได้

| ประเภท | สิ่งนี้คืออะไร | สิ่งที่เราเพิ่ม |
|---|---|---|
| **Benchmark / dataset** | คลังข้อมูลสำหรับการประเมินหรือเกณฑ์มาตรฐาน | การ์ดข้อมูลเมตา (metadata) + ตัวชี้แบบ *fetch-from-source* — จะไม่มีการเพิ่มเนื้อหาของคลังข้อมูลโดยเด็ดขาด |
| **Resource** | พจนานุกรม, คลังข้อมูลจัดเก็บ, แอปพลิเคชัน, FST (เครื่องมือวิเคราะห์หน่วยคำ) หรือเครื่องมือ | รายการพร้อมตัวชี้ + ระดับการเข้าถึง (เปิดกว้าง / จำกัด / ต้องได้รับความยินยอม) |
| **Translation method** | เอนจิน MT, ผู้ให้บริการ LLM หรือไปป์ไลน์ | รายการใน method-registry เพื่อให้สามารถรันและวัดผลเกณฑ์มาตรฐานได้ |
| **Human translation service** | สำนักงานชุมชนที่เข้าร่วม (opt-in), เอเจนซี่ หรือนักแปลอิสระ | รายการตามคู่ภาษา (รายละเอียดการติดต่อจะอยู่นอกระบบ — จะไม่เปิดเผยใน issue สาธารณะโดยเด็ดขาด) |
| **External published result** | คะแนนที่รายงานโดยระบบอื่นหรืองานวิจัย | **การอ้างอิง** — ผลลัพธ์จากภายนอกจะถูกอ้างอิง จะไม่มีการโฮสต์ซ้ำหรือจัดอันดับใหม่เสมือนเป็นการวัดผลของเราเองโดยเด็ดขาด |
| **Language-card correction** | ข้อมูลบางอย่างบน [การ์ดภาษา](/catalogue) ไม่ถูกต้อง ล้าสมัย หรือขาดหายไป — เช่น จำนวนผู้พูดโดยประมาณ, สถานะ, ระบบการเขียน, ทรัพยากรที่เรายังไม่ได้ระบุไว้ | **การแก้ไขที่มีการอ้างอิงซึ่งนำไปใช้ที่แหล่งข้อมูล** (การ์ดถูกสร้างขึ้นอัตโนมัติ ดังนั้นการแก้ไขจะคงอยู่ถาวร) เมื่อแหล่งข้อมูลไม่ตรงกัน การ์ดจะแสดงข้อมูลทั้งหมดพร้อมระบุที่มา |

การ์ดภาษาทุกใบยังมีลิงก์ **"Suggest a correction or addition"**
ซึ่งจะเปิดแบบฟอร์มการแก้ไขโดยมีการกรอกข้อมูลภาษาไว้ล่วงหน้า

**คำขอการลบและจำกัดการเข้าถึงจากชุมชน** หากคุณเป็นสมาชิกชุมชน
หรือผู้มีอำนาจ และต้องการจำกัดการเข้าถึงหรือลบข้อมูลเกี่ยวกับภาษาของคุณ ให้ใช้
แบบฟอร์มการแก้ไข (หรือติดต่อผู้ดูแลระบบนอกช่องทางปกติ หากคุณไม่ต้องการให้เป็น
สาธารณะ) คำขอเหล่านี้จะผ่าน [การตรวจสอบอธิปไตย](/docs/network/sovereignty/data-sovereignty)
เป็นกรณีพิเศษ — โดยไม่จำเป็นต้องมีการอ้างอิง

## กระบวนการตรวจสอบ

นี่คือส่วนสำคัญ: **การส่งข้อมูลจะถูกตรวจสอบโดยมนุษย์ ไม่ใช่ระบบอัตโนมัติ** เมื่อคุณส่งข้อมูล คุณจะเปิด GitHub issue ซึ่ง issue นั้นคือคิวการตรวจสอบ ผู้ดูแลระบบจะอ่านและตรวจสอบตามกฎของโครงการก่อนที่จะเพิ่มข้อมูลใด ๆ:

- **ทรัพย์สินทางปัญญาและใบอนุญาต** เราต้องได้รับอนุญาตให้แสดงรายการนั้น เนื้อหาที่ไม่ใช่เชิงพาณิชย์ ห้ามแจกจ่ายซ้ำ หรือมีใบอนุญาตไม่ชัดเจน ยังสามารถ *จัดทำรายการ* ได้ แต่จะถูกกั้นออกจากช่องทางเชิงพาณิชย์ / รางวัล / การดึงข้อมูลสาธารณะ
- **ชุมชนและอธิปไตยทางภาษา** ข้อมูลภาษาของชนพื้นเมืองและชุมชนจะถูกแสดงรายการเฉพาะเมื่อได้รับความยินยอมจากชุมชนเท่านั้น ผู้ให้บริการหรือผู้ดูแลจะไม่ถูกระบุชื่อสาธารณะก่อนที่พวกเขาจะยืนยัน
- **เราไม่โฮสต์เนื้อหาของคลังข้อมูล** ชุดข้อมูลจะถูกแสดงเป็น metadata พร้อมตัวชี้ไปยังแหล่งที่ดึงข้อมูล **อย่าวางประโยคต้นฉบับ/อ้างอิงลงในการส่งข้อมูล**
- **ไม่มีข้อมูลส่วนบุคคล** ไม่มีอีเมล หมายเลขโทรศัพท์ หรือข้อมูลส่วนบุคคลอื่น ๆ ใน issue สาธารณะ สำหรับบริการแปลโดยมนุษย์ ข้อมูลติดต่อจะถูกส่งให้ผู้ดูแลระบบแบบส่วนตัว
- **ขอบเขต** คลังข้อมูลพระคัมภีร์ / พิธีกรรม และคลังข้อมูลอื่น ๆ ที่เป็นผลจากการบังคับใช้ภาษาในยุคอาณานิคม อยู่นอกขอบเขตและจะถูกปฏิเสธ

ทุกแบบฟอร์มจะสิ้นสุดด้วยการรับรองที่บังคับ:

> *"ข้าพเจ้าขอยืนยันว่าข้อมูลนี้สามารถแสดงรายการสาธารณะได้ ไม่มีเนื้อหาของคลังข้อมูลหรือข้อมูลส่วนบุคคล และเคารพใบอนุญาตของแหล่งที่มาและข้อจำกัดด้านชุมชน/อธิปไตยทางภาษา"*

## สองวิธีในการส่งข้อมูล

### ผ่านเบราว์เซอร์

เปิดตัวเลือก issue และเลือกแบบฟอร์มที่ตรงกับสิ่งที่คุณต้องการส่ง:

➡️ **[เปิดแบบฟอร์มการส่งข้อมูลบน GitHub](https://github.com/gamedaysuits/Champollion/issues/new/choose)**

แต่ละแบบฟอร์มจะถามเฉพาะข้อมูลที่ดัชนีนั้น ๆ ต้องการ (ชื่อ ภาษา/คู่ภาษา ใบอนุญาต URL ต้นทาง และอื่น ๆ) พร้อมช่องทำเครื่องหมายการรับรอง

### ผ่าน CLI

หากคุณมี [champollion CLI](/docs/network/getting-started/submit-a-method) `champollion submit` จะรวบรวมข้อมูลและสร้าง URL ของแบบฟอร์ม GitHub เดียวกันแบบ **กรอกข้อมูลล่วงหน้า** ให้คุณ:

```bash
# Interactive — pick a type and answer the prompts
champollion submit

# See the submission types
champollion submit --list

# Fully scripted (prints a pre-filled GitHub issue URL)
champollion submit --yes --type dataset --attest \
  --field dataset-name="GlobalVoices eng-amh" \
  --field pairs=eng-amh \
  --field license=CC-BY-4.0 \
  --field source-url=https://globalvoices.org
```

CLI จะแสดง URL — เปิดลิงก์นั้น ตรวจสอบการรับรองในเบราว์เซอร์ และส่งข้อมูล เพิ่ม `--out submission.json` เพื่อบันทึกสำเนาในเครื่องที่ไม่มีเนื้อหาของสิ่งที่คุณกำลังเสนอด้วย CLI ไม่อัปโหลดข้อมูลใด ๆ เองและไม่เขียนลงในดัชนี

## สิ่งที่เกิดขึ้นหลังจากคุณส่งข้อมูล

1. การส่งข้อมูลของคุณจะปรากฏเป็น GitHub issue — คิวการตรวจสอบ
2. ผู้ดูแลระบบจะตรวจสอบตามกฎด้านทรัพย์สินทางปัญญา / ใบอนุญาต / อธิปไตยทางภาษาข้างต้น
3. **หากได้รับการยอมรับ:** ผู้ดูแลระบบจะเพิ่มรายการลงในแหล่งข้อมูลที่เกี่ยวข้อง (ทะเบียนชุดข้อมูล การ์ดข้อมูล ทะเบียนวิธีการหรือบริการแปลโดยมนุษย์ หรือรายการผลลัพธ์ภายนอก) ผ่านกระบวนการปกติ และติดป้ายกำกับ issue ว่า **accepted**
4. **หากไม่สามารถแสดงรายการได้ตามที่ส่งมา:** ผู้ดูแลระบบจะติดป้ายกำกับว่า **declined** (หรือขอข้อมูลเพิ่มเติม) พร้อมระบุเหตุผล

ไม่มีการ merge อัตโนมัติและไม่มีการเผยแพร่อัตโนมัติ มนุษย์เป็นผู้ตัดสินใจทุกครั้ง
