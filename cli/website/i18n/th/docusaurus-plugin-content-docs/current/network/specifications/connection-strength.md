# ความแข็งแกร่งของการเชื่อมต่อ

เมื่อแผนผังเครือข่ายวาดเส้นเชื่อมโยงระหว่างสองภาษา สีของเส้นจะตอบคำถาม
เพียงข้อเดียว: **คู่ภาษานี้ได้รับการวัดผลจริงแล้วหรือไม่?**

นั่นเป็นสิ่งที่น้อยกว่าที่แผนผังเคยแสดงไว้อย่างตั้งใจ จนถึงวันที่ 2026-09-04 เส้นเชื่อมโยง
เคยแสดงสีตามระดับความเข้มแบบ 5 ขั้น — ซึ่งบ่งบอกว่าการแปลที่ดีที่สุดนั้น*ดี*เพียงใด
บนสเกลที่ปรับแก้ค่าความน่าจะเป็นจากการสุ่ม (chance-corrected scale) ระดับสีดังกล่าวได้ถูกยกเลิกไปแล้ว หน้านี้
จะอธิบายถึงตัวเลขที่อยู่เบื้องหลัง เหตุใดการนำออกจึงเป็นการตัดสินใจที่ตรงไปตรงมา
และสิ่งที่แผนผังกำลังสื่ออยู่ในปัจจุบัน

## ปัญหา: คะแนนดิบไม่เป็นศูนย์เมื่อไม่มีความหมาย

คะแนนส่วนใหญ่ของเราคือ **chrF++** (character n-gram F-score, [Popović
2017](https://aclanthology.org/W17-4770/)) — วัดว่าตัวอักษรและคำในการแปลทับซ้อนกับการแปลอ้างอิงมากเพียงใด โดยมีช่วงคะแนนตั้งแต่ 0 ถึง 100

แต่ *ข้อความสุ่มไม่ได้ได้คะแนนเป็นศูนย์* ระบบการเขียนทุกระบบให้ค่าทับซ้อน "ฟรี" บางส่วน: อักขรวิธีที่มีตัวอักษรเฉพาะน้อย หรือคำที่ยาวและคาดเดาได้ จะได้คะแนนสูงกว่าศูนย์อย่างวัดได้ แม้ว่า "การแปล" นั้นจะไม่มีความหมายก็ตาม ค่าทับซ้อนฟรีนี้ — **ค่าพื้นฐานจากโอกาส** — แตกต่างกันไปตามภาษา จากการวัดของเรา ค่านี้อยู่ในช่วงประมาณ 1.6 (อักษรจีน) ถึงมากกว่า 13 (ภาษาที่ใช้อักษรละตินและอาหรับบางภาษา) chrF++ ดิบที่ 14 อาจเป็นเพียงสัญญาณรบกวนใกล้สุ่มในภาษาหนึ่ง แต่เป็นสัญญาณจริงในอีกภาษาหนึ่ง — ดังนั้น chrF++ ดิบจึง **ไม่สามารถเปรียบเทียบข้ามภาษาได้** และแผนที่ที่ใช้สีตามค่านี้จะยกย่องอักษรบางชนิดอย่างเงียบๆ โดยไม่ตั้งใจ

ปัญหานี้มีอยู่จริง และเป็นเหตุผลว่าทำไมแผนผังจึง**ไม่**จัดอันดับความแข็งแกร่งข้าม
ภาษา นี่ไม่ใช่ปัญหาที่เราแก้ไขได้แล้ว

## การปรับแก้ที่เราสร้างขึ้น และเหตุใดมันจึงไม่ได้ใช้แสดงสีบนแผนผังอีกต่อไป

**chrF++ ที่ปรับแก้ค่าความน่าจะเป็นจากการสุ่ม (cchrF++)** จะปรับสเกลคะแนนเพื่อให้ 0 หมายถึง "ไม่ดีไปกว่า
การสุ่มเดา" *ในภาษานั้นๆ* และ 1 หมายถึงสมบูรณ์แบบ:

```
cchrF++ = (chrF++ − floor) / (100 − floor)
```

ค่าต่ำสุด (floors) ได้มาจากการวัดผลจริง ไม่ใช่การสมมติ: สำหรับแต่ละภาษา เราทำการประเมิน
ด้วยวิธี Monte-Carlo — โดยเปรียบเทียบคะแนนของค่าตั้งต้นแบบสุ่มที่มีระบบการเขียนเดียวกันจำนวนหลายพันชุดกับข้อมูลอ้างอิงจริง
— โดยใช้เพียงข้อความภาษาเดียวที่เผยแพร่ต่อสาธารณะเท่านั้น (FLORES-200 dev,
ดึงมาจากต้นทาง ไม่มีการเผยแพร่ต่อ) ตารางค่าต่ำสุดนี้ครอบคลุม 196
ภาษา และเป็นผลงานที่พัฒนาขึ้นโดย Champollion

**สิ่งที่การปรับแก้นั้นพิสูจน์ได้จริง** ค่าต่ำสุดจากการสุ่มเดานั้นมีอยู่จริง แตกต่างกันได้
ถึงประมาณเก้าเท่าในแต่ละระบบการเขียน และสามารถประมาณการได้จากข้อความภาษาเดียว
โดยไม่จำเป็นต้องมีป้ายกำกับการประเมินคุณภาพจากมนุษย์เลย การหักค่านี้ออกสามารถขจัด
องค์ประกอบจากการสุ่มเดาออกจากค่าตั้งต้นที่ไม่ซับซ้อนได้อย่างเห็นได้ชัด: การโกงแบบคัดลอกข้อความต้นฉบับ
ซึ่งได้คะแนนดิบ 15+ ในภาษาฟินแลนด์ จะลดลงเหลือประมาณ 2.5 และในภาษาส่วนใหญ่จะลดลงเหลือ
ศูนย์พอดี "การสุ่มเดา" ที่ถูกตัดออกไปคือสถิติเชิงพื้นผิว ไม่ใช่ความหมายที่หลงเหลืออยู่

**สิ่งที่ไม่สามารถพิสูจน์ได้** การปรับแก้นี้ทำให้ค่า **0** มีความหมายเดียวกันในทุก
ภาษา แต่ไม่ได้ทำให้ค่า **40** มีความหมายเดียวกัน เมื่ออยู่เหนือระดับค่าต่ำสุด
การปรับแก้จะเป็นเพียงการปรับสเกลเชิงเส้นตรง และหลักฐานที่แสดงว่า*คุณภาพ*ที่เท่ากัน
จะให้คะแนนที่ปรับแก้แล้วเท่ากันในทุกภาษานั้น ได้รับการพิสูจน์เฉพาะที่ช่วงล่างสุดของสเกล
เท่านั้น เมื่อเทียบกับกลุ่มผลการตัดสินของมนุษย์ วิธีนี้ช่วยได้ในกรณีที่ค่าต่ำสุด
แตกต่างกันจริง แต่ไม่ได้สร้างความแตกต่างในกรณีที่ไม่ต่างกัน และในกลุ่มข้อมูลหนึ่งที่มีค่าต่ำสุด
ต่ำอย่างสม่ำเสมอ มันกลับทำให้ความสอดคล้องกับผู้ประเมินที่เป็นมนุษย์เปลี่ยนไปในทิศทางที่*ผิด* — ซึ่งเป็น
ผลลัพธ์ที่เรายังไม่สามารถไขคำตอบได้

การระบายสีแผนผังสาธารณะด้วยระดับความเข้ม 5 ขั้นเป็นการอ้างเกินกว่าที่
หลักฐานรองรับ โดยเฉพาะอย่างยิ่งกับภาษาที่มีทรัพยากรน้อยซึ่งความผิดพลาด
สร้างผลกระทบได้มากที่สุด ดังนั้น ระดับสีดังกล่าวจึงถูกยกเลิกไปจนกว่าการศึกษาเพิ่มเติมจะให้คำตอบที่ชัดเจน

โปรดทราบว่าการใช้สีตามค่า chrF++ แบบ**ดิบ**แทนนั้นไม่เคยเป็นทางเลือกเลย เนื่องจากคะแนนดิบ
ไม่สามารถนำมาเปรียบเทียบข้ามภาษาได้เลยแม้แต่น้อย ซึ่งนั่นเป็นเหตุผลทั้งหมดที่ต้องสร้างการปรับแก้
นี้ขึ้นมา การเข้ารหัสแบบทวิภาค (binary encoding) จึงเป็นทางเลือกสำรองที่ตรงไปตรงมา ไม่ใช่การลดระดับ
ไปสู่สิ่งที่มีประสิทธิภาพด้อยกว่า

## ลำดับชั้นความน่าเชื่อถือของการวัดผล

จากน่าเชื่อถือมากที่สุดไปหาน้อยที่สุด:

1. **การตรวจสอบโดยมนุษย์** — ผู้ใช้ภาษาอย่างคล่องแคล่วเป็นผู้ตัดสินผลลัพธ์ ([การตรวจสอบความถูกต้องโดยผู้พูด](/docs/network/specifications/speaker-validation)) ไม่มีระบบอัตโนมัติใดมีลำดับสูงกว่านี้
2. **การกำกับคำอธิบายโดยผู้เชี่ยวชาญตามแนวทาง MQM** ([Multidimensional Quality
   Metrics](https://aclanthology.org/2014.tc-1.6/), Lommel et al.) — เกณฑ์วิธีที่ WMT ใช้สำหรับคำตัดสินระดับมาตรฐานสูงสุด (gold judgments); มีค่าใช้จ่ายสูง พบได้ยาก ดีมาก
3. **คะแนนอัตโนมัติ — ภายในคู่ภาษาเดียวกันเท่านั้น** chrF++ ดิบ, BLEU,
   COMET และตัววัดอื่นๆ มีประโยชน์สำหรับการเปรียบเทียบระบบต่างๆ บนคู่ภาษา*เดียวกัน*;
   ดูที่ [ความน่าเชื่อถือของตัววัด](/docs/network/specifications/metric-reliability)
   สำหรับข้อมูลว่าแต่ละตัววัดอาจติดตามการตัดสินของมนุษย์ในคู่ภาษาของคุณได้คลาดเคลื่อนเพียงใด
4. **ความแข็งแกร่งข้ามภาษา** เราไม่เผยแพร่การจัดอันดับ โปรดดูข้อมูลข้างต้น

เมื่อผลลัพธ์ที่ผ่านการตรวจสอบโดยมนุษย์และระดับ MQM เข้ามาในกระดาน ผลลัพธ์เหล่านั้นจะมีความสำคัญเหนือกว่าคะแนนอัตโนมัติสำหรับคู่ภาษาเดียวกัน

## วิธีที่แผนที่แสดงผล

แต่ละช่องทางภาพมีความหมายเพียงหนึ่งอย่าง:

| ช่องสัญญาณ | ความหมาย |
|---------|---------|
| **สี** | วัดผลแล้ว มีสีเดียว ไม่มีระดับความเข้ม — เส้นเชื่อมโยงบ่งบอกว่ามีการประมวลผลวัดคะแนนคู่ภาษานี้แล้ว และไม่ได้บอกสิ่งใดเกี่ยวกับคุณภาพว่าดีเพียงใด |
| **เส้นประ + สีจางลง** | ชั่วคราว: ชุดทดสอบมีขนาดต่ำกว่า [เกณฑ์ขั้นต่ำที่มีนัยสำคัญ](/docs/network/specifications/significance) (n &lt; 100) ซึ่งช่องว่างคะแนนภายในช่วง ~5 chrF++ ถือเป็นสัญญาณรบกวน (noise) นี่เป็นคุณสมบัติของขนาดตัวอย่าง โดยไม่ขึ้นอยู่กับตัววัดใดๆ |
| **ความหนา** | คงที่ ไม่เหลือข้อมูลอื่นใดให้เข้ารหัสอีก |

เฉพาะคู่ภาษาที่**วัดผลแล้ว**เท่านั้นที่จะวาดเส้นเชื่อมโยงแบบวัดผลแล้ว ส่วนคู่ภาษาที่ลงทะเบียนไว้
— ซึ่งอยู่ในคิวรอการวัดผลแต่ยังไม่ได้ให้คะแนน — จะปรากฏเป็นเส้นบางๆ สีทึบจางๆ
ซึ่งสีนั้นจะบ่งบอกเพียง*วิธีการเข้าถึงคู่ภาษานั้นได้ในปัจจุบัน*เท่านั้น
(commercial API · โมเดลโอเพนซอร์ส · โมเดลระดับแถวหน้าแบบไม่มีผู้ให้บริการ) ไม่เคยบอกว่า
สิ่งใดแปลได้ดีเพียงใด ชุดสัญลักษณ์ทั้งสองถูกแยกจากกันโดยเจตนา: เส้นสีทึบโทนหม่น = การเข้าถึงได้,
สีสำหรับวัดผลเพียงสีเดียว = วัดผลแล้ว คะแนนเบื้องหลังของเส้นเชื่อมโยงคือรอบการประมวลผลที่ได้คะแนนดีที่สุด
สำหรับคู่ภาษานั้นบนตารางสาธารณะ โดยจะอัปเดตใหม่อัตโนมัติเมื่อมีรอบการประมวลผลใหม่เข้ามา และจะแสดง
เป็นตัวเลขภายในคู่ภาษาเมื่อคุณเปิดดูเส้นเชื่อมโยง — ไม่เคยแสดงเป็นอันดับเปรียบเทียบข้ามภาษา

## รายละเอียดเพิ่มเติม

- ค่าต่ำสุดจากการสุ่มเดาเป็นคุณสมบัติของ ตัววัด × ระบบการเขียน ซึ่งประเมินจาก
  ข้อความภาษาเดียวเท่านั้น โดยไม่มีเนื้อหาคลังข้อมูลคู่ภาษาเข้ามาเกี่ยวข้องหรือถูกจัดเก็บไว้
- แผนที่ค่าต่ำสุดและการปรับแก้ยังคงเป็นงานวิจัยที่ได้รับการเผยแพร่ และโค้ดยังคงอยู่ใน
  คลังเก็บข้อมูลเพื่อการทดสอบ โดยไม่ได้เชื่อมต่อกับส่วนแสดงผลสาธารณะใดๆ
- **เป็นการปรับแก้ค่าต่ำสุด ไม่ใช่ค่าสูงสุด** ขีดจำกัดความสูงของคะแนนที่การแปลที่ดีจริง
  จะทำได้นั้นยังคงแตกต่างกันไปตามแต่ละภาษา และการปรับแก้นี้ไม่ได้ช่วยจัดการกับเรื่องดังกล่าว
- **ไม่ใช่วิธีป้องกันการคัดลอกข้ามระบบการเขียนเดียวกัน** ผลลัพธ์ที่เพียงแค่คัดลอก
  ข้อความต้นฉบับยังคงสามารถได้คะแนนสูงกว่าการสุ่มเดาได้ เมื่อภาษาต้นทางและภาษาเป้าหมายใช้ระบบการเขียนเดียวกัน
- **ไม่สามารถจัดอันดับระบบใหม่ภายในคู่ภาษาเดียวกันได้** เมื่ออยู่เหนือระดับค่าต่ำสุด
  การปรับแก้จะเป็นการปรับสเกลเชิงเส้นตรง ดังนั้นการจัดอันดับภายในคู่ภาษาจึงเหมือนเดิมทุกประการ
  ทั้งก่อนและหลังการปรับแก้ — ประโยชน์เพียงอย่างเดียวที่เป็นไปได้คือการใช้เปรียบเทียบข้ามคู่ภาษา
- เส้นเชื่อมโยงที่วัดผลแล้วจะบอกคุณว่าคู่ภาษานั้นได้รับการให้คะแนนแล้ว แต่**ไม่ได้**ตรวจสอบความถูกต้อง
  ของความหมาย ระดับภาษา หรือความเหมาะสมทางวัฒนธรรม สิ่งเหล่านั้นยังคงต้องอาศัยการตัดสินโดยมนุษย์ ([ข้อจำกัดตามความเป็นจริง](/docs/network/honest-limitations))
- ระเบียบวิธีค่าต่ำสุดจากการสุ่มเดาเป็นงานวิจัยของ Champollion ซึ่งเผยแพร่ไว้ที่นี่
  อย่างชัดเจนเพื่อให้สามารถตรวจสอบและโต้แย้งได้
