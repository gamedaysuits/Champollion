# ความแข็งแกร่งของการเชื่อมต่อ

เมื่อแผนที่เครือข่ายลากส่วนโค้งระหว่างสองภาษา สีของส่วนโค้งนั้นตอบคำถามเดียว: **การแปลที่ดีที่สุดที่วัดได้ระหว่างภาษาทั้งสองนั้นดีเพียงใด — อย่างตรงไปตรงมา?**

ส่วนที่ว่า "ตรงไปตรงมา" นั้นยากกว่าที่ฟังดู หน้านี้อธิบายตัวเลขที่อยู่เบื้องหลังสีนั้นด้วยภาษาที่เข้าใจง่าย

## ปัญหา: คะแนนดิบไม่เป็นศูนย์เมื่อไม่มีความหมาย

คะแนนส่วนใหญ่ของเราคือ **chrF++** (character n-gram F-score, [Popović
2017](https://aclanthology.org/W17-4770/)) — วัดว่าตัวอักษรและคำในการแปลทับซ้อนกับการแปลอ้างอิงมากเพียงใด โดยมีช่วงคะแนนตั้งแต่ 0 ถึง 100

แต่ *ข้อความสุ่มไม่ได้ได้คะแนนเป็นศูนย์* ระบบการเขียนทุกระบบให้ค่าทับซ้อน "ฟรี" บางส่วน: อักขรวิธีที่มีตัวอักษรเฉพาะน้อย หรือคำที่ยาวและคาดเดาได้ จะได้คะแนนสูงกว่าศูนย์อย่างวัดได้ แม้ว่า "การแปล" นั้นจะไม่มีความหมายก็ตาม ค่าทับซ้อนฟรีนี้ — **ค่าพื้นฐานจากโอกาส** — แตกต่างกันไปตามภาษา จากการวัดของเรา ค่านี้อยู่ในช่วงประมาณ 1.6 (อักษรจีน) ถึงมากกว่า 13 (ภาษาที่ใช้อักษรละตินและอาหรับบางภาษา) chrF++ ดิบที่ 14 อาจเป็นเพียงสัญญาณรบกวนใกล้สุ่มในภาษาหนึ่ง แต่เป็นสัญญาณจริงในอีกภาษาหนึ่ง — ดังนั้น chrF++ ดิบจึง **ไม่สามารถเปรียบเทียบข้ามภาษาได้** และแผนที่ที่ใช้สีตามค่านี้จะยกย่องอักษรบางชนิดอย่างเงียบๆ โดยไม่ตั้งใจ

## วิธีแก้ไข: ลบค่าพื้นฐานออก

**Chance-corrected chrF++ (cchrF++)** ปรับสเกลคะแนนใหม่ให้ 0 หมายถึง "ไม่ดีกว่าโอกาส" *ในภาษานั้น* และ 1 หมายถึงสมบูรณ์แบบ:

```
cchrF++ = (chrF++ − floor) / (100 − floor)
```

ค่าพื้นฐานได้จากการวัด ไม่ใช่การสมมติ: สำหรับแต่ละภาษา เราใช้การประมาณแบบ Monte-Carlo — ค่าพื้นฐานสุ่มที่ใช้อักขรวิธีเดียวกันหลายพันรายการ นำไปเทียบกับข้อมูลอ้างอิงจริง — โดยใช้เฉพาะข้อความ monolingual ที่เผยแพร่สาธารณะ (FLORES-200 dev ดึงมาจากแหล่งต้นทาง ไม่มีการเผยแพร่ซ้ำ) ตารางค่าพื้นฐานครอบคลุม 196 ภาษาในปัจจุบัน และเป็น artifact ที่ได้จาก Champollion
(`champollion-derived` provenance; สร้างใหม่โดย
`cli/website/scripts/build-cchrf-floors.mjs`)

กฎอนุรักษ์นิยมสองข้อช่วยให้การแก้ไขมีความซื่อสัตย์:

- **คู่ภาษาจะได้รับการแก้ไขเฉพาะเมื่อทั้งสองฝ่ายมีค่าพื้นฐานที่วัดได้** หากฝ่ายใดฝ่ายหนึ่งไม่มีข้อมูล ส่วนโค้งจะแสดงเป็นสีเทากลาง — *วัดแล้ว แต่ไม่ทราบค่าพื้นฐาน* — และจะไม่ถูกนำไปใช้กับแถบสี
- **คู่ภาษาใช้ค่าพื้นฐานที่สูงกว่าของทั้งสอง** การแก้ไขอาจประเมินความแข็งแกร่งต่ำกว่าความเป็นจริง แต่จะไม่เกินจริงเด็ดขาด

## ตำแหน่งของ cchrF++ ในลำดับชั้น

cchrF++ คือมาตรวัดความแข็งแกร่ง *อัตโนมัติ* ที่ดีที่สุดของเรา — แต่ไม่ใช่อันดับสูงสุดในลำดับชั้น เรียงจากน่าเชื่อถือที่สุดไปน้อยที่สุด:

1. **การตรวจสอบโดยมนุษย์** — ผู้พูดที่คล่องแคล่วประเมินผลลัพธ์ ([การตรวจสอบโดยผู้พูด](/docs/network/specifications/speaker-validation)) ไม่มีวิธีอัตโนมัติใดเทียบได้
2. **การวิเคราะห์โดยผู้เชี่ยวชาญแบบ MQM** ([Multidimensional Quality
   Metrics](https://aclanthology.org/2014.tc-1.6/), Lommel et al.) — โปรโตคอลที่ WMT ใช้สำหรับการตัดสินระดับ gold; มีค่าใช้จ่ายสูง หายาก แต่ดีมาก
3. **cchrF++** — แก้ไขค่าโอกาสแล้ว เปรียบเทียบข้ามภาษาได้ คำนวณได้ทุกที่ด้วยต้นทุนต่ำ
4. **chrF++ ดิบ / BLEU / neural metrics** — มีประโยชน์ภายในชุดข้อมูลเดียว; ดู [ความน่าเชื่อถือของ Metric](/docs/network/specifications/metric-reliability) สำหรับข้อมูลว่าแต่ละตัวติดตามการตัดสินของมนุษย์ได้แย่เพียงใดสำหรับคู่ภาษาของคุณ

เมื่อผลลัพธ์ที่ผ่านการตรวจสอบโดยมนุษย์และระดับ MQM เข้ามาในกระดาน ผลลัพธ์เหล่านั้นจะมีความสำคัญเหนือกว่าคะแนนอัตโนมัติสำหรับคู่ภาษาเดียวกัน

## วิธีที่แผนที่แสดงผล

แต่ละช่องทางภาพมีความหมายเพียงหนึ่งอย่าง:

| ช่องทาง | ความหมาย |
|---------|---------|
| **สี** | แถบ cchrF++ — ห้าระดับ จากแดงถึงเขียวอ่อน: *ใกล้ค่าพื้นฐาน* (&lt; 0.15), *อ่อน* (0.15–0.35), *กำลังพัฒนา* (0.35–0.55), *ใช้งานได้* (0.55–0.75), *แข็งแกร่ง* (≥ 0.75) |
| **สีเทากลาง** | วัดแล้ว แต่ไม่ทราบค่าพื้นฐานของโอกาสสำหรับอย่างน้อยหนึ่งฝ่าย — ไม่นำไปใช้กับแถบสีเด็ดขาด |
| **เส้นประ + จางลง** | เบื้องต้น: ชุดทดสอบต่ำกว่า [ค่าพื้นฐานนัยสำคัญ](/docs/network/specifications/significance) (n &lt; 100) ซึ่งช่องว่างคะแนนภายใน ~5 chrF++ ถือเป็นสัญญาณรบกวน |
| **ความกว้าง** | ทำซ้ำแถบสี (ความซ้ำซ้อนเพื่อการเข้าถึง ไม่ใช่ตัวแปรที่สอง) |

เฉพาะคู่ภาษาที่ **วัดแล้ว** เท่านั้นที่จะอยู่บนแถบความแข็งแกร่ง คู่ภาษาที่ลงทะเบียนแล้ว — อยู่ในคิวรอการวัดแต่ยังไม่ได้คะแนน — จะปรากฏเป็นเส้นบางสีแบนจางๆ ที่สีบอกเพียง *วิธีที่คู่ภาษานั้นเข้าถึงได้ในปัจจุบัน* (commercial API · open-source model · frontier, ไม่มี provider) ไม่ใช่คุณภาพของการแปล คำศัพท์ทั้งสองชุดแยกจากกันโดยเจตนา: เส้นแบนสีมืด = การเข้าถึงได้, แถบแดง→เขียว = ความแข็งแกร่งที่วัดได้ คะแนนพื้นฐานของส่วนโค้งคือผลการรันที่ดีที่สุดที่วัดได้สำหรับคู่ภาษานั้นบนกระดานสาธารณะ อัปเดตอัตโนมัติเมื่อมีการรันใหม่เข้ามา

## รายละเอียดเพิ่มเติม

- ค่าพื้นฐานเป็นคุณสมบัติของ metric × อักขรวิธี ประมาณจากข้อความ monolingual เท่านั้น ไม่มีการใช้หรือจัดเก็บเนื้อหา parallel corpus ใดๆ
- cchrF++ บอกว่าการแปลดีกว่าโอกาสและดีกว่ามากเพียงใด — แต่ **ไม่** ตรวจสอบความหมาย ระดับภาษา หรือความเหมาะสมทางวัฒนธรรม สิ่งเหล่านั้นยังคงเป็นการตัดสินของมนุษย์ ([ข้อจำกัดที่ตรงไปตรงมา](/docs/network/honest-limitations))
- วิธีการคำนวณค่าพื้นฐานจากโอกาสเป็นงานวิจัยของ Champollion; atlas ค่าพื้นฐานและการแก้ไขได้รับการเผยแพร่ที่นี่เพื่อให้สามารถตรวจสอบและท้าทายได้
