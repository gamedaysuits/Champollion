# ใครคือผู้ที่ได้รับประโยชน์

> **บทสรุปผู้บริหาร** จากภาษาที่ยังมีผู้ใช้งานอยู่ราว 7,000 ภาษาทั่วโลก มีไม่ถึง 600 ภาษาที่มีระบบการแปลด้วยเครื่อง (machine translation) ในรูปแบบใดรูปแบบหนึ่ง และกว่าครึ่งหนึ่งของภาษาเหล่านั้นอยู่ในภาวะเสี่ยง (ตามสถานะ Agglomerated Endangerment Status ของ Glottolog; อ้างอิงผ่าน Champollion) หาก Champollion ประสบความสำเร็จ — ในฐานะเลเยอร์การแปลที่เป็นสากลและชุมชนเป็นเจ้าของ — ผลลัพธ์ที่ได้จะมีสองประการคือ: การสื่อสารในปัจจุบันสำหรับผู้พูดภาษาที่อุตสาหกรรมมองข้าม และเครื่องมือที่ใช้งานได้จริงในการอนุรักษ์และฟื้นฟูภาษาที่อยู่ในภาวะเสี่ยง กลยุทธ์นี้ถูกกำหนดมาอย่างรอบคอบ: การพัฒนาวิธีการแบบคราวด์ซอร์ส (crowdsourced) ที่วัดผลด้วยกฎเกณฑ์แบบเปิด, การสร้างคลังข้อมูล (corpus) ที่ได้รับการสนับสนุนในอัตราค่าตอบแทนที่เปิดเผย และชุมชนที่เป็นผู้กุมกุญแจสู่ข้อมูลของตนเอง ชุดทดสอบของตนเอง และวิธีการใดๆ ที่ผ่านการตรวจสอบความถูกต้องด้วยข้อมูลเหล่านั้น หน้านี้จะอธิบายว่าแต่ละกลุ่มจะได้รับอะไรและควรเริ่มต้นทำสิ่งใดเป็นอันดับแรก

## ผู้พูดและชุมชนของพวกเขา \{#speakers}

หากคุณพูดภาษาที่ขาดแคลนทรัพยากรและภาษาอังกฤษ วิจารณญาณของคุณคือสิ่งที่มีค่าที่สุดในโปรเจกต์นี้ — มากกว่าโมเดลหรือตัวชี้วัดใดๆ คอมพิวเตอร์สามารถนับได้ว่าประโยคสองประโยคดูคล้ายกันแค่ไหน แต่ไม่สามารถบอกได้ว่าประโยคนั้นเป็นสิ่งที่ผู้พูดจริงๆ จะพูดหรือไม่ วิจารณญาณนั้นเป็นของคุณ และมันคือความจริงพื้นฐาน (ground truth) ที่ทุกสิ่งทุกอย่างในที่นี้ต้องนำมาตรวจสอบเทียบเคียง

**การตรวจสอบความถูกต้องโดยผู้พูดเป็นงานที่ได้รับค่าตอบแทนในอัตราวิชาชีพที่เปิดเผย ($50–65 CAD/ชั่วโมง) ตามตารางเวลาของคุณ โดยไม่จำเป็นต้องมีความเชี่ยวชาญด้านเทคนิค** — หากคุณสามารถอ่านได้ทั้งสองภาษาและตัดสินประโยคได้ คุณก็มีคุณสมบัติครบถ้วน [Speaker Validation Protocol](/docs/network/specifications/speaker-validation) ได้เผยแพร่ประเภทงานไว้ 3 ประเภท:

| งาน | สิ่งที่คุณต้องทำ | เวลา | ค่าตอบแทนที่เปิดเผย |
|------|-------------|------|---------------|
| ให้คะแนนคำแปล | อ่านคำแปลจากเครื่อง ให้คะแนนแต่ละประโยคว่า "เป็นธรรมชาติหรือไม่?" และ "ความหมายถูกต้องหรือไม่?" | ~8 ชั่วโมง กระจายทำได้หลายสัปดาห์ | $400–520 CAD |
| ตรวจสอบคู่ประโยคที่ "เทียบเท่ากัน" | ระบุว่าการใช้ถ้อยคำสองแบบมีความหมายเหมือนกันจริงๆ หรือไม่ | ~2 ชั่วโมง | $100–130 CAD |
| ตรวจสอบคำที่ถูกปฏิเสธ | ตรวจสอบคำที่เครื่องมือไวยากรณ์ตั้งข้อสังเกตว่าไม่ถูกต้อง — เครื่องมือทำถูกหรือไม่? | ~1.5 ชั่วโมง | $75–100 CAD |

นอกจากนี้ยังมีงานด้านคลังข้อมูล (corpus) — การสร้างคำแปลอ้างอิงสำหรับประโยคในชีวิตประจำวัน — ซึ่งจ่ายในอัตราต่อชั่วโมงเท่ากัน ([รายละเอียด](/docs/network/perspectives/how-speakers-get-paid)) เงื่อนไขโดยสรุปคือ: **เป็นงานที่ได้รับค่าตอบแทน ไม่ใช่งานอาสาสมัคร** (จ่ายเงินภายในสองสัปดาห์หลังจากจบงานแต่ละบล็อก จ่ายให้ไม่ว่าผลลัพธ์จะออกมาเป็นอย่างไร); **การให้เครดิตตามเงื่อนไขของคุณ** (ระบุชื่อหรือไม่ระบุชื่อ เป็นผู้ร่วมเขียนผลงานได้หากต้องการ); **คุณสามารถถอน** ผลงานของคุณได้ตลอดเวลา พร้อมสิทธิ์ยับยั้งการเผยแพร่ผลลัพธ์ที่คุณพบว่ามีปัญหา

:::note[สถานะปัจจุบัน]
พูดตามตรง: อัตราค่าตอบแทนและเงื่อนไขข้างต้นเป็นข้อผูกมัดที่ประกาศไว้ แต่ [ยังไม่มีการดำเนินการตรวจสอบโดยชุมชนรอบใดเลย](/docs/network/honest-limitations) — การมีส่วนร่วมกลุ่มแรกกำลังอยู่ในระหว่างการจัดเตรียม การติดต่อเข้ามาในตอนนี้หมายถึงการลงทะเบียนเพื่อเป็นกลุ่มแรกๆ ไม่ใช่การเข้าร่วมโปรแกรมที่มีอยู่แล้ว
:::

**สิ่งแรกที่ควรทำ:** เริ่มต้นวันนี้ด้วยการเพิ่มประโยคลงใน [Tatoeba](https://tatoeba.org) — Champollion ไม่เคยรวบรวมหรือโฮสต์คลังข้อมูลด้วยตัวเอง (ข้อมูลทดสอบจะถูก [ดึงมาจากแหล่งที่มา](/docs/network/sovereignty/registering-corpora) เสมอ) แต่เกณฑ์มาตรฐาน (benchmarks) หลายรายการที่นี่สร้างขึ้นจากประโยคใน Tatoeba และชุดข้อมูลเปิดอย่าง [OPUS](https://opus.nlpl.eu/) จากนั้นให้อ่าน [How Speakers Get Paid](/docs/network/perspectives/how-speakers-get-paid) (ใช้เวลา 5 นาที มีตัวเลขทั้งหมด) และติดต่อมาที่ — [info@champollion.dev](mailto:info@champollion.dev) หรือเปิด issue บน [public repository](https://github.com/gamedaysuits/Champollion/issues) — โดยระบุว่าคุณพูดภาษาอะไรและถนัดในการตัดสินภาษาถิ่น (varieties) ใดบ้าง

## ชุมชนภาษาที่สร้างคลังข้อมูล \{#communities}

จุดยืนที่แข็งแกร่งที่สุดที่ชุมชนสามารถมีได้ในระบบนี้คือ **การเป็นเจ้าของเกณฑ์มาตรฐาน (benchmark) เอง** ชุดทดสอบเปรียบเสมือนเฉลยคำตอบ: ผู้ใดที่ถือครองมันจะเป็นผู้ตัดสินว่า "การแปลที่ดี" สำหรับภาษานั้นหมายถึงอะไร และทุกวิธีการ — ไม่ว่าจะเป็นของเรา ขององค์กร หรือของใครก็ตาม — จะถูกวัดผลเทียบกับมาตรฐาน *ของคุณ*

กฎพื้นฐานข้อแรกคือ: **ข้อมูลภาษาของคุณเป็นของคุณ** การลงทะเบียนคลังข้อมูลหมายถึงการเผยแพร่การ์ดข้อมูลเมตา (metadata card) ที่เป็นคำอธิบาย — ไม่ใช่การอัปโหลดคลังข้อมูล — ใน [ระดับการเปิดเผยที่คุณเลือก](/docs/network/sovereignty/registering-corpora): แบบเปิด (open), แบบจำกัดการเข้าถึง (gated), หรือแบบมีอธิปไตยเต็มรูปแบบ (fully sovereign - ชุดทดสอบที่เราจะไม่มีวันได้เห็น และให้คะแนนบนโครงสร้างพื้นฐานของคุณเอง) การสร้างคลังข้อมูลและการตรวจสอบคำแปลเป็นงานระดับมืออาชีพที่ [ได้รับค่าตอบแทนตามอัตราที่เปิดเผย](/docs/network/perspectives/how-speakers-get-paid) และการจ่ายเงินไม่ได้เป็นการซื้อข้อมูลของคุณ เมื่อวิธีการแปลที่สร้างขึ้นสำหรับภาษาของคุณผ่านการตรวจสอบความถูกต้องที่นี่ [ความเป็นเจ้าของจะถูกโอน](/docs/network/sovereignty/ownership-transfer) ไปยังองค์กรกำกับดูแลของชุมชนของคุณ — ทั้งโค้ด, น้ำหนัก (weights), และการควบคุมการนำไปใช้งาน (deployment) แม้แต่คู่คำแปลที่ผ่านการคัดกรองเพียง 50 คู่ก็เพียงพอที่จะเปิดแทร็กใหม่บนกระดานผู้นำ (leaderboard) ได้แล้ว

ช่องทางแบบเต็มรูปแบบสำหรับชุมชน — การรับประกันอธิปไตย, สิ่งที่เครือข่ายร้องขอและมอบกลับคืนให้, และการเริ่มต้นทีละขั้นตอน — อยู่ที่ **[For Language Communities](/docs/network/community/for-language-communities)** โดยมี [Run a Sovereign Contest](/docs/network/sovereignty/run-a-sovereign-contest) เป็นคู่มือสำหรับการประเมินผลที่ควบคุมโดยชุมชน

## บริการแปลภาษาและผู้ให้บริการ MT \{#vendors}

หากคุณสร้างหรือขายบริการแปลภาษา — ไม่ว่าจะเป็นเอนจิน MT, ไปป์ไลน์ LLM, ระบบที่อิงตามกฎ (rule-based system), หรือบริการแปลโดยมนุษย์ — คุณสามารถวัดผลเกณฑ์มาตรฐานได้ที่นี่บนชุดทดสอบที่เผยแพร่ ปรากฏบนกระดานผู้นำและแผนที่สาธารณะ และถูกตัดสินด้วยกฎเดียวกันกับทุกคน **ไม่มีค่าธรรมเนียม ไม่มีข้อตกลงความเป็นหุ้นส่วน ไม่มีความลำเอียงต่อเทคโนโลยีใดๆ:** ระบบทดสอบ (harness) ถูกออกแบบมาให้เป็นกลางต่อทุกวิธีการ คุณจ่ายเพียงแค่ค่าประมวลผลหรือค่า API ของคุณเองเท่านั้น ([วิธีการให้ทุนสนับสนุนการทำงาน](/docs/network/sovereignty/economic-model))

เกณฑ์มาตรฐาน MT สาธารณะส่วนใหญ่ครอบคลุมภาษาที่มีทรัพยากรสูงเพียงไม่กี่ร้อยภาษาเหมือนๆ กัน และส่วนใหญ่มีการปนเปื้อน (contaminated) แคตตาล็อกของ Champollion ลงทะเบียนชุดข้อมูลการประเมิน <SSOTCount field="registryDatasetCount" /> ชุดในรูปแบบการ์ดข้อมูลเมตาที่ดึงจากแหล่งที่มาและตรึงด้วย SHA (sha-pinned) โดยมี [การเปิดเผยสถานะการปนเปื้อนต่อชุดข้อมูล](/docs/network/leaderboard/datasets) และมีช่องทางสำหรับชุดทดสอบใหม่ที่ไม่เคยเผยแพร่มาก่อน คะแนนจะใช้ตัวชี้วัดแบบเปิดที่สามารถทำซ้ำได้ (chrF++/BLEU/TER ผ่าน sacreBLEU; COMET/AfriCOMET จะรายงานแยกในช่องทาง neural) ภายใต้ [กฎการให้คะแนน](/docs/network/specifications/scoring) ที่เผยแพร่ไว้ การพึ่งพาวิธีการ (method dependencies) จะถูกประกาศอย่างชัดเจน ไม่มีการปิดบัง และเอนจินที่เป็นกรรมสิทธิ์ (proprietary) จะยังคงเป็นกรรมสิทธิ์ต่อไป — ระบบทดสอบจะเรียกใช้งานระบบของคุณ แต่จะไม่แตะต้องน้ำหนักหรือโค้ดของคุณ ข้อควรระวังตามความเป็นจริงสองประการ: **กระดานผู้นำยังใหม่อยู่** ([Honest Limitations](/docs/network/honest-limitations) ระบุชัดเจนว่าปัจจุบันมีการตรวจสอบอะไรไปแล้วบ้าง) และ **คะแนนไม่ได้ให้สิทธิ์ในการนำไปใช้งาน (deployment rights)** — สำหรับภาษาที่ดูแลโดยชุมชน ชุมชนจะเป็นผู้ตัดสินใจเรื่องการนำไปใช้งาน ([Data Stewardship](/docs/network/sovereignty/data-sovereignty))

**สิ่งแรกที่ควรทำ (เอนจิน MT หรือไปป์ไลน์):** เลือกคู่ภาษาของคุณจาก [ชุดข้อมูลการประเมิน](/docs/network/leaderboard/datasets) และ [กระดานผู้นำ](/leaderboard); `pipx install mt-eval-harness` และทำตาม [Submit a Method](/docs/network/getting-started/submit-a-method); หากเอนจินของคุณไม่สามารถเข้าถึงได้ผ่าน OpenRouter ให้ดำเนินการตาม [TranslationMethod protocol](/docs/network/specifications/methods#eval-harness-translationmethod-protocol) หรือเปิดให้ใช้งานเป็นบริการ API ขนาดเล็ก ([คู่มือ](/docs/guides/serving-a-method)); จากนั้นรันและเผยแพร่ — การส่งผลงานจากชุมชนจะเผยแพร่ในระดับความน่าเชื่อถือแบบวัดผลด้วยตนเอง (self-benchmarked) โดยมีป้ายกำกับชัดเจน ภายใต้ [กฎของกระดานผู้นำ](/docs/network/leaderboard/rules)

**หากคุณขายบริการแปลโดยมนุษย์:** ในกรณีที่ไม่มีเครื่องมือใดเชื่อถือได้สำหรับคู่ภาษา เว็บไซต์จะระบุไว้อย่างชัดเจนและแสดงผู้ให้บริการที่เป็นมนุษย์ซึ่งผ่านการให้ความยินยอมแทน — โปรดอ่าน [ช่องทางบริการโดยมนุษย์](/human-services) จากนั้นขอลงรายชื่อทางอีเมล ([info@champollion.dev](mailto:info@champollion.dev)) โดยระบุคู่ภาษาและภาษาถิ่นที่คุณให้บริการ เงื่อนไขของคุณ และการยืนยันความยินยอม รายละเอียดการติดต่อของคุณจะไม่ถูกเผยแพร่หากไม่ได้รับความยินยอม การแปลโดยมนุษย์ก็ถือเป็นวิธีการหนึ่งในที่นี้เช่นเดียวกับวิธีอื่นๆ — บางทีมวัดผลไปป์ไลน์การแก้ไขหลังการแปล (post-editing) ของตนเพื่อแสดงให้ผู้ซื้อเห็นถึงความแตกต่างเมื่อเทียบกับ MT ดิบ

## นักวิจัย \{#researchers}

วิธีที่แพงที่สุดในการนำการแปลด้วยเครื่องมาสู่ภาษาที่มีทรัพยากรน้อยคือวิธีที่วงการนี้มักจะพยายามทำ: การสร้างคลังข้อมูลสำหรับฝึกสอน (training corpus) นั่นหมายถึงคู่ประโยคหลายแสนคู่ — ซึ่งมากเกินกว่าที่ใครจะตรวจสอบได้ — ดังนั้นคุณภาพจึงแตกต่างกันไปในแบบที่ไม่มีใครมองเห็น และความล้มเหลวจะปรากฏขึ้นในตอนท้ายเท่านั้น เมื่อโมเดลที่ฝึกสอนด้วยคู่ประโยคเหล่านั้นทำผิดพลาดในจุดเดียวกับที่ข้อมูลผิดพลาด การทำงานรวบรวมข้อมูลนานหลายเดือนอาจสร้างคลังข้อมูลที่คุณไม่สามารถเชื่อถือได้อย่างเต็มที่และโมเดลที่คุณไม่สามารถนำไปใช้งานจริงได้

ชุดการประเมิน (evaluation set) จะพลิกกลับหลักเศรษฐศาสตร์เหล่านั้น ชุดทดสอบสำหรับการพัฒนาและชุดทดสอบที่แยกไว้ (held-out test set) สำหรับภาษาเดียวกันจะมีขนาดประมาณ **หนึ่งพัน** คู่ — ซึ่งเล็กพอที่จะสามารถคัดกรองอย่างมืออาชีพได้จริง โดยทุกคู่จะถูกตรวจสอบโดยผู้ที่รู้ภาษานั้น คู่ประโยคเจ็ดแสนคู่ที่คุณไม่สามารถตรวจสอบได้ หรือหนึ่งพันคู่ที่คุณตรวจสอบได้: ชุดการประเมินคือผลลัพธ์เดียวที่วิจารณญาณของนักวิจัยสามารถเข้าถึงได้ทุกประโยค และต่างจากคลังข้อมูลสำหรับฝึกสอนตรงที่มันจะไม่ล้าสมัย — ทุกโมเดล เอนจิน หรือวิธีการใหม่ๆ ที่ปรากฏขึ้นสามารถนำมาวัดผลเทียบกับชุดการประเมินนี้ได้ตลอดไป

นี่คือเดิมพันที่โปรเจกต์ทั้งหมดนี้สร้างขึ้น — **ทฤษฎีคู่ประโยคแห่งยุค (generational-pair thesis)**: สร้างมาตรฐานการประเมินและแรงจูงใจ แล้วชุมชนจะสร้างโซลูชันที่ใช้งานได้จริง คุณคัดกรองคู่ประโยคหนึ่งพันคู่ รางวัลที่ตั้งไว้สำหรับชุดทดสอบที่แยกไว้ของคุณจะทำให้ภาษานั้นกลายเป็นเป้าหมายที่ผู้สร้างวิธีการใดๆ ก็สามารถมุ่งเป้าไปได้ กระดานผู้นำจะวัดผลทุกความพยายามต่อสาธารณะ การคัดกรองอย่างระมัดระวังในยุคหนึ่งจะเปิดการแข่งขันแบบปลายเปิดสำหรับสิ่งอื่นๆ ทั้งหมด [Corpus Partnership](/docs/network/specifications/corpus-partnership) คือเอกสารการทำงานสำหรับสิ่งนี้โดยเฉพาะ — ขนาดของคลังข้อมูล, ขั้นตอนการทำงาน, การจ่ายค่าตอบแทนผู้พูด — และ [Prize Specification](/docs/network/specifications/prizes) คือส่วนที่เป็นแรงจูงใจ

เครื่องมือวัดผลพร้อมใช้งานแล้ววันนี้ `pipx install mt-eval-harness` จะให้คุณเข้าถึง [ระบบทดสอบการประเมิน (eval harness)](/docs/network/specifications/harness): การให้คะแนนแบบกำหนดได้ (deterministic scoring), [การ์ดการรัน (run cards)](/docs/network/specifications/run-card) ที่มีลายนิ้วมือดิจิทัล, [นัยสำคัญ (significance)](/docs/network/specifications/significance) แบบ paired bootstrap, และเส้นทางการเผยแพร่ไปยังกระดานผู้นำ [ข้อกำหนดการให้คะแนน (scoring spec)](/docs/network/specifications/scoring) จะบันทึกทุกตัวชี้วัดพร้อมสถานะการตรวจสอบความถูกต้อง — ตรวจสอบจากภายนอก, ตรวจสอบผ่านตัวแทน (proxy-validated), หรือฮิวริสติกทางวิศวกรรม — และรักษาให้ผลรวมสามารถกำหนดได้; ตัวชี้วัดแบบ neural จะรายงานในช่องทางแยกต่างหาก โดยไม่มีการรวมเข้าไปอย่างเงียบๆ ตัวชี้วัดมาตรฐานทำงานบน sacreBLEU และ COMET/AfriCOMET พร้อมส่วนขยายด้วยการตรวจสอบโครงสร้าง (ความถูกต้องของ FST) ซึ่งจะแสดงสิ่งที่ตัวชี้วัดแบบทับซ้อนของตัวอักษร (character-overlap) มักจะพลาดไปในภาษาที่มีโครงสร้างซับซ้อน (polysynthetic languages) ระบบทดสอบเป็นโอเพนซอร์ส AGPL-3.0; ส่วน CLI เป็น PolyForm Noncommercial 1.0.0 — เปิดเผยซอร์สโค้ด ใช้งานฟรีสำหรับวัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์

เบื้องหลังเครื่องมือเหล่านี้คือระบบทะเบียน (registries) **ชุดข้อมูลการประเมิน <SSOTCount field="registryDatasetCount" /> ชุด** แต่ละชุดเป็นการ์ดข้อมูลเมตาที่ดึงจากแหล่งที่มาและตรึงด้วย SHA ซึ่งจัดทำแคตตาล็อกไว้ใน [Evaluation Datasets](/docs/network/leaderboard/datasets); **การ์ดภาษา <SSOTCount field="catalogLanguageCount" /> รายการ** ซึ่ง [ทุกฟิลด์ระบุแหล่งที่มา](/docs/reference/language-card-spec) และแหล่งที่มาที่ขัดแย้งกันจะถูกแสดงทั้งหมด ([ขั้นตอนการแก้ไข](/docs/reference/language-card-citation-procedure)); การรวบรวมใบอนุญาตของ **แหล่งที่มาต้นน้ำที่ลงทะเบียนไว้ <SSOTCount field="licensedSourceCount" /> รายการ** โดยคลังข้อมูลที่ไม่ใช่เชิงพาณิชย์จะถูกแยกออกจากช่องทางเชิงพาณิชย์ รางวัล หรือ API โดยโครงสร้าง การปนเปื้อน (Contamination) ถือเป็นคุณสมบัติระดับเฟิร์สคลาส: เกณฑ์มาตรฐานสาธารณะที่สันนิษฐานว่าโมเดลระดับแนวหน้า (frontier models) เคยเห็นแล้ว จะรันใน **ช่องทางแบบสัมพัทธ์เท่านั้น (relative-only lane)**, คลังข้อมูลใหม่ของชุมชนจะถูกปิดผนึกและแบ่งส่วนด้วยแฮชแมนิเฟสต์ (hash manifests) ([corpus partnership §4](/docs/network/specifications/corpus-partnership#4-cryptographic-sealing-and-sandbox-testing)), และชุมชนสามารถถือครองเกณฑ์มาตรฐานที่มีอธิปไตยซึ่งเราจะไม่มีวันได้เห็น โมเดลภัยคุกคาม (threat model) ระบุไว้ใน [กรอบการออกแบบคลังข้อมูล (corpus design framework)](/docs/network/specifications/corpus-design)

มี 3 ทางเข้า ขึ้นอยู่กับสิ่งที่คุณต้องการสร้าง **คลังข้อมูล (corpus)**: เริ่มต้นจากเส้นทางที่เน้นการประเมินเป็นอันดับแรก (eval-first) ด้านบน — [Corpus Partnership](/docs/network/specifications/corpus-partnership) แบบครบวงจร โดยจัดสรรงบประมาณสำหรับเวลาของผู้พูดที่ได้รับค่าตอบแทนตั้งแต่วันแรก **วิธีการ (method)**: ดำเนินการตาม [TranslationMethod protocol](/docs/network/specifications/methods) และทำตาม [Submit a Method](/docs/network/getting-started/submit-a-method) — ใช้เวลาประมาณ 15 นาทีด้วยคีย์ OpenRouter **ตัวชี้วัด (metric)**: เสนอผ่านพื้นผิวปลั๊กอินของระบบทดสอบ (เปิด issue หรือ PR บน [repository](https://github.com/gamedaysuits/Champollion); เกณฑ์ในการเข้าสู่ผลรวมอยู่ในข้อกำหนดการให้คะแนน) ไม่ว่าจะเข้าทางประตูใด โปรดอ่าน [Honest Limitations](/docs/network/honest-limitations) ก่อน — รวมถึงข้อเท็จจริงที่ว่ายังไม่มีการตรวจสอบความถูกต้องของตัวชี้วัดโดยผู้พูดในชุมชน — และอ่าน [ระเบียบวิธี microeval](/docs/network/context/microeval-methodology) รวมถึง [ภูมิทัศน์การประเมิน MT](/docs/network/context/mt-evaluation-landscape) ก่อนที่จะออกแบบสิ่งใดๆ

**การอ้างอิง Champollion:** ขณะนี้ยังไม่มีเปเปอร์ของ Champollion — โปรดอย่าอ้างอิงเปเปอร์ ให้อ้างอิง repository และข้อกำหนดเฉพาะเวอร์ชัน หรือการ์ดชุดข้อมูลที่ตรึงด้วย SHA ที่คุณใช้งาน:

```bibtex
@software{champollion,
  author  = {Forbes, Curtis},
  title   = {Champollion: open evaluation infrastructure for machine
             translation in low-resource languages},
  url     = {https://github.com/gamedaysuits/Champollion},
  year    = {2026},
  note    = {Specifications at https://champollion.dev/docs/network}
}
```

หากคุณใช้คลังข้อมูลต้นน้ำผ่านระบบทะเบียนของเรา **ให้อ้างอิงผู้สร้างคลังข้อมูลนั้นๆ** — การ์ดชุดข้อมูลจะมีข้อมูลการระบุแหล่งที่มาต้นน้ำและใบอนุญาตกำกับไว้

## ผู้ให้ทุนและผู้สนับสนุน \{#funders}

**Champollion ไม่ใช่เชิงพาณิชย์** เงินสนับสนุนจะนำไปใช้ในการสร้างคลังข้อมูล เครื่องมือ และงานของชุมชน — **ส่งผ่าน 100% ตรวจสอบบัญชีได้แบบสาธารณะ และไม่มีส่วนใดเข้าสู่ Champollion**: ไม่มีเปอร์เซ็นต์ค่าใช้จ่ายในการดำเนินการ (overhead) ไม่มีส่วนแบ่งรายได้ ไม่มีการอ้างสิทธิ์ในทรัพย์สินของชุมชน เงินที่เข้ามาจะกลายเป็นงานด้านภาษาที่ได้รับค่าตอบแทน — โดยจะจ่ายให้กับผู้พูด ผู้สร้างคลังข้อมูล และผู้ชนะรางวัล — และค่าใช้จ่ายด้านโครงสร้างพื้นฐานในปัจจุบันผู้ก่อตั้งเป็นผู้รับผิดชอบ ([วิธีการให้ทุนสนับสนุนการทำงาน](/docs/network/sovereignty/economic-model))

จุดเริ่มต้นตามความเป็นจริง: ทุกสิ่งที่อธิบายในที่นี้คือกลไกที่ **ระบุไว้และพร้อมใช้งาน ไม่ใช่โปรแกรมที่กำลังทำงานในสเกลใหญ่แล้ว** ขณะนี้ยังไม่มีเงินทุนหรือผู้สนับสนุน กระดานผู้นำเปิดใช้งานแล้วแต่ยังอยู่ในช่วงเริ่มต้น และกลไกรางวัลเป็นเพียง [ข้อกำหนดที่นำเสนอ](/docs/network/specifications/prizes) — ยังไม่มีการเปิดรับรางวัลใดๆ ในวันนี้ สิ่งที่ผู้ให้ทุนจะได้รับจากความซื่อสัตย์นี้คือ: ต้นทุนต่อหน่วยที่เปิดเผย บัญชีแยกประเภทการอ้างสิทธิ์ (claims ledger) และข้อกำหนดที่คุณสามารถใช้ตรวจสอบเราได้

**ช่องทางที่ 1 — การสนับสนุนคลังข้อมูล** ทรัพย์สินที่หายากที่สุดใน MT สำหรับภาษาที่มีทรัพยากรน้อยคือชุดทดสอบที่เชื่อถือได้ และค่าใช้จ่ายได้ถูกเปิดเผยไว้ดังนี้:

| เงินที่จ่ายไปได้อะไรบ้าง | ค่าใช้จ่ายที่เปิดเผย | เงินไปที่ไหน |
|--------------------|---------------|----------------|
| คลังข้อมูลเกณฑ์มาตรฐานสำหรับหนึ่งภาษา (รายการที่คัดกรองแล้ว 50–150 รายการ) | $2,500–6,000 CAD | เวลาของผู้พูดสองภาษาที่ $50–65/ชม. — เป็นรายการค่าใช้จ่ายที่ใหญ่ที่สุดอย่างจงใจ |
| รอบการตรวจสอบความถูกต้องของตัวชี้วัด (ผู้พูดสามคนตรวจสอบตัวชี้วัดอัตโนมัติเทียบกับวิจารณญาณของมนุษย์) | $1,475–1,920 CAD | งานตรวจสอบโดยผู้พูดที่ได้รับค่าตอบแทน |
| การตรวจสอบผลลัพธ์ของวิธีการ | $500–1,500 CAD | อัตราค่าตอบแทนรายชั่วโมงที่เปิดเผยแบบเดียวกัน |
| การนำภาษาเข้าสู่ระบบแบบเต็มรูปแบบ รวมทุกอย่าง | $3,350–8,500 CAD | ดู [Benchmark Specification §10](/docs/network/specifications/benchmark) |

ทรัพย์สินนี้จะคงอยู่ยาวนานกว่าเงินทุน: คลังข้อมูลเป็นของผู้สร้าง/ผู้ดูแล ไม่ใช่ของ Champollion — ลงทะเบียนเป็นข้อมูลเมตา [เนื้อหาไม่เคยถูกโฮสต์](/docs/network/sovereignty/registering-corpora) ภายใต้ใบอนุญาตและตัวเลือกช่องทางของผู้ดูแล สำหรับผู้ให้ทุนทางวิชาการ [Corpus Partnership Strategy](/docs/network/specifications/corpus-partnership) คือเวอร์ชันที่ปรับให้เหมาะกับรูปแบบของภาควิชาสำหรับช่องทางนี้

**ช่องทางที่ 2 — การสนับสนุนรางวัล** รางวัลแห่งความสำเร็จจะให้ทุนสำหรับ **ผลลัพธ์ ไม่ใช่ความพยายาม**: เงินจะถูกปล่อยออกมาก็ต่อเมื่อมีวิธีการที่สามารถผ่านเกณฑ์ที่กำหนดไว้และเป็นกลางต่อวิธีการได้อย่างชัดเจน โดยมีการตรวจสอบจากผู้พูดในชุมชนที่ได้รับค่าตอบแทนเป็นส่วนหนึ่งของการอ้างสิทธิ์ทุกครั้ง ตาม [Prize Specification](/docs/network/specifications/prizes) เงินทุนจะถูก **ถือครองโดยผู้สนับสนุน** — เงินจะอยู่กับองค์กรที่สนับสนุน หรือกับทรัสต์ของชุมชน หรือเอสโครว์ (escrow) บุคคลที่สามที่ผู้สนับสนุนกำหนด และ **ไม่เคยอยู่กับ Champollion** ซึ่งทำหน้าที่ประสานงานการวัดผลและไม่แตะต้องเงินใดๆ **ปัจจุบันยังไม่มีการถือครองเงินรางวัลใดๆ ในที่ใดเลย** หากไม่มีใครผ่านเกณฑ์ ก็จะไม่มีใครได้รับเงิน; รางวัลที่หมดอายุจะยังคงอยู่กับผู้สนับสนุน เพื่อนำไปใช้ในทางอื่นหรือถอนออกตามดุลยพินิจของพวกเขา วิธีการที่ชนะจะถูกโอนกรรมสิทธิ์ให้กับชุมชนภายใต้เงื่อนไขของรางวัล

สิ่งที่ผู้ให้ทุนสามารถวัดผลได้: คลังข้อมูลที่สร้างและลงทะเบียนภายใต้การควบคุมของผู้ดูแล; ชั่วโมงของผู้พูดที่ได้รับค่าตอบแทนซึ่งส่งมอบให้กับชุมชนภาษา; คู่ภาษาที่ครอบคลุมโดยเกณฑ์มาตรฐานสาธารณะที่เชื่อถือได้; วิธีการที่ถูกวัดผลและ (หากเงื่อนไขของรางวัลระบุไว้) ถูกโอนกรรมสิทธิ์ให้กับชุมชน

**สิ่งแรกที่ควรทำ:** อ่าน [How the Work Is Funded](/docs/network/sovereignty/economic-model) (ใช้เวลา 10 นาที โมเดลฉบับเต็ม); เลือกช่องทางใน [Get Involved — sponsors](/get-involved#sponsors) — งานคลังข้อมูล, รางวัล, หรือเครดิตการประมวลผล/API สำหรับ [คิวเกณฑ์มาตรฐานสาธารณะ](/contribute); จากนั้นพูดคุยกับเราที่ [info@champollion.dev](mailto:info@champollion.dev) หรือบน [public repository](https://github.com/gamedaysuits/Champollion/issues) เราจะตอบกลับพร้อมรายละเอียดเฉพาะเจาะจง รวมถึงส่วนที่ยังไม่ได้สร้างขึ้นด้วย

## สื่อมวลชน \{#press}

Champollion เป็นโปรเจกต์วิจัยที่ไม่ใช่เชิงพาณิชย์ ซึ่งสร้างการประเมินการแปลด้วยเครื่องที่เชื่อถือได้สำหรับทุกภาษา — เปิดเผยซอร์สโค้ดและใช้งานฟรีสำหรับวัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์ พร้อมด้วยระบบทดสอบการประเมินและระบบทะเบียนแบบโอเพนซอร์ส — เป็นโครงสร้างพื้นฐานสำหรับตอบคำถามหนึ่งอย่างตรงไปตรงมา: *การแปลด้วยเครื่องสำหรับภาษานี้ดีแค่ไหนกันแน่?* โปรเจกต์นี้เผยแพร่ระบบทะเบียนชุดทดสอบ กฎการให้คะแนน ระบบทดสอบที่รันสิ่งเหล่านี้ รวมถึงกระดานผู้นำและแผนที่สาธารณะที่แสดงว่าใครสามารถแปลอะไรได้และแปลได้ดีเพียงใด — ยินดีต้อนรับทุกวิธีการ ทั้งมนุษย์และเครื่องจักร โดยตัดสินด้วยกฎแบบเปิดเดียวกัน ในที่ที่ชุมชนถือครองข้อมูลภาษา พวกเขาคือผู้กุมกุญแจสำคัญ

สิ่งที่ Champollion **ไม่ใช่**: ไม่ใช่เชิงพาณิชย์ (ไม่มีผลิตภัณฑ์ ไม่มี API แบบเสียเงิน ไม่มีการคิดค่าบริการตามการใช้งาน ไม่มีส่วนแบ่งรายได้ ไม่มีเงินทุนร่วมลงทุน — [ให้ทุนสนับสนุนตนเองโดยผู้ก่อตั้ง](/docs/network/sovereignty/economic-model)); ไม่ใช่ผู้เก็บเกี่ยวข้อมูล (เนื้อหาคลังข้อมูล **ไม่เคยถูกโฮสต์**; ระบบทะเบียนเก็บเฉพาะการ์ดข้อมูลเมตาที่ตรึงด้วย SHA และคลังข้อมูลของชุมชนยังคงเป็นทรัพย์สินของผู้ดูแลอย่างสมบูรณ์); ไม่ใช่ผลิตภัณฑ์แปลภาษาด้วย AI (Champollion วัดคุณภาพการแปล; CLI ที่มาคู่กันเป็นเครื่องมือสำหรับนักพัฒนา); และยังไม่เสร็จสมบูรณ์ — กระดานผู้นำเปิดใช้งานแล้วแต่ยังใหม่อยู่ โปรแกรมสำหรับชุมชนกำลังอยู่ในระหว่างการจัดตั้ง และเราอยากให้ถูกอ้างอิงอย่างถูกต้องว่าอยู่ในช่วงเริ่มต้น มากกว่าที่จะถูกยกย่องเกินจริงว่าก้าวหน้าไปไกลแล้ว

ข้อความมาตรฐาน (Boilerplate):

> Champollion เป็นโปรเจกต์วิจัยที่ไม่ใช่เชิงพาณิชย์ ซึ่งสร้างการประเมินการแปลด้วยเครื่องที่เชื่อถือได้สำหรับทุกภาษา — เปิดเผยซอร์สโค้ดและใช้งานฟรีสำหรับวัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์ พร้อมด้วยระบบทดสอบการประเมินแบบโอเพนซอร์สและระบบทะเบียนที่ใช้ร่วมกัน โปรเจกต์นี้ดูแลดัชนีภาษาที่อ้างอิง <SSOTCount field="catalogLanguageCount" /> ภาษา, ระบบทะเบียนชุดข้อมูลการประเมิน <SSOTCount field="registryDatasetCount" /> ชุด (เนื้อหาคลังข้อมูลไม่เคยถูกโฮสต์), และระบบทดสอบแบบเปิดรวมถึงกระดานผู้นำที่วิธีการแปลใดๆ — ไม่ว่าจะเป็นเครื่องจักรหรือมนุษย์ — จะถูกให้คะแนนภายใต้กฎที่เผยแพร่แบบเดียวกัน สร้างขึ้นร่วมกับชุมชนภาษา ไม่เคยดึงข้อมูล (scrape) มาจากพวกเขา: ชุมชนเป็นเจ้าของข้อมูลของตนเอง ชุดทดสอบของตนเอง และวิธีการใดๆ ที่ถูกโอนกรรมสิทธิ์ให้กับพวกเขา Champollion ก่อตั้งโดย Curtis Forbes และอยู่ที่ champollion.dev
