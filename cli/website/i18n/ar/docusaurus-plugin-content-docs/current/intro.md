# champollion

إطار عمل قابل للتخصيص بالكامل للتدويل (i18n). أمر واحد يترجم ملفات اللغات المحلية (locale files) لديك. ملف إعدادات واحد يتحكم في كل طريقة ونموذج وزوج لغوي. وإذا لم تكن الطرق المدمجة كافية — ابنِ طريقتك الخاصة، واختبر كفاءتها، ثم انشرها.

```bash
npx champollion sync
```

يكتشف champollion تلقائيًا ملفات اللغات المحلية وتنسيقها واللغات المستهدفة. يترجم ما هو مفقود، ويتخطى ما تم إنجازه، ويفحص كل نتيجة بحثًا عن أي مخرجات معيبة، ويكتب مخرجات سليمة. هذه هي نقطة البداية فحسب.

:::info[جزء من مشروع أكبر]

تُمثّل أداة السطر البرمجي (CLI) هذه جانب النشر والتطبيق في **Champollion** — وهي بنية تحتية
تقيس جودة الترجمة الآلية للغات لا يقيسها أحد غيرها،
وتنشر ما تتوصل إليه من نتائج. يبني جانب القياس مجموعات اختبارات تقييمية
وخريطة عامة توضح من يستطيع ترجمة ماذا، وبأي مستوى من الجودة، وعلى أي أنواع من النصوص؛
في حين تُعد أداة CLI المكان الذي تتحول فيه الطريقة المُثبتة فعاليتها إلى شيء يمكنك تشغيله عمليًا.

هناك قاعدة واحدة تحكم كل شيء: تُعامَل البيانات اللغوية معاملة البيانات الحيوية، لذا فإن
الأشخاص الذين يقدمون متنًا لغويًا (corpus) يملكون مفاتيح التحكم فيه وفي أي شيء يُقاس
بناءً عليه. تجد الصورة الكاملة — ما هو موجود، وما هي القواعد، وموضعك في هذا النظام — في صفحة [ما هو Champollion](/docs/what-is-champollion)، بينما يقع جانب القياس تحت قسم [الشبكة](/docs/network/).

:::

## لمَ لا تكتفي ببرمجة سكربت بنفسك؟

يمكنك كتابة حلقة تكرار (loop) سريعة تستدعي Google Translate لكل مفتاح. هذا ما يفعله معظم المطورين — ويتطلب ذلك حوالي 30 سطرًا. ولكن ها هي مواضع القصور:

- **غياب ميزة اكتشاف التغييرات.** إذا قمت بتحديث نص باللغة الإنجليزية — ستبقى الترجمة قديمة دون تحديث إلى الأبد. يتتبع champollion كل قيمة مصدرية باستخدام تجزئات SHA-256، ويعيد ترجمة ما تغير فقط.
- **غياب تجميع الطلبات (Batching).** إجراء استدعاء API واحد لكل مفتاح يعني أن 200 مفتاح = 200 طلب ذهاب وإياب. يقوم champollion بتجميع الطلبات بذكاء (قابل للإعداد، القيمة الافتراضية 80 مفتاحًا/دفعة لنماذج LLM، و128 لخدمة Google).
- **غياب التخزين المؤقت (Caching).** تؤدي كل عملية مزامنة إلى إعادة ترجمة كل شيء. تخزن ذاكرة الترجمة (Translation Memory) في champollion الترجمات مؤقتًا حسب النص المصدر + اللغة المحلية + الطريقة — وإعادة تشغيل المزامنة بعد تغيير مفتاح واحد تترجم ذلك المفتاح فقط، وليس الملف بأكمله.
- **غياب بوابة فحص الجودة.** قد تهلوس الترجمة الآلية، أو تعيد تكرار النص المصدر، أو تُخرج نصوصًا بنظام كتابة (script) خاطئ. يفحص champollion كل ترجمة قبل كتابتها — حيث يتم رصد المخرجات الفارغة، وتكرار المصدر، وحلقات التكرار، والتضخم المفرط في الطول، والمحتوى المحذوف، ونظام الكتابة الخاطئ ورفضها جميعًا. ترصد البوابة المخرجات المعيبة، وليس المعنى الخاطئ.
- **غياب إدراك التنسيقات.** هل سكرِبتك مخصص فقط لتنسيق JSON؟ يتعامل champollion مع JSON وTOML وYAML وHugo Markdown (البيانات الوصفية frontmatter + المتن) مع ميزة الاكتشاف التلقائي.
- **انعدام التحكم في الطرق.** يُطبّق السكربت الطريقة نفسها على كل زوج لغوي. يتيح لك champollion استخدام Google Translate للفرنسية، ونموذج لغوي كبير (LLM) لليابانية، ومسار معالجة مخصص مستضاف لدى المجتمع للغة Cree — كل ذلك ضمن ملف الإعدادات نفسه.

إن champollion هو النسخة الجاهزة للإنتاج من ذلك السكربت.

## ما الذي يجعله مختلفًا

### كل طريقة هي إضافة برمجية (Plugin)

طريقة الترجمة **قابلة للإعداد لكل زوج لغوي على حدة**. اجمع بين Google Translate ونماذج LLM والمطالبات الموجَّهة (coached prompts) وواجهات API المخصصة في المشروع نفسه:

```json title="champollion.config.json"
{
  "version": 3,
  "pairs": {
    "en:fr": { "method": "google-translate" },
    "en:ja": { "method": "llm", "model": "google/gemini-3.1-pro-preview" },
    "en:crk": { "method": "llm-coached" }
  }
}
```

تحصل الفرنسية على Google Translate (سريع واقتصادي). وتحصل اليابانية على نموذج LLM رائد (دقيق في الفروق اللغوية الدقيقة). وتحصل لغة Plains Cree على نموذج LLM موجَّه بقواعد النحو والمعجم الذي توفره أنت. كل ذلك باستخدام أمر `sync` نفسه. وبوابة الجودة نفسها. وأداة CLI نفسها.

### استكشف ما يُجدي نفعًا

هل تعتقد أن طريقتك قادرة على الترجمة من الإنجليزية إلى الإسبانية؟ أو من التركية إلى الأذربيجانية؟ أو من الإنجليزية إلى Cree؟

**ابنِها واختبرها.** تقيس [بيئة التقييم الاختباري (eval harness)](/docs/network/specifications/harness) المصاحبة أداء أي طريقة ترجمة بدرجات تقييم قابلة لإعادة الإنتاج وموثقة ببصمة رقمية. وتسجل [لوحة المتصدرين](/leaderboard) كل عملية تشغيل منشورة، ليتسنى للجميع معرفة ما يُثبت فعاليته.

تتشارك بيئة التقييم وأداة CLI الإنتاجية واجهة الإضافات البرمجية نفسها. وأي طريقة تحقق نتائج جيدة في بيئة التقييم يمكن استخدامها في بيئة الإنتاج — شريطة موافقة المجتمع الذي تخدم طريقته لغته. وبالنسبة للغات الشعوب الأصلية واللغات شحيحة الموارد (low-resource languages)، فإن تلك الموافقة أمر جوهري. راجع [سيادة البيانات](/docs/network/sovereignty/data-sovereignty).

```bash
# Benchmark a method against a real, non-bundled eval corpus
# (GlobalVoices amh->fra, 945 sentences, fetched from source on first run)
python3 -m pip install mt-eval-harness
export OPENROUTER_API_KEY=sk-or-...   # any OpenRouter-proxied model works
mt-eval run --corpus eval-amh-fra-globalvoices-test-v1 --model google/gemini-3.1-pro-preview --yes

# Use it locally
npx champollion sync
```

الإضافة البرمجية نفسها. صِلها واختبرها.

### مجموعة الأدوات الكاملة

ليس champollion مجرد أداة `sync`، بل هو مسار عمل متكامل للتدويل (i18n):

| الأمر | وظيفته |
|---------|-------------|
| `sync` | ترجمة المفاتيح المفقودة وتلك التي عفا عليها الزمن (مع التحقق بعد المزامنة) |
| `watch` | مزامنة تلقائية عند تغير الملف المصدر لديك |
| `lint` | فحص الشيفرة البرمجية المصدرية بحثًا عن النصوص الثابتة |
| `wrap` | تغليف النصوص الثابتة تلقائيًا باستدعاءات `t()` |
| `audit` | إدراج جميع علامات الرجوع الاحتياطي `[EN]` من عمليات التشغيل السابقة |
| `verify` | التحقق من وجود الترجمات وصحتها (بوابة التحقق في مسار CI) |
| `integrity` | اكتشاف تلف العناصر البديلة، ومشاكل الترميز، واكتمال صيغ الجمع في ICU |
| `seo` | إنشاء وسوم hreflang، وخرائط المواقع، ومخطط JSON-LD |
| `status` | عرض إعدادات الأزواج اللغوية والإضافات البرمجية ونتائج القياس المعياري |
| `provenance` | تدقيق ترخيص موارد الترجمة |
| `plugin` | تثبيت الإضافات البرمجية الخاصة بالطرق وإزالتها وإدراجها |
| `fonts` | تنزيل خطوط الويب لمحولات خطوط PUA |
| `tm` | إدارة الذاكرة المؤقتة لذاكرة الترجمة (الإحصائيات، والمسح، وبحسب كل لغة محلية) |
| `xliff` | تصدير واستيراد ملفات XLIFF 1.2 لمراجعة المترجمين المحترفين |

تُشكل أربعة من هذه الأوامر — `lint`، و`sync`، و`verify`، و`audit` — مسار عمل للتكامل المستمر (CI pipeline) يرصد النصوص الثابتة، ويترجمها، ويتحقق من صحتها، ويوقف عملية البناء إذا كانت أي لغة محلية غير مكتملة.

## الشبكة

تُعد [لوحة متصدري الطرق](/leaderboard) بمثابة لوحة النتائج — فهي مباشرة وعامة ومفتوحة للمشاركات. وتُوثَّق كل مشاركة ببصمة رقمية مرتبطة بإيداع Git، ومحددة بإصدار طقم بيانات معين، ويتم تقييمها بواسطة بيئة التقييم نفسها. والمشاركة متاحة للجميع.

**ما الذي يمكنك بناؤه؟** تستقبل بيئة التقييم بيانات بتنسيق JSON. وتأخذ الإضافات البرمجية بيانات بتنسيق JSON. وبالتالي يمكن اختبار أي طريقة تُنتج بيانات بتنسيق JSON:

| الأسلوب | مثال |
|----------|---------|
| **نموذج LLM موجَّه** | حقن القواعد النحوية والمعاجم في موجه نموذج رائد |
| **نموذج مضبوط بدقة** | تدريب نموذج مفتوح على نصوص متوازية — شريطة ألا تكون بيانات التقييم |
| **مسار عمل مضبوط بـ FST** | يولد نموذج LLM النص ← يتحقق محول الحالات المنتهية (FST) من الصرف ← إعادة المحاولة |
| **سلسلة نماذج** | يضع النموذج (أ) المسودة الأولى ← يحرر النموذج (ب) بعد الترجمة ← يقيّم النموذج (ج) النتيجة |
| **معجم + LLM** | فرض مصطلحات معروفة من المعجم، وترك الباقي ليتولاه نموذج LLM |
| **خوارزميات تطورية** | توليد خيارات متعددة، وتقييمها، وتعديل أفضلها، ثم التكرار |
| **ترجمة جزئية** | ترجمة عينة يدويًا، وإثبات تطابق نموذج LLM معها، ثم ترجمة الباقي تلقائيًا |

اضبط النماذج بدقة. وانشر خوارزميات تطورية. واختبر إجابات الطلاب في امتحانات اللغة. وابنِ جداول بحث. واربط ثلاثة نماذج في سلسلة واحدة. طالما أن طريقتك تُخرج بيانات بتنسيق JSON، فإن بيئة التقييم ستمنحها الدرجات وإطار العمل سيقوم بتشغيلها.

:::danger[القاعدة الوحيدة]
**لا تدرب النموذج على بيانات التقييم.** سيتم استبعاد أي طريقة تعرضت لمجموعة بيانات الاختبار القياسي. يمكنك إجراء الضبط الدقيق على أي شيء تريده، باستثناء مجموعة بيانات الاختبار.
:::

هذه دعوة مفتوحة. إذا كنت تعمل على لغة شحيحة الموارد — كباحث، أو فرد من أفراد المجتمع، أو طالب، أو مجرد شخص مهتم — فابنِ طريقة ترجمة، وشغّل بيئة التقييم، وعزز الشبكة لخدمة الجميع. لا تزال المشكلة قائمة دون حل؛ ولكن البنية التحتية أصبحت متوفرة هنا، ومفتوحة للجميع.
