# champollion للمؤسسات

يقوم فريقك بترجمة المحتوى بانتظام. لديك مجموعة من ملفات اللغات (locale files)، ومسار تكامل مستمر (CI pipeline)، وعملية تتضمن على الأرجح قيام شخص ما بتشغيل Google Translate يدويًا، ونسخ النتائج إلى ملفات JSON، وتمني الأفضل. أو أنك تدفع مقابل منصة إدارة ترجمة (TMS) حيث تكون مقيدًا بمحرك ترجمة خاص بمورد واحد.

يمنحك champollion خيارًا أكثر هدوءًا: اختر الطريقة المناسبة لكل لغة — آلية كانت أم بشرية — وقم بتشغيلها جميعًا من خلال أمر واحد.

## لماذا تستخدم الفرق champollion

1. **اختيار الطريقة المناسبة لكل لغة** — آلية أو بشرية، وليس ما يفرضه المورد كخيار افتراضي
2. **النشر بأمر واحد** — يقوم `npx champollion sync` بترجمة كل لغة، وكل تنسيق، في كل مرة
3. **تبديل الطرق دون تغيير الكود** — تغيير في الإعدادات، وليس عملية ترحيل (migration)
4. **امتلاك مسار العمل الخاص بك** — لا يوجد تقييد بمورد معين، ولا لوحات تحكم شهرية، ولا حسابات

```json title="champollion.config.json"
{
  "version": 3,
  "pairs": {
    "en:fr": { "method": "deepl" },
    "en:ja": { "method": "llm", "model": "google/gemini-2.5-pro" },
    "en:de": { "method": "google-translate" },
    "en:ko": { "method": "llm", "register": "polite-haeyo" },
    "en:es": { "method": "api", "endpoint": "https://review.your-lsp.example/mtpe" },
    "en:crk": { "methodPlugin": "crk-coached-v3" }
  }
}
```

تحصل الفرنسية على DeepL (يفضل فريقك طلاقته الأوروبية). وتحصل اليابانية على نموذج لغوي كبير (LLM) متطور. وتحصل الألمانية على Google Translate (سريع، ورخيص، وجيد بما يكفي). وتحصل الكورية على نموذج لغوي كبير (LLM) ذو أسلوب رسمي. وتُوجَّه الإسبانية إلى خدمة ترجمة بشرية احترافية / تحرير لاحق للترجمة الآلية (MTPE) عبر طريقة `api` — الترجمة البشرية هنا هي طريقة من الدرجة الأولى، وليست مجرد إضافة ثانوية. وتحصل لغة Plains Cree على مكون إضافي (plugin) موجه ومبني ومملوك من قِبل المجتمع.

**نفس الأمر. نفس مسار التكامل المستمر (CI pipeline). طرق مختلفة لكل زوج لغوي — بشرية أو آلية. ملف إعدادات واحد.**

:::note[طرق لغات المجتمع تتمتع بالسيادة]
المكون الإضافي للغة Plains Cree المذكور أعلاه ليس مجرد "طريقة أخرى". الطرق الخاصة بلغات السكان الأصليين ولغات المجتمعات الأخرى هي **مملوكة ومُدارة من قِبل المجتمع**: يمتلك المجتمع مفاتيح البيانات التي تقف خلفها، ويحدد شروط الاستخدام، ويتم استبعاد أي مدونة نصوص (corpus) أو طريقة غير تجارية (NC) من المسارات التجارية افتراضيًا. إذا كان استخدامك تجاريًا، فتحقق من ترخيص الطريقة قبل النشر. راجع [سيادة البيانات](/docs/network/sovereignty/data-sovereignty).
:::

## مسار العمل: من لوحة الصدارة (Leaderboard) إلى النشر

:::tip[يأتي `champollion leaderboard` مدمجًا مع واجهة سطر الأوامر (CLI)]
يعمل مسار العمل أدناه على أمر `champollion leaderboard` — تصفح لوحة صدارة [الشبكة](/arena) من الطرفية (terminal) الخاصة بك وقم بتثبيت المكون الإضافي للطريقة مباشرة منها. راجع [مرجع واجهة سطر الأوامر (CLI)](/docs/reference/cli#leaderboard) لمعرفة كل الخيارات المتاحة.
:::

[الشبكة](/arena) هي المكان الذي يتم فيه قياس أداء طرق الترجمة باستخدام تقييمات قابلة لإعادة الإنتاج وموثقة ببصمة رقمية. تحصل كل طريقة على درجة مركبة عبر مقاييس متعددة (chrF++، والتطابق التام، وقبول FST، والتقييم الدلالي). تتتبع لوحة الصدارة كل عملية إرسال.

مسار العمل:

```bash
# Browse the leaderboard from your terminal
npx champollion leaderboard --pair en:crk

# Output:
# ┌──────┬───────────────────────┬────────────┬──────────┬───────────┐
# │ Rank │ Method                │ Model      │ chrF++   │ Composite │
# ├──────┼───────────────────────┼────────────┼──────────┼───────────┤
# │  1   │ crk-coached-v3        │ gemini-2.5 │ 43.2     │ 0.67      │
# │  2   │ fst-gated-pipeline    │ gpt-4o     │ 41.8     │ 0.63      │
# │  3   │ prompt-baseline       │ claude-4   │ 38.1     │ 0.55      │
# └──────┴───────────────────────┴────────────┴──────────┴───────────┘

# Install the method that fits as a plugin
npx champollion leaderboard --install crk-coached-v3

# Use it
npx champollion sync
```

*للتوضيح فقط — صفوف لوحة الصدارة أعلاه هي مجرد تخطيط كمثال. اللوحة مفتوحة حاليًا لتلقي المشاركات ولا تحتوي على أي عمليات تشغيل منشورة بعد.*

**أنت لا تبني الطريقة. ولا تدرب النموذج. بل تختار الطريقة التي تناسب مجالك، وميزانيتك، وترخيصك — سواء كانت بشرية أو آلية — وتقوم بنشرها.** وإذا ظهرت طريقة أكثر ملاءمة في الشهر القادم، يمكنك تبديلها بأمر واحد.

## ما هو متاح اليوم

الجسر الرابط بين لوحة الصدارة وواجهة سطر الأوامر (CLI) قيد التطوير. إليك ما يعمل حاليًا:

### الطرق المدمجة (لا حاجة لمكونات إضافية)

| الطريقة | الأفضل لـ | التكلفة |
|--------|----------|------|
| `llm` (الافتراضي) | التركيز على الجودة، أي لغة | لكل رمز (Per-token) عبر OpenRouter |
| `gemini` | الجودة + باقة مجانية | مجاني (محدود)، ثم لكل رمز |
| `google-translate` | السرعة + الحجم | 20 دولارًا / مليون حرف |
| `deepl` | اللغات الأوروبية | 25 دولارًا / مليون حرف |
| `llm-coached` | اللغات التي تحتوي على بيانات توجيهية (coaching data) | لكل رمز عبر OpenRouter |
| `api` | الطرق المخصصة/المستضافة من قِبل المجتمع | استضافة ذاتية (Self-hosted) |

### طرق المكونات الإضافية (تُثبت بشكل منفصل)

يمكن للمكونات الإضافية المخصصة تغليف أي منطق ترجمة — نموذج مُحسّن (fine-tuned model)، أو مسار عمل مقيد بـ FST، أو واجهة برمجة تطبيقات (API) مجتمعية، أو أي شيء آخر ينتج ملفات JSON. راجع [بناء مكون إضافي](/docs/tutorials/build-a-plugin).

## مسار عمل المؤسسات

### 1. تقييم الجودة الحالية

```bash
# See what you're getting today
npx champollion status

# Output shows: method per pair, cache hit rate, quality gate stats
```

### 2. تشغيل منصة التقييم (eval harness) على المرشحين

تتيح لك [منصة التقييم](/docs/network/specifications/harness) قياس أداء طرق متعددة مقابل نفس مجموعة البيانات. قم بإجراء مسح شامل، وقارن الدرجات، واختر الفائزين:

```bash
# In the eval harness repo
python -m mt_eval_harness.run \
  --methods coached-v3 baseline prompt-tuned \
  --dataset data/your-corpus.json
```

### 3. تكوين الفائزين لكل زوج لغوي

قم بتحديث إعداداتك لاستخدام أفضل طريقة لكل زوج لغوي. اللغات المختلفة لها طرق مفضلة مختلفة — وهذا هو بيت القصيد.

### 4. الدمج في مسار CI/CD

```bash
# In your CI pipeline
npx champollion lint        # Catch hardcoded strings
npx champollion sync        # Translate what changed
npx champollion audit       # Fail if any locale is incomplete
npx champollion integrity   # Validate placeholder consistency
```

ثلاثة أوامر. صفر ترجمة يدوية. يلتقط مسار العمل السلاسل النصية المضمنة (hardcoded strings)، ويترجمها باستخدام الطرق التي اخترتها، ويوقف عملية البناء (fails the build) إذا كان هناك أي شيء مفقود أو تالف.

### 5. المراجعة الاحترافية (اختياري)

للمحتوى عالي الأهمية، قم بالتصدير إلى تنسيق XLIFF للمراجعة البشرية:

```bash
npx champollion xliff export --locale ja --output translations.xliff
# → Send to your translation agency
# → Import corrections back:
npx champollion xliff import translations.xliff
```

ترجم الجزء الأكبر آليًا. وراجع المسارات الحرجة بشريًا. ادفع مقابل وقت البشر فقط حيثما يكون ذلك ضروريًا.

## نموذج التكلفة

لا يحتوي champollion على **أي اشتراكات أو تسعير لكل مستخدم (per-seat)**. واجهة سطر الأوامر (CLI) متاحة المصدر بموجب ترخيص PolyForm Noncommercial 1.0.0 — وهي مجانية للاستخدام غير التجاري (الأبحاث، والتعليم، والعمل المجتمعي)؛ أما الاستخدام التجاري فيتطلب إذنًا، لذا [تحدث إلينا](/get-involved) أولاً. بخلاف ذلك، أنت تدفع فقط مقابل استدعاءات واجهة برمجة تطبيقات (API) الترجمة:

| الحجم | Google Translate | نموذج لغوي كبير (Gemini Flash) | نموذج لغوي كبير (GPT-4o) |
|--------|-----------------|---------------------|---------------|
| 1,000 مفتاح × 5 لغات | ~0.50 دولار | ~0.30 دولار (باقة مجانية) | ~2.00 دولار |
| 10,000 مفتاح × 15 لغة | ~15 دولارًا | ~8 دولارات | ~60 دولارًا |
| 50,000 مفتاح × 30 لغة | ~75 دولارًا | ~40 دولارًا | ~300 دولار |

ذاكرة الترجمة (Translation Memory) تعني أنك تدفع فقط مقابل **المفاتيح المتغيرة** في عمليات المزامنة اللاحقة. إذا قمت بتحديث 10 سلاسل نصية من أصل 10,000، فإنك تدفع مقابل 10 ترجمات، وليس 10,000.

## مقارنة مع منصات إدارة الترجمة (TMS)

| | champollion | Crowdin / Phrase / Locize |
|---|---|---|
| **التسعير** | مجاني للاستخدام غير التجاري (التجاري بإذن) + تكاليف API | 50–500 دولار/شهر + لكل مستخدم |
| **التقييد بمورد (Vendor lock-in)** | لا يوجد — بدّل المزودين من الإعدادات | عالٍ — البيانات في سحابتهم |
| **اختيار الطريقة** | أي مزود، أي نموذج، لكل زوج لغوي | ما يقدمونه فقط |
| **CI/CD** | من الدرجة الأولى (`lint → sync → audit`) | مكون إضافي/خطاف ويب (webhook) |
| **الطرق المخصصة** | نظام مكونات إضافية، مكونات إضافية مجتمعية | غير مدعوم |
| **بوابة الجودة (Quality gate)** | مدمجة (نص خاطئ، صدى، طول) | متفاوت |
| **استضافة ذاتية** | نعم (LibreTranslate، واجهة برمجة تطبيقات مخصصة) | لا |

راجع [المقارنة الكاملة](/docs/guides/comparison) للحصول على التفاصيل.
