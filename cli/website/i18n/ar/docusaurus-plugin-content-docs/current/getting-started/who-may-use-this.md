# من يحق له استخدام هذا

لا تشترك حزم Champollion في رخصة واحدة. توضح هذه الصفحة، بعبارات مبسطة، الفئات المشمولة بكل رخصة منها.

**هذا ملخص ولا يُعد مشورة قانونية؛ فنص الرخصة هو المرجع الملزم.** يتوفر رابط كل رخصة في الجدول أدناه، كما تأتي مرفقة مع الحزمة الخاصة بها.

## الحزم ورخصها

| الحزمة | ماهيتها | الرخصة |
|---|---|---|
| `champollion` (npm) | أداة CLI التي تترجم ملفات اللغات الخاصة بك | [PolyForm Noncommercial 1.0.0](https://github.com/gamedaysuits/Champollion/blob/main/cli/LICENSE) |
| `champollion-mcp-server` (npm) | خادم MCP الذي يتيح لوكلاء الذكاء الاصطناعي هذه الأدوات | [PolyForm Noncommercial 1.0.0](https://github.com/gamedaysuits/Champollion/blob/main/mcp-server/LICENSE) |
| `nmt-forge` | حزمة تدريب النماذج | [PolyForm Noncommercial 1.0.0](https://github.com/gamedaysuits/Champollion/blob/main/forge/LICENSE) |
| `mt-eval-harness` (PyPI؛ أمر `mt-eval`) | بيئة التقييم | [AGPL-3.0-or-later](https://github.com/gamedaysuits/Champollion/blob/main/arena/LICENSE)، مع [استثناء للإضافات](https://github.com/gamedaysuits/Champollion/blob/main/arena/LICENSE-EXCEPTION.md) |
| `champollion-lyss` (PyPI) | إضافة معايير التقييم للغة كري السهول (Plains Cree) | رخصة مؤقتة خاصة بها: الاستخدام بإذن مسبق فقط ([على PyPI](https://pypi.org/project/champollion-lyss/)) |

تخضع سجلات البيانات (`shared/`) وترحيلات قاعدة البيانات (`mt-eval-arena/`) في [المستودع](https://github.com/gamedaysuits/Champollion) لرخصة Apache-2.0.

## أداة CLI وخادم MCP وnmt-forge

تخضع هذه الحزم الثلاث لرخصة PolyForm Noncommercial License 1.0.0. يحق لك استخدامها وتعديلها ومشاركتها لأي **غرض غير تجاري**. وتحدد الرخصة نفسها تلك الأغراض بالتفصيل، حيث يفصل بندان منها في أغلب الحالات:

> **الاستخدامات الشخصية.** يُعد الاستخدام الشخصي لأغراض البحث والتجريب والاختبار لصالح المعرفة العامة، أو للدراسة الشخصية، أو الترفيه الخاص، أو مشاريع الهواة، أو الممارسات غير الاحترافية، أو الشعائر الدينية، دون أي تطبيق تجاري متوقع، استخداماً لغرض مصرح به.

> **المنظمات غير التجارية.** يُعد الاستخدام من قِبل أي منظمة خيرية، أو مؤسسة تعليمية، أو منظمة أبحاث عامة، أو منظمة معنية بالسلامة العامة أو الصحة، أو منظمة لحماية البيئة، أو مؤسسة حكومية، استخداماً لغرض مصرح به بغض النظر عن مصدر التمويل أو الالتزامات المترتبة على هذا التمويل.

بالنسبة لمنظمة تنتمي لإحدى هذه الفئات، لا تؤثر طريقة تمويلها على هذا التصريح، فالنص ينص صراحةً على: "بغض النظر عن مصدر التمويل".

| الجهة | مشمولة بالرخصة؟ | السبب |
|---|---|---|
| مدرسة تترجم تطبيقها أو نشرتها الإخبارية | ✓ نعم | مؤسسة تعليمية |
| مستشفى عام أو عيادة صحية عامة تترجم إرشادات المرضى | ✓ نعم | منظمة سلامة عامة أو صحة |
| مؤسسة خيرية تترجم موقعها الإلكتروني | ✓ نعم | منظمة خيرية |
| مكتب حكومي أو معهد أبحاث عام | ✓ نعم | مؤسسة حكومية أو منظمة أبحاث عامة |
| أنت، في مشروع شخصي أو بحثي دون أي تطبيق تجاري مستهدف | ✓ نعم | استخدام شخصي لأغراض البحث أو التجريب أو الاختبار أو الدراسة الخاصة أو ممارسة هواية |
| متجر يترجم واجهة متجره الإلكتروني | ✗ لا | يُعد منتج العمل التجاري الهادف للربح استخداماً تجارياً |
| عيادة خاصة هادفة للربح تترجم بوابة المرضى الخاصة بها | ✗ لا | يُعد منتج العمل التجاري الهادف للربح استخداماً تجارياً، كما أنها ليست منظمة صحية عامة |

الاستخدام لأغراض تجارية غير مشمول: فهذه الرخصة لا تمنح أي إذن بذلك.

## بيئة التقييم (`mt-eval-harness`)

تُعد بيئة التقييم مفتوحة المصدر بموجب رخصة جنو أفيرو العمومية، الإصدار 3 أو أي إصدار لاحق (AGPL-3.0-or-later). وتسمح رخصة AGPL بالاستخدام التجاري وفق شروطها الخاصة، ومن أبرزها:

- إذا قمت بتوزيع بيئة التقييم، سواء كانت معدلة أم لا، فيجب عليك توزيعها بموجب الرخصة نفسها مع إتاحة شفرتها المصدرية.
- إذا قمت بتعديل بيئة التقييم وأتحت للآخرين استخدامها عبر الشبكة، فيجب عليك توفير الشفرة المصدرية لإصدارك المعدل لهؤلاء المستخدمين (القسم 13، "التفاعل عبر الشبكة عن بُعد").

يتيح إذن منفصل ([LICENSE-EXCEPTION.md](https://github.com/gamedaysuits/Champollion/blob/main/arena/LICENSE-EXCEPTION.md)، بموجب القسم 7 من رخصة AGPL) لإضافات معايير التقييم الخاضعة لرخص أخرى العمل مع بيئة التقييم من خلال واجهة الإضافات العامة الخاصة بها. ولا يغير هذا الإذن رخصة بيئة التقييم نفسها.

## إضافة لغة كري السهول (`champollion-lyss`)

تخضع `champollion-lyss` لرخصة مؤقتة خاصة بها: لا يجوز استخدامها إلا بإذن كتابي. وعادةً ما يُمنح الإذن مجاناً لأغراض البحث غير التجاري، والتعليم، والمشاريع التي تعود بالنفع على المجتمع. ولا يُسمح بأي استخدام تجاري. وهي رخصة مؤقتة يُقصد استبدالها بشروط تُحدد من خلال حوكمة مجتمعية. ويتوفر نص الرخصة وإشعارها (NOTICE) داخل الحزمة.

## ما لا تغطيه هذه الرخص

تحتفظ خدمات الترجمة والنماذج ومجموعات النصوص (corpora) التي تستخدمها من خلال هذه الأدوات بشروطها الخاصة: شروط واجهة برمجة التطبيقات (API) الخاصة بالمزود، ورخصة النموذج، ورخصة مجموعة النصوص. تسجل بيئة التقييم رخصة كل مجموعة نصوص وتطبق قواعدها بشأن خدمات النماذج المصرح لها بالاطلاع عليها، إلا أن تلك الشروط يحددها أصحابها، وليس الرخص الموضحة في هذه الصفحة.
