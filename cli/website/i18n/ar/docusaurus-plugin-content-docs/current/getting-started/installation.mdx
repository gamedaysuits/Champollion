## الحصول على مفتاح API

يحتاج Champollion إلى واجهة خلفية للترجمة. اختر إحداها:

| المزود | متغير البيئة | الأنسب لـ |
|----------|---------------------|----------|
| **OpenRouter** (موصى به) | `OPENROUTER_API_KEY` | المشاريع الغنية بالمحتوى، وMarkdown، وأكثر من 200 نموذج |
| **Gemini** (الفئة المجانية) | `GEMINI_API_KEY` | البدء بدون تكلفة، وجودة جيدة |
| **OpenAI** | `OPENAI_API_KEY` | الوصول المباشر إلى GPT-4o |
| **Anthropic** | `ANTHROPIC_API_KEY` | الوصول المباشر إلى Claude، والنصوص الدقيقة |
| **DeepL** | `DEEPL_API_KEY` | اللغات الأوروبية، ودرجات الرسمية المضمنة |
| **Google Translate** | `GOOGLE_TRANSLATE_API_KEY` | أزواج المفتاح والقيمة ذات الحجم الكبير، و194 لغة |
| **Microsoft Translator** | `MICROSOFT_TRANSLATOR_API_KEY` | Azure، و135 لغة |
| **LibreTranslate** | `LIBRETRANSLATE_API_URL` | الاستضافة الذاتية، والأولوية للخصوصية |
| **Tilde MT** | `TILDE_API_KEY` | لغات البلطيق واللغات الأوروبية، واستضافة داخل الاتحاد الأوروبي |
| **Translated (Lara)** | `LARA_ACCESS_KEY_ID` + `LARA_ACCESS_KEY_SECRET` | الترجمة الآلية الاحترافية، و200 لغة |

<Tabs>
  <TabItem value="openrouter" label="OpenRouter (recommended)" default>

يوفر [OpenRouter](https://openrouter.ai) واجهة API موحدة لأكثر من 200 نموذج من نماذج LLM. تتوفر فئة مجانية.

```bash
# Sign up at https://openrouter.ai, then:
export OPENROUTER_API_KEY=sk-or-v1-...
```

أو أضفه إلى `.env.local`:

```bash
OPENROUTER_API_KEY=sk-or-v1-your-key-here
```

الأنسب لـ: المشاريع الغنية بالمحتوى، وترجمة Markdown، والمشاريع التي تتطلب حماية واعية بالمحتوى (كتل الأكواد البرمجية، والأكواد القصيرة، ومتغيرات الاستيفاء).

  </TabItem>
  <TabItem value="google" label="Google Translate">

```bash
export GOOGLE_TRANSLATE_API_KEY=...
```

الأنسب لـ: أزواج السلاسل النصية بنظام المفتاح والقيمة ذات الحجم الكبير (194 لغة). **لا يُوصى به** لمحتوى Markdown — لا يدرك Google Translate كتل الأكواد البرمجية، أو الأكواد القصيرة، أو متغيرات الاستيفاء.

:::tip[التعرف التلقائي الذكي]
إذا تم تعيين `GOOGLE_TRANSLATE_API_KEY` فقط (دون وجود مفتاح OpenRouter)، يتحول Champollion تلقائيًا إلى Google Translate. لا يلزم أي تغيير في الإعدادات.
:::

  </TabItem>
</Tabs>
