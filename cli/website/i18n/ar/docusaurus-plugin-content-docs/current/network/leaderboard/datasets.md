# مجموعات بيانات التقييم

> **ملخص تنفيذي.** تصف هذه الصفحة مجموعات بيانات التقييم المتاحة لاختبارات الأداء القياسية (benchmarking)، بما في ذلك مخطط مدخلات المكنز (corpus)، ومستويات الصعوبة (1–5)، ومتطلبات المصدر (provenance). يتضمن الفهرس **حوالي 4,700 مجموعة بيانات تقييم يتم جلبها من المصدر عبر 19 عائلة مكانز** (TICO-19، وIN22، وTatoeba، وGlobalVoices، وSMOL، وALT، وTurkic-x-WMT، وWMT24++، ومجموعات الاختبار الأعمى WMT newstest/General للأعوام 2014–2025، وMAFAND-MT، وNusaX، وNusaTranslation، وLoResMT، وAmericasNLP 2021، وNICT-SAP، وBSD، وMENYO-20k، وGamayun، وEdTeKLA) بالإضافة إلى FLORES+ — لا تتم استضافة *محتوى* المكانز هنا نهائيًا؛ فكل مجموعة بيانات عبارة عن بطاقة بيانات وصفية مثبتة بتجزئة sha يُعاد بناؤها بشكل حتمي من أرشيف المنبع المثبت الخاص بها. تم استبعاد **المسار غير التجاري / المخصص للبحث فقط** (Gamayun، وEdTeKLA، وMAFAND-MT، وNusaTranslation، وLoResMT، وAmericasNLP، وNICT-SAP، وBSD، وMENYO-20k، ومجموعات WMT للاستخدام البحثي) من أي مسار تجاري / جوائز / واجهات برمجة التطبيقات (API)؛ وداخل هذا المسار، فإن المكانز الخاضعة لمنح معدلة أو مخصصة أو غير محددة تكون بالإضافة إلى ذلك **مشروطة بالموافقة** — حيث يرفض التقييم عن بُعد عبر واجهات برمجة تطبيقات النماذج (model-API) العمل ما لم ينص نص الترخيص نفسه على منح إذن الاستخدام في التقييم (يُسجل كقرار صريح لكل مجموعة بيانات، كما هو الحال مع مجموعات WMT للاستخدام البحثي) أو يتم تسجيل إذن صاحب الحقوق في مدخلة مجموعة البيانات. تم تفصيل مجموعتي البيانات المرجعيتين المنسقتين بشريًا — EDTeKLA Dev v1 (لغة Plains Cree) وFLORES+ Devtest (870 زوجًا لغويًا مفهرسًا، بواقع 1,012 جملة لكل منها) — أدناه؛ ويتم ذكر التفصيل الكامل لعدد المدخلات الخاصة بـ EdTeKLA مرة واحدة، في [قسمها المخصص](#edtekla-development-set-v1).

مجموعات البيانات هي الأهداف الثابتة التي تعمل بيئة التقييم (harness) بمواجهتها. كل مجموعة بيانات عبارة عن ملف JSON يحتوي على أزواج مصدر←هدف مع مراجع معيارية ذهبية. تقوم بيئة التقييم باحتساب درجات مخرجات النموذج مقابل هذه المراجع — ولا تقوم بتعديلها أبدًا.

:::danger[لا تتدرب على بيانات التقييم]

⚠️ **مجموعات البيانات هذه مخصصة للتقييم فقط.** الطرق التي يتم تدريبها، أو ضبطها الدقيق، أو تضمين بيانات التقييم في مطالباتها ذات الأمثلة القليلة (few-shot-prompted)، أو تعريضها لبيانات التقييم بأي شكل آخر ستنتج درجات متضخمة بشكل مصطنع و**سيتم استبعادها من لوحة الصدارة.**

استخدم مكانز منفصلة للتدريب. يجب أن تظل مجموعات التقييم غير مرئية لنموذجك أثناء مرحلة التطوير.
:::

## تنسيق مجموعة البيانات {#dataset-format}

تتبع كل مجموعة بيانات نفس مخطط JSON:

```json
{
  "dataset": {
    "id": "dataset-slug",
    "version": "1.0",
    "language_pair": "EN→CRK",
    "description": "Human-readable description of the dataset",
    "source_language": "en",
    "target_language": "crk",
    "created": "2025-05-01",
    "license": "CC-BY-NC-4.0",
    "provenance": ["gold_standard", "textbook"]
  },
  "entries": [
    {
      "id": 1,
      "source": "Hello",
      "reference": "tânisi",
      "difficulty": 1,
      "provenance": "gold_standard",
      "register": "conversational",
      "context": "greeting",
      "notes": "Common greeting, SRO orthography"
    }
  ]
}
```

:::info[المخطط القياسي]
تحدد [مواصفات الاختبار القياسي](/docs/network/specifications/benchmark) المخطط القياسي للمكنز والمدخلات. توثق هذه الصفحة مجموعات البيانات المتاحة وكيفية إنشاء مجموعات جديدة.
:::

### كتلة `dataset` على المستوى الأعلى

| الحقل | النوع | الوصف |
|-------|------|-------------|
| `id` | `string` | معرّف مجموعة البيانات الفريد (المستخدم في بطاقات التشغيل ولوحة الصدارة) |
| `version` | `string` | الإصدار الدلالي. زيادة هذا الرقم تبطل مقارنات بطاقات التشغيل السابقة |
| `language_pair` | `string` | تسمية العرض (مثل، `EN→CRK`) |
| `description` | `string` | اختياري. ملخص مقروء للبشر |
| `source_language` | `string` | رمز BCP 47 للغة المصدر |
| `target_language` | `string` | رمز BCP 47 للغة الهدف |
| `created` | `string` | تاريخ الإنشاء بتنسيق ISO 8601 |
| `license` | `string` | معرّف ترخيص SPDX |
| `provenance` | `string[]` | قائمة بوسوم المصدر المستخدمة عبر المدخلات |

### حقول المدخلة

| الحقل | النوع | مطلوب | الوصف |
|-------|------|----------|-------------|
| `id` | `integer` | ✅ | معرّف مدخلة فريد داخل المكنز |
| `source` | `string` | ✅ | النص المصدر المراد ترجمته |
| `reference` | `string` | ✅ | الترجمة المرجعية المعيارية الذهبية |
| `difficulty` | `integer` | ✅ | مستوى الصعوبة من 1 إلى 5 (انظر أدناه) |
| `provenance` | `string` | ✅ | أصل هذه المدخلة (مثل، `gold_standard`، `textbook`، `elicited`) |
| `register` | `string` | ✅ | مستوى السجل اللغوي/الرسمية (مثل، `conversational`، `formal`، `ceremonial`) |
| `context` | `string` | ✅ | الوظيفة التواصلية (مثل، `greeting`، `declaration`، `instruction`) |
| `notes` | `string` | ❌ | سياق اختياري للمراجعين البشريين |
| `morphological_analysis` | `string` | ❌ | التحليل الصرفي المعياري الذهبي |
| `variant_class` | `string` | ❌ | تسمية فئة تجمع متغيرات الترجمة المقبولة |

## مجموعات البيانات المتاحة

يتضمن الفهرس **حوالي 4,700 مجموعة بيانات تقييم يتم جلبها من المصدر عبر 19 عائلة مكانز**، بالإضافة إلى مجموعتي البيانات المرجعيتين المنسقتين بشريًا (EDTeKLA + FLORES) المفصلتين أدناه — ليصل إجمالي السجل إلى **5,601 مجموعة بيانات** اعتبارًا من 2026-09-06. كل مكنز هو عبارة عن **بطاقة بيانات وصفية مثبتة بتجزئة sha** — حيث لا تتم استضافة محتوى المكنز هنا أبدًا؛ بل يُعاد بناؤه بشكل حتمي من أرشيف المنبع المثبت في وقت التقييم. تحمل جميع مجموعات البيانات `do_not_train`. تتفرع بطاقة المصدر الواحدة إلى العديد من مجموعات البيانات المخصصة لكل زوج لغوي، وبالتالي فإن إجمالي السجل يتجاوز بطاقات المصدر البالغ عددها ~1,417 بطاقة؛ تغذي مجموعات بيانات المسار المفتوح طابور المسح الشامل مباشرة؛ ويعمل المسار المخصص للبحث فقط عند الطلب حين يسمح ترخيصه بذلك بوضوح (المكانز الخاضعة لمنح معدلة/مخصصة/غير محددة تكون مشروطة بالموافقة للتقييم عن بُعد عبر واجهات برمجة تطبيقات النماذج).

:::

تم تفصيل مجموعات البيانات المرجعية أدناه؛ تتبع مكانز العائلات نفس مخطط JSON ومدرجة في سجل مجموعات البيانات.

:::note[الفهرس ليس لوحة مكتملة بالنتائج]
فهرس المكانز الضخم يمثل ما *يمكن* تقييم الطرق بمواجهته — وليس لوحة صدارة مليئة بالنتائج. اللوحة نفسها قيد التغذية الأولية؛ راجع [قواعد لوحة الصدارة](/docs/network/leaderboard/rules) و[القيود الصريحة](/docs/network/honest-limitations).
:::

### مجموعة تطوير EDTeKLA الإصدار 1 {#edtekla-development-set-v1}

أول مجموعة بيانات تقييم، أُنشئت للترجمة من الإنجليزية إلى لغة Plains Cree (باستخدام نظام الكتابة بالحروف اللاتينية القياسي SRO). تم إنشاؤها بواسطة [مجموعة أبحاث EdTeKLA](https://spaces.facsci.ualberta.ca/edtekla/) في جامعة ألبرتا.

| الخاصية | القيمة |
|----------|-------|
| **المعرّف** | `eval-eng-crk-edtekla-dev-v1` (و `eval-eng-crk-edtekla-textbook`) |
| **الإصدار** | `1.0` |
| **الزوج اللغوي** | EN ← CRK (لغة Plains Cree، نظام كتابة SRO) |
| **عدد المدخلات** | تقسيم تطوير يضم 436 مدخلة (`textbook_dev.json`). السلسلة: 589 سطرًا محاذيًا خامًا في المنبع ← 486 زوجًا صالحًا فريدًا بعد التسوية وإزالة التكرار (عدد مستنتج من Champollion) ← 436 للتطوير + 50 محجوزة (تقسيم Champollion الحتمي ذو البذرة 42 — تنشر EdTeKLA الملفات الخام، وليس التقسيم). ترفع مجموعة معيارية ذهبية منفصلة تضم 62 مدخلة (منسقة يدويًا، للأبحاث فقط، **ليست** من مواد EdTeKLA) إجمالي مجموعة تقييم Plains Cree المجمعة للمشروع إلى 548. |
| **توزيع الصعوبة** | سهل، متوسط، صعب |
| **المصدر** | `gold_standard` (تم التحقق منها بواسطة متحدثين أصليين)، `textbook` (مواد تعليمية منشورة) |
| **الترخيص** | [ترخيص CC BY-NC-SA المعدل الخاص بـ EdTeKLA](https://github.com/EdTeKLA/IndigenousLanguages_Corpora) (`LicenseRef-EdTeKLA-Modified-CC-BY-NC-SA-4.0` — محدد بسيادة اللغة؛ الكتاب التعليمي الأساسي يخضع لـ CC BY-NC-ND 4.0) — **خاضع للحجر**: مفهرس لكن لا يمكن تشغيله نهائيًا، وأي نتيجة تسجل ضده ترفضها قاعدة البيانات؛ مستبعد من لوحة الصدارة والجوائز ومسارات الاستخدام التجاري/واجهات برمجة التطبيقات (غير تجاري) |

> **هذا هو البيان القياسي المعتمد لأعداد مجموعة تقييم Plains Cree.** تشير الصفحات الأخرى بروابط إلى هنا بدلاً من إعادة ذكرها. الأرقام 486/436/50 مستنتجة بواسطة Champollion من ملفات المحاذاة الخام الخاصة بـ EdTeKLA (لا تنشر EdTeKLA نفسها أي أعداد أو تقسيمات)؛ تمتلك المجموعة المعيارية الذهبية المكونة من 62 مدخلة مصدرًا منفصلاً ليس تابعًا لـ EdTeKLA. يقترن العدد أعلاه دائمًا بمساره: تخضع EdTeKLA لترخيص CC BY-NC-SA معدل ومحدد بسيادة اللغة، وهي **مستبعدة من لوحة الصدارة والجوائز ومسار الاستخدام التجاري/واجهات برمجة التطبيقات**.

**ما يختبره:**

- التحيات الأساسية والعبارات الشائعة
- حيوية الأسماء والتمايز الغيابي (obviation)
- تصريف الأفعال عبر مختلف الضمائر والأزمنة
- التراكيب الدالة على المكان (locative)
- أنماط صيغ الملكية
- تراكيب الجمل المعقدة

:::tip[هيكل المكنز]
تنقسم المواد المشتقة من EdTeKLA إلى مجموعة تطوير عامة ومجموعة محجوزة (تقسيم Champollion لمحاذاة الكتاب التعليمي الخام من EdTeKLA — الأعداد موضحة في الجدول أعلاه). المجموعة المعيارية الذهبية المنفصلة المكونة من 62 مدخلة منسقة يدويًا من مصادر أخرى وليست جزءًا من مكنز EdTeKLA. تعد مجموعة البيانات الأصغر وعالية الجودة المزودة بمعايير ذهبية محققة أكثر فائدة من مجموعة كبيرة ومليئة بالشوائب — خاصة بالنسبة للغة منخفضة الموارد حيث غالبًا ما تكون الترجمات "القريبة بما فيه الكفاية" غير صالحة صرفيًا.
:::

## إنشاء مجموعة بيانات جديدة

لإنشاء مجموعة بيانات لزوج لغوي أو مجال جديد:

### 1. هيكلة ملف JSON

اتبع مخطط [تنسيق مجموعة البيانات](#dataset-format). يجب أن تحتوي كل مدخلة على `source`، و`reference`، و`difficulty`، و`provenance`، و`register`، و`context`.

### 2. تعيين معرّف فريد

استخدم نصًا تعريفيًا وصفيًا (slug): `{project}-{split}-v{version}` (مثل، `edtekla-dev-v1`، `quechua-test-v1`).

### 3. التحقق من المعايير الذهبية

يجب التحقق من كل قيمة لـ `reference` بواسطة متحدث بطلاقة أو الحصول عليها من مصدر منشور ومحكّم. المراجع المُنشأة آليًا تفسد الغرض من التقييم.

### 4. تحديد مستويات الصعوبة

عيّن لكل مدخلة مستوى صعوبة كعدد صحيح:

| المستوى | الوصف | أمثلة |
|------|-------------|----------|
| 1 — مفردات أساسية | كلمات مفردة، تحيات شائعة، أرقام | "hello" ← "tânisi" |
| 2 — جمل بسيطة | فاعل-فعل أو فاعل-فعل-مفعول (SVO)، زمن المضارع | "I see the dog" |
| 3 — تعقيد معتدل | زمن الماضي/المستقبل، صيغ الملكية، حيوية الاسم | "I saw his dog yesterday" |
| 4 — صرف معقد | التمايز الغيابي، المبني للمجهول، صيغ الربط التابعة | "the woman whose son went to the store" |
| 5 — متقدم | متعددة الجمل، سجل لغوي رسمي، طقسي، اصطلاحي | فقرة كاملة بنبرة مناسبة للسجل اللغوي |

### 5. وسم المصدر

يجب أن توضح كل مدخلة مصدرها. الوسوم الشائعة:

- `gold_standard` — تم التحقق منها بواسطة متحدثين بطلاقة
- `textbook` — من مواد تعليمية منشورة
- `elicited` — أُنتجت من خلال جلسات استخلاص لغوي منظمة
- `corpus` — مستخرجة من مكنز موازٍ

### 6. التحقق من صحة الملف

قم بتشغيل بيئة التقييم بمواجهة مجموعة بياناتك باستخدام أي نموذج للتحقق من أن ملف JSON سليم البنية وأن جميع الحقول المطلوبة موجودة:

```bash
mt-eval run --corpus path/to/your-dataset.json --dry-run
```

ستُظهر بيئة التقييم خطأً في حال وجود حقول مفقودة، أو مؤشرات مكررة، أو انتهاكات للمخطط.

### 7. الإرسال للإدراج

افتح طلب سحب (pull request) في [مستودع بيئة التقييم](https://github.com/gamedaysuits/Champollion) يضيف **بطاقة بيانات وصفية تُجلب من المصدر** — وهي عبارة عن مدخلة في السجل توجه بيئة التقييم إلى مصدر المنبع (أداة التحميل/عنوان URL، وتثبيت تجزئة SHA، والترخيص، والمصدر). **لا تقم بإيداع محتوى المكنز نفسه نهائيًا.** لا يستضيف Champollion أو يتتبع نصوص المكانز التابعة لجهات خارجية؛ إذ تقوم بيئة التقييم بجلب المراجع من مصدر المنبع أثناء وقت التشغيل وتقييم النتائج مقارنة بالبيانات المجلوبة حديثًا. تحقق محليًا أولاً (الخطوة 6)، ثم أرسل البطاقة فقط. أرفق توثيقًا لمنهجية التحقق الخاصة بك ومصادر المادة.

## FLORES+ Devtest

اختبار أداء قياسي متعدد اللغات واسع التغطية تتولى صيانته [مبادرة بيانات اللغات المفتوحة (OLDI)](https://huggingface.co/datasets/openlanguagedata/flores_plus). يُستخدم لمقارنات النماذج الرائدة المتعددة في Champollion.

| الخاصية | القيمة |
|----------|-------|
| **المعرّف** | بطاقة واحدة لكل زوج: `eval-flores-devtest-v1-<src>-<tgt>` (مثل `eval-flores-devtest-v1-amh-fra`) |
| **الأزواج اللغوية** | 870 زوجًا مفهرسًا وقابلاً للتشغيل (812 منها بين لغتين غير الإنجليزية) |
| **عدد المدخلات** | 1,012 جملة لكل زوج |
| **الترخيص** | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| **المصدر** | Meta FLORES-200، تتولى OLDI صيانته حاليًا — يُجلب من المصدر، مع تثبيت تجزئة SHA لكل زوج (لا يتم تتبع محتوى المكنز هنا نهائيًا) |
| **التلوث** | **مرتفع** — للمقارنات النسبية فقط، للاختبار / التوضيح فقط (انظر الملاحظة) |

:::warning[تلوث مرتفع — للمقارنات النسبية فقط، وليس معيارًا قياسيًا مطلقًا أبداً]
FLORES+ هي بيانات عامة تم جمعها من الويب ومن المرجح جدًا أن النماذج الرائدة قد اطلعت عليها بالفعل. يُشغل Champollion هذه البيانات في مسار **نسبي فقط**: يُستخدم لمقارنة الطرق وجهًا لوجه، ولكن **لا يتم الإبلاغ عنه أبدًا كدرجة جودة مطلقة**، و**لا يُستخدم أبدًا كحافة رابطة (chain edge)** على [خريطة الترجمة](https://champollion.dev).
إنه مخصص **للاختبار والتوضيح فقط**.
:::

:::danger[للتقييم فقط]
مجموعة FLORES+ مخصصة حصريًا للتقييم. يطلب المشرفون صراحةً **عدم استخدامها كبيانات تدريب**. تأكد من استبعاد محتوياتها من أي مكانز تدريبية.
:::
