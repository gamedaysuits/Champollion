# مجموعات بيانات التقييم

> **ملخص تنفيذي.** تصف هذه الصفحة مجموعات بيانات التقييم المتاحة لقياس الأداء، بما في ذلك مخطط إدخال المتن (corpus entry schema)، ومستويات الصعوبة (1-5)، ومتطلبات المصدر. يحتوي الكتالوج على **حوالي 4,700 مجموعة بيانات تقييم تُجلب من المصدر (fetch-from-source) عبر 19 عائلة متون** (TICO-19، وIN22، وTatoeba، وGlobalVoices، وSMOL، وALT، وTurkic-x-WMT، وWMT24++، ومجموعات WMT newstest/General العمياء 2014-2025، وMAFAND-MT، وNusaX، وNusaTranslation، وLoResMT، وAmericasNLP 2021، وNICT-SAP، وBSD، وMENYO-20k، وGamayun، وEdTeKLA) بالإضافة إلى FLORES+ — لا يتم استضافة *محتوى* المتن هنا أبدًا؛ فكل مجموعة بيانات عبارة عن بطاقة بيانات وصفية مثبتة بتجزئة (sha-pinned) يُعاد بناؤها بشكل حتمي من أرشيفها المثبت في المنبع (upstream). يُستبعد **مسار الاستخدام غير التجاري / البحثي فقط** (Gamayun، وEdTeKLA، وMAFAND-MT، وNusaTranslation، وLoResMT، وAmericasNLP، وNICT-SAP، وBSD، وMENYO-20k، ومجموعات WMT للاستخدام البحثي) من أي مسار تجاري / جوائز / واجهة برمجة تطبيقات (API)؛ وضمن هذا المسار، تكون المتون الخاضعة لتراخيص معدلة أو مخصصة أو غير معلنة **مقيدة بالموافقة (consent-gated)** بشكل إضافي — حيث يرفض التقييم عبر واجهة برمجة تطبيقات النموذج عن بُعد (remote model-API) التنفيذ ما لم يمنح نص الترخيص نفسه حق الاستخدام في التقييم (يُسجل كقرار صريح لكل مجموعة بيانات، كما هو الحال مع مجموعات WMT للاستخدام البحثي) أو يُسجل إذن صاحب الحقوق في إدخال مجموعة البيانات. تم تفصيل مجموعتي البيانات المرجعيتين المنسقتين بشريًا — EDTeKLA Dev v1 (لغة Plains Cree) وFLORES+ Devtest (870 زوجًا لغويًا مفهرسًا، 1,012 جملة لكل منها) — أدناه؛ يُذكر التفصيل الكامل لعدد إدخالات EdTeKLA مرة واحدة في [القسم الخاص بها](#edtekla-development-set-v1).

مجموعات البيانات هي الأهداف الثابتة التي تعمل أداة الاختبار (harness) مقابلها. كل مجموعة بيانات عبارة عن ملف JSON يحتوي على أزواج المصدر→الهدف مع مراجع ذهبية (gold-standard). تقوم أداة الاختبار بتقييم مخرجات النموذج مقابل هذه المراجع — ولا تقوم بتعديلها أبدًا.

:::danger[لا تقم بالتدريب على بيانات التقييم]

⚠️ **مجموعات البيانات هذه مخصصة للتقييم فقط.** الأساليب التي يتم تدريبها، أو ضبطها الدقيق (fine-tuned)، أو توجيهها بأمثلة قليلة (few-shot-prompted)، أو تعريضها لبيانات التقييم بأي شكل آخر، ستنتج درجات مضخمة بشكل مصطنع وسيتم **استبعادها من لوحة الصدارة (leaderboard).**

استخدم متونًا منفصلة للتدريب. يجب أن تظل مجموعات التقييم غير مرئية لنموذجك أثناء التطوير.
:::

## تنسيق مجموعة البيانات {#dataset-format}

تتبع كل مجموعة بيانات نفس مخطط JSON:

```json
{
  "dataset": {
    "id": "dataset-slug",
    "version": "1.0",
    "language_pair": "EN→CRK",
    "description": "Human-readable description of the dataset",
    "source_language": "en",
    "target_language": "crk",
    "created": "2025-05-01",
    "license": "CC-BY-NC-4.0",
    "provenance": ["gold_standard", "textbook"]
  },
  "entries": [
    {
      "id": 1,
      "source": "Hello",
      "reference": "tânisi",
      "difficulty": 1,
      "provenance": "gold_standard",
      "register": "conversational",
      "context": "greeting",
      "notes": "Common greeting, SRO orthography"
    }
  ]
}
```

:::info[المخطط الأساسي]
تُعرّف [مواصفات معيار القياس](/docs/network/specifications/benchmark) المتن الأساسي ومخطط الإدخال. توثق هذه الصفحة مجموعات البيانات المتاحة وكيفية إنشاء مجموعات جديدة.
:::

### كتلة `dataset` ذات المستوى الأعلى

| الحقل | النوع | الوصف |
|-------|------|-------------|
| `id` | `string` | معرّف فريد لمجموعة البيانات (يُستخدم في بطاقات التشغيل ولوحة الصدارة) |
| `version` | `string` | الإصدار الدلالي (Semantic version). تؤدي زيادة هذا الرقم إلى إبطال مقارنات بطاقات التشغيل السابقة |
| `language_pair` | `string` | تسمية العرض (مثل، `EN→CRK`) |
| `description` | `string` | اختياري. ملخص يمكن للبشر قراءته |
| `source_language` | `string` | رمز لغة المصدر وفقًا لمعيار BCP 47 |
| `target_language` | `string` | رمز لغة الهدف وفقًا لمعيار BCP 47 |
| `created` | `string` | تاريخ الإنشاء بتنسيق ISO 8601 |
| `license` | `string` | معرّف ترخيص SPDX |
| `provenance` | `string[]` | قائمة بعلامات المصدر (provenance tags) المستخدمة عبر الإدخالات |

### حقول الإدخال

| الحقل | النوع | مطلوب | الوصف |
|-------|------|----------|-------------|
| `id` | `integer` | ✅ | معرّف إدخال فريد داخل المتن |
| `source` | `string` | ✅ | النص المصدر المراد ترجمته |
| `reference` | `string` | ✅ | الترجمة المرجعية الذهبية (gold-standard) |
| `difficulty` | `integer` | ✅ | مستوى الصعوبة 1-5 (انظر أدناه) |
| `provenance` | `string` | ✅ | أصل هذا الإدخال (مثل، `gold_standard`، `textbook`، `elicited`) |
| `register` | `string` | ✅ | مستوى السجل/الرسمية (مثل، `conversational`، `formal`، `ceremonial`) |
| `context` | `string` | ✅ | الوظيفة التواصلية (مثل، `greeting`، `declaration`، `instruction`) |
| `notes` | `string` | ❌ | سياق اختياري للمراجعين البشريين |
| `morphological_analysis` | `string` | ❌ | التحليل الصرفي الذهبي (Gold-standard morphological breakdown) |
| `variant_class` | `string` | ❌ | تسمية فئة تُجمّع متغيرات الترجمة المقبولة |

## مجموعات البيانات المتاحة

يحتوي الكتالوج على **حوالي 4,700 مجموعة بيانات تقييم تُجلب من المصدر عبر 19 عائلة متون**، بالإضافة إلى مجموعتي البيانات المرجعيتين المنسقتين بشريًا (EDTeKLA + FLORES) المفصلتين أدناه — بإجمالي **5,602 مجموعة بيانات** في السجل اعتبارًا من 2026-07-12. كل متن عبارة عن **بطاقة بيانات وصفية مثبتة بتجزئة (sha-pinned)** — لا يتم استضافة محتوى المتن هنا أبدًا؛ بل يُعاد بناؤه بشكل حتمي من أرشيفه المثبت في المنبع وقت التقييم. تحمل جميع مجموعات البيانات `do_not_train`. تتفرع بطاقة المصدر الواحدة إلى العديد من مجموعات البيانات لكل زوج لغوي، لذلك يتجاوز إجمالي السجل حوالي 1,417 بطاقة مصدر؛ تُغذي مجموعات بيانات المسار المفتوح (open-lane) قائمة انتظار المسح (sweep queue) مباشرةً؛ بينما يعمل مسار الاستخدام البحثي فقط عند الطلب حيثما يسمح ترخيصه بذلك بوضوح (التراخيص المعدلة/المخصصة/غير المعلنة مقيدة بالموافقة للتقييم عبر واجهة برمجة تطبيقات النموذج عن بُعد).

:::

تم تفصيل مجموعات البيانات المرجعية أدناه؛ تتبع متون العائلات نفس مخطط JSON وهي مدرجة في سجل مجموعات البيانات.

:::note[الكتالوج ليس لوحة صدارة ممتلئة]
كتالوج المتون الكبير هو ما *يمكن* قياس أداء الأساليب مقابله — وليس لوحة صدارة مليئة بالنتائج. اللوحة نفسها في مرحلة التأسيس (seeding)؛ راجع [قواعد لوحة الصدارة](/docs/network/leaderboard/rules) و[القيود الصادقة](/docs/network/honest-limitations).
:::

### مجموعة تطوير EDTeKLA الإصدار 1 {#edtekla-development-set-v1}

أول مجموعة بيانات تقييم، صُممت للترجمة من الإنجليزية إلى Plains Cree (SRO). تم إنشاؤها بواسطة [مجموعة أبحاث EdTeKLA](https://spaces.facsci.ualberta.ca/edtekla/) في جامعة ألبرتا.

| الخاصية | القيمة |
|----------|-------|
| **المعرّف (ID)** | `edtekla-dev-v1` |
| **الإصدار** | `1.0` |
| **الزوج اللغوي** | EN → CRK (Plains Cree، قواعد الإملاء SRO) |
| **عدد الإدخالات** | تقسيم تطويري (dev split) مكون من 436 إدخالًا (`textbook_dev.json`). السلسلة: 589 سطرًا خامًا محاذيًا في المنبع → 486 زوجًا صالحًا فريدًا بعد التسوية/إزالة التكرار (عدد مستمد من Champollion) → 436 للتطوير + 50 محتجزة (تقسيم حتمي ببذرة 42 من Champollion — تنشر EdTeKLA الملفات الخام، وليس التقسيم). هناك مجموعة ذهبية منفصلة مكونة من 62 إدخالًا (منسقة يدويًا، للبحث فقط، **ليست** من مواد EdTeKLA) ترفع إجمالي مجموعة تقييم Plains Cree المجمعة للمشروع إلى 548. |
| **توزيع الصعوبة** | سهل، متوسط، صعب |
| **المصدر** | `gold_standard` (تم التحقق منه بواسطة متحدثين)، `textbook` (مواد تعليمية منشورة) |
| **الترخيص** | [ترخيص CC BY-NC-SA المعدل من EdTeKLA](https://github.com/EdTeKLA/IndigenousLanguages_Corpora) (`LicenseRef-EdTeKLA-Modified-CC-BY-NC-SA-4.0` — مقيد بالسيادة؛ الكتاب المدرسي الأساسي مرخص بـ CC BY-NC-ND 4.0) — **مستبعد من لوحة الصدارة، والجوائز، والمسارات التجارية/واجهة برمجة التطبيقات** (غير تجاري) |

> **هذا هو البيان الأساسي لأعداد مجموعة تقييم Plains Cree.** ترتبط الصفحات الأخرى هنا بدلاً من إعادة ذكرها. الأرقام 486/436/50 مستمدة من Champollion بناءً على ملفات EdTeKLA الخام المحاذية (لا تنشر EdTeKLA نفسها أي أعداد أو تقسيمات)؛ المجموعة الذهبية المكونة من 62 إدخالًا لها مصدر منفصل غير تابع لـ EdTeKLA. يقترن العدد أعلاه دائمًا بمساره: تحمل EdTeKLA ترخيص CC BY-NC-SA معدلًا ومقيدًا بالسيادة وهي **مستبعدة من لوحة الصدارة، والجوائز، والمسار التجاري/واجهة برمجة التطبيقات**.

**ما تختبره:**

- التحيات الأساسية والعبارات الشائعة
- حيوية الاسم (Noun animacy) والتنحية (obviation)
- تصريف الأفعال عبر الأشخاص والأزمنة
- التراكيب المكانية (Locative constructions)
- النماذج الصرفية للملكية (Possessive paradigms)
- تراكيب الجمل المعقدة

:::tip[هيكل المتن]
تنقسم المواد المستمدة من EdTeKLA إلى مجموعة تطوير عامة (dev set) ومجموعة محتجزة (held-out set) (تقسيم Champollion لمحاذاة الكتاب المدرسي الخام لـ EdTeKLA — الأعداد في الجدول أعلاه). المجموعة الذهبية المنفصلة المكونة من 62 إدخالًا منسقة يدويًا من مصادر أخرى وليست جزءًا من متن EdTeKLA. مجموعة بيانات أصغر وعالية الجودة مع مراجع ذهبية تم التحقق منها أكثر فائدة من مجموعة كبيرة مليئة بالضوضاء — خاصة بالنسبة للغة منخفضة الموارد حيث تكون الترجمات "القريبة بما يكفي" غالبًا غير صالحة صرفيًا.
:::

## إنشاء مجموعة بيانات جديدة

لإنشاء مجموعة بيانات لزوج لغوي أو مجال جديد:

### 1. هيكلة ملف JSON

اتبع مخطط [تنسيق مجموعة البيانات](#dataset-format). يجب أن يحتوي كل إدخال على `source`، و`reference`، و`difficulty`، و`provenance`، و`register`، و`context`.

### 2. تعيين معرّف فريد

استخدم اسمًا وصفيًا (slug): `{project}-{split}-v{version}` (مثل، `edtekla-dev-v1`، `quechua-test-v1`).

### 3. التحقق من المراجع الذهبية

يجب التحقق من كل قيمة `reference` بواسطة متحدث طليق أو الحصول عليها من مصدر منشور ومراجع من قبل النظراء. المراجع المُنشأة آليًا تُبطل الغرض من التقييم.

### 4. تحديد مستويات الصعوبة

قم بتعيين مستوى صعوبة بعدد صحيح لكل إدخال:

| المستوى | الوصف | أمثلة |
|------|-------------|----------|
| 1 — مفردات أساسية | كلمات مفردة، تحيات شائعة، أرقام | "hello" → "tânisi" |
| 2 — جمل بسيطة | فاعل-فعل أو فاعل-فعل-مفعول (SVO)، زمن المضارع | "I see the dog" |
| 3 — تعقيد متوسط | زمن الماضي/المستقبل، الملكية، الحيوية (animacy) | "I saw his dog yesterday" |
| 4 — صرف معقد | التنحية (Obviation)، المبني للمجهول، صيغة العطف (conjunct order) | "the woman whose son went to the store" |
| 5 — متقدم | جمل متعددة المقاطع، سجل رسمي، احتفالي، اصطلاحي | فقرة كاملة بنبرة مناسبة للسجل |

### 5. وضع علامات المصدر

يجب أن يشير كل إدخال إلى مصدره. العلامات الشائعة:

- `gold_standard` — تم التحقق منه بواسطة متحدثين طليقين
- `textbook` — من مواد تعليمية منشورة
- `elicited` — أُنتج من خلال جلسات استنباط منظمة
- `corpus` — مُستخرج من متن متوازي

### 6. التحقق من صحة الملف

قم بتشغيل أداة الاختبار مقابل مجموعة بياناتك باستخدام أي نموذج للتحقق من أن ملف JSON منسق بشكل صحيح وأن جميع الحقول المطلوبة موجودة:

```bash
mt-eval run --corpus path/to/your-dataset.json --dry-run
```

ستُصدر أداة الاختبار خطأً عند وجود حقول مفقودة، أو فهارس مكررة، أو انتهاكات للمخطط.

### 7. الإرسال للإدراج

افتح طلب سحب (pull request) في [مستودع أداة التقييم](https://github.com/gamedaysuits/Champollion) يضيف **بطاقة بيانات وصفية تُجلب من المصدر** — إدخال سجل يوجه أداة الاختبار إلى المصدر في المنبع (المُحمّل/عنوان URL، وتثبيت SHA، والترخيص، والمصدر). **لا تقم أبدًا بإيداع (commit) محتوى المتن نفسه.** لا يستضيف Champollion أو يتتبع نصوص متون تابعة لجهات خارجية؛ بل تقوم أداة الاختبار بجلب المراجع من المصدر في المنبع وقت التشغيل وتقييمها مقابل البيانات المجلوبة حديثًا. تحقق محليًا أولاً (الخطوة 6)، ثم أرسل البطاقة فقط. قم بتضمين توثيق لمنهجية التحقق الخاصة بك ومصادر المنشأ.

## FLORES+ Devtest

معيار قياس متعدد اللغات واسع التغطية تديره [مبادرة بيانات اللغة المفتوحة (OLDI)](https://huggingface.co/datasets/openlanguagedata/flores_plus). يُستخدم لمقارنات النماذج الرائدة المتعددة (multi-model frontier comparisons) في Champollion.

| الخاصية | القيمة |
|----------|-------|
| **المعرّف (ID)** | بطاقة واحدة لكل زوج: `eval-flores-devtest-v1-<src>-<tgt>` (مثل `eval-flores-devtest-v1-amh-fra`) |
| **الأزواج اللغوية** | 870 زوجًا مفهرسًا وقابلًا للتشغيل (812 منها بين لغتين غير الإنجليزية) |
| **عدد الإدخالات** | 1,012 جملة لكل زوج |
| **الترخيص** | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| **المصدر** | Meta FLORES-200، تديره الآن OLDI — يُجلب من المصدر، ومثبت بتجزئة SHA لكل زوج (لا يتم تتبع محتوى المتن هنا أبدًا) |
| **التلوث (Contamination)** | **مرتفع** — نسبي فقط، للاختبار / التوضيح فقط (انظر الملاحظة) |

:::warning[تلوث مرتفع — نسبي فقط، وليس معيارًا مطلقًا أبدًا]
FLORES+ عبارة عن بيانات عامة مجمعة من الويب (web-crawled) ومن المحتمل جدًا أن النماذج الرائدة قد رأتها بالفعل. يقوم Champollion بتشغيلها في مسار **نسبي فقط**: يمكن استخدامها لمقارنة الأساليب وجهًا لوجه، ولكن **لا يُبلغ عنها أبدًا كدرجة جودة مطلقة**، و**لا تُستخدم أبدًا كحافة سلسلة (chain edge)** على [خريطة الترجمة](https://champollion.dev).
إنها مخصصة **للاختبار والتوضيح فقط**.
:::

:::danger[للتقييم فقط]
FLORES+ مخصصة للتقييم فقط. يطلب المنسقون صراحةً **عدم استخدامها كبيانات تدريب**. تأكد من استبعاد محتوياتها من أي متون تدريب.
:::
