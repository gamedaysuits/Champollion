# تعزيز الترجمة العكسية

> **الفكرة:** إنشاء بيانات متوازية اصطناعية عن طريق ترجمة النصوص الموجودة باللغة الهدف مرة أخرى إلى اللغة المصدر، ثم استخدام هذه الأزواج الاصطناعية لتدريب أو توجيه نموذج أمامي. يؤدي هذا إلى توسيع مدونتك المتوازية بتكلفة زهيدة — ولكن مع وجود محاذير بشأن الجودة.

:::info[هذا دليل عملي، وليس تنفيذاً نهائياً]
يرسم هذا الدليل ملامح الاستراتيجية ومزالقها الحرجة. الترجمة العكسية قوية ولكنها قد تضخم الأخطاء إذا لم تتم بعناية.
:::

## متى تستخدم هذا

- لديك **نص أحادي اللغة باللغة الهدف** ولكن البيانات المتوازية محدودة
- تريد **توسيع مدونة التدريب** من أجل [الضبط الدقيق](./fine-tuned-model) دون الحاجة إلى ترجمة يدوية
- تحتاج إلى **المزيد من أمثلة التعلم من لقطات قليلة (few-shot)** ولكن لا يمكنك الحصول على ترجمات بشرية بسرعة كافية
- أنت مستعد لـ **تصفية جودة** البيانات الاصطناعية بصرامة

## كيف تعمل

```
[Target-language text]          "awâsisak mêtawêwak"
        │
        ▼
[Back-translate to source]      "The children are playing"  (via LLM or MT API)
        │
        ▼
[Create synthetic pair]         ("The children are playing", "awâsisak mêtawêwak")
        │
        ▼
[Quality filter]                Keep only high-confidence pairs
        │
        ▼
[Use for training/prompting]    Expand your parallel corpus
```

1. **جمع نصوص أحادية اللغة** — كتب، مقالات، نصوص مفرغة، ووسائل تواصل اجتماعي باللغة الهدف
2. **الترجمة العكسية** — استخدم نموذج لغة كبير (LLM) أو واجهة برمجة تطبيقات للترجمة الآلية (MT API) لترجمة كل جملة إلى اللغة المصدر
3. **تصفية الجودة** — إجراء دورة كاملة (الترجمة العكسية مرة أخرى) والمقارنة؛ احتفظ بالأزواج التي تكون فيها الدورة الكاملة ≈ الأصل
4. **استخدام المدونة الاصطناعية** — للضبط الدقيق، أو أمثلة التعلم من لقطات قليلة (few-shot)، أو بيانات التوجيه (coaching data)

## تصفية الجودة: اختبار الدورة الكاملة (Round-Trip)

```python
# Pseudo-code for round-trip quality filtering
for target_text in monolingual_corpus:
    # Back-translate: target → source
    synthetic_source = translate(target_text, "crk", "en")
    
    # Forward-translate: source → target
    round_trip = translate(synthetic_source, "en", "crk")
    
    # Compare round-trip to original
    chrf_score = compute_chrf(target_text, round_trip)
    
    if chrf_score > 0.70:  # High similarity = high-quality pair
        parallel_corpus.append((synthetic_source, target_text))
```

## مزلق حرج: تضخيم الأخطاء

:::warning[الترجمة العكسية تضخم تحيزات النموذج الحالية]
إذا كان نموذج الترجمة العكسية الخاص بك يرتكب نفس الأخطاء باستمرار، فإن مدونتك الاصطناعية ستشفر هذه الأخطاء على أنها "صحيحة". يؤدي هذا إلى إنشاء حلقة مفرغة: التدريب على بيانات سيئة ← إنتاج ترجمات أسوأ ← إنشاء بيانات اصطناعية أسوأ. **قم دائماً بتصفية الجودة بصرامة** واخلط البيانات الاصطناعية مع ترجمات بشرية تم التحقق منها.
:::

## أين تجد النصوص أحادية اللغة

- النشرات الإخبارية المجتمعية، والصحف، والمطبوعات
- الوثائق الحكومية باللغة الهدف (مثل Nunavut Hansard للغة Inuktitut)
- المواد التعليمية والكتب المدرسية
- النصوص الدينية (متوفرة على نطاق واسع للعديد من اللغات)
- وسائل التواصل الاجتماعي (مع الأذونات المناسبة وتصفية الجودة)
- المقاطع الصوتية/المرئية المفرغة من البرامج اللغوية

## الإيجابيات والسلبيات

| | |
|---|---|
| ✅ يوسع بيانات التدريب بتكلفة زهيدة | ❌ يضخم أخطاء النموذج إذا لم تتم تصفيته |
| ✅ يستخدم نصوصاً أحادية اللغة وفيرة | ❌ سقف الجودة محدود بنموذج الترجمة العكسية |
| ✅ سهل الإنشاء على نطاق واسع | ❌ تصفية الدورة الكاملة تستهلك موارد حوسبة مكثفة |
| ✅ يكمل الأساليب الأخرى | ❌ البيانات الاصطناعية لا ترقى أبداً لمستوى الترجمة البشرية |
