# الترجمة الجزئية (بشري + آلي)

> **الفكرة:** ترجمة عينة تمثيلية يدوياً، وإثبات أن طريقتك الآلية تطابق الأسلوب البشري في تلك العينة، ثم ترجمة الجزء الأكبر المتبقي آلياً. يجمع هذا بين الجودة البشرية والنطاق الآلي — حيث يضع العنصر البشري المعيار، وتتبعه الآلة.

:::info[هذا دليل إرشادي (Cookbook)، وليس تنفيذاً نهائياً]
يرسم هذا الدليل ملامح سير العمل الهجين بين البشر والآلة. وهو وثيق الصلة بشكل خاص بوكالات الترجمة، والعاملين في مجال لغات المجتمع، والسياقات التعليمية.
:::

## متى تستخدم هذا

- لديك **إمكانية الوصول إلى متحدثين طليقين** ولكن وقتهم محدود
- تحتاج إلى ترجمة **حجم كبير** ولكن جزءاً صغيراً فقط يحتاج إلى أن يكون مثالياً
- ترغب في **إنشاء خط أساس للجودة** باستخدام الترجمة البشرية، ثم التوسع باستخدام الترجمة الآلية (MT)
- أنت تعمل في **سياق تعليمي أو مجتمعي** حيث تكون المراجعة البشرية لمجموعة فرعية أمراً ممكناً

## كيف تعمل

```
[Full corpus: 1,000 entries]
        │
        ├── [100 entries] ──→ Human translator ──→ Gold translations
        │                                              │
        │                                              ▼
        │                                    Train / prompt machine
        │                                    method to match style
        │                                              │
        └── [900 entries] ──→ Machine method ──→ Auto translations
                                                       │
                                                       ▼
                                              [Optional: human review
                                               of flagged entries]
```

1. **تحديد عينة تمثيلية** — تغطية أنواع مختلفة من الجمل، والأطوال، والمواضيع
2. **ترجمة العينة بشرياً** — وضع المعيار الذهبي للأسلوب، ومستوى اللغة (Register)، والمصطلحات
3. **تكوين طريقتك الآلية** — استخدام الترجمات البشرية كبيانات توجيهية (Coaching data)، أو أمثلة قليلة اللقطات (Few-shot examples)، أو بيانات ضبط دقيق (Fine-tuning data)
4. **تقييم الآلة بناءً على العينة البشرية** — هل تطابق الآلة الأسلوب البشري؟
5. **الترجمة الآلية للباقي** — إذا كانت جودة الآلة مقبولة في العينة
6. **مراجعة بشرية اختيارية** — وضع علامة على المخرجات ذات الموثوقية المنخفضة لمراجعتها من قبل المتحدثين

## ضمان الجودة: اختبار مطابقة الأسلوب

```bash
# Translate the human-translated sample with your machine method
mt-eval run \
  --corpus data/human-sample.json \
  --name coached-v3

# Compare: does the machine match the human translator's choices?
# Look at: chrF++ (similarity), FST acceptance (validity),
# and qualitative patterns (register, formality, terminology)
```

## اختيار العينة

**تغطية التوزيع.** يجب أن تتضمن مدخلاتك المائة ما يلي:
- عبارات قصيرة (1-3 كلمات) وجمل كاملة
- مفردات شائعة ومصطلحات خاصة بالمجال
- تراكيب بسيطة ومعقدة
- ميزات نحوية متعددة (أسئلة، أوامر، جمل شرطية)

**لا تنتقِ المدخلات السهلة فقط.** يجب أن تتضمن العينة مدخلات من المحتمل أن تواجه طريقتك صعوبة معها — فهنا تكمن الأهمية القصوى للجودة البشرية.

## سير عمل المراجعة المجتمعية

بالنسبة لمجتمعات لغات السكان الأصليين، يحترم هذا النهج وقت المتحدثين:

1. **يترجم المتحدث 50-100 مدخل** (2-4 ساعات من العمل المركز)
2. **تترجم الآلة الـ 900 مدخل المتبقية** باستخدام عمل المتحدث كبيانات توجيهية
3. **يراجع المتحدث المدخلات المميزة بعلامة** — فقط تلك التي كانت الآلة أقل ثقة بشأنها (1-2 ساعة إضافية)
4. **النتيجة:** 1,000 ترجمة بجودة تقارب الجودة البشرية، مع حوالي 5 ساعات من وقت المتحدث بدلاً من حوالي 50 ساعة

## الإيجابيات والسلبيات

| | |
|---|---|
| ✅ يجمع بين الجودة البشرية والنطاق الآلي | ❌ يتطلب استثماراً بشرياً أولياً |
| ✅ يحترم محدودية توفر المتحدثين | ❌ قد لا تلتقط الآلة جميع الفروق الدقيقة في الأسلوب |
| ✅ سير عمل طبيعي لضمان الجودة | ❌ يؤثر اختيار العينة على الجودة الإجمالية |
| ✅ ممتاز للسياقات المجتمعية/التعليمية | ❌ عنق زجاجة في المراجعة البشرية للمدخلات المميزة بعلامة |
