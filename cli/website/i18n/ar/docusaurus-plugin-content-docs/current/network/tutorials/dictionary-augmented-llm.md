# نموذج لغوي كبير (LLM) معزز بالقاموس

> **الفكرة:** فرض ترجمات معروفة وموثوقة لمصطلحات محددة من قاموس ثنائي اللغة، وترك النموذج اللغوي الكبير (LLM) يتعامل مع بنية الجملة والمفردات غير المعروفة. يوفر القاموس ركائز للصحة والدقة؛ بينما يوفر النموذج اللغوي الكبير الطلاقة.

:::info[هذا دليل عملي (Cookbook)، وليس تنفيذاً نهائياً]
يوضح هذا الدليل الخطوط العريضة للنهج. ستعتمد استراتيجية مطابقة القاموس وحقن المصطلحات المحددة على زوج اللغات الخاص بك والموارد المعجمية المتاحة.
:::

## متى تستخدم هذا النهج

- **وجود قاموس ثنائي اللغة** لزوج اللغات الخاص بك (حتى لو كان صغيراً)
- النموذج اللغوي الكبير (LLM) **يهلوس باستمرار في المصطلحات الرئيسية** — باختلاق كلمات لا وجود لها
- تحتاج إلى **اتساق المصطلحات** عبر الترجمات (ترجمة نفس الكلمة بنفس الطريقة في كل مكان)
- أنت تترجم **محتوى خاص بمجال معين** حيث تكون ترجمات النموذج اللغوي الكبير القياسية خاطئة (قانوني، طبي، تعليمي)

## كيف تعمل

1. **تحميل قاموس ثنائي اللغة** — أزواج من المفتاح والقيمة (key→value) تربط المصطلحات المصدر بترجمات هدف موثوقة
2. **مطابقة النص المصدر مع القاموس** — تحديد المصطلحات في المدخلات التي لها ترجمات معروفة
3. **حقن التطابقات في الموجه (Prompt)** — إخبار النموذج اللغوي الكبير "يجب ترجمة هذه المصطلحات على النحو التالي"
4. **توليد الترجمة بواسطة النموذج اللغوي الكبير** — مع اعتبار قيود القاموس كمتطلبات صارمة
5. **المعالجة اللاحقة** — التحقق من ظهور مصطلحات القاموس في المخرجات؛ وإعادة المحاولة إذا لم تظهر

## تنسيق القاموس

```json title="dictionaries/crk-terms.json"
{
  "school": "kiskinwahamâtowikamik",
  "teacher": "okiskinwahamâkêw",
  "student": "kiskinwahamâkan",
  "book": "masinahikan",
  "home": "kīwēwin",
  "water": "nipiy"

```

## بنية الموجه (Prompt)

```
Translate the following English to Plains Cree (SRO).

REQUIRED TERMINOLOGY — use these exact translations:
- "school" → "kiskinwahamâtowikamik"
- "teacher" → "okiskinwahamâkêw"

Source: "The teacher went to the school"
```

## قرارات التصميم الرئيسية

**استراتيجية المطابقة:** المطابقة التامة (Exact match) هي الأبسط. المطابقة القائمة على التجذير (Lemmatized matching) (مثل مطابقة "teachers" مع "teacher") تلتقط المزيد من الكلمات ولكنها تتطلب أداة تجذير (lemmatizer) للغة المصدر. أما المطابقة التقريبية (Fuzzy matching) فتحمل خطر النتائج الإيجابية الخاطئة.

**التعامل مع التصريف:** في اللغات متعددة التركيب (polysynthetic languages)، قد يحتاج شكل الكلمة في القاموس إلى تصريف ليتناسب مع الجملة. يمكنك توفير الجذر وترك النموذج اللغوي الكبير يقوم بالتصريف، أو توفير أشكال مصرفة متعددة. يمكن لـ [FST](./fst-gated-pipeline) التحقق من صحة النتيجة.

**حل التعارض:** ماذا لو تجاهل النموذج اللغوي الكبير مصطلحاً من القاموس؟ الخيارات: (أ) إعادة المحاولة بتعليمات أقوى، (ب) المعالجة اللاحقة عن طريق استبدال السلاسل النصية، (ج) قبول النتيجة ووضع علامة عليها للمراجعة.

## الإيجابيات والسلبيات

| | |
|---|---|
| ✅ يقضي على الهلوسة للمصطلحات المعروفة | ❌ تغطية القاموس تكون دائماً غير مكتملة |
| ✅ يضمن الاتساق للمفردات الرئيسية | ❌ قد لا يتطابق التصريف/الاشتقاق مع سياق الجملة |
| ✅ سهل التدقيق والتحديث | ❌ التقييد المفرط قد ينتج مخرجات غير طبيعية |
| ✅ القاموس أصل قابل لإعادة الاستخدام | ❌ يتطلب وجود قاموس في المقام الأول |

## أين تجد القواميس

- **[itwêwina](https://itwewina.altlab.app/)** — لغة الكري في السهول (Plains Cree) إلى الإنجليزية (مدعوم بـ FST؛ منصة morphodict مفتوحة المصدر — محتوى القاموس نفسه ليس مرخصاً بشكل مفتوح)
- **[Wolvengrey, *nêhiyawêwin: itwêwina / Cree: Words*](https://uofrpress.ca/Books/C/Cree-Words)** — مرجع شامل للغة الكري في السهول (Plains Cree) (مطبعة جامعة ريجينا)
- **[Apertium](https://www.apertium.org/)** — قواميس ثنائية اللغة لعشرات من أزواج اللغات
- **[Giellatekno](https://giellalt.github.io/)** — قواميس للغات السامي (Sámi)، والأورالية (Uralic)، ولغات الأقليات الأخرى
- مسارد المصطلحات التي أنشأها المجتمع، والمواد التعليمية، وقوائم المصطلحات
