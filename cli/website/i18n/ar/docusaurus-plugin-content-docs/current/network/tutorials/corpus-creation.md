# دليل إنشاء المكنز

> **الفكرة:** قبل أن تتمكن من تقييم طريقة ترجمة ما، ستحتاج إلى مكنز للتقييم. يغطي هذا الدليل كيفية بناء مكنز من الصفر — جمع البيانات، ومتطلبات التنسيق، ومعايير الجودة، والترخيص، والمساهمة في Network.

:::info[هذه ليست طريقة ترجمة]
يمثل هذا الدليل متطلبًا أساسيًا للعديد من الطرق. فمكنز التقييم الجيد هو الأساس الذي يجعل كل شيء آخر ممكنًا. حتى وجود 50 زوجًا منسقًا بعناية يكفي لفتح مسار جديد في لوحة الصدارة.
:::

## متى تستخدم هذا الدليل

- ترغب في **إضافة زوج لغوي جديد** إلى لوحة صدارة Network
- أنت **معلم لغة** ترغب في قياس أداء ترجمات الطلاب وتقييمها
- أنت **عامل في مجال لغات المجتمعات المحلية** ولديك إمكانية الوصول إلى مواد ثنائية اللغة
- أنت **باحث** بحاجة إلى مجموعة تقييم معيارية لزوجك اللغوي

## تنسيق المكنز

تستقبل أداة التقييم صيغة JSON بسيطة:

```json title="my-corpus.json"
{
  "metadata": {
    "name": "Quechua Dev v1",
    "version": "1.0.0",
    "source_language": "eng",
    "target_language": "que",
    "entry_count": 75,
    "license": "CC-BY-SA-4.0",
    "author": "Your Name / Organization",
    "description": "75 English-Quechua pairs from educational materials"
  },
  "entries": [
    {
      "id": 1,
      "source": "Hello, how are you?",
      "reference": "Allillanchu, imaynallan kashanki?"
    },
    {
      "id": 2,
      "source": "The sun is shining today",
      "reference": "Kunan p'unchay inti k'anchashan"
    }
  ]
}
```

## مصادر جمع البيانات

| المصدر | الجودة | الحجم | الترخيص |
|--------|---------|--------|-----------|
| **الكتب الدراسية / المواد التعليمية** | عالية (مراجعة من قِبل خبراء) | منخفض إلى متوسط | راجع الناشر |
| **الوثائق الحكومية** | متوسطة (أسلوب رسمي) | متوسط إلى مرتفع | غالبًا ضمن الملك العام |
| **القواميس ثنائية اللغة** | عالية (مدخلات موثقة ومحققة) | متوسط | يتفاوت |
| **شيوخ المجتمع / المتحدثون الأصليون** | الأعلى (حدس المتحدث الأصلي) | منخفض (بسبب ضيق الوقت) | خاضع لإدارة المجتمع المحلي |
| **النصوص الدينية** | متوسطة (خاصة بمجال محدد) | مرتفع | عادة ما تكون مفتوحة |
| **المكانز الحالية** (Hansard، وFLORES) | متوسطة إلى عالية | مرتفع | تحقق من الترخيص |
| **مُعدّة يدويًا** | الأعلى | منخفض | مملوكة لك بالكامل |

## معايير الجودة

يتميز مكنز التقييم الجيد بما يلي:

1. **محتوى متنوع** — ليس مجرد عبارات ترحيبية أو جُمَل بسيطة. احرص على تضمين أسئلة، وأوامر، وجُمل معقدة، ومصطلحات خاصة بمجالات محددة
2. **ترجمات موثقة** — تمت مراجعتها من قِبل متحدث طلق واحد على الأقل، ويفضل اثنان
3. **رسم إملائي متسق** — نظام كتابة واحد، وقواعد إملائية موحدة في كافة النصوص
4. **مصادر مستقلة** — غير مستمدة من النص نفسه الذي ستُدرَّب عليه الطرق
5. **ترخيص واضح** — ترخيص صريح يسمح بالاستخدام لأغراض التقييم

:::danger[تلوث المكنز]
يجب أن يكون مكنز التقييم **مستقلاً** عن أي بيانات تدريب. إذا تم تدريب أي طريقة أو توجيهها ببيانات من مكنز التقييم، فسيتم استبعادها. صمم مكنزك ليكون محجوبًا ومستقلاً منذ اليوم الأول.
:::

## إرشادات الحجم

| الحجم | ما يتيحه |
|------|----------------|
| **50 مدخلة** | تقييم أدنى قابل للتطبيق — كافٍ لرصد الفروق الجوهرية في الجودة |
| **100–200 مدخلة** | تصنيف موثوق — كافٍ لتحقيق دلالة إحصائية بين الطرق المختلفة |
| **+500 مدخلة** | ملائم للأبحاث العلمية — فترات ثقة ضيقة لمقياس chrF++، واختبارات دلالة يمكنها الفصل بين الطرق المتقاربة |
| **+1,000 مدخلة** | المعيار الذهبي — يعادل تغطية مجموعة اختبار وتطوير FLORES |

ابدأ صغيرًا؛ إذ تكفي 50 مدخلة لفتح مسار في لوحة الصدارة. يمكنك التوسع لاحقًا.

## المساهمة في Network

1. **أنشئ مكنزك** بتنسيق JSON الموضح أعلاه
2. **حدد ترخيصه** — يُوصى بالترخيص CC BY-SA 4.0 للتقييم المفتوح؛ والترخيص CC BY-NC-SA 4.0 للاستخدام المقيد
3. **استضفه في مصدر مستقر** (مستودعك الخاص، أو أرشيف مؤسسي، أو سجل بيانات) — لا يقوم Champollion أبدًا باستضافة محتوى المكنز أو تتبعه
4. **أرسل بطاقة بيانات وصفية للجلب من المصدر** — افتح PR في [المستودع العام](https://github.com/gamedaysuits/Champollion) لإضافة مدخلة في السجل توجّه أداة التقييم إلى مصدرك الأصلي (المحمّل/الرابط loader/URL، وتثبيت SHA، والترخيص، ومصدر البيانات)؛ راجع [مجموعات البيانات](/docs/network/leaderboard/datasets#creating-a-new-dataset) لمعرفة تنسيق البطاقة
5. **تُفتَح لوحة الصدارة** لزوجك اللغوي بمجرد دمج البطاقة

## لمجتمعات اللغات الأصلية

إن إنشاء المكنز هو ممارسة **للسيادة اللغوية**. مكنزك يخضع لشروطك:

- أنت من يحدد الترخيص وشروط الوصول
- يمكنك المساهمة بـ **مجموعة تطوير عامة** (لتطوير الطرق) مع الاحتفاظ بـ **مجموعة اختبار سرية** (للتقييم الرسمي) تحت سيطرة المجتمع المحلي
- يحمي [إطار عمل السيادة](/docs/network/sovereignty/data-sovereignty) بياناتك على كل المستويات

حتى المكنز الصغير يُعد **أصلًا استراتيجيًا** — فهو المقياس المرجعي الذي يحدد ما يعنيه "جيد بما فيه الكفاية" للغتك.
