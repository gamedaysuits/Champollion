# دليل إنشاء المتن اللغوي

> **الفكرة:** قبل أن تتمكن من تقييم طريقة ترجمة، ستحتاج إلى متن لغوي للتقييم. يغطي هذا الدليل كيفية بناء واحد من الصفر — مصادر البيانات، ومتطلبات التنسيق، ومعايير الجودة، والترخيص، والمساهمة في الشبكة.

:::info[هذه ليست طريقة ترجمة]
هذا الدليل هو المتطلب الأساسي للعديد من الطرق. المتن اللغوي الجيد للتقييم هو الأساس الذي يجعل كل شيء آخر ممكناً. حتى 50 زوجاً منسقاً تكفي لفتح مسار جديد في لوحة الصدارة.
:::

## متى تستخدم هذا

- تريد **إضافة زوج لغوي جديد** إلى لوحة صدارة الشبكة
- أنت **معلم لغة** يريد قياس أداء ترجمات الطلاب
- أنت **عامل لغوي مجتمعي** لديك وصول إلى مواد ثنائية اللغة
- أنت **باحث** يحتاج إلى مجموعة تقييم موحدة لزوجك اللغوي

## تنسيق المتن اللغوي

تأخذ أداة الاختبار (harness) تنسيق JSON بسيط:

```json title="my-corpus.json"
{
  "metadata": {
    "name": "Quechua Dev v1",
    "version": "1.0.0",
    "source_language": "eng",
    "target_language": "que",
    "entry_count": 75,
    "license": "CC-BY-SA-4.0",
    "author": "Your Name / Organization",
    "description": "75 English-Quechua pairs from educational materials"
  },
  "entries": [
    {
      "id": 1,
      "source": "Hello, how are you?",
      "reference": "Allillanchu, imaynallan kashanki?"
    },
    {
      "id": 2,
      "source": "The sun is shining today",
      "reference": "Kunan p'unchay inti k'anchashan"
    }
  ]
}
```

## من أين تحصل على البيانات

| المصدر | الجودة | الحجم | الترخيص |
|--------|---------|--------|-----------|
| **الكتب المدرسية / المواد التعليمية** | عالية (مراجعة من قبل خبراء) | منخفض-متوسط | تحقق مع الناشر |
| **الوثائق الحكومية** | متوسطة (أسلوب رسمي) | متوسط-عالي | غالباً ملكية عامة |
| **القواميس ثنائية اللغة** | عالية (مُدخلات تم التحقق منها) | متوسط | يختلف |
| **شيوخ المجتمع / المتحدثون** | الأعلى (حدس أصلي) | منخفض (وقت محدود) | محكوم من قبل المجتمع |
| **النصوص الدينية** | متوسطة (خاصة بالمجال) | عالي | مفتوح عادةً |
| **المتون اللغوية الحالية** (Hansard، FLORES) | متوسطة-عالية | عالي | تحقق من الترخيص |
| **مُصاغة يدوياً** | الأعلى | منخفض | أنت تملكها |

## معايير الجودة

يتميز المتن اللغوي الجيد للتقييم بما يلي:

1. **محتوى متنوع** — ليس مجرد تحيات أو عبارات بسيطة. قم بتضمين أسئلة، وأوامر، وجمل معقدة، ومصطلحات خاصة بالمجال
2. **ترجمات تم التحقق منها** — تمت مراجعتها من قبل متحدث طليق واحد على الأقل، ويُفضل اثنان
3. **إملاء متسق** — نظام كتابة واحد، وقاعدة إملائية واحدة في جميع الأنحاء
4. **مصادر مستقلة** — غير مستمدة من نفس النص الذي ستتدرب عليه الطرق
5. **ترخيص واضح** — ترخيص صريح يسمح بالاستخدام في التقييم

:::danger[تلوث المتن اللغوي]
يجب أن يكون المتن اللغوي للتقييم **مستقلاً** عن أي بيانات تدريب. إذا تم تدريب طريقة ما أو توجيهها باستخدام بيانات من المتن اللغوي للتقييم، فسيتم استبعادها. صمم المتن اللغوي الخاص بك ليكون معزولاً (held-out) منذ اليوم الأول.
:::

## إرشادات الحجم

| الحجم | ما يتيحه |
|------|----------------|
| **50 مُدخلاً** | الحد الأدنى للتقييم القابل للتطبيق — يكفي لاكتشاف الفروق الكبيرة في الجودة |
| **100–200 مُدخل** | تصنيف موثوق — يكفي للدلالة الإحصائية بين الطرق |
| **500+ مُدخل** | مستوى بحثي — درجات مركبة قوية، وفترات ثقة |
| **1,000+ مُدخل** | المعيار الذهبي — يعادل تغطية اختبار التطوير (devtest) في FLORES |

ابدأ صغيراً. 50 مُدخلاً تكفي لفتح مسار في لوحة الصدارة. يمكنك التوسع لاحقاً.

## المساهمة في الشبكة

1. **أنشئ المتن اللغوي الخاص بك** بتنسيق JSON المذكور أعلاه
2. **قم بترخيصه** — يُوصى باستخدام CC BY-SA 4.0 للتقييم المفتوح؛ و CC BY-NC-SA 4.0 للاستخدام المقيد
3. **استضفه في مصدر مستقر** (مستودعك الخاص، أو أرشيف مؤسسي، أو سجل بيانات) — لا يقوم Champollion أبداً باستضافة أو تتبع محتوى المتن اللغوي
4. **أرسل بطاقة بيانات وصفية للجلب من المصدر (fetch-from-source)** — افتح طلب سحب (PR) في [المستودع العام](https://github.com/gamedaysuits/Champollion) لإضافة إدخال سجل يوجه أداة الاختبار إلى مصدرك الأساسي (المُحمِّل/الرابط، وتثبيت SHA، والترخيص، والمصدر)؛ راجع [مجموعات البيانات](/docs/network/leaderboard/datasets#creating-a-new-dataset) لمعرفة تنسيق البطاقة
5. **تُفتح لوحة الصدارة** لزوجك اللغوي بمجرد دمج البطاقة

## لمجتمعات لغات الشعوب الأصلية

إن إنشاء المتن اللغوي هو عمل من أعمال **السيادة اللغوية**. متنك اللغوي، وشروطك:

- أنت من يقرر الترخيص وشروط الوصول
- يمكنك المساهمة بـ **مجموعة تطوير عامة** (لتطوير الطرق) مع الاحتفاظ بـ **مجموعة اختبار سرية** (للتقييم الرسمي) تحت سيطرة المجتمع
- يحمي [إطار عمل السيادة](/docs/network/sovereignty/data-sovereignty) بياناتك على كل المستويات

حتى المتن اللغوي الصغير يُعد **أصلاً استراتيجياً** — فهو المعيار الذي يحدد معنى "جيد بما فيه الكفاية" للغتك.
