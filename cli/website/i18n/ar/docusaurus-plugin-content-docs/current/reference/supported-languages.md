# اللغات المدعومة

يأتي champollion مزودًا بـ **بطاقات اللغات (Language Cards)** — وهي ملفات تكوين مهيكلة لـ 50 لغة. تحتوي كل بطاقة على إعدادات مسبقة للسياق (register presets)، وبيانات وصفية لنظام الرسمية، وعلامات دعم الطرق، وقواعد الطباعة، ومعلومات نظام الكتابة. يمكن إضافة أي لغة يعرفها نموذجك اللغوي الكبير (LLM) بسطر تكوين واحد — هذه هي اللغات التي تحتوي على سياقات منسقة وجاهزة للإنتاج.

---

## طرق الترجمة

يمكن لكل لغة استخدام واحدة أو أكثر من طرق الترجمة التالية:

| الأيقونة | الطريقة | كيف تعمل | التكلفة |
|------|--------|-------------|------|
| 🟢 | **Google Translate** | خط الأساس للترجمة الآلية العصبية (Neural MT). 194 لغة. سلاسل المفتاح-القيمة (Key-value) فقط — لا يمكنها ترجمة محتوى Markdown بأمان. | ~$20/1M حرف |
| 🔵 | **LLM (OpenRouter)** | أي لغة يعرفها النموذج. مطالبات موجهة بالسياق (Register-steered). تتعامل مع المفتاح-القيمة + محتوى Markdown. | تختلف حسب النموذج |
| 🟣 | **LLM-Coached** | نموذج لغوي كبير (LLM) + قواميس نحوية + بيانات تدريبية تُحقن في المطالبات. الأفضل للغات المعقدة صرفيًا. | تختلف حسب النموذج |
| 🟠 | **API (Plugin)** | مسارات ترجمة مستضافة مجتمعيًا تُقدم عبر HTTP. [نهج طامح إلى السيادة](/docs/network/community/low-resource-languages). | تختلف حسب المزود |

عيّن `GOOGLE_TRANSLATE_API_KEY` لـ Google Translate، أو `OPENROUTER_API_KEY` لطرق LLM. راجع [طرق الترجمة](/docs/guides/translation-methods) للحصول على التفاصيل الكاملة.

## اللغات الأصلية وقليلة الموارد

هذه اللغات غير مدعومة من قبل خدمات الترجمة الآلية (MT) التجارية. يوفر champollion الأدوات اللازمة للمجتمعات اللغوية لبناء طرقها الخاصة وفقًا لـ [مبادئ سيادة البيانات المجتمعية](/docs/network/community/low-resource-languages).

| | اللغة | الرمز | Google | LLM | Coached | نظام الكتابة | الحالة |
|---|----------|------|:------:|:---:|:-------:|--------|--------|
| 🪶 | لغة الكري السهول | `crk` | ❌ | ✅ | ✅ | 🔤 SRO→مقاطع | 🚧 قيد التطوير |
| 🌄 | الكيتشوا | `qu` | ✅ | ✅ | — | — | Runasimi. لواحق استدلالية. |

:::info[لغة الكري السهول قيد التطوير النشط]
السياق، والبنية التحتية للتدريب، ومحول نظام الكتابة، وأدوات التقييم للغة الكري السهول تعمل جميعها، ولكن مسار الترجمة **لم يُصدر بعد**. نحن نعمل مع المجتمعات اللغوية وفقًا لـ [مبادئ سيادة البيانات المجتمعية](/docs/network/community/low-resource-languages) لضمان الجودة قبل الإصدار. راجع [دعم لغة قليلة الموارد](/docs/network/community/low-resource-languages) لمعرفة القصة الكاملة — وكيف يمكنك المساهمة.
:::

:::tip[إضافة المزيد من اللغات قليلة الموارد]
تم تصميم نظام المكونات الإضافية للطرق في champollion لهذا الغرض. يمكن للمجتمع اللغوي بناء طريقة ترجمة مخصصة، واستضافتها تحت سيطرته الخاصة، وتقديمها عبر [طريقة API](/docs/guides/serving-a-method). تتتبع [لوحة صدارة الطرق (Method Leaderboard)](/leaderboard) الدرجات لأي زوج لغوي — قم ببناء طريقة، وشغّل أدوات التقييم، واحصل على أعلى درجة.
:::

## اللغات المصطنعة (Constructed Languages)

يتم دعم اللغات المصطنعة (Conlangs) عبر سياقات LLM ومحولات أنظمة الكتابة الاختيارية. وهي تستخدم نفس البنية التحتية للغات الحقيقية — حيث تعمل بوابة الجودة، ونظام التدريب، ومسار تحويل نظام الكتابة بشكل متطابق.

| | اللغة | الرمز | Google | LLM | نظام الكتابة | ملاحظات |
|---|----------|------|:------:|:---:|--------|-------|
| 🖖 | الكلينغونية | `tlh` | ❌ | ✅ | 🔤 رومنة→pIqaD | يتطلب خط PUA. مفردات Marc Okrand. |
| 🧝 | السندارين (لغة الإلف لتولكين) | `x-elvish-s` | ❌ | ✅ | 🔤 لاتيني→Tengwar | يتطلب خط CSUR PUA. |
| 🏴‍☠️ | إنجليزية القراصنة | `x-pirate` | ❌ | ✅ | — | سياق فقط. استعارات بحرية. |
| 🦸 | الكريبتونية | `x-kryptonian` | ❌ | ✅ | 🔤 لاتيني→Kryptonian | يتطلب خط PUA. |
| 🎭 | الإنجليزية الشكسبيرية | `x-shakespeare` | ❌ | ✅ | — | سياق فقط. صيغ Thee/thou و -eth/-est. |
| 🐸 | لغة يودا | `x-yoda` | ❌ | ✅ | — | سياق فقط. ترتيب الكلمات OSV. |

راجع [اللغات المصطنعة، وأنظمة الكتابة، والإملاء](/docs/guides/conlangs-scripts-orthography) لمعرفة متطلبات خطوط PUA، وقيود Unicode، وكيفية إضافة لغتك الخاصة.

## الإعدادات المسبقة للغات

يدعم معالج `init` أسماء الإعدادات المسبقة للإعداد السريع. يمكنك مزج الإعدادات المسبقة مع الرموز الفردية.

| الإعداد المسبق | يتوسع إلى |
|--------|-----------|
| `european` | fr, de, es, it, pt, nl |
| `asian` | ja, zh, ko |
| `global` | fr, es, de, ja, zh, ko, pt, ar |
| `nordic` | da, fi, nb, sv |

```bash
# Mix presets with individual codes
champollion init
# → Target languages: european, ja
# → Resolves to: fr, de, es, it, pt, nl, ja
```

## إضافة أي لغة

يمكن لـ champollion الترجمة إلى **أي لغة يعرفها نموذجك اللغوي الكبير (LLM)** — الجدول أعلاه يسرد فقط اللغات التي تحتوي على إعدادات سياق مسبقة مدمجة. لإضافة لغة غير مدرجة، قم بتضمين رمز BCP-47 الخاص بها في تكوينك:

```json
{
  "languages": {
    "sw": {},
    "am": {
      "register": "Formal Amharic. Professional register with Geʽez script."
    }
  }
}
```

سيقوم LLM بالترجمة باستخدام معرفته التدريبية باللغة. يمنحك تعيين `register` التحكم في النبرة، والرسمية، والاصطلاحات الإملائية. راجع [التكوين](/docs/getting-started/configuration) للحصول على التفاصيل.

## بطاقات اللغات {#language-cards}

تحتوي كل لغة مدمجة على **بطاقة لغة (Language Card)** — وهي ملف JSON موحد في `shared/language-cards/` يحتوي على جميع البيانات الوصفية: السياقات، والرسمية، ودعم الطرق، وقواعد الطباعة، والتصنيف الأنسابي، والتحديات اللغوية، وموارد معالجة اللغات الطبيعية (NLP).

### بنية البطاقة الموحدة

يتم تحميل كل بطاقة بشكل مبكر (eagerly) عند الاستيراد. لا يوجد مستوى مرجعي منفصل — تعيش جميع البيانات في ملف واحد لكل لغة. يتم إثراء البطاقات من مصادر موثوقة:

| المصدر | البيانات |
|--------|------|
| [Glottolog](https://glottolog.org) | تصنيف العائلة، سلسلة النسب، رمز Glottocode |
| [WALS](https://wals.info) | تصنيف الجنس (Genus)، السمات النمطية |
| [CLDR](https://cldr.unicode.org) | نظام الكتابة، الاتجاه، قواعد الجمع، الطباعة |
| [ISO 15924](https://unicode.org/iso15924/) | رموز أنظمة الكتابة |

### حقول البطاقة الرئيسية

| الحقل | ماذا يحتوي |
|-------|------------------|
| **`nativeName`** | الاسم المحلي (Endonym) — اسم اللغة كما يطلق عليها متحدثوها، بنظام كتابتها الخاص (مثل: ქართული، Runasimi) |
| **`classification`** | المرساة الأنسابية: العائلة، الجنس (genus)، سلسلة النسب الكاملة من Glottolog |
| **`contactInfluences`** | تاريخ الاتصال العالمي — طبقات الاستعارة، اللغات الفوقية (superstrates)، اللغات التحتية (substrates) |
| **نظام الرسمية (Formality system)** | تمييز T-V، مستويات الكلام، keigo، الأدوات، إلخ. |
| **الإعدادات المسبقة للسياق (Register presets)** | إعدادات مسبقة مسماة لمطالبات LLM خاصة بطابع اللغة |
| **دعم الطرق (Method support)** | واجهات برمجة تطبيقات (APIs) الترجمة التي تدعم هذه اللغة |
| **إرشادات الجنس (Gender guidance)** | قواعد الجنس النحوي ونصائح الكتابة الشاملة |
| **نظام الكتابة/الاتجاه (Script/direction)** | رمز نظام الكتابة ISO 15924 والاتجاه (RTL/LTR) |
| **القواعد (Rules)** | الطباعة (علامات الاقتباس، المسافات)، الأحرف الكبيرة، فئات الجمع |
| **`glottocode`** | المعرف الأساسي من Glottolog للإسناد الترافقي |
| **`dataSources`** | تتبع المصدر (مثل: `["glottolog-5.3", "cldr-48"]`) |

### إنشاء هيكل بطاقة لغة جديدة

استخدم المولد لإنشاء هيكل بطاقة من مصادر البيانات الموثوقة (IANA، CLDR، Glottolog):

```bash
# Preview what would be generated
node scripts/generate-language-card.mjs sw --dry-run

# Generate a unified card
node scripts/generate-language-card.mjs sw
```

يقوم المولد بملء البيانات الوصفية تلقائيًا (الرموز، نظام الكتابة، الاتجاه، صيغ الجمع، علامات الاقتباس، دعم الطرق، التصنيف) ويضع علامة TODO على حقول التقييم اللغوي ليتم تنسيقها بشريًا.

### استخدام مفاتيح الإعدادات المسبقة

بدلاً من كتابة نص السياق بالكامل، يمكنك استخدام اسم مفتاح إعداد مسبق:

```json
{
  "languages": {
    "fr": "casual-tu",
    "ko": "formal-hapsyo",
    "ja": "polite"
  }
}
```

يقوم Champollion بحل المفتاح إلى مطالبة السياق الكاملة. قم بتشغيل `npx champollion init` لرؤية الإعدادات المسبقة المتاحة لكل لغة.

### أمثلة على الإعدادات المسبقة

| اللغة | الإعدادات المسبقة | الافتراضي |
|----------|---------|--------|
| الفرنسية | `formal-vous`, `casual-tu` | `formal-vous` |
| الكورية | `polite-haeyo`, `formal-hapsyo`, `casual-hae` | `polite-haeyo` |
| اليابانية | `polite`, `formal-keigo`, `casual` | `polite` |
| الألمانية | `formal-Sie`, `casual-du` | `formal-Sie` |
| التايلندية | `neutral-professional`, `polite-male`, `polite-female` | `neutral-professional` |
| الإسبانية | `neutral-professional`, `formal-usted`, `casual-tuteo` | `neutral-professional` |

راجع [المساهمة ببطاقة لغة](https://github.com/gamedaysuits/champollion) للحصول على المواصفات الكاملة، بما في ذلك التحقق من صحة الحقول وقائمة التحقق الخاصة بطلبات السحب (PR).
