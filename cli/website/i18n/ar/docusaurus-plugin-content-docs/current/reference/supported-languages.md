# اللغات المدعومة

يأتي champollion مزوداً بـ **بطاقات اللغات (Language Cards)** — وهي ملفات تكوين مهيكلة لـ 50 لغة. تحتوي كل بطاقة على إعدادات أسلوب الخطاب المسبقة، وبيانات وصفية لنظام الرسمية، وشارات دعم الطرق، وقواعد الطباعة، ومعلومات نظام الكتابة. يمكن إضافة أي لغة يعرفها نموذج LLM الخاص بك عبر سطر تكوين واحد — وهذه هي اللغات التي تمتلك أساليب خطاب منقّحة وجاهزة للإنتاج.

---

## طرق الترجمة

يمكن لكل لغة استخدام طريقة أو أكثر من طرق الترجمة التالية:

| الأيقونة | الطريقة | كيف تعمل | التكلفة |
|------|--------|-------------|------|
| 🟢 | **Google Translate** | خط أساس للترجمة الآلية العصبية. 194 لغة. سلاسل نصوص مفتاح-قيمة فقط — لا يمكنها ترجمة محتوى Markdown بأمان. | حوالي 20 دولاراً / 1 مليون حرف |
| 🔵 | **LLM (OpenRouter)** | أي لغة يعرفها النموذج. مطالبات موجهة بأسلوب الخطاب. تعالج نصوص مفتاح-قيمة + محتوى Markdown. | تختلف بحسب النموذج |
| 🟣 | **LLM-Coached** | LLM + قواميس القواعد + بيانات تدريب وتوجيه محقونة في المطالبات. الأفضل للغات المعقدة صرفياً. | تختلف بحسب النموذج |
| 🟠 | **API (Plugin)** | مسارات ترجمة يستضيفها المجتمع وتُقدَّم عبر HTTP. [تتطلع للسيادة على البيانات](/docs/network/community/low-resource-languages). | تختلف بحسب المزود |

عيّن `GOOGLE_TRANSLATE_API_KEY` لـ Google Translate، أو `OPENROUTER_API_KEY` لطرق LLM. راجع [طرق الترجمة](/docs/guides/translation-methods) للاطلاع على التفاصيل الكاملة.

## اللغات الأصلية وقليلة الموارد

لا تدعم خدمات الترجمة الآلية التجارية هذه اللغات. يوفر champollion الأدوات اللازمة للمجتمعات اللغوية لبناء طرقها الخاصة بموجب [مبادئ سيادة المجتمع على البيانات](/docs/network/community/low-resource-languages).

| | اللغة | الرمز | Google | LLM | Coached | نظام الكتابة | الحالة |
|---|----------|------|:------:|:---:|:-------:|--------|--------|
| 🪶 | كري السهول | `crk` | ❌ | ✅ | ✅ | 🔤 SRO←المقطعية | 🚧 قيد التطوير |
| 🌄 | الكيتشوا | `qu` | ✅ | ✅ | — | — | روناسيمي (Runasimi). لواحق الأدلة والإثبات. |

:::info[لغة كري السهول قيد التطوير النشط]
إن أسلوب الخطاب، والبنية التحتية للتوجيه، ومحوّل نظام الكتابة، وبيئة التقييم الخاصة بلغة كري السهول (Plains Cree) تعمل جميعها، لكن مسار الترجمة **لم يُطرح بعد**. نحن نعمل مع المجتمعات اللغوية بموجب [مبادئ سيادة المجتمع على البيانات](/docs/network/community/low-resource-languages) لضمان الجودة قبل الإصدار. راجع [دعم لغة قليلة الموارد](/docs/network/community/low-resource-languages) للاطلاع على القصة كاملة — وكيف يمكنك المساهمة.
:::

:::tip[إضافة المزيد من اللغات قليلة الموارد]
صُمم نظام الإضافات لطرق الترجمة في champollion خصيصاً لهذا الغرض. يمكن لأي مجتمع لغوي بناء طريقة ترجمة مخصصة واستضافتها تحت إدارته الخاصة، وتوفيرها عبر [طريقة API](/docs/guides/serving-a-method). تتبع [لوحة صدارة الطرق](/leaderboard) الدرجات لأي زوج لغوي — قم ببناء طريقة، وشغّل بيئة الاختبار، وتصدّر قائمة الدرجات.
:::

## اللغات المصنوعة

تُدعم اللغات المصنوعة (Conlangs) عبر أساليب خطاب LLM ومحوّلات أنظمة كتابة اختيارية. وهي تستخدم البنية التحتية ذاتها التي تستخدمها اللغات الحقيقية — حيث تعمل بوابة الجودة، ونظام التوجيه، ومسار تحويل نظام الكتابة بالطريقة ذاتها تماماً.

| | اللغة | الرمز | Google | LLM | نظام الكتابة | ملاحظات |
|---|----------|------|:------:|:---:|--------|-------|
| 🖖 | الكلنغونية | `tlh` | ❌ | ✅ | 🔤 الكتابة بالحروف اللاتينية←pIqaD | يتطلب خط PUA. مفردات مارك أوكراند. |
| 🧝 | السندارينية (لغة إلف تولكين) | `x-elvish-s` | ❌ | ✅ | 🔤 اللاتينية←Tengwar | يتطلب خط CSUR PUA. |
| 🏴‍☠️ | إنجليزية القراصنة | `x-pirate` | ❌ | ✅ | — | أسلوب خطاب فقط. استعارات بحرية. |
| 🦸 | الكريبتونية | `x-kryptonian` | ❌ | ✅ | 🔤 اللاتينية←الكريبتونية | يتطلب خط PUA. |
| 🎭 | الإنجليزية الشكسبيرية | `x-shakespeare` | ❌ | ✅ | — | أسلوب خطاب فقط. صيغ Thee/thou، و -eth/-est. |
| 🐸 | أسلوب يودا | `x-yoda` | ❌ | ✅ | — | أسلوب خطاب فقط. ترتيب كلمات مفعول-فاعل-فعل (OSV). |

راجع [اللغات المصنوعة، وأنظمة الكتابة وقواعد الإملاء](/docs/guides/conlangs-scripts-orthography) للاطلاع على متطلبات خطوط PUA، وقيود Unicode، وكيفية إضافة لغتك الخاصة.

## الإعدادات المسبقة للغات

يدعم معالج `init` أسماء الإعدادات المسبقة للإعداد السريع. يمكنك الجمع بين الإعدادات المسبقة والرموز الفردية.

| الإعداد المسبق | يتوسع إلى |
|--------|-----------|
| `european` | fr, de, es, it, pt, nl |
| `asian` | ja, zh, ko |
| `global` | fr, es, de, ja, zh, ko, pt, ar |
| `nordic` | da, fi, nb, sv |

```bash
# Mix presets with individual codes
champollion init
# → Target languages: european, ja
# → Resolves to: fr, de, es, it, pt, nl, ja
```

## إضافة أي لغة

يمكن لـ champollion الترجمة إلى **أي لغة يعرفها نموذج LLM الخاص بك** — يقتصر الجدول أعلاه على إدراج اللغات التي تحتوي على إعدادات مسبقة مدمجة لأسلوب الخطاب. لإضافة لغة غير مدرجة، ضمّن رمز BCP-47 الخاص بها في ملف التكوين:

```json
{
  "languages": {
    "sw": {},
    "am": {
      "register": "Formal Amharic. Professional register with Geʽez script."
    }
  }
}
```

سيقوم نموذج LLM بالترجمة باستخدام المعرفة التي اكتسبها أثناء تدريبه على اللغة. يمنحك ضبط `register` التحكم في النبرة، ومستوى الرسمية، وقواعد الإملاء المتبعة. راجع [التكوين](/docs/getting-started/configuration) للاطلاع على التفاصيل.

## بطاقات اللغات {#language-cards}

تمتلك كل لغة مدمجة **بطاقة لغة** — وهي ملف JSON موحد في `shared/language-cards/` يحتوي على جميع البيانات الوصفية: أساليب الخطاب، والرسمية، ودعم الطرق، وقواعد الطباعة، والتصنيف الجيني، والتحديات اللغوية، وموارد معالجة اللغة الطبيعية (NLP).

### معمارية البطاقة الموحدة

يتم تحميل كل بطاقة تحميلاً مسبقاً عند الاستيراد. لا توجد طبقة مرجعية منفصلة — فجميع البيانات موجودة في ملف واحد لكل لغة. تُثرى البطاقات من مصادر موثوقة:

| المصدر | البيانات |
|--------|------|
| [Glottolog](https://glottolog.org) | تصنيف العائلة، وسلسلة النسب، ومعرّف Glottocode |
| [WALS](https://wals.info) | تصنيف الجنس اللغوي، والخصائص النمطية |
| [CLDR](https://cldr.unicode.org) | نظام الكتابة، والاتجاه، وقواعد الجمع، والطباعة |
| [ISO 15924](https://unicode.org/iso15924/) | رموز أنظمة الكتابة |

### الحقول الرئيسية للبطاقة

| الحقل | ما يحتويه |
|-------|------------------|
| **`nativeName`** | الاسم الذاتي للغة (Endonym) — اسم اللغة كما تسمي نفسها به، بنظام كتابتها الأصلي (مثل: ქართული، Runasimi) |
| **`classification`** | الرابط الجيني: العائلة، والجنس اللغوي، وسلسلة النسب الكاملة من Glottolog |
| **`contactInfluences`** | تاريخ الاتصال الشامل — طبقات الاستعارة، والطبقات اللغوية العليا (superstrates) والدنيا (substrates) |
| **نظام الرسمية** | تمييز T-V، ومستويات الخطاب، وkeigo، والأدوات، وما إلى ذلك |
| **إعدادات أسلوب الخطاب المسبقة** | إعدادات مسبقة لمطالبات LLM بأسماء محددة تناسب طبيعة اللغة |
| **دعم الطرق** | أي من واجهات برمجة تطبيقات (APIs) الترجمة تدعم هذه اللغة |
| **توجيهات التذكير والتأنيث** | قواعد الجنس النحوي وإرشادات الكتابة الشاملة |
| **نظام الكتابة/الاتجاه** | رمز نظام الكتابة وفق ISO 15924 والاتجاه RTL/LTR |
| **القواعد** | الطباعة (علامات الاقتباس، المسافات)، وحالة الأحرف الكبيرة، وفئات الجمع |
| **`glottocode`** | معرّف Glottolog القياسي للإسناد الترافقي |
| **`dataSources`** | تتبع المصدر والأصل (مثل: `["glottolog-5.3", "cldr-48"]`) |

### إنشاء هيكل بطاقة لغة جديدة

استخدم أداة التوليد لإنشاء هيكل بطاقة انطلاقاً من مصادر بيانات موثوقة (IANA و CLDR و Glottolog):

```bash
# Preview what would be generated
node scripts/generate-language-card.mjs sw --dry-run

# Generate a unified card
node scripts/generate-language-card.mjs sw
```

تقوم أداة التوليد بتعبئة البيانات الوصفية تلقائياً (الرموز، ونظام الكتابة، والاتجاه، وصيغ الجمع، وعلامات الاقتباس، ودعم الطرق، والتصنيف) وتضع علامة TODO على الحقول التي تتطلب حكماً لغوياً لمراجعتها وتنقيحها يدوياً بواسطة متخصصين.

### استخدام مفاتيح الإعدادات المسبقة

بدلاً من كتابة نص أسلوب الخطاب بالكامل، يمكنك استخدام اسم مفتاح الإعداد المسبق:

```json
{
  "languages": {
    "fr": "casual-tu",
    "ko": "formal-hapsyo",
    "ja": "polite"
  }
}
```

يقوم Champollion بمطابقة المفتاح مع مطالبة أسلوب الخطاب الكاملة. شغّل `npx champollion init` لعرض الإعدادات المسبقة المتاحة لكل لغة.

### أمثلة على الإعدادات المسبقة

| اللغة | الإعدادات المسبقة | الافتراضي |
|----------|---------|--------|
| الفرنسية | `formal-vous`, `casual-tu` | `formal-vous` |
| الكورية | `polite-haeyo`, `formal-hapsyo`, `casual-hae` | `polite-haeyo` |
| اليابانية | `polite`, `formal-keigo`, `casual` | `polite` |
| الألمانية | `formal-Sie`, `casual-du` | `formal-Sie` |
| التايلاندية | `neutral-professional`, `polite-male`, `polite-female` | `neutral-professional` |
| الإسبانية | `neutral-professional`, `formal-usted`, `casual-tuteo` | `neutral-professional` |

راجع [المساهمة ببطاقة لغة](https://github.com/gamedaysuits/champollion) للاطلاع على المواصفات الكاملة، بما في ذلك التحقق من صحة الحقول وقائمة تدقيق طلبات السحب (PR checklist).
