# لوكلاء الذكاء الاصطناعي

أنت هنا لأن شخصاً ما طلب منك المساعدة في بناء ترجمة آلية للغته باستخدام Champollion. هذا القسم هو دليلك الإرشادي. وهو دقيق حيث تكون صفحات المجتمع بسيطة ومباشرة: أسماء الحقول، والأوضاع، وحالات الرفض، والأوامر مقتبسة من الشيفرة البرمجية.

**اقرأ [عقد التشغيل](/docs/agents/contract) أولاً.** فهو موجز، وهو الجزء الذي لا يجوز لك أن تخطئ فيه: ما يُسمح لك بقراءته، وما يجب عليك السؤال عنه، وما لا ينبغي لك أبداً اتخاذ قرار بشأنه نيابة عن المجتمع، وما هي القواعد التي تفرضها الأدوات مقابل تلك التي لا يمكن لأحد غيرك الالتزام بها.

## الاتصال

المسارات الموجهة عبارة عن خادم MCP. أضفه إلى إعدادات عميل MCP الخاص بك:

```json
{
  "mcpServers": {
    "champollion": { "command": "npx", "args": ["-y", "champollion-mcp-server"] }
  }
}
```

الملف التعريفي الافتراضي هو المسارات الموجهة: ست أدوات — `start_project`،
و`project_status`، و`run_next_step`، و`add_data`، و`try_translation`،
و`explain`. كل خطوة في المسارات هي أيضاً أمر سطر أوامر عادي
(`champollion`، و`nmt-forge`، و`mt-eval`)، لذا يمكن لوكيل لا يستخدم MCP اتباع
المسارات نفسها من خلال وحدة طرفية.
