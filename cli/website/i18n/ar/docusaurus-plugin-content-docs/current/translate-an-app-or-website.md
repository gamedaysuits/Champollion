# ترجمة تطبيق أو موقع إلكتروني

تحتفظ التطبيقات والمواقع الإلكترونية بنصوصها — مثل الأزرار والقوائم والرسائل والصفحات — في
ملفات، ملف لكل لغة. يمكن لـ Champollion ملء ملف لغتك
نيابةً عنك، وإبقاؤه محدثاً كلما تغيّر النص الأصلي. أمر واحد يكفي
للقيام بذلك:

```bash
npx champollion sync
```

يعثر على ملفات لغات تطبيقك، ويترجم فقط ما هو مفقود أو
مُعدَّل، ويفحص كل ترجمة قبل كتابتها، ويترك الباقي
دون تغيير.

## من هو المترجم الذي ينجز العمل

أنت تختار، لكل لغة:

- **مترجمك الخاص**، المبني على المسارات — تصله الأدوات
  بتطبيقك. إذا تدرّب على جُمل خاصة، فلن يتصل إلا بعد أن
  تحدّد من وافق من بين الأشخاص المؤتمنين على الكلمات.
- **نموذج ذكاء اصطناعي أو خدمة ترجمة** — للغات التي
  تتعامل معها هذه الخدمات بكفاءة بالفعل. ترسل هذه الخدمات نصوص تطبيقك إلى الشركة التي تديرها، لذا
  استخدمها مع النصوص التي لا مانع من مشاركتها.
- **خدمتك الخاصة**، على عنوان تحدده أنت.

## ما يتولى إدارته

- **ما تغيّر فقط.** يتذكر ما ترجمه سابقاً، حتى لا تدفع
  مرتين أبداً مقابل الجملة نفسها.
- **فحوصات قبل الكتابة.** يتم رصد النتائج الفارغة، أو نسخ الأصل كما هو، أو تكرار
  الكلمات في حلقة مفرغة، أو النصوص الأطول بكثير مما ينبغي، أو الأجزاء المفقودة، أو
  الأبجدية الخاطئة، ورَفْضها. ترصد هذه الفحوصات المخرجات التالفة،
  لا المعنى الخاطئ — فالقول الفصل يظل دائماً للمتحدث باللغة.
- **ملفاتك وصيغك المفضلة.** صفحات JSON وYAML وTOML وMarkdown،
  وأُطُر عمل التطبيقات والمواقع الإلكترونية الشائعة.

## من يحق له الاستخدام

مجاني للاستخدام غير التجاري — كتطبيق مدرسة، أو موقع لمجتمع محلي، أو
خدمة عامة. منتجات الشركات التجارية غير مشمولة بالترخيص المجاني؛ ولكن إذا رغب مجتمع
متحدثين في استخدامه لأغراض تجارية، فيمكنه الطلب وسيحصل على الترخيص مجاناً.
تجد التفاصيل في [من يحق له استخدام هذا](/docs/getting-started/who-may-use-this).
