## Vereisten

- **Node.js 20.11+** (native ESM)
- Een API-sleutel voor vertaling (zie hieronder)

## Installatie

<Tabs>
  <TabItem value="npm" label="npm" default>

```bash
npm install --save-dev champollion
```

  </TabItem>
  <TabItem value="npx" label="npx (no install)">

  </TabItem>


  </TabItem>
  <TabItem value="yarn" label="yarn">

```bash
yarn add --dev champollion
```

## Een API-sleutel ophalen

Champollion heeft een vertaalbackend nodig. Kies er een:

| Provider | Omgevingsvariabele | Het meest geschikt voor |
|----------|---------------------|--------------------------|
| **OpenRouter** (aanbevolen) | `OPENROUTER_API_KEY` | Projecten met veel content, Markdown, 200+ modellen |
| **Gemini** (gratis tier) | `GEMINI_API_KEY` | Kosteloos beginnen, goede kwaliteit |
| **OpenAI** | `OPENAI_API_KEY` | Directe toegang tot OpenAI |
| **Anthropic** | `ANTHROPIC_API_KEY` | Directe toegang tot Claude, genuanceerde tekst |
| **DeepL** | `DEEPL_API_KEY` | Europese talen, ingebouwde formaliteit |
| **Google Translate** | `GOOGLE_TRANSLATE_API_KEY` | Sleutel-waardeparen in grote volumes, 194 talen |
| **Microsoft Translator** | `MICROSOFT_TRANSLATOR_API_KEY` | Azure, 135 talen |
| **LibreTranslate** | `LIBRETRANSLATE_API_URL` | Zelf gehost, privacygericht |
| **Tilde MT** | `TILDE_API_KEY` | Baltische en Europese talen, gehost in de EU |
| **Translated (Lara)** | `LARA_ACCESS_KEY_ID` + `LARA_ACCESS_KEY_SECRET` | Professionele MT, 200 talen |
| **Een model op uw eigen machine** (Ollama, LM Studio, vLLM of een model dat u zelf heeft getraind en host) | geen (`LOCAL_API_BASE` wanneer het zich niet op het standaardadres van Ollama bevindt) | Geen sleutel; er verlaat niets uw computer |

<Tabs>
  <TabItem value="openrouter" label="OpenRouter (recommended)" default>

[OpenRouter](https://openrouter.ai) biedt een uniforme API voor 200+ LLM-modellen. Gratis laag beschikbaar.

```bash
# Sign up at https://openrouter.ai, then:
export OPENROUTER_API_KEY=sk-or-v1-...
```

Of voeg toe aan `.env.local`:

```bash
OPENROUTER_API_KEY=sk-or-v1-your-key-here
```

Het meest geschikt voor: inhoudsrijke projecten, Markdown-vertaling en projecten die inhoudsbewuste afscherming nodig hebben (codeblokken, shortcodes, interpolatievariabelen).

  </TabItem>
  <TabItem value="google" label="Google Translate">

```bash
export GOOGLE_TRANSLATE_API_KEY=...
```

Ideaal voor: grote volumes sleutel-waardeparen van strings (194 talen). **Niet aanbevolen** voor Markdown-content — Google Translate houdt geen rekening met codeblokken, shortcodes of interpolatievariabelen.

:::tip[Slimme detectie]
Als alleen `GOOGLE_TRANSLATE_API_KEY` is ingesteld (geen OpenRouter-sleutel), schakelt champollion automatisch over naar Google Translate. Er is geen configuratiewijziging nodig.
:::

  </TabItem>
</Tabs>
