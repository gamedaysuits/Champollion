# Desarrollo e implementación de traducción automática sobre rieles y con salvaguardas

**Cree un traductor para su lengua a partir de las frases que ya tiene.**

- **Sobre rieles:** cada paso dispuesto para usted, en orden.
- **Con salvaguardas:** verificaciones que evitan los errores habituales y mantienen sus
  palabras en sus manos.

Creado pensando en las comunidades de lenguas indígenas y de bajos recursos.

**¿Primera vez aquí?** [Lea primero la historia](/docs/what-is-champollion) — cuatro páginas
cortas, unos veinte minutos.
