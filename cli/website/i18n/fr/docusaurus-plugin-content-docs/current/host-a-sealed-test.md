# Organiser un test scellé

Parfois, le meilleur traducteur pour votre langue viendra de quelqu'un d'autre —
un chercheur, un étudiant, une entreprise. Un **test scellé** leur permet de le prouver sur
*vos* phrases, sans jamais voir ces phrases.

## Comment cela fonctionne

Vos phrases de test sont verrouillées avec une clé, sur votre ordinateur. Les personnes qui souhaitent
participer envoient leurs traducteurs. Votre ordinateur exécute chacun d'eux sur les
phrases verrouillées, et seuls les scores en ressortent — jamais les phrases, et
jamais les traductions.

Le test reste ainsi un véritable test : personne ne peut l'étudier ni s'y ajuster, car
personne ne peut le lire.

## Ce que vous décidez

Vous définissez les conditions, avant que quiconque ne participe :

- **Ce qui est jugé suffisant** pour l'emporter.
- **Ce qu'il advient d'une méthode gagnante :**
  - **elle devient vôtre** — elle vous revient, à vous qui détenez le test ;
  - **son créateur la conserve** — vous l'évaluez, et ne gardez tout au plus qu'une copie verrouillée pour
    vérification ;
  - **son créateur la conserve, mais la partage avec tout le monde** — il doit la publier
    ouvertement.
- **S'il y a un prix** ou non, et qui le finance. Champollion ne prélève aucune
  part sur les prix.

## Ce qui existe aujourd'hui

Les outils pour les tests scellés fonctionnent : verrouiller un jeu de données, exécuter les
traducteurs soumis sur un ordinateur coupé d'Internet, et ne publier que
les scores. Mais cela n'est **pas encore sur les rails** — aujourd'hui, cela implique de suivre un
manuel plus long, et non de répondre pas à pas aux questions d'un assistant.

Qui détient la clé aujourd'hui : quiconque verrouille le jeu de données. Aucune communauté n'a encore désigné
de personnes pour détenir la clé ensemble, et Champollion ne détient aucune part d'aucune clé.

Les tests scellés ouverts, lorsqu'il y en a, sont répertoriés sur la
page des [tâches partagées](/shared-tasks).
