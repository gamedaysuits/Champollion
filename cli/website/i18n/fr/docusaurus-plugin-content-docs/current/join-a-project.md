# Rejoindre un projet

Un traducteur pour une langue comptant peu de phrases écrites a besoin de nombreuses mains.
**Rejoindre un projet** permet de se rencontrer : les personnes qui développent un traducteur
répertorient leur projet, indiquent ce qui leur serait utile, et d'autres personnes le leur proposent.

## Si vous souhaitez aider

Parcourez les projets sur la page [Rejoindre un projet](/join). Chacun présente les
deux langues, la finalité du projet et ce que demandent ses détenteurs —
des phrases sur certains thèmes, une liste de mots, une méthode à essayer.

Lorsque vous proposez quelque chose :

- **Vous l'envoyez au projet, et non au public.** Votre fichier est téléversé dans
  l'espace de stockage de projet de Champollion, où seuls vous, les détenteurs de ce projet et
  les personnes qui gèrent cet espace de stockage pouvez l'ouvrir.
- **Il est détenu par vous deux.** Vous l'avez soumis ; ils décident de l'accepter
  ou non. Lorsqu'ils l'acceptent, une note consigne qui l'a proposé, qui l'a accepté
  et ce qui a été convenu.
- **Ils voient qui vous êtes.** Les détenteurs du projet voient le nom et l'adresse courriel
  associés à votre proposition, afin de pouvoir vous contacter. La page publique n'affiche jamais d'adresse courriel.
- **Ils peuvent refuser.** Un projet peut décliner une offre.
- **Vous pouvez la retirer** avant qu'ils ne l'aient acceptée. Le retrait (ou leur
  refus) modifie l'état de l'offre mais ne supprime pas le fichier, et les
  détenteurs du projet peuvent toujours l'ouvrir — ne proposez donc que ce que vous êtes disposé
  à leur laisser conserver.
- **Sa note prime.** Les outils ne proposeront pas un fichier marqué comme privé, ou
  un fichier pour lequel les locuteurs n'ont pas tous donné leur accord — seuls ses détenteurs peuvent modifier cela.

Ce que vous n'obtiendrez pas d'un projet : ses phrases. Rien de ce qui leur appartient ne vous est
envoyé sans leur accord.

## Si vous développez un traducteur

Vous pouvez répertorier votre projet une fois qu'il est lancé sur les rails. Vous préciserez :

- les deux langues et la finalité du traducteur,
- le nom que vous souhaitez afficher — jamais votre adresse courriel,
- ce qui vous aiderait le plus.

Chaque fiche fait l'objet d'un court examen avant d'apparaître, afin que la page demeure
digne de confiance. Lorsque quelqu'un propose une contribution, vous décidez : acceptez-la, et elle
arrive dans la boîte de réception de votre projet avec une note vous nommant tous les deux, prête à être
intégrée comme n'importe quel fichier — ou refusez-la.

## Ce qui peut être proposé aujourd'hui

Des fichiers : des phrases, des listes de mots et des méthodes de traduction à essayer. Aider d'autres manières —
vérifier des ébauches à distance ou prêter de la puissance de calcul — n'est pas encore possible.

Lorsqu'aucun projet n'est encore répertorié, la page l'indique en toute franchise.
