# Stellen Sie Ihre Testsätze beiseite

Bevor ein Übersetzer etwas lernt, stellen Sie einige Sätze beiseite, um ihn
damit zu testen. Das ist der wichtigste Schritt auf den Schienen. Jedes
Ergebnis, das Sie jemals sehen werden, wird an diesen Sätzen gemessen – wenn sie
also fehlerhaft sind, ist jedes Ergebnis fehlerhaft.

## Warum das wichtig ist

Stellen Sie sich vor, Sie würden einen Schüler mit genau den Fragen aus seinen
Hausaufgaben testen. Er würde glänzend abschneiden, und Sie würden nichts darüber
erfahren, was er wirklich kann. Bei einem Übersetzer ist es genauso. Wenn er anhand
von Sätzen getestet wird, aus denen er gelernt hat, erinnert er sich schlicht an sie.

Deshalb werden die Testsätze getrennt aufbewahrt: Kein Übersetzer lernt jemals
daraus, und sie werden ausschließlich zur Beurteilung verwendet.

## Gute Testsätze auswählen

- **Von einer fließend sprechenden Person geprüft.** Jeder Satz und seine
  Übersetzung sollten korrekt sein, so wie man es in Ihrer Gemeinschaft sagt.
- **Echte Sätze, die Sie übersetzen lassen möchten.** Alltägliche Dinge, die Sie
  zu Hause sagen, auf einem Zettel notieren oder im Unterricht vermitteln würden –
  jene Arten von Sätzen, für die der Übersetzer gedacht ist.
- **Eine Mischung.** Fragen, Aussagen, Bitten; kurze und längere Sätze.
- **Nicht von den Sätzen kopiert, mit denen Sie lehren.** Schreiben Sie sie
  neu oder übernehmen Sie sie aus einer separaten Quelle.
- **Genauso geschrieben wie der Rest.** Einigen Sie sich vor Beginn auf eine
  einheitliche Schreibweise der Sprache.
- **So viele, wie Ihre sprechende Person prüfen kann.** Ein paar Dutzend sind ein
  Anfang; bei so wenigen ist jedes Ergebnis nur ein grober Richtwert, und die
  Werkzeuge zeigen Ihnen eine breite Spanne statt einer einzelnen Zahl. Ein paar
  Hundert ermöglichen es Ihnen, feinere Unterschiede zu erkennen.

## Wie die Schienen sie schützen

Sie legen sie an ihren eigenen Ort – das Testregal – und die Werkzeuge kennzeichnen sie:

- privat: verbleiben auf diesem Computer, sofern die verwahrenden Personen nicht
  anders entscheiden,
- niemals zum Lernen verwendet,
- ausgeschlossen von allem, was die Werkzeuge ausgeben.

Bevor das Lehren dann beginnt, wird jeder Satz, aus dem der Übersetzer lernen
würde, mit den Testsätzen abgeglichen. Kopien und Beinahe-Kopien werden beiseitegestellt,
damit der Übersetzer nicht für reines Erinnerungsvermögen belohnt werden kann.

Und jedes Mal, wenn die Trainingswerkzeuge die Testsätze bewerten, wird dies
protokolliert. Im Alltag
wird der Fortschritt anhand einer separaten Gruppe von **Übungssätzen** beurteilt,
damit die Testsätze für die entscheidenden Momente unverbraucht bleiben.

überhaupt ein Lehren begann. Ohne diesen Schritt hätte das erste Ergebnis besser
ausgesehen, als es in Wirklichkeit war.

## Einen Testdatensatz später teilen

Ihre Testsätze können für immer auf Ihrem Computer bleiben – das ist die Voreinstellung.
Wenn Sie jemals möchten, dass andere sich daran messen können, können die Werkzeuge
den Datensatz auf einer von vier Stufen registrieren:

- **Hier behalten** – niemals registriert; nichts verlässt diesen Computer.
- **Privat gelistet** – es wird nur eine Beschreibung des Datensatzes geteilt, niemals die
  Sätze. Ergebnisse können veröffentlicht werden, ohne dass jemand die Daten zu Gesicht bekommt.
- **Öffentlich gelistet** – eine Beschreibung sowie ein Verweis darauf, wo der Datensatz
  bereits veröffentlicht ist. Nur für Datensätze, deren Lizenz dies erlaubt. Champollion
  hostet die Sätze zu keinem Zeitpunkt.
- **Versiegelt** – mit einem Schlüssel auf Ihrem Computer verschlossen, sodass andere ihre
  Übersetzer daran testen können, ohne sie jemals zu sehen.
