# Entwicklung und Bereitstellung maschineller Übersetzung auf Schienen mit Leitplanken

**Erstellen Sie einen Übersetzer für Ihre Sprache aus den Sätzen, die Sie bereits haben.**

- **Auf Schienen:** Jeder Schritt ist für Sie vorgegeben, der Reihe nach.
- **Mit Leitplanken:** Prüfungen, die die üblichen Fehler verhindern und dafür sorgen, dass Ihre
  Wörter in Ihren Händen bleiben.

Entwickelt speziell für ressourcenarme und indigene Sprachgemeinschaften.

**Neu hier?** [Lesen Sie zuerst die Geschichte](/docs/what-is-champollion) — vier kurze
Seiten, etwa zwanzig Minuten.
