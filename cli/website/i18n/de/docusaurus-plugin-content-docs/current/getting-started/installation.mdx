# Installation

## Voraussetzungen

- **Node.js 20.11+** (natives ESM)
- Einen API-Schlüssel für die Übersetzung (siehe unten)

## Installation

<Tabs>
  <TabItem value="npm" label="npm" default>

```bash
npm install --save-dev champollion
```

  </TabItem>
  <TabItem value="npx" label="npx (no install)">

```bash
npx champollion sync
```

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

```bash
pnpm add -D champollion
```

  </TabItem>
  <TabItem value="yarn" label="yarn">

```bash
yarn add --dev champollion
```

  </TabItem>
</Tabs>

## Einen API-Schlüssel erhalten

Champollion benötigt ein Übersetzungs-Backend. Wählen Sie eines aus:

| Anbieter | Umgebungsvariable | Ideal für |
|----------|---------------------|----------|
| **OpenRouter** (empfohlen) | `OPENROUTER_API_KEY` | Inhaltsreiche Projekte, Markdown, 200+ Modelle |
| **Gemini** (kostenloser Tarif) | `GEMINI_API_KEY` | Kostenloser Einstieg, gute Qualität |
| **OpenAI** | `OPENAI_API_KEY` | Direkter GPT-4o-Zugriff |
| **Anthropic** | `ANTHROPIC_API_KEY` | Direkter Claude-Zugriff, nuancierte Texte |
| **DeepL** | `DEEPL_API_KEY` | Europäische Sprachen, integrierte Höflichkeitsform |
| **Google Translate** | `GOOGLE_TRANSLATE_API_KEY` | Große Mengen an Schlüssel-Wert-Paaren, 194 Sprachen |
| **Microsoft Translator** | `MICROSOFT_TRANSLATOR_API_KEY` | Azure, 135 Sprachen |
| **LibreTranslate** | `LIBRETRANSLATE_API_URL` | Selbstgehostet, datenschutzorientiert |
| **Tilde MT** | `TILDE_API_KEY` | Baltische & europäische Sprachen, in der EU gehostet |
| **Translated (Lara)** | `LARA_ACCESS_KEY_ID` + `LARA_ACCESS_KEY_SECRET` | Professionelle maschinelle Übersetzung, 200 Sprachen |

<Tabs>
  <TabItem value="openrouter" label="OpenRouter (recommended)" default>

[OpenRouter](https://openrouter.ai) bietet eine einheitliche API für mehr als 200 LLM-Modelle. Eine kostenlose Variante ist verfügbar.

```bash
# Sign up at https://openrouter.ai, then:
export OPENROUTER_API_KEY=sk-or-v1-...
```

Oder fügen Sie es zu `.env.local` hinzu:

```bash
OPENROUTER_API_KEY=sk-or-v1-your-key-here
```

Am besten geeignet für: inhaltslastige Projekte, Markdown-Übersetzung und Projekte, die eine inhaltsbewusste Abschirmung (Codeblöcke, Shortcodes, Interpolationsvariablen) benötigen.

  </TabItem>
  <TabItem value="google" label="Google Translate">

```bash
export GOOGLE_TRANSLATE_API_KEY=...
```

Ideal für: große Mengen an Schlüssel-Wert-Paaren (194 Sprachen). **Nicht empfohlen** für Markdown-Inhalte — Google Translate berücksichtigt keine Codeblöcke, Shortcodes oder Interpolationsvariablen.

:::tip[Intelligente Erkennung]
Wenn nur `GOOGLE_TRANSLATE_API_KEY` gesetzt ist (kein OpenRouter-Schlüssel), wechselt champollion automatisch zu Google Translate. Keine Konfigurationsänderung erforderlich.
:::

  </TabItem>
</Tabs>

## Installation überprüfen

```bash
npx champollion --help
```

Sie sollten die Liste der verfügbaren Befehle sehen. Sie sind nun bereit für den [Schnelleinstieg](/docs/getting-started/quick-start).
