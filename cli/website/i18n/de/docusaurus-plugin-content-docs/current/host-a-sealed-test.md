# Einen versiegelten Test ausrichten

Manchmal stammt der beste Übersetzer für Ihre Sprache von jemand anderem –
einer forschenden Person, einer studierenden Person, einem Unternehmen. Ein **versiegelter Test** ermöglicht es ihnen, dies an
*Ihren* Sätzen zu beweisen, ohne diese Sätze jemals zu sehen.

## Wie es funktioniert

Ihre Testsätze werden mit einem Schlüssel auf Ihrem Computer verschlossen. Personen, die
am Wettbewerb teilnehmen möchten, reichen ihre Übersetzer ein. Ihr Computer führt jeden davon an den
verschlossenen Sätzen aus, und nur die Punktzahlen werden ausgegeben – niemals die Sätze und
niemals die Übersetzungen.

So bleibt der Test ein echter Test: Niemand kann ihn analysieren oder darauf abstimmen, weil
niemand ihn lesen kann.

## Was Sie entscheiden

Sie legen die Bedingungen fest, bevor jemand antritt:

- **Was als gut genug gilt**, um zu gewinnen.
- **Was mit einer siegreichen Methode geschieht:**
  - **sie gehört Ihnen** – sie geht an Sie über, die Personen, die den Test durchführen;
  - **ihre Ersteller behalten sie** – Sie bewerten sie und behalten höchstens eine verschlossene Kopie zur
    Überprüfung;
  - **ihre Ersteller behalten sie, teilen sie aber mit allen** – sie müssen sie offen
    veröffentlichen.
- **Ob es überhaupt einen Preis gibt** und wer ihn finanziert. Champollion behält keinen
  Anteil an irgendeinem Preis ein.

## Was heute bereits existiert

Die Werkzeuge für versiegelte Tests funktionieren: das Verschließen eines Datensatzes, das Ausführen eingereichter
Übersetzer auf einem vom Internet getrennten Computer und das ausschließliche Veröffentlichen
von Punktzahlen. Doch dies läuft **noch nicht auf Schienen** – heute bedeutet es, einer
längeren Anleitung zu folgen, statt Schritt für Schritt die Fragen eines Assistenten zu beantworten.

Wer den Schlüssel heute verwahrt: wer immer den Datensatz verschließt. Bislang hat noch keine
Gemeinschaft Personen benannt, die den Schlüssel gemeinsam verwahren, und Champollion hält keinen Teil irgendeines Schlüssels.

Offene versiegelte Tests werden, sofern vorhanden, auf der Seite
[Gemeinsame Aufgaben](/shared-tasks) aufgeführt.
