# テスト用の文を取り分ける

翻訳機が何かを学習する前に、テストに使うための文をいくつか取り分けておきます。これはレール上で最も重要なステップです。今後目にするすべての評価結果は、これらの文に基づいて測定されます。そのため、文が間違っていれば、すべての結果が間違ったものになってしまいます。

## なぜ重要なのか

宿題とまったく同じ問題で生徒をテストすることを想像してみてください。とても優秀に見えるかもしれませんが、実際に何ができるのかについては何も分かりません。翻訳機も同じです。学習に使った文でテストしても、ただそれを記憶しているだけにすぎません。

そのため、テスト用の文は分けて保管されます。翻訳機がその文から学習することは決してなく、評価のためだけに用いられます。

## 適切なテスト用の文を選ぶ

- **流暢な話者が確認したもの。** それぞれの文とその翻訳が、コミュニティで実際に話されている表現として正しいものである必要があります。
- **実際に翻訳してほしい文。** 家で話すこと、メモに書くこと、授業で教えることなど、日々の暮らしで使う言葉――その翻訳機が使われる場面に合った文です。
- **さまざまな種類の文。** 疑問文、平叙文、依頼文、短いものや長いものを混ぜます。
- **学習に使う文から複製しないこと。** 新しく書き起こすか、別の情報源から用意してください。
- **他と同じ綴り（表記）にすること。** 始める前に、言語の表記方法を1つに合意しておきましょう。
- **話者が確認できる限りの数。** 数十文から始められます。ただし、数がこれだけ少ないと評価結果は大まかなものになり、ツールは単一の数値ではなく広い範囲で結果を示します。数百文あれば、より細かな違いが見えてきます。

## レールがどのように保護するか

文を所定の場所（テスト棚）に置くと、ツールによって次のように目印が付けられます。

- 非公開（private）：保管している人が別段の判断をしない限り、このコンピューター内にとどまります。
- 学習には決して使われません。
- ツールが出力する表示には含まれません。

そして、学習が始まる前に、翻訳機が学習することになるすべての文がテスト用の文と照合されます。コピーやほぼ同じ文は取り除かれるため、翻訳機が単なる記憶によって高い評価を得ることはできません。

また、トレーニングツールがテスト用の文を採点するたびに、その記録が残されます。日々の進捗は別の**練習用の文**のセットで評価されるため、ここぞという重要な場面までテスト用の文を「新鮮な状態」で保つことができます。

## 実際の様子

記録されたウォークスルー（作られた例文による具体例）では、ある家族が確認済みの文を<WalkFact of="test.pairs" />取り分けました。ツールが他の文をそれらと照合したところ、家族が学習に使おうとしていた文の中に、そのうちの<WalkFact of="twins.n" />（およそ100文に<WalkFact of="twins.pct" />文）とほぼ同じ文が見つかりました。そうしたほぼ同じ文は、学習が始まる前に取り除かれました。その手順がなければ、最初のスコアは実際よりも良く見えてしまっていたはずです。

## テストセットを後から共有する

テスト用の文はずっとコンピューターに残しておくことができます。それが既定の設定です。他の人がその文を使って評価できるようにしたい場合は、ツールを使って4つのレベルのいずれかでセットを登録できます。

- **この場所に保管（Kept here）** — 登録されず、このコンピューターから外に出ることは一切ありません。
- **非公開で掲載（Listed privately）** — セットの説明のみが共有され、文自体が共有されることは決してありません。誰にもデータを見せることなく結果を公開できます。
- **公開で掲載（Listed publicly）** — 説明に加えて、そのセットがすでに公開されている場所へのリンクを含めます。ライセンスで許可されているセットのみが対象です。Champollionが文自体をホストすることはありません。
- **封印（Sealed）** — コンピューター上で鍵をかけて保護されるため、他の人は文の内容を一切見ることなく、自分の翻訳機をテストできます。
