# プロジェクトに参加する

書かれた文が少ない言語の翻訳ツールを作るには、多くの手が必要です。
**プロジェクトに参加する**は、互いを見つけ合うための仕組みです。翻訳ツールを作っている人たちがプロジェクトを掲載し、何が役立つかを伝え、他の人たちがそれを提供します。

## 協力したい場合

[プロジェクトに参加する](/join)ページでプロジェクトを見てみてください。それぞれのプロジェクトには、2つの言語、翻訳ツールの目的、そして管理者たちが求めているもの（特定のトピックの文、単語リスト、試してみたい手法など）が表示されています。

何かを提供するとき：

- **公開されるのではなく、プロジェクトに送られます。** ファイルはChampollionのプロジェクトストレージにアップロードされ、あなた、そのプロジェクトの管理者、そしてそのストレージを運営する人だけが開くことができます。
- **双方で保持されます。** あなたが提出し、相手側がそれを受け取るかどうかを決めます。受け入れられた場合、誰が提供し、誰が受け入れ、何が合意されたかが記録に残ります。
- **相手にはあなたが誰か分かります。** プロジェクトの管理者に連絡が取れるよう、あなたが提供時に入力した名前とメールアドレスが表示されます。公開ページにメールアドレスが表示されることはありません。
- **断ることもできます。** プロジェクト側は提供を辞退する場合があります。
- **相手が受け入れる前であれば、取り下げることができます。** 取り下げた場合（または相手が辞退した場合）、提供のステータスは変わりますが、ファイルは削除されず、プロジェクトの管理者は引き続き開くことができます。そのため、相手の手元に残っても差し支えないものだけを提供してください。
- **記録（ノート）が優先されます。** 非公開とマークされたファイルや、話者全員の同意が得られていないファイルをツールが提供することはありません。それを変更できるのはその管理者だけです。

プロジェクトから手に入らないものもあります。それは文のデータです。プロジェクト側の承諾がない限り、相手のデータがあなたに送られることはありません。

## 翻訳ツールを作っている場合

レール上でプロジェクトを開始したら、掲載することができます。以下の内容を伝えます。

- 2つの言語と、翻訳ツールの目的
- 表示させたい名前（メールアドレスが表示されることはありません）
- 最も助けになること

ページの信頼性を保つため、すべての掲載内容は公開前に簡単な確認が行われます。誰かが何かを提供してくれたら、受け入れるかどうかをあなたが決めます。受け入れると、双方の名前が記されたノートとともにプロジェクトの受信箱に届き、他のファイルと同じように取り込めるようになります。あるいは辞退することもできます。

## 現在提供できるもの

ファイルです。文、単語リスト、試してみたい翻訳手法などです。遠隔からの下訳の確認や、コンピューター処理能力の貸し出しなど、他の方法での協力はまだ対象外です。

まだ掲載されているプロジェクトがない場合は、ページにその旨が率直に表示されます。
