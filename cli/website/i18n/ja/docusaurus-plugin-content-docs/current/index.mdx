# レールとガードレールに沿った機械翻訳の開発とデプロイ

**すでにお持ちの文から、自分たちの言語のための翻訳ツールを作ることができます。**

- **レールに沿って：** すべての手順が順番通りに用意されています。
- **ガードレールを備えて：** よくある間違いを防ぎ、言葉を自分たちの手元にとどめるためのチェックが行われます。

低リソース言語や先住民族言語のコミュニティを念頭に置いて構築されました。

**初めてですか？** [まずはストーリーをお読みください](/docs/what-is-champollion) — 短い4つのページで、約20分で読めます。
