# このサイトの翻訳について

このサイトは13言語で利用可能です。英語以外のすべてのロケールは、**Champollion自身によって機械翻訳されています**。これは、このドキュメントで説明しているCLIと同じものです（`npx champollion sync`）。私たちは自社ツールをドッグフーディングしています。

現在、すべての言語ペアで単一のモデル（**`google/gemini-3.1-pro-preview`**）を使用し、後述する言語ごとのレジスター（文体）と用語のガイダンスに従って翻訳しています。ベンチマークに基づくモデル選択（後述）を再構築している間、誠実なデフォルトとして意図的に1つのモデルを選択しました。したがって、これは明確に文書化された選択であり、事実と異なるように見せかけている結果ではありません。

読者の皆様に知っておいていただきたいことが2つあります。

1. **これらのページは機械翻訳です。** 後述するレジスターと用語のガイダンスを使用して生成されていますが、人間がすべての文をレビューしたわけではありません。不自然な箇所がある場合は、英語版が正式なものとなります。また、修正の提案も歓迎します。
2. **現在は1つのデフォルトモデルですが、将来的にはベンチマークごとに選択されます。** Champollionの設計では、ベンチマークによって*言語ペアごとに*翻訳モデルを選択します。開発コーパスですべての候補をスコアリングし、最もスコアの高い方法でそのロケールを翻訳します（統計的に同点の場合はコストで決定します）。言語ペアごとの勝者をここに固定する前に、独自の整合性ゲートを通じてその選択を再実行しています。**それらの実行結果が[Network leaderboard](/leaderboard)で公開されるまで、このページでは提示できないベンチマークの出所を主張することはありません。**

## 再構築中のベンチマーク選択

意図された手法（および設定が機能するように構築されている方法）は、独自の評価に基づく言語ペアごとのモデル選択です。ペアの開発コーパスですべての候補モデルをスコアリングし、最も高い総合スコアを採用し、統計的に同点の場合はコストで決定します。この一連のループは、再現したい人のためにすべて文書化されています。

現在、このページでは言語ごとの総合スコアや「ベンチマークの勝者」を公開して**いません**。これらの数値を裏付ける選択プロセスを、まずテストハーネスの整合性ゲートを通じて再実行しているためです。これが完了すると、実行結果は公開リーダーボードに掲載され、この表には各ペアの勝者モデルとその引用元となる実行結果が記載され、サイト設定でペアごとの勝者が再固定されます。それまでは、1つの誠実なデフォルトを使用します。

*総合スコア（Composite score）*は、Networkの複合的な品質指標（chrF++、完全一致、およびロードされたメトリクスプラグイン、bootstrap-CIによる検証済み）です。スコアは**同一の言語ペア内**でのみ比較可能であり、ペア間での比較はできません。文字体系やコーパスの違いにより、ペア間の比較は無意味になります。

## レジスター（文体）とトーン

各言語は、Champollionの言語カードから選択された明示的なレジスターで翻訳されるため、サイト全体でフォーマルさが統一されています。

- **Deutsch** — Sie-Form

## 機械翻訳されないもの

コードブロック、CLIコマンド、設定キー、パッケージ名、URL、および固有名詞は、翻訳中に保護され、意図的に英語のまま保持されます。

## 誤訳を見つけましたか？

IssueまたはPRを作成してください。すべての翻訳ページのソースは英語の原文です。翻訳されたページへの修正は、そのページの英語ソースが変更されない限り、将来の同期でも保持されます（同期では、英語ソースが変更された場合にのみページが再翻訳されます）。
