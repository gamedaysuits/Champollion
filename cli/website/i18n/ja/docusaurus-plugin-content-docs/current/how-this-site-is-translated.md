# このサイトの翻訳について

このサイトは13言語で利用可能です。英語以外のすべてのロケールは、**Champollion自身によって機械翻訳されています**。これは、このドキュメントで説明しているCLIと同じものです（`npx champollion sync`）。私たちは自社ツールをドッグフーディングしています。

現在、すべての言語ペアで単一のモデル（**`google/gemini-3.1-pro-preview`**）を使用し、後述する言語ごとのレジスター（文体）と用語のガイダンスに従って翻訳しています。ベンチマークに基づくモデル選択（後述）を再構築している間、誠実なデフォルトとして意図的に1つのモデルを選択しました。したがって、これは明確に文書化された選択であり、事実と異なるように見せかけている結果ではありません。

読者の皆様に知っておいていただきたいことが2つあります。

1. **これらのページは機械翻訳です。** 後述するレジスターと用語のガイダンスを使用して生成されていますが、人間がすべての文をレビューしたわけではありません。不自然な箇所がある場合は、英語版が正式なものとなります。また、修正の提案も歓迎します。
2. **現在は1つのデフォルトモデルですが、将来的にはベンチマークごとに選択されます。** Champollionの設計では、ベンチマークによって*言語ペアごとに*翻訳モデルを選択します。開発コーパスですべての候補をスコアリングし、最もスコアの高い方法でそのロケールを翻訳します（統計的に同点の場合はコストで決定します）。言語ペアごとの勝者をここに固定する前に、独自の整合性ゲートを通じてその選択を再実行しています。**それらの実行結果が[Network leaderboard](/leaderboard)で公開されるまで、このページでは提示できないベンチマークの出所を主張することはありません。**

## 再構築中のベンチマーク選択

意図されている方法（および設定が動作するように構成されている方法）は、
独自の評価に基づく言語ペアごとのモデル選定です。各候補モデルをその
ペアの開発コーパスでスコアリングし、最も高いchrF++を持つモデルを採用
します。また、対応のある有意差検定で2つの候補を区別できない場合は、
より安価な方を採用します。この一連のプロセス全体は、再現を希望する
方のために文書化されています。

現時点では、このページで言語ごとのスコアや「ベンチマークの勝者」を公開
して**いません**。それらの数値を裏付ける選定スイープを、まずハーネスの
整合性ゲートを通じて再実行しているためです。完了すると、実行結果は
公開リーダーボードに掲載され、この表には各ペアの勝者モデルと引用された
実行結果が表示され、サイト設定はペアごとの勝者を再固定します。
それまでは、1つの誠実なデフォルト設定を使用します。

Networkは標準的な方法で実行結果をスコアリングします。コーパスレベルのchrF++
（95%ブートストラップ信頼区間およびsacreBLEUシグネチャ付き）、並記される
その他の標準メトリクス、そして個別に報告される診断情報です
（[実行結果のスコアリング方法](/docs/network/specifications/scoring#how-runs-are-scored)）。
スコアが比較可能なのは**同一の言語ペアおよび評価セット内**のみであり、
言語ペア間で比較することは決してできません。文字体系やコーパスの違いにより、
言語ペアをまたいだ比較は無意味であるためです。

## レジスター（文体）とトーン

各言語は、Champollionの言語カードから選択された明示的なレジスターで翻訳されるため、サイト全体でフォーマルさが統一されています。

- **Français** — vouvoiement（フォーマルな *vous*）
- **Deutsch** — Sie-Form
- **Nederlands** — u-vorm
- **Filipino** — フォーマル、標準的な専門用語を使用
- **Español** — ニュートラルなラテンアメリカスペイン語
- **简体中文** — プロフェッショナル・テクニカルレジスター
- **日本語** — です/ます調（丁寧語）
- **한국어** — 해요체（丁寧語）
- **Português** — プロフェッショナルレジスター
- **ไทย** — ニュートラル・プロフェッショナル
- **Tiếng Việt** — ニュートラルな *bạn* 形式
- **العربية** — 現代標準アラビア語（MSA）、プロフェッショナルレジスター

## 機械翻訳されないもの

コードブロック、CLIコマンド、設定キー、パッケージ名、URL、および固有名詞は、翻訳中に保護され、意図的に英語のまま保持されます。

## 誤訳を見つけましたか？

IssueまたはPRを作成してください。すべての翻訳ページのソースは英語の原文です。翻訳されたページへの修正は、そのページの英語ソースが変更されない限り、将来の同期でも保持されます（同期では、英語ソースが変更された場合にのみページが再翻訳されます）。

*このページ自体も、上記で説明した方法によって機械翻訳されています。つまり、自身の翻訳について説明しています。*
