# 実際に使ってみる

翻訳機は使ってこそ価値があります。最も手軽な方法から本格的なものまで、作成した翻訳機の使い方をご紹介します。そして、すべてに通じるたったひとつの原則があります。それは、**言葉を預かる人びとが、何をお使いのコンピューターから外に出すかを決める**ということです。

## ブラウザで試す

一番手軽な方法です。ツールがお使いのコンピューター上で翻訳機を起動し、Webブラウザで開くためのページを用意します。文章を入力すると、翻訳結果が表示されます。お使いのコンピューターから外部にデータが出ることは一切ありません。学習中に一度も見かけなかった言葉が文章に含まれている場合は、ページ上でそれがどれかが示されます。どれほど自然に読めたとしても、その行は間違っている可能性が非常に高くなります。

非公開の文章から学習した翻訳機は、その文章をそのまま出力してしまうことがあります。そのため、ガードレールの試行ツールは翻訳結果をAIアシスタントに渡しません（渡してしまうとアシスタントの運営会社に送信されてしまうためです）。代わりにページのURLが提示され、ご自身でブラウザを開いて確認します。お使いのコンピューターでコマンドを実行できるアシスタントは翻訳機に直接問い合わせてしまう可能性があるため、そうしないよう指示してください。

## 文書を翻訳する

文章が書かれたファイルをツールに渡すと、翻訳機のテスト時に使われた設定を用いて、お使いのコンピューター上で1行ずつ新しいファイルへと翻訳されます。新しくできたファイルにも、翻訳機が学習した文章と同じ規則が適用されます。

## サービスとして動かす

ツールを使って、お使いのコンピューター上で翻訳機を小さなサービスとして実行できます。これにより、他のプログラムから翻訳をリクエストできるようになります。初期設定では、同じコンピューター上のプログラムのみがアクセスでき、パスワードを要求することもできます。

他のコンピューターからアクセスできるようにするのは、さらに大きな一歩です。非公開の文章から学習した翻訳機の場合、言葉を預かる人びとのうち、誰が合意したかを明記して記録に残すまで、ツールはアクセスを拒否します。

## アプリに接続する

アプリを開発している場合、ツールを使って翻訳機をアプリに接続し、アプリ内の言葉をその翻訳機で翻訳させることができます。ここでも同じ規則が適用されます。非公開の文章から学習した翻訳機は、誰が合意したかを明記してはじめて接続できるようになります。

## 他のコンピューターやスマートフォンで使う

翻訳機は、それが構築されたコンピューターの中にあります。学校や職場の他のコンピューターやスマートフォンから使うには、ネットワーク上でサービスとして実行するか、アプリ内に組み込むなどして、それらの機器からアクセスできるようにする必要があります。どちらもより大きな一歩であり、非公開の文章から学習した翻訳機の場合は、言葉を預かる人びとの合意が得られるのを待つ必要があります。この部分でお困りの際は、[いつでもご相談ください](/docs/getting-help)。

## アプリやWebサイトの文言を翻訳する

アプリやWebサイトのボタン、メニュー、ページを翻訳し、原文の変更に合わせて常に最新の状態に保つ方法については、[アプリやWebサイトを翻訳する](/docs/translate-an-app-or-website)で詳しく説明しています。

## 日常での利用：話者が最終確認をする

スコアがどれほど良くても、公開する前には必ずその言語を話す人が目を通すべきです。おすすめの進め方は下書き方式です。翻訳機が下書きを作成し、話者がそれを修正します。修正のひとつひとつは、翻訳機がどこを間違えたのかを教えてくれる、次回の学習への贈り物でもあります。

誤った訳が外に出てしまったときは、隠さずに修正し、何を変更したかを説明してください。完璧を装う翻訳機よりも、間違いを見つけて率直に受け止める姿勢のほうが、より深い信頼につながります。
