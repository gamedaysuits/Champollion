# 数字の読み方

ガイドレールは、各段階でさまざまな数字を表示します。それぞれの数字は、**何を測っているのか**、**何点満点（または全体の母数）なのか**、そして**どの文を対象にしているのか**という3つのことが分かって初めて役に立ちます。ツールはその3つをすべて明記しますし、アシスタントもそうするよう指示されています。このページでは、それぞれの数字について説明します。

## 話者が「正解」と判定した下書きの割合

**最も重要な数字です。** 各ラウンドで、話者が翻訳機の下書きを正解か不正解か判定します。*「40件中31件の下書きが正解」* というのは、言葉どおりの意味です。ご家族が今回のラウンドで翻訳を希望した40文のうち、話者が31文を正解と判定したことを意味します。

コンピューターが測定するいかなる指標も、話者の判断にはかないません。ただし、この数字は文の内容にも左右されます。同じ翻訳機を使っていても、簡単な文が多かった週と難しい文が多かった週とでは結果が異なることがあります。そのため、ツールは毎回同じ方法で、同じ文を使って測定も行います。それが「スコア」です。

## 100点満点のスコア

**スコア**は、翻訳機の文が話者の書いた同じ文にどれだけ近いかを0から100までの数値で表したものです。一致する文字や単語を数え、部分点も与えられます。ほぼ正しい翻訳は、大きく的外れな翻訳よりも高いスコアになります。100は完全に同一であることを意味します。

知っておくべきことが2点あります。

- **これは「正しさ」ではなく「近さ」を測るものです。** 話者とは異なる言い回しをした良い翻訳は、スコアが低くなることがあります。意味が違っていても流暢な翻訳は、かなり高いスコアになることがあります。だからこそ、話者による確認のほうが重要なのです。
- **正解した文の割合（パーセンテージ）ではありません。** スコアが60だからといって、100文のうち60文が正解だったという意味ではありません。

参考までに、このスコアは **chrF++** と呼ばれ、この分野で翻訳機どうしを比較する際によく使われる標準的な手法です。ツールはこれと並んで他の指標も報告します。

## 範囲（信頼区間）

多くの数字には、*14〜22* のような**範囲**が添えられています。これは2つの結果が出たという意味ではありません。ツールの確信度を示しており、真の値は高い確率でその範囲内のどこかにあることを意味します。文の数が少なければ範囲は広くなり、文の数が多ければ範囲は狭まります。

2つの範囲が大きく重なっている場合、2台の翻訳機の性能は実際には同じである可能性があります。

## 対象となる文の種類

数字には、どの文を対象に測定されたかが常に明記されます。

- **テスト用の文** — 話者が確認済みで、翻訳機が学習に一度も使っていない文です。本当に重要な結果を見極めるために、たまにだけ使われます。
- **練習用の文** — お手元のデータから取り分けておいたもので、こちらも翻訳機の学習には一切使われません。各ラウンドの評価に使われ、テスト用の文が手つかずのまま保たれるようにします。
- **そのラウンドの文** — ご家族が翻訳を希望した文です。話者の判定はこれらの文に対して行われます。

翻訳機が学習に使った文で測定した数字には何の意味もありません。そのため、ガイドレールがそうした数字を結果として表示することは決してありません。

## 「測定可能な変化なし」

これは何も変わらなかったという意味ではありません。お手元にある練習用の文の数では、偶然のブレと区別がつかないほど変化が小さかったことを意味します。ツールは、どのくらいの大きさの変化であれば検出*できたはず*かを示します。練習用の文を増やせば、より小さな変化も見分けられるようになります。練習用セットが少ないうちは、各ラウンドのシートの数行が話者に書いてもらうために残されているのはそのためです。

## 「判断するには練習文が少なすぎます」

練習文が50文未満の場合、どのスコアを使っても、2つの翻訳のどちらが優れているかを確実に判断することはできません。私たちの練習用言語では、23文の練習文を使った場合、
慎重な判定ルールでも、ほぼ差のない2つの翻訳を100回中9回は「違いがある」と判定してしまい――100点中約6点の実際の改善があった場合でも、それに気づけたのは100回中わずか21回でした。
50文になると、それが4回と96回になりました。そのため、50文未満ではツールは判定を行いません。現在お使いのものがそのまま残り、次のシートにある話者の評価で決めることになります。

## 辞書フロア

単語リストを用意した場合、*単に単語を辞書引きしただけ*のスコアが表示されます。これは最低ライン（フロア）です。翻訳機は、このスコアを上回る場合にのみ使う価値があります。文の数が非常に少ないと、最初の翻訳機はこのラインを下回ることがあります。これは知っておくべき事実であり、隠す必要はありません。

## 当サイトで見かける数字：「意味の正しさ」

私たちが作成した練習用の架空言語について説明する際、*「100文のうち79文が完全に正確」* といった記述を目にすることがあります。これは正解した文の割合です。コンピューターが、架空言語自体の文法に照らし合わせて、各翻訳の意味のあらゆる部分を検証しました。これが可能なのは、私たちが作った言語であり、正解が完全に分かっているからにすぎません。実際の言語において、これに最も近いのは話者による判定です。
