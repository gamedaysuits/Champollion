# 仕組み：レールとガードレール

2つの文が並んでいる様子を思い浮かべてみてください。一方の言語の文と、もう一方の言語の同じ文です。翻訳機はそこから学び、そうした文を書きます。

これまでは、翻訳機を作るには専門家が必要でした。文をどう準備するか、翻訳機にどう学習させるか、そして何より難しいのは、自分をごまかさずにどうテストするかを知っている必要がありました。そうした教訓の多くは、手痛い失敗を通じて学ばれてきたものです。

Champollionは、そのすべてを**レール**として整えます。すべての手順が順番に並び、すべてのものに決まった置き場所があります。レールに沿って走るのが**ガードレール**です。よくある間違いを防ぎ、言葉をあなたの管理下に保つためのチェック機能です。あなた、あるいは信頼できるAIアシスタントが、このレールに沿って進みます。決断を下すのはあなたです。

## 誰が何を決めるか

レールが手順を進めます。判断するのは人です。すべての手順は、次の4種類のいずれかに分かれます。

- **人の手でのみ行えること** — 文の作成や、翻訳の確認です。ツールが話者のふりをすることはありません。
- **あなただけが答えられること** — 言葉の権利は誰にあるのか、翻訳機がそれを学習に使ってよいか、結果を見る前に何を期待するか、などです。アシスタントは質問しますが、あなたの代わりに答えることは決してありません。
- **アシスタントが事前に確認すること** — 何かをインストールしたり、翻訳機に学習させたり、費用が発生したり、オンラインに何かを公開したりする処理は、あなたの承諾を待って実行します。「今はしない」と答えることもでき、そのセッション中、レールが同じ質問を繰り返すことはありません。
- **アシスタントがそのまま実行すること** — 文に問題がないか確認したり、一部を取り分けたりする処理などです。

## レール：すべてのものに決まった場所を

プロジェクトはコンピューター上の1つのフォルダーであり、種類ごとに置き場所（棚）が分かれています。

| 棚 | 入るもの |
|---|---|
| 学習用の文 | 2つの言語で対になった文のペア |
| テスト用の文 | 流暢な話者が確認した文。評価にのみ使用し、学習には絶対に使用しない |
| 単語リスト | 辞書や単語リスト |
| 文法のメモ | その言語の仕組みについて書かれたあらゆる資料 |
| 合意事項 | 誰が、いつ、何に合意したかの記録 |
| 受信箱 | 取り込みを待っている、手元にあるファイル |

作成した翻訳機やその結果、各ステップの記録にも、それぞれ専用の棚が用意されます。

集めた文は、最終的に3つの山に分かれます。大半は**学習用**です。一部（最初は
4分の1、文が増えてきたら10分の1）は**練習用の文**になります。
これは練習問題のようなもので、上達具合を確認するために
毎回使われます。話者が確認したごく一部の文は**テスト用の文**となり、
たまにしか使われません。翻訳機は、
後ろの2つからは決して学習しません。

すべてのものに決まった場所があるため、ツールはいつでも完了した作業と次に行うべき作業を把握できます。いつでも尋ねれば、フォルダーの状況を直接読み取って**次のステップ**を教えてくれます。アシスタントは専門家である必要も、前回どこで中断したかを覚えておく必要もありません。レールに従って進むだけです。

手順は次の順序で進みます。

1. **プロジェクトを開始する** — 2つの言語の名前と、どちらの向きに翻訳するかを指定します。
2. **データを集める** — 手元にあるデータを取り込み、誰に帰属し、どのように利用できるかを記録します。
3. **テスト用データを保護する** — すべての翻訳機の評価基準となる文をあらかじめ取り分けておきます。
4. **学習ツールをインストールする** — あなたの承諾を得て、一度だけ行います。
5. **翻訳機を作成してテストする** — 学習させ、テスト用の文で性能を確認します。
6. **ラウンドごとに改善する** — 話者が下書きを確認し、間違えた部分を各ラウンドで重点的に改善していきます。

手作業や他のツールを使って、自分のやり方でステップを進めることもいつでも可能です。レールは、フォルダーが示す現在の状況から作業を再開します。

## ガードレール

ガードレールには2つの役割があります。

**1つは、自分をごまかしてしまうのを防ぐことです。** すでに学習した文でテストされた翻訳機は見かけ上すばらしく見えますが、実際はそうではありません。たまたま結果が良かったラウンドも、進歩のように見えてしまいます。そのため、レールは以下のように機能します。

- 学習を始める前にテスト用の文を取り分ける
- テスト用の文とほぼ同じ文を除外する
- 結果を見る前に期待する数値を書き留めるよう求める
- 単なる偶然を超えて以前の翻訳機を上回った場合にのみ、新しい翻訳機のほうが優れていると判断する

**もう1つは、言葉をあなたの管理下に保つことです。** 各ファイルには、言葉の権利を持つ人々が下した決定（このコンピューターの外に出してよいか、翻訳機が学習に使ってよいかなど）を記したメモが付けられ、すべてのツールはそのメモに従います。

ツールは、こうしたチェックの大部分をスキップすることを拒否します。一部のチェックはあなたとアシスタントの判断に委ねられており、どれが該当するかは[ガードレールのページ](/docs/guardrails)に記載されています。
