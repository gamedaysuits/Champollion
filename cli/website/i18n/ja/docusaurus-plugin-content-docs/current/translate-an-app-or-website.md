# アプリやウェブサイトを翻訳する

アプリやウェブサイトの文言（ボタン、メニュー、メッセージ、ページなど）は、言語ごとにファイルへ保存されます。Champollion は、お使いの言語のファイルを自動で作成・入力し、原文が変更されるたびに最新の状態へ更新できます。コマンドを1つ実行するだけです：

```bash
npx champollion sync
```

アプリの言語ファイルを見つけ出し、不足している部分や変更された部分だけを翻訳します。書き込む前にすべての訳文をチェックし、それ以外の部分はそのまま残します。

## どの翻訳機能を使うか

言語ごとに選択できます：

- **自作の翻訳モデル**：レール上で構築され、ツールがそれをアプリに接続します。非公開の文章から学習させた場合は、言葉を守り伝える人々のうち、誰が同意したかを指定して初めて接続されます。
- **AIモデルまたは翻訳サービス**：すでに十分に対応している言語向けです。アプリの文言が提供元の企業に送信されるため、外部と共有しても問題ないテキストに使用してください。
- **自前のサービス**：指定したアドレスで接続します。

## 自動で行われること

- **変更された部分のみ：** 過去に翻訳した内容を記憶するため、同じ文章に対して二重にコストを支払うことはありません。
- **書き込み前のチェック：** 空白の応答、原文のままのコピー、言葉のループ（繰り返し）、不自然に長すぎるテキスト、欠落、誤った文字体系などは検知して除外されます。これらのチェックは出力の破損を防ぐものであり、意味の誤りを正すものではありません。最終的な判断は、その言語の話者が行います。
- **使い慣れたファイルと形式：** JSON、YAML、TOML、Markdown ページ、および一般的なアプリやウェブサイトのフレームワークに対応しています。

## 利用可能な対象

学校のアプリ、コミュニティのウェブサイト、公共サービスなど、非営利の用途であれば無料で利用できます。企業の商用製品は無料ライセンスの対象外ですが、話者コミュニティが商用利用を希望する場合は、お問い合わせいただければ無料でライセンスが提供されます。詳細は[利用条件](/docs/getting-started/who-may-use-this)をご覧ください。
