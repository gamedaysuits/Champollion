# 文はいくつ必要ですか？

これは誰もが最初に尋ねる質問ですが、正直に答えると2つの点があります：
**多くの人が思っている以上に必要であること**、そして**あなた自身のラウンドを重ねることで分かってくること**です。

## 分かっていること

コンピューターがすべての回答を検証できるように、私たちは練習用の言語を作りました。約2,000語、完全に規則的な文法、整理されたデータです。ノートパソコン上で学習させた翻訳機は、日常的な新しい文の正確な意味を正しく捉えられました：

- **6,400**の例文のあとでは、**100文につき約79文**
- **25,600**の例文のあとでは、**100文につき約96文**

一度も見たことがない単語を含む文は、すべて間違って出力されました。ただし、6,400の例文の時点で間違えたもののうち、そうした単語によるものは約3分の1にすぎませんでした。残りは、まだ学習していなかった文法によるものでした。

## 分かっていないこと

*あなたの*言語にいくつ必要かということです。実際の言語には、私たちの練習用言語よりもはるかに多くの日常語があり、複数の意味を持つ単語や、英語では口に出さないことを表現する文法があります。そのため、上記の数字は最低限の目安です。実際の言語ではもっと多くの文が必要になりますが、どれくらい多くなるかはまだ分かっていません。現在、測定を行っているところです。

今、あなたの言語について具体的な数値を1つだけ提示する人がいたとしても、それは当て推量にすぎません。

## 必要な文数の見積もり方

あなたが行うラウンドこそが、最も確かな見積もりになります。途中でより良い翻訳機を実戦に投入し、話者によるブラインドチェックで確認しながら数ラウンドを重ね、話者の評価が実際に向上してくると、毎回のラウンドレポートに予測範囲が表示されます。そこには、これまで文数を倍増させるごとにどれだけ改善したかに基づいて、大半の新しい文を正しく訳せる翻訳機に達するまでに、あとどれくらいの文数と話者の時間が必要かが示されます。この予測は毎ラウンド更新され、手持ちの時間が足りそうにない場合も率直に示されます。

## 所要時間

私たちはまだ、実際の話者の所要時間を測定していません。大まかな目安として、1文を書くか確認するのに約1分かかるとすると、6,400文で話者の時間は約100時間になります。そして実際の言語ではそれ以上が必要になります。これは膨大な時間に思えるかもしれません。家族や教室、コミュニティで分担し、それぞれが週に2、3時間ずつ持ち寄れば積み上がっていきます。また、[他の人たちに協力してもらう](/docs/join-a-project)こともできます。

## 1つひとつの文を活かす

文の数よりも、*どんな*文を使うかの方が大切です：

- **実際の文を使うこと。** 家族が実際に言いたいことのほうが、作られた練習問題よりも効果的です。私たちの練習用言語でも、日常的な文のほうが、できるだけ多くの新しい単語を詰め込むように選んだ文よりも多くのことを教えられました。3,200文の学習後、新しい文の正確な意味を正しく捉えられたのは、約同じ話者時間で100文につき39文だったのに対し、日常的な文では100文につき53文でした。
- **1つの単語にいくつかの文を用意すること。** 翻訳機が一度しか出会わなかった単語は、ほとんど身につきません。ガードレールのウィッシュリストには、まだ見たことがない単語が挙げられます。それぞれの単語について、異なることを表す文を2〜3文用意してください。多くの単語を1回ずつ見せるよりも、少ない単語をいくつかの文の中で見せるほうが効果的です。
- **間違いに狙いを定めること。** 翻訳機が間違えた文に似た文は、無作為な文よりも多くのことを教えられます。ウィッシュリストにはそうした文も提案されます。
- **短く、多様にすること。** 短い文で、質問、頼みごと、昔話など、多くの種類を用意します。
- **修正は宝物です。** 話者が下訳に間違いの印をつけ、正しくはどう言うべきかを書いたとき、そこはまさに翻訳機が間違えた箇所そのものです。
