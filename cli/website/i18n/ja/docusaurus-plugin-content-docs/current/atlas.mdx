# The Atlas

**Atlasは言語のインデックスです。言語ごとに1枚のカードがあり、すべての値に出典元の情報源が明記されています。**

これは、Champollionの他のすべてが基礎とするリファレンス層です。[CLI](/docs/intro)は言語がどのように振る舞うかを把握するためにこれを読み込みます。[リーダーボード](/docs/reference/leaderboard)はベンチマークが*何の*ベンチマークであるかを知るためにこれを読み込み、ネットワークマップはその上に描かれます。そして、これ単体でも十分に有用です。カードには、あちこちに散らばっている言語についての引用された事実が、すべての情報源を明記した上で1か所に集約されています。

カードは情報源から生成されるものであり、手作業で書かれるものではありません。誰かが座って、ある言語について知っていることを入力するわけではありません。

## Champollionはインデックスであり、裁定者ではありません

これはThe Atlas全体が従うように構築されたルールであり、言葉の響き以上に厳格なものです。

カード上のすべての値は情報源を引用し、その情報源が**実際に述べていること**を報告します。私たちが真実だと考えることや、修正されたバージョン、丸められた数値ではありません。情報源間で意見が分かれる場合、カードは**出典を明記した上でそれらすべて**を表示します。話者数は常に一致しません。Wikidataが示す数値、Ethnologueが示す数値、国勢調査が示す数値、地域調査が示す数値がそれぞれ異なることがあります。カードは、それらすべてを情報源と日付とともに掲載します。私たちはそれらを平均したり、それらの間で裁定を下したり、最も見栄えの良いものを密かに選んだりすることはありません。

その理由は謙遜ではありません。合意を捏造したカードは、私たちが発明した、誰かの言語に関する新しくて引用不可能な主張になってしまいます。不一致をそのままにしておくことで、カードは現実世界と照らし合わせて検証可能な状態に保たれ、判断は本来あるべき場所、つまり読者やその言語を話すコミュニティに委ねられます。

以下に3つの読み方のルールを示します。これらは、カードを何かに使用する前に知っておく価値があります。

- **フィールドがないことは「不明」を意味し、「非該当」ではありません。** 引用された情報源で言及されていないフィールドはカードから除外されます。これは、まだ情報源が見つかっていないということです。これは確定的な判断ではなく、調査への呼びかけです。フィールドが真に当てはまらない場合は、カード上で言葉で明記されます。
- **派生値は派生であると明記されます。** Champollionが計算したもの（中央値、複合値、再コード化されたフラグ、データセットから抽出された件数など）には、何*から*派生したものかを明記したメモとともに`champollion-derived`のスタンプが押されます。アップストリームのデータセット名のもとに登録されることは決してありません。そうすることは、私たちの計算結果を他者の主張にしてしまうことになるからです。
- **カバレッジよりも引用が優先されます。** 三次情報源で穴埋めされた網羅的なカードよりも、確かな情報源に基づくフィールドが少ないカードのほうが健全です。Wikipedia、LLMが生成したテキスト、自己の知識はここでは一次情報源ではなく、情報源として受け入れられることはありません。

[Citation Procedure](/docs/reference/language-card-citation-procedure) では、どの種類の主張に対してどの情報源が権威を持つか、そしてその優先順位を定めています。

## カードが主張すること — そして決して主張しないこと

カードは正確に2種類の声明を出します。

**1. 言語の特性。** 分類と語族、音韻目録、類型論、文字と正書法、活力と消滅の危機状況、話者数の推定。それぞれが引用され、派生または主張としてラベル付けされています。

**2. リソースの存在。** コーパス、モデル、FST、辞書、メトリクスプラグイン、または翻訳手法がこの言語に*存在する*こと、およびそのアクセスレベル。これは能力に関する主張であり、品質に関する主張ではありません。

そして、決して越えてはならない明確な一線があります。

:::danger[測定スコアが言語カードに記載されることはありません]
**手法の出力に関する測定スコア**（chrF++、BLEU、COMET、TER、FST受理率、「形態論的に妥当な割合」など）は、特定の手法、データセット、評価指標に紐づく**実行結果**です。これは指紋情報が付与された実行カードに添付され、[リーダーボード](/leaderboard)（[公開の仕組み](/docs/reference/leaderboard)）に掲載されるべきものです。**言語カードへの記載は禁止されており**、リンターによってスコアが含まれるカードはすべて拒否されます。
:::

この区別は、「この言語向けのFSTが存在する」（私たちとは無関係に真か偽かが決まる、世界についての事実）と、「この手法のFST受理率は0.82である」（1回の実行、1つのデータセットバージョン、1つの手法バージョンにおいてのみ真となる測定結果）の違いです。この2つを混同すると、カードは特定の実行の裏付けもなく、撤回する方法もないまま、言語の品質についての主張に暗黙のうちに恒久化してしまいます。そのため、これらが混同されることはありません。Atlasが示すのは**何が存在するか**であり、リーダーボードが示すのは**それがどれほどうまく機能するか**です。

さらに2つの不変条件が同じように適用されます。声調に関する主張はカード自身の音韻目録と矛盾してはならず、表示される話者数はカードに引用された推定値のいずれかと等しくなければなりません（または独自の派生値としてスタンプが押されていなければなりません）。すべてのフィールドとそのルールを含む完全なスキーマは、[Language Card Specification](/docs/reference/language-card-spec) にあります。

## 収録内容とその情報源

カードは、個別にライセンスが追跡されている<SSOTCount field="licensedSourceCount" />件の登録済みアップストリーム情報源から構築されています。これは、カード全体の再配布可能性はそこに含まれるすべての要素が再配布可能である場合にのみ担保されるためであり、非商用情報源は善意に頼るのではなく、構造的に商用レーンから隔離されているためです。

このカタログには、自然言語としての手話が含まれ、ISO 639-3が認識する人工言語が含まれ、プログラミング言語は除外されています。また、マクロランゲージの包括的な枠組みではなく、個々の言語をベンチマークの対象としています。これは、翻訳リソースが変種に固有のものであり、包括的なコードにスコアを付けることは、誰も評価していない変種についての主張になってしまうためです。分類法に不一致がある場合、カードは勝者を選ぶのではなく、その不一致を表示します。これらの選択のそれぞれと、その結果についての議論は、[What Counts as a Language Here?](/docs/network/context/what-counts-as-a-language) に記載されています。

**カバレッジは品質ではなく、存在はカバレッジではありません。** ある言語について3つのリソースがリストされているカードは、3つのものが存在することを示しているに過ぎず、それらのいずれかが使用可能であることや、その言語がカバーされていることを示すものではありません。本プロジェクトがどのようにカバレッジをカウントし、何をカウント対象から除外しているかについては、このページの上記の各セクションで説明しています。

## カードが間違っている場合

一部のカードは間違っていると想定してください。互いに意見が異なる情報源から組み立てられたこの規模のインデックスには、エラーが含まれるものです。そして、最も重要なエラーは通常、私たちには見えず、話者にとっては明白なものです。

**すべてのカードには「Suggest a correction or addition（修正または追加を提案する）」リンクがあり**、これをクリックすると、言語が事前に入力された修正フォームが開きます。情報源がある場合は提示してください。コミュニティからの削除または制限の要求については、引用は不要であり、優先的に処理されます。

修正は**カードに対してではなく、ジェネレーターに**適用されます。カードは情報源から再生成されるため、手作業による編集は次のビルドで暗黙のうちに上書きされてしまいます。情報源を修正することこそが修正を永続的なものにし、通常は同じ情報源を共有する他のすべてのカードの同じ欠陥も修正します。これはファイルを編集するよりも時間がかかりますが、永続する唯一の方法です。その仕組みについては、[Submit to the Index](/docs/network/getting-started/submit-to-the-index) に記載されています。

**あなたがコミュニティのメンバーまたは関係当局であり**、ご自身の言語に関するデータの制限、変更、削除を希望される場合、その要請について私たちに理由を説明する必要はありません。また、ご希望であれば公開キューに登録されることもありません。言語データは生体データ（バイオデータ）です。それを話す人々のアイデンティティや関係性を宿しており、意味のある形で匿名化することはできません。私たちは**主権の尊重を目指すものであり、主権の認証を受けたものではありません**。私たちは仕組みを構築し、それらを誠実に説明しますが、それらが言語データのコミュニティによる所有と管理を尊重しているかどうかを判断するのは、私たちではなく関係するコミュニティです。詳細な方針については、[あなたの言葉、あなたのルール](/docs/your-words-your-rules)をご覧ください。
