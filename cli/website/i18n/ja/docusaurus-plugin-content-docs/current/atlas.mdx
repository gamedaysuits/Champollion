# The Atlas

**The Atlasは言語インデックスです。言語ごとに1枚、計<SSOTCount field="catalogLanguageCount" />枚のカードがあり、すべての値にはその情報源が明記されています。**

これは、Champollionの他の部分が依存するリファレンスレイヤーです。[CLI](/docs/intro)はこれを読み取って言語の振る舞いを把握します。[Arena](/docs/arena)はこれを読み取って、ベンチマークが「何についての」ベンチマークであるかを知ります。[Network](/docs/network/)はこれの上に描かれています。そして、これ単体でも非常に有用です。収録されているほとんどの言語において、このカードは、その言語の状況について出典が明記された、1か所で確認できる最も完全な要約となっています。

カードは情報源から生成されるものであり、手作業で書かれるものではありません。誰かが座って、ある言語について知っていることを入力するわけではありません。

## Champollionはインデックスであり、裁定者ではありません

これはThe Atlas全体が従うように構築されたルールであり、言葉の響き以上に厳格なものです。

カード上のすべての値は情報源を引用し、その情報源が**実際に述べていること**を報告します。私たちが真実だと考えることや、修正されたバージョン、丸められた数値ではありません。情報源間で意見が分かれる場合、カードは**出典を明記した上でそれらすべて**を表示します。話者数は常に一致しません。Wikidataが示す数値、Ethnologueが示す数値、国勢調査が示す数値、地域調査が示す数値がそれぞれ異なることがあります。カードは、それらすべてを情報源と日付とともに掲載します。私たちはそれらを平均したり、それらの間で裁定を下したり、最も見栄えの良いものを密かに選んだりすることはありません。

その理由は謙遜ではありません。合意を捏造したカードは、私たちが発明した、誰かの言語に関する新しくて引用不可能な主張になってしまいます。不一致をそのままにしておくことで、カードは現実世界と照らし合わせて検証可能な状態に保たれ、判断は本来あるべき場所、つまり読者やその言語を話すコミュニティに委ねられます。

以下に3つの読み方のルールを示します。これらは、カードを何かに使用する前に知っておく価値があります。

- **`null` は「不明」を意味し、「適用不可」ではありません。** フィールドが空であることは、引用可能な情報源をまだ見つけていないことを意味します。これは招待であり、最終的な判定ではありません。フィールドが本当に適用されない場合、カードにはその旨が言葉で記載されます。
- **派生値は派生したものであると明記されます。** 中央値、合成値、再コード化されたフラグ、データセットから抽出されたカウントなど、Champollionが計算したものはすべて、何*から*派生したかを示す注記とともに `champollion-derived` のスタンプが押されます。上流のデータセット名で登録されることは決してありません。それは、私たちの計算結果を他人の発言として扱うことになるからです。
- **引用は網羅性に勝ります。** 項目が少なくても情報源がしっかりしているカードの方が、三次資料で埋め尽くされたカードよりも健全です。Wikipedia、LLMが生成したテキスト、および自己知識はここでは一次資料ではなく、一次資料として受け入れられません。

[Citation Procedure](/docs/reference/language-card-citation-procedure) では、どの種類の主張に対してどの情報源が権威を持つか、そしてその優先順位を定めています。

## カードが主張すること — そして決して主張しないこと

カードは正確に2種類の声明を出します。

**1. 言語の特性。** 分類と語族、音韻目録、類型論、文字と正書法、活力と消滅の危機状況、話者数の推定。それぞれが引用され、派生または主張としてラベル付けされています。

**2. リソースの存在。** コーパス、モデル、FST、辞書、メトリクスプラグイン、または翻訳手法がこの言語に*存在する*こと、およびそのアクセスレベル。これは能力に関する主張であり、品質に関する主張ではありません。

そして、決して越えてはならない明確な一線があります。

:::danger[測定されたスコアが言語カードに記載されることはありません]
chrF++、BLEU、COMET、TER、FSTの受理率、「形態論的に有効な割合」など、**手法の出力の測定スコア**はすべて、特定の手法、データセット、メトリクスに紐づく**実行結果**です。これらは[リーダーボード](/leaderboard)や[the Arena](/docs/arena)内に属し、フィンガープリント付きの実行カードに添付されます。これらを**言語カードに記載することは禁止**されており、リンターはこれらを含むカードを拒否します。
:::

この区別は、「この言語にはFSTが存在する」という、私たちとは無関係に真偽が決まる世界についての事実と、「この手法はFST受理率0.82を記録した」という、1回の実行、1つのデータセットバージョン、1つの手法バージョンにおいてのみ真となる測定値との違いです。この2つを混同すると、カードは暗黙のうちに言語に関する品質の主張となり、裏付けとなる実行結果もなく、撤回する方法もないまま永続してしまいます。そのため、これらを混同することはありません。The Atlasは**何が存在するか**を伝え、the Arenaは**それがどれほどうまく機能するか**を伝えます。

さらに2つの不変条件が同じように適用されます。声調に関する主張はカード自身の音韻目録と矛盾してはならず、表示される話者数はカードに引用された推定値のいずれかと等しくなければなりません（または独自の派生値としてスタンプが押されていなければなりません）。すべてのフィールドとそのルールを含む完全なスキーマは、[Language Card Specification](/docs/reference/language-card-spec) にあります。

## 収録内容とその情報源

<SSOTCount field="catalogLanguageCount" />の言語がカタログ化されており、ライセンスが個別に追跡されている<SSOTCount field="licensedSourceCount" />の登録済み上流情報源から構築されています。これは、カード上のすべてのものが再配布可能である場合にのみカード自体も再配布可能となるためであり、非商用の情報源は善意によってではなく、構造的に商用利用から隔離されているためです。

このカタログには、自然言語としての手話が含まれ、ISO 639-3が認識する人工言語が含まれ、プログラミング言語は除外されています。また、マクロランゲージの包括的な枠組みではなく、個々の言語をベンチマークの対象としています。これは、翻訳リソースが変種に固有のものであり、包括的なコードにスコアを付けることは、誰も評価していない変種についての主張になってしまうためです。分類法に不一致がある場合、カードは勝者を選ぶのではなく、その不一致を表示します。これらの選択のそれぞれと、その結果についての議論は、[What Counts as a Language Here?](/docs/network/context/what-counts-as-a-language) に記載されています。

**網羅性は品質ではなく、存在は網羅性ではありません。** ある言語について3つのリソースをリストしているカードは、3つのものが存在することを伝えているだけであり、それらのいずれかが使用可能であることや、その言語が十分にサポートされていることを意味するわけではありません。プロジェクトが網羅性をどのようにカウントし、何をカウントしないかについては、[Counting Coverage](/docs/network/context/coverage-counting) を参照してください。

## カードが間違っている場合

一部のカードは間違っていると想定してください。互いに意見が異なる情報源から組み立てられたこの規模のインデックスには、エラーが含まれるものです。そして、最も重要なエラーは通常、私たちには見えず、話者にとっては明白なものです。

**すべてのカードには「Suggest a correction or addition（修正または追加を提案する）」リンクがあり**、これをクリックすると、言語が事前に入力された修正フォームが開きます。情報源がある場合は提示してください。コミュニティからの削除または制限の要求については、引用は不要であり、優先的に処理されます。

修正は**カードに対してではなく、ジェネレーターに**適用されます。カードは情報源から再生成されるため、手作業による編集は次のビルドで暗黙のうちに上書きされてしまいます。情報源を修正することこそが修正を永続的なものにし、通常は同じ情報源を共有する他のすべてのカードの同じ欠陥も修正します。これはファイルを編集するよりも時間がかかりますが、永続する唯一の方法です。その仕組みについては、[Submit to the Index](/docs/network/getting-started/submit-to-the-index) に記載されています。

**あなたがコミュニティのメンバーまたは権威者であり**、自身の言語に関するデータの制限、変更、または削除を希望する場合、その要求を私たちに正当化する必要はありません。また、公開キューに入れたくない場合は、そうしないことも可能です。言語データは生体データ（バイオデータ）です。それは、その言語を話す人々のアイデンティティと関係性を帯びており、意味のある形で匿名化することはできません。私たちは**主権の実現を目指す（sovereignty-aspirant）立場であり、主権の認証を受けた（sovereignty-certified）立場ではありません**。私たちはメカニズムを構築し、それらを誠実に説明しますが、それらが言語データのコミュニティによる所有と管理を尊重できているかどうかの判断は、私たちではなく、関与するコミュニティに委ねられています。完全な見解は [Data Stewardship](/docs/network/sovereignty/data-sovereignty) にあり、コミュニティ向けの窓口は [For Language Communities](/docs/network/community/for-language-communities) です。
