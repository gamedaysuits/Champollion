# The Arena

**The Arenaは測定が行われる場所です。** 結果を提出するためのドアであり、結果を保持する台帳であり、その両方の上に構築されたコンテストの仕組みでもあります。

これはインフラストラクチャであり、スコアボードやマップではありません。以下の3つは混同されやすいため、ここで明確に区別しておく価値があります。

| | 概要 | 実行場所 |
|---|---|---|
| **[MT-Eval Harness](/docs/network/specifications/harness)** | スコアラー。手法とテストセットを与えると、数値とランカード（run card）を生成します。 | **あなたのマシン。** 私たちがあなたの手法を実行することはありませんし、その必要もありません。 |
| **The Arena** | 提出用のドア、ランカードの台帳、およびコンテストと賞金の仕組み。 | ここ。 |
| **[The Network](/docs/network/)** | 十分な数のランカードが存在したときに現れるマップ。誰が何を、どれほどの精度で翻訳できるか、そして空白地帯がどこにあるかを示します。ルーティングはここを横断します。 | 結果であり、コンポーネントではありません。 |

The Arenaを経由しない限り、The Networkに入ることはできません。また、スコア付けされ、フィンガープリントが付与された実行（run）としてでなければ、The Arenaに入ることはできません。これが設計のすべてです。出所（provenance）のない測定値がマップの一部になることはありません。

## The Arenaの構成要素

**ドア。** 誰でも提出できます。ファインチューニングされたモデル、プロンプトを与えられたフロンティアモデル、FSTゲートパイプライン、ルールベースのシステム、プロの人間による翻訳者など、プロセスにおいて手法は問われません。固定されているのは手順のみです。お持ちのものに応じて2つの異なるドアがあります。すでにスコア付けされたものがある場合は[ランカードを公開する](/docs/network/getting-started/submit-a-method)、データセット、辞書、エンジン、翻訳サービス、外部で公開された結果、または言語カードの修正がある場合は[エントリを提案する](/docs/network/getting-started/submit-to-the-index)を選択します。提案はロボットではなく人間によって読まれ、自動承認されるものは一切ありません。

**台帳。** 公開されたすべての実行はランカードとなります。これには、スコア、データセットのハッシュ、モデルのスラッグ、条件、およびそれらすべてに対するフィンガープリントが含まれます。2人の人間が同じ構成を実行しても、設計上無害です。同一の実行は公開時に重複排除され、独立した再現は無駄ではなく証拠となります。[ランカード仕様](/docs/network/specifications/run-card)はカードが開示しなければならない内容を定義し、[ベンチマーク仕様](/docs/network/specifications/benchmark)はカードを生成するプロトコルを定義します。

**ターゲットのセット。** <SSOTCount field="registryDatasetCount" />の評価データセットが登録されています。それぞれはメタデータカードとソースからのフェッチポインタで構成されています。**コーパスのコンテンツがここでホストされることは決してありません**。ハーネスは実行時にアップストリームからリファレンスをフェッチし、フェッチしたばかりのものに対してスコアを付けます。

登録されていることと、どこでも実行可能であることは同じではなく、この違いは意図的なものです。これらのエントリのうち数百は、変更されたライセンス、カスタムライセンス、または明記されていないライセンスを持っており、権利者が明示的な送信同意を記録するまで**リモート評価を拒否**します。いかなるエージェントも権利者の代わりに同意を追加することはできません。これらはローカルで実行可能であり、ライセンスが許可する場合には学習なし（no-train）のチャネルに対しても実行可能です。[評価データセット](/docs/network/leaderboard/datasets)および[データスチュワードシップ](/docs/network/sovereignty/data-sovereignty)を参照してください。

**コンテストの仕組み。** 単一の実行の上には、その他の要素が存在します。[共有タスクとコンテスト](/shared-tasks)、マップを最も改善するであろう測定の[パブリックキュー](/docs/network/getting-started/contributing-compute)、そして賞金が提供される場合の[賞金の要件](/docs/network/specifications/prizes)です。コミュニティは、独自の資金を使って独自のコーパスで独自のコンテストを開催できます。[Champollionはそのどちらも保持しません](/docs/network/sovereignty/run-a-sovereign-contest)。

## ここで常に適用されるルール

これらは不変のルールです。それぞれについて詳細を説明するページがあります。

**評価データで学習しないこと。** トレーニングデータ、Few-shotの例、辞書エントリ、またはプロンプトの素材としてベンチマークセットにさらされた手法は失格となります。好きなものでファインチューニングして構いませんが、テストセットだけは避けてください。これは、システム全体が破綻せずに済むための唯一のルールです。なぜなら、汚染されたスコアは、それ以降のすべての比較を台無しにするからです。（[リーダーボードのルール](/docs/network/leaderboard/rules)）

**すべての数値には出所（provenance）が伴う必要があり、そうでないものは無効です。** ランカードには、データセットのバージョン、モデル、条件、システムプロンプト、およびコストが明記されます。スコアは同じデータセットのバージョン内でのみ比較可能であり、フィンガープリントはそれを単なる主張ではなく検証可能なものにします。（[ベンチマーク仕様](/docs/network/specifications/benchmark)）

**私たちはあなたのコーパスを保持しません。** 登録されるのはメタデータです。テストセットは引き渡されることなくスコア付けされ、ソブリンレーン（sovereign lane）ではコミュニティのインフラストラクチャから出ることは一切ありません。移動するのはスコアのみです。（[コーパスの登録](/docs/network/sovereignty/registering-corpora)）

**ライセンスレーンは構造的なものであり、編集的なものではありません。** 非営利および研究専用のコーパスは、構造上、すべての賞金、API、および商用パスから除外されます。変更されたライセンス、カスタムライセンス、または明記されていないライセンスの下にあるコーパスは、さらに同意による制限（consent-gated）を受けます。権利者の許可が記録されるまで、ハーネスはサードパーティのモデルAPIへのテキスト送信を拒否します。（[データスチュワードシップ](/docs/network/sovereignty/data-sovereignty)）

**スコアは機械的なシグナルであり、最終的な判定ではありません。** 自動化された指標は人間の判断の代用であり、[話者検証プロトコル](/docs/network/specifications/speaker-validation)は、それらが*何の*代用であるかという人間のゲートを定義します。リーダーボードの順位は、手法が良好な測定結果を出したことを証明するものです。翻訳が優れていることを証明するものではなく、コミュニティの言語にそれを展開する許可を誰かに与えるものでもありません。

**勝利が最終状態ではありません。** 先住民の言語については、機能する手法がコミュニティのガバナンス組織に譲渡され、コミュニティが管理するインフラストラクチャに展開されるように設計されています。そこで得られた収益からChampollionがシェアを受け取ることはありません。（[派生成果物に関するコミットメント](/docs/network/sovereignty/derived-artifacts)）

## あなたの参加方法

すでにお持ちのものに一致する行を選択してください。

| お持ちのもの | 行うこと | 開始ページ |
|---|---|---|
| 手法とAPIキー | 登録されたコーパスに対してハーネスを実行し、ランカードを公開する | [手法を提出する](/docs/network/getting-started/submit-a-method) |
| インデックスに欠けているもの（データセット、辞書、FST、エンジン、人間による翻訳サービス、公開された結果、またはカードの修正） | 構造化された提案を提出する（メンテナーが手動でレビューします） | [インデックスに提出する](/docs/network/getting-started/submit-to-the-index) |
| 余っているAPIクレジット（独自の手法はなし） | 自分のキーを使用してパブリックキューからオープンなアイテムを実行し、返ってきた結果を公開する | [計算リソースの提供](/docs/network/getting-started/contributing-compute) |
| コミュニティが所有するコーパス | メタデータとして登録し、公開レーン（オープン、ゲート付き、または完全なソブリン）を選択する | [コーパスの登録](/docs/network/sovereignty/registering-corpora) |
| コーパスと、そこでコンペティションを開催する理由 | 独自の条件で自ら実行する（私たちはデータも資金も保持しません） | [ソブリンコンテストの開催](/docs/network/sovereignty/run-a-sovereign-contest) |
| すでに高いスコアを出している手法 | プラグインとしてエクスポートし、本番環境にデプロイする | [本番環境へのデプロイ](/docs/network/getting-started/deploy-to-production) |
| まず質問がある | スコアリング、失格、モデル、FST、主権（sovereignty）について | [FAQ](/docs/network/getting-started/faq) |

AIエージェントの場合、キュー、結果、およびランカードはすべてツールとして利用可能です。[MCPサーバー](/docs/network/getting-started/mcp-server)を参照してください。

## 現在実際に稼働しているもの

The Arenaはローンチ段階にあり、正直なところその説明は短くなります。

- **ボードは稼働中で公開されており、提出を受け付けています。** 現在のコンテンツはライブデータであるため、このページには何が掲載されているかは記載されていません。[リーダーボードを読む](/leaderboard)を参照してください。
- **「自己申告（Self-reported）」がデフォルトの信頼階層（trust tier）です。** サーバー側の検証（SHAで固定された正規コーパスに対する提出物の再スコアリング）は存在し拡大していますが、まだ普遍的ではありません。各行のバッジを確認してください。
- **現在開催中の賞金付きコンテストはなく、このサイトのどのスコアも賞金の基準をクリアしていません。** [賞金仕様](/docs/network/specifications/prizes)は、賞金が提供された*場合に*その基準が明確になるように書かれています。賞金はスポンサーが資金を提供し保持するものであり、Champollionが賞金を保持、エスクロー、またはルーティングすることは決してありません。
- **コミュニティのスピーカーによるレビューはまだ実施されていません。** ゲートは指定されており、ツールは構築中です。CompositeおよびchrF++の数値は機械的なシグナルであり、コミュニティの最終判定ではありません。
- **コミュニティに譲渡された手法はまだありません。** 所有権の譲渡モデルは確約された設計であり、現在実行中のプログラムではありません。これが記載されているのは、私たちがその約束を守ることを保証するためであり、すでに動いていることを示唆するためではありません。
- **キーの保管方法は決定していますが、保管者は未定です。** メカニズムは、Champollionがキーのシェアを一切保持しないしきい値スキーム（threshold scheme）です。保管者はコミュニティによって選ばれ、その対話は現在進行中です。そのため、私たちは**コミュニティのキー保管者（確認中）**としています。

このプロジェクトが主張*しない*ことの完全な台帳は、[誠実な制限事項](/docs/network/honest-limitations)にあります。もしこのページの内容が、そのページで許容されている以上のことを暗示している場合、そのページが優先され、このページの記述はバグとみなされます。
