# プロジェクトを始める

始める方法は2つあります。どちらの方法でも、ツールはお使いのコンピューター上で動作し、一歩ずつ順番に進めていくことができます。

## AIアシスタントを使う場合

これが最も簡単な方法です。文字入力はアシスタントが行い、ご自身で判断すべき質問に答えるだけで進められます。

**必要なもの:** スマートフォン用アプリだけでなく、お使いのコンピューター上のアプリとして動作し、コンピューター内のツールを使用できるAIアシスタント。

### 1. アシスタントにレールを追加する

以下の短い設定をコピーしてアシスタントに貼り付け、*「これを設定してください」* と伝えてください。多くのAIアシスタントはこれに対応しています。もし対応していない場合は、コンピューターに詳しい人に一度設定を依頼してください。手順はすぐ下にあります。

```json
{
  "mcpServers": {
    "champollion": { "command": "npx", "args": ["-y", "champollion-mcp-server"] }
  }
}
```

<details>
<summary>手動での設定手順</summary>

アシスタントはMCPと呼ばれる共通規格を通じてツールと接続します。上記の設定は、アシスタントにレールの起動方法を伝えるものです。また、お使いのコンピューターには無料のプログラムであるNode.js 20.11以降が必要です。

- **Claude デスクトップアプリ:** Settings → Developer → Edit Configの順に開きます。そのファイルに設定を追加して保存し、アプリを再起動してください。
- **Claude Code:** ターミナルで以下を一度実行します。
  `claude mcp add champollion -- npx -y champollion-mcp-server`
- **Cursor:** プロジェクトの`.cursor`フォルダー、またはホームフォルダーの`.cursor`フォルダーにある`mcp.json`ファイルに設定を追加してください。

</details>

### 2. 自分の言葉で伝える

例えば、次のように伝えます。

> *英語から私たちの言語への翻訳機を作りたいです。champollionを使ってください。*

### 3. 質問に答える

まず、アシスタントは翻訳の向きを確認します——*「英語を入力すると、あなたの言語が出力されます。この向きでよろしいですか？」*——これは逆にしてしまいがちな間違いだからです。その後、プロジェクトフォルダーを作成し、ファイルの提供を求めます。

それ以降は、言葉の所有者は誰か、翻訳機がその言葉から学習してよいか、何かをインストールしてよいかなど、判断が必要になるたびに尋ねてきます。ご自身でお答えください。まだ分からない場合は、そう伝えてください。レールは待つことができます。また、*「今はしない」* というのも立派な答えです。そのセッションの間は、レールが同じことを再度尋ねることはありません。

**あらかじめ知っておくべきこと:** ほとんどのアシスタントは、読み取った内容を運営会社に送信します。このコンピューターに保存されているファイルについて、ツールがアシスタントに伝えるのは文が*何行あるか*だけであり、文そのものを伝えることはありません。ただし、お使いのコンピューターを使用できるアシスタントは、あなたが閲覧できるファイルであれば何でも開くことができます。非公開にしたい言葉がある場合は、開かないよう指示するか、ご自身のコンピューター上で動作するアシスタントを使用してください。詳しくは[あなたの言葉、あなたのルール](/docs/your-words-your-rules)で説明しています。

## 自分で進める場合

コマンド入力に慣れている場合は、4行で済みます。プロジェクトツールをインストールし（Node.js 20.11以降が必要です）、プロジェクトを開始して、次の手順を確認します。

```bash
npm install -g champollion
champollion new family --from English --to qaa --target-name "Our language"
cd family
champollion next
```

`qaa`は「まだ言語コードがない言語」を意味します。これでも問題なく機能しますが、ツールが文字体系などの情報を自動補完することはありません。引用符で囲まれた名前は、その言語の呼び名です。もし言語コードがある場合や、ツールが認識できる名前がある場合は、代わりにそれを使用してください。1つの名称が複数の言語を指す可能性がある場合は、コードを選択する前に、話者の方々にどの言語を話しているか確認してください。確認が取れるまでは`qaa`を使用できますが、言語カードがないため、複数形の規則や表記体系の情報は自動設定されません。

それ以降は、`champollion next`を実行すれば、いつでも次のステップと実行すべき正確なコマンドが示されます。翻訳機をトレーニングする段階になると、レールはトレーニング用ツールをインストールする前に確認を求めます。

## インターネットに接続せずに作業する

インストールと初回のトレーニングが完了するまでは、オンライン状態を保ってください。トレーニングツールと、より高性能な翻訳モデル（約1.2 GB）はその際にダウンロードされます。それ以降の作業はすべてお使いのコンピューター上で行われます。ツール自身による問い合わせ（言語の公開情報カードを取得するために言語コードのみを送信することがあります）を停止するには、ターミナルおよびアシスタントの設定で以下を指定してください。

```bash
export CHAMPOLLION_OFFLINE=1
```

外部企業のコンピューターで動作するAIアシスタントは、依然としてインターネット接続が必要です。完全にオフラインで作業するには、ご自身のコンピューター上で動作するアシスタントを使用してください。

## 期待できること

最初にできる翻訳機は、おそらく会話集のようなものになるでしょう。学習元の文とよく似た文は得意ですが、それ以外の文はまだうまく扱えません。どのプロジェクトもそこから始まります。[現時点でできないこと](/docs/what-it-cant-do-yet)では何が期待できるかを率直に説明しており、[改善する](/docs/make-it-better)では翻訳機をどのように成長させていくかを紹介しています。
