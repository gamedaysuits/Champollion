# 手元にあるものを持ち寄る

翻訳システムは**ペア**から学習します。ある言語の文と、別の言語での同じ意味の文のペアです。このページでは、お手元のペアを取り込む方法と、各ファイルについて尋ねられる質問について説明します。この質問は、レールの上の何よりも重要なものです。

## ツールが読み込めるもの

ファイルは普段保管している形のままお持ちください。変換する必要は一切ありません。

| お手元にあるもの | ツールが読み取る内容 |
|---|---|
| 文とその翻訳のスプレッドシート | Excel (`.xlsx`)、LibreOffice (`.ods`)、`.csv`、`.tsv`、またはプレーンテキスト |
| Word文書内の表 | 表の各行 |
| ToolboxやFieldWorks（多くの言語学者が使うプログラム）で作成された辞書 | 単語、およびその例文（ペアとして） |
| ELAN（録音を文字起こしするプログラム）で文字に起こされた録音 | 文字に起こされた文とその翻訳（ペアとして） |
| 単語リスト | 各単語とその翻訳 |
| 文法についてのメモ | 人やツールが参照できるよう、専用の場所に保管されます |
| 聖典 | ご自身から要望があった場合のみ。それを保持する方々が許可を出すまで、翻訳システムがそこから学習することはありません |

ファイルはその場所のままで読み込まれます。スプレッドシートの列にどちらがどの言語か書かれていない場合は、ツールがあなたに尋ねます。内容から勝手に推測することはありません。

ツールは、誤りと思われる行も探します。翻訳が1行ずれてしまっているもの、2つの列が入れ替わっているもの、反対側からコピーされた翻訳、同じペアの重複、通常より極端に長いまたは短い翻訳などを検出し、該当する行番号をお知らせします。ツールが何かを変更したり削除したりすることは決してありません。データをよく知る人が判断します。

## ツールは数を数えるだけです。あなたの言葉を誰かに読み上げることはありません。

ファイルが取り込まれると、ツールは見つかったペアの数と使用した列をお知らせします。AIアシスタントに表示されるのはこれだけです。件数と列名だけであり、文そのものが表示されることは決してありません。

## 各ファイルについて尋ねられる質問

ファイルから何かが学習を行う前に、レールはそれを保持する人々に次のように尋ねます。

- **これは誰のものですか？** あなた自身の言葉で答えてください（家族、先生、地域の事務所など）。
- **ここに含まれているのは誰の言葉ですか？** その文を話した人、あるいは書いた人です。おばあさんのノートはお孫さんが入力したとしても、そこにあるのはおばあさんの言葉です。
- **それらの人々はその使用に同意していますか？** 「*はい*」、「*まだ*」、または「*一部の人が断った*」のいずれかです。この質問に答えるまで、レールは確認を続けます。まだ同意していない人や、断った人の言葉が、翻訳システムの学習に使われることは決してありません。
- **翻訳システムがここから学習してもよいですか？**
- **このファイルをこのコンピューターの外部に出してもよいですか？** あなたが回答するまで、ファイルは最初は非公開（このコンピューター内のみに保持）のままです。

回答はファイルの横にある小さなメモに記録され、すべてのツールがこれに従います。一度回答した後は、ツールがルールをより厳しくすることはあっても、緩めることは決してできません。唯一の例外は、まだ確認を取っていなかった話し手の方が後から同意してくれた場合です。

アシスタントがこれらの質問を尋ねますが、あなたの代わりに答えることは決して許されていません。まだ分からない場合（たとえば、叔母さんに確認する必要がある場合など）は、「*まだ*」と答えてください。レールはそのファイルを脇に置いて作業を続け、後でまたそっと尋ねます。

## 実際の様子

ツールの練習走行（作成した文を使った例）では、ある家族が4つのファイルを持ち込みました。祖父のスプレッドシートから<WalkFact of="trainingFiles.0.pairs" />個の文ペア、叔母のものから<WalkFact of="trainingFiles.1.pairs" />個、<WalkFact of="lexicon.pairs" />語の単語リスト、そしてテスト用に話者が確認した<WalkFact of="test.pairs" />文です。その都度、アシスタントは件数を報告し、次にファイルが誰のものか、そして翻訳システムがそこから学習してよいかを尋ねました。

## ほかの場所からの文

ご自身が書いたものではない文（書籍、ウェブサイト、出版された文献集など）を使用する場合、それらには固有のルールがあります。閲覧はできても共有はできないものや、何かの学習に使ってはならないものもあります。そうした文も同様に取り込み、同じように質問に正直に答えてください。ツールはあなたの回答を厳格に守ります。文献集のライセンスが一般的でない場合や不明確な場合、所有者が許可するまで、ツールがそれを外部のAIサービスに送信することはありません。
