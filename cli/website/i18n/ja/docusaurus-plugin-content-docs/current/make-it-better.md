# ラウンドを重ねて、より良くしていく

最初の翻訳機は始まりに過ぎず、終わりではありません。ここから翻訳機は**ラウンド**を重ねて成長していきます。各ラウンドでは、話者が翻訳文を確認し、最も役に立ちそうな文を追加して、翻訳機が再び学習します。毎ラウンドの終わりに、短いレポートが届きます。何が変わったか、ツールの確信度はどのくらいか、そして次に何をすべきかがわかります。

これがガイドレール（rails）の中核です。そして、話者の時間が最も活きる場面でもあります。

## 最初のラウンドの前に：どのくらいの時間をかけられますか？

ガイドレールはまず、話者がどのくらいの時間を費やせるかを尋ねます。週に何時間か、そして全体でどのくらいかです。各ラウンドはその時間に合わせて調整されます。いくつかのラウンドを経て傾向が見えてくると、その時間で何が達成できそうかを、ガイドレールがありのままにお伝えします。時間が足りなさそうな場合も含めてです。それ以上の時間を無理に求めることは決してありません。話者の時間は、話者自身のものです。

## 1つのラウンドの流れ

1. **ほしいものリスト。** ツールは翻訳機が間違えた箇所を確認し、最も学習の助けになるものをまとめた印刷用シートを作成します。これまで見たことのない単語（一度見かけただけの単語は身につきにくいため、1語につき2〜3文が求められます）や、つまずきやすい文のパターンなどです。シートの4分の1は空けてあるので、*あなた*が必要な文を書き込むこともできます。使い方は自由で、たくさん使っても少しだけでも構いません。
2. **あなたの文。** 実際に翻訳してほしい文を20文以上書きます。家庭で話すようなこと、メモに書くこと、授業で教えるようなことなどです。話者の方が今週確認できる分だけ用意してください。
3. **翻訳機が下書きを作成します。** 翻訳機はそれぞれの訳文を話者向けのシートに書き出します。練習用の文が少ないうちは、下書きのない行が一部あります（練習用文が50文になるまでは2行に1行、200文になるまでは4行に1行）。話者がその行を書き、それらが新しい練習用の文（学習には使われない文）になります。
4. **話者が確認します。** 各下書きについて、合っていれば**Y**、間違っていれば**N**（その上で正しい言い回しを記入）、よく分からなければ**?**を付けます。表計算ソフトで開いて入力するか、印刷して後から印を入力します。

   2巡目以降は、以前のシートから約10行に1行が意図的に再登場します。シートの上部にその旨が記載されていますが、どの行かは書かれていません。初めて見る文として、新たに判定を付けてください。判定がどれくらい一致するかによって、その評価がどれほど信頼できるかが分かります。これらの行にかかる時間はそれぞれ数秒程度で、その巡の結果に影響することはありません。
5. **ツールが判定を読み取ります。** 正しかった下書きの数を数えます。修正された文と、正しいと判定された下書きは、通常のファイルと同じように誰のものかを指定した上で、新たな学習用の文になります。
6. **レポート。** 以下をご覧ください。
7. **再度学習します。** あなたが承認すると、翻訳機はこれまでのすべてから学習します。通常は現在使用しているものを引き継ぐため、1巡にかかる時間は最初の学習時よりも短くなります。新しい翻訳機は、現在使用中のものと同じ練習用の文を使って、1文ずつ比較されます。単なる偶然を超えて優れている場合にのみ、レールはそれをあなたに提案し、あなたが同意した場合にのみ切り替わります。そうでなければ現在の翻訳機がそのまま維持され、次の巡が始まります。練習用の文が50文未満の場合、スコアからどちらが優れているかを判断することはできないため、ツールが推測することはありません。現在使用中のものがそのまま維持され、代わりに話者が判断します（以下を参照）。

## ラウンドレポート

各レポートは、進捗、確認結果、次にすべきことの順で表示されます：

- **話者が正しいと判定した下書きの割合** — 最も重要な数値 — ツールの確信度を示す範囲とともに表示されます。
- **練習スコア** — 翻訳機が一度も学習していない練習用の文において、どれだけ正解に近いかを示す100点満点の数値 — そして新しい翻訳機が本当に以前の翻訳機を上回ったかどうか。
- **単なる丸暗記になっていないかの確認** — 練習用の文での向上が、新しい文でも見られるかどうか。
- **判定がどれほど信頼できるか** — 再度提示された10行の判定が終わった時点で、話者がどれくらいの頻度で同じ判定をしたか、そして以前は間違いと判定された下書きが、より頻繁に正しいと判定されるようになっていないか（翻訳機に慣れるにつれて誰にでも起こり得ることです）。これは誰のせいでもなく、知っておく価値があることです。
- **「実用」まであとどれくらいか** — 向上傾向が確かなものになった時点で、文の数が2倍になるごとに、あとどれくらいの文数と時間が必要になりそうかを示す予測範囲。この範囲には、話者の判定がどれほど信頼できるかも反映されます。
- **次にやるべき2〜4つのこと** — たとえば、*これらの単語を使った文を書く*、*このシートに印を付ける*、*より強力な翻訳機を試す*、*「プロジェクトに参加」から助けを求める*など。

アシスタントは、すべての数値の意味とともにそれらを伝え、ツールが測定できた成果のみを称え、結果がそうであれば *"測定可能な変化はありませんでした"* とありのままに伝えるよう設定されています。測定可能な変化がなかったラウンドも無駄ではありません。現在の翻訳機が維持され、現在地を把握することができます。

## 話者はどちらの訳か知らずに確認する

ご自身の文に対して、どちらの翻訳機によるものかを伏せたブラインド確認を行う場面が2つあります：

- **新しい翻訳者を使い始めた後**、次のシートにはその下書きと、置き換えられた翻訳者の下書きがランダムに混ざって表示されます（ラベルは付きません）。話者自身の評価が一致した場合にのみ、向上が本物の進歩と見なされます。
- **練習文で判断がつかない場合**（練習文が50文未満であるか、ラウンドで測定可能な変化が見られなかった場合）、次のシートの下書きの半分は新しい翻訳者によるものになります。話者が明らかにそちらを好む場合、レールはそれを使い始めることを提案し（同意するかどうかはあなたが決めます）、レポートには話者の評価に基づいて選ばれたことが記録されます。

どちらの場合も、話者はどの翻訳機が書いたかを知ることなく、すべての下訳を同じように判定します。

## ラウンドを進めても変化が見られなくなったら

目に見える向上が2ラウンド続けて見られないからといって、ラウンドの効果がなくなったわけではありません。翻訳機がある程度良くなると、1回のラウンドで加わる改善幅が、練習文で捉えられる大きさを下回ることがあります。レポートにはその旨がありのままに示され（わずかな改善なのか、まったく改善していないのかを判別できないこと）、より早く前に進む方法を提示します。より強力な翻訳機を使うか、間違えやすい種類の文をもっと増やすことです。

小さなモデルの翻訳者から使い始め、お使いのコンピューターでより強力なモデルを学習できる能力があり、前回の翻訳者変更から2ラウンド連続で測定可能な向上が見られない場合、レールは切り替えを提案します（練習文が少なすぎて判断できないラウンドは数えません）。ダウンロード容量が大きくなり、学習にも時間がかかるため、レールは*はい*か*今はしない*かを尋ねます。同意した場合、これまで集めたすべてから学習を行い、測定可能なほど優れている場合にのみ提案されます。切り替える前には、やはりあなたの同意が必要です。

## まだ同意を得られていない人たち

まだ同意を得られていない人からの文が含まれている場合、ガイドレールはそれらを一旦除外して処理を続けます。セッションごとに、全員の同意が得られたかどうかを一度だけ穏やかにお尋ねします。「はい」と答えられた文は、次のラウンドから学習に加わります。
