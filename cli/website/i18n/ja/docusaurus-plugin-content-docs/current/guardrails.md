# ガードレールを一つずつ見ていく

ほとんどの翻訳プロジェクトは、派手に失敗するわけではありません。静かに失敗します。信頼して共有された言葉が、あるべきでない場所に届いてしまう。すでに暗記した文でテストされているために、翻訳機が素晴らしく見えてしまう。たまたま結果が良かっただけの回が、進歩のように見えてしまう。

以下に挙げるそれぞれのガードレールは、そうした失敗を防ぎます。ツールはそれらのほとんどを自動で適用します。いくつかについては、あなたとアシスタントの対応に委ねられており、それぞれその旨を明記しています。

この先によく出てくる言葉：**スコア**とは、翻訳機の文が話者の語った文にどれだけ近いかを示す数値です。スコアが高いほど、近いことを意味します。

## 1. あなたの言葉が外に出てしまうこと

**何が問題か。** 信頼して共有された言葉が、他人のコンピューター上や、他人のAIの中に入り込んでしまいます。

**レールは何をするか。** 各ファイルのすぐ隣に、その言葉が属する人々が決めたことを記したメモが置かれます。このコンピューターから外に出してよいか、翻訳機がそこから学習してよいか、が書かれています。すべてのツールはこのメモに従います。

- ファイルは、その言葉が属する人々が回答するまでは、非公開として扱われます。
- 一度回答が出たら、ツールはルールをより厳しくすることはあっても、緩めることは決してありません。ルールを緩められるのは、人間が意図して手作業で行う場合だけです。まだ尋ねられていなかった人が後から同意した場合、その同意が追加されます。
- その話者が同意したと人々が認めるまでは、誰の言葉も翻訳機の学習には使われません。まだ同意していない話者や、同意しなかった話者の言葉は除外されます。
- 非公開の文から学習した翻訳機も、学習した内容をそのまま出力する可能性があるため、非公開として扱われます。
- このコンピューター内に置かれたファイルについて、ツールはAIアシスタントに文そのものではなく、件数だけを示します。

**あなたに委ねられていること。** ほとんどのAIアシスタントはある企業のコンピューター上で動作し、読み取ったものをすべてその企業に送信します。ファイルを開くよう指示すれば開けてしまいます。それを防げるツールはありません。非公開にしておきたい言葉については、ご自身のコンピューター上で動作するアシスタントを使用するか、ファイルを開くよう指示しないでください。また、ツール側では誰が質問に答えたかまでは判別できないため、言葉が属する人々自身が回答する必要があります。全容については[あなたの言葉、あなたのルール](/docs/your-words-your-rules)をご覧ください。

## 2. 実は宿題と同じだったテスト

**何が問題か。** 翻訳機に学習させた文そのものを使ってテストしてしまいます。翻訳機はそれを覚えているため優秀に見えますが、新しい文になると途端につまずきます。これは、前夜の宿題とまったく同じ問題で生徒を採点するようなものです。

**レールは何をするか。** 学習を始める前に、流暢な話者が確認したテスト用の文を取り分けておきます。それらには印が付けられ、翻訳機がそこから学習することは決してありません。また、人間が見たいと要求しない限り、ツールがそれらを表示することはありません。

## 3. ほぼ同じ文

**何が問題か。** テスト文そのものは翻訳機が学習した文の中にはありませんが、ほぼ同じ文が含まれている場合があります。テストされる文が「*私たちは店に行きます*」で、学習した文が「*私たちは今、店に行きます*」だったとします。これでは翻訳機が評価されるのは、翻訳する力ではなく記憶力になってしまいます。

**レールは何をするか。** 学習を始める前に、翻訳機が学習しようとしているすべての文が、テスト文と照合されます。完全に一致する文やほぼ同じ文は取り除かれます。文のパターンだけが共通している文は残されますが、その数は記録されるため、それによってスコアが実態よりどれだけ良く見えている可能性があるかを把握できます。

## 4. 答えの盗み見

**何が問題か。** 少し変更を加えるたびにテスト文に対して翻訳機をチェックしていると、次第にその文に合わせた調整をしてしまいます。それではテストから新しいことが何も分からなくなります。

**レールは何をするか。** 日々の進捗は、データから取り分けられた別の**練習用の文**で判断されます。トレーニングツールがテスト文を評価するたびにその記録が残り、事前の予測が記録されるまで、テストのスコアは表示されません。

## 5. 結果を見てから予想を決めること

**何が問題か。** 結果が画面に出てしまうと、「*だいたい予想通りだった*」と言ってしまいがちです。これでは結果から驚きを得ることも、何かを学ぶこともできなくなります。

**レールは何をするか。** 最初の翻訳機を学習させる前に、構築する人々が自分たちの言葉で予想を書き留めます。それが書かれるまでレールは先へ進みません。そして後から、結果がその予想と突き合わせて確認されます。

## 6. 偶然の良さを進歩と勘違いすること

**何が問題か。** 特に文の数が少ない場合、単なる偶然で2つの翻訳機のスコアにわずかな差が出ることがあります。たまたま結果が良かっただけの回が進歩のように見えたり、本当の改善が偶然のばらつきの中に隠れてしまったりします。

**レールの役割。** 新しい翻訳ツールは、現在使っているものと同じ練習文を使って、一文ずつ比較されます。単なる偶然とは考えにくいほど高いスコアを出した場合にのみ提案され、その場合でも、あなたが「はい」と答えて初めて切り替わります。そうでなければ、ツールは*「測定可能な変化なし」*と表示し、その練習文の数では捉えきれないほどわずかな向上幅であることを伝えます。練習文が50文未満の場合、スコアでは判断できないため、ツールは一切判断を下しません。代わりに、どちらが作ったかを伏せた両方の下書きに対して、話者がつけた評価によって判断されます。

## 7. 辞書よりも優れているか？

**何が問題か。** スコアそのものだけでは、ほとんど意味がありません。単語リストで各単語を一つずつ引くのと大差ない結果しか出せていない翻訳機かもしれません。

**レールは何をするか。** 単語リストがある場合、ツールはまず単語を一つずつ引くだけでどれだけの成果が出るかを測定します。翻訳機は、その結果を上回る場合にのみ使う価値があります。

## 8. 一つのスコアに隠れた2つの翻訳機

**何が問題か。** 翻訳機がある文を処理できない場合、2つ目のバックアップ翻訳機が代わりに引き受けることがあります。実際に翻訳機を使用しているときはそれで構いません。しかし、テストのスコアにその2つが混ざってしまうと、どちらを測定したのかが分からなくなります。

**レールは何をするか。** テストのスコアは常に1つの翻訳機からのみ取得されます。バックアップの使用は、翻訳機を実際に使うときには認められますが、測定するときには決して認められません。

## 9. 事実以上のことを言うこと

**何が問題か。** 熱心なアシスタントが、ほとんど学習が進んでいないにもかかわらず、「*翻訳機の準備ができました！*」と報告してしまいます。

**レールは何をするか。** ツールは実際に起きたことの記録を保持します。アシスタントはそれだけを報告し、すべての警告を一言一句そのまま伝えるよう指示されます。これについては、アシスタントが指示を正しく守るかどうかに委ねられています。

---

これらを守ったからといって、翻訳機が自動的に良くなるわけではありません。翻訳機の現在の立ち位置を常に把握できるようにし、その言語を持つ人々が常に主導権を握り続けられるようにするためのものです。
