# はじめる前に

翻訳機を作るうえで最も大切な部分には、コンピューターはまったく必要ありません。
ツールの公開前であっても、今日からすべて進めることができます。

## 話者の方々と話す

翻訳機は人々の言葉から作られます。ですから、まずは人々から始めましょう。何を作りたいのか、なぜ作るのか、集めた文は誰の目に触れるのか、そして断ることもできるのだということを伝えてください。誰にどのように感謝を伝えるべきかも確認しましょう。詳しくは[話者の方々と協力する](/docs/working-with-speakers)をご覧ください。

## つづり方を決める

言語の表記が人によって異なると、翻訳機は混乱した内容を学習してしまいます。学校で使われている表記やコミュニティの標準的なつづりなど、プロジェクトとして1つの方法を選び、文がどの方言のものかを記録しておきましょう。

## 言葉が誰のものかを決める

集めた文の集まりごとに、誰がそれを保持しているのか、何に使ってよいのかを把握しておきましょう。翻訳機がそれを学習してもよいのか、そのデータがコンピューターの外に出てもよいのか、といった点です。レール（rails）がこれらの質問をしてきます。その重要性については[あなたの言葉、あなたのルール](/docs/your-words-your-rules)で説明しています。

## 文を書き留めはじめる

まだ何も書き留めていなくても大丈夫です。話者がいれば始めることができます。1人がその言語で文を話し、もう1人がスプレッドシートに英語の対訳を並べて入力します。列は2つ、1行につき1文です。

家族が普段実際に話しているようなこと（家で、学校で、お店で、友達同士で交わす言葉）を書き留めてください。短く日常的な文こそが、
もっとも多くのことを教えてくれます。

## テスト用に文をいくつか取り分けておく

もっとも堪能な話者の方に数十文ほど丁寧に確認してもらい、それらを別のファイルに保存しておきます。これらがテスト文になります。すべての翻訳機を評価するために使われ、学習には決して使われない文です。その理由については[テスト文を取り分けておく](/docs/your-test-sentences)で説明しています。

## 後で必要になるもの

- コンピューター — 最近のものであればどれでも始められます。新しめのMacや、
  NVIDIAグラフィックスカードを搭載したコンピューターがあれば、より強力な翻訳機を構築できます。
- ディスクの空き容量。ツールが保存する強力な翻訳機は、それぞれ1ギガバイト以上の
  容量を使います。学習を始める前に空き容量があるか確認が行われ、使われていない
  以前の翻訳機を片付けて削除することもできます。
- そのコンピューター上でアプリとして動作するAIアシスタント、または
  少しのコマンド入力に抵抗がない人。

文がいくつか集まり、ツールが公開されれば、準備完了です。
