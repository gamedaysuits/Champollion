# 封印テストを主催する

皆さんの言語に最適な翻訳機は、研究者、学生、企業といった他の誰かから提供されることがあります。**封印テスト**を使えば、相手に文章を一切見せることなく、*皆さん自身の*文章を使ってその性能を証明してもらうことができます。

## 仕組み

テスト用の文章は、皆さんのコンピュータ上で鍵をかけて施錠されます。参加を希望する人々は、自身の翻訳機を提出します。コンピュータが施錠された文章に対して各翻訳機を実行し、出力されるのはスコアのみです。文章そのものや、生成された翻訳が出力されることは決してありません。

そのため、テストとしての真実性が保たれます。誰も文章を読むことができないため、事前に研究したり、テストに合わせて調整したりすることはできません。

## 主催者が決めること

参加者が競い合う前に、皆さんが条件を設定します：

- **勝利と見なす基準**（どこまでの品質が求められるか）。
- **勝利した手法の扱い**：
  - **皆さんのものになる** — テストを主催する皆さんに権利が渡されます。
  - **開発者が保持する** — 皆さんはスコアを付けるだけで、確認用に施錠されたコピーを保持するにとどまります。
  - **開発者が保持するが、全員に共有する** — 開発者はそれをオープンに公開しなければなりません。
- **賞金や賞品の有無**、およびその提供者。Champollionが賞の分け前を受け取ることは一切ありません。

## 現在利用可能なもの

封印テストのためのツールは機能しています。データセットの施錠、インターネットから切り離されたコンピュータでの提出された翻訳機の実行、そしてスコアのみの公開が可能です。しかし、これは**まだ自動化（レールに乗って）はいません**。現在は、アシスタントの質問に一歩ずつ答えていくのではなく、詳細なマニュアルに沿って手順を進める必要があります。

現在の鍵の保持者：データセットを施錠した人が保持します。鍵を共同で管理する担当者を指定したコミュニティはまだなく、Champollionが鍵の一部を保持することも一切ありません。

参加募集中の封印テストがある場合は、[共有タスク](/shared-tasks)のページに一覧表示されます。
