# Champollionとは

**Champollionは、他の誰も測定していない言語の機械翻訳を測定し、
その結果を公開します。**

それがすべての基本理念です。このサイトにあるものはすべて、その測定を行うツール、
測定結果によって構築されるマップ、または私たちが測定を行う際のルールのいずれかです。

---

## 課題

現在、約7,000の生きた言語が存在します。そのほとんどについて、次のような
基本的な質問に答えることはできません。*「これを翻訳する必要がある場合、利用可能な最善の方法は何で、
それは実用に耐えうる品質なのか？」*

「どの企業がデモを持っているか」ではありません。人間の翻訳者、ルールベースのシステム、
プロンプトによる言語モデル、学習済みモデルなど、どの手法が**この言語ペアの、この種のテキスト**に対して
実際に機能するのか、そしてそれをどうやって知るのか、ということです。

英語↔フランス語の場合、その質問にはすでに何千回も答えが出されています。しかし、
英語↔Plains Cree（平原クリー語）、あるいはAyta Abellen（アエタ・アベレン語）、その他何千もの言語については、
そもそも質問すらされていないことがよくあります。対応言語の追加は発表されますが、品質が示されることは稀です。

誰も測定していないため、プレスリリースから真の改善を見分けることは誰にもできません。
そして、この技術を利用したいと考えるコミュニティには、自分たちの言語を任せても安全かどうかを
確認する術がありません。

## 私たちの取り組み

私たちは翻訳エンジンを構築しているわけではありません。エンジンを構築するのは大手テクノロジー企業です。
私たちは、エンジンが機能するかどうかを判断するためのものを構築しています。

1. **テストセットに対して手法を実行し**、すべての手法とすべての言語で同じ手順を用いてスコアを算出します。
2. **結果をその出所とともに公開します**。どのようなデータ、どのバージョンの手法、どの指標を使用し、どれだけのコストがかかったかを示します。
3. **マップの形が見えるまで繰り返します**。どの言語がどの言語とつながっているか、そのつながりの強さはどの程度か、そして空白地帯はどこにあるかを明らかにします。

「この言語ペアで機能する手法はまだない」という正直な結果も、私たちが公開する結果の一つです。
現在、マップの大部分はそのような回答で占められており、それを明言することに意味があります。
目に見えるギャップは、誰かが資金を提供したり、埋めたりできるギャップなのです。

## 私たちが従うルール

これらはマーケティングではなく、制約事項です。これらがソフトウェアにできることを形作ります。

**私たちはあなたのコーパスを保持しません。** テストセットは、私たちにアップロードするのではなく、
すでに存在している場所を指定することで登録されます。手法は、私たちが決して所有しないコーパスに対して
スコア付けされます。封印されたセットの場合、データは外部に出る前にあなたのマシン上で暗号化され、
コミュニティの鍵管理者の一定数が揃って初めて実行を承認できます。

**言語データは生体データのように扱われます。** コーパスを提供する人々は、そのコーパスと、
それに対して測定されるすべてのものに対する鍵を保持します。同意は当然のものとみなされるのではなく、
求められるものであり、撤回することも可能です。

**私たちは主権の実現を目指す（sovereignty-aspirant）立場であり、主権の認証を受けた（sovereignty-certified）立場ではありません。**
プロジェクトが言語データのコミュニティによる所有と管理を尊重できているかどうかは、
プロジェクト自身が主張できることではありません。
私たちは作業を行い、そのメカニズムを正直に説明します。その判断は関与するコミュニティに委ねられます。

**人間であれ機械であれ、あらゆる手法を歓迎します。** プロの翻訳者、FSTベースのルールシステム、
プロンプトによるフロンティアモデル、ファインチューニングされたNMTモデルは、同じテストセット上で
同じように比較されます。私たちが重視しているのは言語が翻訳されることであり、どのツールが勝つかではありません。

**できないことも公開します。** [正直な制限事項](/docs/network/honest-limitations)をご覧ください。
これは、このプロジェクトがまだ主張して*いない*ことのリストです。ここにある他の情報を信頼する前に、
まずこれをお読みください。

## 各コンポーネントとその目的

| 目的 | 使用するもの | 概要 |
|---|---|---|
| アプリやサイトを翻訳する | **[Champollion CLI](/docs/intro)** | 1つのコマンドでロケールファイルを翻訳します。言語ペアごとに手法を選択できます。 |
| 手法をスコア付けする、またはスコアを再現する | **[MT-Eval Harness](/docs/network/specifications/harness)** | Pythonの評価エンジンです。このサイトのすべての数値はここから出力されます。 |
| 結果を提出する、またはコンテストを開催する | **[The Arena](/docs/network/getting-started/submit-a-method)** | 提出窓口、データベース、コンテストの仕組みであり、測定が行われる場所です。 |
| 言語ペアについてわかっていることを確認する | **[The Network](/docs/network/)** | 測定によって構築されるマップです。カバレッジ、つながりの強さ、ルーティング、次に測定すべきもののキューが含まれます。 |
| 言語を調べる | **[The Atlas](/languages)** | <SSOTCount field="catalogLanguageCount" />の言語カードです。分類、音韻論、活力、存在するリソースが含まれます。すべての値には情報源が引用されています。 |
| 自分を欺くことなくモデルをトレーニングする | **[NMT Forge](/docs/network/getting-started/training-honestly)** | 標準的な自己欺瞞（テストデータの漏洩、代表的でない分割）を構造的に困難にするガードレールを備えたトレーニングスイートです。 |
| AIエージェントとしてこれに取り組む | **[エージェントガイド](/docs/network/getting-started/agent-guide)** | ツール、MCPサーバー、および機械可読エンドポイントに含まれる内容です。 |

**Champollionはインデックスであり、裁定者ではありません。** すべての値は情報源を引用し、
その情報源が実際に述べていることを報告します。情報源間で意見が異なる場合（話者数については
非常に頻繁に起こります）、カードにはそれらすべてが帰属とともに表示されます。
私たちが勝者を選んだり、コンセンサスを捏造したりすることはありません。

## 名前について

Jean-François Champollion（ジャン＝フランソワ・シャンポリオン）は、3つの文字で同じテキストが書かれた
ロゼッタ・ストーンを使用して、エジプトのヒエログリフを解読しました。パラレルテキスト（対訳コーパス）は、
現在でも翻訳を学習するための方法です。また、この名前には、声に出して言及する価値のある緊張感も含まれています。
それは、搾取の時代に、ヨーロッパの学者が他人の書いたものを読んだということです。私たちはそのことについて
考えています。だからこそ、上記の主権に関するルールは、パンフレットの1ページではなく、
ソフトウェアの制約事項となっているのです。

- **背景を知りたい場合** → [この分野がどのようにしてここに至ったか](/docs/network/context/mt-field-briefing)、[何が言語としてカウントされるか](/docs/network/context/what-counts-as-a-language)、および[カバレッジはどのようにカウントされるか](/docs/network/context/coverage-counting)。
