# これは何か

大手の翻訳アプリは、世界の大半の言語に対応していないか、大きく間違った訳を出してしまいます。あなたの言語もそうであるなら、自分専用の翻訳機を作ることができます。ご家族やコミュニティがすでに持っている文や単語リスト、物語を使って、ご自身のパソコン上で作れます。

AIアシスタントがすべての手順を案内してくれますし、重要な決定はあなたが下します。翻訳が母語話者の話し方にどれだけ近づいているかを各ステップで確認できます。そして大きな成果は、話者が確認した文を使ってテストされます。

## 始めるのに必要なもの

すでに手元にあるもので十分です。

- 例文とその翻訳をまとめたスプレッドシート
- 単語リストや辞書
- 先生の授業用プリント、または誰かが文字に起こした録音資料
- そして何よりも貴重なのは、その言語を話し、翻訳機が書いたものを確認してくれる人です。

まだ文字になっているものがない場合でも、話者がいれば始められます。方法は[始める前に](/docs/before-you-begin)をご覧ください。

事前にファイルを変換する必要はありません。ツールはスプレッドシート、Wordの表、辞書ファイルをそのまま読み込みます。また、おかしな行（行が1つずれた翻訳、入れ替わった2つの列、重複した文など）があっても、何も勝手に変更せずに指摘してくれるので、データに詳しい人がどうするかを決められます。

## 進め方

プロジェクトを開始すると、ツールがそこから一歩ずつ案内してくれます。文を取り込み、テスト用に一部を取り分け、最初の翻訳機を学習させ、試し、さらに改良していきます。

細かな作業はAIアシスタントが担当します。言葉の権利は誰にあるのか、翻訳機がそれらから学習してよいか、ツールをインストールするか、何をもって十分な品質とするかなど、あなた自身が下すべき判断のたびに作業を止めて確認してくれます。そうした事柄があなたの許可なく決められることはありません。

アシスタントは、AIアシスタントのデスクトップアプリのように、お使いのパソコン上で動くものである必要があります（スマートフォンのアプリではツールを実行できません）。多くのアシスタントは読み取った内容を運営企業に送信するため、このツールはアシスタントに対して、非公開ファイルに文が「何行あるか」のみを伝え、文そのものは決して送信しません。ただし、パソコンを操作できるアシスタントは自分でファイルを開くことができます。非公開にしておくべき言葉がある場合は、アシスタントにそのファイルを開かせないでください。詳しくは[あなたの言葉、あなたのルール](/docs/your-words-your-rules)をご覧ください。

## 得られるもの

ご自身のパソコン上で動く翻訳機です。ウェブブラウザで試したり、翻訳の下書きに使ったりできます。そして準備が整ったと判断し、言葉を受け継ぐ人々が同意したときには、アプリやウェブサイトに組み込むこともできます。

**最初にできる翻訳機は、おそらく「会話集」のようなものです。** 学んだものと似た文は得意ですが、新しい文になると不安定になります。どんなプロジェクトもそうやって始まります。そこから、何往復も重ねて成長していきます。話者が下書きの正誤を判定し、ツールが次に最も役立ちそうな種類の文を提案し、そのたびに本当に向上したかどうかが分かります。

実際の言語をこの仕組みに乗せて、実用的な翻訳機の完成までやり遂げたコミュニティはまだありません。今始めれば、あなたが最初のひとりになります。[まだできないこと](/docs/what-it-cant-do-yet)で、現状できることの目安を確認できます。

## 対象となる方

ご家族、教師、言語プログラム、コミュニティの事務所、そしてそれらを支える人々など、大手の翻訳ツールが見落としている言語を持つすべての人のためのものです。書かれた文が少ない言語や、自分たちの言葉をどう扱うかを自ら決める人々のために作られました。

## 発生するコストについて

このツールは、ご家族、学校、慈善団体、病院などの公共サービスには無償で提供されます。話者のコミュニティが商業目的（語学アプリや有料サービスなど）で使いたい場合も、ご連絡いただければライセンスは無償です。

パソコンが必要です。近年のものであればどれでも始められます。16 GBのメモリを搭載した比較的新しいMac（M1チップ以降）、または16 GBのメモリを持つNVIDIAグラフィックボードを搭載したパソコンがあれば、より強力な翻訳機（または8 GBでその軽量版）を構築できます。（Windowsの場合、学習ツールはWindows標準のLinux環境であるWSL内で動作します。）それ以外のパソコンでは、ずっと小型のものが作られます。AIアシスタントをご利用の場合、別途費用がかかることがあります。

## これが対象としないもの

文字を入力して今すぐ翻訳を得るためのアプリではありません。翻訳機を作るための作業場です。また、翻訳機が必ず優れたものになると約束するものでもありません。お約束するのは、現在の到達点が常に分かり、何をすればさらに良くなるかが分かるということです。

この名前は、コプト語（コプト教会の祈りの中に今も生き続けているエジプト語の最後の形態）を手がかりにヒエログリフを解読したジャン＝フランソワ・シャンポリオン（Jean-François Champollion）に由来します。受け継がれ、生き続けた言語こそが鍵でした。詳しくは[なぜこの名前なのか](/docs/the-name)をご覧ください。
