# まだできないこと

最初にできあがる翻訳機は、おそらく**フレーズ集**のようなものでしょう。
学習に使った文とよく似た文は得意ですが、新しい文になると怪しくなります。
それは普通のことです。どんなプロジェクトもそこから始まります。

翻訳機を進歩させるのは、より多くの文です。それも適切な種類で、その言語を話す人によって確認された文です。
毎回のラウンドで、ツールは翻訳機が本当に良くなったかどうかを知らせ、次に最も役立つ文を提案します。
このページでは、その道のりでどのようなことが起きるかを、分かりやすくお伝えします。

## 実用的な翻訳機にはたくさんの文が必要です

どのくらいの数でしょうか？ 実在する言語については、まだ誰にも分かっていません。分かっているのは以下のことです。

私たちは、コンピューターがすべての回答を自動で判定できるように、練習用の言語を作りました。
語数は約2,000語、完全に規則的な文法、整ったデータです。ノートパソコンで学習させた翻訳機に、
一度も見たことのない新しい日常の文を翻訳させ、英語の意図が正しく再現されているかを
コンピューターで判定しました。

- 6,400の例文を学習させた後では、**100文中およそ79文**が完全に正解でした。
- 25,600例の後では、**100文中およそ96文**でした。

一度も見たことのない単語が含まれる文は、すべて間違って出力されました。6,400例の時点での誤りの約3分の1がこれにあたり、
残りはまだ学習していない文法によるものでした。まず知っておくべきことはこれです。**翻訳機は、学んだことのない単語を翻訳することはできません。**
そのためツールはそれを指摘します。翻訳機がレッスンで一度も見たことのない単語が文に含まれている場合、
どの単語かを知らせます。その文は、どれほど自然に読めたとしても、間違っている可能性が非常に高いからです。

本物の言語は、私たちの練習用言語よりもはるかに豊かです。日常の語彙はもっと多く、複数の意味を持つ単語があり、
英語では表現されない事柄を示す文法もあります。そのため、これらの数字は最低限の目安であって、正確な予測ではありません。
実際の言語ではもっと多くの文が必要になりますが、具体的にどれだけ必要かはまだ分かっていません。現在、検証を進めています。

時間に関して言えば、本物の話し手の時間を測定したことはまだありません。もし1文の作成や確認におよそ1分かかるとすると、
6,400文で約100時間になります。家族やクラスのみんなで分担し、各自が週に1〜2時間ずつ取り組めば、積み重ねていくことができます。
また、そこまで行かなくても、ずっと手前の段階で小さな翻訳機がよく使うフレーズに役立ってくれます。
詳しくは[文はいくつ必要？](/docs/how-many-sentences)をご覧ください。

## 良い翻訳機を保証することはできません — 分かるのは現状だけです

スコアは、話し手が口にした文に翻訳機がどれだけ近づけたかを測るものです。
表現は違っていても良い翻訳であるのに低いスコアになることもあれば、自然に聞こえるけれど中身が間違っている翻訳が
かなり高いスコアを取ることもあります。だからこそ、話し手が下書きを確認することが、どんな数値よりも大切なのです。

また、スコアは測定に使った文と同種の文についてしか語れず、文の数が少なければ大まかなものにとどまります。
ツールが示すのも単一の数値ではなく範囲です。翻訳機が書く*次の*文が正しいかどうかまでは教えてくれません。
使うに足るものかどうかを判断するのは、その言語を流暢に話す人です。

## 実在する言語で最後までやり遂げた人はまだいません

私たちは練習用の言語とさまざまなAIアシスタントを使って、空のフォルダーからブラウザで試せる翻訳機に至るまで、
レールのすべての工程を何度も試してきました。AIアシスタントが模擬の家族を手伝う最近の練習ランでは、
半分以上がどこかの段階でうまくいかなくなりました。私たちはそれらの手順を修正し、現在改めてテストを行っています。

実際の言語を使って、このレール上で実用的な翻訳機の完成までやり遂げたコミュニティはまだありません。
今始めるなら、あなたが最初のひとりになります。

## 一部、まだ準備中の機能があります

- **ステップごとの案内ツールは次のバージョンで提供されます。** それまでは、これらのページでツールの仕組みを説明します。[始める前に](/docs/before-you-begin)には、今日できることが書かれています。
- **文の内容を見せることなく、他の人があなたの文で翻訳機をテストできるようにする機能**は動作しますが、まだレールには組み込まれていません。現時点では、長めのマニュアルに沿って作業する必要があります。
- **お使いのコンピューターの性能が重要です。** 16 GBのメモリを搭載した新しめのMac（M1以降）、または16 GBの専用メモリを持つNVIDIAグラフィックスカードを搭載したPCであれば、より強力な種類の翻訳機を構築できます。8 GBの場合はその軽量版になりますが、8 GBのPCでの動作はまだ試されていません。Windowsでは、学習ツールを実行するためにWSL（Windowsの組み込みLinux）が必要です。その他のコンピューターでははるかに小型のモデルを構築することになりますが、私たちのテストでは大幅に見劣りする結果となりました。
- **各ラウンドにはコンピューターの処理時間がかかります。** ほとんどのラウンドは最初からやり直すのではなく、使用中の翻訳機から引き継いで行われますが、強力な翻訳機では1回のラウンドに数時間かかることがあり、1台のコンピューターで一度に学習できる翻訳機は1つだけです。
- **文は短く保ってください。** 強力な翻訳機であっても、一度に読める文の長さには限りがあります。お使いの言語が独自の文字体系を使用している場合は、読める長さがさらに短くなります。長すぎる文があった場合はツールがカウントしてお知らせしますので、文を分割することができます。
- **つづりの自動チェックはありません。** 人によって言語の表記方法が異なる場合は、プロジェクトを始める前に表記ルールを1つに決めておいてください。

## すべての情報流出を防げるわけではありません

このコンピューター上に保持されているファイル（デフォルト設定）については、ツールはAIアシスタントに対して文そのものではなくカウント情報のみを表示します。
しかし、コンピューターを操作できるアシスタントは、指示の有無にかかわらず、あなたがアクセスできるすべてのファイルを開くことができ、
そのほとんどは読み取った内容を実行元の企業に送信します。
対策については、[あなたの言葉、あなたのルール](/docs/your-words-your-rules)で説明しています。

## 翻訳機は、生きた言語そのものではありません

翻訳機は、言語プログラムや学校、家族の助けにはなります。しかし、言語はそれを話す人々の中に、
そして日々使われることの中に生きています。
詳しくは[翻訳は言語復興ではない](/docs/network/perspectives/translation-is-not-revitalization)をご覧ください。

- 練習用言語の数値について：各データサイズにつき1回のみ実行したため、試行ごとのばらつきは測定していません。「完全に正解」とは、人の主観による判断ではなく、作られた言語独自の文法に照らして意味のあらゆる部分（動詞、時制、人称、否定、主語、目的語など）を自動検証した結果です。翻訳機には、Appleシリコン搭載のノートPC上でファインチューニングされた事前学習済みバイトレベルモデルを使用しました。学習時間によって結果は大きく変わります（同じモデルと6,400文の条件でも、学習時間を4分の1にすると約27/100の正解率でした）。したがって、これらは性能の限界値ではありません。6,400文の時点では、自然な文法で実在する単語を使用しているものの、元の意味とは異なってしまっている翻訳がおよそ9/100ありました。他のコンピューター上でツールが使用する小型モデルでは、6,400文の時点での正解率は約6/100でした。
- 強力な翻訳機が読み取れるのは1文あたり最大320バイトです。アクセント付きの文字やラテン文字以外の文字は1文字あたり2〜4バイトを消費するため、音節文字（カナやシラビックスなど）の場合は約100文字に相当します。学習処理では制限を超えたペアをカットする前にカウントし、提供される翻訳でも何をカットしたかが表示されます。
