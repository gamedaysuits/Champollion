# 話者とともに進める

翻訳プロジェクトにおいて最も価値があるのは、コンピューターではありません。その言語を話す人々です。文章を書き、下書きを確認し、*「いいえ、私たちの言い方はこうです」* と指摘してくれる人たちです。もしあなたがその一人なら、このページはあなたのため、そしてあなたの隣で働く人たちのためのものです。

## 一人ひとりに確認する

どの文も、誰かから生まれたものです。翻訳機が誰かの言葉から学習する前に、その人に確認してください。それが難しい場合は、その人の代わりに判断する立場にある人たちに確認してください。

- **分かりやすい言葉で尋ねる**: 文章が何に使われるのか、誰が目にするのか、そして断ることもできるということを伝えてください。
- **記録に残す**: レールには合意事項を記録する場所が用意されています。誰が、何に、いつ同意したのかを記録します。各ファイルの横にあるメモには、話者が同意したかどうか（*はい*、*まだ*、あるいは*一部が断った*）が記録され、ツールはその指示に従います。
- **「まだ」という答えでも問題ありません**: レールはそのような文章を脇に置き、作業を進めながら、後で改めて確認します。
- **亡くなった方について**: その方の言葉については、家族やコミュニティに判断を仰ぐべきであり、決して勝手に判断してはなりません。
- **考えが変わることもあります**: いつでも考え直すことができるようにしておきましょう。

## 相手の時間を尊重する

翻訳の確認は大変な作業です。レールは計画を立てる前に、話者がどれくらいの時間を割けるかを尋ね、各回の作業量をそれに合わせます。決してそれ以上を要求することはありません。目標達成には時間が足りなさそうだと分かった場合も、率直にその旨を伝えます。そのため、一緒に相談して決めることも、[プロジェクトに参加する](/docs/join-a-project) を通じて協力者を募ることもできます。

長時間の作業よりも、短時間のセッションのほうが効果的です。疲れてくると確認作業は難しくなり、疲れた状態での *「はい」* は翻訳機に誤った内容を学習させてしまいます。下書きに **?**（*わからない*）と付けることは、いつでも認められています。

## クレジットと謝礼

- **相手が希望する方法でクレジットを記載する** — 実名、家族名、コミュニティ名、あるいは記載しないこと。必ず確認してください。
- **話者の時間に対して報酬を支払うのは当然のことであり**、プロジェクトにおいてはリーダーがそれを決定します。Champollionはコミュニティが得た収益から一切の手数料を取りません。スポンサーからの支援金はすべて直接渡されます。

## 神聖な言葉と制限された言葉

誰にでも公開してよいわけではない言葉もあります。儀式用の言語、神聖な物語、特定の人だけが口にできる言葉、あるいは特定の時期にしか口にできない言葉などです。**そうした言葉は含めないでください。** 翻訳機は学んだことを、誰に対しても、いつでも繰り返すことができます。外に広めるべきではない言葉なら、翻訳機に教えてはならないのです。

確信が持てないときは、詳しい人に確認し、確認が取れるまでは含めないようにしてください。反対がないことではなく、前向きな同意が得られていることが基準です。

## 表記方法を決める

人によって言葉の書き方が異なると、翻訳機は混乱した状態を学習してしまいます。作業を始める前に、学校で使われている表記体系やコミュニティの標準など、プロジェクトで使用する表記法を1つ決め、その文章がどの地域の方言によるものかを明記してください。ツールはまだ自動でスペルチェックを行わないため、これは人間が一度決めて記録しておくべき判断事項です。

## 下書きの確認

レールが話者に下書きのシートを提示したときは、次のように対応します。

- **Y** — 下書きは正しく、自分ならそう言います。
- **N** — 間違っています。その上で、自分なら *どのように言うか* を書いてください。その修正こそが最も有用な一文になります。翻訳機がどこで間違えたかが正確にわかるからです。
- **?** — よくわかりません。それでも問題ありません。

下書き自体は正しくても、自分の普段の言い回しとは異なって聞こえることがあります。正しいものは正しいとしてマークし、より良い言い方があれば書き添えてください。

第2回目からは、前のシートからいくつかの行が意図的に再び登場します —
シートにはその旨が示されていますが、具体的にどの行かは書かれていません。初めて見るものとして、まっさらに評価をつけてください。2回とも
完全に同じ評価になる人はいませんし、それで問題ありません。評価がどれくらい一致するかによって、
結果をどれほど信頼できるかが分かるだけです。
