# リーダーボードと公開

[リーダーボード](/leaderboard)は、スコア測定された翻訳実行（run）の公開記録です。
誰でも追加できます。ご自身のマシン上で評価ハーネス（`mt-eval`）を登録済みデータセットに対して実行し、その結果を**実行カード**として公開します。ボードはこのカードを保持するだけであり、あなたに代わって手法を実行することはありません。文ごとのテキストを保持するのは、オープンライセンスの再配布可能なデータセットのみです。非商用、制限付き、封印（sealed）、隔離（quarantined）、またはローカル専用のデータセットについては保持せず、`--scores-only` を指定して公開した場合も決して保持しません。

これは測定値の台帳であり、いかなる翻訳モデルに対する優劣の最終判定でもありません。ここでの順位は、ある手法が特定のデータセットと指標においてどのようなスコアを出したかを示すものです。翻訳が優れていることを保証するものではなく、その手法をコミュニティの言語に使用する許可を誰にも与えるものではありません。

## 明確に区別される3つの要素

| | 概要 | 実行場所 |
|---|---|---|
| **ハーネス** ([`mt-eval`](/docs/network/specifications/harness)) | スコア測定ツール。手法とテストセットを受け取り、スコアと実行カードを生成します | あなたのマシン |
| **リーダーボード** | 提出の窓口であり、データセットと言語ペアの方向ごとにインデックス化された実行カードの台帳 | champollion.dev |
| **ネットワークマップ** | 公開された実行結果の集約：どの言語ペアが測定済みで、どれが未測定かを表示 | 台帳のビュー（コンポーネントではない） |

ボードを経由せずにマップに追加されるものはなく、スコア測定とフィンガープリントが付与された実行結果以外がボードに登録されることもありません。出所（provenance）のない測定値がこれらに含まれることはありません。

## 2種類のベンチマーク

**公開ベンチマーク**はオープンなデータセットを使用します。各データセットは、ソースからの取得ポインタを持つメタデータカードとして登録されます。ハーネスは実行時にアップストリームから参照訳をダウンロードし、固定されたSHA-256ハッシュと照合した上で、取得したデータに対してスコアを測定します。公開データはすでにモデルの訓練データに含まれている可能性があるため、データセットには汚染（contamination）グレードが付与されています。`HIGH` または `MEDIUM` と判定されたセット（FLORES+ は `HIGH`）、あるいはグレードが付与されていないセットは**相対比較専用**です。そのセット上で実行された手法同士の比較には使用できますが、絶対的な品質として報告することはできません。`LOW` と判定されたセットのみが絶対的な品質として順位付けされます。隔離されたデータセットは決して順位付けされず、データベースはそれに対して投稿されたスコアを拒絶します。
登録済みデータセットとそのライセンスレーンは、[評価データセット](/docs/network/leaderboard/datasets)に記載されています。

**封印ベンチマーク**は、ホストが自身のマシン上に保持する非公開のテストセットです。参加者がこれを見ることはできません。参加エントリーはモデルまたは手法であり、ホスト自身のスコアリングノードが封印されたセットに対して実行します。出力されるのはスコアのみであり、すべての封印実行にはホストの承認が必要です。セットの鍵は現在、主催者が保持しています。コミュニティの鍵管理者は、現時点では任命されていません。Champollionは鍵のシェアを一切保持しません。賞は封印コンテストでのみ存在し、誰もエントリーする前にホストが宣言した条件に従います。主催方法については、[主権コンテストの実施](/docs/network/sovereignty/run-a-sovereign-contest)をご覧ください。

## 対象範囲

- **書面テキスト：** ボードは書面テキストの翻訳を測定します。文書、教育資料、公式資料、UI文字列などが対象です。音声、リアルタイム通訳、自由形式のチャットは測定しません。
- **テキストベースの言語：** 手話の機械翻訳は性質が異なる課題です。インデックス内の手話のエントリには「未対応」と表示されます（[言語の定義について](/docs/network/context/what-counts-as-a-language)）。
- **1回につき1つのデータセット：** スコアは、同一データセットのバージョンにおけるスコアとのみ比較可能です。異なるデータセットや言語をまたいで順位を比較することはありません。
- **文ではなく手法：** スコアはベンチマークにおける手法の性能を表します。いかなる翻訳についても、文ごとの信頼度は公開されません（[技術的な制限](/docs/network/honest-limitations#system-vs-output)）。

## 公開される実行結果の内容

すべての新しいカードは **scoring standard/1** に従ってスコア測定されます（[スコア測定仕様](/docs/network/specifications/scoring)）。

- **メイン指標：** コーパスレベルの chrF++（0–100）。95%ブートストラップ信頼区間と sacreBLEU シグネチャが付き、誰でも再計算できます。
- **補助指標：** BLEU、spBLEU、TER、および算出されている場合は COMET。これらはメイン指標とは分けて表示され、メイン指標に混ざることはありません。
- **個別診断項目：** FST 受理や完全一致など、対応ツールが存在する場合の診断値。これらがメイン指標に入ったり、実行結果の順位に影響したりすることはありません。
- **廃止されたフィールド：** `composite`、`quality_tier`、`cost_adjusted` は、すべての新しいカードで `null` となります。古いカードでは保存された複合スコアが保持され、「legacy composite (retired)」と表示されます。自動スコアに品質ラベルが付くことはありません。
- **出所情報：** データセットIDとそのSHA-256、正確なモデルスラッグ、実行条件、モデルに与えられた指示（プロンプトのSHA-256、および伏字化されていない場合はそのテキスト）、コスト、ハーネスのバージョン、設定のフィンガープリント。同一の実行は公開時に重複排除され、独立した再現実験は検証結果としてカウントされます。
- **信頼ティア：** すべての行は最初に*自己ベンチマーク（self-benchmarked）*として届きます。*Champollion Verified* は、提出された出力から固定参照訳に対してスコアが再算出されたことを意味します。この再スコア測定はメンテナが手動で実行するコマンドであるため、現時点では登録時に自動で昇格される行はありません。*Community Validated* は、コミュニティ自身のレビューによってのみ付与されます（[検証ティア](/docs/network/leaderboard/rules#verification-tiers)）。

完全なスキーマは[実行カード仕様](/docs/network/specifications/run-card)に記載されています。

## 公開

```bash
# See exactly what would be uploaded (no sign-in, no network)
mt-eval publish eval/logs/harness/<run-id>_report.json --dry-run

# Publish to the live board (a browser sign-in the first time)
mt-eval publish eval/logs/harness/<run-id>_report.json --prod
```

- 本番ボードへの書き込みには `--prod`（または `MT_EVAL_ALLOW_PROD=1`）が必要です。これがない場合、ハーネスは書き込みを拒否します。
- `--anonymous` はサインインせずに公開します。ボード上には「anonymous」と表示されます。
- `--scores-only` は集計スコアとデータセットのハッシュおよびサイズを公開しますが、ソーステキストや参照テキストは公開しません（独自コーパスや非公開コーパス向け）。
- `--redact-coaching` はプロンプトのテキストをマーカーに置き換え、そのハッシュのみを保持します。ローカル専用コーパスの指導付きプロンプトはデフォルトで伏字化されます。

ステップ別の手順ガイドは[手法の提出](/docs/network/getting-started/submit-a-method)をご覧ください。

## 全体に適用される共通ルール

- **評価データでの訓練は禁止：** 訓練データ、few-shotの例、辞書エントリ、プロンプトの素材などとしてベンチマークセットに触れた手法は失格となります（[提出ルール](/docs/network/leaderboard/rules)）。
- **優劣は2つの数値ではなく検定で判断：** ある実行が別の実行を上回っているかどうかは、chrF++ の対応のある有意差検定によって判断されます。検定で差が認められない近接する結果は同順位となります（[有意差](/docs/network/specifications/significance)）。
- **コーパスはここではホストしない：** 登録されるのはメタデータのみであり、コーパスは提供元から取得されます。オープンライセンスのセットで公開された実行結果には、文ごとのテキストが含まれる場合があります（上述）。
- **ライセンスレーンは構造的に分離：** 非商用コーパスは、すべての賞、API、商用利用の経路から除外されます。改変されたライセンス、特注のライセンス、またはライセンス未明記（`LicenseRef-*`）のコーパスは、権利者の同意がカードに記録されるまでリモートのモデルAPI評価を拒絶します。標準的な非商用ライセンスは、学習不使用チャンネル経由でのみリモートモデルに送信されます。封印セグメントが外部のリモートに送信されることはありません。EdTeKLA Plains Cree セットは隔離ラベルとしてカタログ化されており、データベースはこれに対して投稿されたいかなるスコアも拒絶します。

## 現在の稼働状況

- ボードは稼働中であり、公開されており、提出を受け付けています。その内容はライブデータであるため、このページには記載していません。[ボードをご覧ください](/leaderboard)。
- 現在のすべての行は自己ベンチマークです（上記の信頼ティアを参照）。
- 開催中の賞金コンテストはなく、賞の基準を満たしたスコアもありません（[賞の仕様](/docs/network/specifications/prizes)）。
- コミュニティの話者によるレビューは実施されていません（[話者による検証](/docs/network/specifications/speaker-validation)）。
- コンテストの条件に基づいてコミュニティに渡された手法はありません。

何が保証されないかの完全なリストは[技術的な制限](/docs/network/honest-limitations)に記載されています。このページと該当ページの内容に相違がある場合は、該当ページの内容が優先されます。
