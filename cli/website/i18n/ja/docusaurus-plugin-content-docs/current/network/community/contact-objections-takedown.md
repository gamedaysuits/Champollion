# 連絡先、異議申し立て、および削除要請

> **概要:** このプロジェクトは意図的に未完成であり、永遠に進行中の作業（ワークインプログレス）です。もしここにある内容が間違っていたり、搾取的であったり、コミュニティの権利を軽視していたり、あるいは単に説明が不十分であったりする場合は、ぜひお知らせください。私たちはそれに対応します。このページでは、私たちへの連絡方法、私たちのコミットメント、そして修正や削除を依頼する方法について説明します。適切な異議申し立ては、このプロジェクトをより良くするものです。私たちはそれを単に容認するのではなく、歓迎します。

## 対象者

- **言語コミュニティおよびその代表者**: ここに記載されている自分たちの言語、データ、またはガバナンスについて、修正、削除、または対話を希望する方。
- **研究者、翻訳者、およびデータセットの管理者**: 自身の著作物が引用されており、帰属の修正やリストの変更を希望する方。
- **すべての方**: 誤り、誇大主張、または無礼に感じられる文章を発見した方。

アカウントは不要であり、技術的な知識も必要ありません。ご自身の言葉による平易な表現で全く問題ありません。

## 私たちの立ち位置（およびそれが修正に意味するもの）

Champollionは**インデックスであり、権威ではありません。** 言語カードやNetwork上のすべての事実は情報源を引用し、その情報源が実際に述べていることを報告しています。情報源の間で意見の相違がある場合、勝者を決めるのではなく、すべてを提示します。この設計は、皆様に直接的な結果をもたらします。つまり、**引用された情報源が間違っている場合、または私たちの表現が不適切な場合、それは修正可能な欠陥であり、私たちはそのように扱います。** 私たちは自分たち自身の主張を擁護しているわけではありません。他者の著作物や言語そのものを正確に示そうとしているのです。

私たちの主権に対する姿勢は**sovereignty-aspirant（主権の実現を目指すもの）**です。コミュニティが自らのデータおよびそこから派生するあらゆるものに対して、所有（ownership）、管理（control）、アクセス（access）、および保持（possession）を行使*できる*ように設計されています。それが*達成されている*かどうかを判断するのはコミュニティであり、まさにそのためにこの窓口が存在しています。

## 連絡方法

| 目的 | 使用する方法 | 連絡先 |
|---|---|---|
| 質問、異議申し立て、または修正の依頼 | **サイトガイドのチケットフォーム**（チャットパネル → 「Send a message」）、またはメール | `info@champollion.dev` |
| データ、引用、またはリストの**削除**要請 | チケットフォーム（**Takedown**を選択）、または件名に「Takedown」と記載したメール | `info@champollion.dev` |
| **セキュリティの脆弱性**の報告 | メール | `security@champollion.dev` |

チケットフォームとメールアドレスは同じ宛先に届きます。フォームは、送信中に何も失われないようにメッセージを確実に記録するだけのものです。回答をご希望の場合は返信先アドレスを残すことができ、そうでない場合は匿名のままにすることもできます。

## 私たちのコミットメント

1. **受領の確認:** 連絡先を残していただいた場合、法的な言い逃れをせず、平易な言葉で迅速にメッセージを受領したことを確認するよう努めます。
2. **削除要請を優先し、原則として対応します:** 権利者やコミュニティから削除を求められた、私たちがホストまたはインデックスしているあらゆるものについて、私たちの基本的な姿勢は議論ではなく削除です。そもそも私たちは**コーパスのコンテンツを一切ホストしていません**（コーパスはメタデータカードのみを使用してソースから取得されます）。そのため、ほとんどの「削除」は引用、リスト、またはカードのフィールドであり、これらは迅速に修正または取り下げることができます。
3. **同意なしに、コミュニティ、国家、または組織をパートナーや管理者として名前を挙げることは決してありません:** 同意なしにあなたのコミュニティにそのような名前が付けられているのを発見した場合は、お知らせください。削除いたします。
4. **異議申し立てを誠実に記録します:** 批判は称賛と同様に公開されるべきものです。私たちのhonest-limitations（誠実な制限）ページは、未解決の問題を隠すのではなく、可視化するためにまさに存在しています。
5. **意見の相違が解決したふりはしません:** ご要望にお応えできない場合は、黙殺するのではなく、その旨、理由、そして誰が決定するのかをお伝えします。

## 迅速な対応のために役立つこと

これらは必須ではありませんが、対応を早めるのに役立ちます。

- 特定のページ、カード、または値へのリンク。
- 何が間違っているのか、そしてどうあるべきかについての、ご自身の言葉による説明。
- ご自身を代表して発言しているのか、それともコミュニティや組織を代表しているのか（また、削除の場合は権利者との関係。証明は求めませんが、優先順位を付けるのに役立ちます）。

## この窓口の対象外となるもの

- 開発のサポート、カスタムスクリプト、またはオンデマンドの翻訳を依頼する場所では**ありません**。プロジェクトとしてツールを紹介することはできますが、ここを訪れた方のためにエンジニアリング作業を行うことはありません。
- 言語のランク付け、プロモーション、またはフィーチャーを依頼する手段では**ありません**。Networkのランキングは評価の実行からのみ得られるものであり、リクエストによるものではありません。

私たちは、異議が正当であるにもかかわらず語られないままになるよりも、早期に異議をお聞きしたいと心から願っています。このプロジェクトを誠実なものに保つためのご協力に感謝いたします。
