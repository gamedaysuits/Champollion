# 言語コミュニティの方へ

> **エグゼクティブサマリー** コミュニティは、あらゆる翻訳手法の評価基準となる「正解キー」としての独自のテストセットを所有し、データを外部に引き渡すことなく、独自の条件で独自のコンテストを実施できます。このページでは、Networkが言語コミュニティにお願いしたいこと（参照訳、翻訳レビュー、コーチングデータ）、その対価として得られるもの（資金確保後の公開レートに基づく有償作業（現時点では資金は保持されていません）、コードの所有権、完全なデプロイ制御権）、そして最優先される主権保護について説明します。プログラミングの知識は不要です。保護措置の一部はソフトウェアやデータベースに組み込まれています。その他の保護措置は現時点では公約の段階であり、[率直な制限事項](/docs/network/honest-limitations)でその内訳を明記しています。

Networkへの貢献にプログラマーである必要はありません。先住民言語や低リソース言語を話す方こそ、このエコシステムで最も重要な存在です。

---

## 主権が最優先

何かをお願いする前に、基本ルールをお伝えします。**言語データはあなたのコミュニティのものです。** 言語データは*生体データ（biodata）*です。コミュニティのアイデンティティや関係性を内包しており、本質的に匿名化することはできません。したがって、それを提供する人々がデータそのものや、それと照合して評価されるすべてのものに対する鍵を保持します。Networkは[先住民族のデータ主権原則](/docs/network/sovereignty/data-sovereignty)に基づいて構築されています。

- 私たちはあなたの言語データをサーバーで収集・保存することはありません
- 翻訳手法は`api`アーキテクチャを使用しており、すべてのコーチングデータ、辞書、文法規則はあなたが管理するインフラ上に保持されます
- あなたの言語に対して手法を開発できる人を決めるのはあなたです
- リーダーボードのスコアは手法が機能することを証明するものであり、デプロイの許可を与えるものではありません

:::note[現状について]
以下に説明するオーナーシップ移転モデルは、**確定済みの設計であり、まだ稼働中のプログラムではありません。** リーダーボードは申請を受け付けており、現時点では公開済みの実行結果はなく、コミュニティへの移転も行われていません。このモデルがどのように機能するよう設計されているかをここで説明するのは、皆さんが私たちにその実現を求めるためであり、すでに動き出していることを示唆するものではありません。関係性と、皆さん自身のデータに対する権限が最優先です。それ以外はすべて、そこから生まれます。
:::

## テストセットを所有する

このシステムにおいてコミュニティが持てる最も強力な立場は、**ベンチマーク自体を所有すること**です。テストセットは答え合わせの基準です。それを持つ者が、その言語における「良い翻訳」の意味を決め、私たちの手法であれ、企業の手法であれ、誰の手法であれ、すべてが*あなたの*基準で評価されます。

- **登録はメタデータであり、コンテンツではありません。** コーパスをNetworkに登録するとは、説明カードを公開することを意味し、コーパスをアップロードすることではありません。[公開レーン](/docs/network/sovereignty/registering-corpora)はオープン、ゲート付き、完全主権型の中から選択できます。
- **主権型ベンチマークは非公開のままです。** 主権型レーンでは、テストセットはコミュニティのインフラ外に出ることはなく、私たちが見ることもありません。手法はあなたの側でスコアリングされ、スコアのみが送信されます。
- **独自のコンテストを運営できます。** ステップバイステップのランブック — [主権型コンテストの運営](/docs/network/sovereignty/run-a-sovereign-contest) — では、あなた自身のテストセット、ルール、公開内容（もしあれば）の決定など、コミュニティが主導する評価を独自の条件で開催する方法を説明しています。

これらすべての背後にある保証は、暗黙のものではなく、明確に文書化されています。
[データスチュワードシップ](/docs/network/sovereignty/data-sovereignty)（データ主権／CARE原則に基づく立場と、当プロジェクトに禁止される事項）および
[所有権と利用規約](/docs/network/sovereignty/ownership-transfer)（ある手法が勝利した際に契約上何が起こるか）。

## 私たちが必要としていること

### 参照翻訳

評価のために、精選された翻訳ペアが必要です。片側に英語、もう片側にあなたの言語を配置したものです。これらはすべての翻訳手法を評価するための「答え合わせの基準」となります。

作成に使用できる素材の例：
- **教育資料** — 教科書の演習、授業計画、ワークシート
- **コミュニティ文書** — 会議の議事録、ニュースレター、お知らせ
- **日常的なフレーズ** — UI文字列、アプリのラベル、よく使う表現
- **文化的コンテンツ** — 物語、歌、または説明文（適切な許可を得たもの）

フォーマットはシンプルなJSONです：
```json
{
  "entries": [
    { "id": 1, "source": "Hello", "reference": "tânisi" },
    { "id": 2, "source": "Thank you", "reference": "kinanâskomitin" }
  ]
}
```

### 翻訳レビュー

機能する翻訳を生成すると主張するすべての手法には、人間による検証が必要です。バイリンガルの話者が出力結果をレビューし、コンピューターが正しく翻訳できたかどうか、そしてより重要なこととして、*なぜ*誤ったのかを教えてください。

### コーチングデータ

文法規則、辞書エントリ、形態論的パターン — これらは翻訳手法を機能させる言語リソースです。あなたの言語がどのように機能するかについての知識は、いかなるAIモデルにも代替できないものです。

## あなたが得られるもの

### 所有権

あなたの言語のための翻訳手法が構築され、Networkで検証されると、[所有権はコミュニティのガバナンス組織に移転されます](/docs/network/sovereignty/ownership-transfer)。コード、モデルの重み、デプロイはすべてあなたのものになります。

### 搾取ではなく、有償の作業

コーパスの構築と翻訳レビューは専門的な作業であり、資金が確保され次第、
[公開レート](/docs/network/perspectives/how-speakers-get-paid)に従って支払われます
（現時点では資金は保持されていません）。また、支払いによってあなたのデータが買い取られることはありません。作業に対する報酬が支払われるとともに、構築した成果物の所有権は*引き続き*
あなたのコミュニティに帰属します。Champollionは非営利の研究プロジェクトです。製品を販売することも、従量課金を行うこともなく、コミュニティが所有する手法から得られた収益から[一切の取り分を受け取りません](/docs/network/sovereignty/economic-model)。

### 制御

あなたのガバナンス組織が以下を管理します：
- 手法にアクセスできる人
- 商業的に使用できるかどうか — 使用できる場合は、あなたの条件で、得られた収益をすべて保持
- いつ、どのように更新するか
- さらなる開発に使用するデータ

## 参加するには

:::tip[話者が今日からできること — コミュニティの合意がある場合]
Champollionはコーパスの構築やホスティングを行いません。テストデータは常に元のソースから取得されます。コミュニティの話者が*今すぐ*文を寄贈したい場合、[Tatoeba](https://tatoeba.org)ではあらゆる言語での文単位の寄贈を受け付けており、[OPUS](https://opus.nlpl.eu/)のようなオープンなコレクションでは、Networkがベンチマークを構築する元となる並行テキストを集約しています。それらに追加された文は、ここでの評価データとして活用できます。

トレードオフを事前に把握してください。Tatoebaはオープンライセンス（デフォルトではCC BY 2.0 FR）の下で文を公開しているため、AIモデルの学習用を含め、誰でも複製することができ、すでに作成された複製を取り消すことはできません。日常的な文脈の文であれば、それが適切な選択肢となる場合があります。コミュニティが自身の管理下に留めておきたいものについては、データを手元に保管し、代わりに[非公開テストセット](/docs/network/sovereignty/run-a-sovereign-contest)を使用してください。
話者による直接寄贈アプリやコーパスビルダーは計画中ですが、まだ構築されていません。
:::

1. **お問い合わせ** — [Networkリポジトリ](https://github.com/gamedaysuits/Champollion)でIssueを開くか、[info@champollion.dev](mailto:info@champollion.dev)までメールでお問い合わせください
2. **言語についての説明** — どの語族に属していますか？ 話者数は何人ですか？ どの表記体系が使われていますか？ どのような計算言語リソース（FST、辞書、コーパスなど）が存在しますか？
3. **小さく始める** — 厳選された50組の翻訳ペアがあるだけでも、評価用データセットを作成し、新しいリーダーボードトラックを開設するのに十分です。コーパスの作業は、資金が確保され次第、[公開レートで支払われます](/docs/network/perspectives/how-speakers-get-paid)（現時点では資金は保持されていません）
4. **主権を維持する** — 選択したレーンにメタデータとしてコーパスを登録します（[コーパスの登録](/docs/network/sovereignty/registering-corpora)）。テストセットを完全非公開にしたい場合は、[主権的コンテスト運用手順書](/docs/network/sovereignty/run-a-sovereign-contest)の手順に従ってください
5. **ガバナンスとの連携** — コミュニティ内で言語データや技術に関する権限を持っているのは誰ですか？ Networkの主権モデルには、ガバナンスパートナーが必要です
