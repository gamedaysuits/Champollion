# 接続強度

ネットワークマップが2つの言語間にアーク（弧）を描くとき、その色は1つの問いに答えています。**このペアは実際に測定されたことがあるか？**

これは、以前マップが示していた内容よりも意図的に限定されたものです。2026年9月4日までは、アークは5段階の強度グラデーション（チャンス補正スケール上で最良の翻訳がどれほど*優れている*か）によって色分けされていました。そのグラデーションは廃止されました。このページでは、その背景にあった数値、廃止することが誠実な判断であった理由、そして現在マップが何を示しているかについて説明します。

## 問題：生スコアはゼロ点でゼロにならない

スコアの大部分は **chrF++**（文字 n-gram F スコア、[Popović 2017](https://aclanthology.org/W17-4770/)）です。これは翻訳の文字・単語が参照訳とどれだけ一致するかを 0 から 100 で測定します。

しかし、*ランダムなテキストはゼロにはなりません*。どの文字体系でも、ある程度の一致が「無条件に」生じます。固有文字の少ない正書法や、予測しやすい長い単語を持つ言語では、「翻訳」がでたらめな内容であっても、計測上ゼロを明確に上回るスコアが出ます。この無条件の一致——**偶然フロア**——は言語によって異なり、私たちの計測では約 1.6（中国語系文字）から 13 超（一部のラテン文字・アラビア文字系言語）の範囲に及びます。生の chrF++ が 14 であれば、ある言語ではほぼランダムなノイズであり、別の言語では実質的なシグナルです。そのため、生の chrF++ は**言語をまたいで比較できず**、それを色に使ったマップは一部の文字体系を密かに過大評価することになります。

この問題は現実に存在しており、マップが言語間の強度をランク付け**しない**理由でもあります。これは私たちが解決できた問題ではありません。

## 私たちが構築した補正と、それがマップの色分けに使われなくなった理由

**チャンス補正済みchrF++（cchrF++: Chance-corrected chrF++）**は、*その言語において*0が「偶然（当てずっぽう）と同等」、1が「完全」を意味するようにスコアをリスケールします。

```
cchrF++ = (chrF++ − floor) / (100 − floor)
```

ベースラインとなるフロア（下限値）は想定値ではなく実測値です。言語ごとに、公開されている単一言語テキストのみ（ソースから取得し、再配布は一切行わないFLORES-200 dev）を使用してモンテカルロ推定（数千もの同一書記体系によるランダムなベースラインを実際の参照訳と照合してスコアリング）を実行しています。フロアテーブルは196の言語をカバーしており、Champollionから派生した成果物です。

**この補正が真に確立するもの。** チャンスフロアは実在し、書記体系によって約9倍の開きがあり、人間の品質評価ラベルが一切ない単一言語テキストから推定できます。これを差し引くことで、単純なベースラインから偶然による要素が確実に排除されます。例えば、フィンランド語でソースをそのままコピーするチート手法は未補正（raw）スコアでは15以上になりますが、補正後は約2.5まで低下し、多くの言語では完全にゼロになります。ここで取り除かれる「チャンス（偶然）」とは、表面的な統計的偏りであり、残留した意味ではありません。

**この補正が確立しないもの。** これにより**0**はすべての言語で同じ意味を持つようになりますが、**40**が同じ意味を持つようになるわけではありません。フロアより上では、補正は単純なリスケーリング（線形変換）にすぎず、言語間で等しい*品質*が等しい補正スコアに対応するという証拠は、スコア範囲の最下端でのみ実証されているにすぎません。人間の評価データ群と照合した場合、フロアが真に異なる言語間では有効ですが、そうでない言語間では効果がなく、さらにフロアが一様に低いデータ群の1つでは、人間の評価者との一致度を*好ましくない*方向へ動かしてしまいました。これは私たちがまだ解決できていない結果です。

5段階の強度グラデーションで公開マップを色分けすることは、エビデンスが裏付ける以上の主張をしており、それも誤りが最も重大な問題となるまさに低リソース言語においてそうでした。そのため、今後の研究によってこの問題が解決されるまで、グラデーションは廃止されました。

なお、代わりに**未補正（raw）**のchrF++で色分けすることは、最初から選択肢にありませんでした。生スコアは言語間でまったく比較できず、それこそがそもそもこの補正を構築した理由だからです。バイナリ（測定済みか否か）によるエンコーディングは誠実な代替策であり、より劣ったものへのダウングレードではありません。

## 測定がヒエラルキーのどこに位置づけられるか

信頼性の高い順：

1. **人間による検証** — 流暢な話者による出力の判定（[話者による検証](/docs/network/specifications/speaker-validation)）。自動評価がこれに勝ることはありません。
2. **MQM方式のエキスパートアノテーション**（[Multidimensional Quality
   Metrics](https://aclanthology.org/2014.tc-1.6/)、Lommelら） — WMTがゴールドスタンダード判定に使用しているプロトコル。高コストで希少ですが、極めて優れています。
3. **自動スコア（同一言語ペア内のみ）** — 生のchrF++、BLEU、COMETなどは、*同一*ペア上でのシステム比較に有用です。対象のペアにおいて各指標が人間の判断とどれほど乖離しうるかについては、[指標の信頼性](/docs/network/specifications/metric-reliability)を参照してください。
4. **言語をまたいだ強度** — ランキングは公開していません。上記を参照してください。

人間による検証済みおよび MQM グレードの結果がボードに追加されると、同じペアの自動スコアより優先されます。

## マップでの表示方法

各視覚チャンネルはそれぞれ一つの意味を持ちます。

| チャンネル | 意味 |
|---------|---------|
| **色** | 測定済み。単色、グラデーションなし — アークはある実行によってこのペアがスコアリングされたことのみを示し、その質の高さについては何も示しません |
| **破線 + 薄暗い表示** | 暫定：テストセットが[有意性フロア](/docs/network/specifications/significance)（n &lt; 100）を下回っており、約5 chrF++以内のスコア差はノイズとなります。これは指標に依存しないサンプルサイズ自体の特性です |
| **幅** | 一定。他にエンコードすべき情報はありません |

**測定済み**のペアのみが測定済みアークを描きます。登録済みペア（測定キューに入っているがまだスコアリングされていないもの）は、淡い単色のヘアライン（極細線）として表示され、その色は*そのペアが現在どのように到達可能か*（商用API · オープンソースモデル · フロンティア、プロバイダーなし）を示すだけであり、翻訳の品質を示すことは決してありません。この2つの表現体系は意図的に明確に区別されています。トーンを抑えた単色の線＝到達可能性、単一の測定済みカラー＝測定済み。
アークの基礎となるスコアは、公開ボードにおけるそのペアの最良の測定実行結果であり、新しい実行結果が追加されるたびに自動的に更新され、アークを開いたときにペア内数値として表示されます（言語横断のランクとして表示されることは決してありません）。

## 補足事項

- チャンスフロアは、単一言語テキストのみから推定された指標×正書法（書記体系）の特性であり、対訳コーパスのコンテンツは一切関与せず、保存もされません。
- フロアアトラスと補正は公開された研究成果として残り、コードもテスト対象としてリポジトリに残されています。ただし、公開されている画面やUIには一切接続されていません。
- **補正されるのはフロア（下限）であり、シーリング（上限）ではありません。** 真に優れた翻訳がどこまで高いスコアを取れるかは言語によって依然として異なり、この補正はその点については何も解決しません。
- **同一文字体系のコピーに対する防御にはなりません。** ソースとターゲットが同じ書記体系を共有している場合、ソースを単にコピーしただけの出力でもチャンスフロアを上回るスコアを獲得してしまうことがあります。
- **単一言語ペア内でのシステムの順序を並べ替えることはできません。** フロアより上では補正は単純なリスケーリングであるため、ペア内のランキングは補正の前後で同一となります。したがって、その唯一の潜在的な価値は言語ペア間をまたいだ比較にありました。
- 測定済みアークは、ペアがスコアリングされたことのみを示します。意味、レジスター（言葉遣い・語調）、または文化的な適合性を検証するものでは**ありません**。それらは依然として人間による判断事項です（[率直な制限事項](/docs/network/honest-limitations)）。
- チャンスフロアの手法はChampollion独自の研究であり、検証や批判的検討を受けられるよう、まさにそのためにここで公開されています。
