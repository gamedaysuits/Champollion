# 接続強度

ネットワークマップが2つの言語の間に弧を描くとき、その色は一つの問いに答えています。**その言語間で計測された最良の翻訳は、正直なところ、どれほど優れているのか？**

「正直なところ」という部分は、聞こえるよりも難しい問題です。このページでは、色の背後にある数値をわかりやすく説明します。

## 問題：生スコアはゼロ点でゼロにならない

スコアの大部分は **chrF++**（文字 n-gram F スコア、[Popović 2017](https://aclanthology.org/W17-4770/)）です。これは翻訳の文字・単語が参照訳とどれだけ一致するかを 0 から 100 で測定します。

しかし、*ランダムなテキストはゼロにはなりません*。どの文字体系でも、ある程度の一致が「無条件に」生じます。固有文字の少ない正書法や、予測しやすい長い単語を持つ言語では、「翻訳」がでたらめな内容であっても、計測上ゼロを明確に上回るスコアが出ます。この無条件の一致——**偶然フロア**——は言語によって異なり、私たちの計測では約 1.6（中国語系文字）から 13 超（一部のラテン文字・アラビア文字系言語）の範囲に及びます。生の chrF++ が 14 であれば、ある言語ではほぼランダムなノイズであり、別の言語では実質的なシグナルです。そのため、生の chrF++ は**言語をまたいで比較できず**、それを色に使ったマップは一部の文字体系を密かに過大評価することになります。

## 解決策：フロアを差し引く

**偶然補正 chrF++（cchrF++）** は、0 が「その言語において偶然と同程度」、1 が完璧を意味するようにスコアを再スケーリングします。

```
cchrF++ = (chrF++ − floor) / (100 − floor)
```

フロアは仮定ではなく実測値です。各言語について、モンテカルロ推定を実行します——同じ正書法のランダムなベースラインを何千通りも生成し、実際の参照訳に対してスコアを算出します——使用するのは公開されている単言語テキスト（FLORES-200 dev、ソースから取得、再配布なし）のみです。フロアテーブルは現在 196 言語をカバーしており、Champollion 由来の成果物です（`champollion-derived` 出所；`cli/website/scripts/build-cchrf-floors.mjs` により再生成）。

補正を誠実に保つために、2 つの保守的なルールを設けています。

- **補正は両側のフロアが計測済みの場合にのみ適用されます。** どちらか一方が不明な場合、弧はニュートラルなスレートカラーで表示されます——*計測済み、フロア不明*——色のランプには乗りません。
- **ペアには2つのフロアのうち高い方を使用します。** 補正は強度を過小評価することはあっても、過大評価することはありません。

## 階層における cchrF++ の位置づけ

cchrF++ は最良の*自動*強度指標ですが、階層の最上位ではありません。信頼性の高い順に並べると：

1. **人間による検証** — 流暢な話者が出力を評価する（[話者検証](/docs/network/specifications/speaker-validation)）。自動指標がこれを上回ることはありません。
2. **MQM スタイルの専門家アノテーション**（[Multidimensional Quality Metrics](https://aclanthology.org/2014.tc-1.6/)、Lommel ら）— WMT がゴールド判定に使用するプロトコル。コストが高く、希少ですが、非常に優れています。
3. **cchrF++** — 偶然補正済み、言語をまたいで比較可能、どこでも安価に計算できます。
4. **生の chrF++ / BLEU / ニューラル指標** — 単一データセット内では有用。各指標がそのペアの人間判定をどれほど追跡できないかについては、[指標の信頼性](/docs/network/specifications/metric-reliability)を参照してください。

人間による検証済みおよび MQM グレードの結果がボードに追加されると、同じペアの自動スコアより優先されます。

## マップでの表示方法

各視覚チャンネルはそれぞれ一つの意味を持ちます。

| チャンネル | 意味 |
|---------|---------|
| **色** | cchrF++ バンド — 5 段階、赤からソフトグリーン：*フロア付近*（&lt; 0.15）、*弱い*（0.15–0.35）、*発展中*（0.35–0.55）、*実用的*（0.55–0.75）、*強い*（≥ 0.75） |
| **ニュートラルスレート** | 計測済みだが、少なくとも一方の偶然フロアが不明——色のランプには乗りません |
| **破線 + 薄表示** | 暫定：テストセットが[有意性フロア](/docs/network/specifications/significance)を下回っている（n &lt; 100）。この範囲では chrF++ 約 5 以内のスコア差はノイズです |
| **幅** | 色のバンドを繰り返します（アクセシビリティのための冗長性であり、第二の変数ではありません） |

強度ランプに乗るのは**計測済み**のペアのみです。登録済みのペア——計測待ちでまだスコアが出ていないもの——は、淡い単色の細い線として表示されます。その色が示すのは*そのペアが現在どのように到達可能か*（商用 API・オープンソースモデル・フロンティア、プロバイダーなし）のみであり、翻訳の品質ではありません。2 つの語彙は意図的に分離されています。くすんだ単色の細い線 = 到達可能性、赤→緑のランプ = 計測済み強度。弧の基となるスコアは、公開ボード上でそのペアの最良計測結果であり、新しい実行結果が追加されると自動的に更新されます。

## 補足事項

- フロアは単言語テキストのみから推定された指標×正書法の特性です。並列コーパスのコンテンツは一切使用・保存されません。
- cchrF++ は翻訳が偶然を上回っているかどうか、またどの程度上回っているかを示します——意味、文体、文化的適切さを**検証するものではありません**。それらは人間による判断に委ねられます（[誠実な限界](/docs/network/honest-limitations)）。
- 偶然フロアの方法論は Champollion の研究成果です。フロアアトラスと補正手法は、検証・批判を受けられるよう、ここで公開しています。
