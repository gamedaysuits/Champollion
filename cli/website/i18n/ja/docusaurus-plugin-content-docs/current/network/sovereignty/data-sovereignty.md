# データ管理

> **エグゼクティブサマリー** Champollionは機械翻訳の研究開発ツールです。ソースコードが公開されており、非商用利用は無料、その評価ハーネスはオープンソースです。このページでは、言語データに対するChampollionのスタンスを詳細に説明します。コーパスはそれを提供する人々に帰属し、すべてのライセンスとコミュニティの規約は単なる約束ではなく機械的に遵守され、プラットフォームが誰の言語に対しても独自の条件を設定することはありません。

:::info[言語データはバイオデータである]
言語データは**バイオデータ**です。遺伝情報や健康データと同様に、言語はそれを話す人々のアイデンティティ、親族関係、そして人と人とのつながりを担っています。また、ゲノムと同じように、言語データを真の意味で匿名化することはできません。名前を取り除いても、その言語にはその民族が誰であるかが刻み込まれているからです。したがって、コーパスを提供する人々はそのデータの、そしてそのデータをもとに測定されるあらゆるものの、管理権を持っています。以下に述べるすべての内容は、この前提に基づいています。
:::

その前提から、設計が導かれます。Champollion はすべてのコーパス貢献者を**スチュワード**として扱います。コーパスは法的にも、物理的にも、実際的にも貢献者のものであり続け、インフラはそれを*測定可能*にします。

## コミットメント

1. **データを保持しません。** コーパスはハッシュで固定されたメタデータカードとして登録され、評価時にスチュワード自身のホスティングから取得されます。このリポジトリにコピーされることも、私たちのインフラから提供されることもありません。アーカイブをオフラインにすれば、それに対する評価は単純に停止します。[コーパスの登録](/docs/network/sovereignty/registering-corpora)を参照してください。

2. **すべてのライセンスは約束ではなくゲートによって遵守されます。** 非商用および研究専用のコーパスは、ライセンスが許可しない使用から機械的に除外されます。ライセンスを超えてコミュニティが主張する制限は、その出典とともに記録され、同様の方法で遵守されます。この強制はコード・オブ・コンダクトではなく、CI ゲートとデータベーストリガーに実装されています。

3. **条件はスチュワードのものであり、それぞれ異なります。** 言語によって合意内容は異なります。パブリックな CC0 コーパス、研究専用のコミュニティコーパス、主権的なデプロイ要件を持つ非公開テストセットのいずれも、それぞれの条件で参加できます。ここには普遍的な契約も、いかなるものに対するデフォルトの権利主張もありません。[条件フレームワーク](/docs/network/sovereignty/ownership-transfer)を参照してください。

4. **秘密コーパスは例外ではなくアーキテクチャとしてサポートされています。** コミュニティはテストセットを非公開のまま保持し、自身のインフラ上に保管し、Champollion や開発者に公開することなく、それに対してメソッドをスコアリングすることができます。抽出不可能性を保ちながら測定可能にすることは、回避策ではなく設計目標です。

5. **帰属とクレジットはデータとともに移動します。** ビルダーおよび言語学者のクレジットは、コーパスが表示されるすべての場所で必須です。コミュニティが [Local Contexts](https://localcontexts.org/) の TK または BC ラベルを適用している場合、それらを表示し、エンコードされたプロトコルを遵守します。ラベルを掲示しますが、発行することはありません。

6. **貢献者には報酬が支払われます。** コーパスの構築と検証は専門的な作業であり、公開されたレートで報酬が支払われます。[話者への報酬の仕組み](/docs/network/perspectives/how-speakers-get-paid)を参照してください。報酬の支払いはコーパスの購入を意味しません。ビルダーは報酬を受け取り、*かつ*スチュワードであり続けます。

## ライセンスが強制力を持つ仕組み

コミットメント2には具体的な形があり、その全容を説明する価値があります。これは「すべてのライセンスが尊重される」ということが実際にどのように運用されているかを示すものであり、単なる善意の要約ではありません。

**すべてのベンチマークは保留状態で登録されます。** 新しくカタログ化されたテストセットは、デフォルトで隔離されます。インデックスには表示されますが、評価キュー、コンテスト、およびすべてのランキングからは除外されます。取り込み時には、コーパスについて何も推測されません。一見寛容に見えるライセンスであっても、固定されたアップストリームのリビジョンで実際のライセンス条文と照らし合わせて条件が確認されるまでは同様です。

**レビューの判定は機械的であり、判断が難しいケースは保留されたままになります。** 明確に記載された寛容なライセンス（permissive license）は、すべてのレーンでコーパスの利用を許可します。明確に記載された非商用ライセンスは、すべての商用、賞、APIサーフェスから除外された研究レーンでの利用を許可します。そして、明記されていない、変更されている、混在している、または独自のライセンスは、**決して権利者の代わりに解釈されることはありません**。権利者が条件を明示するか、許諾を記録するまで、コーパスはカタログ化されたまま保留され、キュー、コンテスト、ランキングから除外されます。判定結果、その日付、レーン、およびその根拠は、コーパスカードとそのレジストリエントリに機械可読な形で刻印されます。そのため、「なぜこれが実行可能なのか？」という問いには常に引用可能な答えがあり、「なぜ実行できないのか？」という問いにも同様に答えが用意されています。

**モデルへのテキスト送信はデータ転送であり、ゲート制御されます。** モデルを評価するということは、ソースとなる文をモデルに送信することを意味します。つまり、コーパスが外部に出るということであり、これはライセンスごとに管理されます。寛容なライセンスのコーパスは、標準のチャネルを使用できます。明示された非商用ライセンス下のコーパスは、入力データでトレーニングを行わないことが契約上保証されているチャネルのみを経由します。これは「保持しない（no-retention）」という保証ではなく、まさに「トレーニングしない（no-training）」という保証として明記されています。明記されていない、または変更された許諾条件下のコーパスは、同意が記録されるまでリモート評価が完全に拒否されます。また、封印されたコミュニティセットは、管理者のインフラストラクチャから決して外部に出ることはありません。ゲートが拒否した場合、その拒否メッセージにはライセンスレビューの判定結果が引用されます。

**強制力はすべてのクライアントの基盤部分に組み込まれています。** 保留状態は、どのクライアントもバイパスできないデータベーストリガーによって強制されます。ホスティング禁止のルールは、追跡対象のすべてのパスでコーパスコンテンツをスキャンするリポジトリゲートによって強制され、転送ゲートは評価ハーネス自体の内部で実行されます。これらのいずれもが私たちに対して「ノー」と言う可能性があり、それこそが重要なポイントなのです。

## これが該当しないもの

Champollion はデータブローカーでも、翻訳ベンダーでも、商業プラットフォームでもありません。研究ツールです。リーダーボードの高スコアはメソッドが技術的に機能することを証明しますが、翻訳を公開したり、コーパスを再配布したり、コミュニティの意向に反して何かをデプロイしたりするライセンスではありません。それらの決定は常にスチュワードに帰属します。

## この設計を形成したフレームワーク

このアプローチはここで考案されたものではありません。過去20年間の先住民データガバナンスの取り組みに基づき、その恩恵を受けています。

- **ファースト・ネーションズのデータ主権原則** — カナダのファースト・ネーションズは、自らの情報に対するコミュニティによる所有、管理、アクセス、および保持を表明してきました。ここでのスチュワードシップモデルは、これらの主張との互換性を持つよう設計されています。
- **[CARE Principles](https://www.gida-global.org/care)** (Collective Benefit, Authority to Control, Responsibility, Ethics) — Global Indigenous Data Alliance。
- **[Te Mana Raraunga](https://www.temanararaunga.maori.nz/)** — マオリ・データ主権ネットワーク。
- **[Kaitiakitanga License](https://tehiku.nz/)** — Te Hiku Media によるテ・レオ・マオリデータのための後見に基づくライセンス。ここで使用されているスチュワードが鍵を保持するカストディモデルへの直接的な影響源です。

自分たちの言語データのガバナンスを設計する方には、それらの情報源を直接参照することをお勧めします。権威はそちらにあり、私たちにはありません。コミュニティがこれらのフレームワークのいずれかをコーパスに採用した場合、コーパスカードにその主張が記録され、ツールがそれを遵守します。

Champollion は Local Contexts の **"Open to Collaborate" Notice** を表示しています。ここに掲載されている言語を持つコミュニティと関係を構築し、コミュニティが作成したラベルは私たちがそのデータについて述べることよりも優先されます。
