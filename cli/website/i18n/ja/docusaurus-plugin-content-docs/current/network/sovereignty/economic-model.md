# 活動資金について

> **概要。** Champollionは非営利の研究プロジェクトです。
> ソースが公開されており（source-available）、非営利目的では無料で利用でき、評価ハーネスと
> レジストリはオープンソースです。そして現在、**創設者の完全な自己資金によって
> 運営されています**。助成金や
> スポンサー、背後にある機関は（今のところ）ありません。しかし現在、[スポンサーを
> 積極的に募集しています](/get-involved#sponsors)。スポンサーからの資金は
> **100%パススルー（全額還元）**されます。公開されたレートでコーパス構築、ツール開発、コミュニティ活動の
> 資金として使われ、公的に会計報告されます。Champollion自体には一切入りません。
> ここでは何も収益化されていません。有料API、従量課金、レベニュー
> シェアはなく、コミュニティが所有するものに対するプラットフォーム側の権利主張もありません。このページでは、
> 現在の資金源、資金提供によって何が実現できるか、そして最初の部分（資金源）を変えたい場合に
> どのように私たちに連絡すればよいかを明確に説明しています。

Champollionは、機械翻訳の研究開発ツールです。
ソースが公開されており（source-available）、非営利目的では無料で利用できます。CLIはPolyForm
Noncommercial 1.0.0（商用利用には許可が必要）であり、評価
ハーネスはオープンソースのAGPL-3.0、データレジストリはオープンソースの
Apache-2.0です。これらの背後に商用製品はなく、また（今のところ）資金提供も
受けていません。

## 現在の資金源

**一人の人間。** ハーネス、CLI、言語インデックス、ベンチマーク仕様、サイトに至るまで、これまでに構築されたすべては、プロジェクト創設者の自己資金によるものです。これを率直に述べるのには、二つの理由があります：

1. **規模についての正直な説明。** 自己資金のプロジェクトでは、仕様書に記載されたコーパス構築や話者検証にかかる費用をまだ賄えません。公開されたレートは、資金が存在する場合に*どのように*動くかについての約束であり、すでに動いているという証拠ではありません。
2. **これはオープンな招待です。** インフラは構築済みで、単価も公開されています。不足しているのは、それを動かすための資金です。助成機関、財団、学術部門、または個人として言語技術に資金提供をお考えの方は、**ぜひご連絡ください**：[GitHub](https://github.com/gamedaysuits/Champollion) で Issue を開くか、[champollion.dev](https://champollion.dev) からお問い合わせください。

## 資金で何ができるか

コストはすでに仕様化されているため、資金提供者は具体的かつ範囲の明確なものに資金を充てることができます：

- **ある言語のコーパス構築への参加** — 話者への報酬として 2,500〜6,000 ドル（公開レート：時給 50〜65 カナダドル）を支払うことで、構築者の所有物として残るベンチマークコーパスを作成できます。[話者への報酬について](/docs/network/perspectives/how-speakers-get-paid)をご覧ください。
- **メトリクス検証ラウンド** — 1,475〜1,920 ドルで、3 名のバイリンガル話者が自動メトリクスを人間の判断と照合して検証します。
- **スポンサー付き賞** — 特定の目標（例：信頼性の高い英語 → Plains Cree 翻訳）に対して資金を提供します。賞の資金はコミュニティが運営するトラストが保管・授与し、コミュニティの条件に従います — Champollion ではありません。[賞の仕様](/docs/network/specifications/prizes)をご覧ください。
- **コンピューティングおよび API クレジット** — 公開ベンチマークキューの実行に充てるためにプールされます。

実際には、これによりネットワークは言語データ作業のための資金配分の仕組みとして機能します：資金が入り、コーパスを構築する人々への有償の仕事として出ていく — そして彼らは構築したものを所有し続けます。

## 資金の使途

- **公開レートに基づき、コーパス構築者および検証者へ。** 支払いは所有権を移転しません：構築者は作業に対して報酬を受け取り、かつコーパスのスチュワードであり続けます。
- **コミュニティトラストを通じて、賞の受賞者へ。** スポンサー付き賞が受け取られると、トラストが開発者に支払いを行います。その方法は、その賞の条件に従ってコミュニティに移転されます（[所有権と条件](/docs/network/sovereignty/ownership-transfer)を参照）。
- **インフラへ** — ホスティング、評価の実行、およびメンテナンス。
- **公開会計。** スポンサー付きの取り組みは、何に資金が提供されたか、どの公開レートで、何が成果として提供されたかを公開形式で記録します — これにより、スポンサー（およびすべての人）がパススルーの約束が守られたかを確認できます。

## Champollion が受け取るもの

**何もありません。** 収益の分配も、インフラ使用料も、コミュニティの資産への権利主張も存在しません。コミュニティが自ら所有する方法を — 自分たちのサーバーで、自分たちのチャンネルを通じて、商業的かどうかにかかわらず — 展開した場合、そこから得られるすべては自分たちのものです。ネットワークに登録されたコーパスは、評価の前・中・後を問わず、スチュワードの所有物であり続けます。

この活動に関連して商業的な機会が生じた場合、その話し合いには応じる用意があります — ただし、そのような取り決めは、関係するデータや方法を持つスチュワードと、その時点で、彼らの条件に基づいて交渉されます。このドキュメントで事前に約束されていることは何もなく、ここにあるいかなる文書も、プラットフォームのために何らかの取り分を留保するものとして読まれるべきではありません。

## 資金提供者の方へ

言語技術における持続可能性の問いは、通常「助成金が終わった後はどうなるか？」というものです。非商業プロジェクトにとっての正直な答えは：*資産*は資金よりも長く存続する、ということです。なぜなら、それを維持できる人々が所有しているからです。

| 従来のモデル | スチュワードシップモデル |
|---|---|
| 助成金が研究に資金提供 | 助成金が研究に資金提供 |
| 論文が発表される | コーパスが構築され、方法が測定される |
| 助成金終了、ツールは放棄される | コミュニティがコーパスと移転された方法を完全に所有する |
| コミュニティは何も受け取らない | 話者はすべての時間に対して報酬を受け取り、資産は地元に残る |

資金提供者にとっての測定可能な成果：

- スチュワードの管理下で構築・登録されたコーパス
- 言語コミュニティに提供された有償の話者時間
- 測定された方法、および（賞の条件でそう定められている場合）コミュニティの所有権に移転された方法
- 信頼性の高い公開ベンチマークでカバーされた言語ペア

詳細なコストモデルについては、[ベンチマーク仕様](/docs/network/specifications/benchmark)の §10 をご覧ください。
