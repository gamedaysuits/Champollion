# 派生成果物に関するコミットメント

[データスチュワードシップ](/docs/network/sovereignty/data-sovereignty)のスタンスは、*入力（インプット）*を対象としています。コーパスはスチュワード（管理者）の元に留まり、私たちがコミュニティのデータをホストしたり再配布したりすることは決してありません。このページでは、*出力（アウトプット）*、つまり言語データ**から構築される**もの（学習済みモデルとその重み、翻訳メモリ、ファインチューニング、コーチングセット、評価基準、実行成果物など）について説明します。

このコミットメントを一言で表すと、以下のようになります。

> **私たちは、コミュニティのデータから構築されたいかなる言語モデルや言語派生成果物に対しても所有権を主張しませんし、そうするつもりもありません。このプロジェクトの最大の目的は、これらの技術に対する開発レベルおよび所有レベルのコントロールを、話者自身の手に委ねることです。**

Champollionは**インフラストラクチャ**です。道路が、そこを通行する貨物を所有することはありません。

## 具体的な意味

**モデルは、その言語を話す人々に帰属します。** コミュニティのデータでモデルが学習された場合（私たちのツールであれ他のツールであれ）、その重み、ファインチューニング、およびすべての派生物は、私たちの条件ではなくコミュニティの条件に従います。私たちはコピーを取得せず、ライセンスの再発行も行わず、「私たちが学習スクリプトを書いた」ことを、生成されたものに対する所有権の根拠として扱うことはありません。この教訓は仮説ではなく歴史的なものです。言語コミュニティは、外部の組織が彼らの言語を記録、編纂、または学習に使用し、その結果（長老の録音に対する著作権や、スクレイピングされた音声で学習されたモデルなど）を保持するのを何度も目の当たりにしてきました。その一方で、話者自身が自分たちの声を使用するために許可を求めなければなりませんでした。このコミットメントは、そのような失敗の構図を排除するために存在しています。

**平原クリー語（nêhiyawêwin）の取り組みはテストケースであり、その答えはすでに確定しています。** このプロジェクトでクリー語のために構築されたものは、何一つ私たちのものではありません。学習コーパス（権利者の許可を得て使用され、決して再配布されない）、コーチングされたパイプライン、学習済みモデルのいずれもです。この取り組みで作成されたクリー語モデルは、教育機関、長老会議、またはコミュニティ自身が指定する機関など、**認められたコミュニティの権威に対してのみ**、コミュニティ独自の条件の下でリリースされ、他の誰にも提供されません。クリー語モデルが製品として出荷されるようなシナリオは存在しません。クリー語の評価作業も同様に**終始非営利**です。Champollionが維持するのは、せいぜい*汎用的な*評価手法（LYSS標準 — 内包的で形態論を考慮し、失敗を正直に評価するスコアリングの概念）のみです。その標準の**クリー語におけるインスタンス化**（それがエンコードし、検証の対象とする言語知識）は私たちが所有するものではありません。その商業的利用はnêhiyaw言語コミュニティとの協議が完了するまで保留され、コミュニティの条件が適用されます。

**スコアは移動しますが、成果物は移動しません。** リーダーボードは、手法とコーパスを特定した上で、chrF++値、検証率、信頼区間などの*測定値*を公開します。モデル自体、コーパスのコンテンツ、またはスチュワードの条件が許可する範囲を超える出力を公開、ホスト、または要求することは決してありません。コミュニティが自分たちの言語の行を非公開にしたい場合、[登録レーン](/docs/network/sovereignty/registering-corpora)が存在するのはまさにそのためであり、公開の度合いを調整するのは私たちではなくコミュニティです。

## インフラストラクチャが意味するもの：あなたのデータ、あなたのビルド、あなたのキー

「私たちはインフラストラクチャに過ぎない」ということが実際にどのような形をとるのか、3つの具体的な例を挙げます。

1. **コミュニティが独自のコーパスを構築する。** コミュニティは自分たちのマシンでCLIを使用し、コーパスは彼らが配置した場所に保存されます。ベンチマークのために登録することを選択した場合、レジストリには*ポインタとチェックサム*のみが保存されます。これはソースからのフェッチであり、彼らのライセンスの下にあり、彼らの要求に応じてリストから削除可能です。コーパスが私たちのリポジトリやストレージに入ることは決してありません。これは、誰でも検査可能な仕組みによって強制されています。公開リポジトリには、コミュニティのコンテンツをホストすることを単なるマナー違反ではなく、構造的に不可能にするための隔離ゲートとデータベーストリガーが組み込まれています。

2. **コミュニティが独自のモデルを学習する。** 学習スイート（[nmt-forge](https://github.com/gamedaysuits/Champollion)）は彼らのハードウェア上で実行され、チェックポイントと重みはそこにのみ存在します。評価ハーネスがそれをスコアリングし、ボードがスコアを記録します。私たちがモデルを所有することは決してありません。彼らが永久に非公開にしたいと望めば、その通りになります。公開される痕跡はスコアの行のみであり、それも彼らが公開を選択した場合に限られます。

3. **コミュニティが独自のベンチマークを実行する。** [主権コンテスト（sovereign contests）](/docs/network/sovereignty/run-a-sovereign-contest)を使用すると、テストセットはコミュニティが管理するインフラストラクチャ上で封印されたままになります。手法がデータの*元へ*と移動し、集計されたスコアのみが外部に出力されます。コミュニティは、誰がどのような条件で評価できるかを決定し、いつでも中止することができます。

どの場合でも、移動の方向は同じです。機能（ケイパビリティ）はコミュニティに向かって移動し、データとその派生物がコミュニティから離れることはありません。

## 私たちが模範とするフレームワーク

私たちは、コミュニティ自身が構築した先住民のデータガバナンスフレームワークに**インスピレーションを受け、それを目指しています**。私たちがそれらのいずれかに準拠していると自ら判断する立場にはありません。その判断は、それらを策定したコミュニティや機関に委ねられています。私たちにできることは、その方向に向けて設計し、彼らを基準設定者として挙げ、彼らの精神に則ってこのシステムを改善するために、これらの専門家の声に耳を傾け、協力する機会を深く尊重すると明言することです。

- **ファースト・ネーションズのデータ主権原則** — コミュニティ自身の情報に対する所有（ownership）、管理（control）、アクセス（access）、および保持（possession）。まさにこのページがコミュニティの手に委ねることを約束する4つの機能です。
- **先住民データガバナンスのためのCARE原則**（Collective Benefit: 集合的利益、Authority to Control: 管理する権限、Responsibility: 責任、Ethics: 倫理）。Global Indigenous Data Allianceによるもので、純粋な「オープン」データに対する是正レンズとなります。オープンであることは、人々が自身の知識に対する権限を奪われる場合には美徳とはなりません。
- **Te Mana Raraunga**。マオリ・データ主権ネットワークの憲章であり、データを生きたtaonga（宝物）と見なし、それに伴う権利と責任を定めています。
- **Kaitiakitangaライセンス**（Te Hiku Media）。私たちの知る限り、言語技術における派生成果物の主権に関する最も明確な実例です。Te Hikuはマオリ語（te reo Māori）の*データから*、マオリ語の*ために*音声モデルを構築し、モデルがマオリの人々に利益をもたらし、マオリのガバナンスの下に留まるよう、保護者の条件の下でアクセスをライセンスしています。「モデルは話者に帰属する」と私たちが言うとき、Te Hikuはそれが機能することの存在証明となります。
- **Masakhaneの参加型研究モデル**。データソースとしてではなく、共同執筆者および所有者としての話者・研究者によって構築されたアフリカのNLPです。言語技術を構築する*プロセス*自体が機能の移転になり得ることを実証しています。

これらは、異なる法的および文化的立場を持つ異なる人々のための異なるフレームワークです。私たちはそれらを1つのラベルにまとめるのではなく、並べて挙げています。私たちの設計が彼らの精神に及ばない部分がある場合、それは修正すべき欠陥であり、事後分析で発見するよりも、専門家から直接指摘していただきたいと考えています。もしあなたがこの分野で活動しており、私たちの間違いを指摘していただけるなら、**その対話こそが、このプロジェクトが受け取ることができる最も価値のある貢献です。** [Get Involved](/get-involved)からご連絡ください。

## 私たちが所有するもの

明確にするために、Champollionが所有権を*主張する*ものを挙げます。インフラストラクチャのコード（CLI、ハーネス、学習スイート — それぞれ公開されたライセンスの下にあります）、汎用的な評価手法、およびインデックスの*派生測定値*（これらはコミュニティやアップストリームのソースに誤って帰属されることがないよう、正確に`champollion-derived`の出所情報を保持しています）です。これらはツールボックスです。それを使って構築したものは、あなたのものです。
