# カバレッジギャップ：その推定方法

> **エグゼクティブサマリー** Champollionのホームページには、現在生きている人々のうち*10億人以上*が、第一言語への機械翻訳を利用できないと記載されています。このページでは、その表現の背景にある計算式を示し、数値を変動させる2つの判断基準を挙げ、なぜ大きな生の合計値ではなく、保守的な下限値を公開しているのかを説明します。Champollionはインデックス（指標）であり、権威ではありません。ここにあるすべての数値は公開されているビルドから導き出せるものであり、訂正を歓迎します。

## 私たちが実際に問いかけていること

「機械翻訳（MT）がない言語はいくつあるか」ではなく、**「第一言語への機械翻訳を利用できない人は何人いるか」**です。人の第一言語（L1）とは、その人が思考に使い、ニュースを読む際に最も使いたい言語のことです。バイリンガルであっても、この集団から除外されるわけではありません。第一言語がケチュア語であるケチュア語とスペイン語のバイリンガルは、依然としてウェブページを*ケチュア語で*読むことはできません。したがって、対象となる人口は「専用のMTエンジンが提供されていない現存する言語をL1とするすべての人」となります。

## この数値の計算方法

リポジトリにある以下の2つの要素を使用します。

1. **どの現存する言語にMTがあるか。** ビルドでは、追跡対象となっている9つのエンジンの言語リスト（Google、Microsoft、DeepL、LibreTranslate、NLLB-200、OPUS-MT、M2M-100、MADLAD-400、Tilde — `shared/catalogue/method-coverage.json`、各リストには引用元と日付を記載）の和集合と、`data/tc-index.json`にあるISO 639-3の*個別の現存する*言語（`isoType: 'L'`）との積集合をとります。結果：現存する全**7,077**言語のうち、**552の現存する言語がカバーされており、6,525がカバーされていません**（`stats.coverage.dedicatedLiving` / `uncoveredLiving`）。
2. **カバーされていない言語を話す人は何人いるか。** カバーされていない現存する各言語について、その`speakerCount`（言語カードに引用された推定値から抽出）を取得し、合計します。ビルドはこれを`stats.coverageGap`として出力します。カバーされていない全6,525言語の生の合計は、約**29億**（`uncoveredSpeakerSumRaw` ≈ 2,974,871,273）になります。

この29億という数字は**上限に近い**数値であり、私たちはそのことを明確に述べています。

### なぜ生の合計値が正確ではないのか

`speakerCount`は、各情報源の報告内容に応じて、第一言語（L1）話者と合計（L1+L2）話者が混在しており、マルチリンガルの人は複数の言語でカウントされる可能性があります。その証拠に、*すべて*の現存する7,082言語にわたって`speakerCount`を合計すると、約**108億**になります。これは、現在生きている約81億人（国連の世界人口推計）を上回っています。純粋なL1の国勢調査であれば世界人口を超えることはありませんが、この数値は超えているため、このフィールドが純粋なL1のみではないことが証明されています。

## 2つの判断基準（それぞれが数値を変動させます）

**(a) L1のみか、合計数か。** 第一言語話者のみに限定すれば、推定値は下がります。L2話者は、その定義上、別の言語を*持っている*人々だからです。しかし、私たちが引用している情報源では、言語ごとのL1の数値が一律に利用できるわけではないため、数値を捏造しない限り、すべての言語にL1のみのルールを適用することはできません。混在した数を使用することで、推定値は*押し上げられます*。

**(b) 報告された数値がない777のカバーされていない言語。** カバーされていない6,525の現存する言語のうち、**5,748には話者数の記載があり、777にはありません**（`uncoveredWithCount` / `uncoveredNoCount`）。生の合計値がそうしているように、この777を除外すると*過小評価*になります。なぜなら、これらは実際の（測定されていない）話者を持つ実在の言語であり、そのほとんどが小規模で絶滅の危機に瀕しているからです。

したがって、これら2つの誤差は逆の方向を向いています。L1/L2の混在は数値を膨らませ、777言語の末尾部分は数値を縮小させます。

## なぜ「10億人以上」という下限値を報告するのか

妥当な範囲は、**10億**近くの下限から、生の**約29億**までとなります。L2の重複カウントを厳しく割り引き、*さらに*測定されていない777言語の末尾部分をすべて除外したとしても、カバーされていない言語の第一言語人口は余裕で10億人を超えます。このサイトでは、より大きく不正確な数値を大きく取り上げるのではなく、保守的な下限値を報告しています。「10億人以上」という主張は、私たちが厳しい検証に耐えうると最も確信しているものです。

## 何がそれを変え得るか

より正確な推定を行うには、**言語ごとのL1話者数とそれぞれの引用元**が必要です。そうすれば、L1/L2の混在ではなくL1を直接合計でき、現在カウントされていない777言語についても説得力のある推定値を出すことができます。エンジンが言語を追加するにつれて552という数字は上昇し、ギャップは狭まります。また、言語カードにより信頼性の高い情報源に基づく数値が追加されるにつれて、合計値はより正確になります。これは**継続的な推定**であり、ビルドごとに再計算されるものであって、固定された事実ではありません。

## 訂正と議論の歓迎

より良いデータをお持ちの場合、ここでの判断が間違っていると思われる場合、または欠落している777言語の情報源を提供できる場合は、ぜひお知らせください。それがこのプロジェクトの目的です。[github.com/gamedaysuits/Champollion/issues](https://github.com/gamedaysuits/Champollion/issues)でIssueを開くか、[info@champollion.dev](mailto:info@champollion.dev)までメールをお送りください。

## 情報源

- **カバレッジ** — `cli/shared/catalogue/method-coverage.json`（9つのエンジン、各リストには引用元と日付を記載）∩ `cli/website/data/tc-index.json`にあるISO 639-3の個別の現存する言語。`stats.coverage.dedicatedLiving` / `uncoveredLiving`として表示されます。Champollionから派生。
- **話者数の合計** — `tc-index.json`行の`speakerCount`（各言語カードに引用された`speakerEstimates`から取得）。ビルドによって`stats.coverageGap`（`uncoveredSpeakerSumRaw`、`uncoveredWithCount`、`uncoveredNoCount`）に合計されます。Champollionから派生。情報源によってL1/L2が混在しています。
- **世界人口** — 約81億人（国連『世界人口推計』）。話者数の合計に対する妥当性の境界としてのみ使用されます。

## このサイトでの展開

これらの数値は問題の規模を示しています。この問題に対するサイトの回答は、[Champollionとは](/docs/what-is-champollion)から始まります。カバーされている/カバーされていないの分割の背後にある方法論は、[カバレッジのカウント方法](/docs/network/context/coverage-counting)に記載されています。また、境界線の反対側にある（カバーされていない）言語は、次に評価セットを構築できる可能性が最も高い順にランク付けされ、[コーパスウィッシュリスト](https://champollion.dev/corpus-wishlist.json)で公開されています。
