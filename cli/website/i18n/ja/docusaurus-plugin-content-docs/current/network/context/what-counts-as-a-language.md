# ここでは何を「言語」と見なすか？

> **要約。** このネットワークは ISO 639-3 によって言語を分類し、マクロ言語の傘ではなく個別言語を単位としてベンチマークを行います。手話をそれが本来そうであるような自然言語として含め、ISO が認定した人工言語も含めます。プログラミング言語は除外し、分類上の論争については立場を取らずに表示します。このページでは各判断の内容とリーダーボードへの影響を説明します。

何千もの言語にわたる翻訳をベンチマークするプロジェクトは、古くて意外に難しい問いに答えなければなりません。「言語」とは何か、という問いです。「言語」と「方言」の境界が構造的なものであるのと同じくらい社会的・政治的なものでもあることは、言語学者たちが長い間認識してきました。*「言語とは軍隊と海軍を持つ方言のことだ」* という有名な言葉は、イディッシュ語の言語学者 Max Weinreich が 1945 年に広めたものです（彼は自分の講演の聴衆の一人からこの言葉を聞いたと述べています）。この問いを避けることはできないため、私たちの答えとその根拠をここに示します。

---

## 手話は言語です。それだけです。

手話は自然言語です。完全な文法を持ち、子どもが母語として習得し、生きた言語コミュニティを持っています。このことは、William Stokoe が 1960 年にアメリカ手話（ASL）が話し言葉と同種の内部構造を持つことを示して以来、言語学において決着のついた問題であり、その後 60 年にわたる研究（Klima & Bellugi 1979; Sandler & Lillo-Martin 2006）によってさらに深く裏付けられています。ISO 639-3 は手話に個別の言語コードを割り当てており、Glottolog は話し言葉の語族と並んで手話を収録しています。私たちのカタログには 160 以上の手話が含まれており、`modality: signed` というタグが付いています。

その中には危機に瀕した先住民の言語もあります。北米全域でかつて部族間の主要な共通語として使われていた Plains Indian Sign Language（`psd`）は、今日では深刻な危機状態にあります（Davis 2010, *Hand Talk*）。手話の危機は先住民言語の危機であり、このプロジェクトのミッションの範囲内にあります。

**率直なスコープについての注記。** このネットワークは現在、*テキストベース*の機械翻訳をベンチマークしています。映像・空間文法・広く普及した書記形式を持たない言語を扱う手話の機械翻訳は、異なる、そしていまだ大部分が未解決の技術的問題です（Yin et al. 2021, "Including Signed Languages in Natural Language Processing," ACL を参照）。私たちはまだそれに対応していません。カタログ内の手話エントリにはそのことが明記されています。**未対応（not yet served）** であって、**「言語ではない」ということでは決してありません。**

## モダリティは二つあります。書記はその一つではありません。

言語には二つの主要なモダリティがあります。**話し言葉**と**手話**です。書記は第三のモダリティではありません。言語の上に重ねられた技術であり、世界の言語の多くは標準化された書記体系なしに存在しています。そのため、私たちの言語カードでは書記を別途記録しています（その言語が使用する文字体系、あるいは標準化された正書法がないかどうか）。そして正直に記録しています。テキストベースの機械翻訳プラットフォームにとって、ある言語が書かれているかどうかは脚注ではなく重要な情報です。そして書記を持たない言語は、劣った言語ではありません。

## 人工言語は含む。プログラミング言語は除外する。

私たちは ISO 639-3 自身の基準に従います。この規格が人工言語を認定するのは、それが完全な言語であり、人間のコミュニケーションのために設計され、文学を持ち、第二世代のユーザーに受け継がれたコミュニティを持つ場合に限られます。そしてコンピュータのプログラミング言語は明示的に除外されています。母語話者を持つ Esperanto は条件を満たしますが、Python は誰も親から第一言語として習得しないため、条件を満たしません。私たちのカタログには ISO が認定する約 24 の人工言語が含まれており、そのように分類されています。プログラミング言語は含まれていません。

## ベンチマークの単位は個別言語であり、傘カテゴリではありません

ISO 639-3 は*個別言語*と*マクロ言語*を区別しています。マクロ言語とは、`cre`（クリー語）、`ara`（アラビア語）、`zho`（中国語）のように、密接に関連する複数の個別言語をまとめた傘コードです。このネットワークのベンチマーク単位は**個別言語**です。その理由は実務的なものです。翻訳リソースは変種ごとに異なります。Plains Cree（`crk`）向けに構築された形態素解析器は Moose Cree（`crm`）を生成しません。エジプト・アラビア語のコーパスは、モロッコ・アラビア語における手法の品質についてほとんど何も語りません。マクロ言語コードに紐付けられたスコアは、実際には評価されていない変種についての主張になってしまいます。そのため、私たちはそれを行いません。

マクロ言語はカタログ内に**ハブページ**として引き続き表示されます。傘としてのアイデンティティをその個別メンバーに結びつけるナビゲーションであり、両方のレベルのアイデンティティが実在するという ISO 自身の見解を反映しています。個別言語の下には、Glottolog の languoid ツリー（Hammarström & Forkel 2022）から方言および系統情報を表示します。このツリーは語族・言語・方言を一つのナビゲート可能な階層として構造化しています。

**包括的なコードでラベル付けされて届くコーパスについてはどうでしょうか？** 実際のデータの多くはそのような状態です。「ケチュア語」「ペルシャ語」「中国語（簡体字）」として公開されたデータセットなどがこれに該当します。私たちは上流のラベルを、盲目的に従ったり破棄したりする真理ではなく、*解決すべきメタデータ*として扱います。機械的に判断できるケースは、公式のISOテーブルから自動的に解決されます。スクリプトタグは除去され（`cmn-Hans`は簡体字で書かれた標準中国語であり、スクリプトが記録され、言語識別子は`cmn`となります）、廃止されたコードは公式の後継コードに従います。公開元がデータが実際にどの変種であるかを文書化している場合（FLORES+はそのケチュア語レコードをアヤクーチョ・ケチュア語である`quy`とコード化しています）、その解決結果をコーパスのレジストリエントリに*引用文献とともに*記録し、コーパスは実際の個別の言語の下でベンチマークされます。そして、コレクションにどの変種が含まれているか誰も特定できない場合（一部のコミュニティ主導の文コレクションには、意図的に包括的な「アラビア語」バケットが維持されています）、私たちは推測を行いません。コーパスは独自のラベルの下でカタログ化されたままとなり、キューのメタデータで確認できる機械可読な理由とともに作業キューから除外されます。また、それに対する過去のスコアは、誠実にラベル付けされた包括的ノードに関連付けられたままとなり、一度も評価されていない変種に対して密かに帰属させられることは決してありません。すべての解決結果は再導出可能です。固定されたISOテーブル、コーパスごとの解決スタンプ、および引用文献はすべて公開レジストリに含まれて提供されます。

## 権威ある機関の見解が異なる場合は、両方を表示します

ISO 639-3とGlottologは時折、分割や統合の基準が異なることがあり、コミュニティがその双方と意見が一致しないこともあります。私たちはそれらを裁定しません。言語カードには情報源との相違点を表示する*分類ノート*機能が用意されており、名称についてはコミュニティが希望を表明している場合は常にコミュニティの意向に従います。ある変種が「言語」であるかどうかは、結局のところアイデンティティの問題でもあります。そしてアイデンティティの問題はコミュニティ自身に属するものであり、これは私たちが先住民族のデータガバナンスの枠組みから取り入れている原則です。

## 研究の方向性：測定手段としてのベンチマーク

このようなアリーナが副産物のように生み出すものの一つに、言語変種が*運用上*どれほど近いかについての新しい種類のエビデンスがあります。単一の翻訳方法を固定したまま、関連するいくつかの変種において、その話者が満足する品質の出力を提供できるのであれば、それらの変種は実務上クラスターを形成していると言えます。もし個別のコーパスと個別の手法を必要とするのであれば、命名をめぐる政治がどうであれ、それらは運用上明確に異なっています。これは、録音テキストの相互理解可能性テストから自動化された語彙距離の測定に至るまでの古い実証的伝統に似ていますが、実際のデプロイに基づいているという点が異なります。

これは主張としてではなく、研究の方向性として慎重に提示します。手法の転用結果はコーパスサイズ・ドメイン・正書法・学習データの汚染によって交絡しており、クラスタリングは常に特定の手法と品質閾値に相対的なものです。何より重要なのは、このシグナルは言語と方言についての議論に*情報を提供できる*ものですが、コミュニティが自らの言語をどのように認識するかを決して上書きするものではないということです。
