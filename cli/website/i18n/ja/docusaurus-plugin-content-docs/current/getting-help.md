# サポートを受ける

**お困りの場合や、プロジェクトへの支援をご希望ですか？ ぜひお話ししましょう。**
[info@champollion.dev](mailto:info@champollion.dev?subject=Help%20with%20a%20language%20project) までご連絡ください。

翻訳機を作るにあたって、必ずしも私たちの支援を受ける必要はありません。レールは、ご自身や信頼できるAIアシスタントの手だけで最後まで進められるように作られています。ですが、そばに伴走する人がいることで、より早く進んだり、より安心して取り組めたりするプロジェクトもあります。

## どのような支援ができるか

プロジェクトに必要なことに合わせて、ご相談しながら進めます：

- **環境のセットアップ** — コミュニティのご希望に沿った形で、お使いのコンピューターに設定します。
- **データの整理** — 散らばっているファイルをまとめたり、つづりの表記体系を選んだり、テスト用の適切な文を取り分けたりします。
- **教育とトレーニング** — 私たちがいなくなっても自力で続けられるよう、チームにレールの仕組みをお伝えします。
- **一緒につくる** — 皆さんの指示のもとで、技術的な作業の一部を担当します。
- **運用の代行** — コミュニティからの要望があり、それを希望された場合にのみ行います。

決まった料金表はありません。それぞれのコミュニティが必要としていることに合わせて、最適な形をご一緒に考えます。

## 私たちについて

Champollionは先住民族によるプロジェクトではありません。私たちは支援の立場で、必ず同意に基づいた関わり方のみを行います。言語やデータ、そしてそこから作られるすべての成果物をどう扱うかは、コミュニティ自身が決めることです。コミュニティが自らの言語から得る利益について、私たちが取り分を受け取ることは一切ありません。

## その他のサポート方法

- **[プロジェクトに参加する](/docs/join-a-project)** — プロジェクトを掲載することで、他の人たちから例文や単語リスト、手法などの提供を受けられるようになります。
- **お使いのAIアシスタント** — どの手順についても説明してくれます。「*なぜこの手順が重要なのですか？*」と尋ねれば、レールに書かれている内容を教えてくれます。
