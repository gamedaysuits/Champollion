**Champollion**という名前は、1822年にエジプトのヒエログリフを解読し、ひとつの文字体系を再び世界に読み解かせたジャン＝フランソワ・シャンポリオンに由来しています。私たちが借りるのはその比喩です——意味へのアクセスを回復すること、そして言語をその言語自身の文脈で読むこと。

この名前を使う以上、その歴史から目を背けることはできません。

Champollionは植民地主義的な事業の中で活動していました。彼の
ブレイクスルーを可能にしたロゼッタ・ストーンは、軍事的な略奪品として
ヨーロッパにもたらされ、現在でもその所有権をめぐって議論が続いています。
1828年から1829年にかけての彼自身のエジプト遠征では、セティ1世の墓から
壁パネルを切り取らせてフランスへと送りました。それは今もルーヴル美術館にあります。
同僚のIppolito Roselliniはもう1つをフィレンツェへと持ち帰りました。
そして「解読」それ自体が、ある人々の言葉に対する権威を部外者が主張するという、
文化の奪取行為になり得ます。私たちはこの事実をありのままに語ります。
過去を取り繕うつもりはありません。

私たちがシャンポリオンから受け継ぐのは方法論であり、その人物ではありません。言語とその文字体系はそれ自身の文脈で理解されるべきだという確信、そしてアクセスのための作業は丁寧に行う価値があるという信念です。収奪は拒絶します——このツールはその対極として作られました。

その手法には特徴があります。Champollionは、コプト正教会の典礼の中で
受け継がれてきたエジプト語の最終段階であるコプト語を手がかりに、その文字を読み解きました。
ロゼッタ・ストーンのギリシャ語は彼に名前を与え、生きた伝統は彼に言語を与えました。
これこそが、私たちが堅持する姿勢です。言語を受け継ぐ人々こそが
その言語への入り口であり、すべての取り組みは彼らを通じて行われます。

## ツールがいかに収奪を反転させるか

- **奪い取って保管することはありません。** コーパスは提供元から取得され、
  私たちがホストすることは決してありません。私たちが保持するのはメタデータであり、
  他の人々の言語ではありません。
- **所有権はコミュニティに留まります。** 私たちは先住民族の
  データ主権の原則（言語データのコミュニティによる所有と管理）に沿って開発を行っています。
  その原則を満たしているかどうかを判断するのはコミュニティであり、私たちではありません。
  封印された評価データについて、現在、封印されたセットの鍵は主催者管理（それを主催する者が保持）
  となっており、Champollionは鍵のシェアを保持していません。
  この設計では、コミュニティが選んだ保管担当者がしきい値構成のもとで
  鍵を保持できるようになっています（コミュニティの鍵保管担当者はまだ指定されていません）。
- **私たちは翻訳の精度を測定するのであり、言語を収集するのではありません。** ネットワークは、
  特定の言語ペアにおいて翻訳がどれだけ機能するかを報告します。
  トロフィーを並べる陳列棚ではなく、安易なデータや範囲が不適切なデータは
  ランキングから除外されます。
- **私たちはこの取り組みを支えている人々**（言語学者、話者、
  コーパス作成者）の名前を、同意が得られた場合に限り明記し、
  同意していない人の名前を挙げることは決してありません。
- **同意は撤回可能です。** 話者は自身の判断に対する権利を持ち、
  いつでもそれを撤回できます。

私たちは先住民族の組織ではなく、この名前もそのことを示しています。コミュニティのために
行う活動はすべて奉仕としての立場であり、コミュニティの同意を得た場合に限られます
（まだ私たちに依頼したコミュニティはありません）。そして、この名を冠する非先住民族のプロジェクトは、
信頼を一方的に主張するのではなく、獲得していかなければなりません。厳しい精査を当然のこととして受け止め、
批評を歓迎します。コミュニティからこの名前が悪影響を及ぼしていると指摘された場合、
その意見に真摯に耳を傾けます。[info@champollion.dev](mailto:info@champollion.dev) までご連絡ください。
