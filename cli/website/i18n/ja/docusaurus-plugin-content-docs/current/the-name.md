**Champollion**という名前は、1822年にエジプトのヒエログリフを解読し、ひとつの文字体系を再び世界に読み解かせたジャン＝フランソワ・シャンポリオンに由来しています。私たちが借りるのはその比喩です——意味へのアクセスを回復すること、そして言語をその言語自身の文脈で読むこと。

この名前を使う以上、その歴史から目を背けることはできません。

シャンポリオンは植民地的な事業の中で活動していました。彼の解読を可能にしたロゼッタ・ストーンはヨーロッパに軍事的な戦利品として持ち込まれ、今日もなお帰属が争われています。1828〜29年に自ら行ったエジプト遠征では、セティ1世の墓から壁面パネルを切り取ってフランスに送り、それらは今もそこにあります。そして「解読」という行為そのものが、ある種の収奪になりえます——部外者が人々の言葉に対して権威を主張することです。私たちはこれを率直に述べます。それを覆い隠すつもりはありません。

私たちがシャンポリオンから受け継ぐのは方法論であり、その人物ではありません。言語とその文字体系はそれ自身の文脈で理解されるべきだという確信、そしてアクセスのための作業は丁寧に行う価値があるという信念です。収奪は拒絶します——このツールはその対極として作られました。

## ツールがいかに収奪を反転させるか

- **取得して保持することはありません。** コーパスはその提供元から取得され、私たちがホストすることは決してありません。私たちが保持するのはメタデータであり、他者の言語ではありません。
- **所有権はコミュニティに留まります。** 私たちは先住民族のデータ主権の原則（言語データのコミュニティによる所有と管理）に沿って開発を進めていますが、それを満たしているかどうかを判断するのは私たちではなくコミュニティです。
  封印された評価データについては、私たちが一切のシェアを持たない閾値設定のもとで、コミュニティの保管人に鍵を委ねる設計となっています（保管人はまだ任命されていません）。万が一私たちが存在しなくなっても、管理権はコミュニティに残ります。
- **翻訳がどれだけ機能するかを測定するのであり、言語を収集するのではありません。** The Networkは、特定の言語ペアにおいて翻訳がどれだけ機能するかを報告します。これはトロフィーケースではなく、安易なデータやスコープが不適切なデータはランキングから除外されます。
- **この取り組みを支える人々に謝意を示します** — 言語学者、話者、コーパス構築者の方々です。名前の公表に同意いただいた場合は必ず氏名を明記し、同意のない方を公表することは決してありません。
- **同意は撤回可能です。** 話者は自らの判定結果を所有しており、いつでもそれを取り消すことができます。

この名前を冠する非先住民族かつ非商用のプロジェクトは、信頼を当然のものとして主張するのではなく、自ら獲得しなければなりません。私たちは厳しい精査を想定しており、批判を歓迎します。もしコミュニティからこの名称が害をもたらしているとの指摘があれば、その異議に真摯に耳を傾けます。[info@champollion.dev](mailto:info@champollion.dev) までご連絡ください。
