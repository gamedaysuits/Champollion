**Champollion**という名前は、1822年にエジプトのヒエログリフを解読し、ひとつの文字体系を再び世界に読み解かせたジャン＝フランソワ・シャンポリオンに由来しています。私たちが借りるのはその比喩です——意味へのアクセスを回復すること、そして言語をその言語自身の文脈で読むこと。

この名前を使う以上、その歴史から目を背けることはできません。

シャンポリオンは植民地的な事業の中で活動していました。彼の解読を可能にしたロゼッタ・ストーンはヨーロッパに軍事的な戦利品として持ち込まれ、今日もなお帰属が争われています。1828〜29年に自ら行ったエジプト遠征では、セティ1世の墓から壁面パネルを切り取ってフランスに送り、それらは今もそこにあります。そして「解読」という行為そのものが、ある種の収奪になりえます——部外者が人々の言葉に対して権威を主張することです。私たちはこれを率直に述べます。それを覆い隠すつもりはありません。

私たちがシャンポリオンから受け継ぐのは方法論であり、その人物ではありません。言語とその文字体系はそれ自身の文脈で理解されるべきだという確信、そしてアクセスのための作業は丁寧に行う価値があるという信念です。収奪は拒絶します——このツールはその対極として作られました。

## ツールがいかに収奪を反転させるか

- **持ち去って保持することはありません。** コーパスは元のソースから取得され、私たちがホストすることは決してありません。私たちが保持するのはメタデータであり、他者の言語そのものではありません。
- **所有権はコミュニティに帰属します。** 私たちは先住民族のデータ主権の原則（言語データのコミュニティによる所有と管理）に沿って開発を進めていますが、その原則を満たしているかどうかを判断するのは私たちではなくコミュニティです。封印された評価データについては、閾値方式の取り決めにより暗号鍵をコミュニティの管理者に委ね、私たちがシェアを一切保持しない設計となっています（現時点ではまだ管理者は任命されていません）。万一私たちが活動を停止しても、管理権はコミュニティに残ります。
- **私たちは翻訳の精度を測定するのであり、言語を収集するのではありません。** Networkは、特定の言語ペアに対して翻訳がどれほどうまく機能するかを報告します。ここはトロフィーを飾る陳列棚ではなく、安易なデータや対象範囲が不適切なデータはランキングから除外されます。
- **この活動を支えている人々**（言語学者、話者、コーパス作成者）の功績を称え、あらゆる場所でその名を明記します。
- **同意はいつでも撤回可能です。** 話者は自身の判断結果に対する権利を保持しており、いつでもそれを取り下げることができます。

この名前を冠する先住民族以外による非営利プロジェクトは、信頼を一方的に主張するのではなく、自ら獲得していかなければなりません。私たちは厳しい精査を当然のものとして受け止め、批判を歓迎し、私たちが貢献するコミュニティとともに、この名称、そしてこの取り組みを継続的に見直し続けていきます。
