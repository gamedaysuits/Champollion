**Champollion**という名前は、1822年にエジプトのヒエログリフを解読し、ひとつの文字体系を再び世界に読み解かせたジャン＝フランソワ・シャンポリオンに由来しています。私たちが借りるのはその比喩です——意味へのアクセスを回復すること、そして言語をその言語自身の文脈で読むこと。

この名前を使う以上、その歴史から目を背けることはできません。

シャンポリオンは植民地的な事業の中で活動していました。彼の解読を可能にしたロゼッタ・ストーンはヨーロッパに軍事的な戦利品として持ち込まれ、今日もなお帰属が争われています。1828〜29年に自ら行ったエジプト遠征では、セティ1世の墓から壁面パネルを切り取ってフランスに送り、それらは今もそこにあります。そして「解読」という行為そのものが、ある種の収奪になりえます——部外者が人々の言葉に対して権威を主張することです。私たちはこれを率直に述べます。それを覆い隠すつもりはありません。

私たちがシャンポリオンから受け継ぐのは方法論であり、その人物ではありません。言語とその文字体系はそれ自身の文脈で理解されるべきだという確信、そしてアクセスのための作業は丁寧に行う価値があるという信念です。収奪は拒絶します——このツールはその対極として作られました。

## ツールがいかに収奪を反転させるか

- **私たちは取得して保持することはしません。** コーパスはソースから取得され、私たちが
  ホストすることはありません。私たちが保持するのはメタデータであり、他者の言語そのものではありません。
- **所有権はコミュニティに帰属します。** 私たちは先住民族のデータ主権の原則 —
  言語データのコミュニティによる所有と管理 — に向けて構築を行いますが、それらを満たしているかどうかを判断するのは私たちではなく、コミュニティです。
  封印された評価データについて、その鍵はマルチシグ（複数署名）の仕組みの下でコミュニティの管理者が
  保持し、私たちは一切のシェアを持ちません。私たちが消滅したとしても、管理権限は
  コミュニティに残ります。
- **私たちは信頼度を測定するのみで、言語を収集しません。** ネットワークは、特定の言語ペアにおいて
  翻訳がどの程度うまく機能するかを報告します。これはトロフィーケースではなく、
  安易なデータや不適切にスコープされたデータはランキングから除外されます。
- **私たちは、この基盤となる人々の功績を称えます** — 言語学者、話者、そしてコーパス
  構築者の名前を、あらゆる場所で明記します。
- **同意は撤回可能です。** 話者は自身の判断に対する所有権を持ち、いつでもそれを撤回する
  ことができます。

この名前を冠する、非先住民による非営利プロジェクトは、信頼を主張するのではなく、
獲得しなければなりません。私たちは厳しい目を向けられることを予期し、批判を歓迎し、
私たちが支援するコミュニティとともに、この名前と活動を継続的に見直していきます。
