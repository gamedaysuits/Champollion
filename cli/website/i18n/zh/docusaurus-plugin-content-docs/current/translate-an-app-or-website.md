# 翻译应用或网站

应用和网站将文字内容（按钮、菜单、提示消息、页面）保存在文件中，每种语言对应一个文件。Champollion 可以为你填入目标语言的文件内容，并在原文发生变更时保持同步更新。只需一条命令即可完成：

```bash
npx champollion sync
```

它会自动找到应用中的语言文件，仅翻译缺失或更改的内容，在写入之前检查每处翻译，并保留其余内容不变。

## 由谁来完成翻译

你可以针对每种语言进行选择：

- **你自己的翻译器**，基于本套轨道构建——工具会将其连接到你的应用。如果它曾使用非公开语句进行训练，则只有在你指明在持有这些词句的人当中谁表示同意之后，它才会建立连接。
- **AI 模型或翻译服务**——适用于它们已能良好支持的语言。这些服务会将应用中的文字发送给运营它们的公司，因此请仅将其用于可以放心共享的文本。
- **你自己的服务**，部署在你指定的地址。

## 它负责处理的工作

- **仅针对变更内容。** 它会记住之前翻译过的内容，因此你无需为同一句话重复付费。
- **写入前校验。** 空白结果、直接复制原文、词语循环重复、文本远超正常长度、内容缺失或字符集错误都会被拦截并拒绝。这些校验旨在发现异常输出，而非判断语义正误——母语使用者始终拥有最终决定权。
- **适配你的文件和格式。** 支持 JSON、YAML、TOML 与 Markdown 页面，以及常见的应用和网站框架。

## 谁可以使用

非商业用途完全免费——例如学校的应用、社区网站或公共服务。商业产品不在免费许可证覆盖范围内；如果母语者社区希望将其用于商业用途，只需提出申请，即可免费获得许可。详见[谁可以使用此工具](/docs/getting-started/who-may-use-this)。
