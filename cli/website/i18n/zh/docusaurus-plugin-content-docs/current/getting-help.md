# 获取帮助

**遇到问题，或是希望在项目中获得帮助？欢迎与我们聊聊。**
发邮件至 [info@champollion.dev](mailto:info@champollion.dev?subject=Help%20with%20a%20language%20project)。

构建翻译器其实完全不需要依赖我们：这些轨道（rails）的设计初衷，就是让你或你信任的 AI 助手能够独自走完全程。但若有人并肩同行，有些项目可能会进展得更快，也更让人感到安心。

## 我们可以提供怎样的帮助

无论你的项目需要什么，都可以与你共同商定：

- **安装与配置** — 在你的电脑上，按你的社区所希望的方式进行设置。
- **整理你的数据** — 汇总分散的文件，选定拼写规范，挑出合适的测试句子。
- **指导与培训** — 向你的团队演示这套轨道是如何运作的，以便你们日后无需我们协助也能继续推进。
- **与你协作构建** — 在你的指导下，承担部分技术工作。
- **代为运维管理** — 如果你的社区提出要求，且仅在社区自主决定的前提下。

这里没有固定的价目表：我们会根据每个社区的实际需求，与大家共同商定合理的合作方案。

## 我们是谁

Champollion 是一个非原住民项目。我们承担服务者的角色，并且仅在获得知情同意的前提下开展工作：你的社区全权决定其语言、数据以及基于此构建的一切成果。社区从自身语言中获得的任何收益，我们均不抽取任何分成。

## 获取帮助的其他方式

- **[加入项目](/docs/join-a-project)** — 登记你的项目，以便其他人可以提供句子、词表或方法。
- **你的 AI 助手** — 它可以解释任何步骤。问问它*“为什么这个步骤很重要？”*，它就会告诉你轨道指南中的说明。
