# 带上你现有的资料

翻译器通过**对照句对**来学习：一种语言的一句话，以及另一种语言中意思相同的一句话。本页面将介绍如何导入你的资料——以及针对每个文件你需要回答的问题，这些问题比流程中的任何其他事项都更为重要。

## 工具可读取的内容

按你平时的保存方式直接导入文件即可。你不需要转换任何格式。

| 你拥有的资料 | 工具可读取的内容 |
|---|---|
| 包含句子和翻译的电子表格 | Excel (`.xlsx`)、LibreOffice (`.ods`)、`.csv`、`.tsv` 或纯文本 |
| Word 文档中的表格 | 表格的各行内容 |
| 在 Toolbox 或 FieldWorks（许多语言学家使用的程序）中创建的词典 | 词条——及其例句（作为句对） |
| 在 ELAN（一款用于转录录音的程序）中记录的录音文本 | 转录的文本行及其翻译（作为句对） |
| 词汇表 | 每个词及其翻译 |
| 语法笔记 | 保存在专门的位置，供人员和工具参考 |
| 经文典籍 | 仅在明确要求时读取，且在保管人员同意前，绝不会让翻译器从中学习 |

工具会直接在文件所在位置读取。如果电子表格的各列未注明对应的语言，工具会向你询问——绝不会根据内容自行推测。

工具还会寻找疑似有误的数据行——例如译文错位窜行、两列内容颠倒、直接从对侧复制的译文、完全重复的句对、明显过长或过短的译文——并按行号逐一提示。工具绝不会自行修改或删除任何内容；一切由熟悉数据的人来决定。

## 工具只做计数。绝不会向任何人朗读你的话语。

文件导入后，工具会告知找到了多少个句对以及使用了哪些列。你的 AI 助手能看到的仅限于此：数量统计和列名，绝不会包含句子内容本身。

## 针对每个文件的问题

在任何内容用于学习之前，流程都会向文件的保管人员确认以下事项：

- **它归谁所有？** 用你自己的话说明即可——一个家庭、一位老师，或是一个社区办公室。
- **其中包含谁的话语？** 说出或写下这些句子的人。祖母的笔记本记录的是她的话语，即便这些内容是由她的孙子录入电脑的。
- **他们是否同意使用？** *已同意*、*尚未同意*，或*部分人不同意*。在得到明确答复前，流程会持续询问。来自尚未同意或明确表示不同意的人的话语，绝不会用于训练翻译器。
- **是否允许翻译器从中学习？**
- **是否允许离开这台电脑？** 在你作出回答之前，所有文件默认保持私密——仅保存在本地电脑上。

这些回答会记录在文件旁的一份简短说明中，所有工具都会严格遵循。首次回答后，工具只能将规则改得更严格，绝不能放宽。唯一的例外是：此前尚未被询问的说话人仍可选择同意。

你的助手会提出这些问题；但它绝不能替你回答。如果你还不确定——比如还需要征求某位长辈的意见——请选择*尚未同意*。流程会暂时搁置该文件并继续其他工作，稍后再委婉询问。

## 你将看到的内容

在工具的演练测试中（使用虚构句子的演示），一个家庭导入了四个文件：来自祖父电子表格的 <WalkFact of="trainingFiles.0.pairs" /> 个句对，来自姑姑电子表格的 <WalkFact of="trainingFiles.1.pairs" /> 个句对，包含 <WalkFact of="lexicon.pairs" /> 个词的词汇表，以及供测试使用、经母语者核对过的 <WalkFact of="test.pairs" /> 个句子。每次导入，助手都会报告统计数量，随后询问文件归谁所有，以及是否允许翻译器从中学习。

## 来自其他出处的句子

如果你使用了并非由你编写的句子——来自书籍、网站或公开发行的资料集——它们各自带有使用规则。有些可以阅读但不能共享；有些则不能用于任何学习训练。请以相同的方式导入它们，并如实回答对应的问题：工具会严格按照你的回答来约束其使用。当某个资料集的授权许可较为特殊或不够明确时，在所有者同意之前，工具绝不会将其发送给外部 AI 服务。
