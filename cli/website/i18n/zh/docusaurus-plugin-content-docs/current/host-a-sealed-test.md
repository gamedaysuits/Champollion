# 举办密封测试

有时，适用于您语言的最佳翻译器会来自其他人——
研究人员、学生或某家公司。**密封测试**能让他们在*您的*句子上证明其实力，而完全不需要看到这些句子。

## 运作方式

您的测试句子会在您的计算机上用密钥锁定。想要参赛的人提交他们的翻译器。您的计算机在锁定的句子上运行每一个翻译器，最终仅输出评分——绝不会泄露句子本身，也绝不会泄露翻译结果。

因此测试始终是真正的测试：没有人能研究它或针对它进行调优，因为没有人能读到它。

## 由您决定的事项

在任何人参赛之前，由您来设定规则条款：

- **达到什么标准才算足够优秀**以获胜。
- **对获胜方法如何处置：**
  - **归您所有**——移交给您，即掌握测试的人员；
  - **由制作者保留**——您对其进行评分，最多只保留一份用于核对的锁定副本；
  - **由制作者保留，但与所有人共享**——他们必须公开发布。
- **是否设立奖金**，以及由谁出资。Champollion 不从任何奖金中抽取分成。

## 当前现状

用于密封测试的工具已经可以正常运作：锁定数据集、在断开互联网的计算机上运行提交的翻译器，并仅发布评分。但这**尚未走上既定轨道**——目前这意味着需要遵照一份篇幅更长的手册操作，而不是一步一步回答助手的提问。

如今谁来保管密钥：谁锁定了数据集，谁就保管密钥。目前还没有社区指定人员来共同保管密钥，且 Champollion 不保管任何密钥的任何部分。

开放中的密封测试（如有）会列在[共享任务](/shared-tasks)页面上。
