# 衍生制品承诺

[数据管理](/docs/network/sovereignty/data-sovereignty)立场涵盖了*输入*：语料库由其管理者保留，我们从不托管或重新分发社区数据。本页涵盖了*输出*——那些**基于**语言数据构建的产物：训练好的模型及其权重、翻译记忆库、微调模型、指导集、评估标准以及运行制品。

一句话总结该承诺：

> **我们对基于社区数据构建的任何语言模型或语言衍生制品不主张任何所有权——我们也不想这么做。这个项目的全部意义在于，将这些技术的开发级和所有权级控制权交到语言使用者手中。**

Champollion 是**基础设施**。道路并不拥有在上面运输的货物。

## 具体含义

**模型属于使用该语言的人民。** 如果一个模型是基于某个社区的数据训练的——无论是使用我们的工具还是其他人的工具——其权重、微调以及每一个衍生品都遵循该社区的条款，而不是我们的。我们不保留副本，不重新授权，也不把“我们编写了训练脚本”视为对产物的所有权主张。这个教训是历史性的，而非假设：语言社区已经一次又一次地看到外部组织记录、汇编或使用他们的语言进行训练，然后将成果据为己有——比如长者录音的版权、基于抓取的语音训练的模型——而语言使用者自己却不得不为使用自己的声音而请求许可。这种失败的模式正是本承诺要杜绝的。

**平原克里语（Plains Cree，nêhiyawêwin）的工作是测试用例，且答案已经确定。** 本项目中为克里语构建的任何东西都不属于我们——无论是训练语料库（在其持有者的许可下使用，且从不重新分发），还是经过指导的流水线，亦或是任何训练好的模型。在这项工作中产生的任何克里语模型将**仅发布给受认可的社区权威机构**——教育机构、长者委员会，或社区自行指定的任何机构——并遵循社区自己的条款，绝不提供给其他任何人。在任何情况下，克里语模型都不会作为产品发布。克里语的评估工作同样**全程非商业化**：Champollion 充其量只维护*通用的*评估方法（LYSS 标准——即内涵式、形态学感知的、诚实失败的评分理念）。该标准的**克里语实例**——它所编码并用于验证的语言学知识——并不属于我们；其商业用途将被保留，直至与 nêhiyaw 语言社区协商，并受社区条款管辖。

**分数可以流转；制品则不行。** 排行榜发布的是*测量结果*——chrF++ 值、验证率、置信区间——并标明了方法和语料库。它从不发布、托管或要求提供模型本身、语料库内容，或超出管理者条款允许范围的输出。如果一个社区希望将其语言的记录从公众视野中移除，[注册通道](/docs/network/sovereignty/registering-corpora)的存在正是为了让曝光度由他们来掌控，而不是我们。

## 基础设施意味着：你的数据，你的构建，你的密钥

“我们只是基础设施”在实践中的三种具体表现形式：

1. **社区构建自己的语料库。** 他们在自己的机器上使用 CLI；语料库存放在他们放置的地方。如果他们选择将其注册用于基准测试，注册表仅存储一个*指针和校验和*——从源获取，受其许可证约束，并可应其要求下架。语料库永远不会进入我们的代码库或存储中。这是由你可以检查的机制来强制执行的：公共代码库附带了隔离网关和数据库触发器，这使得托管社区内容在结构上成为不可能，而不仅仅是不礼貌。

2. **社区训练自己的模型。** 训练套件（[nmt-forge](https://github.com/gamedaysuits/Champollion)）在他们的硬件上运行；检查点（checkpoints）和权重仅存在于那里。评估工具（eval harness）对其进行评分；排行榜记录该分数。我们从不拥有该模型。如果他们希望它永远保密，它就会保密——分数记录是唯一的公开痕迹，而且前提是他们发布了分数。

3. **社区运行自己的基准测试。** 通过[主权竞赛（sovereign contests）](/docs/network/sovereignty/run-a-sovereign-contest)，测试集在社区控制的基础设施上保持封闭；方法*走向*数据；只有汇总的分数会流出。社区决定谁可以进行评估、在什么条款下进行，并且可以随时停止。

在每种情况下，流动的方向都是相同的：能力向社区转移；数据及其衍生品不会离开社区。

## 我们推崇的框架

我们**深受社区自行构建的原住民数据治理框架的启发，并以此为目标**。我们无权认定自己符合其中任何一个框架——这种判断属于制定它们的社区和机构。我们能做的是朝着它们的方向进行设计，将它们视为标准制定者，并坦诚地表示，我们非常珍视倾听这些专家的意见并与他们合作的机会，以本着他们的精神改进这个系统：

- **First Nations 数据主权原则**——所有权（Ownership）、控制权（Control）、访问权（Access）和占有权（Possession）：正是本页面承诺保留在社区手中的四项能力。
- **原住民数据治理 CARE 原则**（集体利益 Collective Benefit、控制权 Authority to Control、责任 Responsibility、伦理 Ethics），来自全球原住民数据联盟（Global Indigenous Data Alliance）——这是对纯粹“开放”数据的纠正视角：当开放剥夺了一个民族对自己知识的权威时，开放就不再是一种美德。
- **Te Mana Raraunga**，毛利数据主权网络（Māori Data Sovereignty Network）的章程——将数据视为活的 taonga（宝藏），并伴随着相应的权利和责任。
- **Kaitiakitanga 许可证**（Te Hiku Media）——据我们所知，这是语言技术中衍生制品主权最清晰的实际案例：Te Hiku *基于*毛利语（te reo Māori）并*为*毛利语构建了语音模型，并在监护条款下授权访问，从而使模型造福毛利人并保持在毛利人的治理之下。当我们说“模型属于语言使用者”时，Te Hiku 就是证明其行之有效的存在证明。
- **Masakhane 的参与式研究模型**——由作为共同作者和所有者（而非数据源）的语言使用者-研究人员构建的非洲 NLP；这证明了构建语言技术的*过程*本身就可以是能力的转移。

这些是来自不同民族、具有不同法律和文化立场的不同框架——我们将它们并列列出，而不是将它们归入一个标签。如果我们的设计未能体现它们的精神，那就是一个需要修复的缺陷，我们宁愿从专家那里听到，也不愿在事后分析中才发现。如果你在这个领域工作，并愿意告诉我们哪里做错了：**这种对话是本项目能收到的最有价值的贡献。** 请通过[参与其中（Get Involved）](/get-involved)联系我们。

## 我们确实拥有的东西

为了清晰起见，Champollion *确实*主张所有权的东西包括：基础设施代码（CLI、测试工具、训练套件——各自遵循其发布的许可证）、通用的评估方法，以及索引的*衍生测量结果*（它们带有 `champollion-derived` 来源，正是为了确保它们永远不会被错误地归因于某个社区或上游来源）。这就是工具箱。你用它构建的东西属于你自己。
