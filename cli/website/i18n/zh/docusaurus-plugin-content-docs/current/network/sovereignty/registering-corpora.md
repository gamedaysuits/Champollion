# 注册语料库与曝光通道

> **执行摘要。** 您可以向网络注册评估语料库，以便针对其对各种方法进行基准测试，而**无需向我们移交数据**。每个语料库均注册为固定 SHA 校验和的*元数据卡片*，而非内容本身——实际句子在评估时从其源头获取。注册时，您需要做出两项独立的决定：**暴露层级**——有多少内容会离开您的机器（`local-only`、`private`、`public` 或 `sealed`，其中语料库在您的设备上通过 M-of-N 托管人密钥加密）——以及**许可通道**，用于规范该语料库可用于何种用途（公开、非商业仅限研究或私有）。正是这种机制使社区能够使其语言*可衡量*，同时又不会使其*可被提取*。

机器翻译评估通常要求与数据主权相反的做法："上传你的测试集，以便我们可以针对它进行评分。"这对于土著语言和其他社区持有的语料库来说是不可行的，其中数据由其来源的人拥有。网络的构建使你永远不必做出这种权衡。

---

## 1. 注册是元数据，不是内容 {#1-registration-is-metadata-not-content}

注册的语料库是一个**卡片**：一个小的 JSON 记录，描述语料库*位于何处*和*是什么*，带有内容哈希以便可以验证确切的字节——但**没有句子**。卡片包含：

| 字段 | 它是什么 |
|-------|-----------|
| `url` | 语料库从何处获取（你控制的上游存档） |
| `sha256` | 固定存档的内容哈希——证明没有人交换了数据 |
| `license` | SPDX 标识符（或 `LicenseRef-…` 用于定制许可证） |
| `language_pair` | 源 → 目标，例如 `eng-crk` |
| `do_not_train` | 始终设置——评估数据必须从不用于训练 |
| `attribution` | 在语料库出现的任何地方显示的构建者/语言学家信用 |

在评估时，工具**从源头获取**，验证 `sha256`，并针对新获取的参考文献进行评分。网络从不存储、托管或重新分发语料库内容。如果你将上游存档离线，语料库就停止可运行——控制权留在你手中。这是应用于整个目录的相同的从源头获取纪律（参见[评估数据集](/docs/network/leaderboard/datasets)）。

:::info[为什么使用哈希而不是副本]
内容哈希允许自报的分数能够**重新检验**真实的、未修改的语料库，而我们无需持有该语料库。运行结果的数字无法根据哈希固定的源重现时，该运行会被拒绝。可验证性和非持有性在这里并不矛盾——哈希正是使两者都成为可能的关键。
:::

## 2. 两个独立的决定

注册会向您提出两个独立的问题，将它们区分开来很有必要，因为它们保护的对象各不相同：

1. **什么会离开您的机器**——*暴露层级*。
2. **您的语料库可用于何种用途**——*许可通道*。

语料库可以是封印且非商业的，也可以是公开且已获商业授权的，或是任何其他组合。二者互不蕴涵。

### 2a. 暴露层级——什么会离开您的机器

共有四个层级，定义于 `cli/lib/corpus-registration.mjs` 中。**在任何层级下，明文语料库内容都绝不会被上传**——这不是策略设置，而是对每个层级都适用的硬性规则。注册始终默认为最私密的层级。

| 层级 | 已注册？ | 我们接收的内容 | 跟踪卡片 |
|---|:---:|---|:---:|
| **私有 / 仅本地** | ❌ | 无。卡片和文本保留在您的机器上。**默认设置。** | ❌ |
| **私有注册** | ✅ | 仅元数据——WMT 风格的保密留出集。您保留保管权；结果可以公开发布而不会暴露数据。 | ✅ |
| **公开注册** | ✅ | 元数据 + 从源获取的指针。您的文本按需从上游获取，绝不在本地托管。需要获得再分发许可。 | ✅ |
| **封印（Sealed）** | ✅ | 不含内容的卡片。密文保留在您手中。 | ✅ |

#### 防止测试集接触任何外部 AI 服务

不上传您的文本是一项保证。在评估时**不将其发送**到模型 API 则是另一项保证，这对于包含敏感措辞的测试集尤为重要。通过在文件旁边放置一个同名并添加 `.champollion.json` 后缀的小文件，即可将其标记为仅限本地：

```bash
# data/nurse_checked_test.tsv  →  data/nurse_checked_test.tsv.champollion.json
echo '{"transmission": "local-only"}' > data/nurse_checked_test.tsv.champollion.json
```

这适用于任何语料库格式（TSV、JSONL、纯文本对、JSON）。从此时起，`mt-eval run` 会将该语料库视为已封印：
- 使用远程提供商（OpenRouter、OpenAI、Anthropic、Gemini）时，运行会**在发送任何文本之前**以及请求任何 API 密钥之前被**拒绝**；
- 当 `--provider local` 指向本机器上的模型时（例如 `http://localhost:11434/v1` 等环回地址），运行正常进行；
- 使用 `--method local-model -m <model>` 时（由测试框架在其自身进程中加载的 NLLB、OPUS-MT 或 MADLAD 模型；需要 `-m`），运行正常进行：没有句子会离开机器，且下载权重只会传输模型文件，绝不会传输您的文本；
- 使用机器翻译引擎或方法插件（`--method <plugin dir>`）时，除非您证明其传输完全在本地进行（`--attest-local-transport`，记录在运行日志中），否则运行会被拒绝：测试框架无法查看插件或服务将文本发送到何处；
- 来自语言卡片的该语言自身评估指标**不会被加载**。它们来自独立的软件包，这些软件包可能会在外部服务（例如在线词典）上查词。运行评分时不会包含它们，并且运行卡片会说明它们已被扣留及其原因；
- `mt-eval publish` 会扣留句子，并在默认情况下将指导性或自定义提示词替换为其 sha256 散列值，因此从您自己的句子中提取的提示词示例也会保留在此机器上。语料库的一些元数据确实会随分数一同公开：其 id、版本、语言对、大小、文件的 sha256、其许可和署名、其污染等级、其被标记为仅限本地的状态，以及其分段名称。对于非已注册数据集的 id，发布还会创建一个具有相同 id、语言对、大小和 sha256 的公开 `datasets` 行，外加其领域、分段名称和难度范围。`--dry-run` 预览会在保留在此处的内容（每个句子、文件及其路径）旁边列出您此次运行的这些信息。其他人随后会看到一个他们无法打开的测试集上的分数。这是自评基准，其他人无法重新运行，并且 sha256 仅允许持有相同文件的人确认其为该文件；
- 工具打印的内容会略去句子，因为读取终端的 AI Agent 会将其读取的内容传递给其模型提供商。`mt-eval compare` 显示条目 id 和分数而非句子，并且引用了句子的错误消息在打印时会将其移除。`--show-text` 则会为终端前的人类用户打印它们。写入结果文件夹的文件会保留文本，且每个文件都带有该语料库的标记：测试框架根据该语料库编写的每个运行日志、报告、对比文件和仪表板都会获得其专属的 `.champollion.json`，其中包含相同的条款以及 `derived_from`。下一个工具或该文件后续的运行也会将其视为受保护内容。终端会列出保存该文本的每个文件名；
- 翻译缓存会将此语料库的条目隔离开来：置于 `<cache-dir>/protected/<namespace>/` 下（默认为 `eval/cache/harness/protected/…`），位于以运行设置、语料库 sha256 及其条款为键的命名空间中，因此条目仅会回传给针对同一语料库的运行——绝不会提供给针对其他语料库或未标记语料库的运行。那里的每个缓存文件都带有相同的 `.champollion.json` 标记。（在此保护机制出现之前缓存的条目位于普通缓存中，未作标记；删除 `eval/cache/harness/` 一次即可将其清除。）

该标记只会让语料库的限制更加严格。任何许可和 `--allow-data-collection` 标志都无法放宽它。如果标记文件不可读，运行将停止，而不是将其忽略。

**封印（Sealed）是系统提供的最强保证。** 您的语料库**在您的设备上**使用托管人组的密钥进行加密，密文保留在您的机器或评估节点上。Champollion 仅接收不包含内容的卡片。在离线节点上，密钥被拆分，需要 **M of N** 个托管人共同授权才能进行运行；该仪式已构建完成，但尚未与真正的托管人一起使用。封印集已编入目录但处于隔离状态，并与公开的*限定资格（qualifier）*语料库配对，某种方法必须先通过该公开语料库的考核，才能提议封印运行。请参阅[举办主权竞赛](/docs/network/sovereignty/run-a-sovereign-contest)和[主权评估节点](/docs/network/sovereignty/sovereign-eval-node)。

### 2b. 许可通道——语料库可用于何种用途

另外，许可规范了结果可以出现在何处。

#### 公开

一个开放许可的语料库（例如 CC0、CC-BY），其参考文献可能出现在公开表面，其运行可能在公开排行榜上排名。内容仍然是从源头获取——"公开"管理*参考文献和排名的曝光*，而不是托管。大部分目录（Tatoeba、GlobalVoices、TICO-19、IN22、SMOL、ALT、Turkic-x-WMT、WMT24++ 等）都在这个通道中。

#### 非商业仅限研究

一个在非商业许可证下的语料库（例如 CC BY-NC-SA，或定制的社区/非政府组织许可证，如 Gamayun 工具包的 `LicenseRef-TWB-Gamayun`）。它可以**用于研究基准测试**——方法在其上运行，分数被计算——但它**被排除在所有商业、奖项和 API 路径之外。** 资格是**基于使用的**，而不是基于语料库的：

- **商业通道是严格的**——任何不明确商业许可的东西都被排除；
- **研究通道是宽松的**——非商业语料库是受欢迎的；
- **隔离总是赢**——一个被标记为不当子集（或以其他方式被禁止）的语料库永远不能在*任何*通道中排名，无论许可证如何。

这是社区如何让其语料库推动研究进展，同时将其排除在任何人的产品之外的方式。

#### 私有

为**你自己的评分运行**注册的语料库，其中参考文献从不发布。你持有源头；你运行评估；你决定是否以及什么会被显示。私有语料库稍后可以公开或非商业——曝光只会*放松*通过明确的、所有者驱动的决定，从不无声地。

| 许可通道 | 可作为基准测试 | 公开展示参考译文 | 可在公开排行榜排名 | 处于商业 / 奖项 / API 路径中 |
|------|:---:|:---:|:---:|:---:|
| **公开** | ✅ | ✅ | ✅ | ✅（若许可允许） |
| **非商业仅限研究** | ✅ | 取决于许可 | 仅研究通道 | ❌ |
| **私有** | ✅（仅限您的运行） | ❌ | ❌ | ❌ |

:::note[商业赛道是护栏，不是业务]
Champollion 本身是非商业性的——这背后没有付费 API 或产品。商业/奖项赛道作为一个*前向*护栏而存在：它以机制化的方式记录哪些语料库可能合法地出现在奖项或商业背景下，以便任何人的任何未来使用都不会超越许可证或管理者的条款。
:::

## 3. 主权保证

注册是围绕[数据管理立场](/docs/network/sovereignty/data-sovereignty)设计的。具体来说：

- **持有权留在源头。** 我们持有哈希和 URL，而不是数据。
- **控制权是所有者的。** 通道是所有者的选择，曝光只会通过明确的决定而放松。拉下上游存档会撤销可运行性。
- **非商业意味着非商业。** NC 语料库在机械上被排除在商业、奖项和 API 通道之外——不是通过承诺，而是通过门。
- **不当子集永远不能排名。** 隔离覆盖许可证，所以一个被禁止排名的语料库在任何地方都保持被禁止。
- **归属是强制性的。** 构建者/语言学家信用随卡片到语料库出现的每个表面。

关于如何设置每种语言的条款——包括赞助奖项的方法所有权转移——参见[所有权与条款](/docs/network/sovereignty/ownership-transfer)。

## 4. 如何注册

语料库卡片模式和构建/验证工具在[语料库设计框架](/docs/network/specifications/corpus-design)和[语料库创建食谱](/docs/network/tutorials/corpus-creation)中有文档记录。简而言之：

1. 在你控制的地方托管语料库存档（它留在那里——它从不被复制到网络中）。
2. 编写卡片：`url`、`sha256`、`license`、`language_pair`、`attribution`、`do_not_train`。
3. 选择曝光通道（公开/非商业/私有）。
4. 注册卡片。方法现在可以针对语料库从源头获取进行基准测试，在通道的规则下。

你永远不上传句子。你可以随时停止。

### 卡片 ID

`champollion register-corpus` 会为您编写卡片，并为其分配一个格式为 `eval-<source>-<target>-<name>[-<role>]-v1` 的 ID：

- **name** 来自 `--name`："Ward phrases" 会变为 `ward-phrases`。仅当名称中不包含 a–z 或 0–9 字符时（例如仅用音节文字书写的名称），才会使用发布者名称。
- **role** 说明该数据集的用途：`--role test`、`--role dev` 或 `--role train`。只有在您传入它时，它才会出现在 ID 中。该工具从不臆测角色，因此只有在您明确说明的情况下，留出测试集才会被称为测试集。

```bash
champollion register-corpus --yes --name "Ward phrases" --pair "eng>xyz" \
  --license proprietary --tier private --role test --size 120 --domain medical
```

这将注册 `eval-eng-xyz-ward-phrases-test-v1`。若要自行选择 ID，请传入 `--id eval-…`；它将完全按原样使用。

### 私有测试集该选用哪种许可 ID

`--license` 记录了数据所有者实际授予的条款。它不是占位符，该工具也不会为您代选。请先征得他们的同意（家庭成员、临床医生、社区的数据管理员），然后选择能够准确表达他们要求的 ID：

| 所有者授予的内容 | `--license` |
|---|---|
| 他们已在标准许可下发布该文本 | 其 SPDX ID，例如 `CC-BY-NC-4.0` |
| 仅用于对系统进行评分：绝不用作训练，绝不再分发，不进行付费评分 | `community-eval-grant-nc` (`LicenseRef-Champollion-Eval-Grant-NC`) |
| 同上，但允许为付费用户进行评分 | `community-eval-grant` (`LicenseRef-Champollion-Eval-Grant`) |
| 除其自身使用外不做任何授权：保留所有权利 | `proprietary` (`LicenseRef-Proprietary`) |
| 上述各项未涵盖的自有条款 | `LicenseRef-<a name for their terms>`，按原样输入，且条款记录在管理员保存处 |

表格中的每个 `LicenseRef-…` ID（包括两项评估授权和 `proprietary`）都是定制授权：Champollion 绝不会代表所有者来解读它。在管理员记录其许可之前，针对它的远程评估将被拒绝，因此只有您自己机器上的模型才会针对它进行测试。如果您不确定，既能让您进行度量又是最保守的选择是 `community-eval-grant-nc`；将其记录为临时许可，并让管理员予以确认或指定正确的许可。

许可不会改变句子的去向。无论许可条款如何规定，仅限本地的数据集（`.champollion.json` 标记或 `--tier local-only`）都会保留在您的机器上：该标记会拒绝每个远程模型，而许可绝不能放宽此限制。许可规范了该数据集若被共享后他人可对其执行的操作，以及它可以进入哪些评估通道。一旦使用 `--data` 注册了某个文件，其 ID 就会记录在其旁边的 `.champollion.json` 文件中，并且永不更改。再次注册该文件将会停止，并要求您使用 `--id` 传入该 ID。

对于模型可能会针对其进行训练的测试集（`--role test`，或未指定角色的仅限本地或私有集），该命令随后会打印在对该集合进行首次评分前必须执行的 nmt-forge 步骤：注册它，根据它筛选您的训练语料库，并记下您的预测结果。基准 `mt-eval run` 紧随其后。基准测试是一次评分读取，nmt-forge 会拒绝在评分读取之后写入的预测。

`mt-eval run --corpus <that file>` 通过同一个 `.champollion.json` 文件找到该卡片。运行的数据集 ID 即为该卡片的 ID，因此在该集合上的每次运行都带有相同的名称，并且文件名保留在运行中作为其语料库路径。卡片的污染等级按卡片所述进行报告。两者仅在文件仍为您注册时的原文件时适用：如果此后文件发生过更改，运行会发出提示且二者均不采用。

`local-only`、`private` 或 `sealed` 卡片声明其文本未公开发布（`Contamination: NONE`），因此注册时首先会将您通过 `--data`（或 `--seal-input`）传入的文件与公开语料库进行比对。代码仓库签出（repository checkout）会将其与所持有的语料库卡片进行比对。通过 npm 安装（不包含任何语料库卡片）则会将其与公开语料库目录进行比对：CLI 会下载公开语料库的 ID 和校验和并在您的机器上进行比对，因此您文件的校验和绝不会离开机器。当文件逐字节完全属于公开语料库（相同 sha256）时，注册会停止并指出该语料库的名称。您可以将其注册为公开语料库、使用真正私有的句子，或者保留当前层级并使用 `--contamination` 说明其暴露情况（随后卡片将记录该文本为公开内容）。包含公开文本的封印集将被拒绝：因为这样做没有任何测试意义。

当无法进行比对时（您处于离线状态，或无法访问目录），卡片会被评级为 `Contamination: UNCHECKED` 而非 `NONE`，除非您自己使用 `--contamination` 指定评级。请联网重新注册以进行比对。`mt-eval` 会将 `UNCHECKED` 语料库视为任何未被评为 `LOW` 的语料库：其分数将进入“仅限相对比较”通道。该检查比对的是整个文件，因此经过编辑或重新排版的公开集合将无法被识别；`mt-eval contest prepare` 则按行进行比对。
