## 资金目前的来源

**一个人。** 到目前为止构建的所有内容——工具、CLI、语言索引、基准规范、网站——都由项目创始人自筹资金。我们明确说明这一点有两个原因：

1. **关于规模的诚实态度。** 自筹资金的项目目前还无法为规范所需的语料库构建和使用者验证付费。已公布的费率是关于资金存在时*如何*流动的承诺，而不是它已经在流动的证据。
2. **这是一个公开邀请。** 基础设施已经建成，单位成本已经公布。缺少的是运行它的资金。如果你资助语言技术——作为资助机构、基金会、部门或个人——**我们希望听到你的声音**：在 [GitHub](https://github.com/gamedaysuits/Champollion) 上提交议题或通过 [champollion.dev](https://champollion.dev) 与我们联系。

## 资金的用途

成本已经明确指定，所以资助者可以购买具体、有界的东西：

- **一种语言的语料库参与** — $2,500–6,000 的使用者补偿（$50–65 加元/小时，已公布的费率）构建一个基准语料库，该语料库保持为构建者的财产。参见[使用者如何获得报酬](/docs/network/perspectives/how-speakers-get-paid)。
- **一轮指标验证** — $1,475–1,920 支付三位双语使用者检查自动化指标与人工判断的对应情况。
- **赞助奖项** — 资助一个目标条件（例如，可靠的英语 → 平原克里语翻译）。奖项资金由社区治理的信托基金持有和颁发，按社区的条款——而不是由 Champollion 颁发。参见[奖项规范](/docs/network/specifications/prizes)。
- **计算和 API 额度** — 汇集用于运行公共基准队列。

实际上，这使得网络成为语言数据工作的资金分配机制：资金进入，为构建语料库的人支付工作报酬——他们保留自己构建的内容。

## 资金流向

一旦有任何资金支持——目前尚未持有任何资金：

- **按已公布的费率流向语料库构建者和验证者。** 付款不转移所有权：构建者因工作获得报酬*并且*保持对语料库的管理权。
- **通过社区信托流向奖项获胜者。** 当赞助奖项被领取时，信托基金向开发者支付；该方法按该奖项的条款转移给社区（参见[所有权与条款](/docs/network/sovereignty/ownership-transfer)）。
- **流向基础设施** — 托管、评估运行和维护。
- **公开记账。** 赞助参与被公开记录——资助了什么、按什么已公布的费率、交付了什么——所以赞助商（和其他所有人）可以审计直接通过的承诺是否得到履行。

## Champollion 获得什么

**没有。** 没有收入分成、没有基础设施百分比，也没有对社区资产的所有权声明。如果一个社区部署它拥有的方法——在自己的服务器上、通过自己的渠道、商业性或非商业性——它赚取的一切都是它自己的。在网络中注册的语料库保持为管理者的财产，在任何评估之前、期间和之后都是如此。

如果围绕这项工作出现商业机会，我们对那样的对话持开放态度——但任何这样的安排都将在那时与涉及其数据或方法的管理者协商，按他们的条款。这些文档中没有任何内容是预先承诺的，这里的任何文档都不应被理解为为平台保留任何东西的份额。

## 对于资助者

语言技术的可持续性问题通常是"赠款结束后会发生什么？"对于非商业项目，诚实的答案是：*资产*比资金更持久，因为它们由能够维护它们的人拥有。

| 传统模式 | 管理权模式 |
|---|---|
| 赠款资助研究 | 赠款资助研究 |
| 发表论文 | 构建语料库、测量方法 |
| 赠款结束，工具被放弃 | 社区完全拥有语料库和任何转移的方法 |
| 社区获得无 | 使用者因每小时工作获得报酬；资产留在本地 |

资助者的可衡量成果：

- 构建并注册的语料库，由管理者控制
- 向语言社区交付的已支付使用者工作小时数
- 测量的方法，以及（在奖项条款允许的情况下）转移给社区所有权的方法
- 由可信公共基准覆盖的语言对

参见[基准规范](/docs/network/specifications/benchmark)，第 10 节了解详细的成本模型。
