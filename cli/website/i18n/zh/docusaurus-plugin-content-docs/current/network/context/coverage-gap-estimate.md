# 覆盖率差距：我们如何进行估算

> **内容摘要。** Champollion 的主页上写道，当今世界上有*超过十亿*人无法获得翻译成其第一语言的机器翻译。本页展示了这句话背后的算术逻辑，指出了影响该数字的两个主观判断，并解释了为什么我们发布的是一个保守的下限，而不是更大的原始总数。Champollion 是一个索引，而非权威机构——这里的每一个数据都可以从公开构建版本中推导出来，欢迎指正。

## 我们实际在探讨的问题

不是“有多少种语言缺乏机器翻译（MT）”，而是**有多少人无法获得翻译成其第一语言的机器翻译。** 一个人的第一语言（L1）是他们用来思考、并且最希望用来阅读新闻的语言。双语能力并不会将任何人从这个统计中剔除：一个第一语言是克丘亚语（Quechua）的克丘亚语-西班牙语双语者，仍然无法*用克丘亚语*阅读网页。因此，目标人群是：所有第一语言属于没有任何专用机器翻译引擎支持的现存语言的人。

## 这个数字是如何计算的

包含两个要素，均在代码仓库中：

1. **哪些现存语言拥有机器翻译。** 构建过程将九个被追踪引擎（Google、Microsoft、DeepL、LibreTranslate、NLLB-200、OPUS-MT、M2M-100、MADLAD-400、Tilde —— `shared/catalogue/method-coverage.json`，每个列表均附有引用和日期）的语言列表的并集，与 `data/tc-index.json` 中的 ISO 639-3 *独立现存*语言（`isoType: 'L'`）取交集。结果：在总共 **7,077** 种现存语言中，**有 552 种现存语言被覆盖，6,525 种未被覆盖**（`stats.coverage.dedicatedLiving` / `uncoveredLiving`）。
2. **有多少人使用这些未被覆盖的语言。** 对于每一种未被覆盖的现存语言，我们提取其 `speakerCount`（取自语言卡片中引用的估算值）并进行求和。构建过程将其输出为 `stats.coverageGap`。所有 6,525 种未覆盖语言的原始总和约为 **29 亿**（`uncoveredSpeakerSumRaw` ≈ 2,974,871,273）。

这 29 亿是一个**偏上限**的数字，我们对此直言不讳。

### 为什么原始总和不够纯粹

`speakerCount` 混合了第一语言（L1）和总使用人数（L1+L2），具体取决于每个数据源的报告内容，而且一个多语种使用者可能会在多种语言下被重复计算。明显的迹象是：将*所有* 7,082 种现存语言的 `speakerCount` 相加，大约是 **108 亿**——超过了目前约 81 亿的全球人口（联合国《世界人口展望》）。一个纯粹的 L1 统计数据不可能超过世界人口；而这个数据超过了，这证明该字段并非纯粹的 L1。

## 两个主观判断（都会影响该数字）

**(a) 仅限 L1 与总人数。** 仅限于第一语言使用者会降低估算值——从定义上讲，L2 使用者是*拥有*另一种语言的人。但是，在我们引用的数据源中，并非所有语言都能提供统一的 L1 数据，因此我们无法在不凭空捏造数字的情况下全面应用“仅限 L1”的规则。使用混合统计数据会*推高*估算值。

**(b) 777 种没有报告统计数据的未覆盖语言。** 在 6,525 种未被覆盖的现存语言中，**有 5,748 种包含使用者数据，而 777 种则没有**（`uncoveredWithCount` / `uncoveredNoCount`）。将这 777 种语言搁置一旁——这正是原始总和的做法——会*低估*实际人数，因为这些都是真实的语言，拥有真实的（未被统计的）使用者，其中大多数是小语种和濒危语言。

因此，这两个误差指向相反的方向：L1/L2 的混合导致了夸大，而 777 种语言的尾部数据则导致了缩小。

## 为什么我们报告“超过十亿”的下限

合理的范围是从接近 **10 亿**的下限到原始的**约 29 亿**。即使在大幅扣除 L2 的重复计算*并*撇开整个未统计的 777 种语言尾部数据之后，未覆盖语言的第一语言人口仍然轻松超过十亿。本网站没有将更大、更杂乱的数字作为标题，而是报告了保守的底线。“超过十亿”是我们最有信心经得起推敲的说法。

## 什么会改变这个数字

更精确的估算需要**每种语言的 L1 使用者数据，且每个数据都有引用来源**，这样我们就可以直接对 L1 进行求和，而不是使用 L1/L2 的混合数据，并且可以对目前未统计的 777 种语言进行站得住脚的估算。随着引擎添加更多语言，552 这个数字会上升，差距会缩小；随着语言卡片获得来源更可靠的统计数据，总和会更加精确。这是一个**持续进行的估算**，在每次构建时都会重新计算——而不是一个固定不变的事实。

## 数据来源

- **覆盖率** —— `cli/shared/catalogue/method-coverage.json`（九个引擎，每个列表均附有引用和日期）∩ `cli/website/data/tc-index.json` 中的 ISO 639-3 独立现存语言；呈现为 `stats.coverage.dedicatedLiving` / `uncoveredLiving`。由 Champollion 衍生。
- **使用者总数** —— `tc-index.json` 行上的 `speakerCount`（来自每个语言卡片引用的 `speakerEstimates`），由构建过程求和为 `stats.coverageGap`（`uncoveredSpeakerSumRaw`、`uncoveredWithCount`、`uncoveredNoCount`）。由 Champollion 衍生；根据来源混合了 L1/L2。
- **世界人口** —— 约 81 亿（联合国，《世界人口展望》），仅用作使用者总数的合理性边界。
