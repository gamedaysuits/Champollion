# 联系、异议与下架

> **内容摘要。** 本项目是有意未完成的，并且将永远处于持续开发的状态。如果这里的某些内容有误、具有掠夺性、不尊重社区权利，或者仅仅是解释得不好——我们希望听到您的反馈，并且我们会采取行动。本页面介绍了如何联系我们、我们的承诺，以及如何要求更正或删除某些内容。好的异议能让这个项目变得更好；我们欢迎异议，而不是仅仅容忍它们。

## 适用对象

- **语言社区及其代表**：如果看到此处描述了他们的语言、数据或治理方式，并希望进行更正、删除或交流。
- **研究人员、翻译人员和数据集管理员**：如果他们的工作被引用，并希望修正署名或更改列表信息。
- **任何人**：如果发现了错误、夸大其词或读起来不够尊重的文案。

您不需要注册账号，也不需要具备技术背景。用您自己的话以通俗易懂的语言表达即可。

## 我们的定位（及其对内容更正的意义）

Champollion 是一个**索引，而不是权威。** 语言卡片或 Network 中的每一个事实都引用了来源，并如实报告该来源的实际内容；当来源之间存在分歧时，我们会展示所有来源，而不是选出一个胜者。这种设计对您有一个直接的影响：**如果引用的来源有误，或者我们的表述不佳，这是一个可以修复的缺陷，我们也会将其视为缺陷来处理。** 我们不是在为自己的主张辩护——我们只是试图准确地指向他人的工作以及语言本身。

我们的主权立场是**以数据主权为目标**：在设计上，我们致力于让社区*能够*对其数据及任何衍生内容行使所有权（ownership）、控制权（control）、访问权（access）和占有权（possession）。至于是否*实现*了这一点，则由社区来决定——这正是建立此沟通渠道的原因。

## 如何联系我们

| 您的需求… | 使用方式 | 发送至 |
|---|---|---|
| 提问、提出异议或要求更正 | **网站指南的工单表单**（聊天面板 → "Send a message"），或发送电子邮件 | `info@champollion.dev` |
| 要求**删除**数据、引用或列表信息 | 工单表单（选择 **Takedown**），或发送主题包含 "Takedown" 的电子邮件 | `info@champollion.dev` |
| 报告**安全漏洞** | 电子邮件 | `security@champollion.dev` |

工单表单和电子邮件地址会发送到同一个地方。表单只是持久地记录您的消息，以免在传输过程中丢失；如果您希望得到回复，可以留下回复地址，如果您不愿意，也可以保持匿名。

## 我们的承诺

1. **我们会确认收悉。** 如果您留下了联系方式，我们的目标是快速、用通俗易懂的语言确认我们已收到您的消息，而不会使用法律术语推诿。
2. **下架请求优先处理，且默认采取行动。** 对于我们托管或索引的任何内容，如果权利人或社区要求我们删除，我们的首要态度是删除，而不是争辩。我们从一开始就**不托管任何语料库内容**——语料库仅通过元数据卡片从其来源获取——因此大多数“下架”涉及的是引用、列表信息或卡片字段，我们可以快速更正或撤下这些内容。
3. **未经同意，我们绝不会将任何社区、民族或组织称为合作伙伴或保管人。** 如果您发现您的社区在未经同意的情况下被贴上此类名称，请告诉我们，我们将予以删除。
4. **我们如实记录异议。** 批评和赞美一样值得发表。我们设立“诚实的局限性”页面的目的，正是为了让未解决的问题可见，而不是被掩盖。
5. **我们不会假装分歧已经解决。** 如果我们无法满足您的要求，我们会直言不讳，说明原因，并说明由谁决定——而不是悄悄地置之不理。

## 哪些信息能帮助我们更快采取行动

您不需要提供所有这些信息，但提供它们可以加快处理速度：

- 指向特定页面、卡片或数值的链接。
- 用您的话说明哪里出错了，以及正确的内容应该是什么样。
- 您是代表自己还是代表某个社区或组织发言（对于删除请求，请说明与权利人的任何关系——我们不需要证明，但这有助于我们确定优先级）。

## 此渠道*不适用*于以下情况

- 这里**不是**请求开发帮助、定制脚本或按需翻译的地方——本项目可以为您指明工具，但不会为这里的访问者做工程开发工作。
- 这里**不是**让某种语言获得排名、推广或推荐的途径——Network 的排名仅来自评估运行，绝不会来自请求。

我们真心希望尽早听到异议，而不是让正确的意见保持沉默。感谢您帮助我们保持诚实。
