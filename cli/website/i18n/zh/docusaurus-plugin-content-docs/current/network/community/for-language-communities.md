# 为语言社区服务

> **核心概述。** 您的社群可以拥有自己的测试集——即衡量每种翻译方法的“标准答案”——并完全按照自己的条件举办竞赛，而无需交出任何数据。本页说明了网络对语言社群的诉求（参考翻译、翻译审核、指导数据）、您将获得的回报（一旦资金到位，将按公开费率获得有偿工作报酬——目前暂无储备资金——外加代码所有权和完全的部署控制权），以及放在首位的主权保护措施。无需任何编程知识。部分保护机制已内置于软件和数据库中；其他保护仍属于承诺性质，[坦诚局限](/docs/network/honest-limitations)对此做了具体说明。

您不需要是程序员就能为网络做出贡献。如果您使用土著语言或低资源语言，您是这个生态系统中最重要的人。

---

## 主权优先

在向您提出任何要求之前，先确立一项基本准则：**您的语言数据归您所有。** 语言数据是*生命数据*——它承载着您社群的身份认同与人际关系，无法被有效匿名化——因此提供数据的人掌握着数据的钥匙，以及以此衡量的任何成果的控制权。本网络建立在[原住民数据主权原则](/docs/network/sovereignty/data-sovereignty)的基础之上：

- 我们从不在服务器上收集或存储您的语言数据
- 翻译方法使用 `api` 架构——所有教学数据、词典和语法规则都保留在您控制的基础设施上
- 您决定谁可以为您的语言开发方法
- 排行榜分数证明一种方法有效；它们不授予部署权限

:::note[当前状态]
下面描述的所有权转移模型是一个**既定的设计，但尚未投入运行。** 排行榜已开放提交，目前没有已发布的运行记录，也没有任何方法已转移到社区。我们描述它的构建方式是为了让你能够对我们负责——而不是暗示它已经在进行中。关系和你对数据的权限是首要的；其余的一切都由此而来。
:::

## 拥有您的测试集

社区在这个系统中能够持有的最强地位是**拥有基准本身**。测试集是答案钥匙：谁持有它，谁就决定了该语言的"好翻译"意味着什么，每种方法——我们的、公司的、任何人的——都要对标*您的*标准。

- **注册是元数据，不是内容。** 向网络注册语料库意味着发布描述卡——从不上传语料库。您选择其[曝光通道](/docs/network/sovereignty/registering-corpora)：开放、受限或完全主权。
- **主权基准保持保密。** 在主权通道中，测试集永远不会离开社区基础设施，我们也看不到它。方法在您这一侧对标它进行评分；只有分数会传输。
- **您可以运行自己的竞赛。** 分步指南——[运行主权竞赛](/docs/network/sovereignty/run-a-sovereign-contest)——指导您如何按照自己的条款托管社区控制的评估：您的测试集、您的规则、您关于发布什么（如果有的话）的决定。

这一切背后的保障均有明确书面规定，而非默示：
[数据管理与托管](/docs/network/sovereignty/data-sovereignty)（数据主权/CARE 立场以及明确禁止我们从事的行为）以及
[所有权与条款](/docs/network/sovereignty/ownership-transfer)（当某种方法获胜时，合同层面会发生什么）。

## 我们需要您做什么

### 参考翻译

我们需要用于评估的精选翻译对——一侧是英文，另一侧是您的语言。这些成为所有翻译方法都要对标的"答案钥匙"。

您可能从以下来源创建这些：
- **教育材料**——教科书练习、课程计划、工作表
- **社区文件**——会议记录、通讯、公告
- **日常短语**——UI 字符串、应用标签、常见表达
- **文化内容**——故事、歌曲或描述（获得适当许可）

格式很简单，是 JSON：
```json
{
  "entries": [
    { "id": 1, "source": "Hello", "reference": "tânisi" },
    { "id": 2, "source": "Thank you", "reference": "kinanâskomitin" }
  ]
}
```

### 翻译审查

每种声称能够生成有效翻译的方法都需要人工验证。双语使用者审查输出并告诉我们计算机是否做对了——更重要的是，*为什么*它做错了。

### 教学数据

语法规则、词典条目、形态学模式——这些是使翻译方法有效的语言资源。您对语言工作方式的了解是任何 AI 模型都无法替代的。

## 您获得的回报

### 所有权

当为您的语言构建翻译方法并在网络上验证时，[所有权转移](/docs/network/sovereignty/ownership-transfer)到您社区的治理组织。您拥有代码、模型权重和部署。

### 付费工作，而不是提取

语料库构建和翻译审核属于专业工作，一旦获得资金支持，将按照
[公开费率](/docs/network/perspectives/how-speakers-get-paid)支付报酬
（目前暂无储备资金）——且付费并不意味着购买您的数据。您获得劳动报酬的*同时*，仍是
所构建成果的所有者。Champollion 是一个非商业性研究项目：它
不销售任何产品，不计量计费，并且对于您的社群从其拥有的方法中获得的任何收益，[绝不抽成](/docs/network/sovereignty/economic-model)。

### 控制

您的治理组织控制：
- 谁可以访问该方法
- 它是否可以商业使用——如果可以，按照您的条款，保留它赚取的一切
- 何时以及如何更新它
- 用于进一步开发的数据

## 如何参与

:::tip[母语使用者今天即可做的事情——在社群同意的前提下]
Champollion 不构建也不托管语料库——测试数据始终从源头获取。
如果您的社群中有使用者希望*立即*贡献句子，
[Tatoeba](https://tatoeba.org) 接受任何语言的逐句贡献，
而诸如 [OPUS](https://opus.nlpl.eu/) 之类的开放合集汇聚了本网络用于构建基准的平行文本。
在那里添加的句子可以成为此处的评测数据。

首先需要了解其中的权衡：Tatoeba 在开放许可协议（默认为 CC BY 2.0 FR）下发布句子，
因此任何人都可以复制它们——包括用于训练 AI 模型——且已被复制的内容无法撤回。
对于日常语句而言，这可能是合适的选择。但对于社群希望完全自主掌控的内容，
请自行保管数据，并改用[密封测试集](/docs/network/sovereignty/run-a-sovereign-contest)。
面向使用者的直接贡献应用及语料库构建工具已在规划中，但尚未构建完成。
:::

1. **联系我们** — 在 [Network 仓库](https://github.com/gamedaysuits/Champollion)上提交 issue 或发送电子邮件至 [info@champollion.dev](mailto:info@champollion.dev)
2. **描述您的语言** — 它属于哪个语系？有多少使用者？使用哪些书写系统？现存哪些计算资源（FST、词典、语料库）？
3. **从小规模起步** — 哪怕仅有 50 对精心整理的翻译句对，也足以创建评测数据集并开启一条新的排行榜赛道。语料库工作一旦获得资金支持，将[按公开费率支付报酬](/docs/network/perspectives/how-speakers-get-paid)；目前暂无储备资金
4. **保持自主所有权** — 在您选择的通道中将语料库注册为元数据（[注册语料库](/docs/network/sovereignty/registering-corpora)）；如果您希望测试集完全保密，[主权竞赛操作手册](/docs/network/sovereignty/run-a-sovereign-contest)则是实现路径
5. **引荐治理方** — 在您的社群中，谁对语言数据和技术拥有管辖权威？本网络的主权模式需要一个治理合作伙伴
