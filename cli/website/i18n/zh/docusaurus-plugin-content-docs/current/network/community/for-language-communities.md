# 为语言社区服务

> **执行摘要。** 您的社区可以拥有自己的测试集——每种翻译方法都要对标的"答案钥匙"——并按照自己的条款运行自己的竞赛，无需将数据交给任何人。本页说明网络对语言社区的要求（参考翻译、翻译审查、教学数据）、您获得的回报（按公开费率支付的工作、代码所有权、完整部署控制权），以及首先生效的主权保障。不需要编程知识，这里的任何内容都不需要信任我们：保障是结构性的，而不是承诺。

您不需要是程序员就能为网络做出贡献。如果您使用土著语言或低资源语言，您是这个生态系统中最重要的人。

---

## 主权优先

在我们向您提出任何要求之前，基本规则是：**您的语言数据属于您。** 语言数据是*生物数据*——它承载您社区的身份和关系，无法有意义地匿名化——因此提供数据的人掌握着它的钥匙，以及对标它的任何东西的钥匙。网络建立在[原住民数据主权原则](/docs/network/sovereignty/data-sovereignty)之上：

- 我们从不在服务器上收集或存储您的语言数据
- 翻译方法使用 `api` 架构——所有教学数据、词典和语法规则都保留在您控制的基础设施上
- 您决定谁可以为您的语言开发方法
- 排行榜分数证明一种方法有效；它们不授予部署权限

:::note[当前状态]
下面描述的所有权转移模型是一个**既定的设计，但尚未投入运行。** 排行榜已开放提交，目前没有已发布的运行记录，也没有任何方法已转移到社区。我们描述它的构建方式是为了让你能够对我们负责——而不是暗示它已经在进行中。关系和你对数据的权限是首要的；其余的一切都由此而来。
:::

## 拥有您的测试集

社区在这个系统中能够持有的最强地位是**拥有基准本身**。测试集是答案钥匙：谁持有它，谁就决定了该语言的"好翻译"意味着什么，每种方法——我们的、公司的、任何人的——都要对标*您的*标准。

- **注册是元数据，不是内容。** 向网络注册语料库意味着发布描述卡——从不上传语料库。您选择其[曝光通道](/docs/network/sovereignty/registering-corpora)：开放、受限或完全主权。
- **主权基准保持保密。** 在主权通道中，测试集永远不会离开社区基础设施，我们也看不到它。方法在您这一侧对标它进行评分；只有分数会传输。
- **您可以运行自己的竞赛。** 分步指南——[运行主权竞赛](/docs/network/sovereignty/run-a-sovereign-contest)——指导您如何按照自己的条款托管社区控制的评估：您的测试集、您的规则、您关于发布什么（如果有的话）的决定。

所有这些背后的保障都是书面的，而不是隐含的：
[数据管理](/docs/network/sovereignty/data-sovereignty)（数据主权/CARE 立场及其禁止我们做的事情）和
[所有权与条款](/docs/network/sovereignty/ownership-transfer)（当方法获胜时在合同上发生的事情）。

## 我们需要您做什么

### 参考翻译

我们需要用于评估的精选翻译对——一侧是英文，另一侧是您的语言。这些成为所有翻译方法都要对标的"答案钥匙"。

您可能从以下来源创建这些：
- **教育材料**——教科书练习、课程计划、工作表
- **社区文件**——会议记录、通讯、公告
- **日常短语**——UI 字符串、应用标签、常见表达
- **文化内容**——故事、歌曲或描述（获得适当许可）

格式很简单，是 JSON：
```json
{
  "entries": [
    { "id": 1, "source": "Hello", "reference": "tânisi" },
    { "id": 2, "source": "Thank you", "reference": "kinanâskomitin" }
  ]
}
```

### 翻译审查

每种声称能够生成有效翻译的方法都需要人工验证。双语使用者审查输出并告诉我们计算机是否做对了——更重要的是，*为什么*它做错了。

### 教学数据

语法规则、词典条目、形态学模式——这些是使翻译方法有效的语言资源。您对语言工作方式的了解是任何 AI 模型都无法替代的。

## 您获得的回报

### 所有权

当为您的语言构建翻译方法并在网络上验证时，[所有权转移](/docs/network/sovereignty/ownership-transfer)到您社区的治理组织。您拥有代码、模型权重和部署。

### 付费工作，而不是提取

语料库构建和翻译审查是专业工作，按
[公开费率](/docs/network/perspectives/how-speakers-get-paid)支付——支付不会购买您的数据。您为工作获得报酬*并且*仍然拥有您构建的东西的所有权。Champollion 是一个非商业研究项目：它不销售任何东西、不计量任何东西，并且[不获取](/docs/network/sovereignty/economic-model)您的社区从它拥有的方法中赚取的任何东西的份额。

### 控制

您的治理组织控制：
- 谁可以访问该方法
- 它是否可以商业使用——如果可以，按照您的条款，保留它赚取的一切
- 何时以及如何更新它
- 用于进一步开发的数据

## 如何参与

:::tip[社区使用者现在可以做的事]
Champollion 不构建或托管语料库——测试数据始终从其源头获取。如果你的社区中的使用者想要*立即*贡献句子，[Tatoeba](https://tatoeba.org) 接受任何语言的逐句贡献，而 [OPUS](https://opus.nlpl.eu/) 等开放集合汇总了网络构建基准的平行文本。在那里添加的句子可以在下一次语料库构建时成为这里的评估数据。直接的使用者贡献应用和语料库构建器是我们路线图上的下一个计划步骤。
:::

1. **联系我们** — 在 [Network 存储库](https://github.com/gamedaysuits/Champollion)上开启一个 issue 或发送邮件至 [info@champollion.dev](mailto:info@champollion.dev)
2. **描述您的语言** — 它属于哪个语族？有多少使用者？使用哪些书写系统？存在哪些计算资源（FST、词典、语料库）？
3. **从小处开始** — 即使只有 50 对精选翻译对也足以创建评估数据集并开启新的排行榜轨道。语料库工作按[公开费率](/docs/network/perspectives/how-speakers-get-paid)支付
4. **保持所有权** — 在您选择的通道中将语料库注册为元数据（[注册语料库](/docs/network/sovereignty/registering-corpora)）；如果您希望测试集完全保密，[主权竞赛指南](/docs/network/sovereignty/run-a-sovereign-contest)是途径
5. **连接我们到治理** — 您社区中谁对语言数据和技术有权威？网络的主权模型需要治理伙伴
