# 连接强度

当网络图在两种语言之间绘制一条弧线时，其颜色仅回答一个问题：**该语言对是否确实经过了测量？**

这显然比该地图过去的表达更为克制。在 2026-09-04 之前，弧线颜色由五级强度色阶表示——即在经偶发修正的标度上，最佳翻译质量究竟有*多好*。该色阶已被弃用。本页将解释其背后的数值、为何移除它是坦诚之举，以及该地图当前所表达的内容。

## 问题：原始分数在零处不为零

我们的大多数分数是 **chrF++**（字符 n-gram F 分数，[Popović
2017](https://aclanthology.org/W17-4770/)）——它衡量翻译的字符和词与参考翻译的重叠程度，范围从 0 到 100。

但*随机文本不为零*。每种书写系统都会"免费"提供一些重叠：具有少数不同字符的正字法，或长的可预测词汇，即使"翻译"是无意义的，分数也会明显高于零。这种免费重叠——**机会基线**——因语言而异。在我们的测量中，它的范围从大约 1.6（中文字符）到超过 13（某些拉丁字母和阿拉伯字母脚本语言）。原始 chrF++ 为 14 在一种语言中接近随机噪声，在另一种语言中是真实信号——因此原始 chrF++ **在语言之间不可比较**，按其着色的地图会悄悄地偏袒某些字符系统。

这一问题切实存在，也正是该地图**不对**跨语言强度进行排名的原因。这个问题我们尚未解决。

## 我们构建的修正方法，以及它为何不再用于地图着色

**经偶发修正的 chrF++（cchrF++）** 对分数进行了重新缩放，使得 0 代表*在该语言中*“不优于随机水平”，而 1 代表完美：

```
cchrF++ = (chrF++ − floor) / (100 − floor)
```

基准下限是测量得出的，而非主观假定：针对每种语言，我们仅使用公开的单语文本（从源头抓取且绝不重新分发的 FLORES-200 dev），运行蒙特卡洛估计——将数千个同正字法的随机基准文本与真实参考译文进行评分对比。该基准下限表覆盖 196 种语言，是 Champollion 衍生的一项产物。

**该修正真正确立的结论。** 偶发基线确实存在，在不同文字系统之间的差异可达约九倍，并且完全可以在无需任何人工质量标注的情况下从单语文本中估计出来。减去该基线后，经证实可以剥离简单基线中的随机成分：在芬兰语中直接复制源文本这种作弊手段的原始得分超过 15 分，修正后会降至约 2.5 分，而在大多数语言中则会精确降至零。“被消除的‘偶发成分’”是表层统计数据，而非残留的语义。

**它未能确立的结论。** 它使得 **0** 在每种语言中具有相同的含义，但并没有让 **40** 具有相同的含义。在基线之上，该修正只是一种简单的线性重新缩放；而关于跨语言中相同*质量*会落在相同修正分数的证据，仅在该区间的底部得到了验证。在与人工评估数据集的比对中，在基线确实存在差异的语言上它有所助益，在差异不大的地方则毫无影响；而在一个基准下限普遍偏低的数据集上，它甚至使与人工评估者的一致性走向了*相反*的方向——这是一个我们尚未解决的结果。

使用五级强度色阶为公开地图着色，所断言的内容超出了该证据的支持范围，尤其是在出错影响最为严重的低资源语言上。因此，在进一步的研究解决该问题之前，该色阶已被弃用。

请注意，改用 **原始** chrF++ 着色从来都不是一个可行的选项：原始分数在不同语言之间完全不具备可比性，而这正是构建该修正的全部初衷。二元编码是坦诚的兜底方案，而非退化为更不可靠的妥协。

## 测量在评估层级中的位置

从最可信到最不可信：

1. **人工验证**——由流利的母语使用者评判译文（[使用者验证](/docs/network/specifications/speaker-validation)）。没有任何自动化指标能超越它。
2. **MQM 风格的专家标注**（[多维度质量指标](https://aclanthology.org/2014.tc-1.6/)，Lommel 等人）——WMT 用于黄金标准判定的协议；昂贵、罕见且极其优秀。
3. **自动评分——仅限于单一语言对内。** 原始 chrF++、BLEU、COMET 等指标可用于比较*同一*语言对上的不同系统；关于各项指标跟踪该语言对人工评估的偏差程度，请参阅[指标可靠性](/docs/network/specifications/metric-reliability)。
4. **跨语言强度。** 我们不发布排名。参见上文。

当人工验证和 MQM 级别的结果进入公告板时，它们对同一对的自动分数优先。

## 地图如何绘制它

每个视觉通道恰好传达一个含义：

| 通道 | 含义 |
|---------|---------|
| **颜色** | 已测量。单一颜色，无渐进色阶——弧线仅表示已有运行对该语言对进行了评分，而不体现其质量高低 |
| **虚线 + 暗淡** | 临时状态：测试集低于[显著性底线](/docs/network/specifications/significance)（n &lt; 100），在此区间内 ~5 chrF++ 以内的分差均属于噪声。这是样本量的属性，与任何评估指标无关 |
| **线宽** | 固定不变。已无其他信息需要编码 |

只有**已测量**的语言对才会绘制测量弧线。已注册的语言对——已排队等待测量但尚未评分——显示为微弱的纯色细线，其颜色仅表明*该语言对当前的可达方式*（商业 API · 开源模型 · 前沿模型，无提供商），绝不代表翻译质量的高低。这两种视觉语言被有意区隔开来：柔和的平色细线 = 可达性，唯一的测量颜色 = 已测量。弧线底层的分数是公开榜单上该语言对的最佳测量运行结果，随着新运行的完成自动刷新，并且在打开弧线时显示为语言对内的数值——绝不会作为跨语言排名展示。

## 细则

- 偶发基线是仅从单语文本中估计出的“指标 × 正字法”属性；不涉及也不存储任何平行语料库内容。
- 基线图谱和修正方法仍然作为已发布的研究保留，且代码保留在仓库的测试套件中。它们未接入任何面向公众的界面。
- **它修正的是下限，而非上限。** 真正优秀的翻译能拿多高的分，在不同语言之间依然存在差异，而该修正对此无能为力。
- **它无法防范同文字系统的直接复制作弊。** 当源语言和目标语言共享相同的文字系统时，简单复制源文本的输出仍可能得分高于偶发基线。
- **它无法重新排列单一语言对内的系统顺序。** 在基线之上，该修正属于纯粹的线性重缩放，因此同一语言对内的系统排名在修正前后完全相同——它唯一可能的价值在于跨语言对的比较。
- 一条已测量的弧线仅说明该语言对已经过评分。它**并不**验证语义、语域或文化契合度。这些仍需由人工进行评判（[坦诚的局限性](/docs/network/honest-limitations)）。
- 偶发基线方法是 Champollion 的研究成果，在此公开发布正是为了方便接受检验和质疑。
