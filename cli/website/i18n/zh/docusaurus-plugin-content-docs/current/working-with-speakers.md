# 与母语者合作

任何翻译器项目中最宝贵的部分都不是计算机。而是那些使用这种语言的人——他们撰写句子、校对初稿，并指出*“不，我们会这样说。”*如果你就是这样的人，本页内容正是为你而写，也是为你身边的合作者编写的。

## 征求每个人的意见

每一个句子都出自某个人。在翻译器从任何人的话语中学习之前，请先征得他们的同意——或者，如果无法做到，请征求有权代表他们做决定的人的意见。

- **用通俗易懂的语言告知**这些句子的用途、谁会看到它们，并说明他们完全可以拒绝。
- **记录下来。** 轨道系统预留了记录协议的位置：谁在何时同意了什么。每个文件旁的注释都会记录母语者是否同意——*yes*（同意）、*not yet*（尚未同意）还是 *some said no*（有人拒绝）——工具会严格遵守这一记录。
- **“尚未同意”也是完全可以接受的答复。** 轨道系统会将这些句子暂搁一旁并继续运行，稍后再行询问。
- **当某人已经离世**，他们留下的话语应由其家人和社区决定如何处置，绝不能擅自做主。
- **人们随时可能会改变主意。** 请为他们提供方便的途径。

## 尊重他们的时间

校对翻译是一项实打实的工作。轨道系统在安排任何工作之前，都会先询问母语者能投入多少时间，并据此调整每轮校对的工作量，绝不强求更多。如果时间看起来不足以达成你的目标，系统会如实说明，以便大家共同做出决定——或者通过 [加入项目](/docs/join-a-project) 寻找更多帮手。

短时间的校对比长时间的效果更好。疲惫时校对会变得更加吃力，而勉强给出的*“对”*会教给翻译器错误的内容。随时都可以将草稿标记为 **?**——即*不确定*。

## 署名与报酬

- **按照当事人的意愿给予署名**——署个人姓名、家族名称、社区名称，或者完全不署名。务必询问。
- **为母语者付出的时间支付报酬是理所应当的**，在你的项目中，这由项目负责人决定。Champollion 不会对社区获得的任何报酬进行抽成，赞助商提供的任何款项都会全额直接转交。

## 神圣与受限的词语

有些词汇并不适合向所有人公开：仪式用语、神圣故事，以及只有特定人员可以说、或只能在特定时间说的话。**请将它们排除在外。** 翻译器可以随时向任何人重复它所学到的内容——因此，如果不应该外传的话，就不应该教给它。

当你不确定时，请向知情人士请教；在确定之前，请勿收录。收录的标准是积极明确的同意，而不是“无人反对”。

## 确定拼写方式

如果大家书写该语言的方式各不相同，翻译器学到的就会是一团混乱。在开始之前，请为项目商定一种拼写方式——例如学校采用的系统，或社区通用的标准——并注明这些句子来自哪种方言。工具目前还不会为你检查拼写，因此这需要由人工做出决定，确定一次并记录在案。

## 校对初稿

当轨道系统向母语者交付一份初稿清单时：

- **Y** —— 初稿正确，正是你会用的表达方式。
- **N** —— 初稿有误。接着写下你*会*怎么说。这种修正句是最有价值的句子：它准确指出了翻译器出错的地方。
- **?** —— 不确定。这完全没关系。

初稿可能本身正确，但与你个人的习惯表达有所不同。只要本身正确就标记为正确；如果你有更好的表达方式，可以写下来。

从第二轮开始，表格中会特意重复之前出现过的几行——
表格上会注明有重复，但不会指出是哪几行。请当作全新的内容重新打分。没有人
两次打分能完全一致，这很正常：评分一致的频率，只是为了
让大家了解结果有多大程度值得信赖。
