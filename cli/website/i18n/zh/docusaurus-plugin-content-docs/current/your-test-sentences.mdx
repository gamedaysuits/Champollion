# 预留测试句

在翻译模型学习任何内容之前，你需要预留几句话用来测试它。这是轨道规范中最关键的一步。你所见到的每一项结果都是基于这些句子来衡量的——因此如果测试句有误，所有的结果就都不可信了。

## 为什么这很重要

想象一下用作业里的原题去考学生。他们会显得非常优秀，但你根本无法了解他们的真实水平。翻译模型也是如此。如果用它学习过的句子进行测试，它只不过是记住了答案而已。

因此，测试句必须单独存放：绝不让任何翻译模型从中学习，它们仅用于评判效果。

## 挑选优质的测试句

- **经母语流利者核对。** 每个句子及其译文都应当准确，符合你们社区的地道表达习惯。
- **你真正希望翻译的真实句子。** 家常对话、便签留言或课堂教学中所用的日常用语——也就是该翻译模型真正服务的那类句子。
- **句型多样。** 疑问句、陈述句、请求句；短句和较长的句子兼备。
- **切勿照搬用于教学的句子。** 重新编写，或从独立的来源获取。
- **拼写方式与其他内容保持一致。** 在开始之前，就该语言的拼写规范达成共识。
- **在核对人员能力范围内尽可能多。** 几十句是一个开始；句子数量太少时，每次测得的结果都比较粗糙，工具会给出一个宽泛的区间而非单一数值。几百句则能让你察觉更细微的差异。

## 轨道机制如何保护测试句

你将它们放入专属位置——测试架（test shelf）——工具便会对它们进行标记：

- 私有：保存在本机上，除非数据持有者另作决定；
- 绝不用于学习；
- 不会出现在工具打印或输出的内容中。

随后，在教学开始前，翻译模型用于学习的每一个句子都会与测试句进行比对核查。完全重复和高度相似的句子都会被单独剔除，防止模型因死记硬背而获得虚高的成绩。

而且训练工具每次对测试句打分时，都会记录在案。在日常工作中，进展是通过另一组独立的**练习句**来评估的，从而让测试句在关键时刻始终保持“全新未见”的状态。

## 你将看到的内容

在记录的演示流程（以虚构句子为例）中，该家庭预留了 <WalkFact of="test.pairs" /> 个经过核对的句子。当工具拿其他句子与它们比对时，发现其中有 <WalkFact of="twins.n" /> 个（约占百分之 <WalkFact of="twins.pct" />）在打算用于教学的句子中存在高度相似的版本。在教学开始前，这些高度相似的句子均已被单独剔除。若没有这一步，最初的分数看起来就会虚高。

## 稍后共享测试集

你的测试句可以永久保存在你的电脑上——这是默认设置。如果你希望其他人也能用它们来进行评估衡量，工具可以在以下四个级别之一注册该测试集：

- **仅限本地（Kept here）**——绝不注册；任何内容都不会离开这台电脑。
- **私密列出（Listed privately）**——仅共享该测试集的描述，绝不共享句子本身。可以在无人看到实际数据的情况下发布评估结果。
- **公开列出（Listed publicly）**——提供描述，以及指向该测试集已公开发布位置的指针。仅适用于许可证允许的测试集。Champollion 绝不会托管这些句子。
- **封存（Sealed）**——用密钥锁定在你的电脑上，以便其他人在完全无法查看数据内容的情况下，使用它来测试其翻译模型。
