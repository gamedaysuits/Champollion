**Champollion** 以让-弗朗索瓦·商博良命名，他在 1822 年破译了埃及象形文字，使一套书写系统重新为世人所读。这是我们采用的隐喻：恢复对意义的访问权，按照语言本身的方式来阅读它。

我们不能只取名字而忽视它的历史。

Champollion 曾在殖民体制内工作。让他实现突破的罗塞塔石碑作为战利品流入欧洲，至今仍是存在争议的财产。在他自己于 1828 至 1829 年前往埃及的考察中，他从塞提一世（Seti I）的陵墓中切割下一块壁板并运回法国，如今它仍存放在卢浮宫；他的同行 Ippolito Rosellini 则将第二块壁板带到了佛罗伦萨。而“破译”本身也可以是一种挪用行为——一个局外人宣称对一个族群的语言拥有权威。我们将这一点坦率道出。我们无意粉饰它。

我们从商博良那里保留的是方法，而不是这个人：相信一种语言及其书写系统值得按照自身的方式被理解，而且进行访问工作是值得好好做的。我们拒绝侵占——我们构建这个工具就是为了与之相反。

那种方法非常具体。Champollion 是通过科普特语（Coptic）来解读这种文字的——那是埃及语的最后一个阶段，在科普特教会的礼拜仪式中得以延续。罗塞塔石碑上的希腊文给了他名字；而活生生的传统则赋予了他语言。这就是我们所坚持的立场：承载一门语言的人群是唯一的切入途径，一切工作都要通过他们来进行。

## 工具如何反转侵占

- **我们不占有和保留。** 语料库直接从源头获取，绝不由我们托管。我们只保留元数据，绝不保留属于他人的语言。
- **所有权留在社区手中。** 我们的构建面向原住民数据主权原则——即社区对语言数据的所有权与控制权——至于我们是否达标，由社区来判定，而非我们自己。对于密封的评估数据，目前密封数据集的密钥由组织者持有——即由组织它的任何一方持有——而 Champollion 不持有任何密钥分片。该设计允许社区选定的保管人在门限方案下持有密钥；社区密钥保管人——目前尚未指定。
- **我们衡量翻译的效果；我们不收集语言。** Network 报告特定语言对的翻译效果。它不是一个陈列战利品的展柜，容易获得或范围不当的数据严禁参与排名。
- **我们向这项工作所依凭的人们致敬**——语言学家、母语使用者以及语料库构建者——凡是同意署名的人，我们均具名致谢；凡是未同意的人，我们绝不透露其姓名。
- **知情同意可撤回。** 母语使用者拥有自己的评判，并可随时将其撤回。

我们不是一个原住民组织，这个名称本身就说明了这一点。我们为社区开展的任何工作均以服务身份进行，并且唯有在取得其同意的前提下才会展开（目前尚无社区与我们合作）——一个带有此名称的非原住民项目，必须去赢得信任，而不是单方面主张信任。我们随时准备接受审视，并欢迎批评。如果社区认为这个名称造成了伤害，可以直接向我们提出，我们必当倾听：请发送邮件至 [info@champollion.dev](mailto:info@champollion.dev)。
