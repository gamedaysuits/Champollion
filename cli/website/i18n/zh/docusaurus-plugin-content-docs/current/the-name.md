**Champollion** 以让-弗朗索瓦·商博良命名，他在 1822 年破译了埃及象形文字，使一套书写系统重新为世人所读。这是我们采用的隐喻：恢复对意义的访问权，按照语言本身的方式来阅读它。

我们不能只取名字而忽视它的历史。

商博良在殖民企业内部工作。使他的突破成为可能的罗塞塔石碑作为军事战利品传入欧洲，至今仍是有争议的财产。在他 1828-29 年的埃及远征中，他让人从塞提一世陵墓中切割出墙板并运往法国，那些墙板至今仍在那里。而"破译"本身可能是一种侵占行为——局外人声称对一个民族的语言拥有权威。我们明确指出这一点。我们对粉饰它不感兴趣。

我们从商博良那里保留的是方法，而不是这个人：相信一种语言及其书写系统值得按照自身的方式被理解，而且进行访问工作是值得好好做的。我们拒绝侵占——我们构建这个工具就是为了与之相反。

## 工具如何反转侵占

- **我们不索取也不保留。** 语料库从其源头获取，我们从不
  进行托管。我们只保留元数据，而不保留他人的语言。
- **所有权归属于社区。** 我们朝着原住民数据主权原则努力
  ——语言数据由社区拥有和控制——我们是否达到了这些标准，由社区来决定，而不是我们。
  对于密封的评估数据，密钥由社区保管人通过多重签名机制
  持有——我们不持有任何份额。即使我们不复存在，控制权
  依然留在社区手中。
- **我们衡量置信度；我们不收集语言。** Network 报告特定
  语言对的翻译效果。它不是一个陈列战利品的橱窗，
  过于简单或范围不当的数据会被排除在排名之外。
- **我们向支撑这项工作的人们致敬**——在任何地方，我们都会实名
  提及语言学家、母语者和语料库构建者。
- **同意是可撤销的。** 母语者拥有他们判断的所有权，并可以随时
  撤回。

一个使用这个名字的非原住民、非商业项目，必须去赢得信任，
而不是强行主张信任。我们期待受到审视，欢迎批评，并与我们服务的社区一起，
对这个名字——以及这项工作——保持持续的审查。
