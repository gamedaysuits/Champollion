**Champollion** 以让-弗朗索瓦·商博良命名，他在 1822 年破译了埃及象形文字，使一套书写系统重新为世人所读。这是我们采用的隐喻：恢复对意义的访问权，按照语言本身的方式来阅读它。

我们不能只取名字而忽视它的历史。

商博良在殖民企业内部工作。使他的突破成为可能的罗塞塔石碑作为军事战利品传入欧洲，至今仍是有争议的财产。在他 1828-29 年的埃及远征中，他让人从塞提一世陵墓中切割出墙板并运往法国，那些墙板至今仍在那里。而"破译"本身可能是一种侵占行为——局外人声称对一个民族的语言拥有权威。我们明确指出这一点。我们对粉饰它不感兴趣。

我们从商博良那里保留的是方法，而不是这个人：相信一种语言及其书写系统值得按照自身的方式被理解，而且进行访问工作是值得好好做的。我们拒绝侵占——我们构建这个工具就是为了与之相反。

## 工具如何反转侵占

- **我们不占有亦不保留。** 语料库均直接从其源头获取，绝不由我们托管。我们只保留元数据，而非他人的语言。
- **所有权归属于社区。** 我们遵循原住民数据主权原则进行构建——即语言数据归社区所有并由其控制——而我们是否做到了这一点，由社区决定，而非我们。对于封存的评测数据，其方案设计是通过门限安排将密钥交由社区保管人掌控，我们持有零份额；目前尚未指定任何保管人。即便我们不复存在，控制权仍留在社区手中。
- **我们衡量翻译效果，而非收集语言。** Network 报告给定语言对的翻译效果。它不是陈列奖品的展柜，任何过于简单或范围界定不当的数据均禁止参与排名。
- **我们致谢这项工作所依托的人群**——语言学家、母语者和语料库构建者——只要他们同意署名，我们便会具名致谢，且绝不会提及任何未同意署名者的姓名。
- **知情同意可随时撤回。** 母语者拥有其评判结果的所有权，并可随时撤回。

使用这一名称的非原住民、非商业项目必须去赢得信任，而非自恃信任。我们期待各方审视，也欢迎批评。如果有社区认为该名称带来了伤害，可以告知我们，这一反对意见定会被认真倾听：请发送邮件至 [info@champollion.dev](mailto:info@champollion.dev)。
