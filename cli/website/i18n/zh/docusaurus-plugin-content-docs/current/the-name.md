**Champollion** 以让-弗朗索瓦·商博良命名，他在 1822 年破译了埃及象形文字，使一套书写系统重新为世人所读。这是我们采用的隐喻：恢复对意义的访问权，按照语言本身的方式来阅读它。

我们不能只取名字而忽视它的历史。

商博良在殖民企业内部工作。使他的突破成为可能的罗塞塔石碑作为军事战利品传入欧洲，至今仍是有争议的财产。在他 1828-29 年的埃及远征中，他让人从塞提一世陵墓中切割出墙板并运往法国，那些墙板至今仍在那里。而"破译"本身可能是一种侵占行为——局外人声称对一个民族的语言拥有权威。我们明确指出这一点。我们对粉饰它不感兴趣。

我们从商博良那里保留的是方法，而不是这个人：相信一种语言及其书写系统值得按照自身的方式被理解，而且进行访问工作是值得好好做的。我们拒绝侵占——我们构建这个工具就是为了与之相反。

## 工具如何反转侵占

- **我们不索取，也不保留。** 语料库直接从其来源获取，绝不由我们托管。我们只留存元数据，绝不留存属于他人的语言。
- **所有权始终归社区所有。** 我们致力于践行原住民数据主权原则——即社区对语言数据的所有权与控制权——而我们是否达成这些原则，由社区来评判，而非我们自己。对于封存的评估数据，架构设计通过门限机制将密钥交由社区保管人掌管，我们在其中不持有任何份额；目前尚未指定保管人。即使我们不复存在，控制权仍归社区所有。
- **我们衡量翻译表现，而非收集语言。** The Network 报告特定语言对的翻译效果。它不是陈列战利品的展柜，过于简单或范围界定不当的数据均不得参与排名。
- **我们向奠定这一切的人致谢**——包括语言学家、母语使用者和语料库构建者——在所有地方实名致谢。
- **知情同意可撤回。** 母语使用者拥有其评判的所有权，并可随时予以撤回。

一个冠以这一名称的非原住民、非商业项目，必须去赢得信任，而非自封信任。我们准备好接受审视，欢迎批评意见，并将与我们所服务的社区一道，持续对这个名称——以及这项工作本身——进行审视。
