# Champollion 是什么

**Champollion 致力于为那些无人问津的语言评估机器翻译质量，并公开发布其评估结果。**

这就是我们的核心理念。本网站上的所有内容，要么是执行此类评估的工具，要么是这些评估结果构建的图谱，要么是我们遵循的规则。

---

## 问题所在

世界上大约有 7,000 种现存语言。对于其中的大多数语言，你都无法回答一个基本问题：*如果我需要翻译这种语言，目前最好的方法是什么？它的质量是否足以投入使用？*

不是问“哪家公司有演示（demo）”。而是问哪种方法——人类译者、基于规则的系统、提示词驱动的语言模型，还是经过训练的模型——能真正适用于**这个语言对、这种类型的文本**，以及你如何验证这一点。

对于英语↔法语，这个问题已经被回答了一千次。但对于英语↔Plains Cree，或者 Ayta Abellen，以及其他数千种语言，这个问题通常从未被提出过。人们总是宣称支持了多少种语言（Coverage），却极少展示实际的翻译质量。

因为没有人进行评估，所以没有人能分辨出什么是真正的技术进步，什么是公关宣传——而那些希望使用这项技术的社区，也无从检验将他们的语言托付给这些技术是否安全可靠。

## 我们的解决方案

我们不是在构建翻译引擎。大型科技公司才会构建引擎。我们构建的是用来告诉你某个引擎是否有效的工具：

1. **在测试集上运行某种方法**并对其进行评分，对每种方法和每种语言都采用相同的流程。
2. **发布结果**及其出处——使用了什么数据、什么方法版本、什么评估指标，以及花费了多少成本。
3. **不断重复，直到图谱成型**：哪些语言与哪些语言相连，连接强度如何，以及哪里还存在空白。

诚实地指出“目前还没有适用于这个语言对的方法”也是我们会发布的结果。目前图谱上的大部分区域都是这个答案，而说出这一点正是我们的目的——一个清晰可见的空白，就是一个可以吸引资金或等待填补的空白。

## 我们遵循的规则

这些是约束条件，而不是营销话术。它们决定了软件能做什么。

**我们从不持有你的语料库。** 注册测试集是通过指向它们已有的存储位置来实现的，而不是将它们上传给我们。一种方法会在我们从未拥有过的语料库上进行评分。对于封闭的测试集，数据在离开你的机器之前就会被加密，只有达到法定人数的社区密钥保管人共同授权，才能运行测试。

**语言数据被视为生物数据。** 提供语料库的人掌握着该语料库的密钥，以及任何基于该语料库进行评估的密钥。我们必须征求同意，而不是想当然地认为已经获得同意——并且这种同意是可以撤回的。

**我们以数据主权为目标，而非宣称已获认证。** 一个项目是否真正实现了语言数据由社区拥有和控制，并不是该项目自己说了算的。我们诚实地开展工作并描述机制；最终的决定权属于相关的社区。

**欢迎任何方法，无论是人工还是机器。** 专业的翻译人员、基于 FST 的规则系统、提示词驱动的前沿模型以及微调的 NMT 模型，都会在同一个测试集上以相同的方式进行比较。我们关心的是如何将语言翻译出来，而不是哪个工具获胜。

**我们公开我们做不到的事情。** 请参阅[诚实的局限性](/docs/network/honest-limitations)——这是本项目目前*尚未*声称能做到的事情列表。在信任这里的任何其他内容之前，请先阅读它。

## 组成部分及其用途

| 如果你想… | 使用 | 它是什么 |
|---|---|---|
| 翻译应用或网站 | **[Champollion CLI](/docs/intro)** | 一条命令即可翻译你的本地化文件；你可以为每个语言对选择翻译方法。 |
| 对方法进行评分，或复现评分 | **[MT-Eval Harness](/docs/network/specifications/harness)** | Python 评估引擎。本网站上的每一个数据都出自于它。 |
| 提交结果，或举办竞赛 | **[The Arena](/docs/network/getting-started/submit-a-method)** | 提交入口、数据库和竞赛机制——评估发生的地方。 |
| 查看关于某个语言对的已知信息 | **[The Network](/docs/network/)** | 评估结果构建的图谱：覆盖范围、连接强度、路由，以及下一步要评估的队列。 |
| 查找一种语言 | **[The Atlas](/languages)** | <SSOTCount field="catalogLanguageCount" /> 语言卡片——分类、音系、活力以及现有的资源。每个数值都标明了出处。 |
| 诚实地训练模型而不自欺欺人 | **[NMT Forge](/docs/network/getting-started/training-honestly)** | 一个训练套件，其护栏机制从结构上杜绝了标准的自欺欺人行为（如测试数据泄露、不具代表性的数据划分）。 |
| 作为 AI 智能体参与此项目 | **[Agent Guide](/docs/network/getting-started/agent-guide)** | 工具、MCP 服务器，以及机器可读端点包含的内容。 |

**Champollion 是一个索引，而不是仲裁者。** 每个数值都标明了出处，并如实报告该出处的实际内容。当不同来源存在分歧时——在母语人数上这种情况非常普遍——卡片会展示所有来源并注明出处。我们不会挑选一个获胜者，也不会人为制造共识。

## 名称由来

Jean-François Champollion 利用罗塞塔石碑（Rosetta Stone）破译了埃及象形文字——同一段文本使用了三种文字。平行文本至今仍是学习翻译的方式。这个名字也带有一种值得大声说出来的张力：在一个掠夺的时代，一位欧洲学者阅读着别人的文字。我们一直在思考这个问题。这就是为什么上述主权规则是软件中的硬性约束，而不仅仅是宣传册上的一页纸。
