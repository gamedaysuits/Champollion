# 这是什么

主流翻译应用忽略了世界上绝大多数语言，或者翻译得错漏百出。如果你的语言也在其中，你可以利用自己的家庭或社区已有的句子、词表和故事，在自己的电脑上构建属于你自己的翻译器。

AI 助手可以引导你完成每一步，而关键的决定始终由你做出。在每一步中，你都会清楚它的翻译与母语者的实际表达有多接近——而重要的成果都会在经母语者核对过的句子上进行测试。

## 你的初始素材

任何你现有的素材：

- 包含句子及其译文的表格，
- 词表或词典，
- 老师的讲义，或有人记录下来的录音文本，
- 以及最宝贵的财富：一位懂这门语言并能核对翻译结果的母语者。

还没有任何书面记录？只要有一位母语者就足以开始。[开始之前](/docs/before-you-begin)会向你展示如何着手。

你不需要预先转换任何格式：这些工具可以直接读取电子表格、Word 表格和词典文件。它们还会指出看起来有误的行——比如译文串行、两列互换、同一句子重复出现——同时不会更改任何内容，以便由了解这些数据的人来做决定。

## 运作流程

你创建一个项目，工具会循序渐进地引导后续流程：导入你的句子，留出一部分用于测试，训练你的第一个翻译器，试用它，并让它变得更好。

你的 AI 助手负责处理繁琐的细节。每当遇到需要你决定的事项时，它都会停下来询问：这些话语属于谁、翻译器是否可以从中学习、是否需要安装软件，以及达到何种程度才算足够好。类似的事情绝不会擅自替你做主。

该助手需要在你的电脑上运行，比如 AI 助手的桌面应用——手机应用无法运行这些工具。大多数助手会把读取到的内容发送给运营它们的公司，因此这些工具只会告诉你的助手私有文件中有*多少*个句子，绝不会透露句子本身的内容——不过，能够操作你电脑的助手也可以自行打开文件。如果有些话语必须保持私密，请不要让你的助手打开这些文件。[你的语言，你的规矩](/docs/your-words-your-rules)对此有详细说明。

## 最终产出

一个运行在你本地电脑上的翻译器。你可以在网页浏览器中试用它，用它来起草初译，并且——当你认为它已经就绪，且语言的所有者也同意时——将它集成到应用或网站中。

**你的第一个翻译器可能类似于一本常用语手册：** 擅长翻译与它学过的类似的句子，遇到新内容则表现不稳定。每个项目都是这样起步的。接着，它会一轮又一轮地成长。母语者会标出初译的对错，工具会提示接下来最有助于提升的句子类型，并且每一轮都会告诉你它是否真正得到了改进。

目前还没有哪个社区在这套轨道流程上把一门真实的语言完整做成一个可用的翻译器。如果你现在开始，你将是首批开拓者之一。[它目前还做不到的事](/docs/what-it-cant-do-yet)会告诉你大致的预期。

## 适用对象

家庭、教师、语言保护项目、社区办公室以及为他们提供帮助的人员——任何拥有主流翻译工具尚未支持的语言的人群。它的设计初衷是服务于低资源语言和原住民语言社区：那些书面语料匮乏的语言，以及有权自主决定如何使用自身语言文字的族群。

## 成本核算

这些工具对家庭、学校、慈善机构以及医院等公共服务机构免费开放。如果母语者社区希望将其用于商业用途（例如语言应用、付费服务），只需提出申请，即可免费获得许可。

你需要一台电脑。任何近期出产的电脑都可以开始。配备 16 GB 内存的较新 Mac（搭载 M1 或更新芯片），或者配备 16 GB 显存 NVIDIA 显卡的电脑，可以构建更强大的翻译器——若是 8 GB，则可以构建轻量版本。（在 Windows 上，训练工具运行在 WSL 中，即 Windows 内置的 Linux 环境。）其他电脑构建的模型规模要小得多。如果你使用 AI 助手，可能还会产生助手本身的费用。

## 这不是什么

它不是一个你今天输入文字就能立刻得到翻译的应用。它是供你亲手打造翻译器的工坊。它并不承诺你的翻译器一定会表现优异，但它保证你始终清楚它处于什么水平，以及如何能让它变得更好。

该名称源于 Jean-François Champollion，他借助科普特语（Coptic）破译了古埃及圣书体象形文字——科普特语是埃及语的最终形态，至今仍留存在科普特教会的祈祷文中。一门仍然活着的语言，最终成为了破解历史谜团的钥匙。[为何取这个名字](/docs/the-name)。
