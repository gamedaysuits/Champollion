# 逐轮改进

你的第一个翻译器只是起点，而不是终点。从这里开始，它将**逐轮**成长。在每一轮中，母语使用者会检查它翻译的内容，你添加最有帮助的句子，然后它再次进行学习。每轮结束时，你都会收到一份简报：有哪些变化、工具的确定程度有多高，以及下一步该怎么做。

这是整套流程的核心。这也是母语使用者的宝贵时间能发挥最大作用的地方。

## 第一轮之前：需要多少时间？

轨道首先会询问母语使用者能够投入多少时间——每周能花多少，总共能花多少。每一轮的规模都会据此调整。一旦几轮之后显现出趋势，轨道就会如实告诉你这些时间大概能换来什么成果，包括在时间看似不足时也会如实相告。它绝不会催促索要更多时间。母语使用者的时​​间属于他们自己。

## 完整的一轮

1. **愿望清单。** 工具会查看翻译器在哪些地方出错，并生成一张可打印的表格，列出最有帮助的内容：它从未见过的词——每个词要求提供两到三个句子，因为只见过一次的词很难学会——以及容易让它卡壳的句子类型。表格留出四分之一的空白，以便你依然能写下*你*所需的内容。你可以完全按自己的意愿使用它，想用多少就用多少。
2. **你的句子。** 写下 20 个或更多你真正希望翻译的句子——比如你在家里会说的话、便签里写的字，或在课堂上教授的内容。数量以说话人这周能核对的为准。
3. **翻译器生成草稿。** 它为每个句子生成翻译，写进给说话人的表格中。当练习句子还很少时，某些行不会有草稿——在达到 50 个练习句子前是每两行空一行，在达到 200 个前是每四行空一行。说话人填写这些空行，它们会变成新的练习句子（绝不用作学习材料）。
4. **说话人核对。** 对每一份草稿：如果正确填 **Y**；如果错误填 **N**，并写下应该怎么表达；如果不确定填 **?**。可以在电子表格中打开核对，也可以打印出来核对后再把标记输入进去。

   从第二轮开始，大约有十分之一的行是特意从之前的表格中抽回的——表格顶部会对此做出说明，但不会标明是哪些行。
   请把它们当作全新内容重新标记。标记的一致程度能告诉大家这些结果有多值得信赖。核对这些行每行只需几秒钟，而且它们绝不会计入本轮的结果。
5. **工具读取标记。** 它们会统计有多少草稿是正确的。修正后的句子以及标记为正确的草稿，在明确归属人（就像任何文件一样）之后，就会成为供翻译器学习的新句子。
6. **评估报告。** 见下文。
7. **再次学习。** 经你同意后，翻译器会根据迄今为止的所有内容进行学习——通常基于你正在使用的模型继续训练，因此一轮训练花费的时间比初次教学更短。新模型会与你正在使用的模型在同一批练习句子上逐句比对。只有当它的改进超越了偶然巧合时，导轨才会将其推荐给你——而且只有在你确认同意后，它才会接管上线。否则，你正在使用的模型将保持不变，并开启下一轮。在练习句子少于 50 个时，没有评分能够判断哪一个更好——所以工具不会妄作猜测。你正在使用的模型将保留，改由说话人来决定（见下文）。

## 轮次报告

每份报告首先呈现进展，接着是检查结果，最后是后续行动：

- **说话人标记为正确的草稿比例**——最重要的数字——附带一个表示工具确信程度的区间范围。
- **练习评分**——百分制分数，衡量翻译器在从未学过的练习句子上的接近程度——以及新翻译器是否真正胜过了旧翻译器。
- **检查是否只是死记硬背**——练习句子上的提升是否也体现在新句子上。
- **标记的可信度**——一旦重复出现的十行内容被完成标记：说话人以相同方式标记它们的频率，以及曾经被标记为错误的草稿现在是否更常被标记为正确（随着任何人逐渐习惯某种翻译器，这种情况都可能发生）。这怪不得任何人，而且非常值得了解。
- **距离“达到可用”还有多远**——一旦提升确凿，每当你的句子数量翻倍时，预估还需多少句子和工时的一个区间范围。该范围还会将说话人标记的可信度考虑在内。
- **接下来要做的两到四件事**——例如*用这些词造句*、*标记这张表格*、*尝试更强大的翻译器*，或*通过“加入项目”寻求帮助*。

你的助手被要求如实传达这一切以及每个数字的含义，只为工具实际测得的进步喝彩，并且在结果确实如此时坦诚说明*“无明显可测量的变化”*。即使某一轮没有可测量的变化，也依然有价值：当前使用的翻译器继续保留，而你也清楚当下所处的阶段。

## 母语使用者在不知情状态下盲测

有两个节点会对你自己的句子进行盲测检查：

- **在你启用新翻译器之后**，下一份表格会将其初稿与被替换翻译器的初稿混排在一起——随机抽取，不加标签。只有当说话人自己的标记也认可时，评分的上升才算作真正的进步。
- **当练习句子无法得出结论时**——少于 50 个句子，或者本轮没有显示出可衡量的变化——下一份表格中会有一半的初稿来自新翻译器。如果说话人明确更喜欢新版本，系统流程会建议启用它（仍需你点头同意），并且报告中会注明它是根据说话人的标记选出的。

无论哪种情况，母语使用者都以相同的方式标记每份草稿，且无需知道草稿是由哪个翻译器生成的。

## 当逐轮迭代停滞不前时

连续两轮没有看到明显提升，并不意味着这些轮次失去了效果。一旦翻译器达到了相当不错的水准，单轮带来的增益可能会微小到练习句无法清晰体现。报告会坦诚说明这一点——当前无法区分微弱提升与毫无提升——并指出更快推进的途径：换用更强大的翻译器，或者针对它容易出错的句子类型补充更多句子。

如果你是从较小规格的翻译器开始，而你的电脑有能力训练更强大的类型，且自上次更换翻译器以来连续两轮都没有可衡量的提升，系统流程就会建议切换。（练习句子太少而无法判断的轮次不算在内。）大模型下载体积更大，训练时间也更长，因此系统流程会询问：*同意*，还是*暂不*。如果你同意，它就会根据你拥有的全部内容进行学习，并且只有在其明显更好时才会推荐给你——在它正式接管之前，依然需要你确认同意。

## 尚未表示同意的人员

如果你的部分句子来自尚未同意授权的人员，轨道会先将这些句子搁置一边并继续运行。在每个会话中，它都会温和地询问一次大家是否均已同意。当回答为“是”时，这些句子就会加入到下一轮中。
