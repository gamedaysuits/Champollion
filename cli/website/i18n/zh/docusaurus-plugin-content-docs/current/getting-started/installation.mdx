# 安装

## 系统要求

- **Node.js 20.11+**（原生 ESM）
- 翻译 API 密钥（见下文）

## 安装

<Tabs>
  <TabItem value="npm" label="npm" default>

```bash
npm install --save-dev champollion
```

  </TabItem>
  <TabItem value="npx" label="npx (no install)">

```bash
npx champollion sync
```

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

```bash
pnpm add -D champollion
```

  </TabItem>
  <TabItem value="yarn" label="yarn">

```bash
yarn add --dev champollion
```

  </TabItem>
</Tabs>

## 获取 API 密钥

Champollion 需要一个翻译后端。选择其中一个：

| 提供商 | 环境变量 | 适用场景 |
|----------|---------------------|----------|
| **OpenRouter**（推荐） | `OPENROUTER_API_KEY` | 内容密集型项目、Markdown、200+ 模型 |
| **Gemini**（免费层） | `GEMINI_API_KEY` | 零成本起步、质量良好 |
| **OpenAI** | `OPENAI_API_KEY` | 直接访问 GPT-4o |
| **Anthropic** | `ANTHROPIC_API_KEY` | 直接访问 Claude、文本细节丰富 |
| **DeepL** | `DEEPL_API_KEY` | 欧洲语言、内置正式程度控制 |
| **Google Translate** | `GOOGLE_TRANSLATE_API_KEY` | 大批量键值对、194 种语言 |
| **Microsoft Translator** | `MICROSOFT_TRANSLATOR_API_KEY` | Azure、135 种语言 |
| **LibreTranslate** | `LIBRETRANSLATE_API_URL` | 自托管、隐私优先 |
| **Tilde MT** | `TILDE_API_KEY` | 波罗的海及欧洲语言、欧盟托管 |
| **Translated (Lara)** | `LARA_ACCESS_KEY_ID` + `LARA_ACCESS_KEY_SECRET` | 专业机器翻译、200 种语言 |

<Tabs>
  <TabItem value="openrouter" label="OpenRouter (recommended)" default>

[OpenRouter](https://openrouter.ai) 为 200+ 个 LLM 模型提供统一 API。提供免费层级。

```bash
# Sign up at https://openrouter.ai, then:
export OPENROUTER_API_KEY=sk-or-v1-...
```

或添加到 `.env.local`：

```bash
OPENROUTER_API_KEY=sk-or-v1-your-key-here
```

最适合：内容密集型项目、Markdown 翻译以及需要内容感知屏蔽的项目（代码块、短代码、插值变量）。

  </TabItem>
  <TabItem value="google" label="Google Translate">

```bash
export GOOGLE_TRANSLATE_API_KEY=...
```

适用场景：大批量键值对字符串（194 种语言）。**不推荐**用于 Markdown 内容 —— Google Translate 无法识别代码块、短代码或插值变量。

:::tip[智能检测]
如果仅设置了 `GOOGLE_TRANSLATE_API_KEY`（没有 OpenRouter 密钥），champollion 会自动切换到 Google Translate。无需更改配置。
:::

  </TabItem>
</Tabs>

## 验证安装

```bash
npx champollion --help
```

你应该会看到可用命令的列表。现在你已准备好进行[快速开始](/docs/getting-started/quick-start)。
