# 本网站是如何翻译的

本网站提供 13 种语言版本。除英语外的所有语言环境均
**由 Champollion 自身进行机器翻译** —— 即本文档所描述的同一个 CLI
工具 (`npx champollion sync`)。我们在内部使用自己的工具（dogfooding）。

目前，每个语言对都使用单一模型：
**`google/gemini-3.1-pro-preview`**，并根据下文所述的各语言
语域和术语指南进行翻译。在我们重建基于基准测试的
模型选择机制（见下文）期间，我们特意选择了一个模型
作为诚实的默认选项 —— 因此，这是一个明确且记录在案的选择，而不是
我们粉饰出来的虚假结果。

作为读者，您应该了解以下两点：

1. **这些页面是机器翻译的。** 它们是根据下文所述的
   语域和术语指南生成的，但并没有经过人工逐句审查。
   如果某些内容读起来有误，请以英文版本为准
   —— 我们非常欢迎您提供修改建议。
2. **目前默认使用单一模型，未来将基于基准测试进行选择。**
   Champollion 的设计是根据基准测试*为每个语言对*选择翻译模型
   —— 在开发语料库上对每个候选模型进行评分，并
   使用得分最高的方法翻译该语言环境（如果统计得分相同，
   则按成本决定）。在我们将每个语言对的获胜模型固定在此处之前，
   我们正在通过我们自己的完整性关卡重新运行该选择过程。**在这些运行结果
   发布到 [Network 排行榜](/leaderboard) 之前，本页面将
   不会声称其具有无法向您展示的基准测试出处。**

## 我们正在重建的基准测试选择机制

预期的工作方法 —— 也是配置结构的设计初衷 —— 是
由我们自己的评估驱动的按语言对进行模型选择：在语言对的开发语料库上
对每个候选模型进行评分，取最高
综合得分，并在统计得分相同时按成本决定。整个循环过程
已记录在案，供任何想要复现它的人参考。

今天我们**不会**在此页面上发布每种语言的综合得分或“基准测试获胜者”，
因为支持这些数字的选择扫描过程正在首先通过测试框架的完整性关卡进行重新运行。
当该过程完成时，运行结果将出现在公开排行榜上，此表格将
列出每个语言对的获胜模型及其引用的运行记录，并且网站配置
将重新固定每个语言对的获胜者。在此之前：我们提供一个诚实的默认选项。

*综合得分（Composite score）*是 Network 的混合质量指标（chrF++、完全
匹配以及加载的指标插件，经过 bootstrap-CI 验证）。得分仅
**在同一语言对内**具有可比性，绝不能跨语言对比较 —— 脚本和
语料库的差异使得跨语言对的比较毫无意义。

## 语域和语气

每种语言都使用从
Champollion 语言卡片中选择的明确语域进行翻译，因此整个网站的正式程度保持一致：

- **Français** — vouvoiement (正式的 *vous* 尊称)
- **Deutsch** — Sie-Form (尊称)
- **Nederlands** — u-vorm (尊称)
- **Filipino** — 正式，使用标准技术术语
- **Español** — 中性拉丁美洲西班牙语
- **简体中文** — 专业技术语域
- **日本語** — です/ます (礼貌体)
- **한국어** — 해요체 (礼貌体)
- **Português** — 专业语域
- **ไทย** — 中性专业
- **Tiếng Việt** — 中性的 *bạn* 形式
- **العربية** — 现代标准阿拉伯语，专业语域

## 哪些内容不进行机器翻译

代码块、CLI 命令、配置键、包名、URL 以及
专有名词在翻译过程中受到保护，并按设计
保留为英文。

## 发现了翻译错误？

请提交 Issue 或 PR —— 每个翻译页面的源文件都是英文
原版。只要该页面的英文源文件未发生更改，对翻译页面的修正就会在未来的同步中
保留（同步仅在其英文源文件发生更改时才会重新翻译
页面）。

*本页面本身也是通过上述方法进行机器翻译的 —— 它
描述了自身的翻译过程。*
