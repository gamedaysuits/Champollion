# 投入使用

翻译器是用来使用的。这里介绍了使用翻译器的几种方式，从最简单到最复杂——以及贯穿其中的唯一一条准则：**掌握这些语言的人决定什么内容可以离开你的电脑。**

## 在浏览器中试用

这是最快捷的方式。工具会在你的电脑上启动翻译器，并提供一个可在 Web 浏览器中打开的页面。输入句子即可查看翻译。任何内容都不会离开你的电脑。如果你的句子中包含翻译器在学习过程中从未见过的词汇，页面会标明是哪一个——无论读起来多么通顺，这一句都很可能是错的。

如果你的翻译器是从私密句子中学习的，它可能会复现这些句子——因此轨道系统的试用工具不会将其翻译结果传递给你的 AI 助手（那会把内容发送给助手所属的公司）。相反，它会为你提供该页面的地址，由你亲自前去查看。能够在你的电脑上运行命令的助手仍有可能直接向翻译器发起请求，因此请让它不要这样做。

## 翻译文档

向工具提供一个包含句子的文件，它们就会使用翻译器测试时所用的设置，在你的电脑上将每一行翻译并写入一个新文件。这个新文件遵循与翻译器学习所用的句子相同的规则。

## 作为服务运行

工具可以将你的翻译器作为小型服务运行在你的电脑上，以便其他程序向其请求翻译。默认情况下，只有同一台电脑上的程序才能访问它，而且可以要求输入密码。

允许其他电脑访问是一个更大的步骤。对于从私密句子中学习的翻译器，工具会直接拒绝，除非你指明掌握这些词句的人中有谁同意了——并且将此记录在案。

## 连接到应用程序

如果你正在构建一个应用程序，工具可以将你的翻译器连接到该应用，从而让应用的文案由你的翻译器进行翻译。同样的规则依然适用：从私密句子中学习的翻译器只有在你指明谁同意之后才能进行连接。

## 在其他电脑和手机上使用

你的翻译器位于构建它的电脑上。若要在学校或办公室通过其他电脑或手机使用它，就必须让这些设备能够访问它——方法是在网络上将其作为服务运行，或者嵌入应用程序中。这两种方式都需要更大的步骤，而对于从私密句子中学习的翻译器，两者都需要等待掌握这些词句的人同意。如果你在这部分需要帮助，[欢迎与我们交流](/docs/getting-help)。

## 翻译应用或网站的文案

关于翻译应用或网站的按钮、菜单和页面，并在原文变更时保持它们最新——[翻译应用或网站](/docs/translate-an-app-or-website)中介绍了完整的细节。

## 日常使用中：母语者拥有最终决定权

无论评分有多高，在公开发布任何内容之前，都应当由一位讲该语言的人进行审阅。一种很好的工作方式是起草草稿：翻译器生成初稿，讲该语言的人进行纠正。每一次纠错也是留给下一轮的馈赠——它准确指出了翻译器出错的地方。

一旦确实有错误内容流出，请公开修正并说明更改了什么。发现错误并勇于承担，比一个自称完美的翻译器更能建立信任。
