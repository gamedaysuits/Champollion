# 加入项目

对于书面句子较少的语言，构建翻译器需要许多人携手合作。
**加入项目**正是大家互相找到彼此的方式：正在构建翻译器的人列出自己的项目，说明需要哪些帮助，其他人则提供相应的协助。

## 如果你想提供帮助

在[加入项目](/join)页面浏览各个项目。每个项目都会显示两种语言、项目用途，以及项目持有者所寻求的帮助——例如特定主题的句子、词汇表或值得尝试的方法。

当你提供协助时：

- **你将内容发送给该项目，而非公开可见。** 你的文件会上传到 Champollion 的项目存储空间，只有你、该项目的持有者以及运行该存储空间的人员才能打开它。
- **它由你们双方共同持有。** 由你提交；由他们决定是否接受。当他们接受时，系统会记录一条附注，载明提供者、接受者以及达成的共识。
- **他们能看到你是谁。** 项目持有者可以看到你提供协助时使用的姓名和电子邮件地址，以便与你联系。公开页面绝不会显示电子邮件地址。
- **他们可以谢绝。** 项目方有权婉拒你提供的内容。
- **你可以在他们接受之前撤回。** 撤回（或他们谢绝）会更改此项提供的状态，但不会删除该文件，且项目持有者仍可打开它——因此请仅提供你同意保留给他们的内容。
- **附注优先。** 工具不会提供标记为私有的文件，也不会提供未经所有使用者同意的文件——只有其持有者才能更改此状态。

你不会从项目中获取的内容：项目的句子。未经他们同意，他们的任何内容都不会发送给你。

## 如果你正在构建翻译器

项目在轨道上启动后，你就可以将其列出。你需要说明：

- 两种语言，以及该翻译器的用途，
- 你希望显示的名称——绝不会显示你的电子邮件，
- 最需要什么样的帮助。

每条信息在展示之前都会经过简短审核，以确保页面的可信度。当有人提供协助时，由你决定：接受后，它会进入你项目的收件箱，附有一条注明你们双方姓名的附注，随时可以像普通文件一样引入；或者也可以谢绝。

## 目前可以提供什么

文件：句子、词汇表，以及可供尝试的翻译方法。其他形式的帮助——例如远程校对草稿或出借计算算力——目前尚未纳入其中。

如果目前没有任何项目列出，页面会如实说明。
