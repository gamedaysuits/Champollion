# 문장이 몇 개나 필요할까요?

누구나 가장 먼저 묻는 질문이에요. 솔직한 답변은 두 가지예요.
**대부분이 생각하는 것보다 더 많이 필요하다**는 것, 그리고 **직접 라운드를 진행해 보면 알 수 있다**는 것이에요.

## 우리가 알고 있는 것

컴퓨터가 모든 답을 채점할 수 있도록 연습용 언어를 하나 만들었어요.
단어는 약 2,000개, 완벽하게 규칙적인 문법, 깔끔한 데이터로요. 노트북에서
학습시킨 번역기가 새로운 일상 문장의 정확한 의미를 맞힌 비율은 다음과 같아요.

- 예시 문장 **6,400개** 학습 후: 100개 중 약 **79개**
- 예시 문장 **25,600개** 학습 후: 100개 중 약 **96개**

본 적 없는 단어가 들어간 문장은 어김없이 틀렸어요. 하지만 예시 6,400개 기준에서는
틀린 것 중 약 3분의 1에 불과했어요. 나머지는 아직 배우지 못한 문법 때문이었어요.

## 우리가 아직 모르는 것

*여러분의* 언어에는 몇 개나 필요할지예요. 실제 언어는 연습용 언어보다 일상 단어가
훨씬 많고, 뜻이 여러 개인 단어도 있으며, 영어에서는 말하지 않고 넘기는 내용을 나타내는
문법도 있어요. 따라서 위 수치는 최솟값이에요. 실제 언어에는 더 많이 필요할 것이고,
얼마나 더 필요할지는 아직 알지 못해요. 지금 측정해 나가는 중이에요.

지금 여러분의 언어에 필요한 문장 수를 딱 잘라 말하는 사람이 있다면, 그저 짐작일 뿐이에요.

## 필요한 양을 가늠하는 방법

직접 진행하는 라운드가 가장 훌륭한 추정 방법이에요. 라운드를 몇 번 거치면서
점점 나아진 번역기를 실전에 투입하고 화자의 블라인드 확인으로 이를 검증하다 보면,
화자의 채점 점수가 실제로 오르는 것이 보여요. 그러면 각 라운드 보고서에서
대부분의 새로운 문장을 정확히 맞히는 번역기를 만들기까지 문장이 몇 개나 더 필요하고,
화자의 시간이 몇 시간이나 더 들지 범위를 알려줘요. 이는 지금까지 문장을 두 배로 늘릴 때마다
얼마나 성능이 향상되었는지를 바탕으로 계산돼요. 이 예측치는 매 라운드마다 업데이트되며,
주어진 시간이 부족해 보일 때는 솔직하게 알려줘요.

## 시간

실제 화자의 작업 시간은 아직 측정해 보지 못했어요. 대략적인 기준을 들자면,
문장 하나를 쓰거나 확인하는 데 1분 정도 걸린다고 할 때 6,400개 문장은 화자 시간으로
약 100시간이에요. 실제 언어라면 더 많이 필요할 테고요. 꽤 길게 느껴질 수 있어요.
하지만 가족, 수업 구성원, 또는 공동체가 함께 나누어 매주 각자 1~2시간씩만 보태도
금방 쌓여요. 그리고 [다른 사람들의 도움을 받을 수도 있어요](/docs/join-a-project).

## 문장 하나하나를 알차게 채우기

문장 개수보다 *어떤* 문장인지가 더 중요해요.

- **실제 문장을 쓰세요.** 지어낸 연습 문제보다 가족들이 실제로 하고 싶은 말이
  훨씬 효과적이에요. 연습용 언어에서도 새 단어를 최대한 빽빽이 채운 문장보다
  일상 문장으로 학습시켰을 때 더 많은 것을 배웠어요. 화자의 시간이 비슷하게 들었을 때,
  문장 3,200개를 거치고 나서 새로운 문장의 정확한 의미를 맞힌 비율이 100개 중 39개가 아니라
  53개였어요.
- **단어마다 문장을 몇 개씩 두세요.** 번역기가 딱 한 번 본 단어는
  거의 학습되지 않아요. 레일의 위시리스트에는 아직 본 적 없는 단어들이 나와 있어요.
  각 단어마다 내용이 서로 다른 문장을 두세 개씩 넣어 주세요. 많은 단어를 한 번씩 보여주는 것보다
  적은 수의 단어를 몇 개 문장에 나누어 보여주는 편이 더 많이 가르쳐 줘요.
- **틀린 부분을 공략하세요.** 번역기가 틀렸던 것과 비슷한 문장이
  무작위 문장보다 더 많은 것을 가르쳐 줘요. 위시리스트에서도 그런 문장을 제안해 줘요.
- **짧고 다양하게 유지하세요.** 짧은 문장, 다양한 종류—질문, 부탁, 이야기처럼요.
- **교정 내용은 보물이에요.** 화자가 초안을 틀렸다고 표시하고 어떻게 말해야 하는지
  직접 적어 준다면, 그것이 바로 번역기가 틀린 지점을 정확히 짚어 주는 데이터예요.
