# 리더보드와 게시

[리더보드](/leaderboard)는 점수가 매겨진 번역 실행 결과를 공개 기록하는 곳이에요.
누구나 기록을 추가할 수 있어요. 보유한 머신에서 등록된 데이터셋을 대상으로 평가 하네스(`mt-eval`)를 실행한 뒤, 그 결과를 **실행 카드**로 게시하면 돼요. 리더보드는 카드를 보관할 뿐, 방법을 대신 실행해 주지는 않아요. 리더보드는 오픈 라이선스가 적용되어 재배포 가능한 데이터셋에 대해서만 문장별 텍스트를 보관해요. 비상업용, 제한적, 밀봉, 격리 또는 로컬 전용 데이터셋은 절대 보관하지 않으며, `--scores-only` 옵션으로 게시할 때도 보관하지 않아요.

리더보드는 측정값의 원장일 뿐, 특정 번역 방식에 대한 최종 판정이 아니에요. 리더보드에서의 순위는 어떤 방법이 하나의 데이터셋에서 하나의 지표로 어떤 점수를 받았는지를 보여줄 뿐이에요. 번역 결과가 훌륭하다는 뜻도 아니며, 어느 누구에게도 해당 언어 공동체의 언어에 그 방법을 사용할 수 있는 권한을 부여하지 않아요.

## 서로 분리되어 있는 세 가지 요소

| | 역할 | 실행 위치 |
|---|---|---|
| **하네스** ([`mt-eval`](/docs/network/specifications/harness)) | 채점기. 방법과 테스트 세트가 주어지면 점수와 실행 카드를 생성해요 | 사용자 머신 |
| **리더보드** | 제출 창구이자 실행 카드 원장. 데이터셋 및 언어쌍 방향별로 색인돼요 | champollion.dev |
| **네트워크 맵** | 게시된 실행 결과들의 종합: 어떤 언어쌍이 측정되었고 어떤 언어쌍이 아직 측정되지 않았는지 보여줘요 | 구성요소가 아닌 원장의 뷰 |

리더보드를 통하지 않고서는 맵에 아무것도 들어갈 수 없으며, 점수가 매겨지고 지문(fingerprint)이 등록된 실행 결과가 아니면 리더보드에 등록될 수 없어요. 출처(provenance)가 없는 측정값은 여기에 포함될 수 없어요.

## 두 가지 유형의 벤치마크

**공개 벤치마크**는 공개 데이터셋을 사용해요. 각 데이터셋은 원본 다운로드 포인터가 포함된 메타데이터 카드로 등록돼요. 하네스는 실행 시 업스트림에서 참조 번역(reference)을 다운로드하고, 고정된 SHA-256과 대조 확인한 뒤, 가져온 데이터를 바탕으로 점수를 매겨요. 공개 데이터는 모델의 학습 데이터에 이미 포함되어 있을 수 있으므로, 데이터셋에는 오염 등급(contamination grade)이 부여돼요. `HIGH` 또는 `MEDIUM` 등급(FLORES+는 `HIGH`)을 받았거나 전혀 등급이 매겨지지 않은 세트는 **상대 비교 전용**이에요. 즉, 해당 세트에서 실행된 방법들을 비교하는 용도로만 쓸 수 있고, 절대적인 품질로 보고해서는 안 돼요. `LOW` 등급을 받은 세트만이 절대적 품질로 순위를 매겨요. 격리된 데이터셋은 절대 순위가 매겨지지 않으며, 데이터베이스가 해당 세트에 대해 제출된 점수를 거부해요. 등록된 데이터셋과 라이선스 경로는 [평가 데이터셋](/docs/network/leaderboard/datasets)에 나열되어 있어요.

**밀봉 벤치마크**는 주최자가 자체 머신에 보관하는 비공개 테스트 세트예요. 참가자는 이를 볼 수 없어요. 참가 항목은 주최자의 자체 채점 노드가 밀봉된 세트를 대상으로 실행하는 모델이나 방법이에요. 점수만 출력되며, 모든 밀봉 실행에는 주최자의 승인이 필요해요. 현재 이 세트들의 키는 주최자가 보유하고 있어요. 커뮤니티 키 수탁자(custodian)는 아직 지정되지 않았으며, Champollion은 키 지분을 보유하지 않아요. 상금은 주최자가 참가 접수 전에 명시한 조건에 따라 오직 밀봉 대회에만 존재해요. 주최 방법은 [자주적 대회 운영하기](/docs/network/sovereignty/run-a-sovereign-contest)를 참고하세요.

## 적용 범위

- **문서 텍스트.** 리더보드는 문서, 교육 및 공용 자료, UI 문자열과 같은 텍스트 번역을 측정해요. 음성, 실시간 통역, 자유로운 대화는 측정하지 않아요.
- **문자 기반 언어.** 수어 기계 번역은 다른 차원의 문제예요. 색인의 수어 항목에는 "아직 지원되지 않음"이라고 표시돼요 ([언어로 간주되는 기준](/docs/network/context/what-counts-as-a-language)).
- **한 번에 하나의 데이터셋.** 점수는 동일한 버전의 데이터셋에 대한 점수와만 비교할 수 있어요. 여러 데이터셋이나 여러 언어에 걸쳐 순위를 매기지 않아요.
- **문장이 아닌 방법.** 점수는 벤치마크에 대한 방법의 성능을 설명해요. 어떤 번역에 대해서도 문장별 신뢰도는 게시되지 않아요 ([기술적 한계](/docs/network/honest-limitations#system-vs-output)).

## 게시된 실행 결과에 포함되는 내용

모든 새 카드는 **채점 표준/1**([채점 사양](/docs/network/specifications/scoring))에 따라 점수가 매겨져요:

- **대표 점수:** 누구나 다시 계산해 볼 수 있도록 95% 부트스트랩 신뢰구간 및 sacreBLEU 서명이 포함된 말뭉치 수준의 chrF++(0–100).
- **보조 지표:** BLEU, spBLEU, TER, 그리고 계산된 경우 COMET. 이 지표들은 함께 표시될 뿐, 대표 점수에 섞이지 않아요.
- **별도 진단:** FST 수락률 및 정확 일치(exact match) 등 해당 도구가 존재하는 경우의 진단 지표. 대표 점수에 포함되거나 순위를 매기는 데 쓰이지 않아요.
- **폐기된 필드:** 모든 새 카드에서 `composite`, `quality_tier`, `cost_adjusted` 필드는 `null` 상태예요. 기존 카드는 저장된 복합 점수를 "이전 복합 점수(폐기됨)"로 표시한 채 유지해요. 어떠한 자동 점수도 품질 레이블을 갖지 않아요.
- **출처:** 데이터셋 ID와 SHA-256, 정확한 모델 슬러그, 조건, 모델에 제공된 내용(프롬프트의 SHA-256 및 제외하지 않은 경우의 프롬프트 텍스트), 비용, 하네스 버전, 구성에 대한 지문. 동일한 실행은 게시 시 중복 제거되며, 독립적인 재현 결과는 증거로 인정돼요.
- **신뢰 등급:** 모든 행은 처음에 *자체 벤치마크(self-benchmarked)* 상태로 등록돼요. *Champollion Verified*는 고정된 참조 번역을 바탕으로 제출된 출력물에서 점수가 재도출되었음을 뜻해요. 이 재채점기는 메인테이너가 수동으로 실행하는 명령이므로, 현재는 등록 즉시 등급이 승격되는 행이 없어요. *Community Validated*는 공동체 자체 검토를 통해서만 부여돼요 ([검증 등급](/docs/network/leaderboard/rules#verification-tiers)).

전체 스키마는 [실행 카드 사양](/docs/network/specifications/run-card)에 정의되어 있어요.

## 게시

```bash
# See exactly what would be uploaded (no sign-in, no network)
mt-eval publish eval/logs/harness/<run-id>_report.json --dry-run

# Publish to the live board (a browser sign-in the first time)
mt-eval publish eval/logs/harness/<run-id>_report.json --prod
```

- 라이브 리더보드에 쓰려면 `--prod`(또는 `MT_EVAL_ALLOW_PROD=1`)가 필요해요. 이 옵션이 없으면 하네스가 게시를 거부해요.
- `--anonymous` 옵션은 로그인 없이 게시하며, 리더보드에 "anonymous"로 표시돼요.
- `--scores-only` 옵션은 종합 점수와 데이터셋의 해시 및 크기만 게시하며, 원문이나 참조 텍스트는 절대 게시하지 않아요. 자체 말뭉치나 비공개 말뭉치에 사용돼요.
- `--redact-coaching` 옵션은 프롬프트 텍스트를 마커로 대체하고 해시만 보관해요. 로컬 전용 말뭉치의 코칭된 프롬프트는 기본적으로 마스킹돼요.

단계별 안내는 [방법 제출하기](/docs/network/getting-started/submit-a-method)를 참고하세요.

## 어디에나 적용되는 규칙

- **평가 데이터로 절대 학습하지 않기.** 벤치마크 세트에 노출된 방법(학습 데이터, 퓨샷 예시, 사전 항목, 프롬프트 자료 등)은 실격 처리돼요 ([제출 규칙](/docs/network/leaderboard/rules)).
- **우열은 두 숫자가 아닌 검정으로 결정.** 한 실행이 다른 실행보다 나은지 여부는 chrF++에 대한 대응 유의성 검정(paired significance test)으로 판단해요. 검정으로 구분할 수 없는 인접 실행들은 동일한 순위를 공유해요 ([유의성](/docs/network/specifications/significance)).
- **말뭉치는 이곳에서 호스팅하지 않음.** 등록은 메타데이터일 뿐이며, 말뭉치는 해당 원본에서 가져와요. 오픈 라이선스가 적용된 세트의 게시된 실행 결과에는 문장별 텍스트가 포함될 수 있어요 (위 내용 참조).
- **라이선스 경로는 구조적으로 구분됨.** 비상업용 말뭉치는 모든 상금, API 및 상업적 경로에서 제외돼요. 수정되었거나 맞춤형이거나 명시되지 않은 라이선스(`LicenseRef-*`)가 적용된 말뭉치는 권리자의 동의가 카드에 기록될 때까지 원격 모델 API 평가를 거부해요. 표준 비상업용 라이선스는 학습 방지 채널을 통해서만 원격 모델로 전송되며, 밀봉된 세그먼트는 원격으로 절대 전송되지 않아요. EdTeKLA Plains Cree 세트는 격리 라벨로 분류되어 있으며, 데이터베이스는 이에 대해 게시된 모든 점수를 거부해요.

## 현재 운영 현황

- 리더보드는 현재 운영 중이며 공개되어 있고 제출을 받고 있어요. 그 내용은 실시간 데이터이므로 이 페이지에서 설명하지 않아요. [리더보드 살펴보기](/leaderboard).
- 현재 모든 행은 자체 벤치마크(self-benchmarked) 상태예요 (위의 신뢰 등급 참조).
- 현재 진행 중인 상금 대회는 없으며, 상금 기준을 통과한 점수도 없어요 ([상금 사양](/docs/network/specifications/prizes)).
- 화자 커뮤니티 검토는 아직 진행되지 않았어요 ([화자 검증](/docs/network/specifications/speaker-validation)).
- 대회 조건에 따라 커뮤니티에 전달된 방법은 아직 없어요.

보장하지 않는 항목의 전체 목록은 [기술적 한계](/docs/network/honest-limitations)를 참고하세요. 이 페이지와 해당 페이지의 내용이 다를 경우 해당 페이지의 내용이 우선해요.
