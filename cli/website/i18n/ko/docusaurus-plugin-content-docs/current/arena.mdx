# The Arena

**The Arena는 측정이 이루어지는 곳입니다.** 결과를 제출하는 창구이자 결과를 보관하는 원장이며, 이 두 가지를 기반으로 구축된 경연 시스템입니다.

이곳은 인프라이며, 점수판이나 지도가 아니에요. 다음 세 가지는 혼동하기 쉬우므로 한 번 명확하게 구분해 둘 필요가 있어요.

| | 무엇인가요 | 어디서 실행되나요 |
|---|---|---|
| **[MT-Eval Harness](/docs/network/specifications/harness)** | 채점기입니다. 방법론과 테스트 세트가 주어지면 점수와 실행 카드(run card)를 생성해요. | **사용자의 머신입니다.** 저희는 사용자의 방법론을 대신 실행하지 않으며, 그럴 필요도 없어요. |
| **The Arena** | 제출 창구, 실행 카드 원장, 그리고 경연 및 상금 시스템입니다. | 이곳입니다. |
| **[Network](/docs/network/)** | 충분한 실행 카드가 모였을 때 나타나는 지도입니다. 누가 무엇을, 얼마나 잘 번역할 수 있는지, 그리고 빈 공간이 어디인지 보여줘요. 라우팅은 이 지도를 가로지릅니다. | 결과물이며, 구성 요소가 아니에요. |

The Arena를 통하지 않고는 아무것도 Network에 들어갈 수 없으며, 점수가 매겨지고 지문(fingerprint)이 남겨진 실행(run)이 아니면 아무것도 The Arena에 들어갈 수 없어요. 이것이 전체 설계의 핵심입니다. 출처가 없는 측정값은 지도의 일부가 될 수 없어요.

## The Arena의 구성 요소

**창구.** 파인튜닝된 모델, 프롬프트가 적용된 프론티어 모델, FST 기반 파이프라인, 규칙 기반 시스템, 전문 번역가 등 누구나 제출할 수 있어요. 방법론은 프로세스와 무관하며, 절차만 고정되어 있습니다. 가지고 있는 것에 따라 두 가지 다른 창구를 이용할 수 있어요. 이미 채점한 결과가 있다면 [실행 카드 발행하기(publish a run card)](/docs/network/getting-started/submit-a-method)를, 데이터셋, 사전, 엔진, 번역 서비스, 외부에서 발표된 결과, 또는 언어 카드에 대한 수정 사항이 있다면 [항목 제안하기(propose an entry)](/docs/network/getting-started/submit-to-the-index)를 선택하세요. 제안은 로봇이 아닌 사람이 직접 읽으며, 자동으로 승인되는 것은 없어요.

**원장.** 발행된 모든 실행은 실행 카드(run card)가 됩니다. 여기에는 점수, 데이터셋 해시, 모델 슬러그(slug), 조건, 그리고 이 모든 것에 대한 지문이 포함돼요. 두 사람이 동일한 구성을 실행하더라도 설계상 아무런 문제가 없어요. 동일한 실행은 발행 시 중복이 제거되며, 독립적인 교차 검증은 낭비가 아니라 증거가 됩니다. [실행 카드 명세(Run Card Specification)](/docs/network/specifications/run-card)는 카드에 공개해야 할 내용을 정의하고, [벤치마크 명세(Benchmark Specification)](/docs/network/specifications/benchmark)는 카드를 생성하는 프로토콜을 정의해요.

**타겟 세트.** <SSOTCount field="registryDatasetCount" />개의 평가 데이터셋이 등록되어 있어요. 각각은 메타데이터 카드와 소스에서 가져오기(fetch-from-source) 포인터로 구성되며, **말뭉치(corpus) 콘텐츠는 절대 이곳에 호스팅되지 않아요**. Harness는 실행 시점에 업스트림에서 참조 데이터를 가져오고, 방금 가져온 데이터를 바탕으로 점수를 매깁니다.

등록되었다고 해서 어디서나 실행할 수 있는 것은 아니며, 이러한 차이는 의도적인 것이에요. 수백 개의 항목에는 수정되었거나, 맞춤형이거나, 명시되지 않은 라이선스가 적용되어 있으며, 권리자가 명시적인 전송 동의를 기록할 때까지 **원격 평가를 거부**합니다. 어떤 에이전트도 권리자를 대신하여 동의를 추가할 수 없어요. 이러한 항목들은 로컬에서 실행할 수 있으며, 라이선스가 허용하는 경우 학습 금지(no-train) 채널을 통해서도 실행할 수 있어요. [평가 데이터셋(Evaluation Datasets)](/docs/network/leaderboard/datasets) 및 [데이터 관리(Data Stewardship)](/docs/network/sovereignty/data-sovereignty)를 참고하세요.

**경연 시스템.** 단일 실행 위에는 나머지 요소들이 자리 잡고 있어요. [공유 태스크 및 경연(shared tasks and contests)](/shared-tasks), 지도를 가장 크게 개선할 수 있는 측정값들의 [공개 대기열(public queue)](/docs/network/getting-started/contributing-compute), 그리고 상금이 열릴 경우 [상금에 필요한 조건](/docs/network/specifications/prizes)에 대한 명세가 포함됩니다. 커뮤니티는 자체 자금으로 자체 말뭉치에 대한 경연을 직접 운영할 수 있어요. [Champollion은 데이터나 자금을 보유하지 않아요](/docs/network/sovereignty/run-a-sovereign-contest).

## 이곳 어디서나 적용되는 규칙

다음은 변하지 않는 원칙들이에요. 각 원칙에 대한 자세한 내용은 해당 페이지에서 확인할 수 있어요.

**평가 데이터로 학습하지 마세요.** 학습 데이터, 퓨샷(few-shot) 예제, 사전 항목 또는 프롬프트 자료 등 벤치마크 세트에 노출된 모든 방법론은 실격 처리됩니다. 원하는 무엇이든 파인튜닝에 사용해도 좋지만, 테스트 세트만은 예외예요. 오염된 점수는 그 이후의 모든 비교를 망치기 때문에, 이 규칙은 전체 시스템을 유지하기 위해 절대 어겨서는 안 되는 유일한 규칙입니다. ([리더보드 규칙(Leaderboard rules)](/docs/network/leaderboard/rules))

**모든 수치는 출처를 동반해야 하며, 그렇지 않으면 인정되지 않아요.** 실행 카드에는 데이터셋 버전, 모델, 조건, 시스템 프롬프트 및 비용이 명시됩니다. 점수는 동일한 데이터셋 버전 내에서만 비교할 수 있으며, 지문(fingerprint)은 이를 단순한 주장이 아닌 검증 가능한 사실로 만들어 줍니다. ([벤치마크 명세(Benchmark Spec)](/docs/network/specifications/benchmark))

**저희는 사용자의 말뭉치를 절대 보관하지 않아요.** 등록은 메타데이터일 뿐입니다. 테스트 세트는 데이터를 넘겨주지 않은 상태에서 채점되며, 주권(sovereign) 레인에서는 커뮤니티 인프라를 전혀 벗어나지 않고 오직 점수만 이동해요. ([말뭉치 등록하기(Registering Corpora)](/docs/network/sovereignty/registering-corpora))

**라이선스 레인은 편집적인 것이 아니라 구조적인 것이에요.** 비상업용 및 연구 전용 말뭉치는 구조적으로 모든 상금, API 및 상업적 경로에서 제외됩니다. 수정되었거나, 맞춤형이거나, 명시되지 않은 라이선스가 적용된 말뭉치는 추가로 동의를 거쳐야 해요. 권리자의 허가가 기록될 때까지 Harness는 해당 텍스트를 서드파티 모델 API로 전송하는 것을 거부합니다. ([데이터 관리(Data Stewardship)](/docs/network/sovereignty/data-sovereignty))

**점수는 기계적인 신호일 뿐, 최종 판결이 아니에요.** 자동화된 지표는 인간의 판단을 대신하는 대리자(proxy)이며, [화자 검증 프로토콜(Speaker Validation Protocol)](/docs/network/specifications/speaker-validation)은 이 지표가 *대신하는* 인간의 관문을 정의합니다. 리더보드 순위는 어떤 방법론이 측정에서 좋은 결과를 얻었음을 증명할 뿐이에요. 번역이 훌륭하다는 것을 증명하지는 않으며, 누구에게도 커뮤니티의 언어에 이를 배포할 권한을 부여하지 않아요.

**우승이 최종 목표는 아니에요.** 원주민 언어의 경우, 효과적인 방법론을 커뮤니티의 거버넌스 조직으로 이전하고 커뮤니티가 통제하는 인프라에 배포하도록 설계되어 있으며, Champollion은 그곳에서 발생하는 수익의 어떤 몫도 취하지 않아요. ([파생 결과물에 대한 약속(The derived-artifacts commitment)](/docs/network/sovereignty/derived-artifacts))

## 참여 방법

현재 가지고 있는 것과 일치하는 행을 선택하세요.

| 가지고 있는 것 | 해야 할 일 | 시작하기 |
|---|---|---|
| 방법론과 API 키 | 등록된 말뭉치에 대해 Harness를 실행하고 실행 카드를 발행하세요. | [방법론 제출하기(Submit a Method)](/docs/network/getting-started/submit-a-method) |
| 인덱스에 누락된 것 — 데이터셋, 사전, FST, 엔진, 인간 번역 서비스, 발표된 결과 또는 카드 수정 사항 | 구조화된 제안서를 제출하세요. 메인테이너가 직접 검토합니다. | [인덱스에 제출하기(Submit to the Index)](/docs/network/getting-started/submit-to-the-index) |
| 여분의 API 크레딧은 있지만 자체 방법론은 없는 경우 | 본인의 키를 사용하여 공개 대기열에서 열려 있는 항목을 실행하고 그 결과를 발행하세요. | [컴퓨팅 기여하기(Contributing Compute)](/docs/network/getting-started/contributing-compute) |
| 커뮤니티가 소유한 말뭉치 | 메타데이터로 등록하고 노출 레인(공개, 제한, 또는 완전한 주권)을 선택하세요. | [말뭉치 등록하기(Registering Corpora)](/docs/network/sovereignty/registering-corpora) |
| 말뭉치와 이를 바탕으로 대회를 개최할 이유 | 원하는 조건으로 직접 대회를 운영하세요. 저희는 데이터나 자금을 보유하지 않아요. | [주권 경연 운영하기(Run a Sovereign Contest)](/docs/network/sovereignty/run-a-sovereign-contest) |
| 이미 좋은 점수를 기록한 방법론 | 플러그인으로 내보내어 프로덕션 환경에 배포하세요. | [프로덕션에 배포하기(Deploy to Production)](/docs/network/getting-started/deploy-to-production) |
| 궁금한 점이 먼저 있는 경우 | 채점, 실격, 모델, FST, 주권에 대한 내용 | [FAQ](/docs/network/getting-started/faq) |

AI 에이전트인 경우 대기열, 결과 및 실행 카드를 모두 도구로 사용할 수 있어요. [MCP 서버(MCP Server)](/docs/network/getting-started/mcp-server)를 참고하세요.

## 현재 실제로 운영 중인 항목

The Arena는 출시 단계에 있으며, 솔직히 설명하자면 아직 내용이 짧아요.

- **보드는 실시간으로 공개되어 있으며, 제출이 가능해요.** 현재 내용은 실시간 데이터이므로 이 페이지에서는 어떤 내용이 있는지 알려드리지 않아요. [리더보드 읽기](/leaderboard)를 확인해 보세요.
- **"자체 보고(Self-reported)"가 기본 신뢰 계층이에요.** 서버 측 검증(SHA로 고정된 표준 말뭉치에 대해 제출물을 다시 채점하는 것)이 존재하고 확장 중이지만, 아직 모든 항목에 적용되지는 않아요. 각 행의 배지를 확인하세요.
- **현재 열려 있는 상금은 없으며, 이 사이트의 어떤 점수도 상금 기준을 통과하지 못했어요.** [상금 명세(Prize Specification)](/docs/network/specifications/prizes)는 상금이 열릴 *경우* 기준이 명확하도록 작성되었어요. 상금은 스폰서가 자금을 지원하고 보유하며, Champollion은 상금을 보유하거나 에스크로(escrow)하거나 전달하지 않아요.
- **커뮤니티 화자 리뷰는 아직 진행되지 않았어요.** 관문은 명세되어 있고 도구는 구축 중이에요. 복합(Composite) 및 chrF++ 수치는 기계적인 신호일 뿐, 커뮤니티의 최종 판결이 아니에요.
- **아직 커뮤니티로 이전된 방법론은 없어요.** 소유권 이전 모델은 확정된 설계이지만, 아직 실행 중인 프로그램은 아니에요. 이미 진행 중임을 암시하려는 것이 아니라, 저희가 이 약속을 지키는지 여러분이 확인할 수 있도록 설명해 둔 것이에요.
- **키 보관 방식은 결정되었지만, 보관자는 아직 정해지지 않았어요.** 이 메커니즘은 Champollion이 키 지분을 전혀 갖지 않는 임계값(threshold) 방식이에요. 보관자는 커뮤니티에서 선정하며 관련 논의가 진행 중이므로, **커뮤니티 키 보관자(확인 중)**라고 표기하고 있어요.

이 프로젝트가 주장하지 *않는* 내용의 전체 목록은 [솔직한 한계(Honest Limitations)](/docs/network/honest-limitations)에 있어요. 만약 이 페이지의 어떤 내용이 해당 페이지에서 허용하는 것 이상을 암시한다면, 해당 페이지의 내용이 우선하며 이 페이지의 내용은 오류(bug)입니다.

- **오늘 무언가를 제출하고 싶다면** → [방법론 제출하기(Submit a Method)](/docs/network/getting-started/submit-a-method)를 읽은 후 [채점 명세(Scoring Specification)](/docs/network/specifications/scoring)를 확인하세요.
- **결과가 어떻게 판정되는지 알고 싶다면** → [MT 평가 규칙(MT Evaluation Rules)](/docs/network/leaderboard/rules) 및 [통계적 유의성(Statistical Significance)](/docs/network/specifications/significance)을 확인하세요.
- **측정값들이 모여 무엇을 이루는지 보고 싶다면** → [Network](/docs/network/)를 확인하세요.
- **언어를 관리하고 있으며 주권에 대한 큰 그림을 먼저 보고 싶다면** → [언어 커뮤니티를 위한 안내(For Language Communities)](/docs/network/community/for-language-communities)를 확인하세요.
- **이 모든 것이 처음이라면** → [Champollion이란 무엇인가(What Champollion Is)](/docs/what-is-champollion)를 확인하세요.

보드에 이름이 지정된 모든 언어는 [Atlas](/docs/atlas)의 해당 카드로 연결되어 분류, 활력도(vitality), 그리고 해당 언어에 대해 어떤 평가 리소스가 존재하는지 확인할 수 있어요.
