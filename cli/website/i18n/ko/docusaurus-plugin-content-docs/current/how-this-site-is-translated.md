# 이 사이트가 번역되는 방식

이 사이트는 13개 언어로 제공돼요. 영어를 제외한 모든 로캘은 이 문서에서 설명하는 것과 동일한 CLI인 **Champollion 자체를 통해 기계 번역**되었어요(`npx champollion sync`). 저희는 저희가 만든 도구를 직접 사용해요.

현재 모든 언어 쌍은 단일 모델인 **`google/gemini-3.1-pro-preview`**을 사용하며, 아래에 설명된 언어별 어조(register) 및 용어 지침에 따라 번역돼요. 벤치마크 기반의 모델 선택 방식(아래 참조)을 재구축하는 동안 정직한 기본값으로 하나의 모델을 의도적으로 선택했어요. 따라서 이는 명확하게 문서화된 선택이며, 사실과 다른 결과를 그럴듯하게 포장한 것이 아니에요.

독자로서 알아두셔야 할 두 가지 사항이 있어요.

1. **이 페이지들은 기계 번역되었어요.** 아래에 설명된 어조 및 용어 지침에 따라 생성되었지만, 사람이 모든 문장을 검토하지는 않았어요. 어색한 부분이 있다면 영어 버전이 기준이 되며, 수정 제안은 언제나 환영해요.
2. **현재는 하나의 기본 모델을 사용하지만, 향후에는 벤치마크에 따라 선택될 예정이에요.** Champollion은 벤치마크를 통해 *각 언어 쌍에 맞는* 번역 모델을 선택하도록 설계되었어요. 개발 코퍼스에서 모든 후보 모델의 점수를 매기고, 가장 높은 점수를 받은 방식(통계적으로 동점일 경우 비용이 낮은 방식)으로 해당 로캘을 번역해요. 각 언어 쌍의 최종 모델을 여기에 고정하기 전에, 자체 무결성 검증을 통해 해당 선택 과정을 다시 실행하고 있어요. **이러한 실행 결과가 [Network leaderboard](/leaderboard)에 게시될 때까지, 이 페이지는 증명할 수 없는 벤치마크 출처를 주장하지 않아요.**

## 재구축 중인 벤치마크 선택 방식

의도된 방식이자 설정이 작동하도록 구성된 방식은 자체 평가를 기반으로 한 언어 쌍별 모델 선택이에요. 해당 언어 쌍의 개발 코퍼스에서 모든 후보 모델의 점수를 매기고, 가장 높은 종합 점수를 받은 모델을 선택하며, 통계적으로 동점일 경우 비용을 기준으로 결정해요. 이 전체 과정은 재현을 원하는 분들을 위해 문서화되어 있어요.

현재 이 페이지에는 언어별 종합 점수나 "벤치마크 우승 모델"을 게시하지 **않고** 있어요. 이러한 수치를 뒷받침할 선택 과정이 하네스 무결성 검증(harness integrity gate)을 통해 먼저 재실행되고 있기 때문이에요. 이 작업이 완료되면 실행 결과가 공개 리더보드에 올라가고, 이 표에는 각 언어 쌍의 우승 모델과 인용된 실행 결과가 표시되며, 사이트 설정은 언어 쌍별 우승 모델을 다시 고정할 거예요. 그때까지는 하나의 정직한 기본값을 사용해요.

*종합 점수(Composite score)*는 Network의 혼합 품질 지표(chrF++, 정확한 일치(exact match), 로드된 지표 플러그인, 부트스트랩 CI(bootstrap-CI) 검증 완료)예요. 점수는 **동일한 언어 쌍 내에서만** 비교할 수 있으며, 다른 언어 쌍 간에는 비교할 수 없어요. 문자 체계와 코퍼스의 차이로 인해 언어 쌍 간의 비교는 무의미하기 때문이에요.

## 어조 및 톤

각 언어는 Champollion의 언어 카드에서 선택한 명시적인 어조로 번역되므로, 사이트 전체에서 격식의 수준이 일관되게 유지돼요.

- **Français** — vouvoiement (격식 있는 *vous*)
- **Deutsch** — Sie-Form
- **Nederlands** — u-vorm
- **Filipino** — 격식, 표준 기술 용어 사용
- **Español** — 중립적인 라틴 아메리카 스페인어
- **简体中文** — 전문적인 기술 어조
- **日本語** — です/ます (정중한 형태)
- **한국어** — 해요체 (정중함)
- **Português** — 전문적인 어조
- **ไทย** — 중립적이고 전문적
- **Tiếng Việt** — 중립적인 *bạn* 형태
- **العربية** — 현대 표준 아랍어(MSA), 전문적인 어조

## 기계 번역되지 않는 항목

코드 블록, CLI 명령, 설정 키, 패키지 이름, URL 및 고유 명사는 번역 과정에서 보호되며 의도적으로 영어로 유지돼요.

## 오역을 발견하셨나요?

이슈나 PR을 열어주세요. 모든 번역된 페이지의 원본은 영어 원문이에요. 번역된 페이지에 대한 수정 사항은 해당 페이지의 영어 원본이 변경되지 않는 한 향후 동기화 시에도 유지돼요(동기화는 영어 원본이 변경될 때만 페이지를 다시 번역해요).

*이 페이지 자체도 위에서 설명한 방식에 따라 기계 번역되었으며, 자체 번역에 대해 설명하고 있어요.*
