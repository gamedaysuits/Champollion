# 프로젝트 시작하기

시작하는 방법은 두 가지가 있어요. 어느 쪽이든 도구는 여러분의 컴퓨터에서 실행되며, 한 번에 한 단계씩 차근차근 안내해 드려요.

## AI 어시스턴트와 함께하기

가장 쉬운 방법이에요. 타이핑은 어시스턴트가 대신하고, 여러분은 직접 결정해야 할 질문에만 답하시면 돼요.

**필요한 것:** 휴대전화 앱만이 아닌 컴퓨터에서 앱으로 실행되며, 컴퓨터의 도구를 사용할 수 있는 AI 어시스턴트.

### 1. 어시스턴트에 레일 추가하기

아래의 간단한 설정을 복사해서 어시스턴트에 붙여넣고 이렇게 말해 보세요:
*"이것 좀 설정해 줘."* 많은 어시스턴트가 알아서 처리할 수 있어요. 어시스턴트가 하지 못한다면 컴퓨터를 잘 다루는 분에게 한 번만 도와달라고 부탁해 보세요. 바로 아래에 단계별 안내가 있어요.

```json
{
  "mcpServers": {
    "champollion": { "command": "npx", "args": ["-y", "champollion-mcp-server"] }
  }
}
```

<details>
<summary>직접 설정하기</summary>

어시스턴트는 MCP라는 공통 표준을 통해 도구에 연결돼요. 위의 설정은 어시스턴트에게 레일을 어떻게 시작하는지 알려 줘요. 또한 컴퓨터에 무료 프로그램인 Node.js 20.11 이상 버전이 설치되어 있어야 해요.

- **Claude 데스크톱 앱:** Settings(설정) → Developer(개발자) → Edit Config(구성 편집). 해당 파일에 설정을 추가하고 저장한 다음 앱을 다시 시작하세요.
- **Claude Code:** 터미널에서 다음 명령어를 한 번 실행하세요:
  `claude mcp add champollion -- npx -y champollion-mcp-server`
- **Cursor:** 프로젝트의 `.cursor` 폴더 또는 홈 폴더의 `.cursor` 폴더에 있는 `mcp.json` 파일에 설정을 추가하세요.

</details>

### 2. 여러분의 말로 이야기하기

다음과 같이 말해 보세요:

> *영어를 우리 언어로 번역하는 번역기를 만들고 싶어. champollion을 사용해 줘.*

### 3. 질문에 답하기

먼저 번역 방향을 다시 확인해 줄 거예요. *"영어를 넣으면 여러분의 언어로 번역됩니다. 이 방향이 맞나요?"* — 방향을 반대로 착각하기 쉽기 때문이에요. 그런 다음 프로젝트 폴더를 만들고 파일을 요청해요.

그 이후로는 여러분이 결정해야 할 때마다 질문할 거예요. 말과 글이 누구의 것인지, 번역기가 이를 학습해도 되는지, 무언가를 설치할지 등을요. 생각하신 대로 답해 주세요. 아직 잘 모르겠다면 그렇다고 말씀하시면 돼요. 레일은 기다릴 수 있으니까요. 그리고 *지금은 안 함*도 언제나 유효한 답변이에요. 해당 세션 동안에는 레일이 다시 묻지 않아요.

**먼저 알아두실 점이 있어요.** 대부분의 어시스턴트는 읽은 내용을 해당 서비스를 운영하는 기업으로 전송해요. 이 컴퓨터에 보관된 파일의 경우, 도구는 어시스턴트에게 문장이 *몇 개* 있는지만 알려줄 뿐 문장 내용은 절대 전달하지 않아요. 하지만 컴퓨터를 사용할 수 있는 어시스턴트는 여러분이 열 수 있는 파일이라면 무엇이든 열어볼 수 있어요. 비공개로 유지하고 싶은 말이 있다면 어시스턴트에게 열어보지 말라고 요청하거나, 컴퓨터 자체에서 실행되는 어시스턴트를 사용하세요. 자세한 내용은 [여러분의 말, 여러분의 규칙](/docs/your-words-your-rules)에서 설명해 드려요.

## 직접 진행하기

명령어를 직접 입력하는 것이 편하시다면 네 줄이면 돼요. 프로젝트 도구를 설치하고(Node.js 20.11 이상 필요), 프로젝트를 시작한 다음 다음 단계를 물어보세요:

```bash
npm install -g champollion
champollion new family --from English --to qaa --target-name "Our language"
cd family
champollion next
```

`qaa`은 "아직 코드가 없는 언어"를 뜻해요. 이렇게 해도 잘 작동하지만, 도구가 문자 체계 같은 정보를 자동으로 채워주지는 못해요. 따옴표 안의 이름은 여러분이 부르고 싶은 명칭이에요. 언어에 고유 코드가 있거나 도구가 알고 있는 이름이 있다면 대신 그것을 사용하세요. 하나의 이름이 여러 언어를 가리킬 수 있다면 코드를 정하기 전에 해당 언어 사용자들에게 어떤 언어를 사용하는지 먼저 여쭤보세요. 확인되기 전까지는 `qaa`을 사용해도 되지만, 언어 카드가 없기 때문에 복수형 규칙이나 문자 체계 정보가 제공되지 않아요.

그 이후로는 `champollion next`이 언제나 다음 단계와 그에 맞는 정확한 명령어를 알려 줘요. 번역기를 학습시킬 때가 되면 학습 도구를 설치하기 전에 레일이 먼저 물어볼 거예요.

## 인터넷 없이 작업하기

설치와 첫 번째 학습이 끝날 때까지는 인터넷 연결을 유지해 주세요. 학습 도구와 성능이 더 뛰어난 번역기(약 1.2GB)가 이때 다운로드돼요. 그 후에는 모든 작업이 사용자의 컴퓨터에서 이루어져요. 도구 자체의 조회를 중단하려면(언어의 공개 정보 카드를 가져오기 위해 언어 코드만을 전송할 수 있어요), 터미널과 어시스턴트 설정에 다음을 지정하세요:

```bash
export CHAMPOLLION_OFFLINE=1
```

기업의 컴퓨터에서 실행되는 AI 어시스턴트는 여전히 인터넷이 필요해요. 완전한 오프라인 작업을 원하신다면 여러분의 컴퓨터에서 실행되는 어시스턴트를 사용하세요.

## 앞으로 기대할 수 있는 것

첫 번째 번역기는 아마 회화책 수준일 거예요. 학습에 사용된 문장과 비슷한 문장은 잘 번역하지만, 아직 그 외의 문장은 잘 다루지 못해요. 모든 프로젝트는 거기서부터 시작돼요. 무엇을 기대할 수 있는지는 [아직 할 수 없는 것들](/docs/what-it-cant-do-yet)에서 솔직하게 설명하고 있으며, 번역기가 어떻게 발전하는지는 [더 좋게 만들기](/docs/make-it-better)에서 확인하실 수 있어요.
