# 앱 또는 웹사이트 번역하기

앱과 웹사이트는 버튼, 메뉴, 메시지, 페이지 등의 텍스트를 언어별 파일에 보관해요. Champollion이 여러분의 언어 파일을 대신 채워주고, 원문이 바뀔 때마다 항상 최신 상태로 유지해 줘요. 명령어 하나면 돼요:

```bash
npx champollion sync
```

앱의 언어 파일을 찾아 누락되었거나 변경된 내용만 번역하고, 파일에 쓰기 전에 모든 번역을 확인하며, 나머지 부분은 그대로 둬요.

## 어떤 번역기가 작업하나요

언어별로 직접 선택할 수 있어요:

- **직접 만든 번역기**: 레일 위에서 구축한 번역기를 도구가 여러분의 앱과 연결해 줘요. 비공개 문장으로 학습한 번역기라면, 말을 지켜온 분들 중 동의해 주신 분을 명시해야만 연결돼요.
- **AI 모델 또는 번역 서비스**: 이미 해당 언어를 잘 지원하는 경우에 사용해요. 앱의 텍스트가 해당 서비스를 운영하는 기업으로 전송되므로, 공유해도 괜찮은 텍스트에 사용해 주세요.
- **자체 서비스**: 직접 지정한 주소에 있는 서비스를 사용할 수 있어요.

## 어떤 작업을 처리해 주나요

- **변경된 내용만 번역해요.** 이전에 번역한 내용을 기억하므로 같은 문장에 비용을 두 번 치르지 않아도 돼요.
- **작성하기 전에 검사해요.** 빈 답변, 원문이 그대로 복사된 경우, 단어가 끊임없이 반복되는 현상, 지나치게 긴 텍스트, 누락된 부분, 잘못된 문자는 걸러내어 제외해요. 이러한 검사는 의미의 오류가 아니라 깨진 결과물을 잡아내는 것이며, 최종 결정은 여전히 언어 화자에게 있어요.
- **원하는 파일, 원하는 형식.** JSON, YAML, TOML, Markdown 페이지뿐만 아니라 자주 쓰이는 앱 및 웹사이트 프레임워크를 지원해요.

## 누가 사용할 수 있나요

비상업적 용도라면 무료예요. 학교 앱, 커뮤니티 웹사이트, 공공 서비스 등이 해당돼요. 기업 제품에는 무료 라이선스가 적용되지 않지만, 언어 사용자 커뮤니티가 상업적으로 사용하고자 한다면 문의해 주세요. 라이선스를 무료로 제공해 드려요.
자세한 내용은 [누가 사용할 수 있나요](/docs/getting-started/who-may-use-this)를 참고하세요.
