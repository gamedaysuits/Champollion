# Champollion이란

**Champollion은 여러분의 언어를 위한 기계 번역을 구축하고, 누군가가 이를 신뢰하기 전에 제대로 작동하는지 검증할 수 있게 해주는 오픈소스 툴킷이에요.**

빅테크가 지나쳐 버린 언어들을 위해 만들어졌어요. 크리어로 소식지를 발행하고 싶은 학교, 돌보는 가족들을 위한 병상용 회화집이 필요한 병원, 자기 언어를 맡길 만큼 믿을 만한 도구가 있는지 알고 싶어 하는 커뮤니티를 위한 것이에요. 사용자 본인, 혹은 이 도구들을 다루도록 지정한 AI 에이전트는 *"어떻게 시작해야 할까요?"*라는 고민에서 출발해 검증을 거쳐 배포된 번역 워크플로까지 나아갈 수 있어요.

## 여정, 그리고 각 단계별 도구

| 단계 | 질문 | 도구 |
|---|---|---|
| **1. 무엇이 있는지 확인하기** | 이 언어에 대해 무엇이 알려져 있나요? — 사전, 문법, 말뭉치, 모델, 발표된 연구 결과, 서비스 등 | **[The Atlas](/languages)** — <SSOTCount field="catalogLanguageCount" /> 언어 카드; 모든 값마다 출처가 명시되어 있어요 |
| **2. 자체 데이터 보호하기** | 데이터를 외부에 넘기지 않고 어떻게 자체 문장으로 테스트할 수 있을까요? | **[말뭉치 등록](/docs/network/sovereignty/registering-corpora)** 및 **[소버린 노드](/docs/network/sovereignty/sovereign-eval-node)** — 로컬 머신이나 에어갭 환경에 테스트 세트 유지 |
| **3. 선택지 측정하기** | *우리* 텍스트에는 어떤 방식이 가장 적합하고, 얼마나 더 뛰어난가요? | **[하네스](/docs/network/specifications/harness)** (`mt-eval`) — 매번 동일한 절차로 어떤 말뭉치에 대해서든 모든 방식을 점수화 |
| **4. 더 나은 것 만들기** | 스스로를 속이지 않고 직접 모델을 훈련하거나 미세 조정할 수 있을까요? | **[NMT Forge](/docs/network/getting-started/training-honestly)** (`nmt-forge`) — 테스트 세트 유출, 잘못된 데이터 분할, 노이즈에 대한 아전인수식 해석을 방지하는 안전장치를 갖춘 훈련 |
| **5. 원한다면 공개적으로 증명하기** | 정말로 더 나은가요? 다른 사람들도 확인할 수 있나요? | **[리더보드와 콘테스트](/docs/network/getting-started/submit-a-method)** — 결과를 공개하거나, 노드 밖으로 절대 유출되지 않는 봉인된 테스트 세트로 콘테스트 주최 |
| **6. 최선의 조합 찾기** | 이 언어 쌍에 대해 누가 무엇을 제공하며, 어떤 것들이 함께 잘 작동하나요? | **[The Network](/docs/network/)** — 존재하는 방식 및 서비스와 각각에 대한 근거 |
| **7. 활용하기** | 앱, 웹사이트, 문서를 번역해요. | **[Champollion CLI](/docs/intro)** — 언어 쌍별로 검증된 방식을 배포하며, 번역 메모리를 통해 동일한 문장에 비용을 두 번 치르지 않도록 지원 |

**[MCP 서버](/docs/network/getting-started/mcp-server)**는 AI 에이전트가 위 모든 단계를 직접 수행할 수 있는 손이 되어 주며, 이 문서는 사람과 에이전트 모두를 위해 작성되었어요(기계 판독용: `/llms.txt`, `/llms-full.txt`).

**측정은 기본 뼈대예요.** 지원 범위는 쉽게 발표되지만, 품질이 실제로 공개되는 경우는 드물어요. 위의 모든 단계는 확인할 수 있는 수치와 출처(어떤 데이터인지, 어떤 방식 버전인지, 어떤 평가 지표인지, 비용이 얼마나 들었는지)로 마무리돼요. "이 언어 쌍에는 아직 제대로 작동하는 것이 없습니다"라는 솔직한 고백 역시 우리가 공개하는 결과예요. 눈에 보이는 공백이어야 누군가 채울 수 있으니까요.

## 우리가 따르는 규칙

이것은 마케팅이 아니라 제약 조건이에요. 소프트웨어가 할 수 있는 일을 결정하죠.

**저희는 사용자의 말뭉치를 절대 보관하지 않아요.** 테스트 세트는 당사 서버로 업로드하는 것이 아니라, 이미 존재하는 위치를 지정하는 방식으로 등록돼요. 번역 방식은 저희가 결코 소유하지 않는 말뭉치를 기준으로 평가받아요. 봉인된 세트의 경우, 데이터는 사용자의 머신에서 암호화된 상태로 유지되며, 커뮤니티 키 수탁자들의 정족수가 함께 실행을 승인해야 하는 구조로 설계되어 있어요(아직 수탁자가 임명되지는 않았어요).

**언어 데이터는 생체 데이터처럼 취급돼요.** 말뭉치를 제공하는 사람들은 해당
말뭉치와 이를 바탕으로 측정된 모든 것에 대한 키를 보유해요. 동의는 당연한
것으로 간주되지 않고 반드시 요청되며, 언제든 철회할 수 있어요.

**저희는 데이터 주권을 지향하지만, 주권 인증을 받은 것은 아니에요.** 어떤 프로젝트가 언어 데이터에 대한 커뮤니티의 소유권과 통제권을 존중하는지 여부는 해당 프로젝트가 스스로 주장할 수 있는 것이 아니에요. 저희는 맡은 바를 수행하고 메커니즘을 정직하게 설명할 뿐이며, 이에 대한 판단은 참여하는 커뮤니티의 몫이에요.

**인간이든 기계든 모든 방법을 환영해요.** 전문 번역가, FST 기반 규칙 시스템,
프롬프트 기반 프론티어 모델, 미세 조정된 NMT 모델 모두 동일한 테스트 세트에서
동일한 방식으로 비교돼요. 우리는 언어가 번역되는 것에 관심이 있을 뿐, 어떤
도구가 이기는지에는 관심이 없어요.

**우리가 할 수 없는 일도 게시해요.** 이 프로젝트가 *아직* 주장하지 않는
사항들의 목록인 [정직한 한계](/docs/network/honest-limitations)를 확인해
보세요. 이곳의 다른 내용을 신뢰하기 전에 먼저 읽어보시길 바라요.

---

**Champollion은 인덱스이지 중재자가 아니에요.** 모든 값은 출처를 인용하고
해당 출처가 실제로 말하는 내용을 보고해요. 출처 간에 의견이 엇갈리는 경우(화자
수에 대해서는 매우 자주 발생함), 카드는 출처를 명시하여 모든 의견을 보여줘요.
우리는 승자를 선택하거나 억지로 합의를 만들어내지 않아요.

## 이름의 유래

Jean-François Champollion은 세 가지 문자로 쓰인 동일한 텍스트인 로제타
스톤(Rosetta Stone)을 사용하여 이집트 상형문자를 해독했어요. 병렬 텍스트는
여전히 번역을 학습하는 방법이에요. 이 이름은 또한 소리 내어 말할 가치가 있는
긴장감을 내포하고 있어요. 바로 착취의 시대에 다른 사람의 글을 읽는 유럽
학자라는 점이죠. 우리는 그 점에 대해 고민해요. 그렇기 때문에 앞서 언급한 주권
규칙이 브로셔의 한 페이지가 아니라 소프트웨어의 제약 조건으로 존재하는 거예요.

## 다음으로 읽어볼 내용

- **어떤 언어를 위한 기계 번역을 처음부터 끝까지 구축하고 싶다면** → [언어별 기계 번역 구축하기](/docs/build-mt-for-your-language): 위 모든 단계의 정확한 명령어와 각 단계에서 에이전트가 호출할 MCP 도구를 안내해요.
- **앱이나 웹사이트를 번역하고 싶다면** → [빠른 시작](/docs/getting-started/quick-start).
- **언어 화자이거나, 언어를 가르치거나 관리하고 있다면** → [언어 커뮤니티 안내](/docs/network/community/for-language-communities)를 읽어보신 후, 데이터를 넘겨주지 않고도 테스트 세트를 활용하는 방법은 [말뭉치 등록](/docs/network/sovereignty/registering-corpora)을 확인해 보세요.
- **연구자이거나 번역 방식 개발자라면** → [누가 혜택을 받는가](/docs/network/who-benefits#researchers)의 평가 우선 논거(정선된 1,000개 언어 쌍이 관리되지 않은 70만 개 언어 쌍보다 나은 이유)를 살펴본 다음, 새로운 언어를 도입하려면 [말뭉치 파트너십](/docs/network/specifications/corpus-partnership)을, 이미 등록된 언어에 대해 경쟁하려면 [방식 제출하기](/docs/network/getting-started/submit-a-method) 및 [채점 사양](/docs/network/specifications/scoring)을 확인해 보세요.
- **AI 에이전트라면** → [에이전트 가이드](/docs/network/getting-started/agent-guide); 기계 판독용 엔트리 포인트는 `/llms.txt` 및 `/llms-full.txt`이에요.
- **이러한 작업에 자금을 지원한다면** → [누가 혜택을 받는가](/docs/network/who-benefits#funders) 및 [솔직한 한계](/docs/network/honest-limitations)를 확인해 보세요.
- **배경지식이 궁금하다면** → [이 분야가 여기까지 오게 된 과정](/docs/network/context/mt-field-briefing), [무엇을 언어로 볼 것인가](/docs/network/context/what-counts-as-a-language), [지원 범위는 어떻게 집계되는가](/docs/network/context/coverage-counting)를 확인해 보세요.
