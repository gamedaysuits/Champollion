# Champollion이란

**Champollion은 다른 누구도 측정하지 않는 언어에 대한 기계 번역을 측정하고,
그 결과를 게시해요.**

이것이 핵심 아이디어예요. 이 사이트의 모든 내용은 측정을 수행하는 도구이거나,
그 측정값으로 구축된 지도이거나, 우리가 이를 수행하는 규칙 중 하나예요.

---

## 문제점

현재 사용되는 언어는 약 7,000개에 달해요. 하지만 그중 대부분은 다음과 같은
기본적인 질문에 답할 수 없어요. *이것을 번역해야 한다면 사용 가능한 가장 좋은
방법은 무엇이며, 실제로 사용할 만큼 충분히 좋은가요?*

"어느 회사에 데모가 있는가"가 아니에요. 인간 번역가, 규칙 기반 시스템,
프롬프트 기반 언어 모델, 훈련된 모델 등 어떤 방법이 **이 언어 쌍과 이러한
종류의 텍스트**에 실제로 효과가 있는지, 그리고 그것을 어떻게 알 수 있는지에
대한 문제예요.

English↔French의 경우 그 질문에 대한 답은 수천 번도 넘게 나왔어요. 하지만
English↔Plains Cree나 Ayta Abellen, 또는 수천 개의 다른 언어에 대해서는 아예
질문조차 제기되지 않은 경우가 많아요. 지원 범위(Coverage)는 발표되지만,
품질이 공개되는 경우는 드물어요.

아무도 측정하지 않기 때문에, 보도 자료와 실제 개선 사항을 구별할 수 있는
사람은 없어요. 그리고 이 기술을 사용하려는 커뮤니티는 자신의 언어를 믿고
맡겨도 안전한지 확인할 방법이 없어요.

## 우리의 해결 방법

우리는 번역 엔진을 만들지 않아요. 엔진은 대형 기술 기업들이 만들죠. 우리는
엔진이 제대로 작동하는지 알려주는 도구를 만들어요.

1. **테스트 세트에 대해 방법을 실행**하고 점수를 매겨요. 모든 방법과 모든
   언어에 대해 동일한 절차를 적용해요.
2. **결과를 출처와 함께 게시**해요. 어떤 데이터, 어떤 방법 버전, 어떤 지표를
   사용했는지, 비용은 얼마나 들었는지 포함해요.
3. **지도의 형태가 갖춰질 때까지 반복**해요. 어떤 언어가 어떤 언어와
   연결되는지, 얼마나 강력하게 연결되는지, 빈 공간은 어디인지 파악해요.

정직하게 "이 언어 쌍에 대해 아직 작동하는 방법이 없습니다"라고 말하는 것도
우리가 게시하는 결과 중 하나예요. 현재 지도의 대부분이 그런 상태이며, 이를
있는 그대로 밝히는 것이 중요해요. 눈에 보이는 공백은 누군가가 자금을
지원하거나 채울 수 있는 공백이니까요.

## 우리가 따르는 규칙

이것은 마케팅이 아니라 제약 조건이에요. 소프트웨어가 할 수 있는 일을 결정하죠.

**우리는 여러분의 말뭉치를 절대 보관하지 않아요.** 테스트 세트는 우리에게
업로드하는 방식이 아니라, 이미 존재하는 위치를 가리키는 방식으로 등록돼요.
우리가 소유하지 않은 말뭉치를 바탕으로 방법의 점수가 매겨져요. 봉인된 세트의
경우, 데이터가 외부로 나가기 전에 여러분의 기기에서 암호화되며, 커뮤니티 키
관리자들의 기준 인원이 모여야만 실행을 승인할 수 있어요.

**언어 데이터는 생체 데이터처럼 취급돼요.** 말뭉치를 제공하는 사람들은 해당
말뭉치와 이를 바탕으로 측정된 모든 것에 대한 키를 보유해요. 동의는 당연한
것으로 간주되지 않고 반드시 요청되며, 언제든 철회할 수 있어요.

**우리는 주권 인증(sovereignty-certified)이 아닌 주권 지향(sovereignty-aspirant)이에요.**
언어 데이터에 대한 공동체의 소유와 통제는 First Nations가 명확히 제시한
데이터 주권 원칙이며, 프로젝트가 이를 충족하는지 여부는 프로젝트 스스로
주장할 수 있는 것이 아니에요. 우리는 정직하게 작업을 수행하고 메커니즘을
설명할 뿐이며, 결정은 관련된 커뮤니티의 몫이에요.

**인간이든 기계든 모든 방법을 환영해요.** 전문 번역가, FST 기반 규칙 시스템,
프롬프트 기반 프론티어 모델, 미세 조정된 NMT 모델 모두 동일한 테스트 세트에서
동일한 방식으로 비교돼요. 우리는 언어가 번역되는 것에 관심이 있을 뿐, 어떤
도구가 이기는지에는 관심이 없어요.

**우리가 할 수 없는 일도 게시해요.** 이 프로젝트가 *아직* 주장하지 않는
사항들의 목록인 [정직한 한계](/docs/network/honest-limitations)를 확인해
보세요. 이곳의 다른 내용을 신뢰하기 전에 먼저 읽어보시길 바라요.

## 구성 요소 및 각 용도

| 목적 | 사용 도구 | 설명 |
|---|---|---|
| 앱이나 사이트 번역 | **[Champollion CLI](/docs/intro)** | 단일 명령어로 로케일 파일을 번역해요. 언어 쌍별로 방법을 선택할 수 있어요. |
| 방법의 점수 측정 또는 점수 재현 | **[MT-Eval Harness](/docs/network/specifications/harness)** | Python 평가 엔진이에요. 이 사이트의 모든 수치는 여기서 나와요. |
| 결과 제출 또는 콘테스트 실행 | **[The Arena](/docs/network/getting-started/submit-a-method)** | 제출 창구, 데이터베이스 및 콘테스트 시스템으로, 측정이 이루어지는 곳이에요. |
| 언어 쌍에 대해 알려진 정보 확인 | **[The Network](/docs/network/)** | 측정값을 바탕으로 구축된 지도예요. 지원 범위, 연결 강도, 라우팅, 다음에 측정할 대기열을 보여줘요. |
| 언어 검색 | **[The Atlas](/languages)** | <SSOTCount field="catalogLanguageCount" /> 언어 카드예요. 분류, 음운론, 활력도 및 존재하는 리소스를 보여줘요. 모든 값은 출처를 인용해요. |
| 스스로를 속이지 않고 모델 훈련 | **[NMT Forge](/docs/network/getting-started/training-honestly)** | 일반적인 자기 기만(유출된 테스트 데이터, 대표성 없는 분할)을 구조적으로 어렵게 만드는 가드레일이 있는 훈련 스위트예요. |
| AI 에이전트로서 작업 | **[Agent Guide](/docs/network/getting-started/agent-guide)** | 도구, MCP 서버 및 기계 판독 가능한 엔드포인트에 포함된 내용을 설명해요. |

**Champollion은 인덱스이지 중재자가 아니에요.** 모든 값은 출처를 인용하고
해당 출처가 실제로 말하는 내용을 보고해요. 출처 간에 의견이 엇갈리는 경우(화자
수에 대해서는 매우 자주 발생함), 카드는 출처를 명시하여 모든 의견을 보여줘요.
우리는 승자를 선택하거나 억지로 합의를 만들어내지 않아요.

## 이름의 유래

Jean-François Champollion은 세 가지 문자로 쓰인 동일한 텍스트인 로제타
스톤(Rosetta Stone)을 사용하여 이집트 상형문자를 해독했어요. 병렬 텍스트는
여전히 번역을 학습하는 방법이에요. 이 이름은 또한 소리 내어 말할 가치가 있는
긴장감을 내포하고 있어요. 바로 착취의 시대에 다른 사람의 글을 읽는 유럽
학자라는 점이죠. 우리는 그 점에 대해 고민해요. 그렇기 때문에 앞서 언급한 주권
규칙이 브로셔의 한 페이지가 아니라 소프트웨어의 제약 조건으로 존재하는 거예요.

## 다음으로 읽어볼 내용

- **무언가를 번역하고 싶다면** → [빠른
  시작](/docs/getting-started/quick-start)을 참고해 보세요.
- **언어를 사용하거나, 가르치거나, 관리한다면** → [언어 커뮤니티를 위한
  안내](/docs/network/community/for-language-communities)를 먼저 읽고,
  테스트 세트를 넘겨주지 않고 사용하는 방법에 대해서는
  [말뭉치 등록](/docs/network/sovereignty/registering-corpora)을 참고해 보세요.
- **연구자이거나 방법론 개발자라면** → [누가
  혜택을 받는가](/docs/network/who-benefits#researchers)의 평가 우선(eval-first) 주장(큐레이션된 1,000개의
  쌍이 큐레이션되지 않은 700,000개의 쌍보다 나은 이유)을 읽은 후,
  언어를 도입하려면 [말뭉치 파트너십](/docs/network/specifications/corpus-partnership)을,
  이미 있는 언어에 대해 경쟁하려면 [방법
  제출](/docs/network/getting-started/submit-a-method) 및
  [채점 사양](/docs/network/specifications/scoring)을 참고해 보세요.
- **AI 에이전트라면** → [에이전트
  가이드](/docs/network/getting-started/agent-guide)를 참고해 보세요. 기계 판독 가능한 진입점은
  `/llms.txt` 및 `/llms-full.txt`예요.
- **이러한 종류의 작업에 자금을 지원한다면** → [누가
  혜택을 받는가](/docs/network/who-benefits#funders) 및 [정직한
  한계](/docs/network/honest-limitations)를 참고해 보세요.
- **배경 지식을 원한다면** → [이 분야가 여기까지 온
  과정](/docs/network/context/mt-field-briefing), [언어로 인정받는
  기준](/docs/network/context/what-counts-as-a-language), 그리고 [지원 범위가
  계산되는 방식](/docs/network/context/coverage-counting)을 참고해 보세요.
