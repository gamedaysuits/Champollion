# 봉인 테스트 주최하기

때로는 여러분의 언어를 가장 잘 번역하는 번역기가 다른 사람(연구자, 학생, 기업 등)에게서 나오기도 해요. **봉인 테스트**를 이용하면 참가자들이 문장을 직접 보지 않고도, 오직 *여러분의* 문장으로 번역기 성능을 입증할 수 있어요.

## 진행 방식

테스트 문장은 여러분의 컴퓨터 안에서 암호 키로 잠겨 있어요. 경쟁에 참여하려는 사람들이 각자의 번역기를 제출해요. 여러분의 컴퓨터는 잠긴 문장으로 각 번역기를 실행하고, 점수만 내보내요. 문장과 번역문은 절대 밖으로 나가지 않아요.

따라서 아무도 문장을 읽을 수 없으므로 미리 공부하거나 거기에 맞춰 튜닝할 수 없어, 테스트의 본래 목적이 온전히 유지돼요.

## 주최자가 결정하는 사항

참가자들이 경쟁을 시작하기 전에 다음 조건을 정해요:

- 우승하기 위해 **어느 정도의 수준을 충족해야 하는지**.
- **우승한 방식에 대한 권리 귀속:**
  - **주최 측의 소유가 됨** — 테스트를 주최한 여러분에게 권리가 이전돼요.
  - **제작자가 소유를 유지함** — 주최 측은 점수만 매기고, 검증용 잠금 사본만 보관해요.
  - **제작자가 소유하되, 모두와 공유함** — 공개적으로 발표해야 해요.
- **상금의 유무** 및 상금 후원 주체. Champollion은 상금에서 어떤 몫도 가져가지 않아요.

## 현재 준비되어 있는 기능

봉인 테스트를 위한 도구는 정상 작동해요. 세트를 잠그고, 인터넷이 차단된 컴퓨터에서 제출된 번역기를 실행하며, 오직 점수만 공개할 수 있어요. 하지만 아직 **레일 위에 올라와 있지는 않아요** — 지금은 도우미의 질문에 단계별로 답하는 대신, 더 긴 설명서를 따라 진행해야 해요.

현재 키를 보유하는 주체: 세트를 잠근 사람이에요. 아직 여러 사람이 키를 함께 보관하도록 지정한 커뮤니티는 없으며, Champollion은 어떤 키의 일부분도 보유하지 않아요.

진행 중인 봉인 테스트가 있다면 [공동 과제](/shared-tasks) 페이지에 안내돼요.
