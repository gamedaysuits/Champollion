# 프로젝트 참여하기

문장 기록이 적은 언어를 위한 번역기를 만들려면 많은 사람의 손길이 필요해요.
**프로젝트 참여하기**는 서로를 찾을 수 있는 공간이에요. 번역기를 만드는 사람들이 프로젝트를 등록하고 어떤 도움이 필요한지 알리면, 다른 사람들이 도움을 보태는 방식이에요.

## 도움을 주고 싶다면

[프로젝트 참여하기](/join) 페이지에서 프로젝트들을 둘러보세요. 각 프로젝트마다 대상이 되는 두 언어가 무엇인지, 번역기를 어디에 쓰려는지, 프로젝트 관리자들이 무엇을 필요로 하는지(특정 주제의 문장들, 단어 목록, 시도해 볼 만한 번역 방식 등) 나와 있어요.

무언가를 제안할 때 알아둘 점:

- **공개되는 것이 아니라 해당 프로젝트로 전달돼요.** 파일은 Champollion의 프로젝트 저장소에 업로드되며, 여러분과 해당 프로젝트의 관리자, 그리고 저장소 운영자만 열어볼 수 있어요.
- **양쪽 모두가 함께 보관해요.** 여러분이 제출하고, 프로젝트 쪽에서 받을지 결정해요. 수락되면 누가 제안했고 누가 수락했으며 어떤 합의가 있었는지 기록에 남아요.
- **프로젝트 관리자가 여러분이 누구인지 알 수 있어요.** 연락을 취할 수 있도록 제안 시 입력한 이름과 이메일이 관리자에게 표시돼요. 공개 페이지에는 이메일이 절대 표시되지 않아요.
- **거절할 수도 있어요.** 프로젝트 측에서 제안을 거절할 수도 있어요.
- **수락되기 전에는 철회할 수 있어요.** 철회하거나 상대방이 거절하면 제안 상태는 바뀌지만 파일이 삭제되지는 않으며, 프로젝트 관리자가 여전히 열어볼 수 있어요. 따라서 상대방이 보관해도 괜찮은 내용만 제안해 주세요.
- **기록이 우선이에요.** 비공개로 표시된 파일이나, 화자들의 전원 동의를 얻지 못한 파일은 도구에서 제안할 수 없어요. 관리자만이 이를 변경할 수 있어요.

프로젝트로부터 문장을 직접 받아볼 수는 없어요. 프로젝트 관리자의 동의 없이는 그들의 어떤 자료도 여러분에게 전송되지 않아요.

## 번역기를 만들고 있다면

프로젝트가 가드레일 위에서 시작되고 나면 목록에 등록할 수 있어요. 등록할 때 다음 내용을 적어 주세요:

- 두 언어와 번역기를 만들려는 목적
- 표시하고 싶은 이름(이메일은 절대 노출되지 않아요)
- 가장 도움이 될 만한 내용

페이지의 신뢰를 지키기 위해, 모든 등록 글은 게시되기 전에 간단한 검토를 거쳐요. 누군가 제안을 보내오면 여러분이 직접 결정할 수 있어요. 수락하면 두 사람의 이름이 적힌 기록과 함께 프로젝트 수신함에 도착하여 일반 파일처럼 바로 가져올 수 있고, 원하지 않으면 거절할 수도 있어요.

## 지금 제안할 수 있는 것

파일 단위예요. 문장, 단어 목록, 시도해 볼 만한 번역 방식 등이에요. 원격으로 초안을 검토하거나 컴퓨터 연산 능력을 빌려주는 등 다른 방식의 도움은 아직 지원하지 않아요.

등록된 프로젝트가 아직 없을 때는 페이지에 솔직하게 그대로 표시돼요.
