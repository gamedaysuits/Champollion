# 가드레일과 함께 레일 위에서 진행하는 기계 번역 개발 및 배포

**이미 가지고 있는 문장으로 여러분의 언어를 위한 번역기를 만들어 보세요.**

- **레일 위에서:** 모든 단계가 순서대로 차근차근 마련되어 있어요.
- **가드레일과 함께:** 흔히 발생하는 실수를 막아주고, 여러분의 언어가
  여러분의 손안에 머물도록 지켜주는 검증 장치가 있어요.

저자원 언어 및 토착어 커뮤니티를 염두에 두고 만들었어요.

**처음 오셨나요?** [이야기를 먼저 읽어보세요](/docs/what-is-champollion) — 짧은
네 쪽 분량으로, 약 20분 정도 걸려요.
