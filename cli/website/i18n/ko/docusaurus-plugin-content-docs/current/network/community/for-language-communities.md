# 언어 공동체를 위한 안내

> **핵심 요약.** 커뮤니티는 데이터를 외부에 전혀 넘기지 않고도 모든 번역 방법의 평가 기준이 되는 "정답지"인 자체 테스트 세트를 직접 소유하고, 원하는 조건에 맞춰 자체 콘테스트를 진행할 수 있어요. 이 페이지에서는 네트워크가 언어 커뮤니티에 요청하는 사항(참조 번역, 번역 검토, 코칭 데이터), 커뮤니티가 얻는 혜택(자금이 확보되면 공시된 요율로 지급되는 유급 작업 — 현재는 자금이 예치되어 있지 않음 — 코드 소유권 및 완전한 배포 제어권), 그리고 가장 우선시되는 주권 보호 조치를 설명해요. 프로그래밍 지식은 필요하지 않아요. 일부 보호 조치는 소프트웨어와 데이터베이스에 이미 내장되어 있으며, 다른 조치들은 아직 약속 단계에 있어요. 자세한 구분은 [솔직한 한계](/docs/network/honest-limitations) 문서에서 확인하실 수 있어요.

Network에 기여하기 위해 프로그래머일 필요는 없어요. 여러분이 원주민 언어나 저자원 언어를 사용한다면, 여러분은 이 생태계에서 가장 중요한 사람이에요.

---

## 주권이 우선이에요

무언가를 요청하기에 앞서, 대원칙이 있어요: **여러분의 언어 데이터는 여러분의 것이에요.** 언어 데이터는 *생체 데이터(biodata)*와 같아요 — 커뮤니티의 정체성과 관계를 담고 있어 유의미하게 익명화할 수 없으므로, 이를 제공하는 사람이 데이터 자체와 이를 기준으로 평가되는 모든 것에 대한 열쇠를 쥐고 있어야 해요. 네트워크는 [원주민 데이터 주권 원칙](/docs/network/sovereignty/data-sovereignty)을 기반으로 구축되었어요:

- 저희는 여러분의 언어 데이터를 저희 서버에 절대 수집하거나 저장하지 않아요
- 번역 방식은 `api` 아키텍처를 사용해요 — 모든 코칭 데이터, 사전, 문법 규칙은 여러분이 통제하는 인프라에 남아 있어요
- 여러분의 언어를 위한 방식을 누가 개발할 수 있는지 여러분이 결정해요
- 리더보드 점수는 방식이 작동한다는 것을 증명해요. 그것을 배포할 권한을 부여하지는 않아요

:::note[현재 상황]
아래에 설명된 소유권 이전 모델은 **아직 운영 중인 프로그램이 아니라, 확정된 설계입니다.** 리더보드는 제출을 받고 있지만 현재 게시된 실행 기록이 없으며, 아직 어떤 방법도 커뮤니티로 이전되지 않았습니다. 이것이 이미 진행 중이라고 암시하려는 것이 아니라, 여러분이 저희에게 책임을 물을 수 있도록 어떻게 작동하게끔 설계되었는지 설명하는 것입니다. 관계, 그리고 여러분의 데이터에 대한 여러분의 권한이 먼저이며, 나머지는 거기서부터 따라옵니다.
:::

## 여러분의 테스트 세트를 소유하세요

이 시스템에서 공동체가 가질 수 있는 가장 강력한 위치는 **벤치마크 자체를 소유하는 것**이에요. 테스트 세트는 정답지예요. 그것을 쥐고 있는 사람이 그 언어에서 "좋은 번역"이 무엇을 의미하는지 결정하고, 모든 방식 — 저희의 것, 기업의 것, 누구의 것이든 — 은 *여러분의* 기준에 따라 평가돼요.

- **등록은 콘텐츠가 아니라 메타데이터예요.** Network에 코퍼스를 등록한다는 것은 서술적 카드를 게시하는 것을 의미해요 — 코퍼스를 업로드하는 것이 절대 아니에요. 여러분은 그것의 [노출 레인](/docs/network/sovereignty/registering-corpora)을 선택해요: 개방형, 게이트형, 또는 완전 주권형이에요.
- **주권 벤치마크는 비밀로 유지돼요.** 주권 레인에서는 테스트 세트가 공동체 인프라를 절대 벗어나지 않으며 저희는 그것을 절대 보지 못해요. 방식은 여러분 쪽에서 그것을 기준으로 평가되며, 점수만 전달돼요.
- **여러분은 자체 대회를 운영할 수 있어요.** 단계별 실행 가이드 — [주권 대회 운영하기](/docs/network/sovereignty/run-a-sovereign-contest) — 는 여러분의 조건에 따라 공동체가 통제하는 평가를 주최하는 방법을 안내해요: 여러분의 테스트 세트, 여러분의 규칙, 그리고 무엇을 (혹시라도) 게시할지에 대한 여러분의 결정이에요.

이 모든 것을 뒷받침하는 보장 사항들은 암묵적인 합의가 아닌 명문화된 문서로 정리되어 있어요:
[데이터 스튜어드십](/docs/network/sovereignty/data-sovereignty) (데이터 주권/CARE
입장 및 당사가 할 수 없도록 금지된 사항) 및
[소유권 및 이용 약관](/docs/network/sovereignty/ownership-transfer) (특정
방법이 우승했을 때 계약상 진행되는 절차).

## 여러분에게 필요한 것

### 참조 번역

저희는 평가를 위한 선별된 번역 쌍이 필요해요 — 한쪽은 영어, 다른 쪽은 여러분의 언어예요. 이것들은 모든 번역 방식이 평가되는 "정답지"가 돼요.

이것들은 다음에서 만들 수 있어요:
- **교육 자료** — 교과서 연습 문제, 수업 계획서, 워크시트
- **공동체 문서** — 회의록, 소식지, 공지사항
- **일상 표현** — UI 문자열, 앱 레이블, 흔한 표현
- **문화 콘텐츠** — 이야기, 노래, 또는 설명 (적절한 허가를 받은 경우)

형식은 간단한 JSON이에요:
```json
{
  "entries": [
    { "id": 1, "source": "Hello", "reference": "tânisi" },
    { "id": 2, "source": "Thank you", "reference": "kinanâskomitin" }
  ]
}
```

### 번역 검토

작동하는 번역을 만든다고 주장하는 모든 방식은 사람의 검증이 필요해요. 이중 언어 사용자가 결과물을 검토하고 컴퓨터가 제대로 했는지 — 그리고 더 중요하게는, *왜* 틀렸는지 — 를 저희에게 알려줘요.

### 코칭 데이터

문법 규칙, 사전 항목, 형태론적 패턴 — 이것들은 번역 방식이 작동하게 만드는 언어 자원이에요. 여러분의 언어가 어떻게 작동하는지에 대한 여러분의 지식은 어떤 AI 모델로도 대체할 수 없어요.

## 여러분이 돌려받는 것

### 소유권

여러분의 언어를 위한 번역 방식이 구축되고 Network에서 검증되면, [소유권이 이전돼요](/docs/network/sovereignty/ownership-transfer) 여러분 공동체의 거버넌스 조직으로요. 여러분은 코드, 모델 가중치, 그리고 배포를 소유하게 돼요.

### 착취가 아닌 유급 작업

말뭉치 구축과 번역 검토는 전문적인 작업이며, 자금이 확보되면
[공시된 요율](/docs/network/perspectives/how-speakers-get-paid)에 따라 대가가 지급돼요
(현재는 자금이 예치되어 있지 않음). 그리고 대가를 지급받는다고 해서 데이터를 넘겨주는 것은 아니에요. 작업에 대한 대가를 받으면서도 구축한 결과물에 대한 소유권을 계속 *유지*하게 돼요. Champollion은 비상업적 연구 프로젝트예요. 아무것도
판매하지 않고, 사용량을 측정하여 과금하지 않으며, 커뮤니티가 소유한 방법으로
창출한 수익에서 [어떠한 지분도 가져가지 않아요](/docs/network/sovereignty/economic-model).

### 통제권

여러분의 거버넌스 조직이 다음을 통제해요:
- 누가 방식에 접근할 수 있는지
- 그것이 상업적으로 사용될 수 있는지 — 그리고 사용된다면, 여러분의 조건에 따라, 그것이 벌어들이는 모든 것을 여러분이 가지고요
- 언제 그리고 어떻게 업데이트되는지
- 추가 개발에 어떤 데이터가 사용되는지

## 참여하는 방법

:::tip[커뮤니티가 동의한다면 — 화자가 지금 바로 할 수 있는 일]
Champollion은 말뭉치를 구축하거나 호스팅하지 않으며, 테스트 데이터는 항상
원본 출처에서 가져와요. 커뮤니티의 화자들이 *지금 당장* 문장을 기여하고
싶다면, [Tatoeba](https://tatoeba.org)는 모든 언어의 문장 단위 기여를
지원하며, [OPUS](https://opus.nlpl.eu/)와 같은 공개 컬렉션은 네트워크가
벤치마크를 구축하는 기반이 되는 병렬 텍스트를 수집해요. 여기에 추가된 문장은 이곳의 평가 데이터가 될 수 있어요.

다만 장단점을 먼저 알아두세요: Tatoeba는 오픈 라이선스(기본값 CC BY 2.0 FR)로 문장을
공개하므로, AI 모델 학습을 포함하여 누구나 문장을 복사할 수 있으며,
이미 복사된 데이터는 회수할 수 없어요. 일상적인 문장에는 이것이 적절한
선택일 수 있어요. 커뮤니티가 직접 통제하고자 하는 모든 데이터는
외부에 넘기지 않고 보관하면서 [봉인된 테스트 세트](/docs/network/sovereignty/run-a-sovereign-contest)를
대신 사용하는 편이 좋아요.
화자가 직접 기여할 수 있는 앱과 말뭉치 빌더는 계획되어 있지만 아직
구축되지는 않았어요.
:::

1. **문의하기** — [네트워크 저장소](https://github.com/gamedaysuits/Champollion)에 이슈를 열거나 [info@champollion.dev](mailto:info@champollion.dev)로 이메일을 보내주세요
2. **언어 소개** — 어떤 어족에 속하나요? 화자 수는 얼마나 되나요? 어떤 문자 체계를 사용하나요? 어떤 전산 자원(FST, 사전, 말뭉치)이 존재하나요?
3. **작게 시작하기** — 신중하게 선별된 50개의 번역 쌍만 있어도 평가 데이터셋을 생성하고 새로운 리더보드 트랙을 열 수 있어요. 말뭉치 작업은 자금이 확보되면 [공시된 요율로 지급돼요](/docs/network/perspectives/how-speakers-get-paid)(현재는 자금이 예치되어 있지 않음)
4. **데이터 소유권 유지하기** — 선택한 레인에 말뭉치를 메타데이터로 등록하세요([말뭉치 등록](/docs/network/sovereignty/registering-corpora)). 테스트 세트를 완전한 비밀로 유지하고 싶다면 [주권 콘테스트 런북](/docs/network/sovereignty/run-a-sovereign-contest)을 참고하세요
5. **거버넌스와 연결하기** — 커뮤니티에서 언어 데이터 및 기술에 대한 권한을 가진 사람은 누구인가요? 네트워크의 주권 모델에는 거버넌스 파트너가 필요해요
