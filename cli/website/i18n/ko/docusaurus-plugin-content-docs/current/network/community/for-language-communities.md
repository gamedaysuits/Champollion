# 언어 공동체를 위한 안내

> **핵심 요약.** 여러분의 공동체는 자체 테스트 세트 — 모든 번역 방식을 평가하는 기준이 되는 "정답지" — 를 소유하고, 데이터를 넘겨주지 않고도 자신의 조건에 따라 자체 대회를 운영할 수 있어요. 이 페이지에서는 Network가 언어 공동체에 요청하는 것(참조 번역, 번역 검토, 코칭 데이터), 여러분이 돌려받는 것(공개된 요율에 따른 유급 작업, 코드 소유권, 완전한 배포 통제권), 그리고 무엇보다 우선하는 주권 보장에 대해 설명해요. 프로그래밍은 필요 없으며, 여기에 있는 어떤 것도 저희를 신뢰할 것을 요구하지 않아요. 보장은 약속이 아니라 구조적인 것이에요.

Network에 기여하기 위해 프로그래머일 필요는 없어요. 여러분이 원주민 언어나 저자원 언어를 사용한다면, 여러분은 이 생태계에서 가장 중요한 사람이에요.

---

## 주권이 우선이에요

저희가 무언가를 요청하기 전에, 기본 원칙은 이거예요. **여러분의 언어 데이터는 여러분의 것이에요.** 언어 데이터는 *바이오데이터*예요 — 그것은 여러분 공동체의 정체성과 관계를 담고 있으며 의미 있게 익명화될 수 없어요 — 따라서 그것을 제공하는 사람들이 그 데이터와, 그것을 기준으로 평가되는 모든 것에 대한 열쇠를 쥐고 있어요. Network는 [원주민 데이터 주권 원칙](/docs/network/sovereignty/data-sovereignty)에 기반을 두고 있어요:

- 저희는 여러분의 언어 데이터를 저희 서버에 절대 수집하거나 저장하지 않아요
- 번역 방식은 `api` 아키텍처를 사용해요 — 모든 코칭 데이터, 사전, 문법 규칙은 여러분이 통제하는 인프라에 남아 있어요
- 여러분의 언어를 위한 방식을 누가 개발할 수 있는지 여러분이 결정해요
- 리더보드 점수는 방식이 작동한다는 것을 증명해요. 그것을 배포할 권한을 부여하지는 않아요

:::note[현재 상황]
아래에 설명된 소유권 이전 모델은 **아직 운영 중인 프로그램이 아니라, 확정된 설계입니다.** 리더보드는 제출을 받고 있지만 현재 게시된 실행 기록이 없으며, 아직 어떤 방법도 커뮤니티로 이전되지 않았습니다. 이것이 이미 진행 중이라고 암시하려는 것이 아니라, 여러분이 저희에게 책임을 물을 수 있도록 어떻게 작동하게끔 설계되었는지 설명하는 것입니다. 관계, 그리고 여러분의 데이터에 대한 여러분의 권한이 먼저이며, 나머지는 거기서부터 따라옵니다.
:::

## 여러분의 테스트 세트를 소유하세요

이 시스템에서 공동체가 가질 수 있는 가장 강력한 위치는 **벤치마크 자체를 소유하는 것**이에요. 테스트 세트는 정답지예요. 그것을 쥐고 있는 사람이 그 언어에서 "좋은 번역"이 무엇을 의미하는지 결정하고, 모든 방식 — 저희의 것, 기업의 것, 누구의 것이든 — 은 *여러분의* 기준에 따라 평가돼요.

- **등록은 콘텐츠가 아니라 메타데이터예요.** Network에 코퍼스를 등록한다는 것은 서술적 카드를 게시하는 것을 의미해요 — 코퍼스를 업로드하는 것이 절대 아니에요. 여러분은 그것의 [노출 레인](/docs/network/sovereignty/registering-corpora)을 선택해요: 개방형, 게이트형, 또는 완전 주권형이에요.
- **주권 벤치마크는 비밀로 유지돼요.** 주권 레인에서는 테스트 세트가 공동체 인프라를 절대 벗어나지 않으며 저희는 그것을 절대 보지 못해요. 방식은 여러분 쪽에서 그것을 기준으로 평가되며, 점수만 전달돼요.
- **여러분은 자체 대회를 운영할 수 있어요.** 단계별 실행 가이드 — [주권 대회 운영하기](/docs/network/sovereignty/run-a-sovereign-contest) — 는 여러분의 조건에 따라 공동체가 통제하는 평가를 주최하는 방법을 안내해요: 여러분의 테스트 세트, 여러분의 규칙, 그리고 무엇을 (혹시라도) 게시할지에 대한 여러분의 결정이에요.

이 모든 것 뒤에 있는 보장은 암시된 것이 아니라 문서로 작성되어 있어요:
[데이터 관리](/docs/network/sovereignty/data-sovereignty) (데이터 주권/CARE 입장과 그것이 저희가 하지 못하도록 금지하는 것) 및
[소유권 및 약관](/docs/network/sovereignty/ownership-transfer) (방식이 우승했을 때 계약상 무슨 일이 일어나는지)이에요.

## 여러분에게 필요한 것

### 참조 번역

저희는 평가를 위한 선별된 번역 쌍이 필요해요 — 한쪽은 영어, 다른 쪽은 여러분의 언어예요. 이것들은 모든 번역 방식이 평가되는 "정답지"가 돼요.

이것들은 다음에서 만들 수 있어요:
- **교육 자료** — 교과서 연습 문제, 수업 계획서, 워크시트
- **공동체 문서** — 회의록, 소식지, 공지사항
- **일상 표현** — UI 문자열, 앱 레이블, 흔한 표현
- **문화 콘텐츠** — 이야기, 노래, 또는 설명 (적절한 허가를 받은 경우)

형식은 간단한 JSON이에요:
```json
{
  "entries": [
    { "id": 1, "source": "Hello", "reference": "tânisi" },
    { "id": 2, "source": "Thank you", "reference": "kinanâskomitin" }
  ]
}
```

### 번역 검토

작동하는 번역을 만든다고 주장하는 모든 방식은 사람의 검증이 필요해요. 이중 언어 사용자가 결과물을 검토하고 컴퓨터가 제대로 했는지 — 그리고 더 중요하게는, *왜* 틀렸는지 — 를 저희에게 알려줘요.

### 코칭 데이터

문법 규칙, 사전 항목, 형태론적 패턴 — 이것들은 번역 방식이 작동하게 만드는 언어 자원이에요. 여러분의 언어가 어떻게 작동하는지에 대한 여러분의 지식은 어떤 AI 모델로도 대체할 수 없어요.

## 여러분이 돌려받는 것

### 소유권

여러분의 언어를 위한 번역 방식이 구축되고 Network에서 검증되면, [소유권이 이전돼요](/docs/network/sovereignty/ownership-transfer) 여러분 공동체의 거버넌스 조직으로요. 여러분은 코드, 모델 가중치, 그리고 배포를 소유하게 돼요.

### 착취가 아닌 유급 작업

코퍼스 구축과 번역 검토는 전문적인 작업이며, [공개된 요율](/docs/network/perspectives/how-speakers-get-paid)에 따라 지급돼요 — 그리고 지급이 여러분의 데이터를 사는 것은 아니에요. 여러분은 작업에 대해 보수를 받으며 *동시에* 여러분이 구축한 것의 소유자로 남아요. Champollion은 비상업적 연구 프로젝트예요: 아무것도 판매하지 않고, 아무것도 과금하지 않으며, 여러분의 공동체가 소유한 방식으로부터 벌어들이는 어떤 것에서도 [몫을 가져가지 않아요](/docs/network/sovereignty/economic-model).

### 통제권

여러분의 거버넌스 조직이 다음을 통제해요:
- 누가 방식에 접근할 수 있는지
- 그것이 상업적으로 사용될 수 있는지 — 그리고 사용된다면, 여러분의 조건에 따라, 그것이 벌어들이는 모든 것을 여러분이 가지고요
- 언제 그리고 어떻게 업데이트되는지
- 추가 개발에 어떤 데이터가 사용되는지

## 참여하는 방법

:::tip[화자분들이 오늘 할 수 있는 일]
Champollion은 코퍼스를 구축하거나 호스팅하지 않으며, 테스트 데이터는 항상
그 출처에서 가져옵니다. 여러분 커뮤니티의 화자분들이 *지금 당장* 문장을
기여하고 싶으시다면, [Tatoeba](https://tatoeba.org)에서 모든 언어로 문장 단위
기여를 받고 있고, [OPUS](https://opus.nlpl.eu/) 같은 공개 컬렉션은 Network가
벤치마크를 구축하는 데 사용하는 병렬 텍스트를 집계합니다. 그곳에 추가된
문장은 다음 코퍼스 빌드 때 이곳의 평가 데이터가 될 수 있습니다. 화자 직접
기여 앱과 코퍼스 빌더는 저희 로드맵의 다음 단계로 계획되어 있습니다.
:::

1. **연락하기** — [Network 저장소](https://github.com/gamedaysuits/Champollion)에 이슈를 열거나 [info@champollion.dev](mailto:info@champollion.dev)로 이메일을 보내세요
2. **여러분의 언어 설명하기** — 어떤 어족에 속하나요? 사용자는 몇 명인가요? 어떤 문자 체계를 사용하나요? 어떤 전산 자원이 존재하나요 (FST, 사전, 코퍼스)?
3. **작게 시작하기** — 선별된 번역 쌍 50개만으로도 평가 데이터셋을 만들고 새로운 리더보드 트랙을 열기에 충분해요. 코퍼스 작업은 [공개된 요율에 따라 지급돼요](/docs/network/perspectives/how-speakers-get-paid)
4. **여러분의 것으로 유지하기** — 여러분이 선택한 레인에서 코퍼스를 메타데이터로 등록하세요 ([코퍼스 등록하기](/docs/network/sovereignty/registering-corpora)); 테스트 세트를 완전히 비밀로 유지하고 싶다면 [주권 대회 실행 가이드](/docs/network/sovereignty/run-a-sovereign-contest)가 그 방법이에요
5. **거버넌스와 연결해 주기** — 여러분의 공동체에서 누가 언어 데이터와 기술에 대한 권한을 가지고 있나요? Network의 주권 모델에는 거버넌스 파트너가 필요해요
