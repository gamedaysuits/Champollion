# 연결 강도

네트워크 맵이 두 언어 사이에 호를 그릴 때, 그 색상은 다음
한 가지 질문에 답해요: **두 언어 사이에서 측정된 최고의 번역이
얼마나 좋은가 — 정직하게 말해서?**

정직하다는 부분이 들리는 것보다 어려워요. 이 페이지는 쉬운
말로, 색상 뒤에 있는 숫자를 설명해요.

## 문제: 원시 점수는 0에서 0이 아니에요

우리 점수 대부분은 **chrF++**(문자 n-gram F-score, [Popović
2017](https://aclanthology.org/W17-4770/))예요 — 번역의 문자와
단어가 참조 번역과 얼마나 겹치는지를 0에서 100까지 측정해요.

하지만 *무작위 텍스트는 0이 아니에요*. 모든 문자 체계는 어느 정도
겹침을 "공짜로" 제공해요: 구별되는 문자가 적은 정서법이나, 길고
예측 가능한 단어를 가진 언어는 "번역"이 무의미하더라도 0보다
측정 가능하게 높은 점수를 받아요. 그 공짜 겹침 — **우연 바닥값** —
은 언어마다 달라요. 우리 측정에서는 약 1.6(중국 문자)부터
13 이상(일부 라틴 및 아랍 문자 언어)까지 범위에 걸쳐 있어요.
원시 chrF++ 14는 어떤 언어에서는 거의 무작위 잡음이고 다른
언어에서는 실제 신호예요 — 그래서 원시 chrF++는 **언어 간에
비교할 수 없고**, 이를 기준으로 색을 입힌 맵은 일부 문자 체계를
슬며시 돋보이게 만들 거예요.

## 해결책: 바닥값을 빼기

**우연 보정 chrF++(cchrF++)**는 점수를 재조정해서 0이 *해당
언어에서* "우연보다 나을 것이 없음"을 의미하고 1이 완벽함을
의미하도록 해요:

```
cchrF++ = (chrF++ − floor) / (100 − floor)
```

바닥값은 가정한 것이 아니라 측정한 것이에요: 각 언어마다 Monte-Carlo
추정을 실행해요 — 수천 개의 무작위 동일 정서법 기준선을 실제 참조에
대해 점수 매기며 — 공개적으로 이용 가능한 단일어 텍스트만 사용해요
(FLORES-200 dev, 소스에서 가져오며 절대 재배포하지 않음). 바닥값
표는 현재 196개 언어를 다루며 Champollion에서 파생된 산출물이에요
(`champollion-derived` 출처; `cli/website/scripts/build-cchrf-floors.mjs`로 재생성됨).

두 가지 보수적인 규칙이 보정을 정직하게 유지해요:

- **한 쌍은 양쪽 모두 측정된 바닥값이 있을 때만 보정돼요.** 어느
  한쪽이라도 없으면, 호는 중립적인 슬레이트 색으로 표시되고 —
  *측정됨, 바닥값 미상* — 절대 색상 램프에 오르지 않아요.
- **한 쌍은 두 바닥값 중 더 높은 것을 사용해요.** 보정은 강도를
  과소평가할 수는 있어도, 절대 부풀리지 않아요.

## 계층 구조에서 cchrF++의 위치

cchrF++는 우리의 최고의 *자동* 강도 측정치예요 — 계층 구조의
최상위는 아니에요. 가장 신뢰할 수 있는 것부터 가장 덜한 순서로:

1. **사람 검증** — 유창한 화자가 출력을 판단하는 것([화자
   검증](/docs/network/specifications/speaker-validation)). 어떤
   자동적인 것도 이를 능가하지 못해요.
2. **MQM 스타일 전문가 주석**([Multidimensional Quality
   Metrics](https://aclanthology.org/2014.tc-1.6/), Lommel et al.) —
   WMT가 골드 판정에 사용하는 프로토콜; 비싸고, 드물고, 아주
   좋아요.
3. **cchrF++** — 우연 보정되어, 언어 간에 비교 가능하고, 어디서나
   계산이 저렴해요.
4. **원시 chrF++ / BLEU / 신경망 메트릭** — 하나의 데이터셋 내에서
   유용해요; 각각이 여러분의 쌍에서 사람 판단을 얼마나 나쁘게
   추적할 수 있는지는 [메트릭 신뢰성](/docs/network/specifications/metric-reliability)을
   참고하세요.

사람이 검증한 결과와 MQM 등급 결과가 보드에 들어오면, 같은 쌍에
대해 자동 점수보다 우선해요.

## 맵이 이를 그리는 방법

각 시각 채널은 정확히 하나의 의미를 전달해요:

| 채널 | 의미 |
|---------|---------|
| **색상** | cchrF++ 대역 — 다섯 단계, 빨강에서 부드러운 초록까지: *바닥값 근처* (&lt; 0.15), *약함* (0.15–0.35), *발전 중* (0.35–0.55), *사용 가능* (0.55–0.75), *강함* (≥ 0.75) |
| **중립 슬레이트** | 측정되었지만, 최소한 한쪽의 우연 바닥값을 알 수 없음 — 절대 색상 램프에 놓이지 않음 |
| **점선 + 흐림** | 잠정적: 테스트 세트가 [유의성 바닥값](/docs/network/specifications/significance) 아래(n &lt; 100)이며, 여기서는 ~5 chrF++ 이내의 점수 차이가 잡음임 |
| **너비** | 색상 대역을 반복함(접근성 중복성이며, 두 번째 변수가 아님) |

**측정된** 쌍만 강도 램프에 올라가요. 등록된 쌍 — 측정 대기 중이지만
아직 점수가 매겨지지 않은 — 은 희미한 단색 가는 선으로 나타나며,
그 색상은 오직 *오늘 그 쌍에 도달할 수 있는 방법*(상용 API ·
오픈 소스 모델 · 프런티어, 제공자 없음)만 말해줄 뿐, 무엇이든 얼마나
잘 번역되는지는 절대 말해주지 않아요. 두 어휘는 의도적으로
분리되어 있어요: 은은한 단색 실 = 도달 가능성, 빨강→초록 램프 =
측정된 강도. 호의 기저 점수는 공개 보드에서 그 쌍에 대해 측정된
최고의 실행이며, 새 실행이 들어오면 자동으로 갱신돼요.

## 세부 사항

- 바닥값은 단일어 텍스트만으로 추정한 메트릭 × 정서법 속성이에요;
  병렬 코퍼스 내용은 관여하거나 저장되지 않아요.
- cchrF++는 번역이 우연을 이기는지와 얼마나 이기는지를 알려줘요 —
  의미, 문체, 또는 문화적 적합성을 **검증하지는** 않아요. 그것들은
  여전히 사람의 판단이에요([정직한 한계](/docs/network/honest-limitations)).
- 우연 바닥값 방법론은 Champollion 연구예요; 바닥값 지도와 보정은
  검증되고 이의를 제기받을 수 있도록 정확히 여기에 공개돼요.
