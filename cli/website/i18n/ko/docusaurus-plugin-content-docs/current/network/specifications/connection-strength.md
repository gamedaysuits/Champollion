# 연결 강도

네트워크 맵이 두 언어 사이에 호(arc)를 그릴 때, 그 색상은 한 가지 질문에 답해요: **이 언어 쌍이 실제로 측정된 적이 있는가?**

이는 이전에 맵이 주장했던 것보다 의도적으로 축소된 정보예요. 2026-09-04 이전까지는 우연 보정(chance-corrected) 척도를 기준으로 최상의 번역이 얼마나 *우수한지*를 5단계 강도 램프로 호의 색상을 나타냈어요. 하지만 이 램프는 이제 폐지되었어요. 이 페이지에서는 그 뒤에 있던 수치와, 이를 제거하는 것이 왜 정직한 선택이었는지, 그리고 이제 맵이 무엇을 보여주는지 설명해요.

## 문제: 원시 점수는 0에서 0이 아니에요

우리 점수 대부분은 **chrF++**(문자 n-gram F-score, [Popović
2017](https://aclanthology.org/W17-4770/))예요 — 번역의 문자와
단어가 참조 번역과 얼마나 겹치는지를 0에서 100까지 측정해요.

하지만 *무작위 텍스트는 0이 아니에요*. 모든 문자 체계는 어느 정도
겹침을 "공짜로" 제공해요: 구별되는 문자가 적은 정서법이나, 길고
예측 가능한 단어를 가진 언어는 "번역"이 무의미하더라도 0보다
측정 가능하게 높은 점수를 받아요. 그 공짜 겹침 — **우연 바닥값** —
은 언어마다 달라요. 우리 측정에서는 약 1.6(중국 문자)부터
13 이상(일부 라틴 및 아랍 문자 언어)까지 범위에 걸쳐 있어요.
원시 chrF++ 14는 어떤 언어에서는 거의 무작위 잡음이고 다른
언어에서는 실제 신호예요 — 그래서 원시 chrF++는 **언어 간에
비교할 수 없고**, 이를 기준으로 색을 입힌 맵은 일부 문자 체계를
슬며시 돋보이게 만들 거예요.

이 문제는 실재하며, 바로 그렇기 때문에 맵에서 언어 간 강도 순위를 매기지 **않는** 것이에요. 이는 저희가 아직 해결하지 못한 문제예요.

## 저희가 구축한 보정 방식과, 더 이상 맵에 색상으로 표시하지 않는 이유

**우연 보정 chrF++(cchrF++)**는 *해당 언어에서* 0이 "우연보다 나을 것이 없음"을 의미하고 1이 완벽함을 의미하도록 점수의 척도를 재조정해요:

```
cchrF++ = (chrF++ − floor) / (100 − floor)
```

바닥값(floor)은 추정한 것이 아니라 직접 측정한 값이에요. 각 언어별로 공개된 단일 언어 텍스트(원본에서 가져온 FLORES-200 dev, 재배포되지 않음)만을 사용하여 실제 참조 번역에 대해 채점한 동일 표기법의 무작위 베이스라인 수천 개를 대상으로 몬테카를로(Monte-Carlo) 추정을 실행해요. 이 바닥값 표는 196개 언어를 다루며 Champollion에서 파생된 산출물이에요.

**이 보정이 실제로 입증하는 것.** 우연 바닥값은 실제로 존재하며, 문자 체계에 따라 최대 9배가량 차이가 나고, 사람의 품질 라벨링 없이 단일 언어 텍스트만으로도 추정할 수 있어요. 이 값을 빼면 단순 베이스라인에서 우연 요소를 확실하게 제거할 수 있어요. 예를 들어 핀란드어에서 원본을 그대로 복사하는 꼼수를 쓰면 원시 점수가 15점 이상 나오지만 약 2.5점으로 떨어지고, 대부분의 언어에서는 정확히 0으로 떨어져요. 이때 제거되는 "우연"은 표면적인 통계일 뿐이며, 잔여 의미가 아니에요.

**이 보정이 입증하지 못하는 것.** 이 보정은 모든 언어에서 **0**이 같은 의미를 갖게 해 줘요. 하지만 **40**이 같은 의미를 갖게 만들지는 못해요. 바닥값 이상의 영역에서 보정은 단순한 척도 재조정일 뿐이며, 서로 다른 언어 간에 동일한 *품질*이 동일한 보정 점수로 귀결된다는 증거는 점수대 최하단에서만 입증되었어요. 사람이 평가한 판단 풀(pool)과 대조해 보면, 바닥값이 실제로 다른 경우에는 도움이 되고 그렇지 않은 경우에는 아무런 영향이 없었으며, 바닥값이 일관되게 낮은 한 풀에서는 인간 평가자와의 일치도를 오히려 *잘못된* 방향으로 이동시켰어요. 이는 저희가 아직 해결하지 못한 결과예요.

공개 맵에 5단계 강도 램프로 색상을 표시하는 것은, 오류의 영향이 가장 치명적인 저자원 언어에 대해 증거가 뒷받침하는 수준 이상의 주장을 하는 것이었어요. 따라서 추가 연구를 통해 이 문제가 명확히 해결될 때까지 해당 램프는 폐지되었어요.

대신 **원시** chrF++ 점수로 색상을 표시하는 것은 결코 대안이 될 수 없었다는 점에 유의해 주세요. 원시 점수는 언어 간에 전혀 비교할 수 없으며, 이것이 바로 보정 방식을 구축했던 이유이기도 해요. 이진(binary) 인코딩은 더 불완전한 무언가로의 강등이 아니라, 정직한 대안이에요.

## 계층 구조에서 측정이 위치하는 곳

신뢰도가 가장 높은 순서부터 나열하면 다음과 같아요:

1. **인간 검증** — 유창한 화자가 출력을 평가해요([화자 검증](/docs/network/specifications/speaker-validation)). 어떤 자동 측정 방식도 이를 넘어서지 못해요.
2. **MQM 스타일 전문가 주석**([다차원 품질 지표(Multidimensional Quality Metrics)](https://aclanthology.org/2014.tc-1.6/), Lommel et al.) — WMT가 골드 판정에 사용하는 프로토콜로, 비용이 많이 들고 드물지만 매우 우수해요.
3. **자동 점수 — 단일 언어 쌍 내에서만 해당.** 원시 chrF++, BLEU, COMET 등은 *동일한* 쌍에서 시스템들을 비교할 때 유용해요. 각 지표가 여러분의 언어 쌍에서 인간의 판단을 얼마나 제대로 추적하지 못할 수 있는지는 [지표 신뢰도](/docs/network/specifications/metric-reliability)를 참고하세요.
4. **언어 간 강도.** 저희는 순위를 공개하지 않아요. 위 내용을 참고하세요.

사람이 검증한 결과와 MQM 등급 결과가 보드에 들어오면, 같은 쌍에
대해 자동 점수보다 우선해요.

## 맵이 이를 그리는 방법

각 시각 채널은 정확히 하나의 의미를 전달해요:

| 채널 | 의미 |
|---------|---------|
| **색상** | 측정됨. 램프 없이 단일 색상 — 해당 호는 실행을 통해 이 언어 쌍이 채점되었음을 나타낼 뿐이며, 얼마나 잘 되었는지는 나타내지 않아요 |
| **점선 + 흐림** | 잠정적: 테스트 세트가 [유의성 바닥값](/docs/network/specifications/significance)(n &lt; 100) 미만이며, 이 경우 약 5 chrF++ 이내의 점수 차이는 노이즈예요. 이는 어떤 지표와도 무관한 샘플 크기 자체의 특성이에요 |
| **두께** | 일정함. 더 이상 인코딩할 정보가 없어요 |

오직 **측정된** 언어 쌍만이 측정된 호를 그려요. 등록된 쌍(측정 대기열에 올랐으나 아직 채점되지 않음)은 희미한 단색의 가는 선으로 나타나며, 그 색상은 *현재 해당 쌍에 어떻게 도달할 수 있는지*(상용 API · 오픈소스 모델 · 프론티어, 제공자 없음)만을 나타낼 뿐, 번역 품질이 얼마나 우수한지는 절대 나타내지 않아요. 두 시각적 체계는 의도적으로 완전히 구분되어 있어요: 톤 다운된 단색 선 = 도달 가능성, 하나의 측정 색상 = 측정됨.
호의 기본 점수는 공개 보드에 등록된 해당 쌍의 가장 우수한 측정 실행 결과이며, 새 실행이 반영될 때마다 자동으로 갱신돼요. 그리고 호를 열었을 때 언어 쌍 내부의 수치로 표시되며, 언어 간 순위로는 절대 표시되지 않아요.

## 세부 사항

- 우연 바닥값은 단일 언어 텍스트만을 기반으로 추정된 지표 × 표기법 특성이며, 병렬 코퍼스 콘텐츠는 전혀 관여되거나 저장되지 않아요.
- 바닥값 아틀라스와 보정 방식은 공개된 연구 결과로 유지되며, 코드는 테스트 상태로 리포지토리에 남아 있어요. 어떤 공개 사용자 인터페이스에도 연결되어 있지 않아요.
- **바닥값만 보정할 뿐, 상한선은 보정하지 않아요.** 진정으로 우수한 번역이 도달할 수 있는 최고 점수는 언어마다 여전히 다르며, 이 보정 방식은 이에 대해 아무런 역할을 하지 않아요.
- **문자 체계를 공유하는 원본 복사에 대한 방어책이 아니에요.** 원본과 대상 언어가 문자 체계를 공유할 경우, 원본을 단순히 복사한 출력이라도 우연 기준을 넘는 점수를 받을 수 있어요.
- **단일 언어 쌍 내에서 시스템의 순위를 바꿀 수 없어요.** 바닥값 이상의 영역에서 보정은 단순한 척도 재조정이기 때문에 쌍 내부의 순위는 보정 전후가 동일해요. 따라서 이 방식의 유일하게 가능한 가치는 언어 쌍 간 비교에 있었어요.
- 측정된 호는 해당 언어 쌍이 채점되었음을 알려줄 뿐이에요. 의미, 어조(register), 문화적 적합성을 검증하지 **않아요**. 이러한 요소는 여전히 인간의 판단 영역으로 남아 있어요([솔직한 한계](/docs/network/honest-limitations)).
- 우연 바닥값 방법론은 Champollion의 연구 성과이며, 검증받고 비판받을 수 있도록 여기에 공개되어 있어요.
