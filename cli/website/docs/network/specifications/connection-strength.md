# Connection Strength

When the network map draws an arc between two languages, its colour answers
one question: **how good is the best measured translation between them —
honestly?**

The honest part is harder than it sounds. This page explains, in plain
language, the number behind the colour.

## The problem: raw scores aren't zero at zero

Most of our scores are **chrF++** (character n-gram F-score, [Popović
2017](https://aclanthology.org/W17-4770/)) — it measures how much a
translation's characters and words overlap with a reference translation, from
0 to 100.

But *random text is not zero*. Every writing system gives some overlap "for
free": an orthography with few distinct characters, or long predictable
words, scores measurably above zero even when the "translation" is nonsense.
That free overlap — the **chance floor** — differs by language. In our
measurements it ranges from about 1.6 (Chinese script) to more than 13
(some Latin- and Arabic-script languages). A raw chrF++ of 14 is near-random
noise in one language and a real signal in another — so raw chrF++ is **not
comparable across languages**, and a map coloured by it would quietly
flatter some scripts.

## The fix: subtract the floor

**Chance-corrected chrF++ (cchrF++)** rescales the score so that 0 means "no
better than chance" *in that language* and 1 means perfect:

```
cchrF++ = (chrF++ − floor) / (100 − floor)
```

The floors are measured, not assumed: for each language we run a Monte-Carlo
estimate — thousands of random same-orthography baselines scored against real
references — using publicly available monolingual text only (FLORES-200 dev,
fetched from source, never redistributed). The floor table currently covers
196 languages and is a Champollion-derived artifact
(`champollion-derived` provenance; regenerated by
`cli/website/scripts/build-cchrf-floors.mjs`).

Two conservative rules keep the correction honest:

- **A pair is corrected only when BOTH sides have a measured floor.** If
  either is missing, the arc shows in neutral slate — *measured, floor
  unknown* — and never rides the colour ramp.
- **The pair uses the HIGHER of the two floors.** The correction can
  understate strength, never inflate it.

## Where cchrF++ sits in the hierarchy

cchrF++ is our best *automatic* strength measure — it is not the top of the
hierarchy. From most to least trustworthy:

1. **Human verification** — fluent speakers judging output ([speaker
   validation](/docs/network/specifications/speaker-validation)). Nothing
   automatic outranks it.
2. **MQM-style expert annotation** ([Multidimensional Quality
   Metrics](https://aclanthology.org/2014.tc-1.6/), Lommel et al.) — the
   protocol WMT uses for its gold judgments; expensive, rare, very good.
3. **cchrF++** — chance-corrected, comparable across languages, cheap to
   compute everywhere.
4. **Raw chrF++ / BLEU / neural metrics** — useful within one dataset;
   see [Metric Reliability](/docs/network/specifications/metric-reliability)
   for how badly each can track human judgment on your pair.

As human-verified and MQM-grade results enter the board, they take
precedence over automatic scores for the same pair.

## How the map draws it

Each visual channel carries exactly one meaning:

| Channel | Meaning |
|---------|---------|
| **Colour** | cchrF++ band — five steps, red to soft green: *near floor* (&lt; 0.15), *weak* (0.15–0.35), *developing* (0.35–0.55), *usable* (0.55–0.75), *strong* (≥ 0.75) |
| **Neutral slate** | measured, but the chance floor is unknown for at least one side — never placed on the colour ramp |
| **Dashed + dimmed** | provisional: the test set is below the [significance floor](/docs/network/specifications/significance) (n &lt; 100), where score gaps within ~5 chrF++ are noise |
| **Width** | repeats the colour band (accessibility redundancy, not a second variable) |

Only **measured** pairs ride the strength ramp. Registered pairs — queued
for measurement but not yet scored — appear as faint flat-coloured
hairlines whose colour says only *how the pair is reachable today*
(commercial API · open-source model · frontier, no provider), never how
well anything translates. The two vocabularies are deliberately disjoint:
muted flat threads = reachability, the red→green ramp = measured strength.
An arc's underlying score is the best measured run for that pair on the
public board, refreshed automatically as new runs land.

## The fine print

- Floors are metric × orthography properties estimated from monolingual text
  only; no parallel corpus content is involved or stored.
- cchrF++ tells you a translation beats chance and by how much — it does
  **not** validate meaning, register, or cultural fit. Those remain human
  judgments ([honest limitations](/docs/network/honest-limitations)).
- The chance-floor methodology is Champollion research; the floor atlas and
  the correction are published here precisely so they can be checked and
  challenged.
